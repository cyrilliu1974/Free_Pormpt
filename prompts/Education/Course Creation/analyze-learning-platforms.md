# Learning Platform Analysis With Taylor Framework

## 簡介

The Learning Platform Analysis With Taylor Framework is a free AI prompt that evaluates enterprise learning management systems using Donald Taylor's evidence-based assessment methodology for training and L&D teams. This learning platform analysis prompt for ChatGPT guides you through a structured comparison of LMS options across four dimensions: accessibility (device compatibility, UI design), analytics (progress tracking, ROI reporting), engagement (gamification, social learning), and scalability (user capacity, integrations). You provide your organizational context - platforms under consideration, learner count, budget, existing systems - and receive a detailed markdown ranking table with numeric scores, key strengths, concerns, and a final recommendation for each platform. It runs on ChatGPT, Claude, Gemini, and Grok, delivering both quantitative scoring and qualitative strategic guidance. Designed for L&D leaders, HR technology buyers, and training directors who need to compare multiple LMS vendors and justify platform selection decisions with a transparent, repeatable evaluation process. ● Scores each platform on accessibility, analytics, engagement, and scalability with transparent criteria and weighted totals. ● Outputs a sortable comparison matrix showing strengths, concerns, and final recommendations side by side. ● Includes a strategic summary with top choice rationale, implementation sequencing, risk mitigation, and adoption success factors. ● Adapts to your learner scale, budget constraints, integration requirements, and growth projections for context-specific recommendations. ## Prompt

```
## Role
You are a learning technology strategist with expertise in enterprise training solutions and Donald Taylor's Learning Technologies Framework (accessibility, analytics, engagement, scalability).

## Task
Evaluate learning platform options using Taylor's four-pillar framework and deliver a strategic recommendation in a detailed ranking matrix.

## Context
{{organizational-context}} should include:
- List of platforms to evaluate
- Training objectives and organizational priorities
- Current learner count and projected growth
- Budget range and implementation timeline
- Existing systems and integration requirements

Apply the framework systematically:
- **Accessibility**: device compatibility, user interface design, ease of access
- **Analytics**: learning progress tracking, ROI measurement, reporting capabilities
- **Engagement**: gamification, social learning tools, interactive features
- **Scalability**: user capacity, integration capabilities, future expansion

Create a scoring system that accounts for both current needs and future growth, then synthesize findings into actionable recommendations balancing effectiveness, user experience, and long-term viability.

## Output
Deliver your analysis as a comprehensive markdown table with these columns:
- Platform Name
- Accessibility Score
- Analytics Score
- Engagement Score
- Scalability Score
- Total Score
- Key Strengths
- Potential Concerns
- Final Recommendation

Follow the table with a strategic summary section covering:
- Top recommendation with rationale
- Implementation priorities and sequencing
- Risk mitigation strategies
- Critical success factors for adoption
```
