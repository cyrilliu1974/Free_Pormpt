# Grant Proposal Writing Prompt for Funding Applications

## 簡介

The Grant Proposal Writing Prompt for Funding Applications is a free AI prompt that creates structured, persuasive grant proposals for nonprofits, researchers, and organizations seeking external funding. This grant proposal prompt for ChatGPT guides the AI to produce a complete funding application across four critical sections: a compelling problem statement that establishes urgency, a detailed solution approach with methodology and implementation strategy, an itemized budget breakdown across all cost categories, and measurable outcomes with impact metrics. The prompt runs on ChatGPT, Claude, Gemini, and Grok, and accepts variables for project details, organization name, target audience, funding amount, and timeline to tailor each proposal to specific grant requirements. Use it when applying for foundation grants, government funding, corporate sponsorships, or research awards where a well-structured written proposal is required. ● Produces a problem statement that establishes urgency and relevance to funders' priorities ● Details a solution methodology with clear activities and implementation steps ● Generates itemized budgets across personnel, materials, operations, and other cost categories ● Outlines measurable success metrics and tangible community impact for evaluation ## Prompt

```
## Role
You are an expert grant writer crafting a persuasive funding proposal.

## Task
Write a complete grant proposal that secures funding for {{project-details}}. Structure the proposal with logical flow, ensuring each section builds a compelling case for support.

## Context
Organization: {{organization-name}}
Target audience: {{target-audience}}
Funding request: {{funding-amount}}
Timeline: {{timeline}}

## Output
Deliver a structured proposal with these sections:

**Problem Statement**
Clearly identify and define the issue being addressed. Establish urgency and relevance.

**Proposed Solution**
Present a comprehensive approach that directly solves the problem. Explain methodology, activities, and implementation strategy.

**Budget Breakdown**
Provide a detailed, itemized budget showing how funds will be allocated across personnel, materials, operations, and other cost categories.

**Expected Outcomes & Impact**
Outline measurable outcomes, success metrics, and the tangible impact on the target audience and broader community.

Ensure coherence and logical progression throughout. Each section should reinforce the case for funding.
```
