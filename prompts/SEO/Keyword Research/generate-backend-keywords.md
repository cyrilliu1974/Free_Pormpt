# Backend Keyword Research Generator for SEO

## 簡介

The Backend Keyword Research Generator for SEO is a free AI prompt that produces a comprehensive keyword analysis table with search volume, difficulty scores, and actionable implementation guidance for marketers and SEO specialists. This backend keyword research prompt for ChatGPT takes three inputs - your marketing subcategory, target audience, and competitive context - and returns a structured table of high-traffic keywords alongside their performance metrics. It then delivers strategic recommendations for deploying those keywords across URL structures, meta tags, on-page elements, and content architecture. The prompt works on ChatGPT, Claude, and Gemini, and is designed for marketers who need to move quickly from keyword discovery to backend implementation without switching between multiple SEO tools. Reach for this prompt when you're planning a new content hub, optimizing existing pages, or need to justify keyword priorities to stakeholders with clear difficulty-versus-opportunity data. ● Produces a sortable keyword table with search volume and difficulty columns for fast prioritization ● Includes tier-specific deployment guidance - where to place high-difficulty versus low-competition terms ● Delivers technical SEO considerations tailored to the competitive landscape you specify ● Outputs priority actions ranked by opportunity, so you know what to optimize first ## Prompt

```
## Role
You are an SEO specialist conducting keyword research for a marketing subcategory.

## Task
Generate a comprehensive list of relevant keywords with search volume and difficulty metrics, then provide strategic recommendations for backend optimization.

## Context
Marketing subcategory: {{marketing-subcategory}}
Target audience: {{target-audience}}
Competitive landscape: {{competitive-context}}

## Process
1. Identify high-traffic keywords relevant to the subcategory using standard keyword research methodologies
2. Analyze search volume and difficulty for each keyword to assess value and competitiveness
3. Prioritize keywords that will drive qualified traffic from the target audience
4. Develop strategic recommendations for incorporating keywords into on-page elements, URL structure, meta tags, and content architecture

## Output
Deliver your analysis as:

**Keyword Research Table:**

| Keyword | Search Volume | Difficulty |
|---------|--------------|------------|
| | | |

**Implementation Recommendations:**
- Specific guidance on where and how to deploy each keyword tier
- Technical SEO considerations for the identified keyword set
- Priority actions based on difficulty vs. opportunity
```
