# Meta Title Template Generator for E-Commerce SEO

## 簡介

The Meta Title Template Generator for E-Commerce SEO is a free AI prompt that creates reusable, high-converting meta title templates optimized for search visibility and click-through rates. This meta title prompt for ChatGPT, Claude, Gemini, and Grok produces collections of 50-60 character templates organized by psychological trigger - urgency, trust signals, benefit-driven messaging, and social proof. Each template uses placeholder variables like [PRODUCT], [BENEFIT], and [BRAND] so you can adapt them across product lines while maintaining brand consistency. E-commerce teams use it to standardize title creation, A/B test messaging strategies, and ensure every product page makes a strong first impression in search results. Reach for this prompt when you need scalable title frameworks that work across catalogs, comply with character limits, and address different competitive scenarios and campaign goals. ● Outputs 3-4 templates per psychological category (urgency, trust, benefit, social proof) with character counts and usage guidance. ● Includes placeholder variables that adapt across product lines and maintain brand voice. ● Provides example applications and recommendations for product type, competition level, and campaign goal. ● Balances SEO compliance with conversion-focused copywriting techniques proven to increase click-through rates. ## Prompt

```
## Role
You are an SEO copywriter specializing in e-commerce meta title optimization that balances click-through rate psychology with search engine compliance.

## Task
Generate a collection of reusable meta title templates (50-60 characters) that incorporate psychological triggers—urgency, trust signals, benefit-driven messaging, and social proof. Each template should use placeholder variables that adapt across product lines while maintaining brand consistency.

## Context
**Business & Products:**
{{business-context}}

**Target Keywords:**
{{target-keywords}}

**Brand Positioning:**
{{brand-positioning}}

Meta titles are the first search result impression. Templates should maximize click-through by addressing search intent and differentiation while staying within character limits.

## Output
Structure your response with:

- **Category headings** for each template type (Urgency-Driven, Trust-Focused, Benefit-Led, Social Proof)
- **Bullet points** for each template with:
  - The template itself using [PRODUCT] [BENEFIT] [BRAND] placeholders
  - Character count range
  - When to use (product type, competition level, campaign goal)
  - Example application

Provide 3-4 templates per psychological trigger category, ensuring variety in structure and emphasis.
```
