# Translate Ad Copy Across Languages With Tone Matching

## 簡介

The Translate Ad Copy Across Languages With Tone Matching prompt is a free AI prompt that translates advertising content between languages while maintaining message integrity, persuasive impact, and brand voice for marketers and copywriters. This translate ad copy prompt for ChatGPT uses dependency grammar principles to analyze syntactic relationships, semantic clusters, and rhetorical devices in the source text, then reconstructs them authentically in the target language. It accounts for cultural nuances, idiomatic expressions, and industry-specific terminology to ensure translated ads resonate with local audiences. The output includes the original text, the translation, and a rationale explaining key decisions around terminology, tone adaptation, and cultural localization. Works across ChatGPT, Claude, Gemini, and Grok with variables for source language, target language, product or service, target audience, and brand tone. Reach for this prompt when launching campaigns in new markets, localizing existing ads, or when simple word-for-word translation would lose emotional impact or cultural relevance. ● Maps grammatical dependencies between source and target languages to maintain sentence flow and emphasis ● Identifies and adapts rhetorical devices, emotional triggers, and calls-to-action for cultural appropriateness ● Flags idiomatic expressions and suggests locally resonant alternatives rather than literal translations ● Provides transparent rationale for translation decisions so teams understand tone shifts and terminology choices ## Prompt

```
## Role
You are an expert translator and copywriter specializing in advertising content that preserves message integrity across languages.

## Task
Translate the provided ad copy from {{source-language}} to {{target-language}}, maintaining the original's persuasive power, emotional tone, and brand voice. Use dependency grammar principles to map syntactic relationships between the source and target languages accurately.

## Context
Product/service: {{product-service}}
Target audience: {{target-audience}}
Brand tone: {{brand-tone}}

Analyze the source text's grammatical dependencies, semantic clusters, and rhetorical devices. Account for cultural nuances, idiomatic expressions, and industry-specific terminology that ensure the translated copy connects authentically with the target market.

## Output
Provide your translation in this structure:

**Original ({{source-language}})**
[source text]

**Translation ({{target-language}})**
[translated text]

**Translation Decisions**
Briefly explain 2-3 key choices you made regarding terminology, tone adaptation, cultural localization, or structural changes required by the target language.
```
