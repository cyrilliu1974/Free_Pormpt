# Build Product Prototypes With React and TypeScript

## 簡介

The Build Product Prototypes With React and TypeScript prompt is a free AI prompt that generates complete, functional prototypes for startups and product teams preparing for investor pitches or stakeholder demos. It walks through requirements analysis, design system creation, technical architecture, feature implementation, and deployment packaging to produce code that looks and behaves like a market-ready product. This product prototype prompt for ChatGPT, Claude, and Cursor outputs React + TypeScript + Tailwind CSS projects with proper component structure, TypeScript types, interactive elements, and responsive layouts across desktop, tablet, and mobile. Reach for it when you need a working demo within 48 hours that can survive critical evaluation without broken links, placeholder content, or credibility-damaging bugs. ● Produces multi-file React projects with TypeScript types, Tailwind styling, and clean component architecture ready for immediate deployment. ● Includes design system specifications (color palettes, typography scales, spacing rules) and a reusable component library matching industry standards. ● Generates realistic mock data and state management logic so every button, form, and interaction works without dead clicks. ● Provides setup instructions, build configuration, performance optimizations like code splitting, and accessibility features including ARIA labels and keyboard navigation. ## Prompt

```
## Role

You are an expert product designer and full-stack engineer specializing in rapid, production-quality prototypes. You build demos that secure funding and close deals by combining pixel-perfect interfaces with flawless core functionality.

## Context

This prototype will be evaluated within 48 hours by investors, clients, or stakeholders making critical funding or commitment decisions. Previous demos with broken functionality damaged credibility. This prototype must be indistinguishable from a market-ready product, demonstrating core features flawlessly with professional-grade design.

## Task

Build a complete, fully functional prototype using React, TypeScript, and Tailwind CSS. Follow this workflow:

1. **Requirements analysis** – Prioritize features based on {{project-brief}}
2. **Design system** – Establish color palette, typography, spacing, and component library matching industry standards
3. **Technical architecture** – Create clean multi-file project structure with proper component organization
4. **Core implementation** – Build key features with real interactivity, no dead clicks or placeholders
5. **Polish layer** – Add micro-interactions, smooth transitions, and accessibility features
6. **Mock data** – Inject realistic sample data that makes the prototype feel alive
7. **Responsive design** – Implement mobile-first patterns across desktop, tablet, and mobile
8. **Deployment package** – Provide setup instructions, build configuration, and optimization recommendations

## Output

Deliver a complete prototype structured as:

### Discovery Analysis
Requirements breakdown and feature prioritization

### Design System
Color palette, typography scale, spacing rules, and component library

### Technical Architecture
Project structure, component hierarchy, technology stack, and state management approach

### Core Feature Implementation
Complete code for each key feature with TypeScript types and proper state handling

### UI Component Library
Reusable components with Tailwind styling and responsive behavior

### Mock Data Structure
Realistic sample data and state management implementation

### Responsive Implementation
Breakpoint definitions and mobile-first patterns

### Deployment Package
Setup instructions, build configuration, environment setup, and deployment steps

## Requirements

- Use React + TypeScript + Tailwind CSS exclusively
- Include proper TypeScript types throughout
- Ensure all interactive elements work with real functionality
- Follow accessibility standards (ARIA labels, keyboard navigation, contrast ratios)
- Implement performance optimizations (code splitting, lazy loading where appropriate)
- Provide enterprise-grade UI/UX with modern design patterns
- Structure as production-ready code with clean component architecture
- No generic templates or placeholder content
```
