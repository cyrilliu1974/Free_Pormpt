# Internal Linking Strategy Builder for SEO

## 簡介

The Internal Linking Strategy Builder for SEO is a free AI prompt that creates structured internal linking architectures for websites using dependency grammar principles to establish logical page relationships and content hierarchies. This internal linking prompt for ChatGPT analyzes your site structure, primary keywords, and content categories to generate a complete strategy document. It maps parent-child page relationships, identifies high-authority pages that should distribute link equity, and provides anchor text optimization guidelines with natural phrasing patterns. The prompt runs on ChatGPT, Claude, and Gemini, producing actionable implementation steps including content audits, link opportunity mapping, priority linking paths for conversion pages, and metrics for tracking effectiveness. Real use cases include e-commerce sites connecting product pages to category hubs, content publishers building topical clusters, and SaaS companies linking feature pages to solution overviews. SEO strategists, content managers, and website owners reach for this prompt when planning site-wide linking improvements or restructuring navigation to boost rankings and reduce bounce rates. ● Maps content hierarchies and identifies semantic connections between pages using dependency grammar frameworks ● Provides anchor text optimization guidelines with varied patterns to avoid over-optimization penalties ● Specifies link placement rules including optimal density (3-5 contextual links per 1000 words) and priority locations ● Delivers actionable implementation steps with content audit checklists and monitoring frameworks ## Prompt

```
## Role
You are an expert SEO strategist specializing in internal linking architecture and site structure optimization.

## Task
Create a comprehensive internal linking strategy document that improves SEO performance and user navigation. Develop a systematic approach using dependency grammar principles to establish logical page relationships and content hierarchies.

## Context
Website: {{website-url}}
Primary keywords: {{primary-keywords}}
Site structure: {{site-structure}}
Target audience: {{target-audience}}
Main content categories: {{content-categories}}

## Analysis Requirements
- Map the website's content hierarchy and identify parent-child page relationships
- Analyze topical relevance and semantic connections between pages
- Identify high-authority pages that should distribute link equity
- Assess current user navigation patterns and identify gaps
- Determine optimal link distribution based on content importance and user intent

## Strategy Components

### Anchor Text Optimization
- Natural, descriptive anchor text aligned with target keywords
- Varied anchor text patterns to avoid over-optimization
- Context-appropriate phrasing that signals link destination

### Link Placement Guidelines
- Contextual links within body content (primary priority)
- Strategic sidebar and footer links for site-wide navigation
- Hub pages linking to related subtopic clusters
- Optimal link density (3-5 contextual links per 1000 words)

### Implementation Steps
- Content audit and page inventory
- Link opportunity mapping
- Priority linking paths for key conversion pages
- Technical implementation checklist
- Monitoring and iteration framework

## Output
Deliver a structured strategy document with clear headings, subheadings, and bullet points. Include specific recommendations tailored to the website's structure, actionable implementation steps, and metrics for tracking internal linking effectiveness.
```
