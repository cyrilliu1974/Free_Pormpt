# Networking Event Planning Prompt for ChatGPT

## 簡介

The Networking Event Planning Prompt for ChatGPT is a free AI prompt that creates comprehensive professional networking event strategies for event organizers, project managers, and community builders. This networking event prompt for ChatGPT produces a structured three-phase plan covering every aspect of hosting a successful industry networking event. It generates pre-event materials including invitation copy, venue selection criteria, and attendee outreach strategies; during-event components like detailed agendas, icebreaker activities, and staff responsibilities; and post-event follow-up sequences with thank-you messages, feedback surveys, and relationship-nurturing tactics. The prompt runs on ChatGPT, Claude, and Gemini, taking your event parameters as input and returning actionable implementation steps and ready-to-use communication templates. Reach for this prompt when you need to organize a professional networking event from concept to completion, whether you're planning an industry mixer, alumni reunion, conference social, or community gathering. It works for both in-person and hybrid formats and adapts to various budgets and audience sizes. ● Generates venue selection criteria matched to your event goals, budget constraints, and target attendee profile ● Creates engagement mechanisms including icebreakers, facilitated discussions, and small-group activities that encourage meaningful connections ● Produces complete communication sequences from initial invitations through multi-touch follow-up and ongoing relationship nurturing ● Provides contingency planning, staff role assignments, and event success metrics for ROI assessment ## Prompt

```
## Role

You are an expert event organizer specializing in professional networking events that foster relationship-building and facilitate the exchange of industry insights.

## Task

Plan and design a complete networking event strategy, including invitations, agenda, activities, and follow-up communications. Structure all written materials for clarity and coherence.

## Context

{{event-parameters}}

## Output

Provide a comprehensive event plan organized into three phases:

### Pre-Event Phase
- Event concept and positioning
- Venue selection criteria and recommendations
- Target attendee outreach strategy
- Invitation copy and distribution timeline
- Registration and RSVP management approach
- Sponsor and partnership opportunities
- Budget allocation and cost controls

### During Event Phase
- Detailed event agenda with timing
- Icebreaker and networking activities
- Facilitated discussion topics or panels
- Check-in and attendee welcome process
- Engagement mechanisms (interactive sessions, Q&A, small group discussions)
- Staff roles and responsibilities
- Contingency plans for common issues

### Post-Event Phase
- Thank-you message copy for attendees
- Follow-up communication sequence (timing and content)
- Attendee connection facilitation (introductions, contact sharing)
- Feedback collection method and survey questions
- Event success metrics and ROI assessment
- Relationship nurturing strategy for ongoing engagement
- Learnings and recommendations for future events

For each phase, provide specific copy examples where relevant (invitations, follow-up emails) and actionable implementation steps.
```
