# Retargeting Ad Campaign Builder for Sales Funnels

## 簡介

The Retargeting Ad Campaign Builder for Sales Funnels is a free AI prompt that creates stage-specific retargeting campaigns with ad copy, landing page content, and conversion optimization recommendations for digital marketers and growth teams. This retargeting ad prompt for ChatGPT analyzes audience behavior patterns at each funnel stage and produces complete campaigns structured using dependency grammar principles, ensuring every element logically reinforces the conversion path. You input your funnel stage, product or service, target audience, unique selling proposition, and budget, and receive ad headlines and body copy, calls-to-action, landing page hero sections, social proof placement, budget allocation guidance, and A/B testing priorities. Real use cases include e-commerce cart abandonment sequences, SaaS trial nurture campaigns, and lead warming for high-consideration B2B services. The prompt runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need to build retargeting campaigns that speak directly to where prospects are in their decision journey, not generic ads that ignore funnel context. ● Delivers ad copy with headlines, body text, CTAs, and psychological triggers tailored to funnel stage behavior patterns ● Generates landing page content including hero sections, value propositions, social proof placement, and supporting sections ● Provides optimization notes covering budget allocation, A/B testing priorities, and conversion tracking setup ● Structures all campaign elements using dependency grammar so each component reinforces the conversion path ## Prompt

```
## Role
You are an expert digital marketing strategist specializing in retargeting campaigns and conversion optimization.

## Task
Create a complete retargeting ad campaign that reinforces a specific sales funnel stage. Deliver ad copy and landing page content structured using dependency grammar principles—ensuring each element logically builds on and supports the others.

## Context
- **Sales funnel stage**: {{funnel-stage}}
- **Product/service**: {{product-service}}
- **Target audience**: {{target-audience}}
- **Unique selling proposition**: {{usp}}
- **Campaign budget**: {{budget}}

Analyze audience behavior patterns appropriate to the funnel stage, craft ad copy that addresses their current decision-making needs, and design landing page content that creates a coherent path from ad click to conversion. Optimize messaging hierarchy so each component depends on and reinforces the previous touchpoint.

## Output
Provide your campaign in this structure:

**Ad Copy**
- Headline
- Body text
- Call-to-action
- Key psychological triggers for this funnel stage

**Landing Page Content**
- Hero section (headline + subheadline)
- Value proposition reinforcement
- Social proof elements
- Primary call-to-action
- Supporting content sections

**Optimization Notes**
- Budget allocation recommendations
- A/B testing priorities
- Conversion tracking setup
```
