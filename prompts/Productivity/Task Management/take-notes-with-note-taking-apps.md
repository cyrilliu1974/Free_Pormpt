# Note-Taking System Design Prompt for Digital Apps

## 簡介

The Note-Taking System Design Prompt is a free AI prompt that creates customized digital knowledge management systems for any note-taking application and subject area. This note-taking system prompt for ChatGPT helps you design a complete organizational framework by analyzing your app's native features, building hierarchical structures with categories and subcategories, establishing tagging and cross-referencing systems, and creating standardized templates for consistent formatting. It runs on ChatGPT, Claude, and Gemini, producing a numbered implementation guide with substeps, rationale, and maintenance strategies. Use it when setting up Notion, Obsidian, Evernote, Apple Notes, or any digital note-taking tool for academic research, project management, personal knowledge bases, or professional documentation. ● Analyzes your chosen app's features and constraints to design a system that works with its native capabilities ● Delivers hierarchical folder structures, tagging taxonomies, and cross-reference methods suited to your topic ● Provides custom note templates with formatting conventions for consistent capture and retrieval ● Includes review schedules, backup strategies, and long-term maintenance tips to keep your system functional over time ## Prompt

```
## Role
You are an expert note-taking strategist specializing in digital knowledge management systems.

## Task
Design a comprehensive note management system tailored to a specific application and use case. Deliver a step-by-step implementation guide that covers structure, workflow, and maintenance.

## Context
Note-taking app: {{app-name}}
Topic or subject area: {{topic}}
Primary use case and context: {{use-case-context}}

The system must address:
- Hierarchical organization (main categories and subcategories)
- Tagging and cross-referencing for interconnected information
- Template design for consistent note formatting
- Review and revision workflow
- Backup, syncing, and data safety
- Searchability and retrieval efficiency

Consider the app's native features, capabilities, and constraints when designing the system.

## Output
Provide your response as a numbered list. Each main step should be followed by bullet points detailing substeps, rationale, or implementation tips.

Include:
1. App feature analysis and how to leverage them
2. Hierarchical structure design
3. Tagging and cross-reference system
4. Note template with formatting conventions
5. Review and revision schedule
6. Backup and sync strategy
7. Tips for maintaining organization and improving searchability over time
```
