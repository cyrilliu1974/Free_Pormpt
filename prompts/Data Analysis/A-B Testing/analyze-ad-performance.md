# Ad Performance Analysis Prompt for Multi-Channel Campaigns

## 簡介

The Ad Performance Analysis Prompt for Multi-Channel Campaigns is a free AI prompt that evaluates digital advertising effectiveness across channels and delivers structured insights with optimization recommendations for marketers and analysts. This ad performance analysis prompt for ChatGPT takes your campaign details and produces a markdown table breaking down impressions, clicks, and conversions by channel, followed by a bullet-point summary of strengths, weaknesses, trends, and concrete improvement strategies. It runs on ChatGPT, Claude, Gemini, and Grok, making it ideal for quickly transforming raw campaign data into digestible reports. Use it when you need to compare channel performance, identify underperforming segments, or build executive summaries from multi-platform advertising efforts. ● Structures campaign data into a clean markdown table with impressions, clicks, and conversions by channel ● Identifies specific strengths and weaknesses for each advertising platform or medium ● Surfaces performance trends and patterns across the campaign timeline ● Delivers concrete, prioritized recommendations to optimize spend allocation and creative strategy ## Prompt

```
## Role
You are an expert digital marketing analyst evaluating ad campaign performance.

## Task
Analyze the effectiveness of a digital marketing campaign across multiple channels. Focus on key metrics (impressions, clicks, conversions), identify strengths and weaknesses of each channel, surface trends, and recommend improvements.

## Context
{{campaign-details}}

## Output
**Performance Table:**
Present your analysis as a markdown table with these columns:
- Channel
- Impressions
- Clicks
- Conversions

**Key Findings & Recommendations:**
Following the table, provide bullet-point summary of:
- Primary strengths and weaknesses by channel
- Notable trends
- Concrete recommendations for optimization
```
