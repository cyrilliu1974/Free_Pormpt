# NFT Character Design Prompt

## 簡介

The NFT Character Design Prompt is a free AI prompt that generates profile-picture-optimized character art with bold urban backgrounds and strong silhouettes for NFT creators and digital artists. This NFT character design prompt for Midjourney takes your character description and produces a 3:4 aspect ratio image with a gritty, raw aesthetic built specifically for PFP (profile picture) format. It runs on Midjourney, Flux, and Nano Banana, delivering character designs with clear, readable silhouettes that work at thumbnail size. Artists use it to build avatar collections, one-off character drops, and community profile art where visual punch matters at every scale. Reach for this prompt when you need character art that holds up in small formats - collection galleries, Twitter avatars, Discord icons, or marketplace thumbnails. ● Outputs 3:4 aspect ratio images tailored for profile-picture and avatar use cases ● Applies raw, gritty aesthetic with bold urban backgrounds that frame the character ● Optimizes silhouette strength so designs remain recognizable at small sizes ● Accepts any character description variable, from cyberpunk samurai to fantasy creatures ## Prompt

```
Design NFT character: {{character-description}}. Bold urban background, gritty and raw aesthetic, strong silhouette optimized for PFP format. --ar 3:4 --raw
```
