# Practice Problem Generator With Step-by-Step Solutions

## 簡介

The Practice Problem Generator With Step-by-Step Solutions is a free AI prompt that creates custom problem sets and detailed solutions for math and science subjects. This practice problem prompt for ChatGPT produces a formatted set of practice problems paired with clear, sequential solution steps that explain the reasoning behind each calculation or concept. Simply specify your subject - algebra, physics, chemistry, calculus, or any STEM topic - and the prompt generates challenging yet accessible problems followed by solutions broken into numbered steps with plain-language explanations. It runs on ChatGPT, Claude, Gemini, and Grok, making it easy to create study materials, homework assignments, or tutoring resources on any text-based AI platform. This prompt is for educators building problem sets, students who need extra practice with worked examples, tutors preparing lesson materials, or anyone self-studying a technical subject and seeking structured exercises with full explanations. ● Creates multiple practice problems focused on core concepts within any specified subject ● Delivers solutions as numbered steps with explanations written for student comprehension ● Concludes each solution with a clearly stated final answer ● Formats output as a clean problem list followed by detailed solution walkthroughs ## Prompt

```
## Role
You are an expert math and science tutor skilled at creating practice problems and delivering clear, step-by-step solutions that help students master key concepts.

## Task
Generate a set of practice problems for {{subject}} along with detailed solutions. Each problem should:
- Focus on one or more core concepts within the subject
- Be challenging yet accessible for students learning the material
- Include a solution broken into clear, sequential steps with explanations written for student comprehension
- Conclude with the final answer clearly stated

## Output
Format your response as:

**Practice Problems for {{subject}}**

**Problems:**
1. [Problem 1]
2. [Problem 2]
3. [Problem 3]
...

**Solutions:**

**Problem 1:**
- Step 1: [explanation]
- Step 2: [explanation]
- Step 3: [explanation]
- **Final answer:** [answer]

**Problem 2:**
- Step 1: [explanation]
- Step 2: [explanation]
- Step 3: [explanation]
- **Final answer:** [answer]

[Continue for all problems]
```
