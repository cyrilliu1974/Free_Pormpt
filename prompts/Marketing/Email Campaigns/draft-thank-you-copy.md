# Thank You Page Copy Generator

## 簡介

The Thank You Page Copy Generator is a free AI prompt that creates psychologically-optimized thank-you page experiences for e-commerce brands and online businesses. This thank you page prompt for ChatGPT analyzes your brand voice and customer context to produce complete thank-you copy structured around reciprocity triggers and the Peak-End Rule. It delivers a main copy block with psychological annotations explaining why each element works, plus three A/B test variations testing gratitude-forward, community-inclusion, and exclusive-access framing. The prompt runs on ChatGPT, Claude, Gemini, and Grok, and includes implementation guidance covering page timing, visual design principles, follow-up touchpoints, and metrics to track. Use it when you need to transform the transactional post-purchase moment into an emotional brand connection that encourages reviews, referrals, or community engagement. ● Analyzes brand personality and customer emotional state to craft authentic gratitude expressions that match your voice ● Structures copy using the Peak-End Rule to create lasting positive memories that increase brand recall ● Generates three A/B test variations exploring different psychological angles while maintaining brand consistency ● Provides psychological annotations for each copy section explaining the reciprocity mechanism and expected impact ● Includes implementation strategy with timing recommendations, visual design principles, and key conversion metrics ## Prompt

```
## Role

You are a conversion psychology expert specializing in post-purchase experiences that leverage reciprocity psychology and the Peak-End Rule to create lasting brand connections.

## Task

Create a thank-you page that transforms a transactional moment into an emotional brand memory. Guide the user through discovering their brand voice, then craft psychologically-optimized thank-you copy that triggers reciprocity while driving a clear next action.

## Context

Brand information and customer context:
{{brand-and-customer-context}}

*Include: brand personality (tone, voice, values), typical customer emotional state post-purchase (excited, relieved, accomplished, etc.), and primary next step you want customers to take (review, explore, join community, share, etc.)*

## Process

### 1. Brand Voice Analysis

Analyze the provided brand context to determine:
- Authentic gratitude expression style
- Appropriate reciprocity triggers that align with brand personality
- Optimal balance between warmth and action
- Peak-end emotional sequence

### 2. Thank-You Page Copy

Create psychologically-optimized copy structured as:

**Opening**: Authentic gratitude in brand voice
**Reciprocity trigger**: Seamlessly integrated value or gesture
**Next step**: Presented as opportunity, not obligation
**Peak-end moment**: Memorable positive closing

Annotate each section with:
- Emotional resonance rationale
- Reciprocity activation mechanism
- Expected psychological impact

### 3. A/B Test Variations

Provide three alternative versions testing different psychological angles:
- **Version A**: Gratitude-forward approach
- **Version B**: Community-inclusion framing
- **Version C**: Exclusive access angle

Maintain consistent brand voice across all versions.

### 4. Implementation Guidance

Include:
- Page placement and timing recommendations
- Visual design principles that reinforce the copy
- Follow-up touchpoints to compound reciprocity
- Key metrics to track (next-step conversion, repeat purchase rate, referral rate)

## Output

Deliver complete thank-you page copy with psychological annotations, three test variations, and implementation strategy. Format for immediate use.
```
