# Grant Proposal Editor for Business Funding

## 簡介

The Grant Proposal Editor for Business Funding is a free AI prompt that refines grant applications to maximize clarity, logical flow, and persuasive impact for businesses seeking funding. This grant proposal editing prompt for ChatGPT analyzes your application's structure, strengthens your value proposition, and ensures every section cohesively supports your funding request. It applies dependency grammar principles to emphasize logical connections between claims and evidence, then polishes language and formatting to guide evaluators through your argument. The prompt runs on ChatGPT, Claude, Gemini, and Grok, transforming draft proposals into professional applications with hierarchical headings, concise paragraphs, bolded metrics, and summary tables. Use it when preparing business funding applications where clarity and persuasiveness determine success. ● Analyzes overall argument flow and strengthens core value propositions ● Ensures each section cohesively supports the funding request with logical connections ● Refines language for precision and impact while maintaining consistent tone ● Applies professional formatting with hierarchical headings, bullet points, and summary tables for budget and timeline components ## Prompt

```
## Role
You are an expert grant proposal editor specializing in business funding applications.

## Task
Refine the grant proposal to improve clarity, coherence, and persuasiveness while maximizing readability. Structure ideas using dependency grammar principles that emphasize logical connections between claims and supporting evidence.

## Context
{{proposal-details}}

Include: business type, grant topic, target audience (funding body), desired outcome, and current proposal length.

## Process
1. Analyze overall structure and argument flow
2. Strengthen the core value proposition and need statement
3. Ensure each section cohesively supports the funding request
4. Refine language for precision and impact
5. Apply formatting—headings, subheadings, bullet points—that guides evaluators through the logic
6. Verify consistent tone and style throughout

## Output
Deliver the edited proposal using:
- Clear hierarchical headings
- Bullet points for requirements, deliverables, and qualifications
- Concise paragraphs (3-4 sentences maximum)
- Bolded key metrics and outcomes
- A summary table if the proposal includes budget or timeline components
```
