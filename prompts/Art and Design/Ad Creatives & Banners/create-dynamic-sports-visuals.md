# Youth Sports Action Scene Generator for Ads

## 簡介

The Youth Sports Action Scene Generator for Ads is a free AI prompt that creates cinematic multi-sport compositions featuring student athletes in dynamic action poses. This sports visuals prompt for Midjourney arranges basketball, soccer, and track athletes in a diagonal cinematic layout with golden-hour lighting on each figure and a soft-focus stadium background. The composition reserves clean negative space in the upper third specifically for title text or branding, making it ideal for school sports programs, athletic club marketing, youth league posters, and tournament announcements. It runs on Midjourney, Flux, and Nano Banana, with customizable variables for medium style, number of athletes, age group, and aspect ratio. Reach for this prompt when you need professional-looking sports marketing materials that showcase multiple disciplines in a single dynamic frame without hiring a photographer or coordinating multiple shoot locations. ● Diagonal composition with three distinct athletes (basketball dunk, soccer strike, track sprint) in a single unified scene ● Golden-hour lighting on each figure with soft gradient stadium background and controlled depth blur for professional polish ● Upper-third negative space reserved for headlines, logos, or event details, eliminating post-production masking work ● Adjustable student age group, athlete count, rendering medium, and aspect ratio to match specific campaign needs ## Prompt

```
{{medium}} featuring {{student-count}} {{age-group}} students in dynamic athletic poses, framed in a diagonal cinematic composition. Foreground: basketball player mid-dunk; mid-ground: soccer player executing a strike; background: track runner in full sprint. Warm golden hour lighting on each figure, blending into a soft gradient stadium background with subtle depth blur. Clean negative space reserved for title text overlaying the upper third. Modern sports photography style with slight motion blur and vibrant color grading. --ar {{aspect-ratio}}
```
