# Mobile SEO Content Optimization Prompt

## 簡介

The Mobile SEO Content Optimization Prompt is a free AI prompt that rewrites existing content for maximum mobile readability while improving search engine rankings through dependency grammar frameworks and current mobile SEO best practices. This mobile SEO prompt for ChatGPT applies dependency grammar principles to restructure content into short paragraphs, clear hierarchical headings, and scannable bullet points that work perfectly on small screens. It optimizes meta titles and descriptions for mobile search, integrates primary keywords naturally, and ensures CTAs and interactive elements are easily tappable. The prompt runs on ChatGPT, Claude, Gemini, and Grok, delivering markdown-formatted output with H1-H3 headings, numbered or bulleted lists, and content blocks optimized for fast mobile load times. Use it when you need to transform desktop-oriented content into mobile-first copy that ranks well and converts on smartphones and tablets. ● Applies dependency grammar framework to ensure logical flow and coherence in every sentence and paragraph ● Restructures content into short 2-3 sentence paragraphs with clear H1-H3 hierarchical headings for mobile scanning ● Generates mobile-optimized meta titles and descriptions that improve click-through rates from search results ● Integrates primary keywords naturally while maintaining readability and avoiding keyword stuffing ● Formats CTAs and interactive elements with mobile tap targets and responsive design considerations in mind ## Prompt

```
## Role
You are an expert mobile SEO specialist optimizing content for mobile devices to improve readability and search engine rankings.

## Task
Rewrite and optimize the provided content using dependency grammar principles to ensure logical flow and coherence. Structure the output for maximum mobile readability while implementing current mobile SEO best practices.

## Context
- Target audience: {{target-audience}}
- Content topic: {{content-topic}}
- Industry: {{industry}}
- Primary keywords: {{primary-keywords}}

## Requirements
- Apply dependency grammar framework for clear logical progression
- Use short paragraphs (2-3 sentences maximum) and concise sentences
- Structure with clear headings, subheadings, and bullet points for scannability
- Optimize for mobile-friendly meta descriptions and title tags
- Ensure responsive design principles and fast load considerations
- Make CTAs and interactive elements easily tappable
- Integrate primary keywords naturally for mobile search

## Output
Deliver the optimized content in markdown format with:
- Clear hierarchical headings (H1, H2, H3)
- Bulleted or numbered lists where appropriate
- Short, scannable paragraphs
- Mobile-optimized meta title and description
- Strategic keyword placement that maintains natural readability
```
