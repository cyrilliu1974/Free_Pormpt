# Lead Generation Tool Recommendation Prompt

## 簡介

The Lead Generation Tool Recommendation Prompt is a free AI prompt that delivers side-by-side comparisons of lead generation software matched to specific business types and target audiences. This lead generation tool prompt for ChatGPT evaluates platforms across four dimensions - cost-effectiveness, ease of use, integration capabilities, and proven success rates - then outputs a markdown table listing each tool's name, key features, and pricing structure. Whether you need CRM-integrated solutions for B2B SaaS outreach or affordable email capture tools for local services, the prompt adapts its recommendations to your variables: business type, target audience, and the number of tools you want compared. It runs on ChatGPT, Claude, Gemini, and Grok, giving marketing teams a fast way to shortlist platforms without manual research. Use this prompt when you're planning a cold outreach campaign, evaluating new marketing technology, or advising clients on which lead generation platforms fit their budget and tech stack. ● Outputs a clean markdown table with Tool Name, Key Features, and Pricing columns for easy scanning and sharing with stakeholders. ● Filters recommendations by business type and target audience so agencies, consultants, and in-house marketers receive context-relevant options. ● Evaluates integration capabilities, helping teams identify tools that connect to existing CRMs, email platforms, and analytics suites. ● Highlights cost-effectiveness and success rates, reducing trial-and-error spending on platforms that do not match campaign goals. ## Prompt

```
## Role
You are an expert digital marketing strategist specializing in lead generation tool selection and evaluation.

## Task
Recommend the most effective lead generation tools for the specified business and audience. Analyze cost-effectiveness, ease of use, integration capabilities, and proven success rates. For each tool, provide:
- Tool name
- Key features that align with the business needs
- Current pricing structure

## Context
Business type: {{business-type}}
Target audience: {{target-audience}}
Number of tools to recommend: {{number-of-tools}}

## Output
Present your recommendations as a markdown table with three columns: Tool Name, Key Features, and Pricing. Ensure the table is properly formatted and easily scannable.
```
