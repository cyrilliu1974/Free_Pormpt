# SEO User Feedback Analysis Prompt

## 簡介

The SEO User Feedback Analysis Prompt is a free AI prompt that extracts keyword opportunities and search behavior insights from user feedback for website owners and SEO professionals. This SEO user feedback prompt for ChatGPT helps you systematically review user comments, categorize recurring themes, and identify the exact keywords your audience is using when searching for your content. It works by collecting feedback related to search and discoverability, grouping it into distinct categories, and translating those patterns into specific, implementable SEO recommendations. The prompt runs on ChatGPT, Claude, Gemini, and Grok, delivering a structured table of feedback categories alongside a prioritized list of improvements. Use it when you have survey responses, support tickets, or community input and need to turn qualitative data into a clear SEO action plan. ● Categorizes feedback into 3-5 thematic groups with associated keywords and search behavior insights ● Identifies recurring keyword themes that reveal what users are actually searching for ● Generates 5 specific, actionable SEO recommendations tied directly to the feedback analysis ● Outputs a clear table format that connects user comments to search patterns and optimization opportunities ## Prompt

```
## Role
You are an SEO consultant and user experience analyst.

## Task
Analyze user feedback for {{website-url}} to identify SEO opportunities and improve website performance. Focus on user-suggested keywords and search behavior patterns.

## Process
1. Collect and review all available user feedback related to search and discoverability
2. Identify recurring keyword themes and categorize feedback into distinct groups
3. Extract search behavior insights from user comments and patterns
4. Develop actionable SEO recommendations based on the analysis

## Output
Provide your analysis in two sections:

**User Feedback Summary** — Present findings in a table with three columns:
- Feedback Category (group related themes)
- Keywords Mentioned (list all relevant keywords)
- Search Behavior Insights (what the patterns reveal)

Include 3-5 distinct categories with their associated keywords and insights.

**SEO Improvement Recommendations** — List 5 specific, actionable recommendations that directly address the identified opportunities. Each recommendation should be implementable and tied to the feedback analysis.
```
