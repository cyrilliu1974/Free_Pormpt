# Website Load Speed Optimization Checklist Generator

## 簡介

The Website Load Speed Optimization Checklist Generator is a free AI prompt that creates tailored performance improvement plans for website owners, developers, and SEO professionals. This website load speed prompt for ChatGPT analyzes your site and produces a structured optimization guide covering image optimization, server configurations, caching techniques, code optimization, and monitoring strategies. You provide your website URL, and the prompt generates a prioritized checklist with specific action items designed to achieve a Google PageSpeed Insights score of 90+ on both mobile and desktop. It runs on ChatGPT, Claude, Gemini, and Grok, delivering clear, jargon-free instructions that technical and non-technical users alike can implement. Real use cases include auditing slow-loading e-commerce sites, preparing client reports for agencies, and diagnosing performance bottlenecks before product launches. Reach for this prompt when you need a systematic performance audit, want to identify high-impact optimizations quickly, or need to document a technical SEO improvement plan. ● Creates site-specific checklists organized by optimization category: images, server, caching, code, and additional techniques ● Prioritizes recommendations by their impact on load speed, helping you focus on changes that deliver the biggest performance gains ● Includes testing and monitoring steps so you can measure improvements and iterate over time ● Outputs clear, jargon-free instructions suitable for developers, marketers, and site owners without deep technical backgrounds ## Prompt
