# Learning Resource Curation Prompt for Educators

## 簡介

The Learning Resource Curation Prompt for Educators is a free AI prompt that identifies and organizes high-quality teaching materials aligned to specific learning objectives and student populations. This learning resource curation prompt for ChatGPT works by casting the AI as an educational researcher who evaluates sources for credibility, pedagogical effectiveness, and accessibility. You provide the subject area, learning goal, target audience, educational context, and preferred resource types - the prompt then returns a structured list grouped by format (videos, articles, interactive tools, textbooks) with each entry annotated for relevance, strengths, and instructional value. Teachers, instructional designers, curriculum developers, and homeschool coordinators use it to build reading lists, supplement lesson plans, and ensure materials meet diverse learning needs. It runs reliably on ChatGPT, Claude, and Gemini for text-based resource recommendations. Reach for this prompt whenever you need to quickly assemble a curated collection of teaching materials that matches both content standards and learner profiles, saving hours of manual searching and vetting. ● Filters resources by type - articles, videos, interactive simulations, open textbooks - so you can match your instructional format. ● Annotates each resource with a brief description, relevance rationale, and notable features like accessibility support or hands-on interactivity. ● Considers diverse learning needs and pedagogical soundness, not just topic match, ensuring materials work in real classroom or training settings. ● Organizes output by resource category with clear headings, making it simple to copy into a syllabus, LMS module, or professional development guide. ## Prompt

```
## Role
You are an educational researcher specializing in resource curation and instructional design.

## Task
Identify and curate a comprehensive list of high-quality educational resources that support the specified learning goal. Evaluate each resource for credibility, alignment with objectives, and suitability for the target audience.

## Context
**Subject:** {{subject}}
**Learning goal:** {{learning-goal}}
**Target audience:** {{target-audience}}
**Educational context:** {{educational-context}}
**Preferred resource types:** {{preferred-resource-types}}

Consider diverse learning needs, accessibility, and pedagogical effectiveness when selecting resources. Prioritize authoritative sources with clear educational value.

## Output
Provide a curated list organized by resource type. For each resource include:
- Title and source
- Brief description (1-2 sentences)
- Specific relevance to the stated learning goal
- Any notable strengths (interactivity, depth, accessibility features)

Format as a bullet point list grouped under resource type headings.
```
