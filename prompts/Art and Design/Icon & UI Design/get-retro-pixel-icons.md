# Retro Pixel Art Icon Generator

## 簡介

The Retro Pixel Art Icon Generator is a free AI prompt that retextures images into authentic low-resolution pixel icons with hard edges, dithered shading, and a classic 8-color palette. This retro pixel art prompt for Midjourney, Flux, and Nano Banana produces 32×32 or 48×48 icons with no anti-aliasing, 1px black outlines, and checkerboard dithering that mimics early computer graphics. It enforces a strict color palette of eight specific hex values - light gray, silver, black, white, blue, green, pale yellow, and teal - and applies three-tone shading (base, highlight, shadow) with flat lighting from the top-left. The result is a static, non-animated icon on a plain background, available in isometric or front-facing perspective. Designers building retro UI kits, game assets, or nostalgia-driven branding reach for this prompt when they need pixel-perfect consistency without manual pixel-pushing. ● Retextures any image into 32×32 or 48×48 pixel art with hard edges and no anti-aliasing ● Applies a locked 8-color palette and 1px black outlines for authentic early-90s computer icon style ● Uses dithering (checkerboard or diagonal lines) for three-tone shading on every surface ● Outputs icons on a plain background in isometric or front-facing perspective ## Prompt

```
Retexture the attached image as a retro pixel art UI icon at 32×32 or 48×48 resolution.

**Style**: Low-resolution pixel art with hard edges and no anti-aliasing.

**Color palette**: #F2F2F2 (light gray), #C0C0C0 (silver), #000000 (black), #FFFFFF (white), #0000FF (blue), #00FF00 (green), #FFFF99 (pale yellow), #008080 (teal). Use only these colors.

**Outline**: 1px black (#000000) outline around all shapes.

**Shading**: Dithering method using checkerboard or diagonal line patterns. Apply three tones per surface: base color, highlight, and shadow.

**Lighting**: Flat lighting from top-left. Highlights in #FFFFFF, shadows in #808080.

**Background**: Plain #F2F2F2, opaque.

**Perspective**: {{perspective}} view with static, non-animated pixel art style.
```
