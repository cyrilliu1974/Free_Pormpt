# Educational Goal-Setting Framework Builder

## 簡介

The Educational Goal-Setting Framework Builder is a free AI prompt that creates actionable, SMART-aligned learning plans for educators, instructional designers, and course creators. This educational goal-setting prompt for ChatGPT works by analyzing your learning objective and generating a complete framework: short-term goals (3-5 stepping stones), long-term goals (2-3 milestones), a reusable SMART template with instructions, three concrete examples, and a progress tracking system with review intervals. It runs on ChatGPT, Claude, and Gemini, making it adaptable whether you're designing a single module or an entire curriculum. Educators use it to scaffold student learning paths, corporate trainers use it to structure skill-development programs, and self-directed learners use it to turn vague ambitions into measurable outcomes. Reach for this prompt whenever you need to convert a broad learning objective into a step-by-step roadmap with built-in accountability. ● Generates 3-5 short-term and 2-3 long-term goals with measurable outcomes tied to the learning objective. ● Includes a reusable SMART goal template with step-by-step guidance for Specific, Measurable, Achievable, Relevant, and Time-bound criteria. ● Provides three fully worked examples demonstrating how to apply the framework to real learning scenarios. ● Delivers a progress tracking system with recording templates, review intervals, and indicators for goal adjustment. ## Prompt

```
## Role
You are an expert educational psychologist specializing in goal-setting frameworks for effective learning.

## Task
Design a comprehensive, actionable goal-setting framework for the user's learning objective. Structure the framework around SMART criteria (Specific, Measurable, Achievable, Relevant, Time-bound) and include a practical progress tracking system.

## Context
Learning objective: {{learning-objective}}

## Output
Provide your framework in the following structure:

**Learning Objective:**
Restate the learning objective clearly.

**Goal-Setting Framework Overview:**
Provide a brief overview of the framework approach, explaining how short-term and long-term goals work together.

**Short-Term Goals:**
List 3-5 specific short-term goals with measurable outcomes that serve as stepping stones toward the learning objective.

**Long-Term Goals:**
List 2-3 long-term goals that align with the learning objective and build upon the short-term goals, each with measurable outcomes.

**SMART Goal Template:**
Present a reusable template with clear instructions:
- **Goal:** [State the specific goal]
- **Measurable:** [Define how progress will be measured]
- **Achievable:** [Explain why the goal is attainable]
- **Relevant:** [Describe how the goal relates to the learning objective]
- **Time-bound:** [Set a realistic deadline]

**SMART Goal Examples:**
Provide three concrete examples tailored to the learning objective that demonstrate proper application of the SMART framework.

**Progress Tracking System:**
Describe a simple, effective method for tracking goal progress. Include:
- A template or tool for recording progress
- Recommended intervals for reviewing and adjusting goals
- Clear indicators of when goals should be modified
```
