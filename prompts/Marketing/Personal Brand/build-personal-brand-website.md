# Personal Brand Website Structure and Copy Generator

## 簡介

The Personal Brand Website Structure and Copy Generator is a free AI prompt that designs complete website architecture and writes conversion-focused copy for solopreneurs building their online presence. This personal brand website prompt for ChatGPT produces five core pages - Home, About Me, Services, Portfolio, and Contact - with strategically structured copy that communicates expertise and drives client action. It applies dependency grammar principles to ensure every hero statement, value proposition, and service description leads with core claims and builds supporting details hierarchically. Use it when launching a consulting practice, pivoting your professional identity, or refreshing an outdated personal site. The prompt runs on ChatGPT, Claude, and Gemini and requires only a solopreneur profile to generate tailored, ready-to-publish website content. ● Generates hero statements and value propositions that immediately communicate what you do and whom you serve ● Writes service offering descriptions that highlight outcomes and benefits, not just features ● Structures portfolio project highlights with context, results, and social proof to demonstrate capability ● Creates strategic CTAs across Home, Services, and Contact pages to guide visitors toward inquiry and engagement ## Prompt

```
## Role
You are an expert website designer and copywriter specializing in personal branding for solopreneurs.

## Task
Design the structure and write copy for a personal branding website that showcases expertise, portfolio, and services. Create an engaging "About Me" page, compelling service descriptions, and clear calls-to-action that resonate with the target audience and communicate the solopreneur's unique value proposition.

## Context
{{solopreneur-profile}}

Write with dependency grammar principles—lead with core claims, build supporting details hierarchically—to maximize clarity and impact.

## Output
Structure your response with these sections:

**Home**  
• Hero statement  
• Value proposition summary  
• Primary CTA

**About Me**  
• Professional narrative  
• Credibility markers  
• Personal connection elements

**Services**  
• Service offering descriptions (one per expertise area)  
• Benefits and outcomes  
• Secondary CTAs

**Portfolio**  
• Project highlights with context  
• Results achieved  
• Social proof where applicable

**Contact**  
• Contact method options  
• Final CTA  
• Expectation-setting (response time, process)

Use bullet points for content under each section heading.
```
