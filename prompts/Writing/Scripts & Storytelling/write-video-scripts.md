# Video Script Writer for Audience-Focused Content

## 簡介

The Video Script Writer for Audience-Focused Content is a free AI prompt that creates production-ready video scripts structured with timestamps, visual cues, and narration for content creators and marketing teams. This video script prompt for ChatGPT produces formatted scripts that include scene-by-scene breakdowns with exact timestamps, on-screen action descriptions, B-roll suggestions, and word-for-word narration. It works by analyzing the intersection of your topic, target audience, and goal to tailor vocabulary, pacing, and examples that resonate. The prompt runs on ChatGPT, Claude, Gemini, and Grok, ensuring logical progression from hook through main content to a clear call-to-action. Real use cases include YouTube tutorials, product explainers, social media campaigns, training videos, and branded content that requires consistent voice and professional structure. Reach for this prompt when you need a complete script that bridges creative vision and production execution, whether you're a solo creator, marketing team, or production house working against tight deadlines. ● Outputs timestamp-structured scripts with visual and audio tracks separated for efficient production handoff ● Analyzes audience psychology and goal alignment to shape tone, pacing, and call-to-action strategy ● Maintains brand voice consistency across introduction, body segments, and conclusion ● Includes specific visual direction for B-roll, graphics, and on-screen elements to guide videographers and editors ## Prompt

```
## Role
You are an expert video script writer specializing in engaging, audience-focused content.

## Task
Write a complete video script that captivates the target audience and achieves the stated goal. Structure the script with clear timestamps, scene descriptions, visual directions, and narration to enable efficient production.

## Context
**Topic:** {{topic}}
**Target audience:** {{target-audience}}
**Goal:** {{goal}}
**Video length:** {{video-length}}
**Brand voice:** {{brand-voice}}

Analyze how the topic, audience, and goal intersect. Tailor vocabulary, pacing, and examples to resonate with the audience. Ensure logical progression: establish context early, build interest through the middle, and conclude with a clear takeaway or call-to-action aligned with the goal.

## Output
Format the script as:

**[00:00 - 00:XX] INTRODUCTION / HOOK**  
*Visual:* [describe on-screen action, B-roll, graphics]  
*Audio/Narration:* [exact spoken words]

**[00:XX - 00:XX] MAIN CONTENT**  
*Visual:*  
*Audio/Narration:*

(Repeat structure for each segment)

**[XX:XX - XX:XX] CONCLUSION / CALL-TO-ACTION**  
*Visual:*  
*Audio/Narration:*

Maintain the specified brand voice throughout. Keep timestamps accurate to the total video length.
```
