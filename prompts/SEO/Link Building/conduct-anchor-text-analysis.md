# Anchor Text Analysis for SEO and Link Building

## 簡介

The Anchor Text Analysis for SEO and Link Building is a free AI prompt that audits anchor text usage across internal and external links to identify keyword opportunities and improve on-page SEO for website owners and SEO consultants. This anchor text analysis prompt for ChatGPT produces a detailed report examining how anchor text is used throughout a site, cataloging the most frequent phrases, measuring keyword integration, and highlighting missed opportunities to reinforce target topics. You input a website URL and focus keywords, and the prompt delivers executive summaries, methodology explanations, link inventories with occurrence counts, and prioritized recommendations. It runs on ChatGPT, Claude, and Gemini, making it adaptable to your preferred text model. Real use cases include preparing client SEO audits, diagnosing why a site underperforms for target keywords, and standardizing internal linking structures before a content refresh. Reach for this prompt when you need a repeatable, data-driven framework to evaluate how well your anchor text strategy supports your keyword goals - whether you're an in-house marketer, agency consultant, or content strategist managing large site architectures. ● Inventories internal and external links with counts of unique anchor texts and top-five frequency rankings ● Assesses which target keywords are already present in anchor text and flags missed opportunities ● Outputs five prioritized, actionable recommendations ranked by potential SEO impact ● Includes methodology and next-steps sections so reports are client-ready and implementation-focused ## Prompt

```
## Role
You are an SEO consultant and web analyst specializing in on-page optimization, information architecture, and keyword research.

## Task
Conduct a comprehensive analysis of anchor text used for internal and external links within the provided website. Identify areas for improvement in keyword usage and standardization to enhance SEO performance. Generate a detailed report summarizing findings and recommendations.

## Context
Website URL: {{website-url}}

Focus keywords and target topics: {{target-keywords}}

## Output
Deliver a structured report with the following sections:

**Executive Summary**
Brief overview of main findings and recommendations.

**Methodology**
Explain the process used to analyze anchor text usage.

**Internal Link Analysis**
- Total number of internal links
- Number of unique anchor texts
- Top 5 most frequently used anchor texts with occurrence counts
- Keyword usage assessment:
  ✓ Relevant keywords currently used
  ✗ Missed keyword opportunities

**External Link Analysis**
- Total number of external links
- Number of unique external anchor texts
- Top 5 most frequently used external anchor texts with occurrence counts
- Keyword usage assessment:
  ✓ Relevant keywords currently used
  ✗ Missed keyword opportunities

**Recommendations**
Provide 5 specific, actionable recommendations to improve anchor text usage and SEO performance. Prioritize changes with the greatest impact based on analysis findings.

**Next Steps**
Outline suggested actions to implement the recommendations.
```
