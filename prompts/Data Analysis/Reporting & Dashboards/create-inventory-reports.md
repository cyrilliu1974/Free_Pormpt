# Inventory Report Generator for Stock Analysis

## 簡介

The Inventory Report Generator for Stock Analysis is a free AI prompt that creates comprehensive inventory reports for businesses tracking stock levels, product movement, and performance metrics. This inventory report prompt for ChatGPT analyzes stock data and structures it into clear markdown tables showing product names, quantities, reorder points, stock status, and movement patterns. It runs on ChatGPT, Claude, Gemini, and Grok, delivering both formatted data tables and an analytical summary that identifies overstock situations, understock risks, slow-moving items, and specific optimization actions like reordering priorities or safety stock adjustments. Warehouse managers, retail operations teams, and e-commerce businesses use it to transform raw inventory data into decision-ready reports for any time period. ● Formats inventory data into organized markdown tables with custom columns for product details, quantities, reorder thresholds, and additional data points ● Analyzes product movement patterns to surface trends, overstock warnings, understock alerts, and slow-moving SKU identification ● Generates actionable recommendations including reordering priorities, SKU rationalization opportunities, and safety stock adjustments ● Adapts to different report types, business models, and time periods while maintaining consistent structure and analytical depth ## Prompt

```
## Role
You are an expert inventory manager creating comprehensive inventory reports.

## Task
Generate a detailed inventory report that provides a clear overview of current stock levels, product movement, and key metrics for {{business-name}} covering {{time-period}}.

## Context
Report type: {{report-type}}

Analyze the data and structure it in a clear, organized manner. Include:
- Product names and quantities
- Reorder points and stock status
- Product movement patterns
- {{additional-data-points}}

Provide insights on inventory trends, highlight potential stock issues (overstock, understock, slow-moving items), and suggest specific actions for inventory optimization (reordering priorities, SKU rationalization, or safety stock adjustments).

## Output
Present the report as a markdown table with all relevant data points as columns. Follow the table with a brief analysis section covering trends, issues, and recommended actions.
```
