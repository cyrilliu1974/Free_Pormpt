# Personal Study Plan Generator for Any Subject

## 簡介

The Personal Study Plan Generator for Any Subject is a free AI prompt that creates customized, structured learning roadmaps for students, educators, and self-learners seeking optimized study strategies. This personalized study plan prompt for ChatGPT analyzes a student's learning preferences, current competency level, and objectives to produce a markdown table breaking down any subject into logical units with matched resources, practice activities, and realistic timelines. It runs on ChatGPT, Claude, Gemini, and Grok, outputting a progressive plan that respects prerequisite relationships and includes checkpoints for assessment. Real use cases span academic exam preparation, professional certification paths, language learning schedules, and homeschool curriculum design. Reach for this prompt when you need to transform broad learning goals into actionable, week-by-week study structures that adapt to different pacing needs and skill levels. ● Breaks any subject into logical, prerequisite-ordered modules that build incrementally ● Matches resources and practice activities to the learner's preferred style and current skill level ● Provides realistic time estimates and assessment checkpoints for progress tracking ● Outputs a markdown table with Topic, Resources, Activities, and Timeline columns for immediate use ## Prompt

```
## Role
You are an expert educational consultant specializing in personalized study plan design.

## Task
Create a comprehensive, tailored study plan for {{subject}} that optimizes learning efficiency and effectiveness. The plan must be structured, progressive, adaptable, and motivating.

## Context
Student profile: {{student-profile}}

Analyze the student's learning preferences, current competency level, and objectives. Design a plan that matches their needs with appropriate pacing and difficulty progression.

## Output
Deliver the study plan as a markdown table with these columns:

| Topic | Resources | Activities | Timeline |
|-------|-----------|------------|----------|

- **Topic**: Break the subject into logical units or modules, ordered by prerequisite relationships
- **Resources**: Specify books, courses, articles, videos, or tools suited to the student's learning approach
- **Activities**: List practice exercises, projects, quizzes, or applied tasks that reinforce each topic
- **Timeline**: Provide realistic time estimates (days/weeks) accounting for the student's skill level and goals

Ensure the plan builds incrementally, includes checkpoints for assessment, and remains flexible for adjustment based on progress.
```
