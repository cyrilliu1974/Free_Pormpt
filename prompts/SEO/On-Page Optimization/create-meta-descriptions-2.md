# SEO Meta Description Generator for Search Results

## 簡介

The SEO Meta Description Generator for Search Results is a free AI prompt that creates optimized meta descriptions designed to improve click-through rates from search engine results pages for content strategists and SEO professionals. This meta description prompt for ChatGPT analyzes your webpage content, target keywords, audience, and unique selling proposition to generate concise 150-160 character descriptions that balance search engine optimization with user engagement. It runs on ChatGPT, Claude, Gemini, and Grok, delivering results in a structured table format that includes the page URL, meta description text, and character count. Real use cases include optimizing product pages for e-commerce sites, crafting descriptions for blog posts that compete in crowded SERPs, and refreshing outdated metadata across enterprise websites. The prompt prioritizes benefit-driven language and natural keyword integration rather than keyword stuffing, ensuring descriptions that appeal to both search algorithms and human readers. Reach for this prompt when you need to scale meta description creation across multiple pages while maintaining quality and consistency, or when existing descriptions are underperforming in search results. ● Enforces the 150-160 character limit to prevent truncation in Google search results ● Integrates target keywords naturally while leading with the strongest user benefit ● Outputs a markdown table with page URLs, meta descriptions, and character counts for easy review ● Incorporates unique selling propositions and audience context to differentiate your pages from competitors ## Prompt

```
## Role
You are an expert SEO content strategist specializing in high-conversion meta descriptions.

## Task
Craft concise, engaging meta descriptions (150-160 characters) that accurately summarize page content and improve click-through rates from search engine results pages.

## Context
Website: {{website-url}}
Target keywords: {{target-keywords}}
Target audience: {{target-audience}}
Unique selling proposition: {{usp}}

## Approach
- Analyze each page's core content and value proposition
- Integrate target keywords naturally without stuffing
- Lead with the strongest benefit or hook
- Include a clear reason to click
- Stay within the 150-160 character limit for optimal SERP display

## Output
Provide results in a markdown table:

| Page URL | Meta Description | Character Count |
|----------|------------------|----------------|
| | | |
```
