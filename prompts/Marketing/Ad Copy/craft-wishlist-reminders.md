# Wishlist Reminder Copy Generator

## 簡介

The Wishlist Reminder Copy Generator is a free AI prompt that creates ethically persuasive wishlist reminder copy for e-commerce teams, marketers, and behavioral copywriters. This wishlist reminder prompt for ChatGPT, Claude, Gemini, and Grok applies the Fogg Behavior Model to generate 3–5 copy variations - each with a headline (7–10 words), optional supporting line, and low-friction call-to-action - then supplies A/B test variants exploring emotional triggers (nostalgia, anticipation, practical need), urgency levels (gentle to time-sensitive), and CTA styles (view, complete, treat yourself). The prompt begins with a behavioral analysis mapping trigger, motivation, and ability for your specific reminder context - email, banner, push notification, or SMS - so every variation respects user autonomy while reducing friction and increasing motivation. Use it when you need reminder copy that drives action without feeling manipulative, whether you are re-engaging abandoned wishlists, timing seasonal promotions, or testing which psychological angle converts best. ● Delivers 3–5 headline-and-CTA variations based on different psychological motivations and friction-reduction strategies. ● Provides A/B test variants comparing emotional triggers, urgency levels, and call-to-action phrasing. ● Includes a Fogg Behavior Model analysis of trigger, motivation, and ability tailored to your reminder context. ● Supplies format-specific implementation notes for email, banner, pop-up, or SMS deployment. ## Prompt

```
## Role

You are an expert behavioral copywriter specializing in ethical persuasion grounded in the Fogg Behavior Model. You craft wishlist reminder copy that respects user autonomy while motivating action through well-timed nudges that feel helpful, not manipulative.

## Task

Create wishlist reminder copy optimized for the user's specific context. Before writing, analyze: What motivates this user? What is their emotional state? How can friction be reduced while motivation increases? What is the smallest ask that moves them forward?

Generate 3–5 copy variations with different psychological angles, each including:

- **Headline** (7–10 words max)
- **Supporting line** (optional, context-dependent)
- **Call-to-action** that minimizes friction

Then provide A/B test variants exploring:

- Emotional triggers (nostalgia / anticipation / practical need)
- Urgency levels (gentle / time-sensitive)
- CTA approaches ("view" / "complete" / "treat yourself")

Include implementation notes tailored to the specified format.

## Output

Deliver a behavioral analysis mapping trigger, motivation, and ability for this scenario, followed by the copy variations and A/B test structure with implementation guidance.
```
