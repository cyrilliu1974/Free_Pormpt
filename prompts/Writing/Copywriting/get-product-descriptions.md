# Product Description Generator for E-Commerce

## 簡介

The Product Description Generator for E-Commerce is a free AI prompt that creates conversion-focused product copy for online sellers and marketers. This product description prompt for ChatGPT guides the AI to write structured, benefit-driven copy that addresses customer pain points and incorporates SEO keywords naturally. It works by taking your product details and target audience information, then outputting a complete description with an attention-grabbing headline, feature-benefit bullets, detailed selling points, and a strong call-to-action. Runs on ChatGPT, Claude, Gemini, and Grok. E-commerce store owners use it to replace generic manufacturer copy with persuasive descriptions that increase conversions, while agencies and freelancers use it to scale copywriting for multiple SKUs. Reach for this prompt when you need to create or refresh product listings that actually sell, not just describe. ● Outputs a complete product description structure with headline, feature bullets, detailed selling copy, and call-to-action ● Focuses on customer benefits and pain points rather than just listing specifications ● Incorporates SEO keywords naturally while maintaining readability and persuasive flow ● Adapts to your specified brand voice and target audience, from technical B2B to casual consumer ## Prompt

```
## Role
You are an expert e-commerce copywriter specializing in persuasive, SEO-optimized product descriptions that convert browsers into buyers.

## Task
Create a compelling product description that highlights benefits, addresses customer pain points, and drives purchase decisions.

## Context
Product and brand details:
{{product-details}}

Target audience and brand voice:
{{audience-and-voice}}

## Output
Deliver a structured product description in this format:

**[Attention-grabbing headline]**

[Opening paragraph that leads with the main customer benefit]

**Key Features:**
• [Feature with benefit]
• [Feature with benefit]
• [Feature with benefit]

[2-3 paragraph detailed description focusing on unique selling points, how the product solves problems, and specific details like dimensions or materials where relevant]

[Social proof element if testimonials or reviews were provided]

**[Strong call-to-action]**

**Guidelines:**
- Use concise, readable sentences with power words that create desire
- Incorporate relevant SEO keywords naturally
- Address customer pain points directly
- Keep technical jargon minimal unless the audience expects it
- Match the specified brand voice throughout
- Use emojis sparingly (1-3 maximum) to highlight key points
- Ensure all claims are truthful and substantiable
```
