# Resilience Framework Builder for Changing Industries

## 簡介

The Resilience Framework Builder for Changing Industries is a free AI prompt that creates comprehensive, actionable resilience frameworks tailored to the unique challenges of rapidly evolving sectors. This resilience framework prompt for ChatGPT analyzes your industry's competitive landscape, identifies critical challenges, and constructs a multi-layered framework grounded in change management, agile methodology, and organizational psychology. It delivers an industry overview, five foundational resilience principles, four detailed framework components with implementation steps and KPIs, a phased rollout roadmap, and methods for measuring success. The prompt runs on ChatGPT, Claude, Gemini, and Grok, producing structured guidance rather than generic advice. Organizations use it to prepare for disruption in technology, healthcare, finance, retail, and other high-velocity industries. ● Generates industry-tailored frameworks with specific implementation steps, not generic resilience platitudes ● Includes measurable KPIs for each framework component to track adoption and effectiveness ● Combines proven disciplines - change management, agile, and organizational psychology - into cohesive guidance ● Delivers a phased implementation roadmap and continuous improvement practices aligned to industry dynamics ## Prompt

```
## Role
You are a resilience expert specializing in rapidly evolving industries, combining principles from change management, agile methodology, and organizational psychology.

## Task
Design a comprehensive, adaptable resilience framework for the specified industry. The framework must be actionable, tailored to the industry's unique challenges, and incorporate best practices from related fields.

## Context
Industry: {{industry}}

## Output
Structure your response with the following sections:

**1. Industry Overview**
Provide a brief overview of the industry's dynamics, pace of change, and competitive landscape.

**2. Key Challenges**
List three critical challenges organizations face in this industry.

**3. Resilience Principles**
Outline five foundational principles for building resilience, drawing from change management, agile methodology, and organizational psychology.

**4. Framework Overview**
Provide a high-level summary of the proposed resilience framework and its strategic approach.

**5. Framework Components**
Detail four key components, each including:
- Component Name
- Description
- Implementation Steps (3 specific steps)
- KPIs (2 measurable indicators)

**6. Implementation Roadmap**
Outline a step-by-step plan for rolling out the framework within an organization.

**7. Measuring Success**
Describe methods for measuring framework effectiveness and practices for continuous improvement.

Ensure all recommendations are specific to the industry's characteristics rather than generic resilience advice. Use bullet points and numbered lists for clarity.
```
