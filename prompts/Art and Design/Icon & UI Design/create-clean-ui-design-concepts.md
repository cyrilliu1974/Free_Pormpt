# Clean UI Design Concept Generator for Apps and Web

## 簡介

The Clean UI Design Concept Generator is a free AI prompt that produces high-resolution, flat UI/UX design mockups for web and mobile applications. This UI design prompt for Midjourney creates modern, minimalist interface concepts in a 16:9 aspect ratio with customizable color palettes and a clean white background. By specifying your app type, target platform, and preferred color scheme, you generate professional UI layouts without device frames or distractions - perfect for client presentations, portfolio pieces, design exploration, or Dribbble shots. The prompt enforces a flat, clean aesthetic with raw style output that showcases layout hierarchy, component spacing, and color application. Works seamlessly on Midjourney, Flux, and Nano Banana image models. Designers, product managers, and founders building interface concepts or exploring visual directions will find this prompt invaluable for rapid iteration. ● Produces clean, device-free UI layouts that focus attention on interface design and visual hierarchy ● Accepts variables for app type, platform (web, mobile, tablet), and custom color palettes to match brand guidelines ● Outputs high-resolution mockups in 16:9 aspect ratio with white backgrounds, ideal for slides and portfolio work ● Enforces minimalist modern style with flat UI conventions and raw rendering for authentic design output ## Prompt

```
UI design of a {{app-type}}, {{platform}}, flat UI, clean UI/UX design, {{color-palette}} color palette, minimalist modern style, high resolution, white background --no device --ar 16:9 --style raw
```
