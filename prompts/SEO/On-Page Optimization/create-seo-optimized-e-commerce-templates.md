# E-Commerce Category Landing Page Template Generator

## 簡介

The E-Commerce Category Landing Page Template Generator is a free AI prompt that produces complete HTML5 templates for SEO-optimized product category pages on e-commerce websites. This e-commerce category landing page prompt for ChatGPT generates clean, semantic code structured around SEO best practices - optimized title tags, meta descriptions, keyword-rich headers, featured product sections, and value proposition blocks. You provide your site name and category details (name, meta description, keywords, intro paragraph, featured products, and key benefits), and the prompt outputs a complete HTML5 template with placeholder brackets for dynamic content injection. It runs on ChatGPT, Claude, and Gemini, producing modification-friendly markup without complex JavaScript or CSS dependencies. Use it when building scalable landing page systems across multiple product categories, launching new collections, or standardizing SEO structure site-wide. ● Outputs a complete HTML5 template with optimized head section, semantic headers, and structured content areas ● Incorporates SEO essentials including meta descriptions, keyword tags, H1 headers, and clean markup ● Includes featured product sections, category introduction blocks, and benefit or value proposition areas ● Uses simple placeholder syntax for easy integration into content management or auto-generation workflows ## Prompt

```
## Role
You are an expert web developer specializing in e-commerce and SEO optimization.

## Task
Generate a clean, semantic HTML template for an SEO-optimized product category landing page. The template uses SEO best practices including optimized headers, meta tags, and keyword-rich content structure.

## Context
This template will be used to auto-generate landing pages across multiple product categories for {{site-name}}. It must be easily adaptable and allow quick deployment without complex JavaScript or CSS dependencies.

## Product Category Details
{{category-content}}

Provide the product category name, a 150-160 character meta description, 5-8 relevant keywords, a compelling introduction paragraph, 3 featured products with brief descriptions, and 3 key benefits or value propositions for this category.

## Output
Deliver a complete HTML5 template with:

- Optimized `<head>` section with meta description, keywords, and title tag
- Header with semantic `<h1>` for the product category
- Main content area containing:
  - Category introduction section
  - Featured products section with structured list
  - Benefits/value proposition section
- Footer with copyright notice for {{site-name}} and current year

Use clean, semantic HTML structure with placeholder brackets `[PLACEHOLDER_NAME]` only where dynamic content injection will occur during page generation. Keep the markup simple and modification-friendly.
```
