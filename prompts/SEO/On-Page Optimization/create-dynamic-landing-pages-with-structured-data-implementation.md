# Landing Page Schema Markup & SEO Implementation Plan

## 簡介

The Landing Page Schema Markup & SEO Implementation Plan is a free AI prompt that creates comprehensive landing page strategies combining structured data optimization, SEO best practices, and conversion design for digital marketers and business owners. This landing page optimization prompt for ChatGPT produces a six-part implementation blueprint tailored to your business model, target audience, primary keywords, unique value proposition, and conversion goals. It specifies which schema.org markup types to implement for better search engine comprehension, architects your content hierarchy using readability principles, maps keyword placement across title tags and meta descriptions, recommends mobile-responsive layout sections with fast-loading design patterns, positions strategic calls-to-action, and defines the analytics framework to measure performance. The prompt runs on ChatGPT, Claude, Gemini, and Grok, delivering actionable specifications ready for developers and content teams to execute. Reach for this prompt when launching new landing pages, redesigning existing conversion funnels, or auditing pages that underperform in organic search or visitor-to-lead conversion rates. ● Recommends specific schema.org types and properties matched to your business model for enhanced search visibility ● Delivers heading hierarchies, content block structures, and readability optimizations that balance user experience with SEO ● Maps keyword integration across title tags, meta descriptions, headings, and body content for organic ranking improvements ● Specifies mobile-responsive layout sections, visual hierarchy principles, and page-speed optimization techniques ● Defines CTA placement, messaging, and design aligned with your conversion action ● Outlines key performance metrics, tracking code requirements, and analytics configuration for ongoing optimization ## Prompt

```
## Role
You are an expert digital marketer and SEO specialist creating high-conversion landing pages with structured data optimization.

## Task
Develop a comprehensive landing page strategy that improves search visibility and drives conversions through:

- Schema markup recommendations tailored to the business model
- SEO-optimized content structure using clear hierarchies and readability principles
- Keyword integration strategy for organic rankings
- Mobile-responsive, fast-loading UX design principles
- Strategic CTA placement aligned with conversion goals
- Analytics implementation for performance tracking

## Context
**Business & Audience:** {{business-and-audience}}

**SEO Strategy:** {{primary-keywords}}

**Value Proposition:** {{usp}}

**Conversion Goal:** {{conversion-action}}

## Output
Provide a structured, step-by-step landing page implementation plan that includes:

1. **Schema Markup Specification** – Recommended schema.org types and properties for this business
2. **Content Architecture** – Heading structure, content blocks, and readability optimizations
3. **On-Page SEO Elements** – Title tags, meta descriptions, keyword placement strategy
4. **Layout & UX Recommendations** – Sections, visual hierarchy, mobile considerations, loading optimization
5. **CTA Strategy** – Placement, messaging, and design for maximum conversion
6. **Measurement Plan** – Key metrics, tracking codes, and analytics setup

Format each section with specific, actionable recommendations ready for implementation.
```
