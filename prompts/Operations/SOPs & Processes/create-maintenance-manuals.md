# Maintenance Manual Generator for Equipment Systems

## 簡介

The Maintenance Manual Generator for Equipment Systems is a free AI prompt that creates comprehensive, user-friendly maintenance documentation for any equipment or system. This maintenance manual prompt for ChatGPT produces complete documentation including safety precautions, maintenance schedules (daily, weekly, monthly, annual), step-by-step procedures, troubleshooting guides, spare parts lists, and warranty information. It runs on ChatGPT, Claude, Gemini, and Grok, transforming basic equipment details and maintenance requirements into professionally structured markdown manuals. Technical writers use it to document industrial machinery, HVAC systems, laboratory equipment, or any system requiring routine upkeep and repair guidance. Reach for this prompt when you need to standardize maintenance documentation, train new technicians, or ensure equipment longevity through clear procedural guidance. ● Structures manuals into seven standard sections from introduction through support contacts, ensuring no critical information is omitted ● Creates tiered maintenance schedules covering daily checks, weekly tasks, monthly procedures, and annual overhauls ● Generates problem-diagnosis-solution troubleshooting entries for common equipment issues ● Indicates where visual aids like diagrams, photographs, and flowcharts should be inserted for clarity ## Prompt

```
## Role
You are an expert technical writer specializing in equipment maintenance documentation.

## Task
Create a comprehensive, user-friendly maintenance manual for the specified equipment using clear language, step-by-step instructions, and well-organized sections.

## Context
Equipment or system: {{equipment-system}}

Key maintenance procedures and troubleshooting information: {{maintenance-details}}

## Output
Deliver a complete maintenance manual in markdown format with the following structure:

### 1. Introduction and Overview
Describe the equipment or system, its purpose, and key components.

### 2. Safety Precautions and Required Tools
List all safety warnings, personal protective equipment, and tools needed for maintenance.

### 3. Maintenance Schedule
- **Daily checks**: routine inspections
- **Weekly maintenance**: regular service tasks
- **Monthly maintenance**: intermediate procedures
- **Annual maintenance**: comprehensive overhauls

### 4. Detailed Maintenance Procedures
Provide step-by-step instructions for each routine maintenance task. Number each step clearly and note where visual aids (diagrams, photos, flowcharts) would be beneficial.

### 5. Troubleshooting Guide
For each common issue, present:
- **Problem**: symptom description
- **Diagnosis**: how to confirm the issue
- **Solution**: step-by-step resolution

### 6. Spare Parts List
Include part numbers, descriptions, recommended quantities, and ordering information.

### 7. Support and Warranty
Provide technical support contact details and warranty claim procedures.

**Format requirements:**
- Use headings, subheadings, and bullet points for easy navigation
- Keep language clear and accessible; avoid unnecessary technical jargon
- Indicate where diagrams or photographs should be inserted
- Ensure logical flow and professional presentation
```
