# Online Course Landing Page Copy Generator

## 簡介

The Online Course Landing Page Copy Generator is a free AI prompt that produces structured, conversion-focused landing page copy for solopreneurs selling online courses. This course landing page prompt for ChatGPT walks you through building a complete page structure: an attention-grabbing headline addressing your audience's pain points, 4-6 outcome-focused benefit statements emphasizing transformation, 2-3 credible testimonials with specific results, and a clear call-to-action with urgency or guarantee copy. The prompt uses dependency grammar principles to ensure each section flows logically into the next, creating a cohesive narrative that guides visitors toward enrollment. It runs on ChatGPT, Claude, Gemini, and Grok, accepting variables for solopreneur type, course topic and duration, unique selling proposition, and pricing strategy. Reach for this prompt when you need sales copy for a course launch, whether you're teaching freelancers, coaches, consultants, or any other solopreneur niche. ● Outputs headline, benefits block, testimonial set, and CTA as labeled sections ready to assemble ● Applies outcome-focused language and transformation framing to benefits copy ● Generates testimonials that address objections and include emotional and concrete results ● Ensures logical flow between sections using dependency grammar for narrative coherence ## Prompt

```
## Role
You are an expert landing page designer specializing in high-converting online course pages.

## Task
Create a complete landing page structure for an online course targeting solopreneurs. Each section must connect logically to build a cohesive narrative that drives enrollment.

## Context
- **Target audience:** {{solopreneur-type}}
- **Course details:** {{course-topic-and-duration}}
- **Unique selling proposition:** {{usp}}
- **Pricing:** {{pricing-strategy}}

## Output
Deliver the landing page in structured sections with clear headings:

### Headline
Craft an attention-grabbing headline that speaks directly to the target audience's pain points and aspirations.

### Benefits
Highlight 4-6 key course benefits using persuasive, outcome-focused language. Emphasize transformation and concrete results the solopreneur will achieve.

### Testimonials
Write 2-3 authentic-sounding testimonials that build credibility. Include specific results, objections overcome, and emotional transformation.

### Call-to-Action
Create a clear, prominent CTA that motivates immediate enrollment. Include the primary button text and supporting urgency or guarantee copy.

Use bullet points within each section for scannable content. Ensure dependency grammar principles guide the flow—each element should logically support and amplify the next.
```
