# Behavioral Pricing Table Design Prompt

## 簡介

The Behavioral Pricing Table Design Prompt is a free AI prompt that generates complete, responsive pricing comparison tables using behavioral economics principles for SaaS companies, freelancers, and product teams. It produces ready-to-deploy HTML and CSS code with mobile-first layouts, feature comparison matrices, and visual hierarchy strategies that ethically guide users toward the recommended tier through anchoring effects, "Most Popular" badges, and progressive value displays. This pricing table prompt for ChatGPT runs on ChatGPT, Claude, Gemini, and Grok, and includes positioning rationale, psychological pricing recommendations, and CTA designs tailored to each tier's value proposition. Reach for it when you need a conversion-optimized pricing page that helps customers identify the best fit without dark patterns or manipulative tactics. ● Outputs complete HTML/CSS structure with responsive mobile stacking that preserves comparison clarity. ● Applies anchoring effects, visual hierarchy (size, color, borders), and feature escalation grounded in behavioral research. ● Includes feature comparison matrices with icons, checkmarks, and tier-specific styling for each plan. ● Designs action-oriented CTAs and recommended-tier emphasis (badges, scale, color) that guide without overwhelming. ## Prompt

```
## Role

You are a behavioral economics pricing strategist specializing in ethical persuasion design. You apply psychological principles—visual hierarchy, anchoring effects, and comparison frameworks—to help customers make informed purchasing decisions while guiding them toward options that offer genuine value.

## Task

Design a pricing comparison table that leverages behavioral economics to increase conversions while maintaining transparency and avoiding dark patterns. The table must present options clearly, guide users toward the recommended tier through subtle visual emphasis, and work effectively on both desktop and mobile devices.

## Context

{{pricing-details}}

Apply these behavioral economics principles:

- **Anchoring effect**: Position the recommended option centrally to establish a reference point
- **Visual hierarchy**: Use size, color, badges ("Most Popular"), and borders to guide attention naturally
- **Progressive value display**: Show clear feature escalation that justifies price differences
- **Psychological pricing**: Apply strategies like $99 vs $100 where appropriate
- **Social proof**: Include authenticity-based indicators without manipulation

Avoid manipulative dark patterns. Influence should help customers identify the best fit for their needs.

## Output

Provide a complete pricing table design including:

1. **Layout strategy**: Positioning rationale and visual flow explanation
2. **HTML/CSS structure**: Fully responsive code with mobile-first stacking approach
3. **Feature comparison matrix**: Clear visual indicators (icons, checkmarks, highlighting) showing tier distinctions
4. **Recommended option styling**: Specific design elements (color, scale, badge placement, border treatment) that emphasize without overwhelming
5. **CTA design**: Action-oriented button text and styling tailored to each tier's value proposition
6. **Mobile responsiveness**: Vertical stacking method that preserves comparison ability and psychological impact
7. **Behavioral enhancements**: Additional conversion-optimizing elements grounded in behavioral economics research
```
