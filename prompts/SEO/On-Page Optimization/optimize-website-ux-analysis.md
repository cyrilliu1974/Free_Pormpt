# Website UX Audit Prompt for SEO Performance

## 簡介

The Website UX Audit Prompt for SEO Performance is a free AI prompt that analyzes websites to uncover user experience issues negatively impacting search rankings and organic visibility. This UX audit prompt for ChatGPT evaluates a target website URL and produces a structured report highlighting specific problems where poor user experience harms SEO performance. It prioritizes issues by severity (high, medium, low), delivers actionable improvement suggestions for each finding, and assigns an overall 1-5 UX rating from an SEO perspective. The analysis covers page speed, mobile responsiveness, navigation clarity, content accessibility, internal linking structure, and Core Web Vitals. Runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need to diagnose why a website underperforms in search despite solid content, or when preparing technical SEO recommendations that address the user experience layer. ● Identifies UX problems with direct SEO consequences, such as navigation barriers, slow load times, and mobile usability failures ● Assigns High, Medium, or Low priority to each issue based on its severity and impact on search visibility ● Delivers specific, actionable improvement suggestions rather than vague recommendations ● Produces a 1-5 overall UX rating calibrated to SEO standards, making it easy to benchmark progress over time ## Prompt

```
## Role
You are an expert website UX analyst with deep SEO knowledge. Evaluate the provided website for user experience issues that negatively impact search engine optimization.

## Task
Analyze {{website-url}} and deliver a structured UX audit focused on SEO impact. Identify specific issues, provide actionable improvements, and assign priority levels based on severity.

## Output
Structure your evaluation as follows:

**Website Evaluated:** {{website-url}}

**Key UX Findings Impacting SEO:**

1. [Issue title]
   - Suggestion: [Specific actionable improvement]
   - Priority: [High/Medium/Low]

2. [Issue title]
   - Suggestion: [Specific actionable improvement]
   - Priority: [High/Medium/Low]

[Continue for all issues identified]

**Additional SEO Considerations:**
- [Factor 1]
- [Factor 2]
- [Factor 3]

**Overall UX Rating for SEO:** [1-5]
- 5 = Excellent, no major issues
- 4 = Good, minor improvements needed
- 3 = Average, several areas need work
- 2 = Poor, significant issues present
- 1 = Very Poor, critical issues severely impacting SEO

## Evaluation Criteria
- Focus exclusively on UX issues with direct SEO impact
- Prioritize critical issues over minor ones
- Provide detailed, specific suggestions—avoid generic advice
- Consider page speed, mobile responsiveness, navigation clarity, content accessibility, internal linking, and Core Web Vitals
```
