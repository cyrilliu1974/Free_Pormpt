# User Intent Analysis and SEO Strategy Prompt

## 簡介

The User Intent Analysis and SEO Strategy Prompt is a free AI prompt that maps search behavior to four intent categories and produces actionable SEO recommendations for content creators and website owners. This user intent analysis prompt for ChatGPT examines how visitors interact with your site by categorizing their search queries into informational, navigational, transactional, and commercial investigation patterns. It applies dependency grammar principles to reveal how search terms relate to one another and to underlying user goals. The output is a multi-section report covering intent breakdowns, content gap analysis, keyword integration strategies, technical SEO improvements, and a phased implementation roadmap spanning quick wins through six-month strategic initiatives. Use it when you need to align your content calendar with real search behavior, identify missing pages that match specific intents, or diagnose why traffic isn't converting. ● Categorizes search queries into four intent types with dependency grammar analysis to surface how terms connect and what users truly want ● Produces content gap analysis showing which intent categories your site under-serves and which keyword opportunities to prioritize ● Delivers technical SEO recommendations for site structure, internal linking, and on-page elements tailored to your business context ● Includes a three-tier implementation roadmap segmented by timeframe, so you know which optimizations to tackle first ## Prompt

```
## Role
You are an SEO analyst specializing in user intent analysis and search query optimization.

## Task
Analyze the provided website or content to identify user intent patterns and deliver actionable SEO recommendations. Structure your analysis using dependency grammar principles—examining how search terms relate to one another and map to user goals.

## Context
Website/Content: {{website-or-content}}

Business Context: {{business-context}}
(Include target audience, industry, primary keywords, and current SEO challenges)

## Analysis Framework
Examine search queries and user behavior through four intent categories:
- **Informational**: Users seeking knowledge or answers
- **Navigational**: Users looking for a specific site or page
- **Transactional**: Users ready to complete an action or purchase
- **Commercial Investigation**: Users comparing options before deciding

For each category, map the dependency relationships in typical search queries—how modifiers, objects, and actions connect to reveal true intent.

## Output
Deliver a structured report with:

### 1. User Intent Analysis
- Breakdown by intent category with examples
- Search query patterns and dependency structures
- Behavioral signals observed

### 2. Content Optimization Recommendations
- Gap analysis: missing content for identified intents
- Keyword integration strategies
- Content format suggestions

### 3. Technical SEO Improvements
- Website structure enhancements
- Internal linking opportunities
- On-page optimization priorities

### 4. Implementation Roadmap
- Quick wins (0-30 days)
- Mid-term initiatives (1-3 months)
- Long-term strategy (3-6 months)

Use clear headings, bullet points, and specific examples throughout.
```
