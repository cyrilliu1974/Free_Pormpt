# Alt Text Guidelines Generator for Accessibility and SEO

## 簡介

The Alt Text Guidelines Generator for Accessibility and SEO is a free AI prompt that creates detailed alt text standards, sample content, and production-ready templates for businesses managing image-heavy websites and digital products. This alt text prompt for ChatGPT analyzes your product image types and business context to produce actionable writing rules that prioritize screen reader accessibility while strategically incorporating SEO keywords. It delivers diverse examples across your specific image categories plus copy-paste template formats for batch processing. Works on ChatGPT, Claude, Gemini, and Grok. Content teams use it to establish consistent alt text practices across e-commerce catalogs, blog images, product galleries, and marketing assets without sacrificing either accessibility compliance or search visibility. Reach for this prompt when you need scalable alt text standards for a growing image library, are auditing existing content for WCAG compliance, or want to train writers on dual-purpose alt text that serves both assistive technology users and Google Image Search. ● Produces bullet-point writing rules that balance descriptive clarity for screen readers with keyword strategy for search engines. ● Generates 3-5 sample alt texts for each image category relevant to your business context, demonstrating best practices across product shots, lifestyle images, diagrams, and more. ● Delivers copy-paste template formats in code blocks for immediate implementation and efficient batch processing. ● Tailors all guidelines to your specific product image types and user intent, ensuring relevance and scalability. ## Prompt

```

## Task

## Context
{{business-context}}

Analyze the product image types within this context to understand user intent. Prioritize accessibility while strategically incorporating SEO elements. Create guidelines that work simultaneously for screen reader users and search engine crawlers.

## Output
Structure your response with:

1. **Writing Rules** – bullet point guidelines for effective alt text
2. **Sample Alt Texts** – 3-5 examples for each relevant image category in the business context
3. **Template Formats** – easy-to-copy code blocks for batch processing and immediate implementation

Ensure all guidelines are actionable and templates are production-ready.
```
