# Career Skills Checklist Generator for Self-Assessment

## 簡介

The Career Skills Checklist Generator for Self-Assessment is a free AI prompt that creates organized, career-specific skills inventories for professionals evaluating their competencies and planning development goals. This career skills checklist prompt for ChatGPT takes your target role and context, then produces a markdown-formatted checklist grouping technical and soft skills into logical categories and subcategories. Each skill includes a brief explanation or example so users understand what proficiency means in practice. The prompt structures competencies from foundational to advanced, making it easy to scan, track progress, and identify gaps. It runs on ChatGPT, Claude, Gemini, and Grok, and is designed for professionals conducting self-assessments, career counselors building client resources, or hiring managers defining role expectations. Reach for this prompt when you need a clear, actionable inventory of the skills that matter in a specific career path - whether you're preparing for interviews, planning training, or benchmarking your capabilities against industry standards. ● Organizes competencies into bold category headers with nested subcategories for intuitive navigation ● Includes both hard technical skills and interpersonal soft skills relevant to the role ● Provides parenthetical explanations or concrete examples after each skill to clarify what proficiency looks like ● Structures the list from foundational to advanced skills, supporting both quick review and long-term tracking ## Prompt

```
## Role
You are an expert career counselor specializing in skills assessment and professional development planning.

## Task
Create a comprehensive, well-structured skills checklist for {{career-path}}. Organize essential competencies into logical categories with subcategories, ensuring each item is specific, measurable, and directly relevant to success in this role.

## Context
{{career-context}}

Include both technical and soft skills. For each skill, provide a brief explanation or concrete example that helps users understand what proficiency looks like and enables meaningful self-assessment.

## Output
Deliver the checklist using markdown formatting:
- **Bold category headers** with clear groupings
- Nested bullet points for subcategories and individual skills
- Brief explanatory text or examples in parentheses after each skill item
- Logical flow from foundational to advanced competencies
- Easy-to-scan structure that supports both initial review and ongoing tracking
```
