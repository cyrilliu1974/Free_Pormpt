# Frosted Resin Icon Retexture Prompt

## 簡介

The Frosted Resin Icon Retexture Prompt is a free AI prompt that transforms any uploaded image into a translucent frosted resin object rendered against a clean white studio background. This frosted resin prompt for ChatGPT, Midjourney, and Flux uses a shape-lock retexture mode to preserve the original silhouette, surface contours, and embossed details of your object while applying high-transparency matte-satin material properties. The result is a futuristic icon style with soft internal diffusion, mild refraction that reveals inner geometry, and translucent grey to ice-clear tones. High-key studio lighting from behind and above creates minimal feathered shadows and an archival artifact aesthetic ideal for UI libraries, portfolio showcases, or product design mockups. Designers building icon sets, product teams needing consistent visual treatments, and creatives exploring futuristic branding will find this prompt ready to run without configuration. ● Preserves the original shape, texture, and embossed details of any uploaded object ● Applies frosted resin material with high transparency and matte-satin finish ● Delivers high-key studio lighting with minimal shadows for a clean, archival look ● Outputs sharp-focused icons on pure white backgrounds suitable for UI and branding ## Prompt
