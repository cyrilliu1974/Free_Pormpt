# Game UI Design Concept Generator

## 簡介

The Game UI Design Concept Generator is a free AI prompt that produces first-person shooter UI screenshots with atmospheric environments and custom HUD overlays for game designers and concept artists. This game UI design prompt for Midjourney creates in-game mockups that combine environmental storytelling with functional interface elements. You specify the game genre (cyberpunk, military, fantasy, etc.) and HUD elements (ammo counters, health bars, radar maps, objective markers), and the prompt renders a first-person view with a weapon in the foreground, atmospheric lighting, and your chosen UI overlay in a cinematic 16:9 format. Game developers use it to visualize interface concepts before coding, while artists and indie studios rely on it to pitch mood and style to stakeholders. Reach for this prompt when you need rapid UI concept art that shows how interface elements will feel inside an actual game environment, not just on a flat artboard. ● Customizable game genre variable adapts the visual style from neon cyberpunk to gritty military or high-fantasy settings. ● HUD elements variable lets you specify exactly which interface components appear in the overlay (health, ammo, minimap, stamina, crosshairs). ● Outputs cinematic 16:9 screenshots with environmental depth, lighting, and a visible weapon to ground the first-person perspective. ● Raw mode flag preserves artistic control and reduces over-processing for cleaner, more professional concept frames. ## Prompt

```
Screenshot of game UI design, first-person {{game-genre}} shooter, neon-lit city street at night, rain-slick pavement reflecting holograms, futuristic weapon visible in foreground. HUD overlay includes {{hud-elements}}, moody neon sci-fi vibe. --ar 16:9 --raw
```
