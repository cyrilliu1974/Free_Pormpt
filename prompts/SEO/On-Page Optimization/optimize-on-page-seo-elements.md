# On-Page SEO Audit Checklist Generator

## 簡介

The On-Page SEO Audit Checklist Generator is a free AI prompt that analyzes any website and produces a comprehensive, actionable optimization checklist for SEO consultants, marketers, and site owners. This on-page SEO prompt for ChatGPT examines nine critical dimensions - title tags, meta descriptions, keyword density, header tags, content quality, internal linking, image optimization, URL structure, and mobile responsiveness - and returns checkbox-formatted recommendations tailored to the specific site you provide. It runs on ChatGPT, Claude, Gemini, and Grok, transforming a single URL into a prioritized action plan that balances keyword targeting with natural, user-friendly content. Use it when auditing client sites, preparing migration checklists, or training junior SEO team members on fundamentals. ● Covers title tags, meta descriptions, header hierarchy, keyword density, content structure, internal links, image alt text, URL formatting, and mobile responsiveness in one pass ● Outputs actionable checklist items you can hand directly to developers or content teams ● Tailors every recommendation to the analyzed site's structure and industry context ● Balances technical SEO requirements with readability and user experience best practices ## Prompt

```
## Role

You are an expert SEO consultant specializing in comprehensive on-page optimization.

## Task

Analyze the provided website and deliver a detailed, actionable checklist for improving its on-page SEO performance across nine critical dimensions.

## Context

Website to analyze: {{website-url}}

## Output

Provide a comprehensive on-page SEO checklist organized into the following sections. Use checkbox format for clarity and actionability:

**Title Tags:**
- [ ] Ensure each page has a unique, concise title tag (under 60 characters)
- [ ] Include primary keyword near the beginning of the title tag
- [ ] Avoid keyword stuffing and ensure titles read naturally

**Meta Descriptions:**
- [ ] Craft compelling, click-worthy meta descriptions for each page (under 155 characters)
- [ ] Incorporate primary and secondary keywords naturally
- [ ] Provide a clear, enticing summary of page content

**Keyword Density:**
- [ ] Aim for a keyword density of 1-2% for primary keywords
- [ ] Distribute keywords evenly throughout page content
- [ ] Avoid overusing keywords, as this may trigger spam filters

**Header Tags:**
- [ ] Use a single, relevant H1 tag per page
- [ ] Incorporate primary keywords in H1 tags when appropriate
- [ ] Use H2-H6 tags to create a logical content hierarchy

**Content Optimization:**
- [ ] Ensure content is well-written, informative, and engaging
- [ ] Optimize content length based on target keyword and user intent
- [ ] Use short paragraphs, bullet points, and subheadings for readability

**Internal Linking:**
- [ ] Link to relevant internal pages using descriptive anchor text
- [ ] Ensure all links are working and up-to-date
- [ ] Create a clear, intuitive site architecture to improve link equity flow

**Image Optimization:**
- [ ] Use descriptive, keyword-rich file names for images
- [ ] Include alt text for all images, incorporating relevant keywords
- [ ] Compress images to reduce page load time without sacrificing quality

**URL Structure:**
- [ ] Use short, descriptive, keyword-rich URLs
- [ ] Avoid excessive parameters and special characters in URLs
- [ ] Ensure URLs are static and easy to read

**Mobile Responsiveness:**
- [ ] Verify that the website is mobile-friendly and responsive
- [ ] Ensure content, images, and navigation elements adapt to various screen sizes
- [ ] Test page load speed on mobile devices and optimize as needed

Tailor all recommendations to the specific characteristics and needs of the analyzed website. Focus on high-impact optimizations that balance keyword targeting with natural, user-friendly content.
```
