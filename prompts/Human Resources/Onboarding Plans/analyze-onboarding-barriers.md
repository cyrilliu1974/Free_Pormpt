# Analyze Onboarding Barriers With Root Cause Mapping

## 簡介

The Analyze Onboarding Barriers With Root Cause Mapping prompt is a free AI prompt that transforms raw employee feedback into a structured root cause analysis for organizations refining their onboarding experience. This onboarding analysis prompt for ChatGPT, Claude, Gemini, and Grok applies fishbone diagram methodology to categorize barriers across six dimensions: People, Process, Technology, Environment, Materials, and Management. You provide your organization details, feedback data from surveys or exit interviews, and observed pain points; the prompt returns a cause-and-effect map of systemic issues and a prioritized action plan showing each issue's root cause, recommended solution, timeline, and resource requirements. Teams use it to reduce time-to-productivity, eliminate friction points, and improve new-hire satisfaction by fixing structural problems instead of patching symptoms. Reach for this prompt when you need to turn scattered onboarding complaints into a clear roadmap for operational improvement. ● Maps feedback into six root cause categories to reveal whether barriers stem from people, process, technology, environment, materials, or management. ● Produces a prioritized action plan with timelines and resource estimates so you can sequence fixes strategically. ● Distinguishes systemic issues from surface symptoms, ensuring solutions address underlying problems rather than temporary workarounds. ● Accepts survey responses, manager reports, exit interview notes, and other qualitative data as input. ## Prompt

```
## Role
You are an organizational systems analyst specializing in employee experience optimization and operational bottleneck elimination through root cause analysis.

## Task
Analyze onboarding feedback to identify recurring barriers, map them into root cause categories using fishbone diagram principles (People, Process, Technology, Environment, Materials, Management), and develop actionable solutions that address systemic issues rather than symptoms.

## Context
Organization and onboarding program:
{{organization-and-program-details}}
(Include: organization type, size, current onboarding duration, and available resources/constraints)

Onboarding feedback data:
{{onboarding-feedback}}
(Paste recent survey responses, exit interview notes, manager reports, or other feedback sources)

Primary challenges:
{{key-pain-points}}
(Describe the most pressing onboarding issues you've observed)

## Output
Structure your analysis with the following sections:

**Root Cause Mapping by Category:**
- **People** – barriers related to roles, skills, communication, culture
- **Process** – workflow gaps, unclear procedures, handoff failures
- **Technology** – system access, tool training, integration issues
- **Environment** – physical/remote workspace, team dynamics, support structures
- **Materials** – documentation quality, resource availability, content gaps
- **Management** – oversight, accountability, leadership engagement

For each category, list identified issues as bullet points showing cause-and-effect relationships.

**Prioritized Action Plan:**
Present recommendations in a table with columns:
- Issue
- Root Cause
- Recommended Solution
- Timeline
- Resource Requirements

Focus solutions on improving time-to-productivity, reducing friction points, and enhancing onboarding satisfaction.
```
