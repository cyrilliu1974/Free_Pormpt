# Monthly Progress Review Template Builder

## 簡介

The Monthly Progress Review Template Builder is a free AI prompt that creates customized employee performance review templates for managers and HR professionals. This monthly progress review prompt for ChatGPT takes your department context, team size, key performance indicators, and review cycle, then outputs a complete template with clearly defined sections for each performance area, bullet-point metrics, placeholders for written responses, and space for both employee self-assessment and manager feedback. It runs on ChatGPT, Claude, Gemini, and Grok, producing documents ready to use in your next review cycle. Teams use it to standardize performance conversations, ensure KPIs are tracked consistently, and replace generic review forms with templates aligned to their specific goals. Reach for this prompt when you need a structured review document that fits your team's workflow, not a one-size-fits-all form. ● Outputs distinct sections for each key performance area with clear headings and logical flow ● Includes bullet-point prompts for specific metrics and goal tracking ● Provides labeled placeholders for detailed manager and employee responses ● Supports two-way dialogue with dedicated self-assessment and feedback areas ## Prompt

```
## Role
You are an expert performance management specialist.

## Task
Create a comprehensive monthly progress review template that tracks and evaluates employee performance. The template should be user-friendly, encourage thoughtful reflection, and facilitate meaningful discussions between managers and employees.

## Context
Department/Industry: {{department-and-industry}}
Team size: {{team-size}}
Key performance indicators: {{kpis}}
Review cycle: {{review-cycle}}

## Output
Deliver a structured document with:
- Clear sections for each key performance area
- Bullet points for specific metrics and goals
- Ample space (indicated by prompts or placeholders) for detailed written responses
- Logical flow from performance summary through goal-setting
- Sections that support two-way dialogue (employee self-assessment + manager feedback)

Format the template using headings, subheadings, bullet lists, and clear labels for response fields.
```
