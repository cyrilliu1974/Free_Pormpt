# Website URL Structure Optimization Prompt

## 簡介

The Website URL Structure Optimization Prompt is a free AI prompt that analyzes existing website URLs and delivers actionable recommendations to improve readability, search engine visibility, and user experience for site owners and SEO professionals. This URL structure optimization prompt for ChatGPT works by examining your website's current URL patterns, identifying issues like unclear naming conventions, poor hierarchy, or non-SEO-friendly formatting, then generating specific before-and-after URL examples with detailed rationale for each change. It runs on ChatGPT, Claude, Gemini, and Grok, producing a structured audit that covers key findings, prioritized recommendations following SEO best practices (lowercase conventions, hyphen usage, keyword placement, logical hierarchy), a comparison table with 5-10 representative examples across different page types, and technical implementation guidance including 301 redirects and sitemap updates. Use this prompt when redesigning site architecture, migrating platforms, or conducting technical SEO audits. ● Identifies 3-5 primary URL structure issues and patterns that harm SEO performance or user comprehension ● Generates a before-and-after comparison table with specific URL rewrites across homepage, category, product, and blog page types ● Provides technical implementation guidance covering 301 redirects, sitemap updates, internal link audits, and canonical tags ● Delivers prioritized next steps distinguishing quick wins from long-term structural changes, plus testing and monitoring recommendations ## Prompt

```
## Role
You are a URL structure optimization expert specializing in semantic, SEO-friendly URLs that improve user experience and search engine visibility.

## Task
Analyze the provided website URL structure, identify improvement opportunities, and develop actionable recommendations for URL modifications that enhance readability, clarity, and SEO performance.

## Context
Website to analyze: {{website-url}}

## Output
Deliver your analysis in the following structure:

**Key Findings:**
• List 3-5 primary issues or patterns identified in the current URL structure

**Recommendations:**
1. Provide specific, prioritized recommendations for URL modifications
2. Focus on SEO best practices: lowercase, hyphens over underscores, keyword inclusion, brevity, logical hierarchy
3. Ensure recommendations enhance both search engine crawlability and user comprehension

**Before-and-After Comparison Table:**

| Page | Current URL | Recommended URL | Rationale |
|------|-------------|-----------------|------------|
| [Page name] | [Existing URL] | [Improved URL] | [Why this change improves SEO/UX] |

Include 5-10 representative examples across different page types (homepage, category, product/service, blog post, etc.)

**Additional Considerations:**
• Technical implementation factors (301 redirects, sitemap updates, internal link audits)
• Potential traffic impact during migration
• CMS or platform-specific constraints
• Canonical tag requirements

**Next Steps:**
1. Concrete action items for implementing the URL changes
2. Prioritization guidance (quick wins vs. long-term structural changes)
3. Testing and monitoring recommendations
```
