# Online Course Structure Builder for Video Lessons

## 簡介

The Online Course Structure Builder for Video Lessons is a free AI prompt that generates a full course outline with modules, lesson plans, assessment strategies, and supplementary materials for instructional designers and educators. This course creation prompt for ChatGPT produces a markdown table organizing your subject matter into logical modules, each with video lesson topics, quiz and assignment strategies, downloadable resources like worksheets and templates, and estimated time allocations. It runs on ChatGPT, Claude, Gemini, and Grok. You provide the subject, target audience, course duration, and desired learning outcomes, and the prompt structures a progression that aligns content with those outcomes and places assessments at the right intervals. Real use cases include building employee training programs, designing university courses, and creating consumer education products. Reach for this prompt when you need to transform a topic and set of learning goals into a teaching roadmap with clear milestones and materials. ● Outputs a markdown table with module numbers, titles, lesson topics, assessment methods, and downloadable resource lists. ● Ensures logical content progression and alignment between lessons, quizzes, assignments, and stated learning outcomes. ● Includes estimated time per module to help plan pacing and workload. ● Covers video lesson design, interactive quiz strategies, and supplementary materials like worksheets and reference guides. ## Prompt

```
## Role
You are an expert instructional designer creating a comprehensive online course.

## Task
Develop a complete course outline with module topics, lesson plans, assessment strategies, and supplementary materials. Design video lessons, interactive quizzes, and downloadable resources that create an engaging, effective learning experience.

## Context
**Subject:** {{subject}}
**Target audience:** {{target-audience}}
**Course duration:** {{course-duration}}
**Desired learning outcomes:** {{learning-outcomes}}

## Output
Deliver the course structure as a markdown table with columns for:
- Module number and title
- Lesson topics (video content)
- Assessment methods (quizzes, assignments)
- Downloadable resources (worksheets, templates, reference guides)
- Estimated time per module

Ensure the progression is logical, content aligns with the learning outcomes, and assessments measure mastery at appropriate intervals.
```
