# Educational Data Dashboard Builder Prompt

## 簡介

The Educational Data Dashboard Builder Prompt is a free AI prompt that creates detailed implementation guides for designing analytics dashboards tailored to educational institutions and data teams. This educational data visualization prompt for ChatGPT walks you through the complete workflow of transforming raw education data into interactive dashboards. It produces a numbered, step-by-step guide covering data preparation, metric definition, visualization selection, layout design, interactivity features, and final documentation. You input your specific education data, analytics tool, target audience, and desired metrics, and the prompt generates a structured plan for building dashboards that surface insights on student performance, attendance, and engagement. Use it when you need to communicate complex educational data to administrators, teachers, or stakeholders through clear visual interfaces. It runs on ChatGPT, Claude, Gemini, and Grok. ● Addresses the full dashboard lifecycle from data validation through testing and refinement ● Guides visualization type selection appropriate for performance, attendance, and engagement metrics ● Includes recommendations for color schemes, accessibility, and user-friendly navigation ● Generates interactive chart configurations that enable dynamic data exploration ● Delivers documentation and presentation strategies for communicating insights to stakeholders ## Prompt

```
## Role
You are an expert data analyst specializing in educational analytics and dashboard design.

## Task
Create a comprehensive dashboard that presents insights into student performance, attendance, and engagement in an easily digestible format. Deliver a step-by-step implementation guide that covers the complete workflow from data preparation through final presentation.

## Context
Education data: {{education-data}}

Analytics tool: {{analytics-tool}}

Target audience: {{audience}}

Key metrics and desired insights: {{metrics-and-insights}}

## Process
For each step, address:
- Data structure understanding and key metric identification
- Appropriate visualization types for performance, attendance, and engagement data
- Interactive chart and graph configurations for dynamic exploration
- User-friendly layout and navigation design
- Color schemes optimized for clarity and accessibility
- Interactivity features that enhance comprehension
- Meaningful at-a-glance insights and summary views

## Output
Deliver your response as a numbered step-by-step guide, covering:
1. Data preparation and validation
2. Metric definition and calculation
3. Visualization selection and design
4. Dashboard layout and structure
5. Interactivity implementation
6. Testing and refinement
7. Final presentation and documentation
```
