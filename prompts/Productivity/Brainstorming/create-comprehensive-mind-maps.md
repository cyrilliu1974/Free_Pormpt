# Mind Map Generator for Complex Topics

## 簡介

The Mind Map Generator for Complex Topics is a free AI prompt that creates structured, three-level hierarchical outlines for any subject you need to understand or communicate. It transforms complex ideas into organized visual frameworks with main concepts, sub-topics, and detailed elements clearly labeled and indented. This mind map prompt for ChatGPT works by identifying three distinct top-level concepts, then developing two sub-topics under each, and finally adding two granular points beneath every sub-topic for a total of twelve detailed nodes. The prompt runs on ChatGPT, Claude, Gemini, and Grok, producing text-based hierarchical outlines that clarify relationships between ideas. Use it when you're learning a new domain, preparing a presentation, teaching a course, planning a project, or researching a topic that has multiple interconnected parts. ● Produces exactly three main concepts with two sub-topics each, ensuring balanced coverage ● Enforces non-overlapping branches so every node adds unique information ● Outputs clean indented text format ready to paste into note-taking or diagramming tools ● Includes quality checks for conciseness, meaningful detail at each level, and complete topic coverage ## Prompt

```
## Role
You are a mind mapping expert who breaks down complex topics into clear, hierarchical structures that reveal relationships between concepts.

## Task
Create a comprehensive three-level mind map for {{topic}} that organizes main concepts, sub-topics, and detailed elements into a visually balanced structure.

## Structure Requirements
- Generate a descriptive title that encapsulates the topic
- Identify 3 distinct main concepts as top-level branches
- Under each main concept, develop 2 sub-topics that detail specific aspects
- Under each sub-topic, develop 2 sub-sub-topics that provide granular information
- Use indentation and bullet points to show hierarchical relationships clearly

## Quality Criteria
- Main concepts must be distinct and non-overlapping
- Each level should add meaningful detail, not redundancy
- Use concise, descriptive labels throughout
- Ensure the map is comprehensive and covers all key aspects of the topic
- Create a well-balanced layout that is easy to follow

## Output Format
```

Main Concept 1

 Sub-sub-topic 1.1.1
 Sub-sub-topic 1.1.2
 Sub-topic 1.2
 Sub-sub-topic 1.2.1
 Sub-sub-topic 1.2.2

Main Concept 2
 Sub-topic 2.1
 Sub-sub-topic 2.1.1
 Sub-sub-topic 2.1.2
 Sub-topic 2.2
 Sub-sub-topic 2.2.1
 Sub-sub-topic 2.2.2

Main Concept 3
 Sub-topic 3.1
 Sub-sub-topic 3.1.1
 Sub-sub-topic 3.1.2
 Sub-topic 3.2
 Sub-sub-topic 3.2.1
 Sub-sub-topic 3.2.2
