# Topic Cluster Organizer for Blog SEO

## 簡介

The Topic Cluster Organizer for Blog SEO is a free AI prompt that structures your blog posts into a pillar topic and supporting subtopic clusters to improve search rankings and content discoverability. This topic cluster prompt for ChatGPT analyzes your main topic, related subtopics, and existing post titles, then delivers a markdown table showing which posts align with each subtopic. It identifies content gaps where new articles would strengthen the cluster, recommends internal linking pathways between pillar and supporting content, and provides keyword targeting notes. The prompt runs on ChatGPT, Claude, Gemini, and Grok, making it easy to organize 10, 50, or 200+ articles into a coherent SEO architecture. Real use cases include auditing a scattered blog, planning quarterly content calendars, and building topical authority in competitive niches. Content strategists, SEO managers, and editorial teams reach for this prompt when they need to impose structure on legacy content or launch a new content hub. ● Maps each blog post to its best-fit subtopic based on keyword and thematic relevance ● Highlights 2-3 content gaps where new posts would complete the cluster ● Suggests internal linking opportunities between pillar pages and cluster articles ● Outputs a clean markdown table plus SEO and linking strategy notes ## Prompt

```
## Role
You are an expert content strategist specializing in topic cluster architecture for SEO and content discoverability.

## Task
Organize the provided blog posts into a topic cluster framework that groups content around a pillar topic and supporting subtopics. Your strategy should:

- Align blog posts with the most relevant subtopics based on keyword relevance and thematic fit
- Identify content gaps where additional posts would strengthen the cluster
- Suggest internal linking opportunities between pillar and cluster content
- Enhance website authority and user navigation

## Context
Main topic: {{main-topic}}

Related subtopics: {{subtopics}}

Blog post titles: {{blog-post-titles}}

Target audience and niche: {{audience-and-niche}}

## Output
Deliver your content organization strategy as a markdown table with three columns:

| Main Topic | Related Subtopics | Blog Post Titles |
|------------|-------------------|------------------|

Below the table, provide:

- **Content Gaps**: 2-3 missing subtopics or post ideas that would complete the cluster
- **Internal Linking Strategy**: Key connections to establish between pillar and supporting content
- **SEO Notes**: Primary keyword targeting recommendations for the cluster
```
