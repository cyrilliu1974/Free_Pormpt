# SEO Training Framework Builder for Corporate Teams

## 簡介

The SEO Training Framework Builder for Corporate Teams is a free AI prompt that creates a structured educational curriculum covering keyword research, on-page optimization, technical SEO, link building, and performance measurement for companies training their teams in search engine optimization. This SEO training framework prompt for ChatGPT produces a ready-to-use table with three columns: Subtopic, Assigned Team Member, and Learning Objectives. You provide your company name and optional team assignments, and the prompt generates specific, actionable learning goals for each SEO discipline. Real use cases include onboarding digital marketing teams, upskilling content creators, and standardizing SEO knowledge across departments. It runs on ChatGPT, Claude, and Gemini. Reach for this prompt when you need to design an internal SEO education program quickly, ensure consistent skill development across your organization, or document a formal training roadmap with accountability. ● Breaks SEO into five core subtopics with specific, measurable learning objectives for each area ● Includes dedicated sections for keyword research, on-page optimization, technical SEO, link building, and analytics ● Supports team member assignment to promote accountability and expertise ownership ● Outputs a clean table format that integrates directly into learning management systems or training documentation ## Prompt

```
## Role

You are an expert educator and curriculum designer specializing in corporate learning experiences.

## Task

Create a comprehensive SEO basics educational framework for {{company-name}}'s team. Break down SEO into key subtopics, assign team members, and define clear learning objectives for each area.

## Output

Present the framework as a table with three columns: Subtopic, Assigned Team Member, and Learning Objectives.

Structure the framework to cover these essential SEO areas:

**SEO Basics Educational Framework for {{company-name}} Team**

| Subtopic | Assigned Team Member | Learning Objectives |
|----------|----------------------|---------------------|
| Keyword Research | {{team-assignments}} | - Understand the importance of keyword research<br>- Learn how to use keyword research tools effectively<br>- Identify high-value, relevant keywords for the company |
| On-Page Optimization | | - Master the elements of on-page SEO<br>- Learn how to optimize titles, meta descriptions, headers, and content<br>- Understand the role of internal linking and site structure |
| Technical SEO | | - Grasp the fundamentals of technical SEO<br>- Learn about crawlability, indexability, and site speed optimization<br>- Understand the importance of mobile-friendliness and responsive design |
| Link Building | | - Recognize the value of high-quality backlinks<br>- Learn white-hat link building strategies and tactics<br>- Understand how to build relationships and earn links naturally |
| Measuring SEO Success | | - Learn how to set SEO goals and KPIs<br>- Understand key SEO metrics and how to track them<br>- Gain insights from SEO data to continually improve strategies |

For each subtopic, ensure learning objectives are specific, actionable, and aligned with building practical SEO competency.
```
