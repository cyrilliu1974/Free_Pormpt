# SEO Landing Page Strategy Builder

## 簡介

The SEO Landing Page Strategy Builder is a free AI prompt that creates end-to-end landing page strategies optimized for target keywords, audience intent, and conversion. This SEO landing page prompt for ChatGPT delivers a multi-section blueprint covering keyword mapping, content structure, technical optimization, and competitive positioning. It analyzes search intent, recommends header hierarchies, outlines meta tag templates, and prescribes A/B testing priorities - all tailored to your industry, audience, unique selling proposition, and competitor landscape. Runs on ChatGPT, Claude, and Gemini. Use it when launching new product pages, optimizing existing campaign landing pages, or building SEO-first lead generation funnels that need both ranking power and conversion lift. ● Delivers keyword placement strategy, semantic clusters, and search intent analysis mapped to page sections. ● Provides title tag and meta description templates, URL structure guidance, and schema markup recommendations. ● Outlines conversion tactics including CTA placement, trust signals, form optimization, and above-the-fold layout. ● Includes competitive gap analysis, USP messaging frameworks, and A/B testing priorities with metrics to track. ## Prompt

```
## Role
You are an expert digital marketer specializing in SEO and landing page optimization.

## Task
Create a comprehensive strategy for building high-performing landing pages optimized for {{target-keywords}} that improve search rankings, drive qualified traffic, and convert visitors effectively.

## Context
Industry: {{industry}}
Target audience: {{target-audience}}
Unique selling proposition: {{usp}}
Main competitors: {{competitors}}

## Output
Provide a structured strategy with clear headings and subheadings covering:

### Keyword Research & Mapping
- Primary and secondary keyword placement strategy
- Search intent analysis for the target keywords
- Semantic keyword clusters to support content depth

### Page Structure & Content
- Headline and subheadline formulas optimized for the keywords
- Content hierarchy using header tags (H1, H2, H3)
- Body content framework that addresses user intent
- Internal linking strategy

### On-Page SEO Elements
- Title tag and meta description templates
- URL structure recommendations
- Image optimization (alt text, file names, compression)
- Schema markup suggestions

### Conversion Optimization
- Above-the-fold layout recommendations
- Call-to-action placement and messaging
- Trust signals and social proof integration
- Form design and field optimization

### Competitive Differentiation
- Analysis of competitor landing page gaps
- USP positioning and messaging strategy
- Unique value propositions to highlight

### Technical Performance
- Page speed optimization checklist
- Mobile responsiveness requirements
- Core Web Vitals considerations

### Testing & Iteration
- A/B testing priorities
- Key performance metrics to track
- Continuous improvement recommendations
```
