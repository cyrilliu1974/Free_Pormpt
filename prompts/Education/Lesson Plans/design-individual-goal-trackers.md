# Student Learning Goal Tracker Template Builder

## 簡介

The Student Learning Goal Tracker Template Builder is a free AI prompt that creates personalized progress monitoring tables for educators and tutors. This learning goal tracker prompt for ChatGPT takes your student age group, subject area, learning objectives, and tracking frequency - then produces a markdown table with three columns: Goals, Milestones, and Achievements. Each goal is broken into 2–4 concrete, sequential milestones that provide clear stepping stones toward mastery, while the Achievements column defines what success looks like and provides space for completion dates and reflections. It works across ChatGPT, Claude, and Gemini, adapting language and complexity to match the student's developmental stage. Teachers use it to monitor individual student progress, tutors rely on it for session planning, and educational consultants deploy it to create motivating, adaptable tracking systems that fit different learning styles and paces. This prompt is designed for educators who need clear, structured ways to celebrate incremental progress and keep students engaged. ● Outputs a markdown table with Goals, Milestones, and Achievements columns for at least five distinct learning objectives ● Breaks each goal into 2–4 sequential, actionable milestones that build toward mastery ● Uses age-appropriate language and adjusts challenge level to match the student's developmental stage ● Includes an Achievements column that defines success criteria and encourages reflection on progress ## Prompt

```
## Role
You are an expert educational consultant specializing in personalized learning goal trackers and progress monitoring systems.

## Task
Design a structured learning goal tracker that breaks down objectives into manageable milestones and celebrates student progress. The tracker should be motivating, clear, and adaptable to different learning styles and paces.

## Context
Student age group and subject: {{student-and-subject}}

Learning objectives: {{learning-objectives}}

Tracking frequency: {{tracking-frequency}}

Consider age-appropriate language, ensure goals are challenging yet achievable, and create milestones that provide clear stepping stones toward mastery. Space for achievements should encourage reflection and celebration of progress.

## Output
Provide your output as a markdown table with three columns: **Goals**, **Milestones**, and **Achievements**.

Include at least 5 rows, with each row representing a distinct learning goal. Each goal should be broken into 2-4 concrete milestones that build sequentially, and the Achievements column should describe what success looks like or provide space for noting completion dates and reflections.
```
