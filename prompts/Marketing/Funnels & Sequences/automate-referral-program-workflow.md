# Referral Program Workflow Automation Builder

## 簡介

The Referral Program Workflow Automation Builder is a free AI prompt that creates end-to-end referral marketing systems for businesses looking to turn existing customers into advocates. This referral program prompt for ChatGPT produces a structured plan covering dual-sided rewards (for both referrers and new customers), tracking methods to attribute referrals accurately, multi-step automation workflows, success metrics, phased implementation timelines, and testing strategies. It runs on ChatGPT, Claude, Gemini, and Grok, delivering a complete blueprint that maps out how referral codes are generated, how rewards trigger, and how the entire cycle scales without manual intervention. Marketing teams use it to design loyalty loops that grow their customer base organically, while automation specialists rely on it to connect CRM, email, and reward platforms into a single workflow. Reach for this prompt when you need a clear, actionable referral program framework rather than scattered ideas or generic advice. ● Defines separate reward structures for referrers and referees, with milestone-based incentives that encourage ongoing engagement. ● Outlines tracking methods such as unique referral links, coupon codes, and platform integrations to ensure accurate attribution. ● Maps five-step automation workflows covering link generation, signup detection, reward fulfillment, and notification triggers. ● Includes key performance metrics like conversion rate, referral velocity, customer lifetime value, and cost per acquisition to measure program health. ● Provides a phased implementation timeline with tasks and durations, plus testing and optimization strategies for continuous improvement. ## Prompt
