# Modular Dashboard UI Design Prompt

## 簡介

The Modular Dashboard UI Design Prompt is a free AI prompt that generates sleek, functional dashboard interfaces with modular panel layouts and drag-and-drop capabilities for designers and product teams. This dashboard UI prompt for Midjourney produces organized workspace mockups featuring responsive grid systems, smooth gradient accents, minimal iconography, and clean typography. It works on Midjourney, Flux, and Nano Banana to create professional dashboard concepts with sidebar navigation and a modern flat design aesthetic. Designers use it to prototype admin panels, project management tools, analytics dashboards, and creative workspace applications where usability and visual clarity are priorities. Reach for this prompt when you need to visualize a data-rich or tool-heavy interface that balances information density with ease of use. ● Produces modular panel layouts with drag-and-drop interface components and responsive grid systems. ● Renders minimal iconography, smooth gradient accents, and clean typography for a modern flat aesthetic. ● Outputs organized sidebar navigation and intuitive workspace experiences tailored to your design focus. ● Generates 3:4 aspect ratio mockups suitable for portfolio presentations, client pitches, and development handoff. ## Prompt

