# URL Structure Best Practices Guide for SEO

## 簡介

The URL Structure Best Practices Guide for SEO is a free AI prompt that creates detailed technical SEO guidance for optimizing website URLs to prevent duplicate content issues and improve crawling efficiency. This URL structure prompt for ChatGPT produces a multi-section guide covering common URL problems, actionable solutions, and implementation steps tailored to your specific website. It runs on ChatGPT, Claude, and Gemini, generating accessible guidance that works for both technical developers and non-technical site owners. The output includes duplicate content diagnostics, architectural best practices, real-world scenario analysis, and ongoing maintenance strategies that improve both search engine indexing and user experience. Reach for this prompt when auditing site architecture, migrating domains, resolving indexation problems, or establishing URL conventions for new websites. ● Identifies four common URL issues causing duplicate content with specific solutions for each ● Delivers five core best practices for URL structure optimization that balance SEO and usability ● Provides three real-world scenario examples with recommended fixes for typical problems ● Includes four implementation steps plus three monitoring tips for sustained optimization ## Prompt

```

## Task
Create a comprehensive guide on URL structure best practices to prevent duplicate content issues and ensure optimal crawling and indexing by search engines. Make the guide accessible to both technical and non-technical readers.

## Context
Website: {{website-url}}

The guide will help identify common URL problems, provide actionable solutions, and recommend implementation steps to optimize website architecture.

## Output
Organize your response into these sections:

**Introduction**
Provide a brief overview of URL best practices and their importance for SEO and user experience.

**Common URL Issues Leading to Duplicate Content**
- List 4 common issues that lead to duplicate content
- Provide a solution for each issue

**Best Practices for URL Structure**
- List 5 best practices for optimizing URL structure

**Example Scenarios**
- Present 3 specific scenarios illustrating common URL structure problems
- Provide a recommended solution for each scenario

**Implementing URL Best Practices**
- Outline 4 steps for implementing the recommended URL best practices

**Monitoring and Maintenance**
- Provide 3 tips for monitoring and maintaining an optimized URL structure

**Conclusion**
Summarize the key points and benefits of following URL structure best practices.

Use bullet points for lists. Use clear language and specific examples. Avoid technical jargon where possible. Emphasize benefits for both SEO and user experience.
```
