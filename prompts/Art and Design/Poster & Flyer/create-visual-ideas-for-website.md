# Website Design Mood Board Generator

## 簡介

The Website Design Mood Board Generator is a free AI prompt that creates cohesive visual design strategies for web designers, brand teams, and creative agencies. This website design mood board prompt for ChatGPT produces a structured concept board covering four core areas: color palettes with hex codes and psychology rationale, typography pairings with hierarchy guidance, imagery direction including photography style and visual tone, and layout concepts with grid structures and component patterns. It works by analyzing your project brief and target audience to ground recommendations in current design trends, user experience principles, and brand identity alignment. Use it when planning website redesigns, pitching new client projects, or establishing visual direction for digital products on ChatGPT, Claude, Gemini, or Grok. ● Outputs primary, secondary, and accent colors with hex codes and color psychology explanations tied to brand messaging ● Suggests heading and body font combinations with rationale for readability and visual hierarchy ● Defines photography style, illustration approaches, and graphic treatments that match the desired mood and tone ● Provides grid structures, spacing principles, and page template recommendations grounded in UX best practices ## Prompt

```
## Role
You are an expert web designer creating visually appealing and engaging design concepts.

## Task
Generate a comprehensive mood board that effectively communicates the brand's message and resonates with the target audience.

## Context
Website type, industry, and design direction: {{project-brief}}

Target audience and brand message: {{audience-and-message}}

Analyze the information provided to develop a cohesive design strategy incorporating color palettes, typography, imagery, and layout concepts. Ground your recommendations in current design trends, user experience principles, and brand identity.

## Output
Present your mood board concept using the following structure:

**Color Palette**
- Primary, secondary, and accent colors with hex codes
- Rationale for color psychology and brand alignment

**Typography**
- Heading and body font pairings
- Hierarchy and readability considerations

**Imagery**
- Photography style, illustration approach, or graphic treatment
- Mood and visual tone

**Layout Concepts**
- Grid structure and spacing principles
- Key page templates or component patterns

Use bullet points or numbered lists for specific details under each category.
```
