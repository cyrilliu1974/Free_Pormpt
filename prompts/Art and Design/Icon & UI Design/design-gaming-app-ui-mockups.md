## 簡介

The Gaming App UI Mockup Prompt for Midjourney is a free AI prompt that generates front-view mobile UI designs for gaming applications with cyberpunk aesthetics and neon styling. This gaming app UI mockup prompt for Midjourney produces a flat, centered phone mockup on a dark neon background, featuring a hero banner with customizable game key art, glowing futuristic typography, and interactive product cards for skins and gear. The output includes RGB accent lighting, sharp geometric interface components, and a bold "Play Now" call-to-action button rendered in a 3:4 aspect ratio with raw style parameters.
