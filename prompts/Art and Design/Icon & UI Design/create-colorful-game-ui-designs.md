# Game UI Design Prompt for 2D Platformers

## 簡介

The Game UI Design Prompt for 2D Platformers is a free AI prompt that generates complete game interface screenshots for colorful side-scrolling platformer levels with customizable game elements. This game UI prompt for Midjourney produces 16:9 screenshots featuring functional interface components - score counters, countdown timers, and remaining lives indicators - overlaid on vibrant platformer scenes with your specified game elements like floating platforms, collectible coins, jumping characters, or power-ups. The output uses a playful cartoon retro-game aesthetic with bold, vibrant colors that capture the feel of classic 2D platformers while maintaining modern visual appeal. Designers, indie game developers, and visual artists reach for this prompt when prototyping UI layouts, pitching game concepts, or creating portfolio pieces that demonstrate interface design skills. ● Produces full 16:9 game UI screenshots with functional interface elements (score, timer, lives) positioned for real gameplay. ● Customizable through the game-elements variable to feature your specific platforms, characters, collectibles, or obstacles. ● Delivers a cohesive playful cartoon retro aesthetic with vibrant color palettes suitable for mobile games, web games, or portfolio mockups. ● Raw style output provides clean, detailed rendering ideal for presentation decks, Steam store mockups, or design system documentation. ## Prompt
