# Product Page SEO Optimization Strategy Builder

## 簡介

The Product Page SEO Optimization Strategy Builder is a free AI prompt that creates comprehensive on-page optimization strategies for e-commerce product pages tailored to your store and competitive landscape. This product page optimization prompt for ChatGPT walks you through seven essential SEO components: keyword research methodology, title tag formulas, meta description best practices, header tag hierarchy, product description enhancement techniques, image SEO implementation, and prioritized action steps. It runs on ChatGPT, Claude, and Gemini, delivering structured guidance that balances search engine visibility with user experience and conversion optimization. E-commerce managers use it to audit existing product pages, onboard new catalog items with proper SEO structure, or build documentation for their content teams. Reach for this prompt when you need a clear, actionable roadmap to improve product page rankings without sacrificing readability or shopping experience. ● Produces keyword research frameworks with intent mapping specific to product categories and customer demographics ● Delivers character-limited formulas for title tags and meta descriptions designed to improve click-through rates ● Provides header tag hierarchies (H1-H3) and product description structures that integrate keywords naturally while maintaining scannability ● Includes image SEO protocols covering file naming conventions, alt text templates, compression guidelines, and structured data markup ● Organizes recommendations into quick wins and long-term improvements with clear rationale tied to ranking factors and conversions ## Prompt

```
## Role
You are an expert SEO specialist optimizing product pages for e-commerce search visibility.

## Task
Create a comprehensive on-page SEO optimization strategy for product pages that balances search engine performance with user experience. Cover keyword research, technical elements (titles, meta descriptions, headers), content optimization, and image SEO.

## Context
**Store & Audience:**
{{store-and-audience}}
(Include: type of e-commerce store, target customer demographics and intent, main product categories)

**Competitive Landscape:**
{{competitive-context}}
(Include: primary competitors, current SEO challenges or pain points)

## Output
Deliver a step-by-step optimization strategy organized with clear headers, subheaders, and bullet points. Structure your response to cover:

1. **Keyword Research Strategy** – methods, tools, and intent mapping for product pages
2. **Title Tag Optimization** – formula, character limits, keyword placement
3. **Meta Description Optimization** – best practices, CTR optimization, length guidelines
4. **Header Tag Structure** (H1-H3) – hierarchy, keyword integration, user scannability
5. **Product Description Enhancement** – unique content strategies, keyword density, readability
6. **Image SEO** – file naming, alt text, compression, structured data
7. **Implementation Priorities** – quick wins vs. long-term improvements

Ensure every recommendation is actionable and includes rationale tied to both search ranking factors and conversion optimization.
```
