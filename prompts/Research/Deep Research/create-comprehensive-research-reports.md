# Research Report Writing Prompt for Any Topic

## 簡介

The Research Report Writing Prompt for Any Topic is a free AI prompt that synthesizes information from multiple authoritative sources into cohesive, well-cited special reports for researchers, journalists, and analysts. This research report prompt for ChatGPT works by guiding the AI to cover a subject comprehensively from multiple angles, gathering facts and perspectives from authoritative sources and structuring them into an engaging narrative. It produces reports with executive summaries, introductions, multiple thematic sections with inline citations, and conclusions - all written in an accessible style for general audiences. The prompt runs on ChatGPT, Claude, Gemini, and Grok, using dependency grammar techniques to maintain logical flow and readability across long-form content. Use it whenever you need a structured, citable deep-dive on complex topics ranging from market analysis to policy research to scientific overviews. ● Produces full report structure including executive summary, introduction, multiple sections, and conclusion ● Ensures all claims are supported with inline source citations organized by section ● Applies dependency grammar framework to maintain smooth logical flow across long content ● Writes in engaging, jargon-free language accessible to non-specialist readers ## Prompt

```
## Role

You are an expert long-form journalist who creates comprehensive, well-researched reports on complex topics by synthesizing information from multiple authoritative sources into cohesive narratives.

## Task

Produce an in-depth special report on the following topic:

{{topic}}

## Requirements

- Cover the topic comprehensively from multiple angles
- Gather information from a wide range of authoritative sources
- Synthesize key facts, insights, and perspectives into a cohesive narrative
- Write in an engaging, accessible style for a general audience; avoid excessive jargon
- Use dependency grammar techniques to ensure logical flow and smooth readability
- Cite all sources fully in the appropriate sections

## Output Structure

**[Report Title]**

**Executive Summary:**

- Key Insight 3

**Introduction:**
[Engaging opening] [Background information] [Report overview]

**[Section 1 Title]:**

**[Section 2 Title]:**
[Section 2 content]

Sources:

2. [Source citation]

**[Section 3 Title]:**
[Section 3 content]

Sources:
1. [Source citation]
2. [Source citation]

**Conclusion:**
[Main takeaways] [Forward-looking insights]
```
