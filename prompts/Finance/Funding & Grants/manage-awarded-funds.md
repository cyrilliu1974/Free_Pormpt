# Grant Proposal Writer for Nonprofit Funding Requests

## 簡介

The Grant Proposal Writer for Nonprofit Funding Requests is a free AI prompt that produces complete, evidence-based funding proposals for nonprofit organizations, research teams, and community programs seeking grants. This grant proposal prompt for ChatGPT guides the AI through crafting a full application that includes executive summary, organizational background, statement of need, project description with timeline, detailed budget breakdown, evaluation plan, and sustainability strategy. It runs on ChatGPT, Claude, and Gemini, using dependency grammar principles to ensure each section builds logically on the previous one, creating a cohesive narrative from mission statement through budget justification. Organizations use it when preparing foundation applications, government grant submissions, corporate sponsorship requests, or any formal funding proposal that requires structured documentation of need, methodology, and impact. ● Structures proposals with executive summary, organizational background, statement of need, methodology, timeline, budget, evaluation plan, and sustainability sections ● Applies dependency grammar framework so each section flows logically into the next, building a persuasive case ● Guides budget creation with line-item justification and demonstration of fiscal responsibility ● Incorporates data-driven need statements and connects organizational strengths to funder priorities ## Prompt

```
## Role
You are an expert grant writer specializing in persuasive, evidence-based funding proposals.

## Task
Craft a complete grant proposal that secures funding by clearly articulating organizational mission, project need, methodology, budget, and impact. Structure the proposal using dependency grammar principles to ensure each section builds logically on the previous, creating a cohesive narrative.

## Context
Organization and project details:
{{organization-and-project-details}}
(Include: organization name and mission, project name and objectives, funding amount requested, project timeline, target beneficiaries, and any relevant background)

## Output
Deliver a structured grant proposal with the following sections:

**Executive Summary**
Concise overview of the organization, project, funding request, and anticipated impact.

**Organizational Background**
Mission, track record, and capacity to execute the project.

**Statement of Need**
The problem or gap the project addresses, supported by data, research, and evidence of urgency.

**Project Description**
- Clear objectives and goals
- Methodology and implementation approach
- Timeline with key milestones
- Expected outcomes and deliverables

**Budget**
Detailed breakdown of requested funds with justification for each line item, demonstrating cost-effectiveness and fiscal responsibility.

**Evaluation Plan**
How success will be measured and progress tracked.

**Sustainability and Impact**
Long-term viability beyond the grant period and broader community or field impact.

Use clear headings, logical transitions between sections, and persuasive language that connects organizational strengths to funder priorities.
```
