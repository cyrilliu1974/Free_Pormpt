# Collaborative Learning Strategy Builder for Educators

## 簡介

The Collaborative Learning Strategy Builder for Educators is a free AI prompt that designs structured teamwork and peer-to-peer learning plans aligned to your subject, audience, environment, time frame, and resources. This collaborative learning prompt for ChatGPT produces a markdown table that maps learning objectives to interactive group activities and assessment methods - ensuring vertical alignment so every objective is supported by corresponding activities and evaluations. You provide the subject, target audience (grade level, course, or cohort), learning environment (classroom, online, hybrid), time frame, and available resources; the prompt returns a strategy table where each row represents one cohesive objective-activity-assessment triad. It runs on ChatGPT, Claude, Gemini, and Grok, and is purpose-built for educators, instructional designers, and curriculum coordinators who need to balance individual accountability with group dynamics. Reach for this prompt when designing lesson plans, professional-development workshops, or any learning experience that depends on peer interaction, knowledge exchange, and differentiated support for diverse learning styles. ● Identifies clear learning objectives tailored to your subject and audience, ensuring focus and measurability. ● Designs collaborative activities - think-pair-share, jigsaw, peer review, group problem-solving - that foster interaction and knowledge exchange. ● Develops dual-level assessment methods that evaluate both individual mastery and group performance, accommodating formative checks, rubrics, and reflection prompts. ● Ensures vertical alignment so every objective is directly supported by matched activities and assessments, preventing curricular drift. ## Prompt

```
## Role
You are an educational strategist specializing in collaborative learning design.

## Task
Create a comprehensive collaborative learning strategy that fosters teamwork and peer-to-peer knowledge sharing. The strategy must:

- Identify clear learning objectives aligned with the subject and audience
- Design collaborative activities that promote interaction and knowledge exchange
- Develop assessment methods that evaluate both individual and group performance
- Accommodate diverse learning styles through varied collaborative techniques
- Include opportunities for reflection and feedback
- Ensure vertical alignment: each objective pairs with activities and assessments that support it

## Context
**Subject**: {{subject}}

**Target audience**: {{target-audience}}

**Learning environment**: {{learning-environment}}

**Time frame**: {{time-frame}}

**Available resources**: {{available-resources}}

## Output
Deliver your strategy as a markdown table with three columns:

| Learning Objectives | Collaborative Activities | Assessment Methods |
|---------------------|-------------------------|--------------------|

Each row must represent one cohesive strategy where the objective, activities, and assessments are aligned and mutually reinforcing.
```
