# E-Learning Content Package Builder

## 簡介

The E-Learning Content Package Builder is a free AI prompt that creates complete digital learning materials for educational institutions and instructional designers. This e-learning content prompt for ChatGPT guides you through developing structured course descriptions, interactive lesson plans, and supplementary resources tailored to your institution's subject area, target audience, and learning outcomes. It works by analyzing learner needs, aligning content strategy with educational goals, and applying dependency grammar principles to ensure logical flow and coherence across all materials. The prompt runs on ChatGPT, Claude, Gemini, and Grok, making it accessible across major text-generation models. Use it when building new course libraries, refreshing existing digital content, or standardizing instructional materials across departments. ● Produces course descriptions with clear objectives, outcomes, and logical progression based on dependency grammar frameworks ● Designs interactive lesson plans specifying multimedia elements, active learning activities, and student engagement strategies ● Generates supplementary materials that reinforce concepts and accommodate diverse learning styles and accessibility requirements ● Includes built-in assessment tools and guidance for measuring student progress and incorporating feedback for continuous improvement ## Prompt

```
## Role
You are an expert e-learning content developer creating engaging, interactive digital library materials for educational institutions.

## Task
Develop a comprehensive content package that includes course descriptions, lesson plans, and supplementary materials. Structure all content using dependency grammar principles to ensure logical flow and coherence.

## Context
**Educational institution:** {{institution-name}}
**Target audience:** {{target-audience}}
**Subject area:** {{subject-area}}
**Desired learning outcomes:** {{learning-outcomes}}
**Available resources:** {{available-resources}}

Approach the content development systematically:
1. Analyze the target audience's needs and learning preferences
2. Align content strategy with institutional goals
3. Design for active learning, engagement, and diverse learning styles
4. Incorporate multimedia elements and interactive components
5. Build in assessment tools that measure progress and understanding
6. Ensure accessibility and inclusivity throughout
7. Include guidance for regular updates based on user feedback

## Output
Provide a structured package with clear headings:

**Course Descriptions**
- Clearly outline objectives, outcomes, and course structure
- Use dependency grammar to ensure logical progression

**Lesson Plans**
- Design interactive activities that promote active learning
- Specify multimedia elements and engagement strategies

**Supplementary Materials**
- Develop resources that reinforce key concepts
- Support diverse learning styles and accessibility needs

Use bullet points or numbered lists for individual elements within each section.
```
