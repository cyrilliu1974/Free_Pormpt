# Marketing Automation Implementation Plan Builder

## 簡介

The Marketing Automation Implementation Plan Builder is a free AI prompt that creates detailed, dependency-ordered roadmaps for deploying marketing automation systems across lead generation, nurturing, and conversion workflows. This marketing automation prompt for ChatGPT builds a structured implementation plan that covers tool selection, user flow mapping, content strategy, technical integrations, and measurable milestones. Each step in the plan includes objectives, specific actions ordered by dependency, concrete deliverables, prerequisite requirements, and validation criteria. The prompt works on ChatGPT, Claude, Gemini, and Grok, producing plans that account for budget constraints, team capabilities, and business context while prioritizing quick wins in early phases. Marketing teams use it to move from strategy to execution with clear technical dependencies and accountability checkpoints built into every phase. This prompt is ideal for marketing leaders, automation specialists, and growth teams launching or overhauling their marketing automation infrastructure without a predefined playbook. ● Produces phased plans with dependency chains that prevent implementation bottlenecks ● Addresses tool selection, user journey mapping, content strategy, and integration requirements in a single workflow ● Includes validation criteria and success metrics for each phase so teams know when to advance ● Adapts recommendations to stated budget, team size, and technical expertise levels ## Prompt

```
## Role

You are an expert marketing automation strategist specializing in lead generation, nurturing, and conversion systems.

## Task

Create a detailed, step-by-step implementation plan for a marketing automation system tailored to the business context provided. Structure the plan so each step logically builds upon the previous one, forming a clear dependency chain from foundation to execution.

## Context

Business context:
{{business-context}}

Target audience:
{{target-audience}}

The plan must address:
- Tool selection appropriate to budget and team capabilities
- User flow mapping across the customer journey
- Content strategy for each automation touchpoint
- Integration points and technical dependencies
- Measurable milestones and success metrics

## Output

Deliver a comprehensive implementation plan formatted as a numbered list with main steps and sub-steps. For each major step, include:

1. **Objective** - what this phase accomplishes
2. **Actions** - specific tasks in dependency order
3. **Deliverables** - concrete outputs
4. **Dependencies** - what must be completed first
5. **Success criteria** - how to validate completion

Ensure the plan maximizes automation efficiency while remaining practical given the stated budget, team size, and expertise constraints. Prioritize quick wins in early phases to build momentum.
```
