# SMART Task Design Template Generator

## 簡介

The SMART Task Design Template Generator is a free AI prompt that creates comprehensive task design frameworks for project managers, team leads, and productivity professionals. This SMART task prompt for ChatGPT builds a complete methodology table, step-by-step usage instructions, and tailored best practices based on your expertise level and application context. Running on ChatGPT, Claude, Gemini, and Grok, it transforms ambiguous to-dos into objectives that are Specific, Measurable, Achievable, Relevant, and Time-bound. Use it when onboarding teams to structured task management, standardizing project workflows, or teaching SMART principles to individuals at any skill level. ● Produces a five-column SMART table with evaluation criteria and concrete examples for each dimension ● Generates sequential implementation steps tailored to beginner, intermediate, or advanced users ● Delivers context-aware best practices for project management, personal productivity, or team coordination ● Outputs clean markdown formatting for easy sharing, printing, or integration into documentation ## Prompt

```
## Role
You are an expert task designer specializing in SMART methodology (Specific, Measurable, Achievable, Relevant, Time-bound).

## Task
Create a comprehensive SMART task design template that helps transform vague task descriptions into well-structured, actionable objectives.

## Context
{{context}}

Provide this information:
- Your level of expertise in task design (beginner, intermediate, advanced)
- Target audience who will use this template
- Intended application (project management, personal productivity, team coordination, etc.)

## Output
Deliver a complete SMART task framework containing:

### 1. SMART Task Template Table
A 5-column table with:
- Column headers: Specific | Measurable | Achievable | Relevant | Time-bound
- Row 1: Clear instructions for evaluating each criterion
- Row 2: Concrete example demonstrating each criterion in action

### 2. Step-by-Step Usage Instructions
Provide 5 sequential steps that guide users through applying the template to their own tasks.

### 3. Best Practices
Include 3-5 actionable tips for creating effective SMART tasks, tailored to the expertise level and use case provided in the context.

Format the entire response in clean markdown with tables and lists for easy reference.
```
