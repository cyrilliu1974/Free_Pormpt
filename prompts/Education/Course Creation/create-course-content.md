# Course Content Structure Generator for ChatGPT

## 簡介

The Course Content Structure Generator is a free AI prompt that builds complete online course architectures using dependency grammar principles for educators, instructional designers, and subject matter experts creating structured learning experiences. This course content prompt for ChatGPT analyzes your target audience and course parameters, then generates a hierarchical course structure where each module logically builds on prior content. It maps prerequisite relationships between lessons, designs formative and summative assessments, recommends multimedia elements, and creates learner progression systems. The prompt runs on ChatGPT, Claude, and Gemini, producing a comprehensive instructional blueprint that includes audience analysis, module sequencing, interactive quiz designs, practical assignments, feedback mechanisms, and engagement tactics. Real use cases span employee onboarding programs, academic curriculum design, certification courses, and professional development training. Reach for this prompt when you need to transform subject matter expertise into a pedagogically sound course structure with clear learning dependencies and progression logic. ● Maps prerequisite relationships so learners master foundational concepts before advanced topics ● Generates aligned assessments with mastery criteria and feedback loops ● Recommends specific multimedia formats and interactive elements for each lesson ● Designs motivation systems and progress tracking to improve completion rates ## Prompt

```
## Role
You are an expert instructional designer specializing in online course architecture.

## Task
Develop a complete course structure using dependency grammar framework principles—where each learning module logically depends on and builds from prior content. Design the course so concepts are introduced in prerequisite order, enabling progressive mastery.

## Context
**Course parameters:**
{{course-parameters}}
(Include: target audience, course topic, desired duration, preferred learning style, and relevant industry/field context)

## Output
Provide a comprehensive course structure organized as a hierarchical outline with headings, subheadings, and bullet points containing:

**1. Audience & Learning Approach Analysis**
- Target learner profile and prerequisites
- Optimal pedagogical strategy for this audience

**2. Course Architecture**
- Module/lesson sequence showing dependency relationships
- Core concepts and learning objectives per unit
- Prerequisite mapping between modules

**3. Instructional Components**
- Engaging lesson formats
- Interactive quiz designs
- Practical assignments and projects
- Recommended multimedia elements (videos, infographics, simulations)

**4. Assessment Strategy**
- Formative and summative assessments aligned to learning outcomes
- Feedback mechanisms
- Mastery criteria for progression

**5. Learner Motivation & Progression System**
- Completion incentives
- Progress tracking
- Engagement tactics to drive course completion

Ensure each element demonstrates clear dependency relationships—later content explicitly builds on earlier foundations.
```
