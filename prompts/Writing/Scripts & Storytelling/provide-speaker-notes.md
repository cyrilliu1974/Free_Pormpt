# Speaker Notes Generator for Presentations

## 簡介

The Speaker Notes Generator for Presentations is a free AI prompt that creates comprehensive, hierarchical speaker notes for any speech topic, duration, and audience. This speaker notes prompt for ChatGPT produces a structured outline using dependency grammar principles, where each main point logically builds on the previous one to form a cohesive narrative arc. The prompt generates 3–5 main points with nested subpoints, supporting details, examples, rhetorical devices, smooth transitions, and audience engagement cues such as questions, pauses, and call-backs. Speakers receive an indented, hierarchical outline format designed for at-a-glance reference during live delivery. It runs on ChatGPT, Claude, Gemini, and Grok, making it accessible across all major text-generation models. Reach for this prompt when preparing conference talks, keynote addresses, training sessions, sales pitches, or any presentation where clarity, logical flow, and audience connection matter. ● Creates 3–5 logically connected main points that advance a core message ● Embeds rhetorical devices, transitions, and audience engagement cues throughout the outline ● Uses dependency grammar so later points reference and build on earlier content for narrative coherence ● Outputs a hierarchical, indented format optimized for quick reference during live speaking ## Prompt

```
## Role
You are an expert speech writer creating structured, delivery-ready speaker notes.

## Task
Develop comprehensive speaker notes for {{speech-topic}} that guide the speaker through a {{duration}} presentation. Structure the content using dependency grammar principles so each point logically builds on the previous one, creating a cohesive narrative arc.

## Context
**Audience:** {{target-audience}}
**Tone:** {{desired-tone}}
**Core message:** {{key-message}}

## Requirements
- Outline 3–5 main points that advance the key message
- Provide supporting details, examples, and evidence under each main point
- Integrate rhetorical devices (repetition, contrast, metaphor) and smooth transitions between sections
- Include audience engagement cues (questions, pauses, call-backs)
- Ensure logical dependencies: later points reference and build upon earlier ones

## Output
Deliver the speaker notes in a hierarchical, indented outline format:

**I. Main Point**
   A. Subpoint
      - Supporting detail / example
      - Transition or engagement note
   B. Subpoint
      ...

**II. Main Point**
   ...

Label each section clearly for at-a-glance reference during delivery.
```
