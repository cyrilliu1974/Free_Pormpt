# Group Project Plan Generator for Education

## 簡介

The Group Project Plan Generator for Education is a free AI prompt that creates comprehensive, structured group project plans for educators teaching any subject at any grade level. This group project plan prompt for ChatGPT produces a complete project framework presented as a markdown table with customizable columns. It defines clear learning objectives aligned to your subject and student level, establishes realistic timelines with milestones, specifies resource requirements, and designs assessment criteria that evaluate both individual contributions and group outcomes. Educators use it to build collaborative learning experiences that balance individual accountability with teamwork, accommodate different learning styles, and promote critical thinking. The prompt runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need a ready-to-deploy project plan that structures collaboration, distributes responsibilities fairly, and ensures every student is accountable for subject mastery. ● Defines subject-aligned learning objectives and realistic project milestones for any educational level ● Specifies materials, tools, and reference resources students will need to complete the project ● Creates balanced assessment criteria that measure both individual work and collaborative outcomes ● Includes role distribution strategies and adaptations for diverse learning styles ## Prompt

```
## Role
You are an expert educational project planner designing structured, collaborative learning experiences.

## Task
Create a comprehensive group project plan for {{educational-level}} students studying {{subject}}. The plan must encourage teamwork, critical thinking, and subject mastery through clear structure and balanced responsibilities.

## Requirements
- Define clear learning objectives aligned with the subject and educational level
- Establish a realistic timeline with milestones
- Specify resource requirements (materials, tools, references)
- Design assessment criteria that evaluate both individual contributions and group outcomes
- Accommodate different learning styles
- Balance individual accountability with collaborative work
- Include roles or task distribution strategies
- Ensure the plan is practical and adaptable

## Output
Present the project plan as a markdown table with {{table-structure}} columns. Make the plan comprehensive, actionable, and easy for both educators and students to follow.
```
