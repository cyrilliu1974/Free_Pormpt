# Expert Position Paper Generator

## 簡介

The Expert Position Paper Generator is a free AI prompt that produces structured, evidence-based position papers on complex issues for academics, researchers, policy analysts, and professionals. This position paper prompt for ChatGPT guides the AI through crafting a complete academic document that presents a clear thesis, analyzes multiple perspectives, addresses counterarguments with rebuttals, and examines both short-term and long-term implications. It runs on ChatGPT, Claude, and Gemini, generating papers that follow APA citation standards and include sections for introduction, background, position argument with supporting points, counterargument analysis, implications, and conclusions. Use it when you need a persuasive, well-researched position on policy questions, academic debates, or organizational decisions. ● Structures arguments with clear claims, evidence, and analysis across multiple supporting points ● Addresses opposing viewpoints fairly and provides convincing, evidence-based rebuttals ● Analyzes stakeholder impacts, implementation challenges, and both short-term and long-term implications ● Formats all citations in APA style with parenthetical references throughout the document ## Prompt

```
## Role
You are an expert position paper author specializing in evidence-based argumentation on complex issues.

## Task
Develop a comprehensive, well-researched position paper on {{issue-or-field}} that presents a clear thesis, analyzes multiple perspectives, and provides credible supporting evidence.

## Requirements
- Craft a persuasive argument supported by credible evidence and rigorous analysis
- Address counterarguments fairly and provide convincing rebuttals
- Analyze both short-term and long-term implications, including stakeholder impacts and potential challenges
- Cite all sources in APA format
- Maintain academic rigor while ensuring accessibility to the intended audience

## Output
Structure the position paper with the following sections:

**Introduction**
- Topic Overview
- Thesis Statement

**Background**
- Key Concepts
- Historical Context
- Current Landscape

**Position Argument**
- Supporting Point 1: Claim, Evidence, Analysis
- Supporting Point 2: Claim, Evidence, Analysis
- Supporting Point 3: Claim, Evidence, Analysis
- Counterargument: Opposing View, Rebuttal

**Implications**
- Short-term
- Long-term
- Stakeholder Impacts
- Potential Challenges

**Conclusion**
- Summary
- Final Thoughts
- Call to Action

**References**
- APA Style Citations

Use clear paragraphs for exposition and bullet points for discrete claims, evidence items, impacts, and challenges. Cite sources parenthetically throughout.
```
