# Blog Template Generator With Typography Principles

## 簡介

The Blog Template Generator With Typography Principles is a free AI prompt that creates complete HTML blog templates with embedded CSS for web developers and content creators who need readable, accessible designs. This blog template prompt for ChatGPT produces a full semantic HTML5 structure with typography that follows Robert Bringhurst's readability guidelines: 45–75 character line lengths, 1.4–1.6 line spacing, clear hierarchies, and generous margins. You provide the blog topic, layout type, and design parameters (audience, brand colors, content style), and the prompt returns ready-to-deploy code with featured image placement, heading structures, metadata areas, related posts sections, and comment placeholders. It runs on ChatGPT, Claude, Gemini, and Grok, producing both the template code and detailed implementation notes covering font stacks, sizing, spacing systems, and color application. Reach for this prompt when you need to quickly scaffold a blog that balances visual appeal with reading comfort, or when launching a new content site that must meet accessibility standards from day one. ● Outputs semantic HTML5 article markup with meta information, navigation, and responsive design considerations. ● Applies Bringhurst's typographic guidelines for optimal line length, spacing, hierarchy, and margin systems. ● Includes featured image zones, heading structures (H1–H6), author and date metadata, related posts, and comment areas. ● Provides embedded CSS with specific font recommendations, color scheme mappings, and spacing measurements in the implementation notes. ## Prompt

```
## Role
You are an expert web developer and typography specialist who applies Robert Bringhurst's typographic principles to modern semantic HTML and user experience design.

## Task
Create a comprehensive, production-ready blog template structure that prioritizes readability, accessibility, and clean design aesthetics. Balance visual hierarchy, optimal reading comfort, and semantic markup to keep readers focused on content without distractions.

## Context
**Blog topic/niche:** {{blog-topic}}

**Layout type:** {{layout-type}}

**Design parameters:** {{design-parameters}}

*Describe target audience, brand colors (hex codes if available), and content style (formal/casual/technical/conversational) in a few sentences.*

## Requirements
Apply Bringhurst's readability guidelines:
- 45–75 character line lengths
- Appropriate line spacing (1.4–1.6 for body text)
- Clear typographic hierarchy
- Generous margins

Include these structural elements:
- Semantic HTML5 article structure with proper meta information
- Featured image placement
- Heading hierarchy (H1–H6) with readable typography
- Metadata display (date, author, categories)
- Related posts section
- Comment area placeholder
- Clean, distraction-free navigation
- Responsive design considerations
- Consistent spacing and margin system

## Output
Deliver a complete HTML template with embedded CSS styling, followed by detailed implementation notes in bullet-point format. Include specific typography recommendations (font families, sizes, weights), color scheme application, and spacing measurements that align with optimal readability standards.
```
