# SEO Hosting Analysis Prompt for ChatGPT

## 簡介

The SEO Hosting Analysis Prompt is a free AI prompt that produces a detailed study of how web hosting infrastructure affects search engine rankings for any website URL. This SEO hosting analysis prompt for ChatGPT guides the model to examine server location and geographic proximity, uptime and crawl reliability, page speed and time-to-first-byte, HTTPS and security configurations, and hosting type (shared, VPS, dedicated, cloud). It structures the output as a professional report with executive summary, methodology, dedicated sections for location, uptime, speed, security, and additional factors, plus prioritized recommendations. Marketing teams use it to audit client sites before migration, in-house SEO teams run it to diagnose performance bottlenecks, and hosting consultants deploy it to justify infrastructure upgrades. The prompt works equally well on ChatGPT, Claude, and Gemini. Reach for this prompt when you need to connect hosting choices to organic search performance or prepare a technical SEO audit that covers infrastructure. ● Analyzes server location, IP geolocation, and latency impacts on localized search results ● Evaluates uptime reliability, crawl accessibility, and the ranking cost of downtime ● Assesses page load speed, time-to-first-byte, CDN usage, and mobile performance ● Reviews HTTPS certificates, malware risks, DDoS protection, and security patches ● Compares hosting types and provides prioritized, actionable optimization recommendations ## Prompt

```
## Role
You are an expert web hosting and SEO strategist with deep knowledge of how hosting infrastructure impacts search engine rankings and organic performance.

## Task
Conduct a comprehensive web hosting and SEO study for {{website-url}}. Analyze how the site's hosting environment affects search visibility and provide actionable optimization recommendations.

## Output
Deliver a structured study report with the following sections:

### Executive Summary
Provide a concise overview of key findings. Highlight the most critical hosting factors impacting search performance.

### Introduction
State the study's purpose, scope, and methodology.

### Server Location Analysis
Examine how server location affects SEO:
- Geographic proximity to target audience
- Relationship to search engine data center locations
- Latency and load times
- Impact on localized search results
- IP address and country TLD considerations

### Uptime Analysis
Investigate the relationship between hosting uptime and SEO:
- Importance of website availability
- Impact of downtime on search engine crawling
- Potential harm to rankings and indexing
- Uptime monitoring tools and metrics

### Speed and Performance Analysis
Analyze how hosting speed influences SEO:
- Page load times and user experience
- Mobile-friendliness and responsiveness
- Time to first byte (TTFB)
- Caching and content delivery networks (CDNs)
- Redirects and server response times

### Security Analysis
Examine hosting security's role in SEO:
- HTTPS and SSL certificates
- Malware and hacking vulnerabilities
- Spam and user-generated content risks
- DDoS protection and mitigation
- Firewalls and security patches

### Additional Factors
Discuss other relevant hosting factors:
- Hosting type (shared, VPS, dedicated, cloud)
- Server hardware and resources
- Bandwidth and traffic allowances
- Email hosting and deliverability
- Customer support quality

### Conclusions and Recommendations
Summarize main findings and provide specific, prioritized recommendations for optimizing the hosting environment to maximize search performance.

## Format
Use clear headings, subheadings, paragraphs, and bullet points to enhance readability. Present technical information in accessible language.
```
