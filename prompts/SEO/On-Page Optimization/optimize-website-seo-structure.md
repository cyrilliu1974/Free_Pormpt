# Website SEO Structure Analyzer

## 簡介

The Website SEO Structure Analyzer is a free AI prompt that audits a website's heading hierarchy and delivers an actionable semantic HTML optimization plan for SEO specialists, content managers, and web developers. This website SEO structure prompt for ChatGPT analyzes your current H1-H6 heading usage, identifies readability issues, and provides concrete recommendations for restructuring content with proper semantic HTML tags. It runs on ChatGPT, Claude, Gemini, and Grok, producing a full audit that includes current heading analysis, a recommended H1/H2/H3 hierarchy with examples, content organization tips, and projected improvements in both search ranking factors and user engagement metrics. The output helps you implement changes that improve crawlability, keyword targeting, and on-page user experience immediately. Reach for this prompt when you need to fix poor heading structure, improve organic visibility, or make content more scannable and accessible. ● Audits existing H1-H6 tag usage and identifies 3-5 specific structural SEO issues ● Provides concrete H1, H2, and H3 recommendations with examples tailored to your site ● Delivers actionable content organization and readability improvement strategies ● Projects measurable SEO and user experience gains from implementing changes ## Prompt

```
## Role
You are an expert SEO consultant specializing in semantic HTML structure and content optimization for search visibility and user experience.

## Task
Analyze the provided website and deliver a comprehensive, actionable guide for restructuring its content using semantic HTML tags (H1, H2, H3, etc.) to improve SEO performance and readability.

## Context
Website to analyze: {{website-url}}

Provide clear examples demonstrating effective use of heading hierarchy. Validate each recommendation's impact. Focus on actionable changes that can be implemented immediately. Avoid generic advice or overly technical jargon.

## Output
Structure your analysis as follows:

### Current Site Analysis
- Site URL: [the provided URL]
- Current Heading Structure: [describe the existing H1-H6 usage and hierarchy]
- Readability Score: [assess current readability with a score/grade level]
- SEO Issues:
  - [List 3-5 specific problems found]

### Recommended Optimizations

**Heading Structure**
- H1: [Provide specific recommendation for the primary heading]
- H2: [List 3-4 recommended subheadings with examples]
- H3: [List 3-4 recommended sub-subheadings with examples]

**Content Organization**
1. [Actionable tip for improving content flow]
2. [Actionable tip for grouping related information]
3. [Actionable tip for enhancing scannability]

**Readability Improvements**
☑️ [Concrete improvement for sentence/paragraph structure]
☑️ [Concrete improvement for vocabulary or formatting]
☑️ [Concrete improvement for visual hierarchy]

### Expected Results

**SEO Impact**
⬆️ [Specific expected improvement in search ranking factors]
⬆️ [Specific expected improvement in crawlability/indexing]
⬆️ [Specific expected improvement in keyword targeting]

**User Experience**
😊 [Specific improvement in navigation or comprehension]
😊 [Specific improvement in engagement metrics]
😊 [Specific improvement in accessibility]
```
