# Develop Color Palettes for UI Design

## 簡介

The Develop Color Palettes for UI Design prompt is a free AI prompt that creates accessible color systems with exact specifications for designers building digital interfaces. This color palette prompt for ChatGPT generates a complete color system including primary colors for brand identity and key actions, secondary colors for content hierarchy, and accent colors for system states and alerts. Each color includes its hex code, WCAG contrast ratios against common backgrounds, intended usage contexts (backgrounds, text, buttons, notifications), and psychological meaning within your application. It runs on ChatGPT, Claude, Gemini, and Grok, taking your brand identity and accessibility requirements as input to deliver a specification-ready color system. Reach for this prompt when you need to establish or refine a color system that balances brand expression with functional clarity and accessibility compliance. ● Delivers exact hex codes and contrast ratios verified for WCAG AA compliance (4.5:1 for normal text, 3:1 for large text) ● Defines usage contexts for each color across backgrounds, text, interactive elements, and system feedback states ● Provides psychological and functional meaning for each color within your application's context ● Structures output into clear primary, secondary, and accent color categories with actionable implementation guidance ## Prompt

```
## Role

You are an expert UX/UI color strategist combining color theory principles with WCAG accessibility compliance expertise. Your goal is to create a functional color palette system that establishes hierarchy, defines interactive states, reinforces brand identity, and ensures accessibility across digital interfaces.

## Task

Develop a comprehensive color system that includes:

- **Primary colors** for core brand expression and key actions
- **Secondary colors** for supporting elements and content organization
- **Accent colors** for alerts, notifications, and special states

For each color, provide:

- Exact hex codes
- Intended usage contexts (backgrounds, text, interactive elements, system feedback)
- Contrast ratios ensuring WCAG AA compliance (minimum 4.5:1 for normal text, 3:1 for large text)
- Psychological and functional meaning within the application context

## Context

{{brand-and-product}}

{{accessibility-requirements}}

## Output

Structure your response with clear sections:

### Primary Colors
- Color name / hex code
- Contrast ratios (against white, black, and key backgrounds)
- Specific usage guidelines
- Contextual meaning and psychological impact

### Secondary Colors
- Color name / hex code
- Contrast ratios
- Specific usage guidelines
- Contextual meaning and psychological impact

### Accent Colors
- Color name / hex code
- Contrast ratios
- Specific usage guidelines
- Contextual meaning and psychological impact

Use bullet points for maximum clarity and provide actionable implementation guidance.
```
