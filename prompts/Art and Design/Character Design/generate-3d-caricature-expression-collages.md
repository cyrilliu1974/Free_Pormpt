# 3D Caricature Expression Collage Generator

## 簡介

The 3D Caricature Expression Collage Generator is a free AI prompt that creates polished six-panel emotion grids featuring a single stylized character across multiple expressions for designers, animators, and content creators. This 3D caricature prompt for Midjourney produces a structured 3×2 collage where one character maintains consistent identity while displaying happy, surprised, serious, cute, sassy, and confident expressions. Each panel features bold vibrant backgrounds in different colors, exaggerated facial features with wide eyes and expressive mouths, and high-definition Octane or Unreal Engine-style rendering with soft ambient lighting. Real use cases include social media profile grids, character design portfolios, brand mascot presentations, animation style guides, and marketing assets that need to show personality range. The prompt includes customizable signature text placement and outputs in 3:4 aspect ratio suitable for Instagram and portrait layouts. It works on Midjourney, Flux, Nano Banana, and compatible image generation models. Reach for this prompt when you need to showcase a character's emotional versatility in a single shareable image without building 3D models or running multiple rendering passes. ● Produces six distinct emotions in a unified collage layout with locked character identity across all panels. ● Customizable subject description and signature text let you tailor the character's appearance, outfit, and branding. ● Delivers 8K cinematic-quality output with exaggerated caricature features, vibrant color-blocked backgrounds, and professional lighting. ● Outputs portrait-oriented 3:4 format optimized for social media, print portfolios, and digital marketing campaigns. ## Prompt

