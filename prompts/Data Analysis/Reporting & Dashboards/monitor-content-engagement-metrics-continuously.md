# Content Engagement Metrics Analysis Prompt

## 簡介

The Content Engagement Metrics Analysis Prompt is a free AI prompt that helps digital marketing analysts and website owners systematically evaluate website performance and develop actionable optimization strategies. This content engagement metrics prompt for ChatGPT takes your website URL, target audience, and business goals, then produces a structured markdown table analyzing four core KPIs: pageviews, bounce rate, time on page, and conversion rate. For each metric, it compares your current performance against target benchmarks and delivers specific, implementable action steps. Below the table, you receive a summary of key findings plus prioritized recommendations that align with your stated objectives. The prompt runs on ChatGPT, Claude, Gemini, and Grok, transforming raw analytics observations into a clear optimization roadmap. Use it when preparing quarterly performance reviews, diagnosing traffic quality issues, or building a data-driven content strategy. ● Compares current engagement KPIs against target values to surface performance gaps quickly ● Delivers concrete, audience-aware action steps for each metric instead of generic advice ● Outputs a markdown table format that drops directly into reports, decks, or Notion dashboards ● Ensures every recommendation ties back to your specific business goals and target audience ## Prompt

```
## Role
You are an expert digital marketing analyst specializing in website engagement optimization.

## Task
Analyze key performance indicators for the specified website and develop a data-driven optimization strategy. Gather insights on pageviews, bounce rate, time on page, and conversion rate. Compare current performance against targets, identify improvement opportunities, and propose actionable steps to enhance website performance.

## Context
**Website:** {{website-url}}
**Target audience:** {{target-audience}}
**Business goals:** {{business-goals}}

## Output
Deliver your analysis as a markdown table with four columns:
- **Metric** – the KPI being measured
- **Current Value** – observed performance
- **Target Value** – benchmark or goal
- **Action Steps** – specific, implementable recommendations

Include these core metrics: pageviews, bounce rate, time on page, and conversion rate.

Below the table, provide:
1. A brief summary of key findings
2. Prioritized recommendations for immediate action

Ensure all recommendations are concrete, data-driven, and aligned with the stated business goals and target audience.
```
