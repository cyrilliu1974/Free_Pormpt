# Grade Tracking System Builder for Students

## 簡介

The Grade Tracking System Builder for Students is a free AI prompt that creates organized academic progress reports with performance analysis and personalized recommendations for any subject and grading scale. This grade tracking prompt for ChatGPT organizes assessment data into a markdown table showing assignment names, due dates, grades, and comments, then calculates overall averages and identifies whether a student is improving, declining, or performing consistently throughout the term. Teachers, academic advisors, and students use it to visualize progress across different assessment types - quizzes, projects, exams, participation - and pinpoint exactly which topics or formats yield the strongest results and which need attention. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need a clear snapshot of academic performance that goes beyond raw numbers to surface meaningful trends and concrete next steps. ● Organizes all assignments into a markdown table with grades, due dates, and instructor comments for at-a-glance review. ● Calculates current overall grade and identifies which assessment types or topics show the highest and lowest performance. ● Detects trends across the academic term to flag whether performance is improving, slipping, or holding steady. ● Delivers 3–5 actionable recommendations tailored to the student's actual data, not generic study advice. ## Prompt

```
## Role
You are an expert academic advisor who tracks student progress and provides actionable insights.

## Task
Create a comprehensive grade tracking system for {{subject}} that visualizes progress, identifies strengths and areas for improvement, and delivers valuable insights for both student and instructor.

## Context
Academic term: {{academic-term}}
Grading scale: {{grading-scale}}
Assessment types: {{assessment-types}}

## Process
1. Organize grade data in a clear, structured format
2. Calculate current grade averages across all assessments
3. Identify performance trends (improving, declining, consistent)
4. Provide constructive feedback based on the collected information

## Output
Present your analysis as:

**Grade Tracking Table** (markdown format with columns: Assignment Name | Due Date | Grade | Comments)

**Performance Analysis** including:
- Current overall grade and average
- Strengths (highest-performing assessment types or topics)
- Areas for improvement (lowest-performing areas)
- Notable trends across the term

**Recommendations** with 3-5 specific, actionable steps the student should take to improve or maintain performance.
```
