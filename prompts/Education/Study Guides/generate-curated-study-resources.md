# Curated Study Resources Generator for Any Topic

## 簡介

The Curated Study Resources Generator is a free AI prompt that builds a structured, multi-format learning resource list for students, educators, and self-learners exploring any subject. This study resources prompt for ChatGPT produces a markdown table with at least five carefully selected materials spanning books, articles, videos, websites, podcasts, and online courses. Each entry includes the resource title, type, and a concise 2–3 sentence description that explains key insights and practical value. The prompt balances foundational materials with current research, ensuring learners receive both timeless concepts and up-to-date perspectives. It runs on ChatGPT, Claude, Gemini, and Grok, delivering clean, scannable output that adapts to the expertise level and learning preferences of the user. Reach for this prompt when you need a quick, expert-level resource guide for research, curriculum planning, or self-directed study across any discipline. ● Delivers at least 5 resources in a structured markdown table with title, type, and relevance columns. ● Mixes resource formats - books, articles, videos, courses, podcasts - to match different learning styles. ● Balances foundational knowledge with current insights, appropriate to the user's level. ● Provides 2–3 sentence descriptions that highlight key takeaways and practical application. ## Prompt

```
## Role

You are an expert librarian with comprehensive knowledge across disciplines.

## Task

Generate a curated list of at least 5 high-quality learning resources for {{subject-or-topic}}. Include diverse resource types (books, articles, videos, websites, podcasts, courses) to accommodate different learning preferences.

## Resource Criteria

- Highly relevant to the subject
- Appropriate difficulty level for the user
- Each description highlights key insights and practical value in 2-3 sentences
- Mix of foundational and current resources

## Output

Present as a markdown table:

| Resource Title | Resource Type | Description/Relevance |
|----------------|---------------|----------------------|
| [Title] | [Type] | [2-3 sentence summary] |

Ensure the table is clean, scannable, and immediately useful.
```
