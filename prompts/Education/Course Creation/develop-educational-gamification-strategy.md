# Educational Gamification Strategy Prompt

## 簡介

The Educational Gamification Strategy Prompt is a free AI prompt that builds full engagement frameworks for educators and instructional designers teaching any subject. This gamification strategy prompt for ChatGPT produces a structured plan covering measurable learning objectives, balanced point systems (lessons, exercises, assessments, streaks), five tiered achievement levels with rewards, and a text-based flowchart mapping the learner journey from entry through milestones and decision points. It runs on ChatGPT, Claude, Gemini, and Grok, and delivers mechanics grounded in learning psychology - leaderboards, daily challenges, social features, narrative hooks, and customization options that drive retention without sacrificing educational rigor. Use it when designing courses, training programs, or classroom activities that need motivation scaffolding aligned to real skill development. ● Delivers tiered achievement levels scaled for sustainable progression, not just quick wins. ● Produces a visual flowchart showing entry points, milestones, decision paths, and checkpoints in ASCII format. ● Aligns point values and rewards with both completion behaviors and genuine skill mastery. ● Includes supplementary mechanics - social, narrative, and personalization features - that extend engagement beyond points. ## Prompt

```
## Role
You are an expert educational game designer specializing in engagement mechanics and learning psychology.

## Task
Create a comprehensive gamification strategy for {{subject}} that includes a balanced point system, tiered achievement levels with rewards, and a visual flowchart of the learning journey.

## Output
Structure your response as follows:

**Subject:** {{subject}}

**Learning Objectives:**
- List 3-5 specific, measurable learning outcomes

**Point System:**
- Define point values for key learner actions (completing lessons, practice exercises, assessments, peer interactions, streaks, bonus challenges)
- Ensure values create meaningful progression

**Achievement Levels:**
1. Through 5: Name each level and specify points required
- Scale difficulty appropriately between tiers

**Rewards:**
- Specify one reward per achievement level (badges, unlocks, privileges, content access)
- Align rewards with intrinsic and extrinsic motivation

**Learning Journey Flowchart:**
Provide a clear ASCII or text-based diagram showing:
- Entry point and key milestones
- Decision points and progress paths
- Achievement checkpoints
- Use arrows (→ ↓) and boxes to show flow

**Additional Gamification Elements:**
- List 3-5 supplementary mechanics (leaderboards, daily challenges, social features, narrative elements, customization options)

## Criteria
- Keep the system intuitive and easy to understand
- Balance challenge with attainability to sustain motivation
- Align all mechanics with the learning objectives
- Design for retention and genuine skill development, not just completion
```
