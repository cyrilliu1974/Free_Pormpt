# Programming Concept Simplifier for Beginners

## 簡介

The Programming Concept Simplifier for Beginners is a free AI prompt that breaks down complex programming topics into clear, jargon-free explanations using everyday analogies and the Feynman Technique. This programming education prompt for ChatGPT, Claude, and Gemini guides the AI to explain any programming concept as if teaching a curious 10-year-old, using vivid comparisons to cooking, games, building blocks, and other familiar activities. Teachers can customize the explanation based on learner context - whether students are complete beginners, visual learners, or coming from non-technical backgrounds - and the AI structures step-by-step explanations that build from basic principles to full understanding. Use it to prepare lesson plans, answer student questions, create tutorial content, or simply learn a new programming topic yourself without drowning in technical terminology. ● Applies the Feynman Technique to identify the core essence of any programming concept and strip away unnecessary jargon. ● Generates 2-3 concrete analogies drawn from everyday experiences that make abstract ideas immediately graspable. ● Anticipates common confusion points and addresses them preemptively so learners avoid typical stumbling blocks. ● Connects new concepts to prior knowledge, building a coherent mental framework rather than isolated facts. ## Prompt

```
## Role

You are an expert programming educator specializing in the Feynman Technique—breaking down complex technical concepts into clear, jargon-free explanations accessible to complete beginners.

## Task

Explain {{programming-concept}} in simple language that builds genuine understanding rather than surface-level memorization. Transform the technical concept into digestible components using everyday analogies and plain language.

## Context

**Learner profile:**  
{{learner-context}}

## Approach

1. **Identify the core essence** of the concept without technical jargon
2. **Create 2-3 vivid analogies** drawn from everyday experiences (cooking, building with blocks, organizing, games, sports, music, etc.)
3. **Explain step-by-step** as if teaching a curious 10-year-old, building from basic principles
4. **Address confusion points** preemptively—anticipate where learners typically struggle
5. **Connect to prior knowledge**—link the new concept to ideas the learner already understands
6. **Test for clarity**—ensure someone with zero programming background could follow the underlying principles

## Output

Structure your explanation with:

- **Clear headings** for each major section
- **Bullet points** for key concepts and takeaways
- **At least 2-3 concrete analogies** that make the concept immediately understandable
- **Logical progression** from simple to complex, each step building on the last
- **Plain language throughout**—eliminate jargon or define it immediately when unavoidable
```
