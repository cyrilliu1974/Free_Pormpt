# Week-by-Week Curriculum Plan Builder for Teachers

## 簡介

The Week-by-Week Curriculum Plan Builder is a free AI prompt that creates structured 8-week learning plans for any subject and grade level, formatted as a ready-to-use markdown table. This curriculum planning prompt for ChatGPT produces a complete week-by-week roadmap with sequenced topics that build on prior knowledge, specific measurable learning objectives aligned to grade-level standards, and curated resources including textbooks, activities, multimedia, and assessments. Teachers and instructional coordinators use it to map out quarter-long units, align lesson sequences with state standards, and ensure every week of instruction has clear goals and supporting materials. The prompt runs on ChatGPT, Claude, Gemini, and Grok, delivering a markdown table you can drop directly into lesson-planning documents or learning management systems. Reach for this prompt when you need to design a coherent instructional unit quickly, ensure logical topic progression, or provide substitute teachers and co-teachers with a clear weekly roadmap. ● Produces a markdown table covering 8 weeks, each row specifying topic, learning objectives, and resources ● Ensures topics are sequenced logically so each week builds on prior knowledge ● Generates measurable, grade-appropriate learning objectives aligned to standards ● Selects age-appropriate resources - textbooks, activities, multimedia, assessments - that directly support each week's goals ## Prompt

```
## Role
You are a curriculum designer creating a structured learning plan.

## Task
Develop a comprehensive week-by-week curriculum plan for {{subject}} at {{grade-level}}. Organize the plan as a table covering 8 weeks, with each week specifying the topic, learning objectives, and resources.

## Requirements
- **Learning objectives**: Make them specific, measurable, and aligned with standards for the grade level. Focus on what students will know and be able to do.
- **Topics**: Sequence them logically so each week builds on prior knowledge and skills.
- **Resources**: Select materials that are age-appropriate, engaging, and directly support the learning objectives (textbooks, activities, multimedia, assessments).
- **Scope**: Cover all essential aspects of the subject while keeping the plan realistic for the timeframe.

## Output
Format as a markdown table:

**Subject:** {{subject}}  
**Grade Level:** {{grade-level}}

| Week | Topic | Learning Objectives | Resources |
|------|-------|---------------------|-----------|  
| 1    |       |                     |           |
| 2    |       |                     |           |
| 3    |       |                     |           |
| 4    |       |                     |           |
| 5    |       |                     |           |
| 6    |       |                     |           |
| 7    |       |                     |           |
| 8    |       |                     |           |

Use bullet points or concise descriptions within cells to keep the table readable.
```
