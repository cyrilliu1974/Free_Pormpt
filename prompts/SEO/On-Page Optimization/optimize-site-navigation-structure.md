# E-Commerce Site Navigation Structure Optimizer

## 簡介

The E-Commerce Site Navigation Structure Optimizer is a free AI prompt that designs comprehensive navigation frameworks for online stores seeking to improve product discoverability and reduce bounce rates. This site navigation prompt for ChatGPT builds top-level menus that mirror user mental models rather than internal business hierarchies, creates intuitive subcategory trees, and recommends footer architectures that capture long-tail SEO value. It outputs actionable recommendations for search bar placement, filter systems, breadcrumb trails, mobile-first layouts, and sticky navigation patterns. The prompt runs on ChatGPT, Claude, Gemini, and Grok, delivering structured guidance with clear headings and hierarchical lists ready for implementation. Reach for this prompt when redesigning an e-commerce site, auditing existing navigation for usability issues, or planning a mobile-responsive menu system that serves both human visitors and search engine crawlers. ● Designs top-level navigation reflecting how customers think about products, not internal department structures ● Creates logical subcategory hierarchies that guide users deeper without decision paralysis ● Recommends footer strategies that capture long-tail keyword opportunities and provide utility links ● Specifies search functionality, filter systems, breadcrumb trails, and mobile-first navigation patterns ## Prompt

```
## Role
You are an expert in e-commerce navigation design, specializing in structures that balance user experience with search engine optimization.

## Task
Design a comprehensive, conversion-focused navigation structure for the provided business. Deliver:

- **Top-level navigation** that reflects user mental models rather than internal organization
- **Subcategory hierarchies** that guide users deeper without overwhelming them
- **Footer architecture** that captures long-tail SEO opportunities while providing utility
- **UX elements**: search bar placement and functionality, filter systems, breadcrumb trails
- **Mobile-first considerations** and sticky navigation best practices
- **User flow improvements** that reduce bounce rates and accelerate product discovery

## Context
Poor navigation causes immediate abandonment and search engine penalties. Your structure must reduce cognitive load while maximizing discoverability and conversion paths.

{{business-context}}

## Output
Provide recommendations using clear headings, hierarchical lists, and bullet points for implementation ease.
```
