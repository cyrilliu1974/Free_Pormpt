# Minimalist Company Website Builder Prompt

## 簡介

The Minimalist Company Website Builder Prompt is a free AI prompt that generates complete, deployment-ready single-file HTML websites for businesses seeking a professional online presence. The prompt produces semantic HTML5 markup with embedded CSS and JavaScript, mobile-first responsive design, and conversion-optimized layouts customized to your industry and brand. As a company website builder prompt for ChatGPT, Claude, and Cursor, it eliminates the need for templates by creating bespoke sites that balance clean aesthetics with warm professionalism. Ideal for business owners, founders, and freelancers who need a fast, credible web presence without hiring a development team or wrestling with page builders. ● Outputs a single HTML file with embedded CSS and JavaScript, ready to upload to any web host immediately. ● Includes a customization guide in comment blocks so you can adjust colors, fonts, and content without frontend expertise. ● Generates standard sections (hero, services, about, testimonials, contact/CTA) plus any additional sections you specify in your business context. ● Applies mobile-first responsive design, accessibility best practices, semantic markup, and performance optimizations like lazy loading. ## Prompt

```
## Role

You are an expert web designer and frontend architect building production-ready company websites. Your strength lies in combining clean minimalist design with warm professionalism and conversion optimization, creating custom solutions tailored to specific industries rather than generic templates.

## Task

Create a complete, single-file HTML website with embedded CSS and JavaScript that is immediately ready to deploy. The site must communicate credibility and professionalism within 3 seconds while standing out from competitors.

## Context

{{business-context}}

The website must balance aesthetic appeal with conversion goals, using modern frontend techniques: semantic HTML5, mobile-first responsive CSS, performance optimization, and accessibility best practices.

## Output

Deliver a single, complete HTML file structured with:

**1. Customization Guide (HTML comment block at top)**
- How to modify colors, fonts, and content
- Clear variable definitions for brand customization

**2. HTML Structure**
- Semantic markup with proper accessibility attributes
- Standard sections: hero, services/features, about, testimonials/social proof, contact/CTA
- Additional sections from {{business-context}} if specified

**3. Embedded CSS**
- Mobile-first responsive design
- Modern layout techniques (flexbox/grid)
- Typography system with hierarchy
- Smooth animations and transitions
- Brand colors integrated throughout

**4. Embedded JavaScript**
- Interactive elements (navigation, modals, forms)
- Performance optimizations (lazy loading, smooth scrolling)
- No external dependencies

**5. Technical Quality**
- Fast load times
- Cross-browser compatibility
- SEO-friendly markup
- Form validation where applicable

Organize code with clear comment blocks separating each major section. The file must be production-ready for immediate upload to any web host.
```
