# Online Course Design Prompt for E-Learning Programs

## 簡介

The Online Course Design Prompt for E-Learning Programs is a free AI prompt that builds structured, multi-module online courses for educators, instructional designers, and subject-matter experts. This e-learning course creation prompt for ChatGPT helps you transform any subject into a complete teaching program with clearly defined modules, lesson plans, interactive exercises, and assessment frameworks. You provide the subject, target audience, course duration, and desired learning outcomes, and the prompt generates a full course architecture that accommodates multiple learning styles and includes multimedia integration points. It works on ChatGPT, Claude, Gemini, and Grok, delivering lesson content organized by module, real-world application assignments, peer collaboration activities, and knowledge-check quizzes. Reach for this prompt when you need to design a cohesive online course from scratch or restructure existing material into a learner-friendly format. ● Produces a complete course outline with module progression and topic breakdown by lesson ● Generates lesson content designed for multiple learning styles with clear multimedia integration points ● Creates interactive assignments including real-world applications and peer collaboration activities ● Delivers an assessment strategy with knowledge checks, quizzes, and success metrics ## Prompt

```
## Role
You are an expert online course creator specializing in structured, engaging e-learning programs.

## Task
Design a comprehensive online course that includes a compelling outline, engaging lesson content, and interactive assignments. The course must be well-organized, accessible, and aligned with stated learning objectives.

## Context
Subject: {{subject}}
Target audience: {{target-audience}}
Course duration: {{course-duration}}
Desired learning outcomes: {{learning-outcomes}}

## Requirements
- Structure content to accommodate multiple learning styles
- Incorporate multimedia elements (videos, infographics, quizzes)
- Include peer interaction opportunities
- Design real-world application exercises that reinforce key concepts
- Ensure all materials are accessible and easy to navigate

## Output
Deliver a complete course framework organized under these headings:

**Course Outline**
- Module structure with clear progression
- Topic breakdown by lesson

**Lesson Content**
- Core teaching material for each lesson
- Multimedia integration points

**Assignments**
- Interactive exercises
- Real-world applications
- Peer collaboration activities

**Assessment Strategy**
- Knowledge checks and quizzes
- Success metrics

Use bullet points for individual elements within each section.
```
