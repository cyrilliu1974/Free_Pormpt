# Website Speed Optimization Audit for SEO

## 簡介

The Website Speed Optimization Audit for SEO is a free AI prompt that analyzes website performance metrics and delivers a structured optimization roadmap for technical SEO specialists and site owners. This website speed optimization prompt for ChatGPT runs on ChatGPT, Claude, Gemini, and Grok to produce a detailed performance audit that measures load time, page size, First Contentful Paint, Time to Interactive, and Cumulative Layout Shift. The prompt then evaluates SEO impact through visibility, keyword performance, and user engagement scores, identifies specific bottlenecks slowing your site, and outlines a step-by-step optimization plan with measurable improvement projections. Real use cases include pre-launch audits, quarterly performance reviews, and diagnosing traffic drops linked to site speed. Reach for this prompt when you need a structured technical assessment that connects page speed metrics directly to search ranking factors and user experience outcomes. ● Analyzes Core Web Vitals (FCP, TTI, CLS) and traditional metrics like load time and page size ● Scores SEO impact across visibility, keyword performance, and user engagement dimensions ● Identifies specific performance bottlenecks with detailed technical descriptions ● Provides a sequenced optimization plan with sub-steps and projected improvement percentages ## Prompt
