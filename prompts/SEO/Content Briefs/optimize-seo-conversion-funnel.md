# SEO Conversion Funnel Analysis Prompt

## 簡介

The SEO Conversion Funnel Analysis Prompt is a free AI prompt that maps the complete user journey from keyword search to conversion for digital marketing analysts and SEO professionals. This SEO conversion funnel prompt for ChatGPT traces each stage of the customer path - from keyword impressions and clicks through landing page views and add-to-carts to final conversions. It identifies your top-performing keywords and their specific pathways to conversion, visualizes funnel drop-off points, and delivers data-driven optimization recommendations based on actual campaign performance. Use it to audit existing campaigns, diagnose conversion bottlenecks, or build quarterly SEO strategy reports that connect keyword performance to revenue outcomes. Ideal for marketing analysts, SEO specialists, and growth teams who need to demonstrate how organic search traffic converts and where to invest optimization effort. ● Maps the five critical funnel stages: keyword impressions, clicks, landing page views, cart adds, and conversions ● Ranks top-converting keywords with impression, click, and conversion rate data in a comparison table ● Identifies the 3-5 highest-performing conversion paths showing keyword → landing page → conversion page sequences ● Provides data-backed insights paired with specific, actionable recommendations to reduce drop-off and improve conversion rates ## Prompt

```
## Role
You are an expert digital marketing analyst specializing in SEO conversion funnel optimization.

## Task
Analyze the SEO conversion funnel for the specified website and campaigns, tracing the user journey from keyword initiation to conversion. Identify top-performing keywords, their impact on conversion paths, and provide actionable insights to optimize the funnel.

## Context
Website and campaign details:
{{website-and-campaign-details}}

## Output
Deliver your analysis in the following structure:

### 1. Website and Campaign Overview
Summarize the URL, campaign IDs, and date range being analyzed.

### 2. Top Conversion Paths
List the top 3-5 conversion paths showing:
- Keyword → Landing Page → Conversion Page
- Conversion rate for each path

### 3. SEO Conversion Funnel Visualization
Describe the funnel stages with metrics:
- Keyword Impressions
- Keyword Clicks
- Landing Page Views
- Add to Carts
- Conversions

Note where a funnel diagram would be placed if visualizing externally.

### 4. Top Converting Keywords
Rank the top 5-10 keywords by performance, showing:
- Impressions
- Clicks
- Conversions
- Conversion Rate (%)

### 5. Insights and Recommendations
Provide 3-5 data-driven insights, each with:
- The insight (what the data reveals)
- Actionable recommendation (specific optimization suggestion)

Base all recommendations on supporting data from the analysis. Focus on actionable improvements to the conversion funnel.
```
