# Google Ad Copy Generator for High CTR Campaigns

## 簡介

The Google Ad Copy Generator for High CTR Campaigns is a free AI prompt that creates character-optimized ad text tailored to your product, audience, and keywords. This Google ad copy prompt for ChatGPT produces 10 complete ad variations, each with a headline under 30 characters and two description lines under 90 characters. It works by analyzing your product's value proposition, mapping audience pain points to key features, and embedding your main keyword naturally into attention-grabbing headlines. Each variation includes action-driven calls-to-action like "Get Started Today" or "Learn More" to maximize click-through rates. Digital marketers use it to launch A/B tests quickly, ensuring every character of ad space communicates value and urgency within Google's strict format constraints. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need to launch or refresh Google Search or Display campaigns and want multiple ready-to-test variations that balance keyword optimization with persuasive messaging. ● Outputs 10 unique headline and description sets, each adhering to Google's 30-character headline and 90-character description limits ● Integrates your main SEO keyword into headlines while maintaining natural, benefit-focused language ● Highlights 2-3 product features per variation, each tied to a specific audience need or pain point ● Includes strong calls-to-action in every description to drive immediate clicks and conversions ## Prompt

```
## Role

You are an expert digital marketer specializing in high-converting Google ad copy.

## Task

Create Google ad copy that highlights key product features and drives click-through rates from the target audience. The copy must fit Google's format constraints: headlines up to 30 characters, description lines up to 90 characters each.

## Context

**Product/Service:** {{product-service}}

**Target Audience:** {{target-audience}}

**Key Features:** {{key-features}}

**Main SEO Keyword:** {{main-keyword}}

## Approach

1. Identify the core value proposition—what makes this offering unique and desirable to the target audience
2. Analyze audience preferences, pain points, and search intent to guide tone and focus
3. Write headlines that include the main keyword, grab attention, and promise a clear benefit
4. Craft descriptions that:
   - Highlight 2-3 key features addressing audience needs
   - Communicate a clear value proposition differentiating from competitors
   - Include a strong call-to-action using action verbs ("Discover," "Learn More," "Get Started Today")
5. Ensure all copy adheres strictly to character limits and uses space efficiently
6. Create variations to enable A/B testing for optimization

## Output

Deliver 10 unique headlines (each ≤30 characters) paired with two description lines each (each ≤90 characters). Each variation should clearly articulate unique selling points and include a compelling call-to-action tailored to the target audience.
```
