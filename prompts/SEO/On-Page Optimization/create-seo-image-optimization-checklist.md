# SEO Image Optimization Checklist Generator

## 簡介

The SEO Image Optimization Checklist Generator is a free AI prompt that builds a tailored, actionable checklist for improving website image SEO across compression, metadata, naming conventions, and performance optimizations. This image optimization prompt for ChatGPT walks you through four essential areas: identifying and compressing images in optimal formats like WebP and JPEG, crafting descriptive ALT tags that balance accessibility with keyword relevance, establishing consistent file-naming conventions using hyphens and keywords, and implementing performance techniques like lazy loading, CDN delivery, and responsive image markup. The checklist adapts to your specific product type, ensuring recommendations align with your visual content strategy whether you run an e-commerce store, portfolio site, or content platform. It runs on ChatGPT, Claude, Gemini, and Grok. This prompt is for SEO specialists, web developers, and content managers who need a repeatable process to audit and optimize image assets without guessing at best practices. ● Produces a four-part checklist covering compression techniques, ALT tag standards, file naming rules, and advanced performance optimizations like lazy loading and srcset attributes. ● Tailors every step to your product type, so recommendations reflect the unique image requirements of fashion, electronics, SaaS, or any other vertical. ● Emphasizes actionable, specific tasks over generic advice, ensuring each checklist item can be assigned and completed by your team. ● Balances technical SEO gains - faster page load, improved Core Web Vitals - with accessibility and discoverability in image search results. ## Prompt

```
## Role
You are an expert SEO specialist with deep knowledge in image optimization best practices for websites.

## Task
Create a comprehensive, step-by-step checklist for optimizing website images for SEO, tailored to {{product-type}}.

## Requirements
The checklist must cover these four core areas:

**1. Image Compression**
- Steps for identifying images that need optimization
- Determining optimal file formats (WebP, JPEG, PNG)
- Compressing images while maintaining acceptable visual quality
- Re-uploading optimized images
- Goal: Balance file size with image quality for faster page load

**2. ALT Tags**
- Review all product images and assign descriptive ALT tags
- Incorporate target keywords naturally when relevant
- Keep ALT tags concise (typically under 125 characters)
- Use natural language that describes the image content
- Avoid keyword stuffing
- Goal: Provide accessibility for visually impaired users and improve search rankings

**3. File Naming Convention**
- Establish consistent naming using lowercase letters and hyphens
- Include relevant keywords in file names
- Examples: "product-name-angle.jpg" or "category-product-color.webp"
- Goal: Create search-friendly, descriptive file names

**4. Additional Performance Optimizations**
- Implement lazy loading for below-the-fold images
- Use a CDN for faster global delivery
- Serve responsive images with srcset attributes
- Schedule regular image optimization audits
- Goal: Maximize page speed and Core Web Vitals scores

## Output Format
Deliver as a structured checklist with checkboxes:

**Image Optimization Checklist for [Product Type] Website**

1. Image Compression
   - [ ] Step 1
   - [ ] Step 2
   ...

2. ALT Tags
   - [ ] Step 1
   - [ ] Step 2
   ...

3. File Naming Convention
   - [ ] Step 1
   - [ ] Step 2
   ...

4. Additional Considerations
   - [ ] Step 1
   - [ ] Step 2
   ...

Provide actionable, specific steps—not generic advice. Tailor recommendations to the unique characteristics of {{product-type}}.
```
