# Local Search Ranking Tracker for SEO Analysis

## 簡介

The Local Search Ranking Tracker for SEO Analysis is a free AI prompt that generates comprehensive local search ranking reports for businesses monitoring their visibility in location-based search results. This local search ranking prompt for ChatGPT produces a markdown table showing current keyword positions, ranking changes over time, and actionable insights for local SEO improvement. It runs on ChatGPT, Claude, and Gemini, analyzing keyword performance patterns to identify which search terms are gaining traction, declining, or remaining stable. The prompt automatically highlights the top three priority keywords based on ranking volatility or opportunity, then delivers key insights summarizing significant movements and recommended optimization actions. SEO professionals use it to track local pack rankings, measure the impact of optimization efforts, and prioritize which keywords need immediate attention. This prompt is ideal for local businesses, digital marketing agencies, and SEO consultants who need to monitor search visibility across specific geographic markets and turn ranking data into strategic decisions. ● Tracks current keyword positions in local search results with historical comparison showing gains and losses ● Identifies ranking patterns to spot which keywords are improving, declining, or holding steady ● Highlights top three priority keywords based on volatility and optimization opportunity ● Delivers structured markdown output with key insights and recommended actions for immediate implementation ## Prompt

```
## Role
You are an expert SEO analyst specializing in local search performance tracking and competitive analysis.

## Task
Generate a comprehensive local search ranking report for {{business-name}} in {{target-location}}. Track current positions for {{keywords}} and identify ranking movements that require attention.

## Process
1. Analyze current rankings for each keyword in the local search results
2. Compare against historical data to calculate ranking changes (indicate improvements with + and declines with -)
3. Identify patterns: which keywords are gaining traction, which are declining, and which remain stable
4. Highlight the top 3 priority keywords based on ranking volatility or opportunity

## Output
Deliver your findings as a markdown table with three columns:

| Keyword | Current Ranking | Ranking Change |
|---------|----------------|----------------|

Below the table, provide:
- **Key Insights**: 2-3 bullet points summarizing the most significant ranking movements
- **Recommended Actions**: 1-2 priority optimization suggestions based on the data
```
