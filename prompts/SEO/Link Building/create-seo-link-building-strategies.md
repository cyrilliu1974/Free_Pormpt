# SEO Link-Building Search Operator Guide Generator

## 簡介

The SEO Link-Building Search Operator Guide Generator is a free AI prompt that creates a comprehensive step-by-step booklet teaching practitioners how to use advanced Google search operators to uncover high-quality backlink opportunities in their industry. This link building prompt for ChatGPT produces a structured educational guide that walks through search operator syntax (site:, inurl:, intitle:, intext:, filetype:), keyword research methods, query construction techniques, and result prioritization strategies. The output includes five chapters covering operator fundamentals, industry-specific keyword identification, effective query combinations for finding guest posts and resource pages, prospect analysis frameworks, and three detailed case studies tailored to your chosen industry. It runs on ChatGPT, Claude, Gemini, and Grok, requiring only an industry variable to generate a customized booklet with clear headings, bullet points, and practical examples that work for both beginners and experienced SEO professionals. Reach for this prompt when you need to train a team on systematic link prospecting, document your agency's search operator methodology, or create an internal resource for discovering directories, forums, broken link opportunities, and niche-relevant pages at scale. ● Produces a five-chapter booklet covering operator syntax, keyword research, query construction, prospect evaluation, and real-world examples ● Includes practical search operator combinations for finding guest posts, resource pages, broken links, directories, and forums ● Generates industry-specific case studies demonstrating how to apply techniques in your niche ● Provides spreadsheet organization frameworks and authority assessment criteria for prioritizing outreach targets ## Prompt

```
## Role
You are an expert SEO and link building strategist with deep knowledge of advanced search operators for uncovering high-quality link opportunities.

## Task
Create a comprehensive, step-by-step instructional booklet titled "Advanced Search Operators for Link Building" that teaches how to discover relevant, authoritative link prospects using search operator techniques.

## Context
Industry focus: {{industry}}

The guide targets practitioners who want to systematically find guest post opportunities, resource pages, broken links, directories, forums, and other link-worthy pages in their niche using Google search operators.

## Output
Structure the booklet with these sections:

**Introduction**
- Importance of link building in SEO
- Role of advanced search operators in link prospecting
- How this guide delivers actionable link opportunities

**Chapter 1: Understanding Advanced Search Operators**
- Explanation of search operators and their syntax
- Most useful operators for link building: site:, inurl:, intitle:, intext:, filetype:, AND, OR, "", -, *
- Examples of effective operator combinations

**Chapter 2: Identifying Relevant Keyword Phrases**
- Brainstorming industry-specific keywords
- Using keyword research tools (Google Keyword Planner, SEMrush, Ahrefs)
- Categorizing keywords by intent (informational, transactional, navigational)
- Prioritizing keyword phrases for link prospecting

**Chapter 3: Constructing Effective Search Queries**
- Combining keywords with search operators
- Targeting specific page types: resource pages, directories, blogs
- Finding guest post opportunities
- Discovering broken link building prospects
- Locating niche-relevant forums and communities
- Query refinement techniques

**Chapter 4: Analyzing and Prioritizing Results**
- Assessing relevance and authority of discovered pages
- Checking existing backlinks using Ahrefs or Moz
- Determining likelihood of securing a link
- Organizing prospects in a spreadsheet with relevant metrics
- Prioritizing outreach based on opportunity value

**Chapter 5: Case Studies and Examples**
Provide three detailed, industry-specific examples:
- Finding resource pages in {{industry}}
- Uncovering guest post opportunities for {{industry}} topics
- Identifying broken links on high-authority {{industry}} websites

**Conclusion**
- Recap of key strategies
- Importance of consistency and persistence in link prospecting
- Encouragement to experiment with operator combinations
- Clear call-to-action to implement these strategies

Format with clear headings, subheadings, and bullet points for maximum clarity and readability. Make it accessible to beginners while providing actionable depth for experienced practitioners.
```
