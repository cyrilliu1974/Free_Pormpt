# Internal Linking Framework for E-Commerce SEO

## 簡介

The Internal Linking Framework for E-Commerce SEO is a free AI prompt that creates a strategic internal linking architecture to maximize crawl efficiency and topical authority for online stores. This internal linking prompt for ChatGPT builds a complete framework that maps optimal crawl paths ensuring every page is reachable within three clicks, organizes content into hierarchical topical clusters, and distributes link equity to prioritize high-value pages. It generates varied anchor text following natural distribution patterns, integrates blog content with product pages, and identifies orphan pages and inefficient crawl patterns. The prompt runs on ChatGPT, Claude, Gemini, and Grok, producing six detailed sections: site architecture overview, linking priority matrix, anchor text variations, visual crawl flow map, implementation checklist, and monthly optimization schedule. Reach for this prompt when you need to transform a sprawling e-commerce catalog into an interconnected site structure that search engines can efficiently navigate and understand. ● Maps homepage-to-product crawl paths with clear hierarchies and three-click reachability for every page ● Generates anchor text variations across four distribution types with usage limits to avoid over-optimization ● Produces a visual crawl flow diagram showing link equity distribution and blog-to-product connections ● Delivers a prioritized implementation checklist and monthly optimization schedule for ongoing link audits ## Prompt

```
## Role
You are an SEO internal linking specialist who designs site architectures that maximize crawl efficiency and topical authority.

## Task
Create a comprehensive internal linking strategy for an e-commerce site that:

- Maps optimal crawl paths ensuring every page is reachable within 3 clicks from the homepage
- Organizes content into topical clusters with clear hierarchies (homepage → categories → subcategories → products)
- Distributes link equity to prioritize high-value commercial and informational pages
- Provides varied anchor text following natural distribution (40% natural phrases, 30% partial match, 20% exact match, 10% branded)
- Integrates blog content with product pages for contextual authority
- Identifies and eliminates orphan pages and inefficient crawl patterns

## Context
{{site-inventory}}

Provide your catalog size, main product categories, top-selling products, existing blog themes, and primary target keywords.

## Output
Deliver the strategy in six sections:

### 1. Site Architecture Overview
Hierarchical breakdown showing homepage → category → subcategory → product flow, with blog integration points and cross-category opportunities.

### 2. Linking Priority Matrix
Table ranking which page types and specific pages should receive the most internal links based on revenue potential and search opportunity.

### 3. Anchor Text Variations
For each major category and product, provide examples across all four distribution types (natural contextual phrases 40%, partial keyword match 30%, exact keyword match 20%, branded anchors 10%). Limit any single anchor to maximum 3 uses per page.

### 4. Visual Crawl Flow Map
ASCII or structured diagram showing link equity distribution from homepage through all levels, including blog-to-product connections and related product cross-links.

### 5. Implementation Checklist
Prioritized action steps for deploying the linking structure, starting with highest-impact changes.

### 6. Monthly Optimization Schedule
Timeline for ongoing link audits, anchor text refreshes, and new content integration.
```
