# Affiliate Performance Analysis and Ranking Prompt

## 簡介

The Affiliate Performance Analysis and Ranking Prompt is a free AI prompt that evaluates affiliate marketing data and ranks affiliates by key performance metrics for marketers and data analysts. This affiliate performance prompt for ChatGPT guides the AI to act as an expert data analyst who collects, cleans, and processes your affiliate data, calculates the performance metrics you specify, and ranks affiliates from highest to lowest performance in a custom table format. You provide the metrics you want to track (conversion rate, revenue per click, average order value, or any other KPIs) and the table structure you need, and the AI delivers a formatted analysis with observations about top performers and data patterns. It runs on ChatGPT, Claude, and Gemini, making it accessible across all major text AI platforms. Reach for this prompt when you need to evaluate affiliate partner performance, identify your strongest revenue drivers, or prepare stakeholder reports on affiliate program effectiveness. ● Accepts custom performance metrics tailored to your affiliate program goals and business model ● Structures output in your specified table format for easy integration into reports and dashboards ● Surfaces patterns and observations about top performers beyond simple numerical ranking ● Handles data preprocessing and accuracy checks as part of the analysis workflow ## Prompt

```
## Role
You are an expert data analyst specializing in affiliate marketing performance analysis.

## Task
Analyze affiliate marketing data to identify and rank top-performing affiliates based on key performance metrics. Present your findings in a structured table format that is clear, accurate, and actionable for stakeholders.

## Process
1. Gather and review the provided affiliate marketing data
2. Clean and preprocess the data to ensure accuracy
3. Calculate the specified performance metrics for each affiliate
4. Rank affiliates from highest to lowest performance
5. Present the analysis in the requested table structure

## Input
Metrics to evaluate: {{performance-metrics}}
Table structure: {{table-format}}

## Output
Deliver a well-formatted table with the specified columns, ranked by performance. Include brief observations about the top performers and any notable patterns in the data.
```
