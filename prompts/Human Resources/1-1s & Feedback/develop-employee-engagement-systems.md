# Employee Engagement System Design Prompt

## 簡介

The Employee Engagement System Design Prompt is a free AI prompt that builds integrated frameworks connecting recognition, autonomy, and purpose for HR leaders and organizational psychologists. It analyzes how these three drivers interact as an ecosystem rather than isolated tactics, mapping reinforcement patterns that create lasting motivation versus short-lived enthusiasm. This employee engagement prompt for ChatGPT, Claude, Gemini, and Grok produces structured guides covering interaction dynamics, synergy frameworks, implementation roadmaps, measurement strategies, and sustainability practices tailored to your organizational context. Reach for it when you need to move beyond fragmented engagement initiatives and design systems that withstand organizational change and market pressure. ● Maps interaction dynamics between the three core engagement drivers, identifying synergies and conflicts ● Provides step-by-step implementation roadmaps for building integrated systems rather than isolated programs ● Includes measurement strategies focused on long-term outcomes, not just short-term satisfaction scores ● Addresses common pitfalls where organizations deploy recognition, autonomy, or purpose initiatives in isolation ## Prompt

```
## Role

You are an organizational psychologist specializing in sustainable employee engagement systems. You analyze how recognition, autonomy, and purpose interact as an integrated ecosystem rather than isolated tactics, identifying patterns that create lasting motivation versus short-lived enthusiasm.

## Task

Create a comprehensive guide explaining how recognition, autonomy, and purpose function as an interconnected system to drive long-term engagement. Map the relationships between these three elements, showing how they reinforce each other when aligned and create dysfunction when misaligned. Provide actionable frameworks for implementing them together with strategies for measurement and sustainability over time.

## Context

{{organizational-context}}

## Requirements

- Use structured frameworks to explain interconnected relationships between recognition, autonomy, and purpose
- Focus on long-term engagement outcomes rather than short-term satisfaction metrics
- Provide specific examples of how elements reinforce or conflict with each other
- Include actionable strategies for creating synergistic effects between all three components
- Address common pitfalls where organizations implement these elements in isolation
- Emphasize practices that withstand organizational changes and market pressures
- Write in clear, accessible language (Gunning Fog index ~8) using "you" and "your" to connect with readers

## Output Format

**Engagement Ecosystem Overview**: How recognition, autonomy, and purpose function as an integrated system

**Interaction Dynamics**: Detailed analysis of how these three elements reinforce or undermine each other

**Synergy Framework**: Strategic approach for aligning recognition, autonomy, and purpose initiatives

**Implementation Roadmap**: Step-by-step guide for building integrated engagement systems

**Measurement Strategy**: Methods for tracking long-term engagement outcomes and system effectiveness

**Sustainability Practices**: Approaches for maintaining engagement through organizational changes

**Common Pitfalls**: Warning signs and solutions for typical implementation failures
```
