# Agile Methodology Adoption Guide for Project Teams

## 簡介

The Agile Methodology Adoption Guide for Project Teams is a free AI prompt that creates a customized, step-by-step roadmap for implementing Agile practices in real organizational environments. This Agile adoption prompt for ChatGPT analyzes your organizational context - team size, project complexity, current workflow maturity, and primary obstacles - then delivers a markdown table covering 5 to 8 Agile practices ranked from foundational to advanced. Each practice includes concrete benefits relevant to your situation and 4 to 6 numbered implementation steps that account for your existing workflows. The output runs on ChatGPT, Claude, Gemini, and Grok, making it accessible across leading text models. Use cases include transitioning waterfall teams to Scrum, introducing sprint planning to startups, or scaling Agile ceremonies for enterprise projects. Project managers, Scrum Masters, engineering leads, and consultants reach for this prompt when they need a pragmatic adoption plan that respects team capacity and addresses specific challenges rather than generic best practices. ● Prioritizes Agile practices based on your team's current workflow maturity and stated challenges ● Provides 4 to 6 actionable implementation steps per practice, sequenced from foundational to advanced ● Includes transition tips showing how practices build on one another for realistic adoption pacing ● Outputs a clean markdown table with Agile Practices, Benefits, and Implementation Steps columns for easy sharing and planning ## Prompt

```
## Role
You are an Agile methodology expert who designs practical adoption guides tailored to real organizational constraints.

## Task
Create a comprehensive Agile adoption guide in markdown table format with three columns: **Agile Practices**, **Benefits**, and **Implementation Steps**. Each row must cover one specific Agile practice with its advantages and a clear step-by-step implementation guide.

## Context
Analyze the organization's current state and recommend Agile practices that fit:

{{organizational-context}}

Consider team size, project complexity, organizational culture, current workflow maturity, and primary obstacles when selecting and sequencing practices. Prioritize practices that address the stated challenges while being realistic for the team's capacity.

## Output
Deliver a markdown table covering 5–8 Agile practices. For each practice:
- **Agile Practices**: Name and brief description
- **Benefits**: 2–4 concrete advantages relevant to the context provided
- **Implementation Steps**: Numbered, actionable steps (4–6 per practice) that account for the current workflow and challenges

Order practices from foundational (adopt first) to advanced. Include transition tips where one practice builds on another.
```
