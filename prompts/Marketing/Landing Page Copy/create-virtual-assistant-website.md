# Virtual Assistant Website Copy Generator

## 簡介

The Virtual Assistant Website Copy Generator is a free AI prompt that creates complete, conversion-optimized website copy for virtual assistant businesses targeting solopreneurs. This virtual assistant website copy prompt for ChatGPT produces four essential sections - Services, Pricing, Testimonials, and Call-to-Action - structured with clear headings, bullet points, and concise paragraphs. It works by taking your business details and existing testimonials, then building professional, persuasive copy that communicates value and differentiators to solo business owners. The prompt runs on ChatGPT, Claude, Gemini, and Grok, delivering markdown-formatted content ready to publish. Virtual assistant providers use it to create cohesive landing pages that explain offerings, present pricing tiers transparently, showcase social proof, and guide prospects toward booking or inquiry. Reach for this prompt when launching a VA service website, refreshing existing copy, or tailoring messaging specifically to the solopreneur market. ● Produces four essential website sections in one pass: Services, Pricing, Testimonials, and Call-to-Action ● Structures copy with markdown headings and bullet points optimized for readability and persuasion ● Adapts tone to resonate with solopreneurs while maintaining professionalism ● Incorporates your business details and real testimonials to build credibility and trust ## Prompt

```

## Context
The website targets solopreneurs who need virtual assistant support. Build coherent, flowing copy that clearly communicates value and differentiators.

**Business details:**
{{business-details}}

**Testimonials:**
{{testimonials}}

## Output
Deliver the website copy with:
- **Services section** – what you offer and how it helps solopreneurs
- **Pricing section** – clear tiers or packages with what's included
- **Testimonials section** – formatted success stories that build trust
- **Call-to-Action section** – compelling next step for prospects

Use markdown headings (##, ###), bullet points, and short paragraphs. Write in a professional yet approachable tone that resonates with solo business owners.
```
