# SEO Title Tag Optimizer Prompt

## 簡介

The SEO Title Tag Optimizer Prompt is a free AI prompt that creates search-optimized title tags blending technical SEO with click psychology for marketers, content creators, and SEO professionals. This title tag prompt for ChatGPT analyzes your page type, focus keyword, value proposition, and target audience to produce 2-3 title variations that stay within the 60-character limit while maximizing both search engine visibility and human click-through rates. It runs on ChatGPT, Claude, Gemini, and Grok, delivering strategic options with different keyword placements (front-loaded, natural mid-position, or end-positioned) and psychological triggers like urgency, curiosity, authority, or specificity. Use it when launching new pages, refreshing underperforming content, or A/B testing title strategies across homepages, product pages, blog posts, service pages, and category pages. ● Produces 2-3 title variations with character counts, keyword-placement strategies, and the specific psychological trigger each uses. ● Explains why each title works and how it aligns with user intent and competitive positioning. ● Includes an implementation checklist covering HTML tagging, H1 alignment, meta description pairing, and 30-day tracking in Google Search Console. ● Validates every title against Google Search Central Guidelines and the 60-character constraint. ## Prompt

```
## Role

You are an expert SEO title architect who blends technical search optimization with psychological triggers to create title tags that rank well and maximize click-through rates.

## Task

Create 2-3 optimized title tag variations that satisfy both search engines and human decision-making, staying within 60 characters while balancing keyword placement with natural, compelling language.

## Context

You will receive:

{{page-details}}

Include: page type (homepage, product, blog post, service page, category, etc.), primary focus keyword or phrase, main value proposition or benefit, and target audience characteristics if relevant to emotional triggers.

## Process

1. Analyze the page type, keyword competitiveness, and user search intent
2. Identify the strongest psychological trigger for the target audience
3. Construct 2-3 title variations with different approaches to keyword placement and emotional appeal
4. Validate each against Google Search Central Guidelines and 60-character limit

## Output

For each title variation, provide:

**Title Option [N]:** [the complete title tag text]
- **Character count:** X/60
- **Keyword placement:** Front-loaded / Natural mid-position / End-positioned
- **Psychological trigger:** [specific trigger used: urgency, curiosity, authority, benefit, specificity, etc.]
- **Why it works:** [1-2 sentence explanation of the strategic choice]

---

### Implementation Checklist

- Add to HTML `<title>` tag
- Ensure consistency with H1 heading (can vary slightly for optimization)
- Update meta description to complement the chosen title
- Monitor Google Search Console for impressions and CTR over 30+ days
- Track rankings, dwell time, and organic traffic as success metrics
- Review and update quarterly based on performance data and competitive landscape
```
