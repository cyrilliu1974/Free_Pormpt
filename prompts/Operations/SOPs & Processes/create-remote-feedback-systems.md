# Remote Feedback System Design Prompt

## 簡介

The Remote Feedback System Design Prompt is a free AI prompt that builds a comprehensive feedback framework tailored to remote work environments for managers, HR professionals, and distributed team leaders. This remote feedback prompt for ChatGPT produces a four-column table covering five distinct feedback scenarios - performance reviews, project check-ins, peer recognition, course corrections, and developmental coaching - with specific recommendations for timing, communication channels, and best practices suited to asynchronous and synchronous remote contexts. It runs on ChatGPT, Claude, Gemini, and Grok, and adapts to your team size, existing communication channels, and documented feedback challenges. Use cases include onboarding distributed teams, standardizing feedback cadence across time zones, and establishing psychological safety in virtual workplaces. Reach for this prompt when you need to formalize feedback processes for a remote or hybrid team, ensure consistency across managers in different regions, or troubleshoot low engagement in existing feedback loops. ● Maps five feedback types to appropriate frequency, communication channels, and actionable best practices ● Includes implementation guidance for timezone differences, documentation needs, and cultural nuances specific to remote work ● Provides measurable success criteria: participation rates, response times, sentiment analysis, and behavior change indicators ● Adapts to your team size, primary communication tools, and the specific feedback challenges you face ## Prompt

```
## Role
You are an expert in remote work dynamics and effective communication, specializing in feedback systems.

## Task
Design a comprehensive feedback system for a remote work environment that facilitates clear, consistent, and constructive feedback exchanges.

## Context
Team size: {{team-size}}
Primary communication channels: {{communication-channels}}
Main feedback challenges: {{feedback-challenges}}

## Output
Provide a table with 4 columns (Feedback Type, Frequency, Communication Channel, Best Practices) and 5 rows, each representing a different feedback scenario appropriate for remote teams.

Ensure feedback types cover a range of situations (performance reviews, project check-ins, peer recognition, course corrections, developmental coaching). Recommend frequency that maintains consistency without overwhelming the team. Match communication channels to feedback formality and urgency. Offer best practices that promote clarity, constructiveness, and engagement in asynchronous and synchronous contexts.

After the table, include:

**Additional Considerations**
Outline points for implementing the system in a remote environment, addressing timezone differences, documentation needs, psychological safety, and cultural nuances.

**Metrics for Success**
Describe how to measure effectiveness: participation rates, response times, sentiment analysis, behavior change indicators, and team satisfaction scores.
```
