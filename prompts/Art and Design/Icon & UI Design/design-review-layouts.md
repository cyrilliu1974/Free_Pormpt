# E-Commerce Review Layout Design Prompt

## 簡介

The E-Commerce Review Layout Design Prompt is a free AI prompt that generates multiple review section layouts optimized for trust, social proof, and conversion in online stores. It produces 3-4 distinct layout options, each with visual hierarchy breakdowns, filtering mechanisms, verified purchase badge styling, mobile-responsive specifications, and implementation roadmaps tailored to your product category and customer objections. This review layout prompt for ChatGPT runs on ChatGPT, Claude, Gemini, and Grok, helping e-commerce teams design review sections that reduce cart abandonment by balancing authentic social proof with strategic trust signals. Ideal for product managers, UX designers, and conversion rate optimizers who need concrete, implementable review interface options rather than generic advice. ● Delivers visual hierarchy breakdowns showing rating summary placement, review card density, verified badge styling, and testimonial callouts that counter stated customer objections. ● Specifies filtering systems with rating level, verification status, product variant, date range, and helpfulness score options, including UI placement rationale and default sort order. ● Includes mobile adaptation rules with responsive breakpoints, touch-optimized controls, and performance considerations for slower connections. ● Provides implementation priorities separating quick-win features from advanced enhancements, with technical complexity and resource estimates for each layout option. ## Prompt

```
## Role

You are a conversion optimization architect specializing in e-commerce review UX. You design review layouts that balance authentic social proof with strategic placement, filtering, and trust signals to reduce cart abandonment and increase purchase confidence.

## Task

Generate 3–4 distinct review layout options tailored to the provided product context. Each layout must combine overall rating summaries, filtering mechanisms, highlighted testimonials, verified purchase indicators, and trust-building features in a cohesive, conversion-focused design.

## Context

{{business-context}}

Provide the product category, target audience, current review volume, main customer objections, and brand visual style. Include any relevant constraints (technical limitations, stakeholder priorities, competitive positioning).

## Output

For each layout option, provide:

**Layout Name & Primary Goal**  
Clear title and the specific conversion objective it addresses.

**Visual Hierarchy Breakdown**  
- Overall rating summary placement and prominence  
- Review card structure, spacing, and density  
- Verified purchase badge styling (icon treatment, color coding, positioning)  
- Highlighted testimonial callouts that counter stated objections  

**Filtering System**  
- Available filters: rating level, verification status, product variant, date range, helpfulness score  
- Filter UI placement (sidebar, top bar, inline dropdown)  
- Default sort order with rationale  

**Trust Signal Placement**  
- Authenticity badges, reviewer verification marks, helpfulness voting UI  
- Integration points that feel native to the layout, not bolted-on  

**Mobile Adaptation**  
- Responsive breakpoints and content stacking order  
- Touch-optimized filter and voting controls  
- Performance considerations for slower connections  

**Implementation Priority**  
- Quick-win features vs. advanced enhancements  
- Technical complexity, dependencies, and resource estimates  

Include psychological rationale for key design choices, specific dimensions or color treatments where relevant, and cite patterns proven to increase trust and conversion in the given product category.
```
