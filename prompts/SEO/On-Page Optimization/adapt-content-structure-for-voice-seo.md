# Voice Search SEO Content Optimization Prompt

## 簡介

The Voice Search SEO Content Optimization Prompt is a free AI prompt that generates a complete action plan to restructure and optimize website content for voice-activated search queries. This voice search optimization prompt for ChatGPT analyzes your target keywords, niche, audience, and existing content structure to deliver specific recommendations across nine optimization areas: conversational language integration, long-tail keyword strategy, structured data markup (FAQ, HowTo, Article schema), featured snippet formatting, FAQ section development, and technical performance fixes. It runs on ChatGPT, Claude, Gemini, and Grok, transforming traditional text-focused SEO into voice-ready content that mirrors natural speech patterns and question-answer formats. Digital marketers, content strategists, and SEO professionals use it to capture voice search traffic from smart speakers, mobile assistants, and conversational AI platforms. ● Analyzes how target keywords appear in voice queries and identifies question patterns and conversational variants ● Provides schema markup recommendations (FAQ, HowTo, Article, LocalBusiness) with placement instructions ● Formats content for featured snippets with concise answers, lists, tables, and definition blocks ● Defines performance tracking metrics including voice search impressions, featured snippet wins, and mobile rankings ## Prompt

```
## Role
You are an SEO specialist focused on voice search optimization.

## Task
Optimize website content to rank for voice search queries by incorporating conversational language, long-tail keywords, and structured data markup. Provide a prioritized action plan with specific recommendations.

## Context
Target keywords: {{target-keywords}}
Website niche: {{niche}}
Target audience: {{audience}}
Current content structure: {{content-structure}}

## Analysis & Recommendations
For each optimization area below, provide specific actions:

1. **Keyword & Intent Analysis** – Analyze how the target keywords are used in voice queries; identify question patterns and conversational variants.

2. **Conversational Language Integration** – Rewrite key content sections to mirror natural speech patterns; use complete sentences and question-answer formats.

3. **Long-Tail Keyword Strategy** – Identify and integrate long-tail variations that match voice query length and structure.

4. **Structured Data Implementation** – Specify which schema types to add (FAQ, HowTo, Article, LocalBusiness, etc.) and where to place them.

5. **Featured Snippet Optimization** – Format content to target position zero with concise answers, lists, tables, and definition blocks.

6. **FAQ Section Development** – Create FAQ modules addressing the most common voice queries related to the target keywords.

7. **Technical Optimization** – Assess mobile responsiveness, page speed, and Core Web Vitals; recommend fixes.

8. **Schema Markup Expansion** – Map additional schema opportunities beyond basic structured data to provide richer context.

9. **Performance Tracking** – Define key metrics (voice search impressions, featured snippet wins, mobile rankings) and monitoring intervals.

## Output
Deliver as a numbered list where each main point includes bullet-point sub-actions tailored to the provided context.
```
