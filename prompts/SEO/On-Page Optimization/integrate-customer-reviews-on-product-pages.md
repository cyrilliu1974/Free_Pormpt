# Customer Review Integration Schema Markup Plan

## 簡介

The Customer Review Integration Schema Markup Plan is a free AI prompt that delivers a technical implementation roadmap for e-commerce teams who want to add review schema and optimize review placement on product pages. This customer review integration prompt for ChatGPT analyzes your existing product page structure, recommends optimal review placement for trust and visibility, specifies the exact schema markup types (Product, Review, AggregateRating) needed for search engines to display star ratings in results, and defines testing steps plus success metrics. It runs on ChatGPT, Claude, Gemini, and Grok. Real-world use cases include online retailers preparing for a site redesign, SEO specialists implementing structured data for the first time, and conversion-rate optimizers testing review layouts that balance social proof with page performance. Reach for this prompt when you need a clear, technical checklist that connects review display strategy to both organic search rankings and on-page conversion rates. ● Analyzes current product page HTML and identifies where review modules will have the highest trust impact ● Specifies Product, Review, and AggregateRating schema markup syntax for Google rich results eligibility ● Recommends strategic review positioning that balances SEO indexing with conversion-focused layout ● Includes structured-data testing steps and defines which metrics (click-through rate, conversion lift, crawl validation) to monitor post-launch ## Prompt

```
## Role
You are an e-commerce SEO specialist focused on review integration and schema markup implementation.

## Task
Provide a step-by-step implementation plan for integrating customer reviews on product pages using schema markup to improve search visibility and conversion rates.

## Context
Product: {{product-name}}
Current product page: {{product-url}}
Target keywords: {{target-keywords}}
Business and customer context: {{business-context}}

## Process
Your plan should cover:
- Analysis of the current product page structure and review placement opportunities
- Schema markup implementation (Product, Review, AggregateRating types)
- Strategic positioning of reviews for visibility and trust
- Testing and validation of structured data
- Metrics to monitor for SEO impact and conversion lift

## Output
Deliver a numbered list detailing each implementation step, including technical requirements, best practices, and success metrics.
```
