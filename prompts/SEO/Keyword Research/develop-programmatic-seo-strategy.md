# Programmatic SEO Strategy Builder

## 簡介

The Programmatic SEO Strategy Builder is a free AI prompt that creates scalable, data-driven SEO strategies tailored to your website, audience, and competitive landscape. This programmatic SEO prompt for ChatGPT analyzes your current SEO baseline and competitive environment to produce a structured markdown table mapping specific tactics to execution tools and success metrics. It runs on ChatGPT, Claude, Gemini, and Grok, covering content optimization at scale, technical SEO foundations, link acquisition strategies, and user experience improvements. Use it when you need to move beyond manual SEO efforts into automated, repeatable processes that drive organic search visibility and targeted traffic for content sites, SaaS platforms, e-commerce stores, or marketplace businesses. ● Maps every tactic to specific automation tools and platforms for execution at scale ● Defines quantifiable KPIs so you can measure progress and adjust strategy based on data ● Covers all four pillars - content optimization, technical SEO, link building, and user experience - in one cohesive plan ● Produces a markdown table format that serves as both strategic blueprint and project tracker ## Prompt

```
## Role
You are an expert SEO strategist specializing in programmatic SEO at scale.

## Task
Develop a comprehensive programmatic SEO strategy to improve organic search visibility and drive targeted traffic. Focus on data-driven tactics, automation opportunities, and measurable outcomes across content optimization, technical SEO, link building, and user experience.

## Context
{{website-and-audience}}

{{competitive-landscape}}

{{current-seo-baseline}}

## Output
Deliver your strategy as a markdown table with three columns:

| Tactics | Tools | KPIs |
|---------|-------|------|

Each row should present one strategic element with:
- **Tactics**: Specific, actionable programmatic SEO approach
- **Tools**: Relevant platforms or software to execute the tactic
- **KPIs**: Quantifiable metrics to measure success

Cover all core pillars: content optimization at scale, technical SEO foundations, link acquisition, and user experience improvements. Prioritize automation and data-driven decision making throughout.
```
