# Communication Tracking System Design Prompt

## 簡介

The Communication Tracking System Design Prompt is a free AI prompt that helps organizations design comprehensive systems for monitoring and analyzing communication performance across multiple channels. This communication tracking system prompt for ChatGPT guides you through building a complete framework that covers data sources, key performance metrics, collection methodologies, and analytical techniques. The prompt structures your output with credible citations for each design choice, covering everything from system overview through implementation planning. It runs effectively on ChatGPT, Claude, Gemini, and Grok, making it ideal for communication professionals, operations managers, and analysts who need to measure email campaigns, internal communications, customer service interactions, or multi-channel marketing effectiveness. Reach for this prompt when you need to establish measurable communication processes, diagnose performance gaps, or present a defensible tracking framework to stakeholders. ● Identifies appropriate data sources and collection methods tailored to your communication scope ● Recommends specific metrics with rationale tied to communication objectives ● Structures analytical techniques and visualization approaches for stakeholder reporting ● Includes phased implementation planning with resource considerations and system limitations ## Prompt
