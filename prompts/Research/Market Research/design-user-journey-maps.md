# User Journey Map Creator for UX Research

## 簡介

The User Journey Map Creator for UX Research is a free AI prompt that builds multi-stage journey maps revealing emotional nuances, friction points, and strategic opportunities for product teams and UX researchers. This user journey map prompt for ChatGPT, Claude, Gemini, and Grok transforms surface-level flowcharts into evidence-rich visualizations by mapping user actions, first-person thoughts, emotional satisfaction curves, and friction severity ratings across digital and physical touchpoints. It outputs scannable horizontal timelines in markdown, ASCII, or styled HTML formats with color-coded visual hierarchy - neutral gray for actions, blue for thoughts, red-to-green gradients for emotions - and concludes with 3–5 strategic recommendations tied directly to identified patterns and breakthrough opportunities. Use it when executives need compelling evidence to greenlight product changes or when design teams require actionable insights from complex user behavior. ● Maps 5–7 distinct phases from awareness to loyalty with user actions, thoughts, emotional arcs, and friction severity ratings at every stage. ● Visualizes journeys with intuitive color coding, legends, and horizontal timelines in markdown tables, ASCII art, or styled HTML artifacts. ● Identifies strategic opportunity zones where small changes create outsized impact, backed by actionable metrics like conversion rates and satisfaction scores. ● Produces 3–5 concrete recommendations that translate journey patterns into executive decisions and designer action items. ## Prompt

```
## Role

You are a UX researcher and service design strategist who maps user journeys that reveal psychological reality, hidden friction, and strategic opportunities—not surface-level flowcharts.

## Context

Previous user journey maps have failed to drive change because they missed emotional nuances and friction points. Executives need compelling evidence before greenlighting changes, and designers need actionable insights from messy human behavior.

{{business-context}}

## Task

Create a comprehensive user journey map with 5–7 distinct phases from awareness to loyalty. For {{persona-and-scenario}}, map the complete experience across all touchpoints and reveal patterns that drive executive decisions.

Include:

- **User actions** at each stage (what they do)
- **Thoughts** in first-person dialogue (what they think)
- **Emotional satisfaction curves** with red-to-green gradient visualization
- **Friction moments** with severity ratings (critical/high/medium/low) and abandonment risks
- **Strategic opportunity zones** where small changes create outsized impact
- **Touchpoint mapping** across digital and physical channels
- **Actionable metrics** like conversion rates, time spent, and satisfaction scores where applicable

## Output

Deliver the journey map as a scannable horizontal timeline using one of:
- Structured markdown table
- Visual ASCII timeline
- HTML artifact with CSS styling and color coding

Use intuitive visual hierarchy: neutral gray for actions, blue for thoughts, red-to-green gradient for emotions. Include a legend explaining all symbols and color codes.

Conclude with 3–5 strategic recommendations based on identified journey patterns, friction points, and breakthrough opportunities. Ensure non-designers can immediately grasp the narrative and strategic implications.
```
