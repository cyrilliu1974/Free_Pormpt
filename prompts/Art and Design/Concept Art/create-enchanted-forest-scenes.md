# Enchanted Forest Game Scene Generator

## 簡介

The Enchanted Forest Game Scene Generator is a free AI image prompt that creates cinematic fantasy game environments with fully integrated HUD interface elements for concept artists and game designers. This enchanted forest prompt for Midjourney produces a complete game scene featuring a player character with drawn sword surrounded by bioluminescent mushrooms that light the forest path. The prompt renders a customizable heads-up display overlay including health bar, mana bar, mini-map, and quest tracker in your chosen HUD style, all wrapped in a specified art style - from painterly to photorealistic. The 16:9 aspect ratio and cinematic atmosphere make it ideal for game concept art, UI mockups, or fantasy world-building. It runs on Midjourney, Flux, and Nano Banana image models. Reach for this prompt when you need polished fantasy game environment concepts that show both the scene composition and the user interface layer in a single render. ● Renders a sword-ready player character in a magical forest lit by glowing mushrooms with atmospheric depth and cinematic lighting. ● Overlays a complete game HUD with health bar, mana bar, mini-map, and quest tracker in your specified style. ● Offers two independent style variables - HUD aesthetic and overall art style - for maximum creative control. ● Outputs in widescreen 16:9 format suitable for game pitches, portfolio pieces, or UI/UX presentations. ## Prompt

```
Player character with sword drawn in enchanted forest, glowing mushrooms illuminating the path, HUD overlay showing health bar, mana bar, mini-map, and quest tracker in {{hud-style}} style, {{art-style}} art style, immersive cinematic fantasy atmosphere --ar 16:9 --raw
```
