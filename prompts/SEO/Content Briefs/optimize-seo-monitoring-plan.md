# SEO Monitoring Plan Creator for Websites

## 簡介

The SEO Monitoring Plan Creator for Websites is a free AI prompt that builds a complete performance tracking strategy tailored to any website URL. This SEO monitoring prompt for ChatGPT generates a custom plan that includes recommended tracking frequency, seven essential metrics (organic traffic, keyword rankings, backlinks, page speed, crawl errors, conversion rate, bounce rate), a markdown table showing desired trends and interpretation for each metric, and five actionable implementation steps. It runs on ChatGPT, Claude, Gemini, and Grok, producing a framework you can immediately use to set up dashboards, establish baselines, and define alert thresholds. Marketers use it to standardize monitoring across client sites, in-house SEO teams use it to justify tooling investments, and agencies use it to onboard new accounts with consistent measurement practices. Reach for this prompt when launching a new site, inheriting an existing property without documentation, or auditing your current monitoring approach for gaps. ● Recommends monitoring frequency calibrated to website type and scale ● Delivers a three-column interpretation table with trend arrows and explanations for each metric ● Provides five concrete action steps for setting up tools, dashboards, and review schedules ● Outputs in markdown format ready to paste into documentation or project management tools ## Prompt

```
## Role
You are an SEO expert specializing in website performance monitoring and reporting.

## Task
Create a comprehensive monitoring plan for {{website-url}} that tracks key SEO performance metrics and provides actionable insights.

## Output
Structure your response as follows:

### Monitoring Frequency
Recommend an appropriate monitoring schedule (daily, weekly, monthly) based on the website type and scale.

### Key Metrics
List 7 essential SEO metrics to track (e.g., organic traffic, keyword rankings, backlinks, page speed, crawl errors, conversion rate, bounce rate).

### Metrics Interpretation
Provide a table with three columns:
- **Metric**: The name of each metric
- **Desired Trend**: Use ▲ for metrics that should increase, ▼ for metrics that should decrease
- **Interpretation**: Concise explanation of what the metric indicates and why it matters

Format the table in markdown.

### Action Steps
Outline 5 clear, implementable steps to establish and maintain the monitoring plan. Focus on practical actions like setting up tracking tools, creating dashboards, establishing baselines, scheduling reviews, and defining alert thresholds.

Keep all guidance actionable and concise. Avoid generic advice.
```
