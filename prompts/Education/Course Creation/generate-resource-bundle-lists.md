# Curriculum Resource List Builder for Educators

## 簡介

The Curriculum Resource List Builder for Educators is a free AI prompt that compiles research-backed educational materials tailored to specific subjects, audiences, and curriculum goals. This curriculum resource list prompt for ChatGPT evaluates textbooks, online courses, worksheets, and lesson plans for pedagogical effectiveness and relevance, then organizes them into a clean markdown table with resource names, types, descriptions, and URLs. It works across ChatGPT, Claude, Gemini, and Grok, ensuring coverage of varied learning styles - visual, auditory, kinesthetic - and teaching methods like direct instruction, inquiry-based learning, and collaborative approaches. Ideal for building course materials, unit planning, or professional development resource guides. Educators, instructional designers, and curriculum coordinators reach for this prompt when they need to quickly assemble vetted resources that support diverse learners and align with specific educational standards. ● Identifies resources across multiple formats: textbooks, digital courses, worksheets, and lesson plans ● Evaluates each resource for quality, pedagogical value, and alignment with curriculum goals ● Organizes findings in a markdown table with name, type, description, and URL for immediate use ● Covers diverse learning styles and teaching methods to support differentiated instruction ## Prompt

```
## Role
You are an expert curriculum developer specializing in identifying and evaluating educational resources across multiple formats and pedagogical approaches.

## Task
Compile a comprehensive, research-backed list of educational resources for curriculum development. Identify textbooks, online courses, worksheets, lesson plans, and other materials relevant to {{subject}}. Evaluate each resource for quality, relevance, and pedagogical effectiveness. Ensure coverage of varied learning styles (visual, auditory, kinesthetic) and teaching methods (direct instruction, inquiry-based, collaborative) to support diverse learners.

## Context
- Subject: {{subject}}
- Target audience: {{target-audience}}
- Educational level: {{educational-level}}
- Curriculum goals: {{curriculum-goals}}

## Output
Present findings as a markdown table with four columns:

| Resource Name | Type | Description | URL |
|---------------|------|-------------|-----|

Provide clear, concise descriptions highlighting each resource's pedagogical value and application. Organize entries logically (by type or topic) for easy reference.
```
