# Information Literacy Skills Development Guide

## 簡介

The Information Literacy Skills Development Guide is a free AI prompt that creates structured educational materials teaching users how to assess source credibility, identify bias, and synthesize information from multiple sources. This information literacy prompt for ChatGPT produces a complete instructional guide organized into evaluation frameworks, practical checklists, and synthesis templates. It covers primary through tertiary source types, credibility assessment criteria (authority, accuracy, currency, purpose), bias identification strategies, and systematic methods for comparing and contrasting information across sources. The prompt runs on ChatGPT, Claude, Gemini, and Grok, generating markdown-formatted guides with tables, bullet points, and actionable examples tailored to specific audiences and writing styles. Educators use it to build course materials, researchers apply it for methodology training, and students rely on it to develop critical thinking skills for academic work. ● Creates source evaluation checklists with yes/no questions formatted as tables for systematic credibility assessment ● Teaches recognition of multiple bias types with concrete identification strategies and real-world examples ● Provides information synthesis templates in table format for organizing findings across multiple sources by theme, credibility, and relevance ● Adapts tone and complexity to match target audience needs, from high school students to professional researchers ## Prompt

```
## Role
You are an expert information literacy instructor specializing in source evaluation and information synthesis.

## Task
Create a comprehensive guide that teaches users how to assess the credibility and bias of information sources and synthesize information from multiple sources effectively.

## Context
{{target-audience-and-goals}}

The guide must be thorough yet accessible, providing actionable strategies, concrete examples, and practical templates that users can apply immediately.

## Output
Organize the guide using this structure:

**Introduction** [1-2 paragraphs on the importance of information literacy in the digital age]

**Part 1: Evaluating Sources**
1. Understanding Types of Sources (primary, secondary, tertiary, scholarly, popular)
2. Assessing Credibility (authority, accuracy, currency, purpose)
3. Recognizing Bias (types of bias and identification strategies)
4. Source Evaluation Checklist (yes/no questions in table format)

**Part 2: Synthesizing Information**
1. Identifying Themes and Patterns
2. Comparing and Contrasting Sources
3. Drawing Conclusions
4. Information Synthesis Template (table format for organizing multiple sources by key points, credibility, and relevance)

**Conclusion** [Reiterate importance and key takeaways]

Format using markdown with clear headings, subheadings, and bullet points. Use tables for the checklist and synthesis template. Each section should provide actionable strategies and examples. Write in a {{writing-style}} style.
```
