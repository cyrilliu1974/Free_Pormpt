# Social Media Analytics Report Generator

## 簡介

The Social Media Analytics Report Generator is a free AI prompt that produces structured performance reports for social media marketers and analysts tracking campaigns across multiple platforms. This social media analytics prompt for ChatGPT guides the model to analyze key performance indicators, interpret trends, and deliver actionable insights organized into four sections: an executive summary showing overall performance and goal attainment, platform-specific markdown tables with metric performance and period-over-period changes, audience engagement analysis tied to campaign goals, and prioritized recommendations with specific next steps. The prompt runs on ChatGPT, Claude, Gemini, and Grok, adapting to your chosen platforms, key metrics, campaign goals, and reporting period. Reach for this prompt when you need to transform raw social media data into a professional, stakeholder-ready report that highlights what worked, what didn't, and what to do next. ● Organizes multi-platform campaign data into clear markdown tables with period-over-period comparisons ● Aligns metric analysis directly with stated campaign goals to show goal attainment ● Surfaces demographic and behavioral audience insights tied to engagement patterns ● Delivers prioritized, specific recommendations rather than generic observations ## Prompt

```
## Role
You are an expert social media analyst specializing in performance measurement and data-driven campaign evaluation.

## Task
Generate a comprehensive analytics report that measures marketing campaign effectiveness across multiple platforms. Analyze key performance indicators, interpret trends, and provide actionable insights highlighting campaign performance, audience engagement, and improvement opportunities.

## Context
**Platforms:** {{platforms}}
**Key metrics:** {{key-metrics}}
**Campaign goals:** {{campaign-goals}}
**Reporting period:** {{reporting-period}}

## Output
Structure the report as follows:

1. **Executive Summary** – Overall performance insights, goal attainment, and high-level trends across all platforms.
2. **Platform-Specific Analysis** – One markdown table per platform showing metric performance, period-over-period changes, and observations.
3. **Audience Engagement Analysis** – Demographic and behavioral insights tied to the campaign goals.
4. **Actionable Recommendations** – Prioritized improvement areas with specific next steps.

Use clear markdown tables for all quantitative data. Ensure metrics align with the stated campaign goals and highlight statistically significant trends.
```
