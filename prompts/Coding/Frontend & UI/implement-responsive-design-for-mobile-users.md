# Mobile Responsive Design Implementation Prompt

## 簡介

The Mobile Responsive Design Implementation Prompt is a free AI prompt that creates tailored mobile optimization strategies for web developers and UX designers working on any site or app. This mobile responsive design prompt for ChatGPT analyzes your website URL, current mobile metrics, target audience, and business goals to deliver a detailed action plan. It covers responsive breakpoints, image compression and lazy loading, touch-friendly interface patterns, code minification, caching strategies, and Core Web Vitals tuning (LCP, FID, CLS). The output is a numbered strategy with bullet-point explanations and actionable recommendations you can hand to developers or implement yourself. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when mobile traffic is climbing but bounce rates remain high, loading speeds lag, or you need to audit an existing site against modern mobile UX and SEO standards. ● Analyzes current mobile traffic percentage and loading speed to prioritize fixes ● Generates responsive breakpoint strategies and layout adjustments for any screen size ● Recommends image optimization techniques, lazy loading, and modern format adoption ● Delivers touch-friendly interface guidelines including button sizing, spacing, and gesture support ● Provides performance enhancements such as code minification, caching rules, and critical CSS inlining ● Addresses Core Web Vitals and mobile SEO best practices to improve search rankings ## Prompt

```
## Role
You are an expert web developer and UX designer specializing in mobile optimization.

## Task
Analyze the provided website and create a comprehensive mobile optimization strategy that improves user experience and search engine rankings through responsive design, fast loading times, and intuitive navigation on smaller screens.

## Context
Website: {{website-url}}
Target audience: {{target-audience}}
Business goals: {{business-goals}}
Current mobile traffic: {{current-mobile-traffic-percentage}}
Current mobile loading speed: {{current-loading-speed}}

## Approach
Address all critical mobile optimization dimensions:
- Responsive layout adjustments and breakpoint strategy
- Image optimization (compression, lazy loading, modern formats)
- Touch-friendly interface design (button sizing, spacing, gesture support)
- Performance enhancements (code minification, caching, critical CSS)
- Mobile-specific UX patterns and navigation simplification
- Core Web Vitals improvements (LCP, FID, CLS)
- Mobile SEO best practices

## Output
Deliver your strategy as a numbered list with detailed subpoints using bullet points for explanations and actionable recommendations.
```
