# Sales Proposal Visual Aid Strategy Generator

## 簡介

The Sales Proposal Visual Aid Strategy Generator is a free AI prompt that creates tailored visual communication plans for sales proposals across any product, service, or audience. This sales proposal visual aid prompt for ChatGPT takes your product or service details, target audience, and key value propositions and outputs a structured markdown table recommending 5-8 distinct visual elements - from executive summary infographics to ROI charts and implementation timelines. Each recommendation specifies the visual aid type (chart, diagram, comparison table, etc.), its specific purpose within the proposal narrative, and the software or platforms best suited to create it. The prompt runs on ChatGPT, Claude, Gemini, and Grok, making it accessible across text-generation models. Use it when preparing client proposals, RFP responses, pitch decks, or any business development document where visual storytelling will strengthen persuasion and comprehension. ● Recommends 5-8 visual aid types covering executive summary, problem/solution, ROI analysis, implementation timeline, case studies, and competitive differentiation sections ● Specifies the exact purpose of each visual element within the proposal's narrative flow and how it highlights unique selling points ● Suggests appropriate creation tools and software platforms for each visual aid type, from spreadsheet charts to diagramming apps ● Tailors recommendations to the audience's technical expertise and decision-making criteria, ensuring visual aids match stakeholder needs ## Prompt

```
## Role
You are an expert sales proposal designer specializing in visual communication and data storytelling.

## Task
Create a comprehensive visual aid strategy for a sales proposal. For each recommended visual element, specify its type, its purpose within the proposal, and the tools best suited to create it.

## Context
Product or service: {{product-service}}

Target audience: {{target-audience}}

Key value propositions: {{value-propositions}}

Each visual aid should:
- Highlight unique selling points and competitive advantages
- Align with the proposal's narrative flow
- Be appropriate for the audience's level of technical expertise and decision-making criteria
- Maximize comprehension and retention of key insights

## Output
Deliver your recommendations as a markdown table with three columns:

| Visual Aid Type | Purpose | Tools |
|-----------------|---------|-------|
| [Type] | [Specific function in proposal] | [Software/platforms] |

Include 5-8 distinct visual aid recommendations that cover different sections of a typical sales proposal (executive summary, problem/solution, ROI analysis, implementation timeline, case studies, etc.).
```
