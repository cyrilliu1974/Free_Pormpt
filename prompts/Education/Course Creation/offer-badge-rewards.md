# Badge Reward System Designer for Educational Games

## 簡介

The Badge Reward System Designer for Educational Games is a free AI prompt that builds a complete gamification framework for educators, instructional designers, and course creators who want to motivate learners through achievement recognition. This badge reward system prompt for ChatGPT works by analyzing your subject matter, target age range, and learning environment to generate a balanced progression of milestones paired with creative, age-appropriate badge names and meaningful rewards. It runs on ChatGPT, Claude, Gemini, and Grok, delivering output as a markdown table with three columns: Badge Name, Milestone, and Reward. The prompt applies motivation psychology principles to ensure each badge marks genuine skill advancement rather than arbitrary checkpoints, making it ideal for online courses, classroom gamification, training programs, and self-paced learning platforms. Reach for this prompt when you need to transform a curriculum into an engaging progression system that balances challenge with achievability and reinforces intrinsic motivation at every level. ● Maps subject-specific learning objectives to tangible milestones that mark real skill progression ● Generates memorable, aspirational badge names tailored to the age range and cultural context of your learners ● Suggests rewards that encourage continued learning without relying on extrinsic prizes ● Outputs a clean markdown table format that integrates directly into learning management systems and course platforms ## Prompt

```
## Role
You are an expert educational game designer specializing in gamified learning systems and motivation psychology.

## Task
Design a badge reward system that recognizes educational milestones and motivates continued learning. Create a progression that balances challenge with achievability, using creative badge names that resonate with the target audience.

## Context
Subject: {{subject}}
Target audience: {{age-range}}
Learning environment: {{learning-environment}}
Number of badge levels: {{badge-levels}}

## Process
1. Identify key learning objectives and skill progressions within the subject
2. Map meaningful milestones that mark genuine achievement
3. Create badge names that are memorable, aspirational, and age-appropriate
4. Assign rewards that reinforce intrinsic motivation and encourage next steps
5. Ensure the progression curve maintains engagement without overwhelming learners

## Output
Deliver your badge system as a markdown table with three columns:

| Badge Name | Milestone | Reward |
|------------|-----------|--------|
| ... | ... | ... |
```
