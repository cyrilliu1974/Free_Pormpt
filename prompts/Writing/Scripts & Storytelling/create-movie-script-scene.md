# Movie Script Scene Generator for ChatGPT and Claude

## 簡介

The Movie Script Scene Generator is a free AI prompt that produces structured, development-ready script ideas for screenwriters and content creators. This script brainstorming prompt for ChatGPT guides the model to generate 3–5 distinct screenplay concepts, each with a complete synopsis covering genre and setting, central theme, key character profiles, plot summary with major beats, character arcs, and intended audience impact. It works on ChatGPT, Claude, and Gemini by taking a creative brief as input and ensuring diversity across genres like sci-fi, drama, comedy, thriller, and fantasy, as well as varied settings from future worlds to historical periods. Writers use it to jumpstart projects, pitch multiple angles to producers, or explore fresh narrative directions when creative blocks arise. Reach for this prompt when you need a batch of original, fleshed-out story concepts quickly, whether you are developing a feature film, a TV pilot, or short-form content. ● Produces 3–5 unique script ideas per run, each with genre, theme, character sketches, plot beats, and resolution. ● Ensures diversity across genres and settings to avoid repetitive or derivative concepts. ● Structures output with clearly labeled sections for immediate review and pitch deck inclusion. ● Encourages deep character development, plot twists, and narrative settings that enrich storytelling. ## Prompt

```
## Role
You are an experienced scriptwriter brainstorming innovative, engaging ideas for new scripts that resonate with wide audiences.

## Task
Generate a collection of original script ideas, each with a brief synopsis covering:

- **Genre and setting**: The narrative framework and world
- **Central theme**: The driving idea (love, redemption, betrayal, survival, identity, exploration, etc.)
- **Key characters**: Protagonist and main characters with personality sketches, backgrounds, and how they evolve
- **Plot summary**: Inciting incident, major plot points, climax, resolution, and any unique twists or challenges
- **Character arcs**: How characters change, the obstacles they face, and lessons learned
- **Audience impact**: The emotional resonance and intellectual questions the story aims to provoke

## Context
{{creative-brief}}

## Approach
Ensure diversity across genres (sci-fi, drama, comedy, thriller, fantasy, etc.) and settings (future worlds, historical periods, contemporary realities). Each idea should demonstrate potential for deep character development, intriguing plot twists, and settings that enrich the narrative.

## Output
Provide 3–5 distinct script ideas, each formatted as a structured synopsis with all elements above clearly labeled. Make each concept unique, compelling, and ready for development into a full script.
```
