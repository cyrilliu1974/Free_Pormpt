# Mobile SEO Technical Audit Prompt for ChatGPT

## 簡介

The Mobile SEO Technical Audit Prompt for ChatGPT is a free AI prompt that delivers a comprehensive mobile-friendliness analysis and actionable optimization roadmap for websites. This mobile SEO technical audit prompt for ChatGPT guides you through a complete evaluation of responsive design implementation, viewport configuration, touch element sizing, page load performance, Core Web Vitals, mobile-specific meta tags, structured data, and mobile user experience factors. The prompt produces a structured technical report with an executive summary, severity-ranked audit findings for each technical area, and a prioritized optimization roadmap that includes specific implementation steps, effort estimates, and expected performance improvements. Website owners, SEO specialists, and developers use it to identify critical mobile usability issues and create data-driven action plans that improve search rankings and mobile user engagement. It runs on ChatGPT, Claude, and Gemini. Reach for this prompt when you need a systematic technical assessment of mobile SEO readiness or when preparing to optimize a site for mobile-first indexing. ● Audits responsive design, viewport settings, touch targets, and mobile layout implementation ● Analyzes Core Web Vitals, resource optimization, and render-blocking issues affecting mobile load speed ● Evaluates mobile-specific technical elements including meta tags, structured data, and sitemap configuration ● Delivers a prioritized optimization roadmap with severity rankings, implementation steps, effort estimates, and expected impact for each recommendation ## Prompt

```
## Role
You are an expert SEO specialist focusing on technical mobile optimization.

## Task
Analyze the provided website and deliver a comprehensive mobile SEO audit with actionable recommendations. Cover:

- **Mobile-friendliness assessment**: responsive design implementation, viewport configuration, touch element sizing
- **Page load performance**: Core Web Vitals, resource optimization, render-blocking issues
- **Mobile-specific technical elements**: mobile meta tags, structured data, mobile-sitemap configuration
- **User experience factors**: navigation patterns, content readability, interaction design

Develop a prioritized optimization strategy for each identified issue, with implementation guidance and expected impact.

## Context
**Website**: {{website-url}}

**Business context**: {{business-context}}

## Output
Deliver a structured technical report with:

### Executive Summary
Current mobile performance snapshot and top 3 priorities

### Audit Findings
For each technical area, document:
- Current state
- Identified issues (severity-ranked)
- Performance metrics

### Optimization Roadmap
For each recommendation:
- Specific technical change required
- Implementation steps
- Expected performance improvement
- Effort estimate

### Appendix
- Tool recommendations for ongoing monitoring
- Testing checklist

Use clear headings, bullet points, and tables where appropriate for actionable readability.
```
