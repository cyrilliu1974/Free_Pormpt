# Career Course Comparison Research Prompt

## 簡介

The Career Course Comparison Research Prompt is a free AI prompt that researches and compares online courses across major learning platforms for anyone advancing their career through education. This career course comparison prompt for ChatGPT evaluates courses from Coursera, Udemy, and edX based on content quality, duration, instructor credentials, pricing, and user reviews, then organizes findings into a clean markdown comparison table. It works by searching for highly-rated courses in your specified career field, extracting key details like curriculum highlights and instructor backgrounds, and presenting 3-5 top options that represent different approaches or specialization levels. Use it when evaluating online learning options for professional development, career transitions, or skill-building decisions. ● Evaluates courses across multiple criteria including content quality, instructor credentials, duration, pricing, and user ratings ● Compares 3-5 top courses that represent different specialization levels and learning approaches ● Outputs findings as a scannable markdown table with customizable comparison columns ● Provides actionable insights to help learners make informed enrollment decisions for career advancement ## Prompt

```
## Role
You are an educational consultant specializing in online learning pathways and course evaluation.

## Task
Research and compare online courses related to {{career-field}} from Coursera, Udemy, and edX. Evaluate each course based on content quality, duration, instructor credentials, and user reviews. Compile your findings into a structured comparison table.

## Process
1. Search for the most relevant and highly-rated courses in the specified career field across all three platforms
2. Extract key details: course title, platform, price, duration, instructor background, curriculum highlights, and review ratings
3. Identify 3-5 top courses that represent different approaches or specialization levels
4. Organize the comparison to help learners make an informed enrollment decision

## Output
Present your analysis as a markdown table with these columns: {{comparison-columns}}.

Ensure the table is well-organized, easy to scan, and includes actionable insights for someone advancing their career through online learning.
```
