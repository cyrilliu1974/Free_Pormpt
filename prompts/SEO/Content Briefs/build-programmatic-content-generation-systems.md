# Programmatic SEO Content System Builder

## 簡介

The Programmatic SEO Content System Builder is a free AI prompt that creates comprehensive implementation plans for scaling SEO content strategies across websites and industries. This programmatic SEO prompt for ChatGPT guides you through building an entire content generation framework, from keyword research and dependency grammar-based structure optimization to user intent mapping and competitive analysis. It runs on ChatGPT, Claude, and Gemini, producing a seven-step implementation roadmap that covers keyword opportunities, on-page best practices, schema markup, internal linking architecture, templating systems, quality checkpoints, and measurement cycles. Digital marketing agencies use it to design repeatable content workflows for clients, while in-house SEO teams apply it to scale content production without sacrificing relevance or search performance. Reach for this prompt when you need a strategic blueprint for generating high-volume, algorithmically optimized content that aligns with user intent and outperforms competitors in organic search. ● Conducts keyword research with long-tail opportunities, search volume insights, and competitive gap analysis ● Applies dependency grammar principles to structure content for clarity, crawlability, and user engagement ● Maps user intent across informational, transactional, and navigational queries to guide content type selection ● Delivers templating frameworks and quality control checkpoints to maintain consistency at scale ## Prompt

```
## Role
You are an expert SEO content strategist designing a programmatic content generation system.

## Task
Create a comprehensive SEO strategy to improve search engine rankings and drive organic traffic for {{website-url}}. Structure your approach using dependency grammar principles to optimize for target keywords, user intent, and search algorithms.

## Context
- **Industry**: {{industry}}
- **Target audience**: {{target-audience}}
- **Primary keywords**: {{primary-keywords}}
- **Main competitors**: {{competitors}}

## Output
Deliver a step-by-step implementation plan as a numbered list covering:

1. **Keyword Research** – Analysis of primary keywords, long-tail opportunities, search volume, and competitive gaps
2. **Content Structure Optimization** – Dependency grammar application, heading hierarchy, internal linking architecture
3. **User Intent Mapping** – Alignment of content types (informational, transactional, navigational) to keyword clusters
4. **On-Page SEO Best Practices** – Meta elements, schema markup, content depth, readability optimization
5. **Content Generation System** – Templating approach, scalability framework, quality control checkpoints
6. **Competitive Differentiation** – Strategies to outperform competitor content based on analysis
7. **Measurement & Iteration** – KPIs, tracking setup, optimization cycles

For each numbered step, provide specific, actionable tactics tailored to the industry and audience context provided.
```
