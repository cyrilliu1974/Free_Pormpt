# BARS Appraisal Form Generator for Performance Reviews

## 簡介

The BARS Appraisal Form Generator is a free AI prompt that creates objective performance evaluation frameworks using Behaviorally Anchored Rating Scales methodology for HR professionals, organizational psychologists, and performance management teams. This performance review prompt for ChatGPT, Claude, Gemini, and Grok produces ready-to-use appraisal forms that replace subjective judgment with measurable behavioral indicators. It defines critical competencies for any job role, then builds 5-7 performance levels - from exceptional to needs improvement - each anchored with concrete workplace scenarios and observable actions. The result is a structured evaluation tool that multiple managers can apply consistently, because every rating level describes specific behaviors that can be verified rather than interpreted. Use it when designing performance reviews for new roles, standardizing evaluation criteria across departments, or eliminating rater bias in existing appraisal systems. ● Defines job-specific competencies with clear relevance statements tied to performance outcomes. ● Creates seven-level rating scales where each level describes observable behaviors and measurable results, not personality traits. ● Ensures evaluator consistency by anchoring ratings to concrete workplace scenarios that different managers interpret the same way. ● Includes implementation guidance to help managers apply the form correctly during evaluation sessions. ## Prompt

```
## Role
You are an organizational psychologist and performance evaluation specialist with expertise in Behaviorally Anchored Rating Scales (BARS) methodology. You design assessment frameworks that replace subjective judgment with observable, measurable behavioral indicators.

## Task
Create a comprehensive BARS appraisal form for {{job-role}}. The form must:
- Identify and define critical competencies that directly impact performance outcomes
- Provide 5-7 performance levels for each competency, from exceptional to needs improvement
- Anchor each level with specific, observable behavioral examples (not personality traits or vague qualities)
- Include measurable outcomes and real workplace scenarios
- Enable consistent application across different employees and managers

## Context
{{organizational-context}}

The evaluation framework should eliminate ambiguity and subjective bias by describing concrete actions managers can observe and verify. Each behavioral anchor must be specific enough that multiple evaluators would reach the same conclusion when observing the same behavior.

## Output
Deliver a ready-to-use appraisal form structured as:

**[Competency Name]**  
*Definition and relevance to role*

- **Level 7 (Exceptional):** [Specific behavioral description with measurable outcomes]  
- **Level 6 (Exceeds Expectations):** [Specific behavioral description with measurable outcomes]  
- **Level 5 (Fully Meets):** [Specific behavioral description with measurable outcomes]  
- **Level 4 (Meets Most):** [Specific behavioral description with measurable outcomes]  
- **Level 3 (Partially Meets):** [Specific behavioral description with measurable outcomes]  
- **Level 2 (Needs Improvement):** [Specific behavioral description with measurable outcomes]  
- **Level 1 (Unsatisfactory):** [Specific behavioral description with measurable outcomes]  

Repeat this structure for each competency. Include implementation guidance for managers at the end.
```
