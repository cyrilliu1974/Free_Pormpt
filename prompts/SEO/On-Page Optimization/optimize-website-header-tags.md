# Website Header Tag SEO Audit and Optimization

## 簡介

The Website Header Tag SEO Audit and Optimization is a free AI prompt that analyzes header tag structure across a website and generates actionable SEO improvement recommendations for digital marketers, SEO analysts, and web developers. This header tag optimization prompt for ChatGPT evaluates all H1, H2, H3, and nested header elements on a given website URL, scoring each tag's keyword optimization on a 1-5 scale and mapping the logical hierarchy of content. It delivers a structured audit table showing current headers, their locations, keyword scores, and tailored improvement suggestions, followed by an optimized header structure with expected SEO impact for each change. The prompt runs on ChatGPT, Claude, Gemini, and Grok, making it accessible across major text-generation models. Real-world use cases include auditing client websites before SEO campaigns, diagnosing ranking drops tied to poor header structure, and ensuring new site launches follow header tag best practices. Reach for this prompt when you need a systematic, repeatable process to evaluate header tags rather than manual page-by-page inspection. ● Scores every header tag on keyword optimization (1-5 scale) so you know which headers need the most attention ● Maps header hierarchy to identify structural gaps, missing H2s under H1s, or illogical nesting that confuses crawlers ● Generates an optimized header structure table with rewritten text and expected SEO impact for each change ● Includes additional SEO considerations tailored to the specific website's content and technical setup ## Prompt

```
## Role

You are an expert SEO analyst and web developer specializing in header tag structure analysis and search engine optimization.

## Task

Audit the header tags (H1, H2, H3, etc.) on the provided website and deliver actionable recommendations to improve search engine rankings.

## Analysis Requirements

1. **Examine current header tags** across the website, evaluating:
   - Keyword usage and relevance
   - Hierarchical structure and logical flow
   - Overall SEO effectiveness

2. **Rate optimization quality** using a Keyword Optimization Score (1-5 scale) for each header tag

3. **Tailor recommendations** specifically to the website's content and structure—avoid generic advice

4. **Prioritize high-impact changes** that will most effectively improve SEO performance

## Output

Deliver your analysis in the following structured format:

**Website URL:** {{website-url}}

### Header Tag Analysis

| Current Header Tag | Location on Page | Current Text | Keyword Optimization Score (1-5) | Suggested Improvements |
|-------------------|------------------|--------------|----------------------------------|------------------------|
| [Create a row for each header tag found] |||||

### Header Tag Hierarchy Recommendations

- [List specific recommendations for improving header tag structure and hierarchy]

### Optimized Header Tag Structure

| Optimized Header Tag | Location on Page | Optimized Text | Expected SEO Impact |
|---------------------|------------------|----------------|---------------------|
| [Create a row for each optimized header tag] ||||

### Additional SEO Considerations

- [List relevant best practices and considerations specific to this website's header tag implementation]
```
