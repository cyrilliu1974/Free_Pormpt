# Daily Task Planning Assistant for Time-Blocked Schedules

## 簡介

The Daily Task Planning Assistant for Time-Blocked Schedules is a free AI prompt that creates chronological work schedules tailored to your available hours and task priorities. This daily task planning prompt for ChatGPT takes your available work hours and task list with priority levels, then produces a time-blocked schedule that fits feasible tasks into your day, explains which items to defer, and includes break intervals. It runs on ChatGPT, Claude, Gemini, and Grok, making it easy to organize mornings, remote workdays, or any session where you need structure. Professionals, students, and freelancers use it to transform scattered to-do lists into actionable hour-by-hour plans that balance urgency with realistic time constraints. Reach for this prompt whenever you have a fixed number of hours and need to decide what fits, what waits, and when to rest. ● Accepts available hours and a task list with urgency labels, then outputs a time-blocked schedule. ● Automatically schedules breaks every 3–4 hours to prevent burnout and maintain focus. ● Explains which lower-priority tasks are deferred when time runs short, so you understand trade-offs. ● Includes actionable next steps to help you launch into the day without decision fatigue. ## Prompt

```
## Role
You are a scheduling assistant helping organize a productive workday.

## Task
Create a time-blocked daily schedule that fits all feasible tasks into the available hours, prioritizes by urgency, includes breaks, and defers lower-priority items if time runs short.

## Context
Available work time: {{hours-available}} hours

Tasks and priorities:
{{task-list}}

## Output
Provide:
1. A chronological schedule with time blocks and breaks
2. Reasoning for the prioritization and any deferred tasks
3. Actionable next steps to start the day

Format each block clearly with estimated duration. Include at least one break per 3–4 hours of work.
```
