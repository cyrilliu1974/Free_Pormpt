# Data Analysis Learning Path Generator

## 簡介

The Data Analysis Learning Path Generator is a free AI prompt that creates personalized 6-month roadmaps to transform beginners into job-ready data analysts. This data analysis learning path prompt for ChatGPT, Claude, Gemini, and Grok builds a week-by-week curriculum tailored to your starting skill level, available study hours, and career goals. It maps a progression from foundational statistics and Excel through advanced Python, R, and SQL, incorporating hands-on projects with real datasets, core techniques like descriptive statistics and predictive modeling, data visualization mastery, portfolio development with case studies, and interview preparation strategies. Each week includes learning objectives, key concepts, exercises, recommended resources, and assessment checkpoints. The prompt also adds gamification elements - points, levels, and progress tracking - to maintain momentum throughout the six-month journey. Use this prompt when you need a realistic, actionable study plan that accounts for your constraints and guides you through technical skills, practical application, and career readiness in a single cohesive timeline. ● Adapts to your current skill level, weekly study time, and specific learning goals ● Covers foundational statistics, Excel, Python, R, SQL, visualization tools, and real-world analysis techniques ● Includes hands-on projects, portfolio case studies, and interview preparation at each stage ● Provides gamified progress tracking with points, levels, and achievement milestones to sustain motivation ## Prompt

```
## Role
You are an expert data analysis educator and curriculum designer who has trained hundreds of successful analysts. Design a structured, comprehensive 6-month learning path that takes someone from their starting point to job-ready data analyst.

## Task
Create a complete step-by-step learning roadmap covering:

- Foundational prerequisites (statistics, Excel)
- Progressive technical skill building (Python, R, SQL)
- Hands-on projects with real datasets
- Core analysis techniques: descriptive statistics, trend analysis, cohort analysis, funnel analysis, predictive modeling
- Data visualization mastery
- Portfolio development with case studies
- Interview preparation strategies
- Weekly milestones with clear assessments
- Recommended resources and tools for each stage
- Troubleshooting common learning obstacles
- Specific timeframes for each focus area

## Context
Starting skill level: {{current-skill-level}}
Available study time: {{hours-per-week}} hours per week
Primary learning goal: {{learning-goal}}

## Output
Structure the learning path as:

🎓 **Month X: [Theme]**
X️⃣ **Week X-X: [Topic]**
- Learning objectives
- Key concepts and tools
- Hands-on exercises/projects
- Resources
- Assessment checkpoint

Include gamification elements to track progress:
🏆 Task Completed! Earned X points.
Current Level: [Level Name]
Next Level: [Next Level Name] (X points away)

End with a summary highlighting what each month delivers and how skills compound toward job-readiness.
```
