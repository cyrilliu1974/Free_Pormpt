# Website Link Maintenance and Broken Link Repair System

## 簡介

The Website Link Maintenance and Broken Link Repair System is a free AI prompt that builds a complete automated system for identifying, prioritizing, and fixing broken links on any website. This technical SEO prompt for ChatGPT creates a six-part management framework: an initial audit plan with spreadsheet documentation, a 1-5 priority scoring system based on traffic and page prominence, automated monitoring configuration tailored to your existing tools, a four-week maintenance schedule with time estimates, SEO impact tracking across crawl errors and organic traffic metrics, and a quarterly review process for continuous improvement. The prompt runs on ChatGPT, Claude, Gemini, and Grok, adapting its recommendations to whatever link-checking tools and plugins you already have installed. Marketing teams use it to maintain site health after migrations; developers use it to prevent 404 errors from eroding domain authority; SEO specialists use it to automate what would otherwise be manual monthly audits. Reach for this prompt when you need a structured, repeatable process for link maintenance that fits your current tech stack and requires minimal ongoing manual effort. ● Produces a documented audit plan with spreadsheet columns for broken link URL, referring page, HTTP status code, and suggested fix ● Assigns priority scores (1-5) based on page prominence, referral traffic volume, and SEO impact with clear scoring criteria ● Configures automated monitoring with scan frequency, notification thresholds, and alert setup for critical breaks ● Establishes a four-week maintenance routine with specific weekly tasks, time estimates, and responsible actions ● Defines monthly SEO tracking metrics including crawl errors, organic traffic recovery, page authority, and user engagement ● Includes a quarterly review process to evaluate new link management tools and best practices ## Prompt

```
## Role
You are an expert website maintainer and SEO specialist with comprehensive knowledge of link monitoring, repair, and optimization tools and techniques.

## Task
Develop a robust, efficient system for identifying and repairing broken links on the user's website, ensuring optimal user experience and search engine performance. Focus on automation using cutting-edge tools and plugins, with clear instructions for implementation and ongoing maintenance.

## Context
Website URL: {{website-url}}
Available tools and plugins: {{tools-and-plugins}}

## Output
Deliver a complete broken link management system structured as follows:

### 1. Initial Audit Plan
Conduct a thorough audit to identify all broken links. Record results in a spreadsheet with these columns:
- Broken Link URL
- Referring Page URL
- HTTP Status Code
- Suggested Fix

Specify which tools from the available toolkit will be used for the audit and how to configure them.

### 2. Prioritization Framework
Assign each broken link a priority score from 1-5 (1 = highest) based on:
- Prominence on page (homepage, navigation, footer vs. buried content)
- Referral traffic volume
- SEO impact (authority of linking pages, keyword relevance)

Provide clear criteria for each priority level.

### 3. Automated Monitoring Setup
Recommend specific configuration for ongoing link monitoring using the available tools and plugins:
- Tool/plugin selection and justification
- Configuration settings (scan frequency, notification thresholds, exclusions)
- Alert setup for immediate attention to critical breaks

### 4. Monthly Maintenance Routine
Establish a structured 4-week schedule:
- Week 1: [specific tasks]
- Week 2: [specific tasks]
- Week 3: [specific tasks]
- Week 4: [specific tasks]

Include time estimates and responsible actions for each task.

### 5. SEO Impact Monitoring
Define key metrics to track monthly:
- Crawl errors and index coverage
- Organic traffic to previously broken pages
- Page authority and backlink health
- User engagement metrics (bounce rate, time on page)

Specify which tools to use for each metric and how to compile monthly reports.

### 6. Continuous Improvement
Outline a quarterly review process to evaluate new tools, plugins, and best practices for link management, with criteria for deciding when to adopt new solutions.

Format the entire response using clear markdown with headers, numbered lists, and bullet points. Provide actionable, specific guidance tailored to the stated tools and website.
```
