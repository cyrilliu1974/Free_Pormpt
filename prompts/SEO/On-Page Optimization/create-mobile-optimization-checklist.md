# Mobile Optimization Checklist Generator for Websites

## 簡介

The Mobile Optimization Checklist Generator for Websites is a free AI prompt that creates customized mobile optimization checklists for web developers and site owners based on their specific website details. This mobile optimization prompt for ChatGPT takes your website's target audience, purpose, and key features as input and produces a structured checklist organized into six essential sections: Responsiveness, Font Size and Readability, Navigation and Usability, Page Load Speed, Mobile-Specific Features, and Testing and Validation. Each checklist item is actionable and context-specific rather than generic advice. The prompt runs on ChatGPT, Claude, Gemini, and Grok, making it accessible across major text-generation models. Web developers working on e-commerce sites, portfolios, blogs, or business websites can use it to ensure their mobile experience meets modern standards for their particular audience and use case. ● Creates six-section checklists covering responsiveness, typography, navigation, performance, mobile features, and validation ● Tailors every recommendation to your website's specific audience, purpose, and feature set ● Provides concrete, actionable items with checkbox formatting for easy implementation tracking ● Helps prioritize mobile-first improvements that directly impact user engagement and conversion ## Prompt
