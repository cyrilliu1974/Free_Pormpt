# Audience Tone Adaptation Analyzer for Copywriting

## 簡介

The Audience Tone Adaptation Analyzer for Copywriting is a free AI prompt that dissects how messaging shifts across target segments to help marketers and copywriters tailor their content for maximum resonance. This copywriting tone analysis prompt for ChatGPT takes any piece of copy and a list of audience segments, then produces a detailed breakdown for each group showing tone characteristics, key language elements, sample adapted phrases, an effectiveness score out of 10, and specific do's and don'ts. It runs on ChatGPT, Claude, and Gemini, making it ideal for content strategists who need to translate one message into multiple voices without losing its core intent. Real-world use cases include adapting product landing pages for B2B versus B2C buyers, rewriting email campaigns for different demographics, and training marketing teams on audience-specific language patterns. Reach for this prompt when you have existing copy that needs to work harder across diverse reader groups or when you need to document the tonal shifts required for multi-segment campaigns. ● Breaks down tone characteristics and language elements segment by segment, not generic advice. ● Generates concrete sample phrases showing the adapted copy in action for each audience. ● Scores messaging effectiveness per segment so you can prioritize rewrites and test assumptions. ● Provides clear do's and don'ts that function as a style guide for each target group. ## Prompt

```
## Role
You are an expert copywriting strategist who analyzes how tone, language, and phrasing adapt to engage different audience segments.

## Task
Analyze the provided copywriting content and show how to tailor it for {{audience-segments}}. For each segment, break down tone characteristics, language elements, sample phrases, effectiveness scoring, and clear do's and don'ts.

## Context
Copywriting content to analyze:
{{copywriting-content}}

## Output
For each audience segment provide:

**Segment Name:** [Name of the segment]

**Tone Characteristics:**
- [Characteristic 1]
- [Characteristic 2]
- [Characteristic 3]

**Key Language Elements:**
- [Element 1]
- [Element 2]
- [Element 3]

**Sample Phrases:**
"[Phrase 1]"
"[Phrase 2]"
"[Phrase 3]"

**Effectiveness Score:** [X]/10

**Do's:**
✅ [Do 1]
✅ [Do 2]
✅ [Do 3]

**Don'ts:**
❌ [Don't 1]
❌ [Don't 2]
❌ [Don't 3]

---

Repeat this structure for each segment. Ensure insights are specific to each segment's unique characteristics, not generic advice. Focus on actionable differences in language, tone, and phrasing that will resonate with each group.
```
