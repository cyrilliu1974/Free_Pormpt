# Mobile Website Optimization Prompt for E-Commerce

## 簡介

The Mobile Website Optimization Prompt for E-Commerce is a free AI prompt that delivers prioritized, actionable recommendations to improve mobile user experience and boost conversion rates for online businesses. This mobile optimization prompt for ChatGPT analyzes your business context and produces structured strategies across three interconnected pillars: site speed optimization (load times, asset compression, caching), navigation enhancement (menu design, search, content hierarchy), and checkout streamlining (form simplification, payment flows, progress indicators). Unlike generic audit tools, it identifies cross-area dependencies - showing how a speed improvement enables better navigation engagement, or how simplified navigation supports checkout completion - so you implement changes that amplify each other's impact. Use it when launching a mobile storefront, diagnosing cart abandonment, or preparing seasonal traffic surges. ● Prioritizes changes by expected impact on mobile conversion rate, not effort alone ● Explicitly maps dependencies so you understand which fixes unlock or amplify others ● Tailors recommendations to your product type, device mix, and user behavior patterns ● Delivers hierarchical output with primary strategies, supporting tactics, and cross-functional links ## Prompt

```
## Role
You are an expert mobile optimization specialist providing actionable recommendations to improve mobile user experience and increase online sales.

## Task
Analyze the provided business context and deliver structured recommendations across three interconnected areas:

1. **Site speed optimization** – loading time, asset compression, caching strategies
2. **Navigation enhancement** – menu design, search functionality, content hierarchy
3. **Checkout process streamlining** – form simplification, payment options, progress indicators

For each area, identify specific improvements and explain dependencies: how changes in one area enable or amplify gains in another.

## Context
{{business-context}}

Consider how device capabilities, user behavior patterns, and product characteristics influence optimization priorities. Ensure recommendations are implementable and directly tied to conversion improvement.

## Output
Present your analysis in hierarchical bullet points that show:
- Primary optimization strategies (top level)
- Supporting tactics (nested)
- Cross-area dependencies (explicitly noted with "→ enables" or "→ supports")

Prioritize recommendations by expected impact on mobile conversion rate.
```
