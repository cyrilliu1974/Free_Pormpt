# Infographic Content Layout Prompt for ChatGPT

## 簡介

The Infographic Content Layout Prompt for ChatGPT is a free AI prompt that transforms complex topics and data points into structured visual communication plans for designers, marketers, and educators. This infographic design prompt for ChatGPT guides you through information prioritization, visual element selection, hierarchy planning, and brand-consistent styling. Feed it your topic, target audience, key points, and brand guidelines, and it returns a comprehensive layout blueprint covering section structure, chart types, icon suggestions, text placement, color application, typography recommendations, and data visualization strategies. Teams use it to plan educational infographics, marketing one-pagers, social media carousels, and data-driven reports that need to communicate clearly at a glance. It runs on ChatGPT, Claude, and Gemini. Reach for this prompt when you need to convert dense information, research findings, or multi-layered concepts into a visual format before moving to design tools like Canva, Figma, or Adobe Illustrator. ● Analyzes your key points and organizes them into logical visual hierarchies that guide viewer attention from primary to supporting information ● Recommends specific chart types, icon styles, and illustration approaches matched to each data point or concept ● Provides text placement strategies for headlines, subheads, body copy, and callouts with positioning guidance ● Applies your brand colors and typography to reinforce information hierarchy while maintaining readability and visual consistency ## Prompt

```
## Role
You are an expert infographic designer creating a visually compelling, easy-to-understand presentation of complex information.

## Task
Design a detailed infographic layout that effectively communicates key ideas to the target audience through strategic visual hierarchy, data visualization, and concise messaging.

## Context
**Topic:** {{topic}}

**Target audience:** {{target-audience}}

**Key information points:** {{key-points}}

**Visual identity:** {{brand-and-color-guidelines}}

## Process
1. Analyze the topic and prioritize the most critical information from the key points
2. Select appropriate visual elements (charts, graphs, icons, illustrations) that best represent each data point
3. Structure content in a logical flow that guides the viewer's attention from primary to supporting information
4. Apply the specified color scheme and typography to enhance readability and brand consistency
5. Write concise, impactful headlines and supporting text
6. Integrate relevant statistics and data to substantiate main ideas
7. Balance the layout to avoid clutter while maintaining visual interest and white space

## Output
Provide a detailed description of the infographic layout and content including:

- **Overall structure:** sections, hierarchy, and information flow
- **Visual elements:** specific chart types, icon suggestions, illustration styles for each key point
- **Text placement:** headlines, subheads, body copy, and callouts with recommended positioning
- **Color application:** how the palette reinforces information hierarchy and brand
- **Typography recommendations:** font styles and sizes for different text levels
- **Data visualization:** how statistics and numbers are displayed

Format your response using bullet points for clarity.
```
