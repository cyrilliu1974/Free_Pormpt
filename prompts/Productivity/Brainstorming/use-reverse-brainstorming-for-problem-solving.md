# Reverse Brainstorming Prompt for Problem Solving

## 簡介

The Reverse Brainstorming Prompt for Problem Solving is a free AI prompt that systematically uncovers creative solutions by flipping problems on their head before building concrete action plans. This reverse brainstorming prompt for ChatGPT guides the model through three structured phases: first, it inverts your challenge to ask "How could we cause or worsen this problem?" to surface unconventional thinking angles; second, it translates each reversed insight into practical solutions; third, it breaks every solution into specific implementation steps. The output is a markdown table with at least five distinct idea chains, each showing the full journey from reversed problem statement through potential solutions to action items. It runs on ChatGPT, Claude, Gemini, and Grok, and accepts two variables: the problem you face and the operational context surrounding it. Reach for this prompt when conventional brainstorming feels stuck, when your team needs fresh perspectives on persistent challenges, or when you want a structured method to move from creative ideation to executable plans. ● Inverts problem statements to unlock non-obvious solution pathways that direct brainstorming often misses ● Produces a structured markdown table linking each reversed insight to actionable solutions and implementation steps ● Accommodates any industry or departmental context through flexible problem and context variables ● Delivers at least five distinct idea chains in a single run, accelerating workshop productivity ## Prompt

```
## Role
You are an expert innovation consultant facilitating a reverse brainstorming session.

## Task
Identify potential solutions for a specific problem using reverse brainstorming methodology. Work systematically through three phases:

1. **Reverse the problem statement** – Invert the challenge to ask "How could we cause or worsen this problem?" to unlock unconventional thinking angles
2. **Generate solutions** – Translate each reversed insight into concrete, actionable solutions that address the original problem
3. **Define action items** – Break down each solution into specific next steps for implementation

## Context
**Problem:** {{problem}}

**Operational context:** {{context}}

Ensure your brainstorming is comprehensive, innovative, and grounded in practical execution.

## Output
Present your analysis as a markdown table with three columns:

| Reverse Problem Statement | Potential Solutions | Action Items |
|---------------------------|---------------------|---------------|

Provide at least 5 rows of distinct brainstormed ideas, each row showing the full chain from reversed problem through to concrete actions.
```
