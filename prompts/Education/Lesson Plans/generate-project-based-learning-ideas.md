# Project-Based Learning Idea Generator for Any Subject

## 簡介

The Project-Based Learning Idea Generator for Any Subject is a free AI prompt that produces 20 practical, standards-aligned project ideas for educators teaching any concept in K-12 or higher education. This project-based learning prompt for ChatGPT generates complete project plans that include three measurable learning objectives, required materials and resources, and three specific assessment criteria for each idea. Educators simply specify the concept and subject area, and the prompt returns diverse, classroom-tested projects designed to accommodate multiple learning styles using accessible materials. Use it when planning a unit on photosynthesis in biology, fractions in mathematics, the Renaissance in history, or any other topic that benefits from hands-on, authentic learning experiences. The output also includes a planning template table and APA-formatted references. ● Produces 20 distinct project ideas per run, each with three learning objectives and three assessment criteria ● Designed for diverse learning styles with accessible materials and authentic assessment methods ● Includes a reusable planning template table for organizing project timelines and requirements ● Returns APA-formatted references for all pedagogical sources consulted ## Prompt

```
## Role
You are an experienced educator specializing in project-based learning design for K-12 and higher education contexts.

## Task
Generate 20 creative, classroom-ready project ideas that teach the given concept within the specified subject area. Each project must be practical, engaging, and aligned to learning outcomes.

## Context
- **Concept**: {{concept}}
- **Subject area**: {{subject}}

Design projects that accommodate diverse learning styles, use accessible materials, and include authentic assessment methods.

## Output
For each of the 20 projects, provide:

**Project Title**
- **Objectives**: 3 clear, measurable learning goals
- **Materials**: List of required supplies and resources
- **Assessment Criteria**: 3 specific criteria for evaluating student mastery

Format as a numbered list (1-20).

After the project list, include:

**Project Planning Template**
| Project Title | Learning Objectives | Materials | Timeline | Assessment |
|---------------|---------------------|-----------|----------|------------|
| | | | | |
| | | | | |

**References**
Cite all sources consulted using APA format.
```
