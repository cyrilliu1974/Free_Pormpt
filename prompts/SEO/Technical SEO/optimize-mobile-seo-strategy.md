# Mobile SEO Audit and Optimization Strategy Prompt

## 簡介

The Mobile SEO Audit and Optimization Strategy Prompt is a free AI prompt that audits websites for mobile performance and delivers actionable recommendations aligned with Google's mobile-first indexing standards. It analyzes page load speeds, responsive design implementation, tap target sizing, viewport configuration, and structured data to identify specific improvements that boost mobile search performance and user experience. This mobile SEO prompt for ChatGPT walks through a structured audit framework covering current mobile analysis (3G load times, font legibility, intrusive interstitials), page speed optimizations, responsive design improvements, mobile UX enhancements, and a mobile-first indexing compliance checklist. Technical SEO professionals, web developers, and digital marketers use it to receive website-specific recommendations rather than generic advice, making it effective for e-commerce sites, local businesses, and content publishers that need to meet Google's mobile requirements. The prompt runs on ChatGPT, Claude, Gemini, and Grok. ● Evaluates seven core mobile factors including 3G load speed, responsive design status, tap target sizing, font legibility, viewport configuration, interstitials, and structured data ● Produces prioritized page speed optimizations, responsive design improvements, and mobile UX enhancements tailored to the specific URL provided ● Includes a mobile-first indexing compliance checklist aligned with current Google standards for technical SEO audits ● Outputs a structured analysis with clear sections for diagnosis, recommendations, and implementation priorities ## Prompt

```
## Role
You are an expert mobile optimization strategist with deep knowledge of Google's mobile-first indexing standards and responsive web design best practices.

## Task
Audit {{website-url}} and develop a comprehensive mobile optimization strategy. Provide specific, actionable recommendations to improve mobile user experience and search performance. Prioritize the most impactful optimizations aligned with current Google mobile-first indexing requirements.

## Output
Deliver your analysis in the following structure:

**Current Mobile Analysis**
- Page load speed on 3G: [X.X seconds]
- Responsive design: [Yes/No]
- Tap targets: [Appropriately sized/Too small]
- Font sizes: [Legible on mobile/Too small]
- Mobile viewport configured: [Yes/No]
- Intrusive interstitials: [None/Pop-ups present]
- Mobile structured data: [Implemented correctly/Missing/Errors]

**Page Speed Optimizations**
1. [Optimization 1]
2. [Optimization 2]
3. [Optimization 3]

**Responsive Design Improvements**
- [Improvement 1]
- [Improvement 2]
- [Improvement 3]

**Mobile UX Enhancements**
• [Enhancement 1]
• [Enhancement 2]
• [Enhancement 3]

**Mobile SEO Recommendations**
→ [Recommendation 1]
→ [Recommendation 2]
→ [Recommendation 3]

**Mobile-First Indexing Checklist**
☑️ [Requirement 1]
☑️ [Requirement 2]

Avoid generic advice. Tailor all recommendations to the specific website provided.
```
