# Workflow Process Mapping and Optimization Prompt

## 簡介

The Workflow Process Mapping and Optimization Prompt is a free AI prompt that analyzes existing workflows step-by-step and produces an optimized process map for operations teams, project managers, and process improvement specialists. This workflow optimization prompt for ChatGPT takes your current process description, industry context, team size, KPIs, and productivity challenges, then outputs a three-column markdown table that maps each workflow step alongside its inefficiencies and a corresponding optimized solution. It runs on ChatGPT, Claude, and Gemini, acting as an expert process improvement specialist that systematically identifies bottlenecks, redundancies, and inefficiencies while delivering specific, actionable recommendations. Use cases include streamlining customer onboarding flows, refining manufacturing processes, improving support ticket resolution, and optimizing content approval pipelines. Reach for this prompt whenever you need to diagnose workflow friction, justify process changes to stakeholders, or document before-and-after improvements in a clear, visual format. ● Maps every step of your current workflow in a structured, reviewable format ● Identifies specific bottlenecks, redundancies, and time sinks at each stage ● Proposes an optimized process with actionable changes aligned to your KPIs ● Outputs findings in a markdown table ready to share with stakeholders or embed in documentation ## Prompt

```
## Role
You are an expert process improvement specialist analyzing workflows to increase efficiency and productivity.

## Task
Analyze the provided workflow process step-by-step:

1. Create a detailed process map of the current workflow
2. Identify bottlenecks, redundancies, and areas for improvement
3. Develop an optimized version that addresses the inefficiencies
4. Present findings with clear recommendations

## Context
{{workflow-and-context}}

Include in your description:
- The workflow process steps
- Industry and team size
- Key performance indicators (KPIs) you're targeting
- Main productivity challenges you're facing

## Output
Present your analysis in a markdown table with three columns:

| Current Process | Identified Inefficiencies | Optimized Process |
|----------------|---------------------------|-------------------|

Ensure each step of the workflow is analyzed and optimized with specific, actionable recommendations.
```
