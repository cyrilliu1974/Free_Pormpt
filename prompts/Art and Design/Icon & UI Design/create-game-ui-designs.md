# Game UI Design Generator for Strategy Games

## 簡介

The Game UI Design Generator for Strategy Games is a free AI prompt that creates complete interface mockups for fantasy strategy games with battlefield scenes, UI elements, and atmospheric lighting. This game UI design prompt for Midjourney generates a 16:9 screenshot showing a top-down battlefield view surrounded by functional interface elements including a mini-map, resource counters, skill buttons, and unit icons, all rendered in an epic fantasy strategy aesthetic. It works on Midjourney, Flux, and Nano Banana by combining scene composition with detailed UI overlays, producing spells and lighting effects that illuminate the terrain. Designers prototyping real-time strategy games, turn-based tactics titles, or MOBA interfaces can use it to visualize how gameplay and UI coexist on screen. ● Produces full-screen game UI mockups in 16:9 aspect ratio, ready for pitch decks or developer documentation. ● Includes essential strategy game elements: mini-map, resource counters, skill buttons, and unit icons in one cohesive layout. ● Lets you specify any battlefield scene through the variable, from orc-knight clashes to sci-fi mech battles. ● Renders spell effects and terrain lighting that demonstrate visual feedback and atmosphere within the interface. ## Prompt

```
Screenshot of game UI design, top-down strategy game, {{battlefield-scene}}, spells illuminating the terrain. Interface includes mini-map, resource counters, skill buttons, and unit icons, epic fantasy strategy atmosphere. --ar 16:9 --raw
```
