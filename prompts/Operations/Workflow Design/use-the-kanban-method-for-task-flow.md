# Kanban Method Implementation Guide for Workflow

## 簡介

The Kanban Method Implementation Guide for Workflow is a free AI prompt that generates a customized, step-by-step plan for adopting Kanban visual management in any team or project environment. This Kanban workflow prompt for ChatGPT produces a complete implementation roadmap covering core principles (visualize work, limit WIP, manage flow), board setup instructions for physical or digital tools, task breakdown and card creation processes, guidelines for moving work through columns with pull systems and WIP limits, and team collaboration practices including standups, metrics, and retrospectives. It runs on ChatGPT, Claude, Gemini, and Grok, adapting its guidance to your specific project type, team size, industry requirements, and existing workflow bottlenecks. Teams use it when transitioning to Kanban for the first time, optimizing an existing board structure, or training new members on visual task management principles. ● Explains the six core Kanban principles with practical application steps for your specific context ● Provides column configuration options and board setup guidance for both physical and digital environments ● Details how to size tasks, prioritize cards, enforce WIP limits, and handle blockers systematically ● Includes collaboration rituals, flow metrics, and continuous improvement practices for sustained productivity gains ## Prompt

```
## Role
You are a Kanban expert specializing in workflow optimization and visual management systems.

## Task
Create a comprehensive, step-by-step guide for implementing the Kanban Method to improve productivity. The guide should be actionable and tailored to the user's specific context.

## Context
Project/process: {{project-or-process}}
Team and workflow context: {{team-and-workflow-context}}

The user needs practical guidance that addresses their current situation, including team dynamics, industry requirements, and specific workflow bottlenecks.

## Output
Deliver a numbered list covering:

1. Core principles of the Kanban Method (visualize work, limit work-in-progress, manage flow, make policies explicit, implement feedback loops, improve collaboratively)
2. Instructions for creating a Kanban board (physical or digital setup, column configuration)
3. Process for breaking down tasks into cards (task sizing, information to include, prioritization)
4. How to move cards across the board effectively (pull system, WIP limits, handling blockers)
5. Best practices for team collaboration and continuous improvement (daily standups, metrics, retrospectives, iterative refinement)

Use sub-points with bullet points for detailed explanations, examples, and practical tips relevant to the provided context.
```
