# App Store Description Generator

## 簡介

The App Store Description Generator is a free AI prompt that writes persuasive, ASO-optimized app store copy for developers, marketers, and product teams. This app store description prompt for ChatGPT produces two deliverables: an AIDA framework breakdown showing the strategic reasoning behind each section, and a polished, copy-paste-ready description optimized for both human readers and app store algorithms. It runs on ChatGPT, Claude, Gemini, and Grok, blending conversion psychology with natural keyword integration to capture attention in the first three seconds, communicate concrete benefits, highlight differentiators with social proof, and close with urgent calls-to-action. Use it when launching a new app, refreshing stale store listings, or testing variations to improve download rates. ● Hooks users immediately with an opening line that addresses their core pain point or aspiration, not generic feature lists. ● Integrates relevant keywords naturally throughout benefit-driven copy that speaks to real-world use cases and outcomes. ● Incorporates social proof elements like testimonials, download milestones, and awards to build credibility and desire. ● Delivers both a strategic AIDA breakdown for internal review and a clean, publication-ready final description with no formatting artifacts. ## Prompt

```
## Role
App store optimization specialist and marketing copywriter with expertise in ASO algorithms, conversion psychology, and the AIDA framework.

## Task
Write a high-converting app store description that hooks users in 3–5 seconds, communicates clear value, and drives downloads through strategic keyword placement and persuasive copy.

## Context
App store users make split-second decisions. The description must work for both human readers (motivation, clarity, social proof) and algorithms (keyword relevance, engagement signals).

Structure the copy using AIDA:

- **Attention**: Open with a hook that directly addresses the target audience's primary pain point or aspiration
- **Interest**: Explain benefits (not features) in concrete, relatable terms; weave in relevant keywords naturally
- **Desire**: Highlight unique differentiators, real-world use cases, and any social proof (testimonials, download counts, awards)
- **Action**: Close with clear, urgent language that removes friction and prompts an immediate download

Emphasize transformation and specificity. Avoid jargon; prioritize readability and natural keyword integration.

{{app-brief}}
*Include: app name and category, unique value proposition, target audience, top 3–5 key features, main competitors and how you differ, any available social proof (testimonials, metrics, awards).*

## Output
Provide two blocks:

1. **AIDA Breakdown** – show your reasoning under headings (Attention / Interest / Desire / Action)
2. **Final App Store Description** – clean, copy-paste-ready text with no section labels, optimized for live publication
```
