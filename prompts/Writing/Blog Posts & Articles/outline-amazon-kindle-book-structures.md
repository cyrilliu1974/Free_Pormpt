# Kindle Book Structure Outline Generator

## 簡介

The Kindle Book Structure Outline Generator is a free AI prompt that creates detailed organizational frameworks for authors planning Writing category Kindle books. This Kindle book structure prompt for ChatGPT analyzes seven essential sections - front matter, introduction, core chapters, examples and exercises, conclusion, back matter, and supplementary content - and outputs a comprehensive table showing each section's purpose, typical length, must-have elements, optional additions, and an impact score from 1 to 10. Authors input their book topic and receive a markdown-formatted analysis that maps the optimal content architecture for their specific subject. It runs on ChatGPT, Claude, and Gemini, making it accessible across major text-generation models. This prompt is for self-publishers, first-time authors, and writing coaches who need a clear blueprint before drafting or restructuring a non-fiction Kindle book. ● Produces a 7-row by 6-column table covering every major section of a professional Kindle book ● Assigns impact scores to help authors prioritize high-value sections during writing and editing ● Distinguishes between must-have and optional elements so authors know what is essential versus nice-to-have ● Tailors recommendations to the author's specific book topic, not generic advice ## Prompt

```
## Role
You are a Kindle book structure analyst specializing in optimal content organization for Writing category books.

## Task
Generate a comprehensive 7-row × 6-column table analyzing the ideal structure for a Kindle book in the Writing category on {{book-topic}}.

## Table Structure
Create a markdown table with these columns:
- Book Section 📚
- Purpose ✍️
- Typical Length 📖
- Must-Have Elements ✍️
- Optional Elements ✍️
- Impact Score (1-10) 📚

## Requirements
- Cover all seven essential sections of a well-structured Writing category Kindle book (front matter, introduction, core chapters, examples/exercises, conclusion, back matter, and supplementary content)
- For each section, specify its purpose, typical page/word count range, required elements, nice-to-have additions, and impact score (1-10, where 10 = highest impact on book quality)
- Use emojis consistently to enhance readability and visual differentiation
- Provide clear, concise information in each cell
- Tailor recommendations to {{book-topic}}

## Output Format
Deliver the table in markdown format with proper column alignment.
```
