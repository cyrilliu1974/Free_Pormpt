# Collaborative Learning Project Outline Generator

## 簡介

The Collaborative Learning Project Outline Generator is a free AI prompt that builds complete group project frameworks for K-12 teachers and instructional designers. This collaborative learning project prompt for ChatGPT takes your subject area, grade level, class size, project duration, and learning objectives, then produces a structured outline covering project goals aligned to curriculum standards, team roles that leverage individual strengths, a milestone-driven timeline, interactive learning activities, and dual rubrics for individual and group assessment. Teachers use it to design science fair collaborations, social studies research teams, literature circles, STEM challenges, and community-based projects. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need to move from lecture-based instruction to team-based learning, when standards require collaboration skills, or when you want scaffolding that balances individual accountability with collective success. ● Aligns project goals to curriculum standards and real-world applications ● Assigns diverse team roles with clear responsibilities matched to student strengths ● Maps a realistic timeline with checkpoints, deliverables, and milestones ● Builds assessment rubrics for both individual contributions and group outcomes ## Prompt

```
## Role
You are an expert educational project designer specializing in collaborative learning experiences.

## Task
Develop a comprehensive collaborative learning project outline that engages students, fosters teamwork, and achieves clear learning objectives.

## Context
- Subject area: {{subject}}
- Grade level: {{grade-level}}
- Number of students: {{student-count}}
- Project duration: {{duration}}
- Learning objectives: {{learning-objectives}}

## Requirements
Your project outline must include:

1. **Project Goals & Standards Alignment**
   - Clear goals aligned with curriculum standards
   - Connection to real-world applications

2. **Team Structure & Roles**
   - Diverse roles that leverage individual strengths
   - Clear responsibilities for each role

3. **Timeline & Milestones**
   - Realistic schedule with key checkpoints
   - Deliverables at each milestone

4. **Interactive Learning Activities**
   - Activities that promote active participation
   - Critical thinking exercises

5. **Assessment Criteria**
   - Individual performance metrics
   - Group performance metrics
   - Rubrics for evaluation

## Output
Provide a structured outline format with main headings and subpoints for each section. Ensure the project promotes active participation, critical thinking, and real-world knowledge application.
```
