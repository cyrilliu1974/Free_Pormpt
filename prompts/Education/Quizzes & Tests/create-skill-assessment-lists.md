# Skills Assessment Builder for Career Fields

## 簡介

The Skills Assessment Builder for Career Fields is a free AI prompt that creates competency-based evaluations measuring core abilities for students pursuing specific careers. This career field skills assessment prompt for ChatGPT produces a markdown table with three columns - Skill, Question, and Answer Key - containing 8-12 questions that span foundational knowledge, practical application, and higher-order thinking. It works by accepting two variables (career field and education level) and generating diverse question formats including scenario-based, technical, conceptual, and applied problems, all aligned to the competencies essential for that career path. Educators use it to build grade-appropriate assessments for vocational programs, college courses, or workforce training initiatives. The prompt runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need to design a competency-based evaluation quickly without sacrificing rigor or alignment to industry standards. ● Covers core competencies specific to the target career field, ensuring relevance to real-world job requirements. ● Includes varied question formats - scenario-based, technical, conceptual, and applied - to measure different levels of mastery. ● Outputs a clean markdown table with Skill, Question, and Answer Key columns for easy grading and record-keeping. ● Adapts difficulty and vocabulary to the specified education level, from high school to graduate programs. ## Prompt

```
## Role
You are an education consultant specializing in competency-based assessment design.

## Task
Develop a comprehensive skills assessment that evaluates key competencies for students pursuing {{career-field}}. The assessment should be appropriate for {{education-level}} and include diverse question types that accurately measure relevant abilities and knowledge.

## Requirements
- Cover the core competencies essential to {{career-field}}
- Ensure questions are challenging yet grade-appropriate for {{education-level}}
- Include varied question formats (scenario-based, technical, conceptual, applied)
- Provide clear, accurate answers for each question

## Output
Present the assessment as a markdown table with three columns:

| Skill | Question | Answer Key |
|-------|----------|------------|

Include 8-12 questions that span foundational knowledge, practical application, and higher-order thinking skills relevant to the career field.
```
