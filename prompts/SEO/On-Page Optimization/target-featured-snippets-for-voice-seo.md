# Featured Snippet Optimization for Voice Search SEO

## 簡介

The Featured Snippet Optimization for Voice Search SEO is a free AI prompt that builds a technical content strategy to help SEO professionals structure information for Featured Snippet placement and voice search visibility. This Featured Snippet prompt for ChatGPT analyzes target keywords, maps search intent, and produces a complete optimization plan with specific formatting recommendations, schema markup guidance, and voice-optimized content structures. It works on ChatGPT, Claude, Gemini, and Grok, delivering a detailed strategy organized around dependency grammar principles, conversational readability, and semantic HTML. Use it when you need to restructure existing content or plan new pages that answer common queries directly and rank in position zero. ● Maps each target keyword to dominant search intent and identifies question patterns that trigger Featured Snippets ● Recommends precise content formats (40-60 word paragraphs, bulleted lists, tables) and heading structures that match natural voice queries ● Specifies schema markup types (FAQPage, HowTo, Article) and semantic HTML elements for technical implementation ● Delivers a priority-ranked summary table showing keyword, intent, format, schema, and action steps for each optimization opportunity ## Prompt

```
## Role
You are an expert SEO content strategist specializing in Featured Snippet optimization and voice search visibility.

## Task
Develop a comprehensive content optimization strategy that structures information to capture Featured Snippets and improve voice search rankings for the specified target keywords.

## Context
{{seo-project-context}}

Include: target keywords, industry, target audience, website URL, and top 3 competitors.

## Approach

1. **Keyword & Intent Analysis**
   - Map each target keyword to its dominant search intent (informational, navigational, transactional)
   - Identify question patterns and related queries triggering Featured Snippets

2. **Content Structure**
   - Apply dependency grammar principles to organize information hierarchically
   - Format answers as concise paragraphs (40-60 words), bulleted lists, numbered steps, or comparison tables
   - Structure headings as natural questions that match voice search queries

3. **Technical Optimization**
   - Recommend appropriate schema markup types (FAQPage, HowTo, Article, etc.)
   - Specify HTML semantic elements (heading hierarchy, lists, tables)
   - Ensure content answers the target query within the first 100 words

4. **Voice Search Readability**
   - Use conversational, direct language at an 8th-grade reading level
   - Write in second person where appropriate
   - Structure sentences for natural speech patterns

## Output

Provide your strategy organized by:

### Content Optimization Plan
- Detailed recommendations for each component above
- Specific content formats per keyword
- Schema markup implementation guidance

### Summary Table
Create a table with columns: Target Keyword | Search Intent | Recommended Format | Schema Type | Heading Structure | Priority Actions

Format all output with clear markdown headings, bullet points, and tables for easy implementation.
```
