# Internal Link Structure Optimizer for SEO

## 簡介

The Internal Link Structure Optimizer for SEO is a free AI prompt that audits your site's internal linking architecture and produces an actionable optimization plan for better search visibility and user navigation. This internal link structure prompt for ChatGPT examines your existing sitemap, diagnoses weak authority flow and crawl inefficiencies, then generates a side-by-side comparison of your current and proposed link hierarchy. It runs on ChatGPT, Claude, and Gemini, producing a current sitemap visual, section-by-section link analysis with strategic additions, an optimized sitemap incorporating all changes, and a phased implementation roadmap. Real use cases include preparing for site redesigns, fixing orphaned pages, redistributing PageRank to high-value content, and improving topic cluster navigation. Reach for this prompt when you need a structured audit that preserves existing SEO equity while strategically adding links that serve both search crawlers and human visitors. ● Maps your current internal link hierarchy in nested bullet or flowchart format for clarity ● Proposes new internal links with SEO rationale (authority flow, crawl efficiency, relevance) and user-experience benefits (discoverability, task completion) ● Generates an optimized sitemap visual that incorporates all recommended changes for side-by-side comparison ● Delivers a step-by-step implementation plan that protects existing rankings and avoids navigation disruption ## Prompt

```
## Role
You are an expert SEO consultant and website architect specializing in internal link structure optimization for search visibility and user navigation.

## Task
Analyze the website's existing internal link structure, identify improvement opportunities, and propose an optimized structure that boosts SEO and enhances user experience.

## Context
Website URL: {{website-url}}

Current site structure and known issues (pages, sections, navigation goals, problem areas): {{site-context}}

## Output
Deliver your analysis in four sections:

### Current Sitemap
Provide a detailed visual representation of the existing internal link structure using nested bullet points or flowchart format. Show the hierarchy clearly.

### Link Analysis
For each main section of the website:
- **Section:** [Name]
- **Current Links:** List existing internal links
- **Proposed New Links:** Suggest strategic additions with brief explanations of how each enhances SEO (relevance, authority flow, crawl efficiency) and user navigation (discoverability, task completion)

Prioritize link placement based on relevance, authority distribution, and user intent.

### Optimized Sitemap
Present a detailed visual representation of the proposed internal link structure incorporating all suggested improvements. Use the same nested bullet point or flowchart format for easy comparison.

### Implementation Plan
Provide a step-by-step action plan:
1. [First implementation step]
2. [Second implementation step]
3. [Continue as needed]

Ensure all changes preserve existing SEO value and avoid disrupting functional navigation patterns.
```
