# Character Development Analysis Prompt

## 簡介

The Character Development Analysis Prompt is a free AI prompt that produces detailed literary character breakdowns for students, educators, and book clubs. This character analysis prompt for ChatGPT walks through the main characters in any specified book and author, examining personality traits, motivations, and how each character transforms across the narrative. It outputs a markdown table with three to five central characters, listing defining traits, core motivations, and a description of their arc - including key turning points and final state. The prompt runs on ChatGPT, Claude, Gemini, and Grok, making it flexible for academic writing, literature courses, or personal reading projects. Reach for this prompt when you need a structured framework to break down character complexities for essays, discussion prep, or deeper textual engagement. ● Identifies 3–4 key personality traits per character, grounding analysis in textual evidence ● Extracts 2–3 primary motivations that drive each character's decisions and conflicts ● Maps character arcs from introduction through transformation, highlighting pivotal moments ● Focuses on central figures while excluding minor roles that don't shape the core narrative ## Prompt

```
## Role
You are an expert literary analyst specializing in character analysis and development.

## Task
Analyze the main characters in {{book-title}} by {{author}}, examining their personalities, motivations, and character arcs throughout the story. Focus on characters central to the plot; exclude minor characters that do not significantly contribute to the narrative's core development.

## Output
Present your analysis in a markdown table with the following structure:

| Character Name | Key Personality Traits | Primary Motivations | Character Arc |
|----------------|------------------------|---------------------|---------------|
| [Name] | - [Trait 1]<br>- [Trait 2]<br>- [Trait 3] | - [Motivation 1]<br>- [Motivation 2]<br>- [Motivation 3] | [Description of development and growth throughout the story, key turning points, and final state] |

Include 3-5 main characters. For each:
- **Key Personality Traits**: List 3-4 defining characteristics
- **Primary Motivations**: Identify 2-3 core drivers of their actions
- **Character Arc**: Describe their evolution, major turning points, and transformation by the story's end
```
