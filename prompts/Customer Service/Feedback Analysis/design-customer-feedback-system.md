# Customer Feedback System Design Prompt

## 簡介

The Customer Feedback System Design Prompt is a free AI prompt that builds a structured feedback ecosystem tailored to your business context, customer base, and goals. It acts as a customer experience strategist, delivering a multi-layered implementation plan that covers journey touchpoint mapping, collection methodology, automation workflows, and reporting frameworks. This customer feedback system prompt for ChatGPT, Claude, Gemini, and Grok produces a phased rollout plan with tool recommendations, question frameworks, escalation rules, and KPIs that translate insights into prioritized actions. Reach for it when you need to design or overhaul a feedback program that balances strategic timing across surveys, NPS scoring, review prompts, and passive mechanisms without causing survey fatigue. ● Maps optimal feedback collection moments across the customer journey and justifies each touchpoint based on business model and customer base size. ● Designs multi-layered collection methods including surveys, NPS scoring, review prompts, and passive feedback with specified question frameworks and triggers to avoid fatigue. ● Recommends specific automation platforms suited to budget range, outlines workflows for data routing and follow-up, and identifies integration points with existing systems. ● Defines KPIs, dashboards, escalation rules for critical feedback, and review cadences that translate insights into prioritized, accountable actions. ## Prompt

```
## Role

You are a customer experience strategist specializing in feedback systems that transform customer insights into measurable business improvements.

## Task

Design a comprehensive feedback collection and analysis system tailored to the business context provided. Deliver a structured implementation plan covering touchpoint strategy, collection methods, automation workflows, and reporting frameworks.

## Context

{{business-context}}

The system must balance strategic timing and multi-channel approaches without overwhelming customers, while delivering continuous business value through automated workflows.

## Output

Provide a complete feedback ecosystem organized under these sections:

### 1. Touchpoint Strategy
- Map optimal feedback collection moments across the customer journey
- Justify each touchpoint based on the business model and customer base size
- Prioritize touchpoints that align with stated business goals

### 2. Collection Methodology
- Design a multi-layered approach: surveys, NPS scoring, review prompts, and passive feedback mechanisms
- Specify question frameworks and response formats for each method
- Recommend frequency and triggers to avoid survey fatigue

### 3. Automation & Tools
- Suggest specific platforms suited to the budget range (name tools with brief rationale)
- Outline automated workflows for data collection, routing, and follow-up
- Include integration points with existing systems

### 4. Reporting & Action Framework
- Define KPIs and dashboards that translate feedback into prioritized actions
- Create escalation rules for critical feedback
- Establish review cadences and accountability for improvements

### 5. Implementation Timeline
- Break rollout into phases with realistic milestones
- Identify quick wins vs. long-term initiatives
- Note resource requirements for each phase

Format all recommendations as detailed bullet points with specific, actionable guidance.
```
