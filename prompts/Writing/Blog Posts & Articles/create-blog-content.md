# SEO Blog Post Writer Prompt for ChatGPT

## 簡介

The SEO Blog Post Writer Prompt for ChatGPT is a free AI prompt that produces complete, search-optimized blog articles for content marketers, SEO specialists, and digital publishers. This blog writing prompt for ChatGPT instructs the AI to generate full-length posts that weave primary and secondary keywords naturally throughout titles, headings, and body text while maintaining readability. It produces not just the article itself but also meta titles, meta descriptions, image alt text suggestions, and internal linking recommendations - everything needed to publish SEO-ready content. The prompt runs on ChatGPT, Claude, Gemini, and Grok, adapting to custom word counts, topics, keyword sets, and calls-to-action. Real-world applications include publishing thought leadership articles, creating product category pages with editorial content, building topical authority clusters, and scaling content calendars without sacrificing on-page optimization. Reach for this prompt when you need publication-ready blog posts that satisfy both search algorithms and human readers, complete with the technical SEO elements often missed in first drafts. ● Outputs full blog posts at any word count with primary and secondary keywords distributed naturally to avoid stuffing ● Generates accompanying SEO metadata including title tags, meta descriptions, image alt text, and internal link suggestions ● Structures content with scannable headings, bullet points, and clear sections that improve dwell time and engagement signals ● Accepts custom topics, keyword sets, and calls-to-action, making it reusable across different content campaigns and editorial calendars ## Prompt

```
## Role
You are an SEO copywriting expert specializing in high-ranking blog content that balances search optimization with reader engagement.

## Task
Write a {{word-count}}-word blog post about {{topic}} optimized for search engines while maintaining readability and value for the target audience.

## Context
The post must incorporate {{primary-keyword}} and {{secondary-keywords}} strategically throughout. Structure the content to rank well in search results while keeping readers engaged through the conclusion, which should include {{cta}}.

## Output Requirements

**Keyword Strategy**
- Integrate the primary keyword naturally in the title, introduction (within first 100 words), at least one subheading, and throughout the body
- Weave secondary keywords organically into content, maintaining 1-2% keyword density overall
- Prioritize readability over keyword stuffing

**Content Structure**
- Craft a compelling, keyword-rich title
- Write an engaging introduction that previews the value readers will gain
- Divide body into clear sections using H2 and H3 headings
- Use bullet points, numbered lists, and short paragraphs for scannability
- Include relevant examples, case studies, or real-world applications
- Close with the specified call-to-action that prompts clear next steps

**SEO Elements to Include**
- Meta title tag (50-60 characters) with primary keyword
- Meta description (150-160 characters) with primary keyword and value proposition
- Alt text suggestions for 2-3 relevant images, incorporating keywords naturally
- 2-3 strategic internal link recommendations to related content

**Quality Standards**
- Deliver comprehensive, accurate information on the topic
- Maintain conversational yet authoritative tone
- Ensure grammatical accuracy and clear, concise language
- Match the specified word count within 5% variance
```
