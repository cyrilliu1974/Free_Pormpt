# Schema Markup Implementation Roadmap Generator

## 簡介

The Schema Markup Implementation Roadmap Generator is a free AI prompt that builds a complete structured data strategy for websites seeking better search visibility and rich snippet performance. This schema markup prompt for ChatGPT audits your site's content, recommends the most impactful schema types for your industry - Organization, Product, Article, LocalBusiness, FAQ, and more - then delivers properly formatted JSON-LD examples with validation instructions. It runs on ChatGPT, Claude, Gemini, and Grok, and outputs a prioritized roadmap that explains where to place each markup, why it matters, and what rich results to expect. SEO professionals use it to move from audit to implementation in one session, ensuring compliance with current schema.org vocabulary and Google Rich Results guidelines. Reach for this prompt when you need a structured data plan tailored to a specific website and business context, not generic boilerplate. ● Audits site content to identify the highest-value schema opportunities for your industry and pages ● Provides correctly formatted JSON-LD code snippets that follow schema.org standards and search engine requirements ● Ranks schema types from foundational to advanced, so you implement in order of impact ● Includes testing instructions using Google's Rich Results Test and Schema Markup Validator for each recommendation ## Prompt

```
## Role
You are an expert schema markup specialist focused on implementing structured data to enhance search engine visibility and rich snippet performance.

## Task
Develop a comprehensive schema markup implementation roadmap for the given website. Analyze the site's content structure, recommend the most impactful schema types for the industry, provide properly formatted markup examples, and create a testing and validation plan.

## Context
**Website & Business Context:** {{website-and-business-context}}
(Include: website URL, industry, primary content types, target audience, and specific SEO objectives)

## Approach
- Audit the website to identify content elements best suited for schema markup
- Prioritize schema types by relevance to the industry and potential search visibility impact
- Ensure all markup follows current schema.org vocabulary and search engine guidelines (Google, Bing)
- Structure recommendations from foundational to advanced schema implementations
- Include validation steps using Google's Rich Results Test and Schema Markup Validator

## Output
Deliver a numbered implementation roadmap. Each step should include:
1. The specific schema type (e.g., Organization, Product, Article, LocalBusiness, FAQ)
2. Where and why to apply it on the website
3. Properly formatted JSON-LD markup example
4. Expected impact on search visibility and rich snippets
5. Testing and validation instructions

Organize from highest to lowest priority based on the business context provided.
```
