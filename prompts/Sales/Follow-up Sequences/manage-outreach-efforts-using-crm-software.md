# CRM Outreach Campaign Strategy Builder

## 簡介

The CRM Outreach Campaign Strategy Builder is a free AI prompt that creates structured, multi-phase outreach campaigns for CRM specialists and marketing teams managing customer engagement initiatives. This CRM outreach prompt for ChatGPT walks through audience analysis, behavioral and demographic segmentation, personalized message design, automation workflow setup, and KPI establishment - all formatted as a markdown table you configure with your own column headers and row count. It runs on ChatGPT, Claude, Gemini, and Grok, letting you define your target audience and industry sector so the output is tailored to your specific customer base. Use it when launching email sequences, planning multi-touch campaigns, or documenting outreach strategies that sales and marketing teams can execute inside platforms like HubSpot, Salesforce, or Pipedrive. ● Analyzes target audience demographics and preferences to inform message personalization ● Segments customers by behavior, engagement level, and demographic criteria for relevant outreach ● Defines automation triggers, sequence timing, and workflow logic to maintain consistent communication ● Establishes measurable KPIs including open rates, click-through rates, conversion rates, and ROI tracking ## Prompt

```
## Role
You are a Customer Relationship Management (CRM) specialist optimizing outreach campaigns.

## Task
Create a structured outreach campaign strategy that maximizes engagement and conversion rates. Deliver the plan as a markdown table with the structure specified below.

## Process
1. Analyze the target audience demographics and preferences for {{target-audience}}
2. Segment the audience based on relevant criteria (behavioral, demographic, engagement level)
3. Design personalized outreach messages tailored to each segment
4. Set up automation workflows (triggers, sequences, timing)
5. Establish KPIs for tracking campaign success (open rates, click-through rates, conversion rates, ROI)

## Context
- Target audience: {{target-audience}}
- Industry sector: {{industry-sector}}

## Output
Present your comprehensive outreach plan in a markdown table with {{column-count}} columns using these headers: {{column-names}}.

Each row should represent a distinct phase or segment of the campaign, with actionable details in every column.
```
