# React Branding App Builder Prompt

## 簡介

The React Branding App Builder Prompt is a free AI prompt that generates detailed implementation plans for building professional brand identity creation tools as standalone React applications. This branding app prompt for ChatGPT produces a complete technical architecture, component structure, design system specifications, and step-by-step implementation guidance for creating a multi-step wizard that takes users from strategic positioning through visual identity to exportable brand assets. It runs on ChatGPT, Claude, Cursor, and other code-generation models, delivering production-ready planning for dark-themed, polished interfaces inspired by Linear.app and Stripe. Real-world use cases include entrepreneurs building internal branding tools, agencies white-labeling brand generators, and developers creating SaaS branding platforms that run entirely in the browser. Reach for this prompt when you need a structured blueprint for a branding application that includes real-time preview rendering, PDF generation, glassmorphism UI patterns, and professional asset export functionality. ● Generates complete component hierarchies, file structures, and state management approaches tailored to your business context and technical profile. ● Provides design system specifications including dark themes, typography scales, spacing systems, and interaction patterns matching modern SaaS standards. ● Delivers real-time mockup preview systems, PDF generation pipelines, and multi-format asset export functionality with concrete code examples. ● Includes performance optimization strategies covering code splitting, lazy loading, animation performance, and error boundary implementation for production use. ## Prompt

```
## Role
You are an expert React developer building a browser-based brand identity platform.

## Task
Create a complete React application that guides users through professional brand creation via a multi-step wizard. The tool must generate enterprise-quality brand systems—strategic positioning, visual identity, real-time mockups, and exportable assets—with UI polish matching Linear.app and Stripe.

## Context
**Business context:** {{business-context}}

**Technical profile:** {{technical-profile}}

## Output
Structure your implementation plan with these sections:

### Technical Architecture
Component hierarchy, state management approach, and file organization strategy.

### Step-by-Step Implementation
Detailed breakdown of each wizard step with specific functionality and data flows.

### Design System Implementation
Dark theme specifications, glassmorphism effects, typography, spacing, and interaction patterns.

### Advanced Features
Real-time preview system, PDF generation pipeline, asset export functionality, and format options.

### Performance Optimization
Code splitting, lazy loading strategies, animation performance, and error boundaries.

### Testing and Polish
Quality assurance checklist, edge case handling, and production-readiness criteria.

Provide complete code examples, specific technical guidance, and implementation priorities for building a production-ready branding application. Use bullet points (●) for clarity.
```
