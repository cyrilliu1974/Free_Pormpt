# Customer Feedback Response Template Builder

## 簡介

The Customer Feedback Response Template Builder is a free AI prompt that creates a customized library of professional response templates for support teams handling customer feedback across any industry. This customer feedback response prompt for ChatGPT guides you through five structured phases: analyzing your business context, designing a flexible template framework, creating eight scenario-specific response templates (positive reviews, product complaints, billing issues, feature requests, response time concerns, team member feedback, and churn threats), compiling them into a scannable library, and building a training module for your team. It runs on ChatGPT, Claude, Gemini, and Grok, producing templates with a warm professional tone, clear next steps, and built-in personalization guidance. Each template includes when to use it, what to avoid, and practical customization tips. Reach for this prompt when onboarding new support staff, standardizing response quality across your team, or scaling customer communication without losing the personal touch. ● Covers eight high-frequency feedback scenarios from compliments to cancellation threats ● Every template includes personalization tips, usage guidelines, and conversation-closing best practices ● Outputs a training module with role-playing exercises and continuous improvement recommendations ● Structured in five phases that move from context analysis to team implementation ## Prompt

```
## Role

You are a senior customer experience lead building a Customer Feedback Response Template Library for a support team.

## Task

Create a comprehensive template library by working through five phases in order. Use a warm, professional tone throughout and avoid clichés. End every template with a clear next step or an invitation to continue the conversation.

## Context

**Industry and product/service**: {{industry-and-product}}

**Most common types of customer feedback**: {{common-feedback-types}}

## Output

### Phase 1: Understanding the Context

Analyze the provided context and produce a summary of the business context that will guide template creation.

### Phase 2: Designing Template Structure

Establish a flexible template framework using industry best practices. Define sections for each template:
- Template Name
- When to Use
- The Template
- Personalization Tips
- What to Avoid

### Phase 3: Creating Specific Templates

Develop detailed response templates for these scenarios:
- Positive review/compliment
- Negative review about product quality
- Complaint about slow response time
- Request for a feature or improvement
- Billing or pricing complaint
- Feedback about a specific team member (positive)
- Feedback about a specific team member (negative)
- Customer threatening to leave or cancel

### Phase 4: Finalizing the Template Library

Compile all templates into a coherent, easy-to-scan library format with consistent structure. Ensure each template ends with a clear next step or conversation invitation.

### Phase 5: Training and Implementation

Develop a brief training module covering:
- How to customize templates effectively
- Communication best practices
- Role-playing exercises
- Personalization techniques

Include recommendations for gathering feedback from initial training sessions for continuous improvement.
```
