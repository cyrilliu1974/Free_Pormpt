# Website Development Plan Generator

## 簡介

The Website Development Plan Generator is a free AI prompt that creates structured blueprints for website projects tailored to specific audiences and business goals. This website development plan prompt for ChatGPT produces a multi-section document that maps out your site's information architecture, user personas, content strategy, design system, and phased implementation timeline. It works by analyzing your website overview and target audience, then generating detailed specifications across audience analysis, site structure, key page content, calls-to-action, design guidelines, development phases, and success metrics. Teams building new websites or redesigning existing ones use it to align stakeholders, guide designers and developers, and ensure the final product serves real user needs. The prompt runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need a structured foundation before starting design or development work, or when you want to document requirements for agency partners or internal teams. ● Builds two detailed user personas with demographics, goals, pain points, and conversion journeys ● Maps complete site structure including page inventory, navigation hierarchy, and content prioritization ● Defines design systems with color palettes, typography scales, imagery style, and responsive layout rules ● Delivers phased timelines with milestones and quantifiable KPIs for measuring post-launch success ## Prompt

```
## Role
You are an expert website developer and user experience designer.

## Task
Create a comprehensive website development plan covering structure, content, user experience, design, and implementation strategy.

## Context
Website overview: {{website-overview}}

Target audience: {{target-audience}}

## Output
Deliver a complete website blueprint organized as follows:

**Target Audience Overview**
● Analysis of audience needs, behaviors, and expectations

**User Persona 1**
● Demographics: Age range, occupation, technical proficiency
● Goals: Primary objectives when visiting the site
● Pain Points: Frustrations with current solutions
● User Journey: Typical path from discovery to conversion

**User Persona 2**
● Demographics: Age range, occupation, technical proficiency
● Goals: Primary objectives when visiting the site
● Pain Points: Frustrations with current solutions
● User Journey: Typical path from discovery to conversion

**Site Structure**
● Pages: Complete list of required pages
● Navigation: Primary and secondary navigation patterns
● Content Hierarchy: Information architecture and priority levels

**Key Content**
● Page 1: Core messaging, value proposition, and content blocks
● Page 2: Core messaging, value proposition, and content blocks
● Page 3: Core messaging, value proposition, and content blocks

**Calls-to-Action**
1. Primary CTA with placement and messaging
2. Secondary CTA with placement and messaging
3. Tertiary CTA with placement and messaging

**Design Guidelines**
● Color Palette: Primary, secondary, and accent colors with purpose
● Typography: Heading and body font families with hierarchy
● Imagery: Photography style, illustration approach, and icon treatment
● Layout: Grid system, spacing, and responsive breakpoints

**Development Timeline**
● Phase-by-phase schedule with milestones and dependencies

**Success Metrics**
● Quantifiable KPIs for user engagement, conversion, and performance
```
