# Product Name to Long-Tail Keyword Generator

## 簡介

The Product Name to Long-Tail Keyword Generator is a free AI prompt that transforms product names into 40-50 categorized long-tail keywords targeting buyers at different stages of the purchase journey. This keyword research prompt for ChatGPT analyzes your product's value proposition, maps buyer intent patterns, and generates keywords organized into five categories: comparison searches, how-to queries, alternative-seeking phrases, problem-focused terms, and purchase-ready searches. It runs on ChatGPT, Claude, Gemini, and Grok, producing a strategic table with search intent classification, recommended use cases, and an implementation roadmap. Reach for this prompt when you need to identify the exact phrases buyers use when moving from problem awareness to purchase decision, whether you're optimizing product pages, planning content strategy, or running paid search campaigns. ● Maps buyer journey stages from problem awareness to purchase readiness, matching keywords to each phase. ● Categorizes 40-50 keywords by commercial intent: comparison, how-to, alternative-seeking, problem-focused, and solution-ready. ● Delivers a strategic keyword table with search intent classification and buyer stage for every term. ● Provides an implementation roadmap identifying quick-win keywords, content clusters, competitive gaps, and success metrics to track. ## Prompt

```
## Role
You are a keyword research specialist focused on identifying high-intent, long-tail search phrases that capture buyers at the moment of purchase decision.

## Task
Generate 40-50 high-converting long-tail keywords for the provided product, organized by search intent and buyer journey stage. Deliver them in phases: first gather product context, then map buyer intent patterns, generate categorized keywords, present a strategic analysis table, and finally provide an implementation roadmap.

## Context
Effective keyword research goes beyond generic terms to uncover the specific language patterns people use when ready to buy. Analyze the product's value proposition, the pain points it solves, and the buyer's journey from problem awareness to purchase readiness. Adapt the depth and number of phases (3-8) based on product complexity, market sophistication, and niche-specific search behaviors.

## Output

### Phase 1: Product Intelligence Gathering
To create keywords that convert, provide:

{{product-context}}

*Include: product name, niche/category, primary problem solved, ideal customer description, and main differentiator.*

### Phase 2: Buyer Intent Mapping
Based on the product details, identify:

- Core pain points driving searches
- Emotional triggers in buying decisions
- Comparison behaviors in the niche
- Solution-seeking language patterns

Keyword categories will include:
- Direct buyer intent phrases
- Comparison/alternative searches
- Problem-aware searches
- Solution-aware searches
- How-to/implementation queries

### Phase 3: Long-Tail Keyword Generation
Generate 40-50 keywords organized by intent:

**Comparison Keywords (High Commercial Intent)** — 10-12 keywords comparing product to alternatives

**How-To Queries (Implementation Intent)** — 10-12 keywords about using/implementing the product

**Alternative Seekers (Substitution Intent)** — 8-10 keywords for people seeking alternatives

**Problem-Focused (Early Stage Intent)** — 8-10 keywords targeting problem awareness

**Solution-Ready (Purchase Intent)** — 8-10 keywords for ready-to-buy searches

### Phase 4: Strategic Keyword Table
Present all keywords in a comprehensive table:

| Keyword | Search Intent | Use Case | Buyer Stage |
|---------|--------------|----------|-------------|
| [Complete table with all 40-50 keywords] |||||

### Phase 5: Implementation Roadmap

**Quick Wins (Implement This Week)**
- 5-7 highest-converting keywords to target immediately
- Recommended content types for each
- Expected conversion potential

**Content Clusters (Build Over 30 Days)**
- Grouped keywords by theme
- Content hub recommendations
- Internal linking strategies

**Competitive Advantages**
- Unique angle keywords competitors miss
- Untapped sub-niches identified
- First-mover opportunities

**Success Metrics**
- Track click-through rates by keyword category
- Monitor conversion rates per intent type
- Measure time-to-purchase by keyword source
- Analyze keyword-to-customer lifetime value
```
