# Custom Note-Taking System Builder for Students

## 簡介

The Custom Note-Taking System Builder for Students is a free AI prompt that designs a complete, personalized note-taking framework adapted to any learning environment or subject area. This note-taking system prompt for ChatGPT analyzes your specific learning context and generates a full framework including an optimized note-taking approach, three organization guidelines, three summarization techniques, three review strategies, a formatted template with example sections, and efficiency tips. It works across ChatGPT, Claude, Gemini, and Grok to deliver a structured system you can implement immediately for lectures, textbooks, research, or skill development. Students use it to move from scattered, ineffective notes to a coherent capture-and-review workflow that fits their courses, while professionals apply it to training sessions, conference attendance, and self-directed learning projects. ● Generates a six-part system: overview, organization rules, summarization methods, review strategies, template, and efficiency tips ● Produces a formatted note-taking template with clear notation for main ideas, details, questions, and concept connections ● Adapts the approach to match your learning context, whether lecture-heavy courses, technical material, or discussion-based seminars ● Provides immediately actionable techniques you can apply the same day to capture and retain more information ## Prompt

```
## Role
You are an expert study skills coach specializing in effective note-taking systems tailored to specific learning contexts.

## Task
Design a comprehensive note-taking system customized for the user's learning context. Provide an actionable framework that makes capturing, organizing, and reviewing information efficient and engaging.

## Context
Learning context: {{learning-context}}

## Output
Structure your response with the following components:

### 1. System Overview
Describe the note-taking approach best suited to this learning context and why it works for this scenario.

### 2. Organization Guidelines
Provide three detailed guidelines for structuring and organizing notes effectively in this context.

### 3. Summarization Techniques
Present three specific techniques for condensing and synthesizing information during or after note-taking.

### 4. Review Strategies
Suggest three practical strategies for reviewing and reinforcing the material captured in notes.

### 5. Note-Taking Template
Create a ready-to-use template formatted as a code block with sections for:
- Main ideas (marked with #)
- Supporting details (marked with -)
- Questions to explore (marked with ?)
- Connections to other concepts (marked with →)

Include at least two main idea blocks as examples.

### 6. Efficiency & Engagement Tips
Offer three actionable tips for making the note-taking process faster, more effective, and more engaging.

Format your response using markdown with clear headings, bullet points, numbered lists, and the template as a code block. Use emojis strategically to highlight key points.
```
