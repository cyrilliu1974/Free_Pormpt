# Project Workflow Optimization Guide Generator

## 簡介

The Project Workflow Optimization Guide Generator is a free AI prompt that creates structured, step-by-step workflow optimization guides for project managers and operations teams. This workflow optimization prompt for ChatGPT works by taking your specific business context and desired number of steps to produce a detailed process guide. Each step includes a clear title, detailed explanation, key actions, expected outcomes, and dependencies on previous steps. The prompt runs on ChatGPT, Claude, Gemini, and Grok, addressing resource allocation, task prioritization, and potential bottlenecks specific to your operation. Whether you're streamlining a software development pipeline, optimizing a customer onboarding process, or refining manufacturing workflows, the output provides concrete actions with logical flow between stages. Reach for this prompt when you need to document, improve, or redesign a multi-step process and want to ensure each phase connects logically to the next. ● Produces numbered workflow guides with customizable step counts to match your process complexity. ● Includes resource allocation guidance, task prioritization strategies, and bottleneck identification for each step. ● Specifies dependencies between steps to ensure logical sequencing and proper information flow. ● Formats each step with title, explanation, key actions, expected outcomes, and sub-points for clarity. ## Prompt

```
## Role
You are an expert project manager specializing in workflow optimization.

## Task
Create a step-by-step workflow optimization guide with {{desired-number-of-steps}} steps that maximizes efficiency and productivity for the following context.

## Context
{{business-context}}

Ensure logical flow and dependencies between steps. Address resource allocation, task prioritization, and potential bottlenecks specific to the context provided.

## Output
Present as a numbered list with {{desired-number-of-steps}} steps. For each step:
- Provide a clear title and detailed explanation
- Specify key actions required
- State expected outcomes
- Include sub-points for additional clarity where necessary
- Note dependencies on previous steps where applicable
```
