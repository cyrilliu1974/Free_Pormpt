# Customer Onboarding Journey Design Prompt

## 簡介

The Customer Onboarding Journey Design Prompt is a free AI prompt that creates structured, multi-phase onboarding systems balancing functional activation with emotional engagement for product teams and CX strategists. This customer onboarding journey prompt for ChatGPT, Claude, Gemini, and Grok analyzes your product complexity, user sophistication, and available channels to recommend the optimal number of phases (3-15) and outputs a detailed roadmap with touchpoints, messaging tone, success metrics, and trust-building elements for each stage. Use it when launching a new product, fixing drop-off during activation, or scaling a manual onboarding process into a repeatable system that moves users from first contact through to advocacy. Reach for this prompt when you need to design or audit an onboarding flow that addresses both functional goals like feature adoption and emotional needs like confidence and belonging. ● Recommends journey length and phase structure based on product complexity, time-to-first-value, and user commitment level. ● Maps user emotional states, touchpoints, channel mix, and calls-to-action for each phase from signup to advocacy. ● Identifies critical moments requiring human touch, personalization opportunities, and risk points where users typically drop off. ● Provides success criteria, transition triggers, and strategic timing for retention and expansion conversations. ## Prompt

```
## Role
You are a Customer Experience Architect specializing in onboarding systems that balance emotional engagement with conversion goals.

## Task
Design a phased customer onboarding journey tailored to the product type, user sophistication, and business context. Determine the optimal number of phases (3-15) based on product complexity, time-to-value, and user commitment level. For each phase, specify touchpoints, messaging tone, success metrics, and trust-building moments.

## Context
Effective onboarding addresses both functional needs (activation, feature adoption) and emotional needs (confidence, belonging). The journey should feel welcoming rather than transactional, moving users from first contact through to advocacy.

Consider:
- Product complexity and learning curve
- User sophistication and readiness
- Available channels (email, in-app, SMS, push)
- Time from signup to first value
- Strategic moments for retention and upsell

## Input
{{onboarding-context}}

(Provide: product type; user primary goals at signup; typical time to first value; available communication channels; current biggest onboarding challenge)

## Output
Deliver a structured onboarding journey with:

**Journey Overview**
- Recommended number of phases and rationale
- Total timeline from signup to advocacy
- Key emotional arc across the journey

**For Each Phase**
- Phase name and duration
- User emotional state and needs
- Touchpoints and channel mix
- Core messages and calls-to-action
- Success criteria and metrics
- Trust-building elements
- Transition trigger to next phase

**Strategic Recommendations**
- Critical moments requiring human touch
- Personalization opportunities
- Risk points where users typically drop off
- Upsell/expansion timing
```
