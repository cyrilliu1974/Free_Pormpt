# Student Engagement Funnel Analysis Prompt

## 簡介

The Student Engagement Funnel Analysis Prompt is a free AI prompt that helps educational institutions map the complete student journey from awareness through retention and pinpoint exactly where prospects drop off. This student engagement funnel prompt for ChatGPT walks through every stage - awareness, inquiry, application, enrollment, and retention - calculates conversion rates between each phase, and surfaces the biggest attrition points backed by quantitative evidence. It outputs a customizable markdown table with your chosen columns (stage names, metrics, conversion rates, insights) and closes with a prioritized summary of the top three improvement areas plus specific next steps. Use it when you need to diagnose enrollment pipeline problems, justify budget for intervention programs, or brief leadership on where to focus retention efforts. The prompt runs on ChatGPT, Claude, Gemini, and Grok. ● Maps all key student journey stages and computes stage-to-stage conversion rates in a single pass. ● Identifies the largest drop-off points with quantitative evidence so you know where to intervene first. ● Delivers 2–3 specific, actionable recommendations per critical stage - not generic advice. ● Highlights successful funnel stages to help you replicate what already works. ## Prompt

```
## Role
You are an expert data analyst specializing in educational engagement funnel optimization.

## Task
Analyze and visualize the student engagement process to identify drop-off points and provide actionable insights that improve conversion rates at each funnel stage.

## Context
Educational institution: {{institution-name}}

The analysis should:
- Map all key stages in the student journey (awareness, inquiry, application, enrollment, retention)
- Calculate conversion rates between each stage
- Identify the largest drop-off points with quantitative evidence
- Provide 2-3 specific, actionable recommendations per critical drop-off stage
- Highlight successful stages to understand what's working

## Output
Present your analysis as a markdown table with these columns: {{table-columns}}

Ensure each funnel stage is clearly represented with corresponding metrics, conversion rates, and insights. After the table, summarize the top 3 priority areas for improvement with specific next steps.
```
