# Special Education Homeschool Resources Builder

## 簡介

The Special Education Homeschool Resources Builder is a free AI prompt that creates structured support guides for parents homeschooling children with learning disabilities and special needs. This special education prompt for ChatGPT produces a detailed four-column table that matches each learning challenge with specific intervention strategies parents can implement at home, readily available assistive technologies, and concrete progress monitoring tools. It runs on ChatGPT, Claude, and Gemini, translating complex special education methodologies into practical, jargon-free guidance that requires no specialized training. Parents input their child's specific learning challenges and receive a customized resource table covering everything from dyslexia and ADHD to sensory processing differences and autism spectrum support. Reach for this prompt when you need to build a clear homeschool support plan that bridges the gap between professional special education resources and everyday home learning environments. ● Produces intervention strategies written for implementation by parents without professional training in special education ● Recommends user-friendly assistive technologies that are commercially available and affordable for home use ● Provides progress monitoring tools that parents can apply consistently to track skill development and learning gains ● Organizes all resources in a scannable table format that serves as an ongoing reference throughout the homeschool year ## Prompt

```
## Role
You are an expert educator and learning specialist with comprehensive knowledge of special education strategies and tools.

## Task
Develop a comprehensive homeschooling guide that provides clear, actionable strategies, recommended assistive technologies, and effective progress monitoring tools for supporting children with special needs or learning disabilities.

## Context
The guide is for homeschooling parents who need practical, easy-to-implement support for {{learning-challenges}}. Focus on:
- Actionable strategies parents can implement without specialized training
- Readily available, user-friendly assistive technologies
- Effective and efficient progress monitoring tools
- Clear language without overly technical jargon
- Comprehensive support across the specified challenges

The goal is to empower parents to feel confident in supporting their child's learning and development at home.

## Output
Provide a table with 4 columns: Learning Challenge, Intervention Strategy, Assistive Technology, and Progress Monitoring Tools.

For each learning challenge listed in {{learning-challenges}}, include:
- At least 2 intervention strategies
- At least 2 assistive technologies
- At least 2 progress monitoring tools

Format:

| Learning Challenge | Intervention Strategy | Assistive Technology | Progress Monitoring Tools |
|-------------------|----------------------|---------------------|---------------------------|
| [Challenge 1]     | - [Strategy 1]       | - [Technology 1]    | - [Tool 1]                |
|                   | - [Strategy 2]       | - [Technology 2]    | - [Tool 2]                |
| [Challenge 2]     | - [Strategy 1]       | - [Technology 1]    | - [Tool 1]                |
|                   | - [Strategy 2]       | - [Technology 2]    | - [Tool 2]                |
| [Challenge 3]     | - [Strategy 1]       | - [Technology 1]    | - [Tool 1]                |
|                   | - [Strategy 2]       | - [Technology 2]    | - [Tool 2]                |
```
