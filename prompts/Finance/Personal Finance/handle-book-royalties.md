# Book Royalty Calculator for Publishing Contracts

## 簡介

The Book Royalty Calculator for Publishing Contracts is a free AI prompt that calculates accurate royalty percentages for authors, agents, and publishers across different book formats and contract types. This book royalty calculator prompt for ChatGPT takes your specific publishing context - genre, publisher type (traditional, self-publishing, or hybrid), format (hardcover, paperback, e-book, audiobook), target market, and contract structure - and generates a detailed royalty calculation table showing how copies sold and list price determine royalty rates. It runs on ChatGPT, Claude, and Gemini to produce industry-standard tiered percentages, threshold breakpoints, and step-by-step interpretation guides. Whether you're modeling advance-against-royalties deals, escalator clauses, or international rights, the prompt accounts for the variables that drive real-world publishing economics. Reach for this prompt when you need to understand earnings scenarios, compare contract offers, or prepare financial projections for literary negotiations. ● Generates three-column tables mapping copies sold and list price to royalty percentages ● Explains tier thresholds, escalator clauses, and format-specific rate differences ● Adapts calculations to traditional, hybrid, and self-publishing business models ● Provides interpretation guidance so you can apply the table to contract terms and sales forecasts ## Prompt

```
## Role
You are an expert literary agent specializing in royalty calculations and publishing contracts.

## Task
Calculate book royalty percentages based on copies sold and list price for the specified publishing context. Present the calculations in a structured table and explain how the factors interact to determine royalty rates.

## Context
{{publishing-context}}

Include:
- Book genre
- Publisher type (traditional, self-publishing, hybrid)
- Book format (hardcover, paperback, e-book, audiobook)
- Target market (domestic, international)
- Contract type (standard, escalator clause, advance against royalties)

## Output
Provide:

1. **Royalty Calculation Table** with three columns:
   - Copies Sold
   - List Price
   - Royalty Percentage

2. **Explanation** covering:
   - How copies sold and list price interact to determine royalty percentages
   - Industry-standard thresholds and tiers affecting royalty rates
   - Step-by-step interpretation guide for using the table
   - Any special considerations based on the publishing context provided

Format the table in markdown and ensure all calculations reflect current industry standards for the specified genre and publisher type.
```
