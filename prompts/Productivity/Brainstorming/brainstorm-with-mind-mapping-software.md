# Mind Map Generator Prompt for Project Brainstorming

## 簡介

The Mind Map Generator Prompt for Project Brainstorming is a free AI prompt that creates structured, hierarchical mind maps to organize and develop project ideas using dependency grammar principles. This mind map prompt for ChatGPT, Claude, Gemini, and Grok transforms a project brief into a text-based conceptual map that shows clear relationships between ideas. It structures information from a central node through multiple levels of branching detail, using indentation and symbols to represent hierarchies. After generating the map, it explains the grammatical relationships applied, showing which ideas serve as core concepts versus supporting details, and where coordination or subordination appears. Project managers use it to structure complex initiatives, product teams rely on it to explore feature sets, and strategic planners apply it to break down business concepts into actionable components. Reach for this prompt when you need to transform a fuzzy project brief into a clear visual structure that reveals how ideas connect, depend on one another, and can be developed further. ● Creates multi-level text-based mind maps using indentation and symbols to show idea hierarchies ● Applies dependency grammar to clarify which concepts are central versus supporting or modifying ● Explores potential developments across branches and identifies how ideas interconnect ● Delivers both the visual structure and an explanation of the grammatical relationships applied ## Prompt

```
## Role
You are an expert project manager specializing in structured ideation and concept mapping.

## Task
Generate and organize project ideas using a mind mapping approach with dependency grammar principles. Create a hierarchical structure that shows clear relationships between concepts, from the central project concept through primary branches to secondary and tertiary ideas. Analyze connections, identify potential developments, and highlight innovative combinations.

## Context
{{project-brief}}

## Output
Deliver a text-based mind map using indentation and symbols (-, *, >) to represent hierarchical levels and connections. Structure it as:

**Central Node:** Main project concept
- **Primary branch:** Core theme or pillar
  * Secondary idea: Supporting concept
    > Tertiary detail: Specific implementation or extension

After the mind map, provide a brief explanation of the dependency grammar relationships you applied (e.g., which ideas serve as heads vs. dependents, how modifiers attach to core concepts, where coordination vs. subordination appears).

Ensure each branch explores potential developments and shows how ideas interconnect across the map.
```
