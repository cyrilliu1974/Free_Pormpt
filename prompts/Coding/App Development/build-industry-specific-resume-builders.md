# Industry-Specific Resume Builder App Prompt

## 簡介

The Industry-Specific Resume Builder App Prompt is a free AI prompt that generates a complete, production-ready React TypeScript web application for building industry-adapted resumes optimized for both ATS systems and human reviewers. This resume builder prompt for ChatGPT, Claude, and Cursor produces full-stack code for a professional SaaS-quality application that understands how hiring expectations differ across industries - finance resumes emphasize quantified achievements with conservative formatting, creative roles showcase portfolio work with visual hierarchy, and tech positions highlight technical skills and projects. The prompt delivers organized React components, TypeScript interfaces, smart forms with conditional logic, a real-time preview engine, and dual PDF export (ATS-optimized machine-readable and visually formatted versions). Real use cases include developers building career services platforms, HR tech startups creating differentiated resume tools, and agencies offering white-label resume solutions to clients. Reach for this prompt when you need to build a complete resume builder application that goes beyond generic templates and adapts intelligently to industry-specific hiring practices and formatting requirements. ● Produces distinct resume templates for finance, creative, tech, healthcare, and other major industries with appropriate visual design and content structure for each sector. ● Includes smart form systems with dynamic fields, validation, auto-save, and conditional logic that adapts based on selected industry and role. ● Delivers a live preview engine with side-by-side editing interface and PDF export system generating both ATS-compatible and visually polished versions. ● Provides content enhancement tools offering industry-specific suggestions for bullet points, skills, and summaries with context-aware recommendations. ## Prompt

```
## Role

You are an expert full-stack developer and UX designer specializing in recruitment platforms and ATS-optimized resume systems.

## Task

Create a complete, production-ready resume builder web application in React TypeScript. The application must generate industry-adapted resume designs that optimize for both ATS parsing and human review.

## Context

Effective resume builders adapt to industry hiring practices rather than applying generic templates. A finance executive's resume should emphasize quantified achievements with conservative formatting, while a creative director needs visual hierarchy and portfolio emphasis. The tool must understand these differences and reflect them in design, content structure, and export optimization.

## Output

Deliver complete, production-ready code organized into these components:

**1. Project Architecture and File Structure**
- Folder organization, routing, state management, and API layer
- TypeScript interfaces and type definitions

**2. Industry-Specific Template Components**
- Distinct templates optimized for finance, creative, tech, healthcare, and other major industries
- Visual designs that reflect industry hiring expectations and standards

**3. Smart Form System**
- Dynamic fields that adapt based on selected industry and role
- Validation and auto-save functionality
- Conditional logic for contextual field display

**4. Live Preview Engine**
- Real-time visual updates as users input information
- Side-by-side editing and preview interface

**5. PDF Export System**
- Generate both ATS-optimized (machine-readable) and visually formatted versions

**6. Content Enhancement Tools**
- Industry-specific suggestions for bullet points, skills, and summaries
```
