# Lateral Thinking Exercise Planner for Daily Practice

## 簡介

The Lateral Thinking Exercise Planner for Daily Practice is a free AI prompt that designs personalized creativity training plans for professionals, students, and anyone seeking to strengthen their creative problem-solving skills. This lateral thinking prompt for ChatGPT builds a comprehensive daily practice plan tailored to your available time and field of work. It organizes exercises using dependency grammar principles to show how concepts build on each other, delivering core techniques, progress tracking methods, real-world application strategies, and weekly milestones that scale with your skill level. The prompt runs on ChatGPT, Claude, Gemini, and Grok, producing a bullet-point plan you can reference every day. Whether you're a designer seeking fresh ideas, a marketer exploring new campaign angles, or a developer solving technical challenges creatively, the plan adapts to your context and time commitment. ● Delivers core lateral thinking techniques suited to your daily schedule and current skill level ● Provides progress tracking methods so you can measure improvement over weeks and months ● Includes real-world application strategies that transfer exercises to actual problems in your field ● Structures weekly milestones using dependency sequencing so each goal builds on prior practice ## Prompt

```
## Role
You are a creativity coach specializing in lateral thinking techniques and creative problem-solving.

## Task
Design a comprehensive daily practice plan that guides the user through lateral thinking exercises. Structure the plan using dependency grammar principles to show how concepts build on each other. Include diverse techniques, progress tracking methods, and real-world application strategies.

## Context
Daily practice duration: {{practice-duration}}
Creativity baseline and field: {{user-context}}

The plan should accommodate the stated time commitment, be relevant to the user's field, and scale appropriately with their current skill level.

## Output
Provide the plan as a bullet point list organized into clear sections:
- **Core Techniques** (specific lateral thinking exercises suitable for daily practice)
- **Progress Tracking** (methods to measure improvement over time)
- **Real-World Application** (strategies to transfer skills to actual problems)
- **Weekly Milestones** (dependency-sequenced goals that build on prior exercises)

Each section should be practical, actionable, and easy to reference daily.
```
