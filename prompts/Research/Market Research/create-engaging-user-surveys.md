# User Survey Builder for Product Feedback

## 簡介

The User Survey Builder for Product Feedback is a free AI prompt that creates comprehensive user surveys to gather actionable feedback on experience, satisfaction, and improvement opportunities for any product or service. This user survey prompt for ChatGPT walks you through building a complete questionnaire with a clear introduction, five core questions that blend multiple-choice, Likert scale, and open-ended formats, three demographic questions, and a closing message. It runs on ChatGPT, Claude, Gemini, and Grok, producing surveys that balance quantitative metrics with qualitative insights. Real use cases include post-purchase experience studies, SaaS feature prioritization, and service quality audits where you need unbiased, relevant questions that encourage honest responses. Reach for this prompt whenever you need to design a user feedback survey but want to avoid leading questions, survey fatigue, or missing key data points. ● Combines Likert scales and multiple-choice questions for quantifiable satisfaction data alongside open-ended fields for improvement ideas ● Includes three standard demographic questions (age, gender, location) with inclusive, appropriate answer ranges ● Structures output with labeled question types, clear text, and answer options so you can import directly into Google Forms, Typeform, or SurveyMonkey ● Maintains survey brevity and logical question order to reduce drop-off and encourage thoughtful responses ## Prompt

```
## Role

You are an expert survey designer specializing in user experience research for products and services.

## Task

Create a comprehensive user survey that gathers actionable feedback on experience, satisfaction, and improvement opportunities for:

{{product-or-service}}

## Survey Structure

Deliver a complete survey with:

**Survey Title & Introduction**
- Clear title reflecting the survey's purpose
- Brief introduction explaining goals and encouraging participation

**5 Core Questions**
Cover user experience, satisfaction levels, and suggestions for improvement. Use a mix of:
- Multiple choice and Likert scale questions for quantitative data
- Open-ended questions for qualitative insights
- Ensure questions are clear, unbiased, and directly relevant to the product/service

**3 Demographic Questions**
- Age (with appropriate ranges)
- Gender (inclusive options)
- Location (appropriate granularity)

**Closing**
- Thank you message
- Optional field for additional comments

## Output Format

Structure each question as:
- Question Type: [type]
- Question Text: [text]
- Answer Options: [options]

Maintain logical flow and keep the survey concise to maximize completion rates.
```
