# Learning Module Builder for Course Creation

## 簡介

The Learning Module Builder for Course Creation is a free AI prompt that generates complete teaching modules with objectives, lecture content, activities, and assessments for educators and instructional designers. This learning module prompt for ChatGPT produces a fully structured educational unit that includes measurable learning objectives, detailed lecture notes organized using dependency grammar principles, interactive activities tied to objectives, and both formative and summative assessments. It works on ChatGPT, Claude, Gemini, and Grok by guiding the model to build logically connected concepts that progress from foundational ideas to advanced applications. Educators use it to design curriculum for academic courses, corporate training programs, online learning platforms, and professional development workshops. Reach for this prompt when you need to rapidly prototype a teaching module, ensure alignment between objectives and content, or create a complete lesson plan framework that can be refined and adapted for your specific audience. ● Outputs clear, measurable learning objectives that define what students will achieve ● Structures lecture content using dependency grammar to show how concepts build logically ● Includes interactive activities with durations and materials lists that reinforce objectives ● Provides both formative assessments for ongoing feedback and summative assessments for final mastery evaluation ## Prompt

```
## Role
You are an expert educator designing a comprehensive, engaging learning module.

## Task
Create a complete teaching module for {{subject-or-topic}} that includes learning objectives, lecture content, interactive activities, and assessments.

## Output
Structure your module exactly as follows:

### Learning Objectives
1. [First objective - clear, specific, measurable]
2. [Second objective - clear, specific, measurable]
3. [Third objective - clear, specific, measurable]

### Lecture Notes
**Overview:** [Brief summary of what the lecture covers]

**Key Concepts:**
- [Concept 1]
- [Concept 2]
- [Concept 3]

**Detailed Notes:**
[Present the lecture content using dependency grammar framework - organize concepts in logical order showing how ideas build on and relate to each other]

### Activities

**Activity 1**
- Name: [Activity name]
- Description: [Interactive exercise that reinforces learning objectives]
- Duration: [Time required]
- Materials: [Resources needed]

**Activity 2**
- Name: [Activity name]
- Description: [Interactive exercise that reinforces learning objectives]
- Duration: [Time required]
- Materials: [Resources needed]

### Assessments

**Formative Assessment:**
[Ongoing evaluation method to check understanding during learning]

**Summative Assessment:**
[Final evaluation method to measure mastery of all learning objectives]

## Requirements
- Learning objectives must be measurable and aligned with the content
- Lecture notes should cover concepts thoroughly in logical progression
- Activities must be interactive and directly support the objectives
- Assessments should effectively evaluate understanding at different stages
```
