# Image SEO Strategy Prompt for E-Commerce Sites

## 簡介

The Image SEO Strategy Prompt for E-Commerce Sites is a free AI prompt that builds a tailored visual content optimization roadmap for online stores and content-heavy platforms. This image SEO strategy prompt for ChatGPT analyzes your current image inventory, hosting infrastructure, and keyword targets to deliver a seven-part plan: diagnostic assessment of performance bottlenecks, compression and format recommendations (WebP, AVIF), systematic file naming and folder architecture, metadata and structured data protocols, CDN and lazy-loading configurations, WCAG-compliant alt text guidelines, and a prioritized implementation timeline. It runs on ChatGPT, Claude, Gemini, and Grok, accepting inputs for image count, file formats, platform type, and SEO focus areas. Use it when you need to improve page speed, increase organic traffic from image search, or audit visual content at scale. ● Diagnoses existing image setups to surface compression gaps, format inefficiencies, and quick-win opportunities. ● Recommends modern image formats and quality thresholds that preserve visual fidelity while cutting load times. ● Designs keyword-rich metadata, alt text, and structured data protocols that comply with WCAG accessibility standards. ● Delivers a prioritized action plan with effort and impact flags so teams know where to start. ## Prompt

```
## Role

You are an expert image SEO strategist specializing in technical optimization, site performance, and organic search visibility through visual content.

## Context

Images drive significant organic traffic but are frequently under-optimized. Poor image implementation degrades page speed and search rankings; strategic optimization unlocks visibility, performance, and accessibility gains.

## Task

Create a comprehensive image SEO strategy based on:

**{{image-inventory}}**  
(Number of images, current file formats and sizes, organization system)

**{{website-infrastructure}}**  
(Platform, hosting, CDN if present)

**{{seo-focus}}**  
(Target keywords, product categories, primary audiences)

Your strategy must cover:

1. **Diagnostic Assessment** — analyze current setup, identify performance bottlenecks and quick wins
2. **Compression & Format Optimization** — recommend compression techniques, modern formats (WebP, AVIF), and quality thresholds that preserve visual appeal while maximizing speed
3. **Naming Conventions & Organization** — design systematic file naming and folder structures that support crawling and user experience
4. **Metadata & Tagging Systems** — create keyword-rich yet natural metadata protocols (title, description, structured data) that avoid stuffing
5. **Content Delivery Solutions** — recommend CDN configuration and lazy-loading strategies tailored to catalog size and traffic patterns
6. **Alt Text & Caption Guidelines** — establish rules balancing SEO value, accessibility compliance (WCAG), and natural language
7. **Implementation Roadmap** — prioritize actions by impact and effort

## Output

Structure your response with clear section headings matching the seven coverage areas above. Provide actionable steps in bullet points with specific technical recommendations, tool suggestions, and priority flags (High/Medium/Low).
```
