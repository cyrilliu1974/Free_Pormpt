# Programmatic Title Tag Optimization Prompt

## 簡介

The Programmatic Title Tag Optimization Prompt is a free AI prompt that builds systematic title tag strategies for SEO specialists managing multi-page websites. This title tag optimization prompt for ChatGPT analyzes your website structure, maps target keywords to landing pages, and generates optimized title tags using dependency grammar principles to ensure natural language hierarchy and semantic clarity. You provide your website URL, target keywords, industry context, and competitor URLs, and the prompt delivers a 10-point strategy covering keyword mapping, search intent alignment, character limit optimization (50–60 characters), and CTR enhancement techniques, plus 5–10 sample title tags with detailed rationale. It runs on ChatGPT, Claude, and Gemini, making it ideal for agencies scaling on-page SEO audits or content teams rolling out programmatic optimizations across product catalogs, regional pages, or service verticals. Each sample title tag includes an explanation of its dependency grammar structure and keyword placement logic, helping you understand the linguistic framework behind high-performing metadata. ● Analyzes website structure to identify priority landing pages for title tag optimization ● Maps target keywords to search intent and applies dependency grammar to ensure natural, readable title tags ● Generates title tag templates and pattern rules for programmatic deployment across page types ● Provides 5–10 optimized title tag examples with character counts, keyword logic, and competitive differentiation rationale ● Includes an implementation roadmap, measurement plan, and iteration framework for ongoing refinement ## Prompt

```
## Role
You are an expert SEO specialist implementing programmatic title tag optimization using dependency grammar principles.

## Task
Develop a systematic strategy to optimize title tags across a website, then generate optimized title tags for key landing pages.

## Context
Website: {{website-url}}
Target keywords: {{target-keywords}}
Industry & audience: {{industry-and-audience}}
Main competitors: {{competitors}}

Analyze the website's structure and identify key landing pages. Apply dependency grammar framework to ensure title tags reflect natural language hierarchy and semantic relationships. Balance keyword relevance, search intent, character limits (50–60 characters optimal), readability, and click-through potential.

## Output
Provide your strategy as a numbered list covering:

1. Website structure analysis and landing page identification
2. Keyword mapping and search intent alignment
3. Dependency grammar application to title tag construction
4. Title tag templates and pattern rules for programmatic generation
5. Character limit optimization and readability checks
6. Click-through rate enhancement techniques
7. Competitive differentiation approach
8. Implementation roadmap and priority sequencing
9. Sample optimized title tags for 5–10 key pages with rationale
10. Measurement and iteration plan

For each optimized title tag example, explain the dependency grammar structure and keyword placement logic.
```
