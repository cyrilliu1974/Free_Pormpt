# Mobile Image SEO Optimization Prompt

## 簡介

The Mobile Image SEO Optimization Prompt is a free AI prompt that analyzes and optimizes website images for mobile devices, improving load times, Core Web Vitals, and search rankings for SEO specialists and web developers. This mobile image SEO prompt for ChatGPT guides the AI through a six-step optimization workflow: auditing current images, calculating optimal dimensions for mobile viewports, applying strategic compression, implementing responsive techniques like srcset and lazy loading, writing keyword-appropriate alt text using dependency grammar principles, and validating improvements in load time. It runs on ChatGPT, Claude, and Gemini, producing numbered action lists with technical specifications including dimensions, compression ratios, format recommendations, and example alt text for each image type. Use it when you need to reduce mobile page weight, improve Core Web Vitals scores, or ensure images meet accessibility and search engine standards. ● Audits existing image assets and quantifies their impact on mobile load times ● Calculates viewport-appropriate dimensions and compression ratios for each image type ● Recommends responsive implementation strategies including srcset, picture elements, and lazy loading ● Generates SEO-friendly alt text using dependency grammar for clear subject-verb-object relationships ● Validates results against Core Web Vitals metrics to measure real performance gains ## Prompt

```
## Role
You are an expert mobile SEO specialist optimizing images for mobile devices to enhance website performance and user experience.

## Task
Analyze and optimize images for faster mobile load times, then create SEO-friendly alt text and captions that improve accessibility and search rankings.

## Context
Website and optimization scope:
{{website-context}}

(Include: website URL, target mobile devices, primary image formats used, industry/niche, and SEO objectives)

## Process
Follow this step-by-step optimization workflow:

1. **Audit current images** - analyze existing image sizes, formats, and load impact
2. **Determine optimal dimensions** - calculate appropriate sizes for mobile viewports
3. **Compress strategically** - reduce file sizes while preserving visual quality
4. **Implement responsive techniques** - apply srcset, picture elements, or lazy loading as appropriate
5. **Write alt text** - craft descriptive, keyword-appropriate alternatives using dependency grammar principles (establish clear subject-verb-object relationships)
6. **Validate results** - measure improvements in load time and Core Web Vitals

## Output
Provide your recommendations as a numbered list with specific actions, technical specifications (dimensions, compression ratios, format recommendations), and example alt text for key image types.
```
