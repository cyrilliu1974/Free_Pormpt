# UI Text Generator for Software Applications

## 簡介

The UI Text Generator for Software Applications is a free AI prompt that produces complete interface copy for software projects, covering everything from button labels to error messages. This UI writing prompt for ChatGPT, Claude, and Gemini helps product teams, UX writers, and developers create consistent, user-friendly text that reduces friction and builds confidence across every touchpoint in an application. The prompt delivers a structured document including application overview, target audience analysis, key feature summaries, and four categories of UI text examples: labels, tooltips, error messages, and instructional content. It also generates writing style guidelines to maintain voice consistency, plus detailed localization considerations (text expansion, cultural sensitivity, RTL support) and accessibility recommendations aligned with WCAG standards. Use it when launching a new product, redesigning an existing interface, or standardizing copy across a design system. ● Creates action-oriented labels, contextual tooltips, helpful error messages, and onboarding instructions in one workflow. ● Includes writing style guidelines to ensure consistent voice and tone across all UI elements. ● Addresses localization requirements like text expansion, date formats, and right-to-left language support. ● Provides accessibility recommendations for screen readers, plain language, and color-independent messaging. ## Prompt

```
## Role
You are a UI/UX writing expert specializing in clear, concise, user-friendly interface text for software applications.

## Task
Write comprehensive user interface text for {{application}} that enhances user experience and usability.

## Context
Effective UI writing guides users intuitively through features, maintains consistent tone, and accommodates localization and accessibility requirements. Your text should reduce friction, prevent errors, and build user confidence.

## Output
Deliver the following sections:

**Application Overview**
Summarize the application's purpose, core value proposition, and main features.

**Target Audience**
Describe who will use this application, including their technical proficiency and primary needs.

**Key Features**
List the 5-7 most important features users will interact with.

**UI Text Examples**

*Labels* (provide 3 examples)
- Button, field, and navigation labels that are scannable and action-oriented

*Tooltips* (provide 3 examples)
- Contextual help text that clarifies without cluttering

*Error Messages* (provide 3 examples)
- Messages that explain what went wrong and how to fix it

*Instructional Text* (provide 3 examples)
- Onboarding, empty states, or guidance that teaches while users work

**Writing Style Guidelines**
Define voice, tone, vocabulary level, and formatting conventions to ensure consistency across all interface text.

**Localization Considerations**
Address text expansion, cultural sensitivity, date/number formats, and RTL language support.

**Accessibility Considerations**
Cover screen reader compatibility, plain language principles, color-independent messaging, and WCAG compliance.
```
