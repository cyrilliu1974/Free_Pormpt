# Gap Analysis Framework for Curriculum Development

## 簡介

The Gap Analysis Framework for Curriculum Development is a free AI prompt that helps curriculum developers systematically identify and address discrepancies between their existing curriculum and their educational goals. This curriculum development prompt for ChatGPT guides you through a four-phase analysis: examining your current curriculum state (structure, content, delivery, assessment), defining your desired state based on industry standards and accreditation requirements, identifying specific gaps across pedagogy and technology integration, and generating prioritized recommendations with implementation timelines. It produces a markdown table with columns for Current State, Desired State, Gaps, and Recommendations, covering 6-8 critical curriculum dimensions from content scope to student outcomes measurement. Runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need to audit an existing curriculum, prepare for accreditation reviews, or align program design with institutional mission and student learning outcomes. ● Systematically compares current curriculum structure against desired outcomes and industry best practices ● Identifies gaps in content coverage, instructional design, technology integration, faculty capacity, and assessment methods ● Generates prioritized, actionable recommendations with resource requirements and implementation sequences ● Outputs a structured markdown table format that organizes findings across 6-8 critical curriculum dimensions ## Prompt

```
## Role
You are an expert curriculum developer conducting a Gap Analysis for educational institutions.

## Task
Create a comprehensive Gap Analysis Framework that identifies discrepancies between the current state and desired state of a curriculum. Work systematically through four phases:

1. **Examine the Current State**: Analyze the existing curriculum structure, content coverage, delivery methods, assessment approaches, and alignment with stated objectives.

2. **Define the Desired State**: Outline the ideal curriculum based on industry standards, accreditation requirements, student learning outcomes, institutional mission, and emerging educational best practices.

3. **Identify Gaps**: Pinpoint specific discrepancies between current and desired states across content, pedagogy, technology integration, faculty development needs, and student support.

4. **Recommend Actions**: Provide prioritized, actionable recommendations to bridge identified gaps, accounting for implementation timeline, resource requirements, stakeholder buy-in, and potential obstacles.

## Context
{{institution-and-curriculum-context}}

Include: institution name and type, specific curriculum focus area, target student demographic, key educational objectives, and available resources for curriculum development.

## Output
Present your analysis as a markdown table with four columns:

| Current State | Desired State | Gaps | Recommendations |
|---------------|---------------|------|------------------|

Each row should address a distinct aspect of curriculum development (e.g., content scope, instructional design, assessment methods, technology infrastructure, faculty capacity, student outcomes measurement).

Provide 6-8 rows covering the most critical curriculum dimensions. Make recommendations specific, measurable, and sequenced by priority.
```
