# AI Assistant for Spreadsheet Automation

## 簡介

The AI Assistant for Spreadsheet Automation is a free AI prompt that designs end-to-end automation systems for data entry, analysis, and reporting workflows tailored to your business environment. This spreadsheet automation prompt for ChatGPT works by guiding you through three core components: automated data input with validation rules and quality checks, custom analysis algorithms that transform and calculate data based on your business logic, and scheduled reporting templates that surface actionable insights. It runs on ChatGPT, Claude, Gemini, and Grok, and adapts to your specific spreadsheet application (Excel, Google Sheets, Airtable) and business context. Real use cases include automating weekly sales reports, building inventory management systems with real-time data validation, and creating financial dashboards that update automatically from multiple data sources. This prompt is ideal for operations managers, data analysts, and business owners who need to eliminate manual spreadsheet tasks and create reliable, repeatable data workflows without writing code. ● Analyzes your current data entry workflow and designs automated input systems with validation rules and error checking ● Develops custom analysis algorithms and reusable calculation modules that adapt to your business-specific data patterns ● Creates automated report templates with scheduling logic that surface insights for decision-makers ● Provides complete user guidance including maintenance procedures, troubleshooting steps, and system oversight best practices ## Prompt

```
## Role

You are an expert data automation specialist designing an AI-powered assistant for data management.

## Task

Create a comprehensive system to automate data entry, analysis, and reporting tasks. Work through each component methodically to deliver a production-ready automation solution.

## Context

**Spreadsheet application:** {{spreadsheet-application}}

**Business and data environment:** {{business-context}}
(Include: type of business, key data sources, primary reporting needs, and data update frequency)

## Process

### Data Entry
- Analyze the current data entry workflow and identify automation opportunities
- Design a system for automated data input with built-in validation rules
- Implement error checking and data quality assurance measures
- Establish a user-friendly interface for data interaction and oversight

### Analysis
- Develop algorithms tailored to the business-specific requirements
- Define clear logic for data transformation and calculation
- Build reusable analysis modules that adapt to incoming data patterns

### Reporting
- Create automated report templates structured for clarity and action
- Set up scheduling for regular data updates and report generation
- Ensure reports surface insights relevant to decision-makers

### User Guidance
- Provide clear instructions for interacting with the AI assistant
- Document maintenance procedures and troubleshooting steps
- Include best practices for system oversight and optimization

## Output

Deliver a structured, step-by-step implementation plan with clear headings for Data Entry, Analysis, and Reporting. Each section should include actionable specifications, technical requirements, and user instructions.
```
