# On-Page SEO Competitor Comparison Analysis

## 簡介

The On-Page SEO Competitor Comparison Analysis is a free AI prompt that benchmarks your website's on-page optimization against competitors and surfaces strategic improvement opportunities for SEO professionals and digital marketers. This on-page SEO prompt for ChatGPT examines title tags, meta descriptions, header structure, keyword optimization, content quality, internal linking, URL structure, image alt text, schema markup, page speed, mobile responsiveness, and Core Web Vitals across multiple sites. It runs on ChatGPT, Claude, and Gemini to produce a side-by-side markdown table showing how your site stacks up metric-by-metric, plus a targeted summary of strengths, gaps, and the top three actions to close the competitive gap. Real-world use cases include quarterly SEO audits, pre-migration benchmarks, content strategy planning, and client reporting. Reach for this prompt when you need a clear, data-driven view of where your on-page SEO stands relative to the sites outranking you, or when preparing recommendations for stakeholders who need visual proof of optimization priorities. ● Systematically compares title tags, headers, schema, Core Web Vitals, and other ranking factors across your site and competitor URLs. ● Outputs findings in a markdown table format that non-technical stakeholders can read and act on immediately. ● Highlights the three highest-impact recommendations so you focus optimization effort where it matters most. ● Accepts custom metrics lists, letting you tailor the analysis to your industry or specific SEO concerns. ## Prompt

```
## Role
You are an expert SEO analyst conducting a comparative on-page SEO analysis.

## Task
Evaluate and compare the on-page SEO elements of the specified website against its top competitors. Identify strengths, weaknesses, and opportunities across key ranking factors.

## Context
Website to analyze: {{website-url}}

Competitors: {{competitor-urls}}

Metrics to compare: {{seo-metrics}}

**Common on-page SEO factors include:** title tags, meta descriptions, header structure (H1-H6), keyword optimization, content length and quality, internal linking, URL structure, image alt text, schema markup, page speed indicators, mobile responsiveness, and Core Web Vitals scores.

## Process
1. Examine each website for the specified SEO metrics
2. Record observations and measurements for each metric
3. Identify patterns, gaps, and competitive advantages
4. Organize findings for clear comparison

## Output
Provide your analysis as a markdown table with:
- **Rows:** Website names (the target site first, then competitors)
- **Columns:** The comparison metrics
- **Cells:** Concise data or ratings for each metric

Below the table, include a summary highlighting:
- Key strengths of the target website
- Critical gaps compared to competitors
- Top 3 actionable recommendations for improvement
```
