# Real-World Examples Generator for Concepts

## 簡介

The Real-World Examples Generator for Concepts is a free AI prompt that produces 20 cited, real-world applications illustrating any concept within a specified subject area. This concept illustration prompt for ChatGPT takes two inputs - a concept and a subject area - and returns a structured list of 20 diverse examples, each with a concise explanation of how it demonstrates the concept. The output includes an introduction explaining the concept's relevance, a numbered list of applications, a difficulty matrix categorizing all examples as beginner, intermediate, or advanced, and a full source list. It runs on ChatGPT, Claude, Gemini, and Grok, making it a practical tool for educators preparing lesson materials, trainers designing workshops, students studying abstract ideas, or anyone who needs to translate theory into tangible examples. ● Produces 20 diverse, non-repetitive real-world applications for any concept and subject area you specify. ● Organizes all examples by difficulty level in a clear matrix, making it easy to match content to learner experience. ● Includes citations for every source, ensuring academic rigor and credibility. ● Provides concise explanations for each example, showing exactly how it illustrates the concept. ## Prompt

```
## Role
You are an expert in applied learning and conceptual illustration across all domains.

## Task
Generate 20 real-world applications that illustrate {{concept}} within {{subject-area}}. For each example, provide a concise explanation showing how it exemplifies the concept. Organize the examples by difficulty level and cite all sources.

## Output

### Introduction
Briefly explain {{concept}} and its relevance to {{subject-area}}.

### Examples
Provide a numbered list of 20 applications:

1. [Example]: [Concise explanation of how it illustrates the concept]
2. [Example]: [Explanation]
...
20. [Example]: [Explanation]

Ensure variety—avoid repetitive or overly similar examples.

### Difficulty Matrix
Categorize all 20 examples by complexity:

| Difficulty Level | Examples |
|------------------|----------|
| Beginner         | [List example numbers/names] |
| Intermediate     | [List example numbers/names] |
| Advanced         | [List example numbers/names] |

### Sources
Cite all references used:
- [Source 1]
- [Source 2]
- [...]
```
