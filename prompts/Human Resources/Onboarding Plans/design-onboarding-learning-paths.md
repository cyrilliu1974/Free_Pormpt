# Onboarding Learning Path Builder for New Hires

## 簡介

The Onboarding Learning Path Builder for New Hires is a free AI prompt that creates structured onboarding curricula for any role using evidence-based learning progression principles. This onboarding learning path prompt for ChatGPT, Claude, Gemini, and Grok builds a complete six-phase program that moves systematically through Bloom's Taxonomy - Remember, Understand, Apply, Analyze, Evaluate, and Create. For each phase, it defines learning objectives, practical activities, required resources, success criteria, feedback checkpoints, and progression triggers. You input the job role and onboarding context, and the prompt outputs a timeline-mapped learning path with measurable outcomes at every competency boundary. HR teams use it to replace ad-hoc training with consistent, skills-focused onboarding; managers use it to align training with actual job demands and reduce time-to-productivity. Reach for this prompt when you need to design or redesign onboarding that respects cognitive load, prevents information overload, and ensures new hires build mental models before tackling complexity. ● Produces a complete learning dashboard with phase durations, competency milestones, and a progression map from entry to mastery. ● Structures every phase around Bloom's cognitive levels, ensuring no conceptual leaps and logical skill layering. ● Defines observable success criteria and feedback checkpoints at natural competency boundaries, not arbitrary activity completion. ● Prioritizes immediate-use skills over theoretical content, reducing new hire ramp time and boosting early productivity. ## Prompt

```
## Role
You are a learning architecture specialist with expertise in cognitive science. You design onboarding systems using evidence-based learning principles, specifically Bloom's Taxonomy, to create structured progression from novice to competent performer.

## Task
Create a comprehensive onboarding learning path for {{job-role}} that moves systematically through Bloom's six cognitive levels: Remember → Understand → Apply → Analyze → Evaluate → Create. Each phase must build on the previous, with clear milestones and measurable outcomes.

## Context
{{onboarding-context}}

Address common onboarding challenges: information overload, lack of progression logic, unclear success criteria, and misalignment between training and actual job demands.

## Output
Deliver a complete learning path structured as follows:

**Learning Path Overview Dashboard**
- Total duration and phase breakdown
- Key competency milestones
- Progression map from entry to mastery

**For Each of the Six Bloom's Taxonomy Levels (Remember → Understand → Apply → Analyze → Evaluate → Create):**

**Phase Name** | Duration: [timeframe]

*Learning Objectives:*
- **Know:** Foundational knowledge required
- **Understand:** Conceptual comprehension targets
- **Apply:** Practical skills to demonstrate

*Activities:* Specific tasks and exercises aligned to this cognitive level

*Resources Needed:* Tools, materials, access, or support required

*Success Criteria:* Observable, measurable outcomes that prove competency

*Feedback Checkpoint:* How and when progress is verified

→ *Progression Trigger:* What must be demonstrated to advance to next phase

---

**Design Principles Applied:**
1. Every objective maps directly to job requirements
2. Strict Bloom's progression—no cognitive leaps
3. Milestones represent genuine skill gains, not activity completion
4. Feedback occurs at natural competency boundaries
5. Cognitive load managed through sequencing
6. Mental models built before introducing complexity
7. Immediate-use skills prioritized over theoretical knowledge
8. Each phase prepares learners for the next level of challenge

Include time estimates, resource requirements, and manager verification points throughout.
```
