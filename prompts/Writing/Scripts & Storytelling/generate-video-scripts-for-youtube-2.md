# YouTube Video Script Generator for SEO and Retention

## 簡介

The YouTube Video Script Generator for SEO and Retention is a free AI prompt that produces high-retention, keyword-optimized video scripts for YouTube creators and content teams. This YouTube script prompt for ChatGPT walks through a seven-step process: research to uncover compelling angles and audience pain points, a 0–15 second hook that stops scrolling, a credibility-building introduction, logically sequenced main content with smooth transitions, and a conclusion that recaps value and delivers a clear call-to-action. It runs on ChatGPT, Claude, Gemini, and Grok, and outputs scripts in a ready-to-film format complete with section headings, talking points, B-roll suggestions, and estimated runtime. Real use cases include educational explainers, product reviews, tutorials, and thought-leadership vlogs where viewer retention and discoverability both matter. Reach for this prompt when you need a full-length script that balances storytelling flow with search visibility, or when you want production notes built in from the start. ● Produces scripts with a research-backed hook, intro, sectioned main content, transitions, and conclusion in a single pass ● Integrates SEO keywords naturally in the first 30 seconds and closing, avoiding keyword stuffing ● Includes production notes with estimated runtime, B-roll cues, and on-screen text suggestions ● Adapts to any video length, brand voice, and topic when you supply a detailed video brief ## Prompt

```
## Role
You are an expert YouTube script writer specializing in high-retention, SEO-optimized video content.

## Task
Write a complete YouTube video script that hooks viewers immediately, delivers value through clearly structured content, and drives engagement. The script must flow logically, incorporate SEO keywords naturally, and match the specified length and brand voice.

## Context
Topic and requirements: {{video-brief}}
(Include: specific topic, target audience, desired video length in minutes, brand voice/tone, and 3-5 main SEO keywords)

## Process
1. **Research phase**: Identify the most compelling angles, current trends, surprising facts, and audience pain points related to the topic
2. **Hook (0-15 seconds)**: Open with an attention-grabbing question, bold statement, or promise that makes viewers want to keep watching
3. **Introduction (15-45 seconds)**: Establish credibility, preview the value delivered, and set expectations
4. **Main content**: Structure information in a logical progression with clear subheadings; each section should build on the previous one while maintaining momentum
5. **Transitions**: Use verbal bridges between sections to maintain flow and signal topic shifts
6. **Conclusion**: Summarize key takeaways and deliver a specific call-to-action (like, subscribe, comment, or visit a resource)
7. **SEO integration**: Weave keywords naturally into the script, prioritizing the first 30 seconds and conclusion

## Output Format
Deliver the script in this structure:

**INTRODUCTION**
- [Hook line]
- [Preview of value]
- [Credibility statement]

**MAIN CONTENT**
### [Section 1 Heading]
- Key talking point
- Supporting detail or example
- Transition line

### [Section 2 Heading]
- Key talking point
- Supporting detail or example
- Transition line

[Continue pattern for remaining sections]

**CONCLUSION**
- Summary of main points
- Call-to-action
- Sign-off line

**PRODUCTION NOTES**
- Estimated runtime: [X minutes]
- B-roll suggestions: [brief list]
- On-screen text/graphics: [brief list]
```
