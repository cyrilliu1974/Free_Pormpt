# Satellite Island View Image Generator

## 簡介

The Satellite Island View Image Generator is a free AI prompt that produces overhead satellite imagery of custom island geographies with intricate water channels and cinematic color treatment. This satellite island prompt for Midjourney generates top-down aerial views where landmasses and connecting channels are clearly visible, enhanced by a distinctive teal-and-gold color grade. The prompt uses overhead lighting to emphasize geographic detail and explicitly excludes clouds and atmospheric haze to maintain sharp, unobstructed clarity. Cartographers, game environment artists, travel marketers, and world-builders use it to create stylized yet detailed island renders that blend geographic accuracy with visual appeal. It runs on Midjourney, Flux, Nano Banana, and similar image-generation models. Reach for this prompt when you need clean aerial island imagery with professional color grading for conceptual maps, game worlds, travel visuals, or environmental design that requires both topographic precision and aesthetic control. ● Accepts custom island geography input to generate tailored overhead satellite perspectives ● Applies teal-and-gold color grading for cinematic yet naturalistic water and land tones ● Uses overhead lighting and excludes clouds or haze for maximum topographic clarity ● Outputs 1:1 square images with high quality and detail settings optimized for geographic features ## Prompt

```
High-resolution satellite view of {{island-geography}}, intricate channels visible between landmasses. Teal-and-gold color grade. Overhead lighting --ar 1:1 --s 40 --q 2 --c 0 --no clouds haze
```
