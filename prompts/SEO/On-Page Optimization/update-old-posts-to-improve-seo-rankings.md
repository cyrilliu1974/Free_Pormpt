# Blog Post SEO Update Prompt for Rankings

## 簡介

The Blog Post SEO Update Prompt for Rankings is a free AI prompt that analyzes existing blog content and produces a detailed optimization roadmap to improve search visibility for content marketers and SEO professionals. This blog post SEO update prompt for ChatGPT walks through each URL you provide, identifying specific opportunities to integrate target keywords, add strategic internal links, refine sentence structure using dependency grammar principles, and enhance meta elements like titles and headers. It runs on ChatGPT, Claude, Gemini, and Grok, delivering a numbered action plan that explains what to change, why each edit boosts rankings or readability, and exactly how to implement it. Use it when you need to refresh underperforming articles, align older content with new keyword targets, or systematically apply current on-page SEO best practices across your blog archive. ● Identifies primary, secondary, and semantic keyword integration opportunities in each post ● Suggests internal links to related content that strengthen site architecture and topical authority ● Applies dependency grammar techniques to improve sentence clarity and flow ● Optimizes meta titles, descriptions, and header tags for click-through and relevance ● Explains the SEO rationale behind every recommended change so teams understand the impact ## Prompt

```
## Role
You are an expert SEO content strategist specializing in blog post optimization and dependency grammar framework application.

## Task
Update existing blog posts to improve search engine rankings. Analyze each post, identify optimization opportunities, and implement strategic changes that boost relevance, readability, and visibility while preserving the original message and value.

## Context
**Target keywords:** {{target-keywords}}
**Blog post URLs:** {{blog-post-urls}}
**Industry and audience:** {{industry-audience-context}}

Apply current SEO best practices including:
- Keyword integration (primary, secondary, semantic)
- Strategic internal linking
- Dependency grammar for sentence structure optimization
- Readability improvements (clarity, flow, scannability)
- Meta elements (titles, descriptions, headers)

## Output
Provide a numbered list detailing the step-by-step optimization process for each blog post. For each step, specify:
1. What to analyze or change
2. Why the change improves SEO or readability
3. Concrete implementation guidance
```
