# Backlink Management Strategy Prompt for ChatGPT

## 簡介

The Backlink Management Strategy Prompt is a free AI prompt that builds a comprehensive backlink monitoring and management system for SEO professionals and website owners. This backlink management prompt for ChatGPT produces a detailed operational plan covering tool recommendations, weekly and monthly monitoring workflows, harmful link identification criteria, dashboard KPIs, reporting schedules, and step-by-step remediation protocols. It runs on ChatGPT, Claude, and Gemini, transforming a single website URL into a structured backlink health strategy that includes outreach templates, disavow file instructions, and proactive relationship-building tactics. SEO managers use it to standardize their link audit process, marketing teams deploy it to protect domain authority, and agencies apply it to deliver client-ready backlink governance frameworks. Reach for this prompt when you need to establish a repeatable system for tracking referring domains, spotting toxic links, and responding to backlink threats before they impact search rankings. ● Recommends 3-5 industry-standard backlink analysis tools matched to your site's scale and budget ● Defines step-by-step weekly and monthly monitoring workflows with specific metrics like link velocity, anchor text distribution, and domain authority trends ● Establishes clear toxic link criteria based on spam scores, content relevance, link placement context, and referring page indexation status ● Specifies 4-6 dashboard KPIs and visualizations for quick health assessment and executive reporting ● Provides prioritization frameworks, outreach templates, Google Disavow Tool implementation steps, and documentation requirements for harmful link remediation ● Includes proactive content strategies, relationship-building tactics, and competitive monitoring practices to maintain long-term backlink health ## Prompt

```
## Role
You are an expert SEO strategist specializing in backlink analysis and management.

## Task
Create a comprehensive routine for monitoring, analyzing, and managing the backlink profile for {{website-url}}.

## Output
Deliver a structured backlink management plan covering:

**Backlink Analysis Tools**
- Recommend 3-5 industry-standard tools suited to the website's scale and budget

**Monitoring Routine**
1. Step-by-step weekly and monthly monitoring workflow
2. Key metrics to track (referring domains, link velocity, anchor text distribution, domain authority trends)
3. Alert thresholds for unusual activity

**Harmful Link Criteria**
Define red flags that identify toxic backlinks:
- Domain authority and trust metrics
- Spam scores and content relevance
- Link placement context (sidebar, footer, editorial)
- Traffic and indexation status of referring pages

**Dashboard Components**
Specify 4-6 KPIs and visualizations for a tracking dashboard that enables quick health assessment and executive reporting

**Reporting Frequency**
Recommend cadence for internal reviews and stakeholder reports based on website size and link acquisition velocity

**Action Plan for Harmful Links**
1. Prioritization framework (impact × urgency)
2. Outreach templates for removal requests
3. Google Disavow Tool implementation steps
4. Documentation requirements

**Proactive Measures**
Ongoing practices to maintain a healthy backlink profile, including content strategies, relationship building, and competitive monitoring
```
