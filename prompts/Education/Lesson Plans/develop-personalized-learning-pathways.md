# Adaptive Learning Pathways Prompt for Education

## 簡介

The Adaptive Learning Pathways Prompt for Education is a free AI prompt that designs three distinct, branching educational routes tailored to student performance, learning styles, and preferences. This adaptive learning pathways prompt for ChatGPT creates flowchart-structured lesson plans with decision points that route learners through activities matched to their needs. Each pathway includes two branching decision points - triggered by assessments, engagement patterns, or mastery demonstrations - and four learning activities complete with credible source citations. Educators use it to differentiate instruction for beginner through advanced students, accommodate visual, auditory, and kinesthetic learners, and support collaborative, independent, or project-based work preferences. It runs on ChatGPT, Claude, and Gemini. This prompt is ideal for instructional designers, K-12 teachers, curriculum developers, and corporate trainers who need to build differentiated learning experiences that adapt to diverse student populations. ● Outputs three complete pathways: performance-based, learning style-based, and preference-based routes for any topic and subject ● Includes two decision points per pathway that branch learners into alternative routes based on real-time assessment or engagement data ● Provides four cited learning activities per pathway, ensuring every route is backed by credible educational sources ● Structures output as a clear flowchart format that educators can immediately implement or adapt in their lesson plans ## Prompt

```
## Role
You are an adaptive learning pathways designer creating personalized educational experiences.

## Task
Design three distinct learning pathways for {{topic}} in {{subject}}, each organized as a flowchart structure. Base the pathways on:
1. Student performance levels (beginner/intermediate/advanced)
2. Learning styles (visual/auditory/kinesthetic)
3. Student preferences (collaborative/independent/project-based)

## Requirements
For each pathway:
- Define two key decision points that branch learners into different routes based on assessment results, engagement patterns, or demonstrated mastery
- Provide two learning activities per route (four activities total per pathway)
- Cite a credible source for each learning activity
- Ensure activities are appropriate for the learner type and build progressively

**Subject:** {{subject}}

### Pathway 3: Preference-Based Learners
```
