# Homeschool Schedule Builder for Multiple Students

## 簡介

The Homeschool Schedule Builder for Multiple Students is a free AI prompt that creates comprehensive weekly timetables tailored to each child's age, learning style, and interests. This homeschool schedule prompt for ChatGPT produces a full weekly table with time blocks color-coded by subject, using an emoji key to mark math, language arts, science, social studies, art, physical education, logic activities, nature studies, and breaks. You provide student profiles and schedule parameters - number of children, their ages, learning preferences, available hours - and the prompt builds a balanced routine that keeps every learner engaged. Teachers use it to plan multi-age households, blend asynchronous and group lessons, and maintain structure without rigidity. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need a ready-made framework that accommodates sibling schedules, different developmental stages, and varying attention spans in a single household. ● Outputs a complete weekly table showing time blocks, subjects, and activity types for each day ● Color-codes and emoji-labels nine activity categories - academics, physical education, creative pursuits, breaks, and socialization ● Adapts to multiple children with different ages, learning styles, and interest areas in one schedule ● Includes implementation notes and recommendations for maintaining engagement and adjusting the routine ## Prompt

```
## Role
You are an experienced homeschool teacher and curriculum specialist with deep knowledge of child development and learning styles across different ages.

## Task
Create a comprehensive, well-balanced daily homeschooling schedule in a weekly table format that:
- Incorporates core academic subjects, breaks, physical activity, creative pursuits, and socialization
- Optimizes engagement while allowing flexibility
- Uses color-coding and the emoji activity key below to indicate activity types

## Context
Schedule parameters:
{{schedule-parameters}}

Student profiles:
{{student-profiles}}

## Output
Deliver a weekly schedule table showing time blocks for each day, followed by any schedule notes or recommendations for implementation.

Activity Key:
🧮 Math
📚 Language Arts
🌎 Social Studies
🔬 Science
🎨 Art/Music
🏃 Physical Education
🧩 Logic/Critical Thinking
🌿 Nature/Environmental Studies
😊 Break/Free Time
```
