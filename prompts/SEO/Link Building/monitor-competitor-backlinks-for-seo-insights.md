# Competitor Backlink Analysis for SEO Strategy

## 簡介

The Competitor Backlink Analysis for SEO Strategy is a free AI prompt that examines competitor backlink profiles and surfaces actionable link building opportunities for SEO professionals and content marketers. This competitor backlink analysis prompt for ChatGPT works by investigating a rival website's inbound links, filtering for high-authority domains, relevant anchor text, and replicable link patterns. You supply the competitor URL, your own site, your industry, and target keywords; the AI returns a markdown table of the most valuable backlinks alongside strategic recommendations for outreach, guest posting, and content partnerships. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need to reverse-engineer a competitor's link profile, discover untapped referral domains, or validate your own outreach targets. ● Outputs a three-column table (URL, Anchor Text, Link Type) ranking the most valuable competitor backlinks by authority and relevance. ● Identifies anchor text patterns, content types, and topics that consistently attract quality links. ● Highlights gaps in the competitor's profile that you can exploit and suggests specific outreach targets. ● Delivers concise recommendations for guest posting, content partnerships, and replicable link building tactics aligned with your target keywords. ## Prompt

```
## Role

You are an expert SEO analyst specializing in competitive backlink analysis and link building strategy.

## Task

Analyze the backlink profile of {{competitor-url}} and produce a comprehensive report that identifies high-quality, relevant backlinks and actionable link building opportunities for {{your-website}}.

## Context

Industry: {{industry}}
Target keywords: {{target-keywords}}

Focus your analysis on backlinks that demonstrate:
- High domain authority and relevance
- Strong alignment with the target keywords
- Replicable link building patterns
- Content partnership and guest posting opportunities

## Output

**Backlink Analysis Table:**

Present the most valuable backlinks in a markdown table with three columns:

| URL | Anchor Text | Link Type |
|-----|-------------|----------|

**Key Insights & Recommendations:**

Follow the table with a concise bullet-point list covering:
- High-value backlink sources worth pursuing
- Anchor text strategies the competitor is using successfully
- Content types or topics that attract quality links
- Gaps in the competitor's profile that represent opportunities
- Specific outreach or content creation recommendations
```
