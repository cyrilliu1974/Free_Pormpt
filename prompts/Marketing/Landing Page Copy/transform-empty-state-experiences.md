# Empty State UX Design Prompt for E-Commerce

## 簡介

The Empty State UX Design Prompt for E-Commerce is a free AI prompt that turns abandoned pages into conversion opportunities for online retailers and product teams. This empty state UX design prompt for ChatGPT, Claude, Gemini, and Grok produces complete design specifications for cart, wishlist, and zero-result search pages. It delivers visual concepts (imagery, color, layout), four tone variations (humorous, professional, empathetic, aspirational), behavioral-based product recommendations, CTA button options, and reusable HTML-like templates. E-commerce teams use it to replace generic "Your cart is empty" placeholders with designs that acknowledge user intent and guide next actions without feeling pushy. Reach for this prompt when redesigning checkout flows, auditing user drop-off points, or building design systems that need consistent empty-state patterns across page types. ● Creates visual concepts with mood, color palette, and layout structure tailored to each empty-state context. ● Writes copy in four tones so teams can A/B test voice or match different user segments and brand personalities. ● Suggests product discovery logic tied to behavioral triggers, not random inventory pushes. ● Outputs reusable template structures and implementation notes covering accessibility, device responsiveness, and when to deploy each variation. ## Prompt

```
## Role
You are an empty-state UX designer who specializes in turning abandoned e-commerce pages into conversion opportunities. You understand that empty carts, wishlists, and zero-result searches trigger user frustration, and you know how to redirect that moment into discovery and engagement.

## Task
Design empty-state experiences for the specified page types that acknowledge user intent, provide immediate next actions, and guide users toward productive browsing. Create visual concepts, copy in multiple tones, and product discovery strategies that feel helpful rather than pushy.

## Context
{{business-context}}

Include: page types (cart, wishlist, search results, etc.), brand voice and personality, target audience expectations, main product categories, and any technical or brand design constraints.

## Output
For each page type, deliver:

**[Page Type] Empty State Design**

*Visual Concept:*
- Imagery/illustration description
- Color palette and mood
- Layout structure

*Copy Variations:*
- Humorous version
- Professional version
- Empathetic version
- Aspirational version

*Discovery Suggestions:*
- Behavioral trigger used
- Product recommendation logic
- CTA button text options (3–4 alternatives)

*Reusable Template Structure:*
```
[Container]
 [Visual Element]
 [Headline]
 [Subtext]
 [Discovery Section]
 [Primary CTA]
 [Secondary CTA]
```

*Implementation Notes:*
- When to use each tone variation
- A/B testing recommendations
- Accessibility considerations

**Design Criteria:**
- Acknowledge user intent and offer immediate next action
- Visual elements create connection without overwhelming
- Copy is scannable: headline → subtext → CTA
- Suggestions relate to behavior patterns, not random inventory
- Templates work across devices
- Avoid generic placeholders, stock imagery, or user-blaming messages
- Fast loading, works without JavaScript
```
