# TikTok Scriptwriting Coach

## 簡介

The TikTok Scriptwriting Coach is a free AI prompt that writes ready-to-record 30-second motivational scripts for content creators, influencers, and marketers building short-form video content. This TikTok script prompt for ChatGPT produces a three-part spoken-word script optimized for social media attention spans: a powerful opening statement designed to hook viewers in the first two seconds, 5-7 standalone motivational sentences that build emotional momentum using rhetorical devices like repetition and contrast, and a 2-3 sentence call to action that drives viewers toward a concrete next step. It runs on ChatGPT, Claude, Gemini, and Grok, turning a single topic variable into a complete script format with clear structural markers. Creators use it to produce consistent, scroll-stopping content on themes like resilience, self-belief, and determination without spending hours on each script. Reach for this prompt when you need to turn an idea into a polished 30-second TikTok video script quickly, or when you want to maintain a motivational content calendar without writing fatigue. ● Outputs scripts in a fixed three-part format with labeled sections for opening, motivational body, and call to action ● Uses proven rhetorical techniques - questions, contrast, and repetition - to build emotional momentum in under 30 seconds ● Ensures every sentence is short and punchy enough to land clearly in spoken-word video format ● Focuses on universal motivational themes that resonate with broad social media audiences ## Prompt

```
## Role

You write short-form social media scripts for TikTok that capture attention in the first two seconds and leave viewers with a clear emotional takeaway.

## Task

Write a 30-second TikTok script on the following topic:

{{topic}}

## Structure

Deliver the script in three parts:

**1. Powerful Opening Statement**  
One sentence that hooks immediately through curiosity or strong emotion. No preamble.

**2. Motivational Content**  
5 to 7 short, standalone sentences building momentum. Draw on universal themes—resilience, courage, self-belief, determination. Use rhetorical devices: repetition, questions, contrast.

**3. Call to Action**  
2 to 3 energizing sentences that leave the viewer ready to act and push them toward their potential with a concrete next step.

## Constraints

- Every sentence is short and punchy—no run-ons
- Start with the message immediately—no introduction or warm-up
- Language is positive, uplifting, and accessible to a broad audience
- Ensure every line lands clearly in a 30-second spoken video

## Output

Format the script exactly as:

**Powerful Opening Statement:**  
[Opening statement]

**Motivational Content:**  
[Sentence 1]  
[Sentence 2]  
[Sentence 3]  
[Sentence 4]  
[Sentence 5]  

**Call to Action:**  
[Sentence 1]  
[Sentence 2]  
[Sentence 3]
```
