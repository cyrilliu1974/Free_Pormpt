# Personal Growth Tracker Prompt for Goal Setting

## 簡介

The Personal Growth Tracker Prompt for Goal Setting is a free AI prompt that builds a structured skill-assessment table and actionable development roadmap for individuals committed to continuous improvement. This personal growth tracker prompt for ChatGPT guides users through honest self-evaluation by creating a markdown table that maps specific skills to current and target proficiency levels. It then defines clear progression markers across four stages - beginner, intermediate, advanced, and mastery - and recommends concrete resources, exercises, and daily habits tailored to each skill. The prompt runs on ChatGPT, Claude, Gemini, and Grok, delivering both the tracking framework and the strategic guidance needed to move between skill levels. Use cases include career development planning, learning new technical abilities, building leadership competencies, and tracking personal wellness goals. This prompt is designed for coaches, self-directed learners, managers conducting development reviews, and anyone who wants measurable milestones instead of vague aspirations. ● Produces a three-column markdown table (Skill, Current Level, Target Level) for honest capability assessment ● Defines beginner-to-mastery progression markers with clear criteria for each stage ● Recommends specific resources, exercises, and daily habits mapped to individual skills ● Maintains a supportive, action-oriented tone that emphasizes sustainable, iterative progress ## Prompt

```
## Role
You are an expert personal growth coach specializing in skill assessment and goal-setting. Help the user build a structured personal development plan with honest evaluation and actionable progression paths.

## Task
Create a "Personal Growth Tracker" table with three columns:
1. **Skill**: The specific ability or area for development
2. **Current Level**: Honest assessment of present capability
3. **Target Level**: Challenging but achievable goal

For each skill in the table, define clear progression markers across four stages: beginner, intermediate, advanced, and mastery. Then recommend specific resources, exercises, or daily habits that support movement between levels.

## Context
Skills and levels to track:
{{skills-and-levels}}

## Output
Deliver the tracker as a markdown table followed by:
- **Level Descriptions**: Clear criteria defining beginner → intermediate → advanced → mastery for each skill
- **Growth Strategies**: Specific resources, exercises, and habits mapped to each skill
- **Encouragement**: Brief reminder that sustainable progress is iterative and personal growth is lifelong

Maintain a supportive tone. Focus on actionable guidance over abstract advice.
```
