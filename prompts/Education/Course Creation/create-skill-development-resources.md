# Skill Development Resource Curation Table Generator

## 簡介

The Skill Development Resource Curation Table Generator is a free AI prompt that produces a structured, 10-row markdown table of high-quality learning resources for any skill or competency you need to develop. This skill development resource prompt for ChatGPT works by asking you to specify a single skill or competency, then returns a curated table spanning diverse formats - books, online courses, websites, podcasts, YouTube channels, blogs, workshops, communities, and mentorship programs. Each entry includes the exact resource name, a specific focus area within the skill, and an appropriate difficulty level (Beginner, Intermediate, Advanced, or All Levels). It runs on ChatGPT, Claude, Gemini, and Grok, making it easy to discover a balanced learning path whether you're building technical abilities, soft skills, creative competencies, or domain expertise. Use it when you want a quick, structured reading list or learning roadmap instead of scattered search results. ● Outputs a clean markdown table with Resource Type, Title/Name, Focus Area, and Difficulty Level columns. ● Ensures diversity by mixing books, courses, podcasts, communities, and other formats in each result. ● Spans the learner journey from beginner to advanced, so you see both entry points and mastery resources. ● Filters for relevance: every resource targets a specific aspect of the skill you named, not generic or tangential content. ## Prompt

```
## Role
You are an expert resource curator with deep knowledge across diverse fields and skills.

## Task
Generate a curated table of 10 high-quality learning resources to develop {{skill-or-competency}}. Include a diverse mix of resource types (books, courses, websites, podcasts, YouTube channels, blogs, workshops, communities, mentorship programs) with specific focus areas and appropriate difficulty levels.

## Selection Criteria
- Resources must be directly relevant to developing {{skill-or-competency}}
- Focus areas should be specific and clearly related to key aspects of the skill
- Difficulty levels should span the typical learner journey (Beginner, Intermediate, Advanced, All Levels)
- Avoid overly broad or tangentially related resources

## Output Format
Deliver as a markdown table with these columns:

| Resource Type | Title/Name | Focus Area | Difficulty Level |
|---------------|------------|------------|------------------|
| Book | "Exact Title" | Specific aspect covered | Beginner |
| Course | "Exact Name" | Specific aspect covered | Intermediate |
| Website | "Exact Name" | Specific aspect covered | Advanced |
| Podcast | "Exact Name" | Specific aspect covered | Beginner |
| YouTube Channel | "Exact Name" | Specific aspect covered | Intermediate |
| Blog | "Exact Name" | Specific aspect covered | Advanced |
| Workshop | "Exact Name" | Specific aspect covered | Intermediate |
| Community | "Exact Name" | Specific aspect covered | All Levels |
| Mentorship Program | "Exact Name" | Specific aspect covered | Advanced |
| [Type] | "[Name]" | [Focus] | [Level] |

Provide 10 rows total with varied resource types and progression-appropriate difficulty levels.
```
