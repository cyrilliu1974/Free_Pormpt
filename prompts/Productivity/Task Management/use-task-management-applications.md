# Task Management Application Implementation Guide

## 簡介

The Task Management Application Implementation Guide is a free AI prompt that creates customized setup and workflow strategies for teams adopting task management software. This task management prompt for ChatGPT walks you through configuring any task management application - from account structure and user roles to custom workflows and collaboration protocols - based on your specific team size, industry, project types, and productivity bottlenecks. It runs on ChatGPT, Claude, Gemini, and Grok, producing a numbered implementation guide with seven core sections: initial setup and configuration, task prioritization frameworks, deadline setting techniques, custom workflow design, template libraries for recurring projects, team collaboration features, and metrics for continuous optimization. Whether you're onboarding a remote team to Asana, configuring ClickUp for an agency, or standardizing Trello workflows for product development, the prompt delivers concrete action steps tailored to your application's capabilities and your team's real challenges. Use this prompt when you need more than generic setup instructions - when your team has specific pain points like missed deadlines, unclear priorities, or collaboration breakdowns that a cookie-cutter approach won't solve. ● Configures account structure, user roles, and workspace organization tailored to team composition and project scope ● Designs task prioritization frameworks and deadline strategies that account for realistic time estimation and buffer planning ● Maps custom workflows with defined status stages and handoff points specific to your project types ● Establishes template libraries, collaboration protocols, and tracking metrics that directly resolve stated productivity pain points ## Prompt

```
## Role
You are a task management expert specializing in productivity workflow optimization.

## Task
Create a comprehensive implementation guide for {{task-management-app}} that addresses the team's specific workflow needs and productivity challenges.

## Context
Team context: {{team-context}}

Current challenges: {{productivity-pain-points}}

The guide should help the team set up the application from scratch, establish sustainable workflows, and adopt practices that directly resolve their existing bottlenecks.

## Output
Provide a numbered implementation guide with clear section headings that covers:

1. **Initial Setup & Configuration** - Account structure, user roles, and workspace organization tailored to the team size and project types
2. **Task Prioritization Framework** - Methods for distinguishing urgent vs. important work and establishing priority levels
3. **Deadline Setting Strategy** - Techniques for realistic time estimation and buffer planning
4. **Custom Workflow Design** - Step-by-step processes mapped to the specific project types, including status stages and handoff points
5. **Template Library** - Standardized templates for recurring project types to eliminate setup redundancy
6. **Team Collaboration Features** - Communication protocols, notification settings, and visibility configurations
7. **Metrics & Optimization** - Key indicators to track and iterative improvement practices

For each section, provide concrete action steps specific to the application's capabilities and the team's context.
```
