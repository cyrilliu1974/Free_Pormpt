# Project Management Software Setup and Workflow Guide

## 簡介

The Project Management Software Setup and Workflow Guide is a free AI prompt that builds a customized implementation roadmap for teams adopting or optimizing a project management system. This project management prompt for ChatGPT walks you through initial tool configuration, task assignment best practices, progress tracking methods, and team collaboration protocols tailored to your specific tool, team size, and project type. Whether you're onboarding a remote team to Asana, structuring sprints in Jira, or organizing client deliverables in Monday.com, the prompt delivers concrete setup steps, workflow recommendations, and a sample task structure table to demonstrate effective task organization. It runs on ChatGPT, Claude, Gemini, and Grok, adapting guidance to your industry and experience level. Designed for project managers, team leads, and operations professionals implementing or refining project management workflows across any tool or team configuration. ● Produces tool-specific configuration steps covering workspace setup, permissions, and organizational structure ● Delivers task assignment frameworks with priority systems, workload balancing criteria, and deadline protocols ● Outlines progress tracking methods including status cadences, visual dashboards, and milestone tracking approaches ● Includes a sample task structure table demonstrating effective task breakdown, assignment, and deadline formatting ## Prompt

```
## Role
You are a project management expert specializing in system implementation and team workflow optimization.

## Task
Provide a comprehensive guide for setting up and using a project management system. Cover initial configuration, task assignment workflows, progress tracking methods, and team collaboration practices. Include concrete steps, best practices, and a demonstration task structure.

## Context
Project management tool: {{tool-name}}
Team and project details: {{team-and-project-context}}

(In {{team-and-project-context}}, describe your team size, project type, industry, and your current experience level with project management.)

## Output
Structure your guide with:

**1. Initial Setup**
- Tool configuration steps
- Workspace organization
- Permission and access settings

**2. Task Assignment Best Practices**
- How to create clear, actionable tasks
- Assignment criteria and workload balancing
- Priority and deadline frameworks

**3. Progress Tracking Methods**
- Status update cadences
- Visual progress indicators (boards, charts, dashboards)
- Milestone and deliverable tracking

**4. Team Collaboration & Communication**
- Communication channels within the tool
- Update and notification protocols
- File sharing and documentation practices

**5. Sample Task Structure**
Include a table with three columns (Task | Assignee | Deadline) demonstrating how to structure project tasks effectively.

Tailor all recommendations to the specific tool and context provided.
```
