# Website Information Architecture Optimizer

## 簡介

The Website Information Architecture Optimizer is a free AI prompt that analyzes any website and builds a logical content hierarchy for information architects, webmasters, and SEO specialists. This information architecture prompt for ChatGPT walks through a systematic six-step process: it identifies 3-5 primary user goals, develops main content categories and subcategories using mind mapping, maps key pages to user intentions, designs intuitive navigation structures, creates internal linking strategies, and outputs a comprehensive site map. The prompt runs on ChatGPT, Claude, Gemini, and Grok, producing structured deliverables that balance user experience with search engine discoverability. Real-world use cases include site redesigns, technical SEO audits, content migration planning, and fixing navigation problems that hurt both users and crawl efficiency. Reach for this prompt when you need to untangle a confusing site structure, prepare for a CMS migration, or diagnose why important pages are not being indexed. ● Maps website content to user goals and generates keyword-rich category labels ● Keeps hierarchy shallow (three levels maximum) to improve both UX and crawl depth ● Produces a navigation structure, internal linking strategy, and full site map in one pass ● Prioritizes SEO fundamentals like descriptive URLs, logical groupings, and discovery paths for search engines ## Prompt

```
## Role
You are an expert information architect and webmaster, skilled in organizing content logically to optimize site navigation and search engine crawlability.

## Task
Analyze the provided website and develop a clear, intuitive content hierarchy that optimizes both user navigation and search engine crawlability.

## Context
Website URL: {{website-url}}

## Process
1. Analyze the website and identify 3-5 primary user goals
2. Develop main content categories and subcategories using a mind mapping approach
3. Identify key pages and map them to the primary user goals
4. Create a logical navigation structure based on the content hierarchy
5. Develop an internal linking strategy to enhance discoverability and crawlability
6. Provide a comprehensive site map outlining the information architecture

## Requirements
- Prioritize user experience and SEO when organizing content
- Use descriptive, keyword-rich labels for categories, subcategories, and pages
- Avoid overly complex or deep hierarchies (aim for 3 levels maximum where possible)
- Ensure the navigation structure is intuitive and easy to understand
- Design internal linking to support both user journeys and search engine discovery

## Output
Provide your analysis in the following structure:

**Primary User Goals:**
- [List 3-5 goals]

**Main Content Categories:**
1. [Category name]
   - [Subcategory]
   - [Subcategory]
2. [Category name]
   - [Subcategory]
   - [Subcategory]

**Key Pages:**
• [Page name] → [Primary goal it serves]
• [Page name] → [Primary goal it serves]

**Navigation Structure:**
[Describe the proposed navigation menu and user flow]

**Internal Linking Strategy:**
[Explain how pages should link to each other to support navigation and SEO]

**Site Map:**
[Provide a hierarchical outline of all pages and their relationships]
```
