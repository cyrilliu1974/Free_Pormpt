# Online Course Outline Builder for Passive Income Topics

## 簡介

The Online Course Outline Builder for Passive Income Topics is a free AI prompt that creates comprehensive course structures for educators and content creators teaching passive income skills. This online course creation prompt for ChatGPT helps instructional designers and entrepreneurs develop logically sequenced curricula where each module builds on previous concepts using dependency grammar principles. It generates module-by-module breakdowns complete with learning objectives, video lesson topics, downloadable resources like worksheets and templates, and interactive quiz formats. The prompt runs on ChatGPT, Claude, Gemini, and Grok, producing course outlines tailored to your specific subject matter, target audience, desired course length, and learning outcomes. Real-world applications include building courses on affiliate marketing, digital product creation, real estate investing, or any passive income methodology. This prompt is ideal for solopreneurs launching their first course, educators pivoting to online teaching, or instructional designers who need a structured framework that ensures knowledge builds logically and learners can immediately apply practical skills. ● Produces complete course outlines with module titles, learning objectives, and content breakdowns ● Identifies prerequisite relationships so learners master foundational concepts before advancing ● Specifies downloadable resource types (checklists, templates, case studies) for each module ● Includes practical exercises and real-world application scenarios to reinforce skills ## Prompt

```
## Role
You are an expert instructional designer specializing in online courses for passive income generation.

## Task
Create a comprehensive course outline that includes video lessons, downloadable resources, and interactive quizzes. Structure the content using dependency grammar principles to ensure logical progression where each concept builds naturally on previous ones.

## Context
Target audience: {{target-audience}}

Subject matter: {{subject-matter}}

Desired course length: {{course-length}}

Key learning outcomes: {{learning-outcomes}}

The course should emphasize practical, applicable skills that learners can immediately use to create passive income streams. Apply instructional design best practices: clear learning objectives for each module, varied content formats (video, text, worksheets, case studies), and opportunities for practice through exercises and real-world application scenarios.

## Output
Provide a detailed course outline formatted with:
- Course title and overview
- Module-by-module breakdown with headings and subheadings
- For each module: learning objectives, video lesson topics, downloadable resources (worksheets, templates, checklists), and quiz/assessment types
- Logical dependency flow showing prerequisite concepts
- Practical exercises or projects for skill application
- Bullet points to organize structure and content clearly
```
