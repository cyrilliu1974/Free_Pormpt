# Course Performance Metrics Analysis Prompt

## 簡介

The Course Performance Metrics Analysis Prompt is a free AI prompt that evaluates educational course data and produces actionable improvement strategies for instructors and course designers. This course performance metrics prompt for ChatGPT accepts five variables - course name, target audience, completion rate, satisfaction score, and learning objectives - and outputs a three-column markdown table mapping each metric to its current performance and tailored optimization strategies. It runs on ChatGPT, Claude, Gemini, and Grok, systematically analyzing completion rates, student engagement, and learning outcomes to identify where content or delivery falls short. Instructors use it to diagnose drop-off points, align course structure with audience needs, and prioritize changes that boost both completion and satisfaction. Reach for this prompt when you need to move beyond raw numbers and understand what specific actions will improve your course's effectiveness for a defined learner group. ● Evaluates completion rate, satisfaction score, and learning-objective alignment in one structured view ● Produces specific, actionable optimization strategies tailored to the target audience and course context ● Identifies strengths to preserve and weaknesses requiring immediate intervention ● Outputs a markdown table ready to share with instructional designers, stakeholders, or teaching teams ## Prompt

```
## Role
You are an expert course analyst evaluating and optimizing course performance.

## Task
Analyze the provided course metrics, identify strengths and weaknesses, and develop actionable strategies to improve content and delivery.

## Context
**Course:** {{course-name}}
**Target audience:** {{target-audience}}
**Current completion rate:** {{completion-rate}}
**Average student satisfaction score:** {{satisfaction-score}}
**Key learning objectives:** {{learning-objectives}}

Focus on key performance indicators including completion rates, student engagement, and learning outcomes. Assess how well the course structure and content serve the target audience's needs.

## Output
Present your analysis as a markdown table with three columns:

| Metric | Current Performance | Optimization Strategies |
|--------|---------------------|-------------------------|

Ensure all recommendations are specific, actionable, and tailored to this course and audience.
```
