# Product Comparison Infographic Design Prompt

## 簡介

The Product Comparison Infographic Design Prompt is a free AI prompt that creates comprehensive design specifications for side-by-side product comparison infographics tailored to specific audiences. This product comparison infographic prompt for ChatGPT guides you through a systematic process: analyze products against chosen criteria, extract features and drawbacks, structure information into parallel bullet points, and specify visual treatments including layout grids, color palettes, typography systems, and icon recommendations. It works with ChatGPT, Claude, Gemini, and Grok to output actionable design briefs that graphic designers, marketers, and content creators can hand directly to design tools or production teams. Use it when you need to help audiences compare software platforms, physical products, service tiers, or any two offerings in a fair, scannable format. ● Structures product information into symmetrical, side-by-side layouts with equal visual weight for fairness ● Specifies color palettes, typography hierarchies, and icon styles tailored to your target audience ● Balances feature lists, benefits, and drawbacks in scannable bullet-point format ● Recommends visual separators, data visualization elements, and whitespace strategies to enhance readability ## Prompt

```
## Role
You are an expert graphic designer specializing in comparative infographics that help audiences make informed product decisions.

## Task
Create a detailed specification for a comparative infographic that presents two products side-by-side, highlighting their features, benefits, and drawbacks in a visually compelling and balanced format.

## Context
Products being compared: {{products}}
Comparison criteria: {{comparison-points}}
Target audience: {{audience}}

## Process
1. Analyze both products across the specified comparison criteria
2. Extract key features, benefits, and drawbacks for each product
3. Structure information into parallel, scannable bullet points
4. Design a symmetrical layout that allows direct side-by-side comparison
5. Recommend specific icons, graphics, or product imagery that clarify each point
6. Specify contrasting visual treatments (colors, typography, spacing) to distinguish the two products while maintaining cohesion
7. Ensure hierarchy through heading levels, font sizing, and visual weight
8. Balance information density—each product receives equal visual space and detail
9. Verify that all claims are substantiated by the product information provided

## Output
Provide a comprehensive infographic specification using this structure:

**Layout & Visual Framework**
- Overall composition and grid structure
- Color palette with specific usage (suggest a professional scheme appropriate for the audience)
- Typography system (headings, body, labels)
- Icon/graphic style direction

**Content Blocks** (organized left-to-right or top-to-bottom):
- Product headers with identifying visuals
- Feature comparison section (bullet points)
- Benefits section (bullet points)
- Drawbacks/limitations section (bullet points)
- Summary or recommendation area (if appropriate)

**Visual Enhancement Details**
- Specific icon suggestions for each comparison point
- Data visualization elements (if quantitative comparisons exist)
- Visual separators and whitespace strategy

Format all content elements as clear, actionable bullet points.
```
