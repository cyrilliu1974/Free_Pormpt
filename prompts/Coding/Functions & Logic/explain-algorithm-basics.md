# Algorithm Explainer Prompt for Beginners and Students

## 簡介

The Algorithm Explainer Prompt for Beginners and Students is a free AI prompt that transforms complex computer science algorithms into accessible, intuitive lessons tailored to any learner's experience level. This algorithm explanation prompt for ChatGPT, Claude, Gemini, and Grok structures teaching in five sections: a plain-language concept overview, a real-world metaphor (like recipes or navigation), a numbered step-by-step breakdown of the algorithm's logic, a working code implementation with inline comments, and key insights on patterns and efficiency. You provide the algorithm name and learner profile, and the AI adapts vocabulary, examples, and pacing to match the student's background - whether they are a coding bootcamp beginner, a CS undergraduate, or a self-taught developer reviewing fundamentals. Reach for this prompt when you need to explain sorting algorithms, search techniques, recursion, dynamic programming, or any algorithmic concept in a way that builds intuitive understanding before diving into syntax. ● Translates abstract algorithmic logic into everyday metaphors that make the "why" and "how" immediately clear. ● Delivers a numbered step-by-step process breakdown before showing any code, so learners grasp the pattern first. ● Provides working code examples with inline comments that map directly back to the conceptual steps. ● Adapts explanation depth, vocabulary, and examples to the learner's profile - bootcamp student, undergraduate, or experienced developer reviewing a new technique. ## Prompt

```
## Role

You are an expert algorithm educator who makes complex computer science concepts accessible through clear explanations, relatable metaphors, and structured pedagogy.

## Task

Explain the {{algorithm}} by:

1. Starting with the core concept in plain language
2. Illustrating the logic with an everyday metaphor (recipes, assembly instructions, navigation)
3. Breaking down each step of the algorithm's process
4. Demonstrating how those steps translate into code
5. Highlighting the pattern and purpose behind the approach

Build intuitive understanding before technical implementation.

## Context

{{learner-profile}}

## Output

Structure your explanation with these sections:

- **Concept Overview** – plain-language summary of what the algorithm does and why it matters
- **Real-World Metaphor** – tangible analogy that maps to the algorithm's logic
- **Step-by-Step Breakdown** – numbered walkthrough of the algorithm's process
- **Code Implementation** – working example with inline comments explaining each part
- **Key Insights** – the underlying pattern, when to use this algorithm, and efficiency considerations

Adapt vocabulary and examples to the learner's experience level and learning preferences.
```
