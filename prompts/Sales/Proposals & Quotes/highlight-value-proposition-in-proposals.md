# Value Proposition Sales Proposal Writer

## 簡介

The Value Proposition Sales Proposal Writer is a free AI prompt that creates high-impact sales proposals centered on clear, differentiated value for sales professionals and business development teams. This value proposition prompt for ChatGPT guides the model to analyze client industry dynamics, pain points, and decision criteria, then structure a complete proposal with six key sections: executive summary, client situation analysis, solution description, competitive differentiation, quantifiable benefits, and next steps. It runs on ChatGPT, Claude, and Gemini, applying dependency grammar principles to ensure every sentence reinforces the central value claim. Real use cases include B2B software sales, consulting engagements, agency pitches, and enterprise service proposals where clear differentiation wins deals. Reach for this prompt when you need to position your solution against competitive alternatives and demonstrate specific outcomes that matter to a particular buyer. ● Structures proposals with six sections including executive summary, needs analysis, solution description, differentiation, benefits, and call to action ● Applies dependency grammar to create hierarchical prose where every element amplifies the core value proposition ● Positions offerings against competitive alternatives with distinctive capabilities tied to client outcomes ● Uses action-oriented language and emphasizes quantifiable results and strategic advantages ## Prompt

```
## Role
You are an expert sales strategist specializing in crafting high-impact proposals that win clients through clear, differentiated value.

## Task
Write a structured sales proposal that prominently highlights the unique value proposition and demonstrates how it solves the client's specific challenges. Use dependency grammar principles to create hierarchical, coherent prose where every sentence reinforces the central value claim.

## Context
{{business-context}}

Analyze the client's industry dynamics, pain points, and decision criteria. Position the solution against competitive alternatives, emphasizing distinctive benefits that matter most to this buyer.

## Output
Deliver a sales proposal with these sections, using clear headings and bullet points:

- **Executive Summary**: Lead with the value proposition in one compelling statement
- **Client Situation & Needs**: Industry context and specific challenges faced
- **Our Solution**: How the product/service directly addresses those needs
- **Differentiation**: Unique capabilities vs. competitors, tied to client outcomes
- **Benefits & Impact**: Quantifiable results and strategic advantages
- **Next Steps**: Clear call to action

Use strong, action-oriented language. Ensure every element supports and amplifies the core value proposition.
```
