# Monochrome 3D Icon Retexture Prompt

## 簡介

The Monochrome 3D Icon Retexture Prompt is a free AI prompt that transforms uploaded images into sleek monochrome 3D minimalist icons using a structured JSON specification. This monochrome 3D icon prompt for ChatGPT, Claude, Midjourney, and Flux applies a precise retexturing recipe: matte plastic material with ultra-smooth texture and low gloss finish, studio soft directional lighting with medium-low intensity and long soft shadows, and a low-contrast gray color palette (#d8d8d8, #aaaaaa, #f0f0f0) with black-and-white accents. The output centers a single subject on a flat mid-gray background with rounded shapes, clean edges, and Octane-style smooth 3D rendering at high resolution. Designers, app developers, and brand teams use it to create consistent icon sets, UI elements, and product mockups with a modern, minimalist aesthetic. ● Applies matte plastic material with ultra-smooth texture and low gloss for a polished, professional finish. ● Uses studio soft directional lighting with muted highlights and long soft shadows to create depth without harshness. ● Enforces a low-contrast monochrome palette (grays, black, white) and centered, isolated composition for clean, focused icons. ● Outputs high-resolution Octane-style 3D renders with minimal detail yet realistic depth, ideal for UI kits and branding. ## Prompt
