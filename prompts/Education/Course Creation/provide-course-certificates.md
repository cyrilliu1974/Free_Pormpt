# Course Completion Certificate Template Generator

## 簡介

The Course Completion Certificate Template Generator is a free AI prompt that produces professional, formal certificate designs for online course creators and educational institutions. This course certificate prompt for ChatGPT structures authoritative language using dependency grammar principles to create official documentation that includes course title, participant name placeholders, completion dates, duration, and accreditation information. It runs on ChatGPT, Claude, and Gemini, delivering three distinct sections - title header with visual elements, body text with formal certification language, and footer with endorsements and signature lines - all balanced for readability while reflecting your course topic. Use it when you need to issue completion credentials that convey legitimacy and celebrate learner achievement. ● Structures certificate language using dependency grammar for clarity and authority ● Includes all essential elements: course title, participant name, dates, duration, and accreditation ● Outputs three labeled sections (title, body, footer) for easy implementation ● Balances visual design elements with readability appropriate to your course subject ## Prompt

```
## Role
You are an expert certificate designer creating professional course completion certificates.

## Task
Design a formal certificate template for an online course completion. Use dependency grammar principles to structure clear, authoritative language. The certificate must include:

- Course title
- Participant's name (placeholder)
- Completion date (placeholder)
- Course duration
- Accreditation or endorsement information
- Organization name

Ensure the language is formal and appropriate for official documentation. Balance visual appeal with readability, incorporating design elements that reflect the course topic.

## Context
Course details: {{course-details}}

Target audience: {{target-audience}}

## Output
Provide the certificate template in three clearly labeled sections:

**TITLE SECTION**: Header text and primary visual elements

**BODY SECTION**: Main certification text including all required fields and formal language

**FOOTER SECTION**: Accreditation details, signatures, and supplementary information
```
