# Trello Board Setup Prompt for Project Management

## 簡介

The Trello Board Setup Prompt for Project Management is a free AI prompt that architects complete Trello board structures for organizing project tasks, tracking progress, and managing team workflows. This project management prompt for ChatGPT guides you through creating workflow-ordered lists, writing actionable card descriptions for specific deliverables, designing label systems for priorities and categories, and mapping milestones across your timeline. It works on ChatGPT, Claude, Gemini, and Grok by accepting your project name and details, then outputting a five-part board blueprint: list structure that mirrors project phases, task cards with clear descriptions, a color-coded labeling system, suggested assignees and due dates, and milestone representation. Teams use it to launch new Trello boards for software releases, marketing campaigns, event planning, and cross-functional initiatives where clear task ownership and visual progress tracking are essential. Reach for this prompt when you need to translate project requirements into a structured Trello board that your team can immediately populate and start using. ● Generates workflow-ordered list names that reflect your project's actual phases and hand-off points ● Writes card titles and descriptions as clear, actionable statements specifying deliverables and deadlines ● Designs a label system with named colors mapped to priority levels, categories, or task types ● Suggests assignee roles and due dates for key cards to distribute work and maintain timeline control ## Prompt

```
## Role
You are a Trello board architect specializing in clear project structure and workflow design.

## Task
Design a complete Trello board that organizes tasks, tracks progress, and manages team workflows. Create lists that mirror project phases, cards for specific deliverables, and a labeling system for priorities and categories.

## Context
Project: {{project-name}}

Project details:
{{project-details}}

Structure your board to support the timeline, distribute work across team members, and surface milestones. Write each card description as a clear, actionable statement that specifies what needs to be done and by when.

## Output
Provide a step-by-step board setup:

1. **Board Structure** - List names in workflow order
2. **Cards by List** - Card titles and descriptions for each task
3. **Label System** - Label names, colors, and when to use them
4. **Assignments & Dates** - Suggested assignees and due dates for key cards
5. **Milestone Markers** - How milestones are represented on the board

Use numbered lists for major sections and bullet points for details within each section.
```
