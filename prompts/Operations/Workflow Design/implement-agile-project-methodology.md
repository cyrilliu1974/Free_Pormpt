# Agile Implementation Plan Generator for Teams

## 簡介

The Agile Implementation Plan Generator for Teams is a free AI prompt that creates customized Agile adoption frameworks for businesses transitioning to or refining iterative project management practices. This Agile implementation prompt for ChatGPT works by analyzing your business context, current approach, challenges, and desired outcomes to produce a markdown table mapping Agile roles (Product Owner, Scrum Master, Development Team) to their specific responsibilities and key artifacts (Product Backlog, Sprint Backlog, Increment). The prompt runs on ChatGPT, Claude, Gemini, and Grok, applying core Agile principles like iterative development, continuous feedback loops, and cross-functional collaboration to produce actionable plans that address your unique team dynamics. Use it when launching Agile adoption, restructuring existing teams, or clarifying role boundaries in software development, product management, or service delivery organizations. ● Produces role-responsibility-artifact mappings that address your stated challenges and outcomes ● Incorporates empirical process control and flexibility principles throughout the plan ● Accounts for current team state and provides implementation guidance for smooth transitions ● Delivers output as a clean markdown table ready for documentation or team onboarding ## Prompt

```
## Role
You are an Agile project management expert designing a tailored implementation plan.

## Task
Create a comprehensive Agile implementation plan that improves team collaboration, adaptability, and product quality. Outline key Agile roles, their responsibilities, and associated artifacts in a structured format that addresses the specific context provided.

## Context
Business context: {{business-context}}

Current state: {{current-approach}}

Challenges to address: {{challenges}}

Desired outcomes: {{outcomes}}

Apply core Agile principles throughout the plan:
- Iterative development with regular increments
- Continuous feedback loops
- Flexibility and responsiveness to change
- Cross-functional collaboration
- Empirical process control

## Output
Present the implementation plan as a markdown table with three columns: **Roles**, **Responsibilities**, and **Artifacts**.

Each row should define:
- A specific Agile role (e.g., Product Owner, Scrum Master, Development Team)
- Comprehensive responsibilities aligned with the business context
- Key artifacts that role produces or maintains (e.g., Product Backlog, Sprint Backlog, Increment)

Ensure the plan addresses the stated challenges and aligns with the desired outcomes. Include implementation guidance that accounts for the current approach and team dynamics described.
```
