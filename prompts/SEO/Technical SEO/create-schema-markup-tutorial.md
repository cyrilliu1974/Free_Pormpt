# Schema Markup Implementation Tutorial Generator

## 簡介

The Schema Markup Implementation Tutorial Generator is a free AI prompt that creates custom, industry-specific structured data tutorials for websites looking to enhance their search engine visibility. This schema markup prompt for ChatGPT produces a complete implementation guide that includes 3-5 relevant schema types for your industry, JSON-LD code samples ready to deploy, step-by-step placement instructions, and testing procedures using Google Rich Results Test and Schema Markup Validator. It runs on ChatGPT, Claude, Gemini, and Grok, making it accessible across major text AI platforms. When you provide your website URL and industry, the prompt analyzes the most effective schema types - such as Organization, LocalBusiness, Product, Article, or FAQ - and delivers properly formatted JSON-LD markup you can immediately add to your HTML. Technical SEO specialists, web developers, and digital marketers use it to accelerate structured data implementation without starting from scratch. ● Identifies the most impactful schema types for your specific industry and use case ● Provides syntactically correct JSON-LD code samples with realistic example data ● Includes complete testing and validation steps to verify successful implementation ● Offers authoritative resources from Schema.org and Google Search Central for ongoing reference ## Prompt

```
## Role
You are an expert technical SEO and web developer specializing in advanced structured data markup.

## Task
Create a comprehensive tutorial for implementing schema markup on the provided website, focusing on industry-relevant schema types to improve search visibility and enable rich snippets.

## Context
Website URL: {{website-url}}
Industry: {{industry}}

## Output
Provide your response in the following structure:

**Relevant Schema Types:**
List 3-5 schema types most relevant to this industry that enhance search visibility and enable rich snippets.

**Implementation Tutorial:**
For each schema type, provide:
- Clear step-by-step implementation instructions
- Properly formatted JSON-LD code samples ready to deploy
- Placement guidance (where in the HTML to insert the markup)

**Testing and Validation:**
Include:
- Google Rich Results Test instructions
- Schema Markup Validator steps
- Common errors to check for
- How to verify successful implementation in search results

**Key Benefits:**
Highlight specific advantages for this industry, such as improved CTR, enhanced SERP features, and competitive advantages.

**Additional Resources:**
Provide 3-4 authoritative resources:
- Schema.org documentation links
- Google Search Central guidelines
- Industry-specific implementation examples
- Validation tools

Ensure all code samples use JSON-LD format (Google's recommended approach), are syntactically correct, and include realistic example data appropriate to the industry.
```
