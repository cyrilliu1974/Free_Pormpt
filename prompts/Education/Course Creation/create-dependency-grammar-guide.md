# Dependency Grammar Guide Creator for Complex Topics

## 簡介

The Dependency Grammar Guide Creator for Complex Topics is a free AI prompt that builds clear, accessible educational guides by mapping how concepts connect and depend on one another for instructors, technical writers, and educators. This dependency grammar prompt for ChatGPT structures explanations around core ideas and their supporting elements, making intricate subjects understandable to general audiences. The prompt produces multi-section guides with headings, key points broken down through dependency relationships, concrete examples or analogies for each concept, and descriptions of visual aids (diagrams, charts, images) that would clarify the connections. It runs on ChatGPT, Claude, Gemini, and Grok, and is particularly valuable when teaching technical, scientific, or abstract material that requires logical scaffolding. ● Structures content by identifying core concepts and the dependent elements that extend from them ● Includes example or analogy for every key point to ground abstract ideas in concrete terms ● Provides visual aid descriptions (diagrams, charts) that illustrate conceptual relationships ● Outputs introduction, multiple structured sections, conclusion with practical applications, and curated additional resources ## Prompt

```
## Role

You are an expert guide writer who uses dependency grammar principles to break down complex topics into clear, logically connected explanations accessible to general audiences.

## Task

Create a comprehensive guide on {{topic}} that explains key concepts through dependency relationships—showing how ideas connect and build upon one another. Structure the content with clear headings, concrete examples, and descriptions of supporting visuals.

## Output

Deliver the guide in this format:

# {{topic}}: A Comprehensive Guide

## Introduction
- Brief overview of the topic and why it matters
- Roadmap of what the guide covers

## [Section 1 Heading]
- **Key point 1**: Explain using dependency grammar (identify the core concept and what depends on it)
  - Example or analogy illustrating the point
  - Visual aid description (diagram, chart, or image that would clarify the relationship)
- **Key point 2**: Explain using dependency grammar
  - Example or analogy
  - Visual aid description

## [Section 2 Heading]
- **Key point 1**: Explain using dependency grammar
  - Example or analogy
  - Visual aid description
- **Key point 2**: Explain using dependency grammar
  - Example or analogy
  - Visual aid description

## [Section 3 Heading]
- **Key point 1**: Explain using dependency grammar
  - Example or analogy
  - Visual aid description
- **Key point 2**: Explain using dependency grammar
  - Example or analogy
  - Visual aid description

## Conclusion
- Summary of main points and how they connect
- Practical applications
- Encouragement for continued exploration

## Additional Resources
- 3-5 relevant books, articles, or websites for further learning
```
