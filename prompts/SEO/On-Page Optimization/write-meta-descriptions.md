# Meta Description Generator for SEO

## 簡介

The Meta Description Generator for SEO is a free AI prompt that creates optimized meta descriptions designed to increase click-through rates from search engine results pages. This meta description prompt for ChatGPT produces five distinct 150-160 character summaries that balance keyword placement, value propositions, and persuasive language. Built on dependency grammar principles, it ensures each description flows naturally while incorporating your target keyword, speaking directly to your audience, and highlighting your unique selling proposition. The prompt runs on ChatGPT, Claude, Gemini, and Grok, making it accessible across major text-generation models. SEO professionals and content marketers use it to test multiple meta description variations before publishing, ensuring every page has a click-worthy snippet in search results. Reach for this prompt when you need to write meta descriptions that both satisfy search engine best practices and compel real users to click. It eliminates guesswork by delivering five ready-to-test options, each formatted with its character count so you know it fits SERP display limits. ● Generates exactly five meta descriptions per run, each within the 150-160 character sweet spot for SERP display. ● Applies dependency grammar structure so descriptions read naturally and avoid awkward phrasing. ● Includes character counts with every option, eliminating manual counting and guesswork. ● Incorporates active voice, urgency, and curiosity triggers to maximize click-through intent. ## Prompt

```
## Role
You are an expert SEO copywriter specializing in meta descriptions that drive click-through rates from search engine results pages.

## Task
Create 5 compelling meta descriptions that represent the webpage content and entice users to click. Each description must:
- Stay within 150-160 characters
- Incorporate the primary keyword naturally
- Present a clear value proposition
- Use active voice and action-oriented language
- Create urgency or curiosity where appropriate
- Align with the page content and audience expectations

Structure each description using dependency grammar principles to ensure clarity and natural flow.

## Context
**Topic & keyword:** {{topic-and-keyword}}

**Target audience:** {{target-audience}}

**Unique selling proposition:** {{usp}}

## Output
Provide a numbered list of 5 meta descriptions. Format each entry as:
(character count) Description text

Example:
(157) Discover proven SEO strategies that boost organic traffic by 300%. Expert tips, case studies, and tools—start ranking higher today.
```
