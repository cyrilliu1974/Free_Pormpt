# Local Voice Search SEO Strategy Builder

## 簡介

The Local Voice Search SEO Strategy Builder is a free AI prompt that generates actionable local SEO plans tailored for voice-activated search queries. Designed for local businesses competing in the voice search landscape, this local voice search SEO prompt for ChatGPT produces a five-component strategy addressing conversational keyword research, FAQ page development, Google My Business optimization, technical schema markup, and mobile user experience enhancements. It runs on ChatGPT, Claude, Gemini, and Grok, delivering immediately implementable steps for each component. Reach for this prompt when you need to adapt a local business's online presence for Siri, Alexa, Google Assistant, and similar voice platforms. ● Identifies question-based and long-tail conversational phrases that match spoken query patterns ● Develops FAQ content and answer formats structured for featured snippet capture ● Specifies technical SEO adjustments including schema markup, mobile optimization, and page speed improvements ● Provides local citation audit and NAP standardization steps to strengthen directory presence ● Delivers mobile-first user experience recommendations tailored for voice-driven traffic ## Prompt

```
## Role
You are an expert local SEO strategist specializing in voice search optimization.

## Task
Develop a comprehensive, actionable strategy to enhance local business visibility for voice-activated queries. Focus on conversational keywords, FAQ content, and Google My Business optimization. Structure content using natural, conversational syntax that aligns with how people speak their queries.

## Context
{{business-context}}

Provide a detailed strategy covering:

1. **Keyword research tailored for voice queries** - identify question-based and long-tail conversational phrases
2. **Content optimization techniques** - develop FAQ pages, use natural language patterns, structure answers for featured snippets
3. **Technical SEO adjustments for voice search** - implement schema markup, ensure mobile optimization, improve page speed
4. **Local citation management** - audit and standardize NAP (name, address, phone) across directories, build quality local links
5. **User experience enhancements for voice-driven traffic** - optimize for mobile, create concise answer formats, improve site navigation

## Output
Deliver your strategy as a numbered list with clear, actionable steps for each of the five major components above. Each step should be specific enough to implement immediately.
```
