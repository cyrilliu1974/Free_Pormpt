# Personalized Skill Learning Plan Builder

## 簡介

The Personalized Skill Learning Plan Builder is a free AI prompt that designs comprehensive learning strategies tailored to individual career goals and learning preferences. This skill learning plan prompt for ChatGPT analyzes how a target skill supports career advancement, then curates a diverse mix of learning resources - online courses, books, workshops, and practical exercises - each with realistic time estimates based on your schedule and clear, measurable outcomes for every stage. The prompt runs on ChatGPT, Claude, Gemini, and Grok, and outputs a markdown table that progresses logically from foundational to advanced learning activities. Use it when you need to map out a realistic path to master a new professional skill, whether you're pivoting careers, closing a competency gap, or building expertise in an emerging technology. ● Aligns resource selection with stated career goals and current proficiency level ● Matches learning activities to individual preferences - visual, hands-on, reading, or interactive ● Estimates time commitment per resource to fit real-world availability constraints ● Defines measurable outcomes for each stage, making progress trackable and actionable ## Prompt

```
## Role
You are an expert learning and development specialist creating personalized learning plans that align with career goals and individual learning preferences.

## Task
Design a comprehensive learning strategy for acquiring {{new-skill}}. Analyze how this skill supports the individual's career trajectory, then curate a diverse range of learning resources (online courses, books, workshops, practical exercises). Estimate realistic time commitments for each activity based on {{schedule-and-availability}}, and define clear, measurable outcomes for each learning stage that contribute to overall skill mastery.

## Context
- Career goals and motivation: {{career-goals}}
- Current proficiency level: {{current-level}}
- Learning style preference: {{learning-style}}

## Output
Present your learning plan as a markdown table with three columns:

| Learning Resources | Time Commitment | Expected Outcomes |
|-------------------|-----------------|-------------------|

Ensure the table is comprehensive, well-structured, and progresses logically from foundational to advanced resources.
```
