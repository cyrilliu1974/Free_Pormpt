# Achievement Badge Collection Creator for Education

## 簡介

The Achievement Badge Collection Creator for Education is a free AI prompt that generates a complete gamification badge system for educational platforms and learning programs. This achievement badge prompt for ChatGPT produces a markdown table of 8-12 badges spanning beginner to advanced milestones, each with a clear name, motivational description, and specific unlock criteria. It works on ChatGPT, Claude, Gemini, and Grok, allowing instructional designers, course creators, and gamification specialists to build coherent progression paths that align with learning objectives. The prompt structures badges around foundational skills, practice milestones, mastery demonstrations, collaboration achievements, and creative applications, ensuring each badge communicates its learning value and shows how requirements build upon one another. Real-world use cases include online course platforms adding motivational mechanics, corporate training programs tracking skill certification, and K-12 educators designing classroom reward systems. ● Generates 8-12 badges forming a coherent progression from introductory achievements to advanced mastery milestones. ● Outputs a three-column markdown table with badge names, motivational descriptions explaining learning value, and specific unlock requirements. ● Structures badge relationships using clear dependencies that show how skills build upon one another across the learning journey. ● Covers diverse achievement types including foundational skills, practice milestones, collaboration wins, and creative application demonstrations. ## Prompt

```
## Role
You are an expert gamification designer specializing in educational achievement systems.

## Task
Design a comprehensive badge collection that motivates learners and tracks progression across {{subject-area}}. Create badges spanning introductory achievements through advanced milestones, ensuring each badge clearly communicates its learning value and unlock criteria.

## Context
**Platform:** {{platform-name}}
**Learners:** {{target-audience}}
**Learning objectives:** {{learning-objectives}}

Structure each badge description using clear dependency relationships—show how requirements build upon one another and how badges form a coherent progression path. Cover diverse aspects of the learning journey: foundational skills, practice milestones, mastery demonstrations, collaboration achievements, and creative applications.

## Output
Deliver a markdown table with three columns:

| Badge Name | Description | Requirements |
|------------|-------------|-------------|
| [name] | [what it represents and why it matters] | [specific criteria to earn it] |

Include 8-12 badges that form a balanced ecosystem from beginner to advanced levels.
```
