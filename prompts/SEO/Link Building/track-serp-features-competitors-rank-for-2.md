# Track SERP Features Competitors Rank For

## 簡介

The Track SERP Features Competitors Rank For is a free AI prompt that maps which competitors dominate featured snippets, knowledge panels, local packs, and other search visibility features in your industry. This SERP feature analysis prompt for ChatGPT asks you to specify your industry and competitor list, then produces a markdown table showing exactly which rivals trigger each type of enhanced search result, for which keyword clusters, and at what strength. SEO professionals use it to spot gaps in their own feature strategy, reverse-engineer competitor content approaches, and prioritize the SERP features that drive the most visibility in their sector. It runs on ChatGPT, Claude, Gemini, and Grok, adapting its analysis to industry-specific features like product carousels for e-commerce or local packs for service businesses. Reach for this prompt when you need competitive intelligence on search visibility beyond traditional blue-link rankings, or when planning content designed to capture featured snippets and other rich results. ● Maps competitor presence across featured snippets, knowledge panels, local packs, People Also Ask boxes, image carousels, and other SERP enhancements ● Identifies keyword clusters that trigger each feature and assigns ranking strength scores (dominant, moderate, weak, none) ● Delivers pattern analysis showing which content strategies and formats correlate with SERP feature wins ● Highlights underutilized features representing the highest-opportunity gaps for your own strategy ## Prompt

```
## Role
You are an expert SEO analyst specializing in competitive SERP feature intelligence and search visibility analysis.

## Task
Create a comprehensive analysis of how competitors rank for SERP features (featured snippets, knowledge panels, local packs, image carousels, people also ask, etc.) in their industry. Deliver your findings as a structured markdown table that reveals competitive advantages and gaps in search visibility.

## Context
Industry: {{industry}}
Competitors to analyze: {{competitor-list}}

SERP features vary by industry—prioritize those most relevant to this sector (e.g., local pack for service businesses, product carousels for e-commerce, featured snippets for informational queries).

## Process
1. Identify 3-5 key competitors if not all specified
2. Determine the 4-6 most valuable SERP features for this industry
3. Research which competitors currently trigger each SERP feature and for which keyword clusters
4. Assess ranking strength: dominant presence, occasional appearance, or absent
5. Identify patterns—which competitors own which features, where gaps exist, and what content strategies drive visibility

## Output
Deliver a markdown table with these columns:
- **Competitor Name**
- **SERP Feature** (one row per feature per competitor)
- **Keyword Examples** (representative queries triggering the feature)
- **Ranking Strength** (dominant / moderate / weak / none)

After the table, provide a brief analysis highlighting:
- Which competitor has the strongest overall SERP feature presence
- Underutilized features representing opportunity gaps
- Patterns in content type or strategy that correlate with SERP feature wins
```
