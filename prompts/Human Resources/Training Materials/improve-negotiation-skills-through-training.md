# Sales Negotiation Training Program Builder

## 簡介

The Sales Negotiation Training Program Builder is a free AI prompt that creates structured, progressive training curricula to improve sales team negotiation skills and deal closure rates. This sales negotiation training prompt for ChatGPT, Claude, and Gemini generates a complete program organized by skill dependencies - moving from foundational concepts through intermediate techniques to advanced deal closure strategies. It produces module sequences with learning objectives, time allocations, role-playing exercises tailored to your market, case studies from real industry situations, objection handling frameworks, and value articulation methods. The output includes participant workbooks, facilitator guides, assessment criteria, and post-training reinforcement activities formatted for immediate classroom or virtual delivery. Sales managers, training consultants, and revenue leaders reach for this prompt when they need a complete negotiation curriculum customized to their team's specific challenges and market context. ● Organizes content using dependency grammar principles so foundational skills are mastered before advanced techniques ● Generates role-playing scenarios and conversation scripts specific to your industry and buyer personas ● Creates facilitator notes, participant workbooks, and assessment rubrics in a single output ● Includes post-training reinforcement activities to ensure skill retention and application ## Prompt

```
## Role

You are an expert sales training consultant specializing in negotiation skills development and deal closure optimization.

## Task

Develop a comprehensive sales negotiation training program that enhances team skills and increases deal closure rates. Structure the program using dependency grammar principles to create logical flow and build skills progressively.

## Context

{{sales-team-context}}

{{negotiation-challenges}}

## Output

Deliver a complete training program with:

### Program Structure
- Module sequence organized by skill dependencies (foundational → intermediate → advanced)
- Learning objectives for each module
- Time allocation and delivery format

### Core Content
- Key negotiation concepts and techniques
- Deal closure frameworks
- Objection handling strategies
- Value articulation methods

### Practical Components
- Role-playing exercises with scenarios tailored to the target market
- Case studies reflecting actual industry negotiation situations
- Practice scripts and conversation templates

### Implementation Resources
- Participant workbook outline
- Facilitator notes and talking points
- Assessment criteria and success metrics
- Post-training reinforcement activities

Format the entire program with clear headings, subheadings, and bullet points for immediate implementation.
```
