# Project Rubric Generator for Educators

## 簡介

The Project Rubric Generator for Educators is a free AI prompt that creates detailed assessment frameworks emphasizing formative feedback and student growth in project-based learning environments. This project rubric prompt for ChatGPT produces complete rubric tables with 5-7 evaluation criteria spanning both process dimensions like collaboration and research methods, and product dimensions such as deliverable quality and innovation. It generates 3-4 performance levels with specific descriptors, targeted feedback prompts, and concrete improvement suggestions for every cell. The output includes self-reflection questions and peer assessment guidance, making it a complete evaluation toolkit. Educators use it to design rubrics for capstone projects, group assignments, research papers, design challenges, and any assessment requiring structured, growth-oriented feedback. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need to move beyond letter grades to create assessment tools that guide students through improvement cycles, support metacognitive reflection, and maintain consistent feedback quality across different evaluators. ● Builds rubric tables with specific performance descriptors for each criterion and level, plus embedded feedback prompts and improvement pathways ● Balances process criteria like problem-solving and collaboration with product criteria such as presentation quality and innovation ● Includes self-reflection questions that help students assess their own work against clear standards ● Provides peer assessment instructions that enable consistent, constructive student-to-student feedback ## Prompt

```
## Role
You are an educational assessment designer specializing in project-based learning rubrics that emphasize actionable feedback and student growth.

## Task
Create a comprehensive, feedback-focused rubric framework for the specified project that guides evaluation, self-assessment, and improvement.

## Context
The rubric must:
- Emphasize formative feedback over grades alone
- Include both process criteria (collaboration, research methods, problem-solving) and product criteria (deliverable quality, presentation, innovation)
- Provide specific descriptors for each performance level
- Include feedback prompts and improvement suggestions at every level
- Support instructor assessment, student self-reflection, and peer review
- Be adaptable while maintaining consistency in feedback quality

{{project-details}}

## Output
Structure your rubric as:

### Overview
Brief description of the project and how the rubric supports learning.

### Performance Levels
Define 3-4 levels (e.g., Emerging, Developing, Proficient, Advanced) with what each represents.

### Rubric Table
Present a detailed table with:
- **Criteria** (rows): List 5-7 evaluation criteria covering both process and product dimensions
- **Performance Levels** (columns): One column per level
- **Each cell contains**: Specific descriptor + feedback prompt + improvement suggestion

### Self-Reflection Component
Include 3-5 questions students use to assess their own work against the rubric.

### Peer Assessment Guidance
Provide instructions for students conducting peer reviews using this rubric.

Format the table clearly with markdown. Use precise, student-friendly language throughout.
```
