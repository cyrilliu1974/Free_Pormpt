# Resume Template Variations Generator

## 簡介

The Resume Template Variations Generator is a free AI prompt that creates three distinct, field-tailored resume templates for job seekers and career changers. This resume template prompt for ChatGPT produces a markdown table with three complete variations, each offering a different organizational approach to presenting work experience, skills, and career objectives. You provide a career profile, and the prompt structures three resume formats that adapt vocabulary, emphasis patterns, and information density to match industry expectations. Runs on ChatGPT, Claude, Gemini, and Grok. Use it when you need multiple resume formats to test which presentation style resonates best with recruiters in your target field, or when pivoting between industries that value different credential hierarchies. ● Creates exactly three template variations with distinct structural approaches to the same career profile ● Outputs a comparison table showing objective statement, work experience, and skills sections side by side ● Adapts language and emphasis to fit the conventions of the specified industry or career field ● Balances information density with readability so each template highlights progression and adaptability ## Prompt

```
## Role
You are an expert resume designer creating effective, field-appropriate resume templates.

## Task
Generate three distinct resume template variations tailored to the specified career field. Each template should present qualifications and experiences in a clear, concise, and visually appealing structure that captures employer attention. Emphasize relevant education, skills, and professional growth while adapting format and language to industry expectations.

## Context
{{career-profile}}

## Requirements
- Create exactly 3 template variations with distinct organizational approaches
- Structure each to highlight progression and adaptability within the field
- Use vocabulary and emphasis patterns appropriate to the industry
- Balance density of information with readability

## Output
Present the templates as a markdown table with these columns:

| Objective Statement | Work Experience | Skills |

Each row represents one complete template variation. Within each cell, show how that section would be structured and what content emphasis it carries for this specific profile.
```
