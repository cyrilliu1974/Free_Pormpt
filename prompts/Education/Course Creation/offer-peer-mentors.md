# Peer Mentoring Program Implementation Plan Generator

## 簡介

The Peer Mentoring Program Implementation Plan Generator is a free AI prompt that builds structured, actionable plans for launching and managing peer mentoring programs in schools, colleges, and training institutions. This peer mentoring program prompt for ChatGPT, Claude, Gemini, and Grok produces a detailed implementation roadmap covering program design, recruitment, mentor-mentee matching systems, training curricula, timelines, support structures, and evaluation frameworks. You provide your education context, program goals, available resources, and student demographics, and the prompt outputs a context-aware plan that balances academic support with personal development. Use it when designing collaborative learning initiatives, formalizing existing mentorship efforts, or responding to institutional needs for student engagement and retention. ● Defines program structure, objectives, and scope tailored to your institution's resources and student population ● Designs recruitment strategies and eligibility criteria for both mentors and mentees ● Creates systematic matching processes with compatibility factors and pairing tools ● Develops mentor training materials, skill-building modules, and ongoing support protocols ● Establishes phase-based timelines, monitoring systems, and success metrics for continuous improvement ## Prompt

```
## Role
You are an expert education consultant specializing in peer mentoring program design.

## Task
Create a comprehensive, step-by-step implementation plan for a peer mentoring program that fosters collaborative learning and mutual support among students.

## Context
**Education level and institution:** {{education-context}}

**Program goals:** {{program-goals}}

**Available resources:** {{available-resources}}

**Target student demographics:** {{student-demographics}}

Incorporate established best practices in peer mentoring. Address both academic growth and personal development outcomes. Ensure the plan is realistic for the institution's context and resources.

## Output
Deliver a detailed implementation plan with clear headings and subheadings. Use bullet points for actionable steps and recommendations. Cover:

- **Program Design & Structure** – framework, objectives, scope
- **Recruitment Strategy** – mentor and mentee outreach, eligibility criteria, application process
- **Matching System** – pairing methodology, compatibility factors, tools or processes
- **Training Materials** – mentor preparation, skill development, ongoing support
- **Implementation Timeline** – phases, milestones, responsibilities
- **Support & Monitoring** – check-ins, troubleshooting, feedback loops
- **Evaluation Plan** – success metrics, data collection methods, reporting schedule
```
