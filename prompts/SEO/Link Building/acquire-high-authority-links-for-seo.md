# High-Authority Backlink Acquisition Plan for SEO

## 簡介

The High-Authority Backlink Acquisition Plan for SEO is a free AI prompt that builds a strategic roadmap for earning editorial backlinks from relevant, high-authority websites in your industry. This backlink acquisition prompt for ChatGPT produces a markdown table of 8-12 prospect domains, each with an estimated domain authority score and a concrete outreach strategy - guest posting, resource page inclusion, broken link replacement, digital PR angles, or expert roundup participation. You supply your industry, target keywords, current domain authority, and website URL; the prompt returns topically relevant prospects with realistic acquisition strategies that prioritize sustainable, editorial-quality links over transactional placements. SEO professionals and content marketers use it to systematically improve organic search rankings and build domain credibility. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need a repeatable framework for link prospecting that goes beyond generic outreach lists and delivers tailored strategies for each target domain. ● Identifies 8-12 high-potential linking domains with estimated domain authority scores on the 0-100 scale. ● Recommends specific, realistic acquisition tactics for each prospect - guest posts, resource pages, broken link opportunities, PR hooks, and expert contributions. ● Filters for topical relevance and editorial quality, steering clear of low-value or transactional link schemes. ● Outputs a clean markdown table you can use as a working document for your outreach team or link building workflow. ## Prompt

```
## Role
You are an expert SEO strategist specializing in high-authority backlink acquisition.

## Task
Develop a comprehensive backlink acquisition plan to improve organic search rankings for the specified target keywords. Research potential linking websites in the industry, evaluate their domain authority, and recommend tailored outreach strategies for each prospect.

## Context
- Industry: {{industry}}
- Target keywords: {{target-keywords}}
- Current domain authority: {{current-domain-authority}}
- Website URL: {{website-url}}

Focus on websites that are topically relevant to the industry, have strong domain metrics, and represent realistic acquisition opportunities. Prioritize strategies that build sustainable, editorial-quality links rather than transactional or low-value placements.

## Output
Provide your backlink acquisition plan as a markdown table with three columns:

| Website | Domain Authority | Link Acquisition Strategy |
|---------|------------------|---------------------------|

Include 8-12 high-potential prospects. For each:
- **Website**: The specific domain or publication
- **Domain Authority**: Estimated DA score (0-100 scale)
- **Link Acquisition Strategy**: Concrete outreach approach (guest posting, resource page inclusion, broken link replacement, digital PR angle, expert roundup participation, etc.) tailored to that site's content model and audience
```
