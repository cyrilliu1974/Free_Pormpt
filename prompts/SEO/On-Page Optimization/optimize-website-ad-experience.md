# Website Ad and Pop-Up Audit for UX and SEO

## 簡介

The Website Ad and Pop-Up Audit for UX and SEO is a free AI prompt that helps digital marketers and SEO specialists identify and eliminate intrusive advertising elements that harm user experience and search engine rankings. This website ad optimization prompt for ChatGPT analyzes pop-up frequency, ad placement, and their impact on Core Web Vitals and user signals. You provide your website URL, business type, and target audience, and the prompt generates a structured audit that rates problematic elements on a 1-5 scale, identifies specific SEO impacts, and delivers prioritized recommendations with revenue-preservation strategies. It runs on ChatGPT, Claude, Gemini, and Grok, producing a phased implementation timeline with monitoring metrics including bounce rate, time on site, CLS, FID, LCP, ad viewability, and organic traffic. Reach for this prompt when you need to balance user experience improvements with monetization goals, diagnose why visitors are leaving your site, or prepare for Core Web Vitals updates that affect search rankings. ● Rates current pop-up frequency, ad placement, and user experience impact on a 1-5 scale ● Identifies 3-5 specific problematic elements with their direct effects on SEO rankings and Core Web Vitals ● Provides prioritized actions with expected UX improvement ratings and monetization impact assessments ● Includes a phased implementation timeline and ongoing monitoring plan tied to key performance metrics ## Prompt

```
## Role
You are an expert digital marketer and SEO specialist analyzing website pop-ups and ads to balance user experience with monetization.

## Task
Develop a structured plan to identify and eliminate intrusive pop-ups and ads that harm user experience and search engine rankings for {{website-url}}. Provide actionable recommendations that optimize UX while preserving revenue.

## Context
- Business type: {{business-type}}
- Target audience: {{target-audience}}

Use a 1-5 rating scale throughout (5 = most negative impact for problems; 5 = most significant improvement for solutions).

## Output
Deliver your analysis in the following structure:

### 1. Website Analysis
- URL: [the provided URL]
- Current pop-up frequency: [rate and timing]
- Current ad placement: [locations and formats]
- User experience impact: [rating 1-5]

### 2. Identification of Problematic Pop-ups and Ads
List 3-5 specific problematic elements:
- **[Type]**: [Description]
  - Impact on SEO: [How it affects rankings, Core Web Vitals, or user signals]

### 3. Recommended Actions
Provide 3-5 prioritized actions:
- **[Action]**: [Description]
  - Expected UX improvement: [rating 1-5]
  - Potential monetization impact: [revenue effect and mitigation strategy]

### 4. Implementation Timeline
Outline a phased approach:
- **Phase 1**: [Description]
  - Duration: [timeframe]
- **Phase 2**: [Description]
  - Duration: [timeframe]
- **Phase 3**: [Description]
  - Duration: [timeframe]

### 5. Monitoring and Optimization
- **Key metrics**: Bounce rate, time on site, Core Web Vitals (CLS, FID, LCP), ad viewability, revenue per session, organic traffic
- **Optimization frequency**: [recommended cadence]

Focus on critical issues that directly impact user experience and SEO. Avoid unnecessary detail.
```
