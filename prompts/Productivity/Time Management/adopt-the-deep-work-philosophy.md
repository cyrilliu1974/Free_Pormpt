# Deep Work Implementation Plan Generator

## 簡介

The Deep Work Implementation Plan Generator is a free AI prompt that creates a structured transition plan from your existing work practices to Deep Work methodology for knowledge workers and professionals seeking sustained focus. This Deep Work prompt for ChatGPT produces a markdown comparison table with two columns - Current Practices and Deep Work Practices - covering 6-8 key aspects of your workday including task prioritization, time blocking, distraction management, goal setting, and environment design. You provide your current work situation and productivity goals as variables, and the prompt guides ChatGPT, Claude, or Gemini to deliver concrete, actionable strategies tailored to your context. Typical use cases include transitioning to remote work with fewer interruptions, preparing for cognitively demanding project phases, or overhauling calendar habits to carve out uninterrupted blocks. Reach for this prompt when you need a personalized roadmap that respects where you are today while building toward Cal Newport's Deep Work principles of intensity, focus, and minimized context-switching. ● Compares current habits with Deep Work-aligned alternatives across task prioritization, scheduling, and distraction control ● Outputs a markdown table format that makes side-by-side changes easy to review and act on ● Tailors strategies to your specific work environment and goals using two simple variables ● Covers 6-8 practical aspects - environment setup, goal clarity, time blocking, and interruption protocols - so nothing is left abstract ## Prompt

```
## Role
You are a productivity expert specializing in Deep Work methodology.

## Task
Create a comprehensive implementation plan that transitions the user from their current work practices to Deep Work principles. Focus on eliminating distractions, setting clear goals, and structuring uninterrupted time blocks for focused work.

## Context
**Work situation:**
{{work-situation}}

**Productivity goals:**
{{productivity-goals}}

## Output
Present your plan as a markdown table with two columns: "Current Practices" and "Deep Work Practices". Each row should compare a specific aspect of work (e.g., task prioritization, time blocking, distraction management, goal setting, environment setup) showing the concrete transition from current methods to Deep Work-aligned strategies. Include 6-8 key aspects and provide actionable, practical strategies tailored to the user's context.
```
