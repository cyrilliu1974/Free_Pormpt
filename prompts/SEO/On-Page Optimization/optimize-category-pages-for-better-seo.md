# Category Page SEO Optimization Prompt

## 簡介

The Category Page SEO Optimization Prompt is a free AI prompt that builds tailored SEO strategies for product category pages across e-commerce and content sites. This category page SEO prompt for ChatGPT analyzes your product category, target audience, competitor landscape, and current rankings to deliver a structured optimization plan. It identifies high-value keywords and semantic variations, crafts optimized title tags and meta descriptions within character limits, designs header tag hierarchies, and recommends content depth improvements, internal linking strategies, schema markup opportunities, and technical SEO fixes. Use it when launching new category pages, refreshing underperforming sections, or preparing for seasonal traffic spikes. The prompt runs on ChatGPT, Claude, Gemini, and Grok. ● Conducts keyword research that uncovers primary terms, long-tail opportunities, and user intent clusters specific to your product category and audience ● Delivers optimized meta tags including character-compliant title tags, action-oriented descriptions, and keyword-distributed header hierarchies ● Provides a content improvement roadmap covering depth, internal linking, engagement elements, schema markup, and technical considerations ● Prioritizes all recommendations by expected SEO impact so you can focus effort where it matters most ## Prompt

```
## Role
You are an expert SEO specialist optimizing category pages for search visibility and ranking.

## Task
Develop a complete SEO optimization strategy for the specified product category page. Deliver actionable recommendations covering keyword research, meta tag optimization, and content improvement that align with user intent and current search engine guidelines.

## Context
Product category: {{product-category}}
Target audience: {{target-audience}}
Website URL: {{website-url}}
Top 3 competitors: {{competitors}}
Current keyword rankings: {{current-rankings}}

## Process
Follow this optimization sequence:

1. **Keyword Research**: Identify high-value, relevant keywords and semantic variations for the product category. Include primary terms, long-tail opportunities, and user intent clusters.

2. **Meta Tag Optimization**: Provide optimized versions of:
   - Title tags (incorporating primary keywords, staying within character limits)
   - Meta descriptions (compelling, keyword-rich, action-oriented)
   - Header tag hierarchy (H1, H2, H3 structure with keyword distribution)

3. **Content Improvement Plan**: Recommend specific enhancements to:
   - Content depth and relevance
   - Internal linking strategy
   - User engagement elements
   - Schema markup opportunities
   - Technical SEO considerations

## Output
Structure your response with clear headings and bullet points for each optimization step. Prioritize recommendations by expected impact.
```
