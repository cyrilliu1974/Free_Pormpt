# Stress Tracking System Design Prompt for ChatGPT

## 簡介

The Stress Tracking System Design Prompt is a free AI prompt that creates evidence-based stress monitoring architectures for health tech developers, researchers, and wellness professionals. This stress tracking system prompt for ChatGPT guides the AI through designing a complete solution including physiological biomarkers (heart rate variability, cortisol, skin conductance), behavioral indicators (sleep quality, activity patterns), hardware recommendations, software platforms, data analysis algorithms, and user interface specifications. It runs on ChatGPT, Claude, and Gemini to produce structured technical documentation that addresses privacy, security, and practical implementation constraints. Use it when you need to design IoT health systems, wellness apps, or employee monitoring tools within specific budget and timeline parameters. ● Identifies 3-5 scientifically validated physiological and behavioral stress indicators ● Specifies practical hardware sensors, software platforms, and optimal data collection schedules ● Delivers algorithms for pattern detection, trend analysis, and personalized recommendation generation ● Includes privacy protocols, system limitations, and future enhancement pathways ## Prompt

```
## Role

You are an expert in stress tracking and analysis, combining deep knowledge in physiology, psychology, data science, and IoT systems.

## Task

Design a comprehensive stress tracking system tailored to {{target-user-profile}}. Address the practical constraints of {{budget-and-timeline}}. Provide a critical, evidence-based approach that identifies scientifically validated stress indicators, specifies practical measurement tools, and creates actionable insights through an intuitive interface.

## Requirements

- Focus on the most relevant and validated biomarkers and behavioral indicators
- Recommend practical, accurate, and user-friendly hardware and software
- Develop algorithms that reveal stress patterns and generate actionable insights
- Design an interface that encourages regular engagement and effective stress management
- Address privacy and security concerns for sensitive health data
- Acknowledge system limitations and suggest future enhancements

## Output

Structure your response as follows:

### Stress Biomarkers
List 3-5 key physiological markers (e.g., cortisol, heart rate variability, skin conductance)

### Behavioral Stress Indicators
List 3-5 behavioral signals (e.g., sleep quality, activity patterns, mood changes)

### Tracking Hardware
Specify 3-5 devices or sensors needed for measurement

### Tracking Software
Recommend 3-5 applications or platforms for data logging and integration

### Data Collection Frequency
Define optimal sampling rates and collection schedules

### Data Analysis Algorithms
Describe 3-5 analytical methods for pattern detection and trend analysis

### Insight Generation
Outline 3-5 types of meaningful insights the system will produce

### User Interface Features
Detail 3-5 core interface elements for monitoring and interaction

### Personalized Recommendations
Explain 3-5 recommendation types based on user data

### Privacy and Security
Describe data protection measures and compliance protocols

### System Limitations
Identify 2-3 key constraints or challenges

### Future Enhancements
Suggest 3-5 potential improvements or expansions
```
