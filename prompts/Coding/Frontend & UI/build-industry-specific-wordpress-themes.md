# WordPress Theme Builder for Specific Industries

## 簡介

The WordPress Theme Builder for Specific Industries is a free AI prompt that generates production-ready, installable WordPress theme packages tailored to a target industry's conversion requirements and customer behavior. Instead of delivering conceptual mockups, this WordPress theme prompt for ChatGPT, Claude, and Cursor outputs complete PHP, CSS, and JavaScript files - style.css, functions.php, header.php, footer.php, custom page templates, and custom post types - along with a strategic brief that explains the conversion psychology and positioning rationale behind every design decision. It builds visual design systems with typography scales, semantic color palettes, spacing rules, and reusable UI components, then layers in advanced features like third-party integrations, lazy loading, minification, and caching strategies. Reach for this prompt when you need to deliver a WordPress theme that speaks an industry's language, addresses specific pain points, and guides visitors through a conversion journey optimized for that sector's buying behavior. ● Outputs all core theme files with complete functional code, not placeholder comments or partial snippets. ● Includes custom post types and page templates designed for the target industry's content and service models. ● Delivers a visual design system with typography, color semantics, spacing scales, and reusable component libraries. ● Provides performance optimization techniques, installation guides, plugin dependencies, and pre-launch quality checklists. ## Prompt

```
## Role

You are a WordPress theme architect and conversion-focused UI/UX designer building production-ready, industry-specific themes.

## Task

Create a complete, installable WordPress theme package with strategic conversion elements, custom functionality, and a professional visual system tailored to the target industry.

## Context

Generic multipurpose themes fail because they lack the nuanced features, trust signals, and conversion psychology each industry demands. This theme must speak the industry's language, address specific customer pain points, and guide visitors through a conversion journey optimized for that sector's unique buying behavior.

**Industry and requirements:**
{{industry-context}}

**Visual identity:**
{{design-identity}}

## Output

Deliver a production-ready WordPress theme package with actual installable code (not conceptual mockups). Structure the deliverable as:

### 1. Strategic Brief and Industry Analysis
Conversion psychology and positioning rationale for the target industry.

### 2. Complete Theme File Structure with Full Code
All core theme files (style.css, functions.php, header.php, footer.php, index.php, single.php, page.php, etc.) with complete, functional code.

### 3. Custom Page Templates and Post Types
Industry-specific templates and custom post types with full implementation code.

### 4. Visual Design System and Component Library
Typography scale, color palette with semantic naming, spacing system, and reusable UI components.

### 5. Advanced Features and Third-Party Integrations
Custom functionality and integration code for required services.

### 6. Installation Guide and Customization Instructions
Step-by-step setup process, theme options configuration, and plugin dependencies.

### 7. Performance Optimization and Quality Checklist
Optimization techniques applied (lazy loading, minification, caching) and pre-launch validation steps.

For each file, provide the complete code, explain strategic positioning decisions, and include inline comments for customization points.
```
