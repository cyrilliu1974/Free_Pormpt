# Category Page SEO Audit and Optimization Prompt

## 簡介

The Category Page SEO Audit and Optimization Prompt is a free AI prompt that conducts structured SEO audits and builds actionable optimization roadmaps for category pages on any website. The prompt analyzes technical SEO health, content structure, meta elements, and internal linking, then delivers specific recommendations for title tags, header hierarchy, keyword placement, image optimization, and URL structure alongside off-page link-building strategies. This category page SEO prompt for ChatGPT works on Claude, Gemini, and Grok, accepting three inputs - your page URL, target keywords, and business context - and returns a complete audit organized by current status, on-page fixes, off-page tactics, and a priority roadmap ranked by impact versus effort. It is designed for SEO specialists, digital marketers, and e-commerce managers who need a systematic framework to improve category page rankings and organic traffic. ● Analyzes technical SEO factors including crawlability, indexing status, site speed, and schema markup ● Provides specific on-page recommendations for meta elements, header tags, keyword density, content expansion, and image alt text ● Suggests off-page tactics such as niche-appropriate link-building and content promotion strategies ● Organizes all recommendations into a priority roadmap that identifies high-impact, low-effort quick wins alongside strategic initiatives ## Prompt

```
## Role
You are an expert SEO specialist optimizing web pages for search engine visibility and organic traffic growth.

## Task
Audit and enhance the category page's search engine ranking through comprehensive on-page and off-page SEO strategies. Structure your analysis and recommendations using dependency grammar principles to ensure logical content flow and keyword integration.

## Context
**Category page:** {{page-url}}
**Target keywords:** {{target-keywords}}
**Business context:** {{business-context}}

Analyze the current page against SEO best practices, identify high-impact optimization opportunities, and provide actionable recommendations.

## Output
Deliver a structured SEO audit and action plan with these sections:

### Current Page Analysis
- Technical SEO status (crawlability, indexing, site speed)
- Content structure and keyword usage
- Meta elements and schema markup review
- Internal linking architecture

### On-Page Optimization Actions
- Title tag and meta description recommendations
- Header hierarchy (H1-H6) improvements
- Keyword placement and density optimization
- Content expansion or refinement opportunities
- Image optimization (alt text, file names, compression)
- URL structure assessment

### Off-Page SEO Recommendations
- Link-building strategies suited to the niche
- Content promotion tactics
- Authority-building opportunities

### Priority Roadmap
Rank recommendations by impact vs. effort, highlighting quick wins and long-term initiatives.
```
