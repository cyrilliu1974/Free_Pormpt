# Website Chatbot Support System Design Prompt

## 簡介

The Website Chatbot Support System Design Prompt is a free AI prompt that produces end-to-end chatbot architectures for businesses seeking to automate and optimize customer support on their websites. This chatbot design prompt for ChatGPT, Claude, and Gemini walks through seven core components: user interface specifications, natural language processing models, intent recognition workflows, knowledge base structure, context-aware conversation handling, escalation protocols to human agents, and analytics frameworks for continuous improvement. You supply your website type, products or services, audience characteristics, and support priorities; the prompt returns a tailored system blueprint that balances AI automation with human touchpoints. Use it when launching a new support channel, replacing outdated live-chat systems, or scaling customer service without proportional headcount growth. ● Covers interface, NLP engine, intent mapping, knowledge retrieval, context management, human handoff, and performance tracking in one cohesive design. ● Adapts to your business context - ecommerce, SaaS, healthcare, education - and surfaces the escalation triggers and FAQ structures that match your support volume. ● Outputs structured blueprints that engineering, product, and customer-success teams can immediately translate into implementation tickets. ● Includes multilingual support planning, mobile responsiveness, and A/B testing frameworks for iterative optimization. ## Prompt

```
## Role
You are an expert in conversational AI and customer support systems, designing chatbot architectures that balance automation with human escalation.

## Task
Design a complete chatbot system for the website that handles customer inquiries, retrieves relevant information, and guides users to solutions. Cover the full stack: interface, NLP capabilities, knowledge management, escalation paths, and optimization.

## Context
{{website-and-business-context}}

Include your website type, products/services offered, target audience characteristics, and any specific support challenges or priorities.

## Output
Provide a structured chatbot system design with these components:

**1. User Interface**
● Intuitive chat window prominently placed on the website
● Supports text input and multimedia attachments
● Adaptive layout for desktop and mobile devices
● Customizable avatar and branding elements

**2. Natural Language Processing**
● Advanced NLP models for understanding user queries
● Handles variations in phrasing, spelling, and grammar
● Multilingual support for global customer base
● Continuous learning from user interactions

**3. Intent Recognition**
● Identifies user intent based on query content and context
● Maps intents to predefined categories and support workflows
● Handles ambiguity and clarifies user intent through follow-up questions
● Escalates complex or unrecognized intents to human agents

**4. Knowledge Base**
● Comprehensive, structured repository of product/service information
● Supports efficient retrieval and presentation of relevant content
● Regularly updated with new features, FAQs, and troubleshooting guides
● Integrates with external systems for real-time data access

**5. Context Awareness**
● Maintains conversational context across user interactions
● Utilizes user profile, interaction history, and current session data
● Enables personalized responses and recommendations
● Seamlessly transitions between related topics and support tasks

**6. Handoff to Human Agents**
● Smooth escalation to human support for complex or sensitive issues
● Transfers conversational context and user details to agent interface
● Provides estimated wait times and callback options during peak hours
● Supports agent-to-chatbot handback for post-resolution follow-up

**7. Analytics and Optimization**
● Tracks key performance metrics (resolution rate, user satisfaction, response time)
● Identifies common pain points and opportunities for improvement
● Enables A/B testing of chatbot responses and workflows
● Generates actionable insights for support team and product development

Tailor each component to the specific needs described in the business context.
```
