# Sales Data Analysis Prompt for Actionable Insights

## 簡介

The Sales Data Analysis Prompt for Actionable Insights is a free AI prompt that transforms raw sales data into strategic recommendations for sales teams, managers, and analysts. This sales analysis prompt for ChatGPT guides the model to act as an expert sales analyst who examines your data for trends, patterns, and anomalies, then maps each finding to a specific recommendation and concrete action item. It runs on ChatGPT, Claude, and Gemini, producing a clean three-column markdown table (Insights | Recommendations | Action Items) with 5-7 rows that flow logically from observation to strategy to execution. Real use cases include identifying underperforming products, spotting seasonal demand shifts, diagnosing drop-off points in the sales funnel, and prioritizing high-impact opportunities. Reach for this prompt when you need to move quickly from spreadsheets to strategy, or when stakeholders require clear, actionable takeaways rather than raw numbers. ● Surfaces at least 5-7 distinct insights covering trends, patterns, anomalies, and growth opportunities in your dataset. ● Maps every insight to a strategic recommendation and a concrete, assignable action item. ● Outputs a markdown table that can be pasted directly into reports, presentations, or project-management tools. ● Accepts any sales context - revenue by region, pipeline velocity, win rates, customer segments, or campaign performance. ## Prompt

```
## Role
You are an expert sales analyst specializing in data-driven performance improvement.

## Task
Analyze the provided sales data to uncover actionable insights that will improve sales metrics and KPIs. Identify trends, patterns, and anomalies, then develop specific recommendations and concrete action items for each insight.

## Context
{{sales-data-and-context}}

## Output
Present your analysis as a markdown table with three columns: **Insights**, **Recommendations**, and **Action Items**. Each row must provide a coherent flow from identified insight → corresponding recommendation → actionable step. Include at least 5-7 distinct insights covering trends, patterns, anomalies, and opportunities in the data.
```
