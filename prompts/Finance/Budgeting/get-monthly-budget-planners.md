# Monthly Budget Planner Spreadsheet Template Generator

## 簡介

The Monthly Budget Planner Spreadsheet Template Generator is a free AI prompt that builds a customized budget spreadsheet blueprint tailored to your income, financial goals, and personal financial profile. This monthly budget planner prompt for ChatGPT produces a complete spreadsheet layout with labeled categories for income, fixed expenses, variable expenses, savings, and investments. It delivers formula instructions for automatic totals and percentages, variance calculations to track progress against goals, and spending pattern analysis sections. The prompt runs on ChatGPT, Claude, Gemini, and Grok, generating a detailed blueprint you can implement in Excel, Google Sheets, or any spreadsheet application. Use it when you need a structured budgeting framework that goes beyond generic templates - one that reflects your specific monthly income, target financial goal, and spending habits. ● Delivers column and row structures with clearly labeled categories and subcategories for granular expense tracking ● Provides step-by-step formula instructions for calculating totals, percentages, and variances automatically ● Includes guidance for identifying overspending patterns and uncovering savings opportunities specific to your financial profile ● Outputs a detailed spreadsheet blueprint with sample formulas and actionable recommendations you can implement immediately ## Prompt

```
## Role
You are an expert financial planner creating a comprehensive monthly budget planner.

## Task
Design a user-friendly budget template in spreadsheet format that enables effective personal finance management and easy tracking of financial goals.

## Context
The user needs to manage:
- Monthly income: {{monthly-income}}
- Financial goal: {{financial-goal}}
- Personal financial profile: {{financial-profile}}

The budget should categorize income, expenses, savings, and investments with clear functionality for data input, automatic calculations, and spending analysis.

## Output
Provide a structured spreadsheet layout with:

**Column and row structure:**
- Clearly labeled categories (Income, Fixed Expenses, Variable Expenses, Savings, Investments)
- Subcategories for detailed tracking
- Monthly columns with total and variance calculations

**Functional elements:**
- Formula instructions for automatic totals and percentages
- Calculation methods for tracking against goals
- Spending pattern analysis sections

**Guidance:**
- Step-by-step data input instructions
- Tips for identifying overspending in each category
- Recommendations for potential savings opportunities based on the user's profile

Format the output as a detailed spreadsheet blueprint with labeled columns, rows, sample formulas, and actionable insights.
```
