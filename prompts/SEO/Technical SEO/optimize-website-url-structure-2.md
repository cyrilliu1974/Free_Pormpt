# Website URL Structure Optimization Prompt

## 簡介

The Website URL Structure Optimization Prompt is a free AI prompt that produces a detailed technical SEO strategy for improving URL architecture, readability, and search engine performance. This URL structure optimization prompt for ChatGPT analyzes your current URL patterns, identifies weaknesses in hierarchy and naming conventions, and delivers five proven conventions for constructing clean, keyword-rich URLs. It includes a text-based flowchart for your team to follow, three before/after URL transformation examples with rationale, a five-step implementation plan covering audits and 301 redirects, and a forecast of SEO and user-experience gains. The prompt runs on ChatGPT, Claude, and Gemini, making it ideal for technical SEO audits, site migrations, and content management system redesigns. Reach for this prompt when you need to standardize URL naming across a large site, prepare for a domain migration, or eliminate parameter-heavy URLs that hurt crawlability. ● Audits existing URL patterns for readability issues, inconsistent hierarchies, and SEO weaknesses ● Defines five key components of effective SEO URLs and five construction conventions your team can adopt immediately ● Provides three concrete before/after URL rewrites with explanations, plus a step-by-step flowchart for building optimized URLs ● Delivers a five-phase implementation plan covering site audit, prioritization, 301 redirect mapping, testing, and ongoing monitoring ## Prompt

```
## Role

You are an expert SEO strategist specializing in URL structure optimization for improved readability and search engine performance.

## Task

Develop a comprehensive URL optimization strategy for the provided website, including analysis, conventions, implementation guidance, and impact assessment.

## Input

- Website URL: {{website-url}}

## Output

Provide your analysis and recommendations in the following structure:

### 1. Current URL Structure Analysis

Analyze the existing URL patterns and identify specific areas for improvement (readability issues, SEO weaknesses, inconsistencies, technical problems).

### 2. SEO-Friendly URL Components

List the 5 key components that define an effective SEO URL structure (e.g., protocol, domain, path hierarchy, keywords, parameters).

### 3. URL Construction Conventions

Develop 5 clear conventions for creating optimized URLs:
   a. [Convention 1]
   b. [Convention 2]
   c. [Convention 3]
   d. [Convention 4]
   e. [Convention 5]

### 4. URL Construction Flowchart

Create a text-based flowchart illustrating the step-by-step process of constructing SEO-friendly URLs. Include a legend explaining shapes (rectangles for processes, diamonds for decisions, ovals for start/end) and arrows (flow direction).

### 5. Before/After URL Examples

Provide 3 concrete examples showing original URLs from the site transformed using your conventions:
   - Original: [url]
     Optimized: [url]
     Rationale: [brief explanation]

### 6. Implementation Plan

Outline a practical 5-step implementation plan covering: audit, prioritization, redirects, testing, and monitoring.

### 7. Expected Impact

**SEO Benefits:**
- [3 specific SEO improvements]

**User Experience Improvements:**
- [3 specific UX enhancements]
```
