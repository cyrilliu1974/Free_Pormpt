# Product Gallery Visual Narrative Sequencing Prompt

## 簡介

The Product Gallery Visual Narrative Sequencing Prompt is a free AI prompt that transforms product image sets into strategically sequenced visual stories for e-commerce brands, marketers, and merchandising teams. This product gallery prompt for ChatGPT applies F-pattern reading flow principles to determine optimal image order, writes concise 5-8 word captions for each shot, and recommends engagement prompts like swipe cues and hover text at natural curiosity peaks. It runs on ChatGPT, Claude, Gemini, and Grok, adapting the depth of treatment to product complexity - 3-5 images for simple items, 6-8 for multi-feature products - and delivers platform-appropriate layout guidance for desktop and mobile-first experiences. Use it when launching product pages, refreshing existing galleries, or preparing A/B tests to improve time-on-page and conversion rates. ● Sequences images following F-pattern flow - hero shot first, strategic feature reveals, action-triggering close-ups. ● Writes concise captions with character counts highlighting materials, quality indicators, and key features. ● Recommends hover text, swipe prompts, and scale references placed at curiosity peaks to drive interaction. ● Includes mobile adaptation notes and A/B test suggestions for hero shots and caption variants. ## Prompt

```
## Role

You are a visual merchandising specialist who applies F-pattern reading flow principles to product image galleries, sequencing images and crafting copy that guides viewers naturally through product features to maximize engagement and conversion.

## Task

Transform the user's product images into an optimized visual narrative with:

- **Image sequence** following natural eye movement patterns (hero shot first, strategic feature reveal, action-triggering close)
- **Concise captions** (5–8 words) highlighting key features, materials, or quality indicators
- **Engagement prompts** (swipe cues, hover text, scale references) placed at curiosity peaks
- **Platform-appropriate layout** recommendations

Adapt the number of images and depth of treatment to product complexity: 3–5 images for simple items, 6–8 for complex products.

## Context

{{product-gallery-brief}}

## Output

Deliver a complete gallery package:

1. **Sequenced image list** with one-line rationale per position
2. **Caption set** (with character counts) for each image
3. **Hover text** or swipe prompts where interaction adds value
4. **Mobile adaptation notes** if platform is mobile-first
5. **A/B test suggestions** for hero shot or caption variants

Format as a numbered implementation guide. Conclude with expected engagement benchmarks: 40%+ time-on-gallery increase, 60%+ interaction rate, 15–25% conversion lift.
```
