# SEO Link Building Strategy Prompt

## 簡介

The SEO Link Building Strategy Prompt is a free AI prompt that generates customized link building plans designed to improve search engine rankings and drive organic traffic for websites across any industry. This link building prompt for ChatGPT analyzes your website's current SEO profile - including domain authority, target audience, and industry niche - and produces a structured table of actionable tactics, each with step-by-step implementation guidance and measurable expected outcomes. Whether you're building links for an e-commerce store, SaaS product, or local service business, the prompt prioritizes tactics by effort-to-impact ratio and ensures compliance with current search engine guidelines. It runs on ChatGPT, Claude, and Gemini, delivering results in an easy-to-follow markdown table format. This prompt is for SEO professionals, content marketers, and site owners who need a data-driven, ready-to-execute link building roadmap that aligns with their specific business context and resources. ● Tailors link building tactics to your website's unique niche, audience demographics, and current domain authority ● Provides numbered, sequential implementation steps for each tactic so your team knows exactly how to execute ● Specifies measurable expected results including estimated link acquisition, ranking improvements, and timeframes ● Prioritizes tactics by effort-to-impact ratio to maximize ROI on your link building investment ## Prompt

```
## Role
You are an expert SEO strategist specializing in link building campaigns that improve search engine rankings and drive organic traffic.

## Task
Develop a comprehensive link building strategy tailored to the website's niche, audience, and current SEO performance. For each tactic, provide actionable implementation steps and realistic expected outcomes.

## Context
Website and SEO profile:
{{website-and-seo-context}}
(Include: website URL, industry/niche, target audience characteristics, current search rankings or domain authority)

Number of tactics to develop: {{number-of-tactics}}

## Requirements
- Select link building tactics appropriate for the industry and audience
- Structure each tactic with clear, sequential implementation steps
- Specify measurable expected results (timeline, estimated links, ranking impact)
- Prioritize tactics by effort-to-impact ratio where relevant
- Ensure all tactics comply with current search engine guidelines

## Output
Present your strategy as a markdown table with three columns:

| Link Building Tactics | Implementation Steps | Expected Results |
|----------------------|---------------------|------------------|
| [Tactic name and brief description] | [Numbered steps to execute] | [Quantified outcomes and timeframe] |
```
