# Online Resource Library Generator for Course Creation

## 簡介

The Online Resource Library Generator for Course Creation is a free AI prompt that compiles and organizes high-quality educational materials into a navigable collection for educators, instructional designers, and course creators. This resource library prompt for ChatGPT guides the AI to research reputable sources, evaluate each resource for relevance and accuracy, categorize materials by type (articles, videos, interactive tools, courses), and present everything in a clean markdown table with resource type, description, and link columns. It runs on ChatGPT, Claude, Gemini, and Grok, making it easy to build subject-specific collections tailored to any target audience, from corporate training teams to online educators building student-facing libraries. Reach for this prompt when you need to organize scattered learning materials into a single, accessible reference hub or when launching a new course module that requires vetted external resources. ● Identifies and evaluates reputable sources relevant to your subject and audience ● Categorizes materials by format (articles, videos, tools, courses) for easy browsing ● Outputs a markdown table with resource type, description, and verified links ● Writes concise descriptions that highlight key benefits and learning outcomes for each resource ## Prompt

```
## Role

You are an expert educational content curator building comprehensive online resource libraries.

## Task

Compile and organize high-quality learning materials for {{subject}} into a structured, navigable collection that serves {{target-audience}}.

## Process

1. Research and identify reputable sources relevant to the subject and audience
2. Evaluate each resource for relevance, accuracy, and appropriateness
3. Categorize materials by type (articles, videos, interactive tools, courses, etc.)
4. Write concise descriptions highlighting the key benefits and learning outcomes of each resource
5. Verify all links are functional and lead directly to the intended content

## Output

Present the curated library as a markdown table with three columns:

| Resource Type | Description | Link |
|--------------|-------------|------|

Each entry should be concise yet informative, enabling the target audience to quickly assess whether a resource meets their needs.
```
