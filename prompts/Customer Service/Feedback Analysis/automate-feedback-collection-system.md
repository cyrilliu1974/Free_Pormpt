# Feedback Collection System Design Prompt

## 簡介

The Feedback Collection System Design Prompt is a free AI prompt that builds structured feedback systems for communication campaigns, complete with KPIs, data collection methods, and analysis techniques. This feedback collection system prompt for ChatGPT guides you through designing measurement frameworks tailored to your specific campaign type and audience. It generates a complete methodology covering performance indicators, data gathering approaches, analysis techniques, reporting formats, and implementation steps - all supported by credible industry sources and citations. Use it to create feedback systems for marketing campaigns, internal communications, public relations initiatives, or any strategic messaging effort where measuring impact matters. The prompt runs on ChatGPT, Claude, and Gemini, producing actionable frameworks that go beyond generic templates. ● Identifies campaign-specific KPIs aligned with objectives and audience behavior ● Recommends data collection methods with credible source citations for transparency ● Outlines analysis techniques and reporting formats for actionable insights ● Provides step-by-step implementation plans and improvement identification frameworks ## Prompt

```
## Role
You are an expert in communication campaign measurement and feedback systems.

## Task
Design a comprehensive feedback collection system that measures campaign impact and identifies areas for improvement. Support your methodology with credible sources and industry best practices.

## Context
Campaign details: {{campaign-details}}

Tailor the feedback system to the specific campaign type. Provide actionable insights for improving future campaigns.

## Output
Deliver your analysis in this structure:

**Campaign Type:** [Identify from the campaign details]

**Target Audience:** [Define the primary audience]

**Key Performance Indicators (KPIs):**
● [KPI 1]
● [KPI 2]
● [KPI 3]

**Data Collection Methods:**
1. [Method 1] (Source: [citation])
2. [Method 2] (Source: [citation])
3. [Method 3] (Source: [citation])

**Analysis Techniques:**
1. [Technique 1] (Source: [citation])
2. [Technique 2] (Source: [citation])

**Reporting Format:**
● [Section 1]
● [Section 2]
● [Section 3]
● [Section 4]

**Improvement Identification:**
1. [Area 1]
2. [Area 2]
3. [Area 3]

**System Implementation:**
[Step-by-step implementation plan]

Focus on providing a comprehensive, well-cited methodology. Be specific and actionable.
```
