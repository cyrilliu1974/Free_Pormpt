# Keyword Clustering Tool for SEO Strategy

## 簡介

The Keyword Clustering Tool for SEO Strategy is a free AI prompt that organizes keywords into semantic groups and generates content ideas for SEO professionals and content strategists. This keyword clustering prompt for ChatGPT analyzes your keyword list and SEO context to group terms by search intent and thematic relationships, then produces a structured markdown table showing cluster names, grouped keywords, and actionable content ideas for each group. It runs on ChatGPT, Claude, Gemini, and Grok, helping you transform raw keyword lists into organized clusters that inform both your editorial calendar and site navigation structure. The output prioritizes clusters by strategic value for your niche, making it practical for building topic hubs, planning pillar pages, or restructuring site taxonomy. Use this prompt when you have keyword research data that needs structure, or when planning content that will target multiple related search terms within a cohesive architecture. ● Groups keywords by search intent and semantic similarity to eliminate guesswork in content planning ● Generates specific content ideas for each cluster that align with user queries and business goals ● Outputs a clean markdown table format that integrates directly into strategy documents and project briefs ● Orders clusters by strategic priority based on your niche and objectives, not arbitrary metrics ## Prompt

```
## Role
You are an expert SEO strategist specializing in keyword clustering for content strategy and site architecture optimization.

## Task
Organize the provided keywords into semantic groups based on search intent and thematic relationships. For each cluster, generate targeted content ideas that will guide content creation and inform site structure decisions.

## Context
**Keywords to cluster:** {{keywords}}

**SEO context:** {{seo-context}}
(Include: target audience, website niche, content goals, and current site structure)

## Process
1. Analyze the keywords to identify common themes and user search intents
2. Group keywords into logical clusters based on semantic relationships
3. For each cluster, develop content ideas that effectively target the grouped keywords
4. Ensure clusters support both content planning and site architecture optimization

## Output
Present your analysis as a markdown table with three columns:

| Cluster Name | Keywords | Content Ideas |
|--------------|----------|---------------|

Each row represents a distinct semantic group with its associated keywords and potential content topics. Order clusters by strategic priority for the specified niche and goals.
```
