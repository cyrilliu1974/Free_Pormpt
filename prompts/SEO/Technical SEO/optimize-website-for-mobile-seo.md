# Mobile SEO Audit & Optimization Action Plan

## 簡介

The Mobile SEO Audit & Optimization Action Plan is a free AI prompt that conducts a full mobile-friendliness assessment and builds a phased roadmap to fix critical issues for website owners and SEO professionals. This mobile SEO prompt for ChatGPT systematically evaluates your site's responsive design, Core Web Vitals (LCP, FID, CLS), mobile content strategy, and technical indexing signals, then delivers a detailed action plan ranked by impact and implementation effort. It runs on ChatGPT, Claude, Gemini, and Grok, requiring only your website URL and business context - including your target audience, mobile traffic share, and top competitors. Real use cases include agencies preparing client mobile SEO roadmaps, in-house teams diagnosing mobile ranking drops, and ecommerce sites optimizing checkout flows for mobile shoppers. Reach for this prompt when you need a structured, prioritized mobile optimization strategy that goes beyond generic advice and delivers a concrete three-phase implementation timeline tied to your specific business goals and competitive landscape. ● Audits four critical areas: responsive design adaptation, mobile page speed and Core Web Vitals, mobile content hierarchy, and technical mobile indexing signals. ● Ranks every identified issue by severity and implementation effort, separating quick wins from long-term initiatives across a 12-week roadmap. ● Includes competitive benchmarking against your top rivals on key mobile metrics, highlighting specific opportunities to gain search advantage. ● Defines clear success KPIs for mobile rankings, traffic, engagement, and conversions, with recommended monitoring tools and tracking frequency. ## Prompt

```
## Role
You are an expert mobile SEO specialist.

## Task
Conduct a comprehensive audit of a website's mobile-friendliness, page load speed, and mobile user experience, then create a detailed action plan to address identified issues.

## Context
**Website:** {{website-url}}

**Business & Audience:**
{{business-context}}
(Include: business type, primary target audience, current mobile traffic percentage, and top 3-5 competitors)

## Approach
Work systematically through these priority areas:

1. **Responsive Design** – Assess layout adaptation, touch targets, viewport configuration, and cross-device consistency
2. **Mobile Page Speed** – Analyze Core Web Vitals (LCP, FID, CLS), resource optimization, caching, and rendering performance
3. **Mobile-Specific Content** – Evaluate readability, navigation patterns, content hierarchy, and mobile user intent alignment
4. **Technical Mobile SEO** – Review mobile indexing signals, structured data, and crawlability

For each area, identify specific issues and rank them by impact and implementation effort.

## Output
Deliver a structured mobile SEO action plan with:

### Executive Summary
- Current mobile SEO health score
- Critical issues requiring immediate attention
- Expected impact of recommended changes

### Detailed Findings by Priority Area
For each of the four areas above:
- **Issues Identified** (with severity: Critical/High/Medium/Low)
- **Recommended Actions** (specific, actionable steps)
- **Expected Outcomes** (measurable improvements)
- **Implementation Priority** (Quick wins vs. long-term initiatives)

### Prioritized Action Plan
- **Phase 1 (Weeks 1-2):** Critical fixes
- **Phase 2 (Weeks 3-6):** High-impact optimizations
- **Phase 3 (Weeks 7-12):** Refinements and ongoing improvements

### Competitive Benchmarking
- How the website compares to listed competitors on key mobile metrics
- Opportunities to gain competitive advantage

### Success Metrics
- KPIs to track (mobile rankings, traffic, engagement, conversions)
- Recommended monitoring tools and frequency
```
