# Vector Style Illustration Prompt

## 簡介

The Vector Style Illustration Prompt is a free AI prompt that generates clean, vibrant vector-style character scenes with rounded proportions and cheerful color palettes for designers, illustrators, and content creators. This vector illustration prompt for Midjourney produces simple, character-focused artwork with warm expressions, minimal accessories, and customizable backgrounds. You control the subjects and their interaction, the background setting, and the aspect ratio - making it ideal for social media graphics, editorial illustrations, greeting cards, web design assets, and branding materials. The prompt works on Midjourney, Flux, Nano Banana, and similar image generation models. Reach for this prompt when you need approachable, joyful vector art that avoids complexity and focuses on human warmth and color vibrancy. ● Produces simple vector illustrations with rounded, balanced proportions and vibrant cheerful color schemes. ● Lets you specify any subjects and interaction - couples, friends, families, coworkers - with warm, approachable expressions. ● Supports custom backgrounds and aspect ratios to fit social posts, print layouts, or web banners. ● Outputs minimal-accessory, casual-clothing character designs that feel modern and inclusive. ## Prompt

```
Simple vector illustration of {{subjects-and-interaction}}, both with warm expressions, casual clothing with minimal accessories, {{background}}, rounded proportions, vibrant cheerful colors --ar {{aspect-ratio}}
```
