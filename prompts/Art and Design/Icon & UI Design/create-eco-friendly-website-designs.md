# Eco-Friendly Website UI Design Prompt

## 簡介

The Eco-Friendly Website UI Design Prompt is a free AI prompt that generates professional website mockups for sustainability-focused startups and green brands. This eco-friendly website design prompt for Midjourney, Flux, and Nano Banana produces high-fidelity UI/UX mockups with an earthy color palette of greens and beiges, fullscreen hero sections featuring looping forest and ocean video backgrounds, bold sans-serif typography for your sustainability message, and clean infographic cards that present carbon footprint data and key environmental metrics. The output includes rounded call-to-action buttons with soft shadows and minimal line-art iconography inspired by leaves, water, and natural elements, all arranged in a breathable layout with ample whitespace. Design teams building green startup websites, environmental nonprofits creating online presences, or agencies pitching eco-brands will find this prompt delivers a fresh, modern aesthetic that communicates environmental values immediately. ● Fullscreen hero sections with video placeholders showing forests, oceans, and natural landscapes that establish tone instantly. ● Infographic card layouts that turn complex sustainability data into digestible visual elements with clean typography and spacing. ● Nature-inspired iconography using minimal line art of leaves, water droplets, and organic shapes that reinforce eco values. ● Rounded, tactile UI elements with soft shadows that create an inviting, approachable interface aligned with environmental brand identity. ## Prompt
