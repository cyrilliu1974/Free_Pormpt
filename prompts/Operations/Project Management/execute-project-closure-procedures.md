# Project Closure Procedures Prompt for ChatGPT

## 簡介

The Project Closure Procedures Prompt for ChatGPT is a free AI prompt that generates structured project closure plans for project managers and PMO teams. This project closure prompt for ChatGPT walks you through a seven-step closure sequence: deliverable verification against acceptance criteria, documentation compilation including lessons learned, final project report creation with KPIs and business value metrics, stakeholder closeout meetings with formal acceptance, resource release and contract closure, archival procedures for future reference, and post-project evaluation with improvement recommendations. The prompt runs on ChatGPT, Claude, and Gemini, producing structured plans with headings, subheadings, and actionable bullet points tailored to your project scope, stakeholders, timeline, and industry context. Real use cases include closing waterfall IT implementations, agile product releases, construction projects, consulting engagements, and marketing campaigns where formal documentation and sign-offs are required. Project managers reach for this prompt when transitioning from execution to closure, ensuring nothing is overlooked between final delivery and formal project acceptance. ● Produces a seven-step closure plan covering deliverable verification, documentation, reporting, stakeholder meetings, resource release, archival, and post-project evaluation ● Ensures formal sign-offs, lessons learned capture, financial reconciliation, and contract closure are documented and tracked ● Adapts the closure procedure to your specific project scope, stakeholder list, timeline, and industry requirements ● Outputs structured plans with clear headings and actionable steps appropriate for cross-functional teams and executive stakeholders ## Prompt

```
## Role
You are an expert project manager executing formal project closure procedures.

## Task
Produce a comprehensive project closure plan that ensures all deliverables are verified, documentation is complete, stakeholders are informed, and resources are properly released.

## Context
Project details:
- Type and objectives: {{project-scope}}
- Key stakeholders: {{stakeholders}}
- Duration and industry context: {{timeline-and-industry}}

Follow this closure sequence:

1. **Deliverable Verification**
   - Review all project deliverables against acceptance criteria
   - Document completion status and obtain sign-offs
   - Address any gaps or outstanding items

2. **Documentation Compilation**
   - Organize all project documentation: reports, change logs, meeting minutes, technical specs
   - Capture lessons learned from team and stakeholders
   - Ensure version control and completeness

3. **Final Project Report**
   - Summarize achievements against original objectives
   - Document challenges encountered and resolutions
   - Present key performance indicators and metrics
   - Highlight deliverables and business value created

4. **Stakeholder Closeout**
   - Schedule and conduct final stakeholder meeting
   - Present project outcomes and final report
   - Address remaining concerns or questions
   - Obtain formal project acceptance

5. **Resource Release**
   - Formally release team members and equipment
   - Close outstanding contracts, purchase orders, and agreements
   - Complete financial reconciliation

6. **Archival**
   - Archive all project materials in the designated repository
   - Ensure accessibility for future reference and audits
   - Document archive location and retrieval procedures

7. **Post-Project Evaluation**
   - Gather feedback from team and stakeholders
   - Identify improvement opportunities for future projects
   - Document recommendations and best practices

## Output
Provide a structured closure plan with main headings and subheadings. Use bullet points for detailed steps under each section. Ensure all communication is clear, precise, and appropriate for cross-functional stakeholders.
```
