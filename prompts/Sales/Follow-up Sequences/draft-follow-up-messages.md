# Follow-Up Message Sequence Generator for Customer Retention

## 簡介

The Follow-Up Message Sequence Generator for Customer Retention is a free AI prompt that creates personalized follow-up strategies designed to prevent churn and build lasting customer relationships through value-first communication. This follow-up sequence prompt for ChatGPT, Claude, Gemini, and Grok analyzes your customer scenario and generates 3-8 phases of follow-up messages tailored to the interaction type - whether post-purchase onboarding, inquiry nurturing, or issue resolution. Each phase includes precise timing, clear objectives, conversational message drafts, specific value elements, and low-friction calls-to-action. The prompt considers customer emotional states and delivers micro-value at every touchpoint, ensuring messages feel like genuine check-ins rather than sales pitches. Real use cases include e-commerce post-purchase sequences that drive repeat orders, SaaS onboarding flows that reduce early churn, and service recovery sequences that transform dissatisfied customers into advocates. This prompt is for customer success teams, retention marketers, and business owners who need systematic follow-up communication that builds relationship depth over time without feeling intrusive or transactional. ● Adapts the number of follow-up phases (3-8) based on interaction type - purchase, inquiry, or support issue - ensuring appropriate relationship depth. ● Delivers specific value elements in every message, from onboarding resources to exclusive insights, so customers benefit from each touchpoint. ● Provides timing guidance and emotional-state analysis to help you send the right message at the right moment in the customer journey. ● Includes clear next-step actions that feel natural and low-pressure, moving customers toward advocacy without aggressive selling. ## Prompt

```
## Role

You are an expert customer retention strategist specializing in relationship-driven follow-up sequences that prevent churn through value-first communication.

## Task

Create a personalized follow-up message strategy that nurtures the customer relationship and delivers value at each touchpoint. Adapt the number of phases (3-8) and content based on interaction type, customer status, and relationship depth required.

## Context

**Customer scenario:**
{{customer-scenario}}

**Phase creation logic:**

- Purchase follow-ups: 5-8 phases (onboarding → advocacy)
- Inquiry follow-ups: 3-5 phases (nurture → conversion)  
- Issue follow-ups: 4-6 phases (resolution → retention)

**Before each phase, consider:**

- What emotional state is this customer in?
- What micro-value can I deliver right now?
- How can I make them feel seen without being intrusive?

## Output

For each phase, provide:

1. **Phase name & timing** (e.g., "Phase 1: Welcome - Day 0")
2. **Objective** (what this message accomplishes)
3. **Message draft** (conversational, value-driven tone)
4. **Value element** (specific utility or insight delivered)
5. **Next step** (clear, low-friction call-to-action)

Present the complete sequence with reasoning for the number of phases chosen and how they build relationship depth over time.
```
