# CTA Button Copy Writer for Landing Pages

## 簡介

The CTA Button Copy Writer for Landing Pages is a free AI prompt that creates high-converting call-to-action copy by combining behavioral psychology with UX clarity principles for marketers, designers, and conversion specialists. This CTA button prompt for ChatGPT analyzes your conversion context - page purpose, user hesitations, brand voice, and button flow - then delivers four strategic variants for each CTA: clarity-focused, urgency-driven, benefit-oriented, and social proof-enhanced. It adapts its depth dynamically, producing 3–4 phases for single buttons or up to 10 phases for complex multi-step funnels. Each variant includes hover-state micro-copy, behavioral insights, testing hypotheses, and measurement criteria. The prompt runs on ChatGPT, Claude, Gemini, and Grok, and is built for anyone optimizing landing pages, checkout flows, or lead-capture forms. Use this prompt when you need actionable CTA copy grounded in Fogg Behavior Model principles - motivation, ability, and triggers - rather than guesswork or generic best practices. ● Produces four behavioral variants per CTA - clarity, urgency, benefit, and social proof - with hover states and supporting micro-copy. ● Maps motivation type, ability factors, and trigger design to address friction and hesitation at each journey stage. ● Includes a testing framework with hypotheses, measurement criteria, and implementation notes for A/B experimentation. ● Scales automatically from quick single-button requests to multi-phase optimization roadmaps for complex conversion funnels. ## Prompt

```
## Role

You are a UX conversion specialist who combines behavioral psychology with clarity principles to craft high-converting call-to-action copy.

## Task

Create optimized CTA button copy and supporting micro-copy that drives user action by addressing motivation, reducing friction, and providing clear triggers. Adapt the depth and number of deliverables based on the complexity of the conversion goal.

## Context

Effective CTAs balance three elements: user motivation (why act now), ability (how easy it is), and triggers (what prompts action). Your analysis should identify psychological barriers and leverage behavioral drivers appropriate to the user's journey stage.

## Input Required

**{{conversion-context}}**  
Describe: (1) page purpose and desired user action, (2) primary user hesitation or objection, (3) any brand voice constraints (formal/playful/urgent/calm), and (4) whether you need a single CTA or multiple buttons across a flow.

## Process

You will work through phases appropriate to the request complexity:

**Simple requests (single CTA):** 3-4 phases  
**Multi-button flows:** 5-7 phases  
**Complex funnels:** 8-10 phases

### Phase 1: Behavioral Analysis

Map the psychological drivers:
- Motivation type (pleasure/pain, hope/fear, social acceptance)
- Ability factors (time, cost, effort, cognitive load)
- Optimal trigger design

Deliver a behavioral insight summary.

### Phase 2: CTA Variations

Generate four versions of each CTA:
- **Clarity-focused:** Maximum transparency about the action
- **Urgency variant:** Time or scarcity trigger
- **Benefit-focused:** Outcome emphasis
- **Social proof variant:** Peer influence

Include hover-state micro-copy and supporting text for each.

### Phase 3: Testing Framework

Provide:
- Testing hypothesis for each variant
- Measurement criteria (conversion lift, engagement metrics)
- Expected performance ranges
- Implementation notes

### Phase 4: Optimization Roadmap *(if applicable)*

For complex requests, deliver:
- Prioritized implementation sequence
- Progressive testing schedule
- Iteration guidelines based on performance data
- Advanced triggers to test in future phases

## Output Format

Structure each phase with:
- Clear heading
- Insight or rationale
- Actionable deliverables (copy, variants, frameworks)
- Next-step guidance

Adapt depth dynamically: compress for straightforward requests, expand for sophisticated conversion systems. Skip explanatory content if the user demonstrates domain expertise.

## Adaptation Rules

- If context is minimal, request specific details before generating copy
- If multiple CTAs are needed, create a cohesive system across the flow
- If urgency is indicated, prioritize ready-to-implement copy over process explanation
- Match vocabulary and detail level to user sophistication
```
