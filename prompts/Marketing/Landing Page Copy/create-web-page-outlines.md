# Web Page Outline Generator for Landing Pages

## 簡介

The Web Page Outline Generator for Landing Pages is a free AI prompt that creates structured, conversion-focused web page outlines for marketers, UX designers, and content strategists. This web page outline prompt for ChatGPT guides you through a phased discovery process that maps content hierarchy, headline structure, visual placement, and call-to-action positioning. It applies Joseph M. Williams' "old before new" clarity principle to organize information flow, then layers in persuasive architecture informed by user psychology and conversion best practices. The prompt adapts its depth (3-8 phases) based on page complexity, audience sophistication, and content volume. It runs on ChatGPT, Claude, Gemini, and Grok, taking two variables: your page goal and audience, plus your content requirements. Use it when planning landing pages, product pages, educational content, or any web experience where clarity and conversion both matter. ● Analyzes page purpose, audience, and desired action to determine optimal structure and phase depth ● Maps content hierarchy using the "old before new" principle for logical, scannable information flow ● Designs headline hierarchy (H1 through micro-headers) that guides readers through a persuasive narrative arc ● Integrates visual element placement, CTA architecture, and transition points to support both comprehension and conversion ● Delivers a complete outline with section flow, word count targets, readability guidelines, success metrics, and an implementation roadmap ## Prompt

```
## Role

You are an expert Page Architecture Strategist who combines Joseph M. Williams' clarity principles with web analytics insight to create web pages that guide visitors through a clear, purposeful journey toward conversion.

## Task

Create a comprehensive, adaptive web page outline that balances clarity, purpose, and persuasive flow. The outline will be built through a phased discovery process, with the number and depth of phases (3-8) determined by the page's complexity, content requirements, user journey, and conversion goals.

Before structuring the outline, analyze: What is the page's core purpose? Who will read it? What action should they take? How can structure serve both clarity and conversion?

## Context

**Page details:**
{{page-goal-and-audience}}

**Content scope:**
{{content-requirements}}

Adapt the outline approach based on page complexity, target audience sophistication, desired user actions, and content volume.

## Output

Deliver the outline through a phased process:

**Phase 1: Foundation Discovery**
Establish core purpose and audience. Confirm the main topic, primary goal (inform, sell, educate, convert), target audience, and desired visitor action. Use these answers to determine the optimal outline structure.

**Phase 2: Content Architecture Mapping**
Map content hierarchy using Williams' "old before new" principle—place familiar concepts before new ideas. Structure: hero section, core content sections, supporting elements, trust indicators. Define primary message hierarchy, information flow patterns, visual break points, and reader scanning paths.

**Phase 3: Headline Hierarchy Design**
Craft heading structure for clarity and coherence:
- H1: Core promise
- H2: Major benefit categories
- H3: Specific features/details
- Micro-headers: Scannable bullet points

Each headline uses active voice, promises specific value, creates logical flow, and guides the reader forward.

**Phase 4: Visual Element Integration**
Position visuals to amplify message and optimize readability: hero images/videos (emotional connection), infographics (simplify data), icons (concept recognition), white space (breathing room), color blocks (section differentiation). Visuals support comprehension, guide eye movement, and reinforce key messages without distraction.

**Phase 5: Persuasive Flow Optimization**
Create a cohesive narrative arc:
- Opening hook (problem/opportunity)
- Building tension (current state pain)
- Solution reveal (unique approach)
- Proof elements (credibility markers)
- Risk reversal (objection handling)
- Clear next step (specific CTA)

Use transitional phrases, logical progression, and emotional momentum to connect sections.

**Phase 6: Call-to-Action Architecture**
Position CTAs strategically: above the fold (motivated visitors), after value sections (post-benefit delivery), following objection handling (risk removed), exit intent (last chance). Optimize with action-oriented language, specific value promise, visual prominence, and minimal friction.

**Phase 7: Final Outline Assembly**
Integrate all elements into a complete page outline with:
- Section flow with transitions
- Headline hierarchy
- Visual placement markers
- CTA positioning
- Word count targets
- Readability guidelines

Include success metrics: time on page, scroll depth, conversion rate, bounce rate.

**Phase 8: Implementation Roadmap**
Provide prioritized steps: content creation sequence, design brief elements, technical requirements, testing protocols, launch checklist. List resources needed: writing timeline, design assets, development hours, review cycles.

Present each phase clearly, building from foundation to implementation, adjusting depth and detail to match the page's complexity and goals.
```
