# Storytelling Speech Writer Prompt

## 簡介

The Storytelling Speech Writer Prompt is a free AI prompt that generates complete, compelling speeches using narrative techniques and dependency grammar principles for speakers, executives, and communicators. This storytelling speech prompt for ChatGPT guides the AI to craft structured presentations that resonate with specific audiences. It runs on ChatGPT, Claude, Gemini, and Grok, producing speeches with attention-grabbing openings, logically connected body sections built on 2-4 main points, and powerful conclusions with clear calls-to-action. The prompt emphasizes dependency grammar to ensure each sentence and idea flows naturally from the previous one, while weaving in anecdotes, metaphors, data, and rhetorical devices that make messages memorable. Real-world use cases include keynote addresses, corporate presentations, fundraising appeals, commencement speeches, and persuasive talks where storytelling drives emotional connection and action. Reach for this prompt when you need a polished speech that balances narrative impact with logical structure, whether for formal events, team meetings, or public forums. ● Produces introduction, body, and conclusion sections with headings, bullet points for talking points, and delivery notes ● Applies dependency grammar framework to ensure each idea connects logically and transitions flow smoothly ● Incorporates storytelling elements including opening hooks, supporting anecdotes, metaphors, and memorable closing lines ● Adapts tone, length, and style based on your parameters - from inspirational and data-driven to humorous and conversational ## Prompt

```
## Role
You are an expert speechwriter crafting compelling narratives that resonate with audiences and drive action.

## Task
Write a complete speech that uses storytelling techniques and dependency grammar principles to ensure logical flow and coherence.

## Context
**Audience & Message:**
{{audience-and-message}}
(Describe who you're speaking to, what core message you need to convey, and any relevant context about the occasion, setting, or situation.)

**Speech Parameters:**
{{speech-parameters}}
(Specify desired length, tone, and storytelling style—e.g., inspirational/data-driven/humorous, personal anecdotes vs. case studies, formal vs. conversational.)

## Output
Structure the speech with clear sections and deliver:

**Introduction**
- Opening hook that captures attention immediately
- Thesis statement encapsulating the key message
- Preview of what's to come

**Body** (2-4 main points)
- Each point built on dependency grammar structure for logical flow
- Supporting anecdotes, metaphors, examples, and data
- Rhetorical devices that enhance impact and memorability
- Smooth transitions linking ideas

**Conclusion**
- Synthesis of main points
- Powerful call-to-action that reinforces the key message
- Memorable closing line

Present each section with a heading and use bullet points for key talking points, phrases, and delivery notes.
```
