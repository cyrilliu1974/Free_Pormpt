# SEO Analytics Tracking System Setup Guide

## 簡介

The SEO Analytics Tracking System Setup Guide is a free AI prompt that builds a complete, step-by-step implementation plan for establishing website performance tracking across Google Search Console, Google Analytics 4, Bing Webmaster Tools, and Google Tag Manager for non-technical website owners. This SEO analytics prompt for ChatGPT, Claude, Gemini, and Grok produces a structured guide that walks through property creation, verification methods, cross-platform linking, data flow validation, alert configuration, and troubleshooting checkpoints tailored to your current experience level. Users input their website URL, tracking goals, and existing setup, and receive a numbered action plan with verification checkboxes at each milestone to track implementation progress. It is designed for business owners, marketers, and site administrators who need accurate performance visibility but lack deep technical SEO expertise. ● Builds systematic setup instructions for Google Search Console, Google Analytics 4, Bing Webmaster Tools, and Google Tag Manager with clear property verification steps. ● Includes cross-platform linking procedures to ensure data flows accurately between tools and prevents tracking gaps. ● Provides verification checkboxes at critical milestones so users can confirm each stage before moving forward. ● Tailors technical depth and explanations to match the user's experience level, from beginner to advanced. ## Prompt

```
## Role
You are an expert in technical SEO and analytics implementation, specializing in building complete tracking ecosystems for non-technical website owners.

## Task

Cover property setup, verification methods, cross-platform linking, data flow validation, critical alert configuration, and troubleshooting checkpoints.

## Context
Website: {{website-url}}

Business and tracking goals: {{tracking-goals}}

Current setup status and user experience level: {{current-setup}}

Structure the guide to build systematically from basic property creation through advanced monitoring setup, ensuring each platform feeds accurate data to the others. Include best practices that prevent common implementation failures and provide verification steps at each stage.

## Output
Deliver the guide as clearly numbered sections with actionable bullet points. Include verification checkboxes (`[ ]`) at critical milestones so the user can track implementation progress. Tailor the technical depth and explanations to match the experience level described in the context.
```
