# Book Outline Generator for Fiction and Nonfiction

## 簡介

The Book Outline Generator is a free AI prompt that builds comprehensive book outlines covering every structural and creative element writers need to move from concept to manuscript. This book outline prompt for ChatGPT walks you through seven core sections: story foundation (theme, conflict, setting), character development (profiles and arcs for each major character), chapter-by-chapter plot structure (key events, character focus, scene details), world-building elements (culture, geography, history, magic systems), writing style notes (POV, tone, voice, pacing), key story beats (opening hook through resolution), and a project timeline with word-count milestones. Simply provide your book project details - genre, audience, premise - and the prompt returns a structured outline ready to guide your drafting process. It runs on ChatGPT, Claude, Gemini, and Grok, making it accessible across all major text-generation models. Writers tackling novels, memoirs, or narrative nonfiction use this prompt to organize ideas before the first draft, ensuring character arcs align with plot beats and every chapter has a clear purpose. ● Covers story foundation, character arcs, chapter breakdowns, world-building, and writing style in one output ● Includes the seven key story beats (inciting incident, midpoint, climax, resolution) so plot structure stays tight ● Provides a project timeline with word-count targets and phase milestones to keep drafting on track ● Works for fiction (novels, short stories) and narrative nonfiction (memoir, creative nonfiction) ## Prompt

```
## Role
You are an expert book development consultant specializing in creative writing project planning.

## Task
Create a comprehensive, detailed book outline that covers all structural and creative elements needed to guide the writing process from concept to completion.

## Context
Book project details:
{{book-project-details}}

## Output
Deliver a complete book outline using this structure:

📚 **Book Title:** [From project details]
**Genre:** [From project details]
**Target Audience:** [From project details]

### 1. Story Foundation
- **Main Theme:** Core message or idea
- **Central Conflict:** Primary tension driving the narrative
- **Setting Details:** Where and when the story takes place
- **Timeline:** Story duration and key time markers

### 2. Character Development
For each major character:
- **Name:**
- **Role:** Protagonist, antagonist, supporting
- **Brief Description:** Appearance, personality, background
- **Character Arc:** How they change from beginning to end

### 3. Plot Structure
Chapter-by-chapter breakdown:
- **Chapter Title:**
- **Key Events:** What happens
- **Character Focus:** Whose perspective/journey
- **Plot Points:** Story advancement moments
- **Scene Details:** Location, mood, purpose

### 4. World Building Elements
- **Culture:** Social norms, values, customs
- **Geography:** Physical landscape and locations
- **History:** Backstory shaping the present
- **Rules/Magic System:** (if applicable) How extraordinary elements function

### 5. Writing Style Notes
- **POV:** First/third person, single/multiple perspectives
- **Tone:** Overall emotional quality (dark, humorous, inspirational)
- **Voice:** Narrative personality and language style
- **Pacing:** Speed and rhythm of story progression

### 6. Key Story Beats
⭐ **Opening Hook:** Initial grabber that pulls readers in
⭐ **Inciting Incident:** Event that launches the main story
⭐ **Plot Point 1:** Commitment to the journey
⭐ **Midpoint:** Major revelation or reversal
⭐ **Plot Point 2:** Lowest point before final push
⭐ **Climax:** Peak confrontation
⭐ **Resolution:** How conflicts are resolved and new status quo

### 7. Project Timeline
- **Total Estimated Word Count:**
- **Overall Target Completion Date:**
- **Phase Milestones:** Breakdown by outline section (foundation, character development, plot structure, world building, revision) with word count targets and dates
```
