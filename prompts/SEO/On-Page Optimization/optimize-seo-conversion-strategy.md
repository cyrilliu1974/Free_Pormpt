# SEO Conversion Rate Optimization Audit Prompt

## 簡介

The SEO Conversion Rate Optimization Audit Prompt is a free AI prompt that analyzes websites and delivers prioritized action plans to increase conversion rates from organic search visitors. This SEO conversion optimization prompt for ChatGPT evaluates five critical dimensions: site structure and internal linking, on-page optimization elements, keyword targeting aligned to conversion funnel stages, page speed and Core Web Vitals, and mobile responsiveness. It runs on ChatGPT, Claude, and Gemini, producing a detailed audit report with a ranked checklist of 10 specific, actionable recommendations tailored to the analyzed website. Use it when you need to move beyond traffic metrics and focus on turning organic visitors into customers, leads, or subscribers. ● Analyzes navigation hierarchy, internal linking patterns, and crawlability to identify friction points in the user journey ● Evaluates title tags, meta descriptions, header structure, and content quality for search intent alignment ● Assesses keyword mapping to conversion funnel stages and identifies gaps between visitor expectations and page delivery ● Measures page speed, Core Web Vitals, and rendering performance to eliminate technical barriers to conversion ● Balances quick-win optimizations implementable within two weeks with strategic long-term initiatives ## Prompt

```
## Role

You are an SEO strategist specializing in conversion rate optimization for organic search traffic.

## Task

Analyze the website at {{website-url}} and deliver a prioritized action plan to increase its conversion rate from organic search visitors.

## Analysis Framework

Evaluate current SEO performance across five dimensions:

**Site Structure** – navigation hierarchy, internal linking patterns, crawlability

**On-Page Optimization** – title tags, meta descriptions, header tags, content quality and relevance

**Keyword Targeting** – search intent alignment, keyword mapping to conversion funnel stages

**Page Speed** – load performance, Core Web Vitals, rendering bottlenecks

**Mobile Experience** – responsive design, touch targets, viewport configuration

For each dimension, identify specific gaps and opportunities tied to conversion impact, not just rankings.
```
