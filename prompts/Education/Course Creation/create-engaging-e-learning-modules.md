# E-Learning Module Design Blueprint Generator

## 簡介

The E-Learning Module Design Blueprint Generator is a free AI prompt that produces comprehensive instructional design frameworks for online courses and training programs. This e-learning module design prompt for ChatGPT walks you through an eight-stage design process - from needs analysis through deployment and evaluation - covering interactive content (simulations, gamified activities, multimedia), three-tier assessments (pre, formative, and summative), downloadable instructional materials, responsive UX with accessibility features, and effectiveness measures aligned to learning objectives. It runs on ChatGPT, Claude, and Gemini, delivering a structured blueprint ready for development teams or learning management system implementation. Instructional designers, corporate trainers, and curriculum developers use it to standardize module creation, ensure pedagogical soundness, and save hours of planning time. ● Delivers a full design roadmap covering simulations, gamification, multimedia, and real-world scenarios ● Specifies pre-assessment, formative check-ins, and summative evaluations with feedback loops ● Includes responsive design, accessibility compliance, and progress tracking for modern LMS platforms ● Provides an eight-step process from needs analysis through iterative improvement and learner analytics ## Prompt

```
## Role

You are an expert instructional designer specializing in creating engaging, interactive e-learning modules across various topics and skills.

## Task

Design a comprehensive e-learning module for:

{{module-specification}}

Provide a complete design blueprint covering interactive content, assessments, instructional materials, user experience, and effectiveness measures.

## Design Framework

### 1. Introduction
Provide an overview of the module, its relevance, and what learners will gain.

### 2. Interactive Content
- **Simulations and scenarios**: Realistic practice environments
- **Gamified learning activities**: Points, badges, challenges, and leaderboards
- **Multimedia**: Videos, animations, and infographics to reinforce concepts

### 3. Assessments
- **Pre-assessment**: Gauge prior knowledge and set baseline
- **Formative assessments**: Check understanding throughout the module
- **Summative assessment**: Evaluate final learning outcomes

### 4. Instructional Materials
- Clear learning objectives and expected outcomes
- Well-structured content with logical progression
- Explanations, real-world examples, and practical applications
- Downloadable resources (job aids, templates, reference guides)

### 5. User Experience
- Intuitive navigation and clean interface design
- Responsive design for desktop, tablet, and mobile
- Accessibility features (screen reader support, captions, keyboard navigation)
- Progress tracking and bookmarking for learner convenience

### 6. Effectiveness Measures
- Tight alignment with stated learning objectives
- Integration of adult learning principles and varied learning styles
- Opportunities for practice, immediate feedback, and reflection
- Plan for usability testing and iterative improvement based on learner data

### 7. Design Process Roadmap
1. **Needs analysis**: Identify learning gaps and success criteria
2. **Content outline and storyboard**: Map module flow and interactions
3. **Content creation**: Develop text, media, and interactive elements
4. **Assessment development**: Build valid, reliable evaluation tools
5. **Implementation**: Assemble components in learning platform
6. **Quality assurance**: Test functionality, accuracy, and user experience
7. **Deployment**: Launch to target audience with monitoring
8. **Evaluation**: Collect feedback and analytics for continuous improvement

### 8. Conclusion
Summarize the module's design strengths and anticipated learner impact.

## Output

Provide the complete e-learning module design as structured above, ready for development and implementation.
```
