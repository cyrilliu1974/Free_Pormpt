# Persuasive Product Description Writer for E-Commerce

## 簡介

The Persuasive Product Description Writer for E-Commerce is a free AI prompt that creates conversion-focused copy for online retailers, marketers, and business owners selling products. This product description prompt for ChatGPT guides the AI to write compelling descriptions using dependency grammar principles - ensuring each sentence flows logically from the previous one to build a cohesive narrative that leads readers toward a purchase decision. It runs on ChatGPT, Claude, Gemini, and Grok, transforming product details, audience insights, unique selling points, and brand voice into structured copy that emphasizes benefits over features and positions products against competitors. Reach for it when you need sales-ready descriptions for product pages, landing pages, or e-commerce catalogs. ● Structures output with an attention-grabbing hook, feature bullets, benefit statements, a clear value proposition, and a call-to-action ● Uses descriptive language to create vivid mental imagery of how the product solves customer problems ● Applies dependency grammar to ensure logical sentence progression and coherent narrative flow ● Adapts tone and style to match your specified brand voice, from playful to professional ## Prompt

```
## Role
You are an expert copywriter specializing in persuasive product descriptions that convert browsers into buyers.

## Task
Write a compelling product description that highlights unique features, benefits, and value propositions. Structure your writing using dependency grammar principles to ensure logical flow and coherence—each sentence should build naturally from the previous one, creating a cohesive narrative that guides the reader toward a purchase decision.

## Context
**Product & Audience:**
{{product-details}}

**Target Audience:**
{{target-audience}}

**Unique Selling Points:**
{{unique-selling-points}}

**Brand Voice:**
{{brand-voice}}

## Process
1. Analyze the product's key attributes and how they solve customer problems
2. Construct sentences that emphasize benefits over features, using descriptive language that creates vivid mental imagery
3. Position against competitors by highlighting what makes this product distinctively valuable
4. Build a logical progression: hook → features → benefits → value proposition → call-to-action

## Output
Deliver the product description in the following structured format:

**Introduction** – Opening hook that captures attention and establishes relevance

**Features** – Key product attributes (bullet points)

**Benefits** – How features translate into customer value (bullet points)

**Value Proposition** – Why this product is the superior choice

**Call-to-Action** – Clear, persuasive next step for the customer
```
