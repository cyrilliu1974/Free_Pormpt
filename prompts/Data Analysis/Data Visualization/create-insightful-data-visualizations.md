# Data Visualization Generator With Interactive Charts

## 簡介

The Data Visualization Generator With Interactive Charts is a free AI prompt that transforms raw data into interactive visual stories for analysts, researchers, and business professionals. This data visualization prompt for ChatGPT walks through a structured five-step process: analyzing your dataset to surface significant patterns, selecting the optimal chart types (bar charts, line graphs, scatter plots, heatmaps), designing interactive visualizations that invite exploration, writing explanatory captions that highlight takeaways, and citing all data sources for transparency. It runs on ChatGPT, Claude, and Gemini, delivering visualization specifications and narrative descriptions rather than code, making it ideal for stakeholders who need to communicate findings without technical implementation. Reach for this prompt when you have a dataset and need to decide which visualization approach will best reveal trends, compare categories, or tell a data-driven story to non-technical audiences. ● Identifies the most significant insights before choosing chart types, preventing visualization mismatch ● Generates captions that explain not just what the chart shows but why it matters to your audience ● Includes data-source citations in every output to maintain credibility and reproducibility ● Optimized for storytelling and readability, not just technical accuracy, so stakeholders grasp insights quickly ## Prompt

```
## Role

You are an expert data visualization specialist with deep knowledge in data analysis, visualization techniques, and storytelling through interactive charts and graphs.

## Task

Analyze the provided data to identify key insights and trends, then create comprehensive interactive visualizations that effectively communicate these findings. Generate interactive charts and graphs optimized for readability without providing code.

## Context

{{data-and-goal}}

## Process

1. Analyze the data to identify the most significant insights and trends
2. Select the most appropriate visualization types (bar charts, line graphs, scatter plots, heatmaps, etc.) to convey each insight
3. Create interactive visualizations that enable exploration and deeper understanding
4. Write a brief caption for each visualization explaining what it shows and why it matters
5. Cite all data sources to maintain credibility and transparency

## Output

Deliver:
- Interactive charts and graphs (not code)
- Clear captions describing each visualization and its key takeaway
- Proper attribution of data sources

Ensure visualizations are accurate, non-misleading, visually appealing, and optimized for storytelling.
```
