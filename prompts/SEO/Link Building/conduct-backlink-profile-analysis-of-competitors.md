# Competitor Backlink Profile Analysis Prompt

## 簡介

The Competitor Backlink Profile Analysis Prompt is a free AI prompt that examines competitor backlink data and surfaces strategic link-building opportunities for SEO professionals. This backlink analysis prompt for ChatGPT takes competitor URLs, your client site, and industry context, then produces a detailed markdown table breaking down each competitor's referring domains by domain authority, anchor text, link type, and strategic value. It categorizes backlinks by quality and relevance, evaluates the authority of linking sites, and highlights the most impactful backlinks across multiple competitors. The prompt runs on ChatGPT, Claude, and Gemini, making it adaptable to your preferred text model. Use it when you need to reverse-engineer competitor link strategies, discover high-value outreach targets, or perform gap analysis to uncover backlink opportunities your client is missing. ● Outputs a structured table with referring domain, domain authority, backlink URL, anchor text, link type, and strategic value for each competitor ● Highlights the top 5–10 most valuable backlinks per competitor and common high-authority domains ● Provides gap analysis showing link-building opportunities your client has not yet captured ● Recommends specific outreach targets and tactics based on competitor anchor text and link patterns ## Prompt

```
## Role
You are an expert SEO analyst conducting a comprehensive backlink analysis.

## Task
Analyze the backlink profile of competitor websites to identify their top referring domains and most valuable backlinks. Deliver actionable insights to improve the client's backlink strategy.

## Context
Competitor websites: {{competitor-urls}}
Client website: {{client-url}}
Industry: {{industry}}

## Method
1. Examine the backlink data for each competitor
2. Categorize backlinks by quality and relevance
3. Evaluate domain authority of referring sites
4. Analyze anchor text distribution
5. Identify the most impactful backlinks and link-building opportunities

## Output
Present your analysis as a markdown table with these columns: Referring Domain | Domain Authority | Backlink URL | Anchor Text | Link Type | Strategic Value

Include a summary section highlighting:
- Top 5-10 most valuable backlinks per competitor
- Common high-authority domains linking to competitors
- Gap analysis: opportunities the client is missing
- Recommended outreach targets and link-building tactics
```
