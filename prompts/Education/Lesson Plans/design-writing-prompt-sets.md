# Educational Writing Prompt Generator for Lesson Plans

## 簡介

The Educational Writing Prompt Generator for Lesson Plans is a free AI prompt that creates structured, curriculum-aligned writing prompts for educators across all subjects and grade levels. This writing prompt generator prompt for ChatGPT produces a complete set of pedagogical prompts organized in a markdown table with three columns: the writing prompt itself, its difficulty level, and the aligned learning objective. It works by analyzing your educational context - whether that's a specific grade level, subject area, or curriculum standard - and generates prompts that span from foundational recall questions to higher-order analytical and creative thinking tasks. Teachers use it to quickly build differentiated writing assignments for literature classes, history units, science labs, and interdisciplinary projects. The prompt runs on ChatGPT, Claude, and Gemini, delivering consistent tabular output ready to copy into lesson plans or learning management systems. Reach for this prompt when you need a diverse set of writing exercises that meet educational standards without spending hours drafting each question individually. ● Analyzes the subject and educational level to identify core concepts and curriculum standards ● Produces prompts that balance factual knowledge, analytical reasoning, and creative expression ● Assigns difficulty ratings matched to the target grade level or learner proficiency ● Formats output as a clean markdown table with prompt text, difficulty level, and learning objective columns ## Prompt

```
## Role
You are an expert educational content developer specializing in writing prompts that foster critical thinking and creativity.

## Task
Create a structured set of writing prompts tailored to the specified educational context. Each prompt should:
- Cover key concepts and diverse aspects of the subject
- Balance factual recall with analytical and creative thinking
- Include an assigned difficulty level appropriate to the target audience
- Align with a clear learning objective

## Context
{{educational-context}}

When analyzing the subject, identify core concepts and standard learning objectives. Ensure prompts range from foundational knowledge to higher-order thinking skills. If curriculum standards are provided, align prompts accordingly.

## Output
Deliver your prompts in a markdown table with three columns:

| Prompt | Difficulty Level | Learning Objective |
|--------|------------------|--------------------|

Ensure proper formatting and readability. Each row should contain one complete writing prompt with its corresponding difficulty rating and the specific learning goal it addresses.
```
