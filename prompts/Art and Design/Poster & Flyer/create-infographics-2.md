# Infographic Design Guide Generator for ChatGPT

## 簡介

The Infographic Design Guide Generator is a free AI prompt that produces comprehensive, step-by-step design instructions for creating digital marketing infographics tailored to your specific topic, target audience, key messages, and brand colors. This infographic design prompt for ChatGPT walks you through six critical design areas: content selection and organization, layout and visual hierarchy, visual elements and iconography, typography and color application, data visualization strategies, and digital optimization for social sharing. Instead of creating the infographic itself, it generates an expert implementation guide you can hand to a designer or follow yourself - specifying which chart types to use, how to structure narrative flow, where to position key messages, font pairings that match your audience, and export settings for digital platforms. Graphic designers, marketing teams, content creators, and brand managers reach for this prompt when they need a structured design plan rather than starting from a blank canvas. ● Analyzes your topic and audience to recommend the most relevant data points, narrative structure, and visual hierarchy ● Suggests specific icon styles, chart types, and graphic elements that reinforce each key message ● Provides font pairing and brand color application strategies optimized for readability and visual impact ● Delivers digital-first guidance on dimensions, export formats, and file-size optimization for social media and web use ## Prompt

```
## Role
You are an expert graphic designer specializing in digital marketing infographics.

## Task
Create a detailed, step-by-step guide for designing a visually appealing and informative infographic that effectively communicates key messages to the target audience.

## Context
Topic: {{topic}}
Target audience: {{target-audience}}
Key messages: {{key-messages}}
Brand colors: {{brand-colors}}

## Process
Analyze the topic and audience, then provide guidance on:

1. **Content Selection & Organization**
   - Which information is most relevant for this audience
   - How to structure a logical narrative flow
   - Where to position key messages for maximum impact

2. **Layout & Visual Hierarchy**
   - Recommended layout structure (sections, grids, flow direction)
   - How to guide the viewer's eye through the infographic
   - Spacing and grouping strategies for readability

3. **Visual Elements**
   - Specific graphics, icons, and chart types that support each message
   - How visual elements reinforce the narrative
   - Balance between text and imagery

4. **Typography & Color**
   - Font pairing recommendations that fit the topic and audience
   - How to apply the brand colors effectively
   - Text sizing hierarchy for scanability

5. **Data Visualization**
   - Relevant statistics to include and how to display them
   - Chart and graph styles that enhance credibility

6. **Digital Optimization**
   - Dimensions and format for digital viewing and social sharing
   - Export settings for quality and file size

## Output
Provide a step-by-step implementation guide using bullet points for clarity. Include specific, actionable suggestions for each element of the infographic design.
```
