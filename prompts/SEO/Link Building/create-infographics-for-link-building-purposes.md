# Infographic Content Plan for Link Building

## 簡介

The Infographic Content Plan for Link Building is a free AI prompt that creates detailed infographic blueprints optimized to earn backlinks from high-authority sites in any industry. This infographic prompt for ChatGPT guides you through organizing key statistics into a logical narrative flow, specifying visual hierarchy, and defining design elements that appeal to publishers and decision-makers. It runs on ChatGPT, Claude, and Gemini, producing a complete content plan that includes thematic sections, chart-type recommendations, color palettes aligned with industry conventions, typography hierarchy, and technical specifications for web embedding. Real use cases include B2B content marketers building SEO campaigns, agencies pitching data-driven assets to clients, and publishers creating shareable research visualizations that attract organic backlinks. Reach for this prompt when you need a strategic blueprint that transforms raw statistics into link-worthy visual content tailored to your niche and audience. ● Organizes raw statistics into 3-4 thematic sections with headlines, core data points, and supporting context ● Specifies visual treatments including chart types, icon suggestions, and emphasis strategies for each data point ● Provides industry-appropriate design specifications: color palettes, typography hierarchy, aspect ratios, and file formats optimized for embedding ● Includes share metadata with suggested title tags and alt text to maximize discoverability and link attribution ## Prompt

```
## Role
You are an expert content strategist and visual designer specializing in data-driven infographics for SEO link building.

## Task
Create a detailed infographic content plan optimized to attract backlinks from authoritative websites. Organize statistics into a logical narrative flow, specify visual hierarchy, recommend design elements, and ensure the output is optimized for web sharing and embedding.

## Context
Industry niche: {{industry-niche}}
Target audience: {{target-audience}}
Key data points: {{key-statistics}}

The infographic should appeal to decision-makers and influencers in {{industry-niche}} who publish on authoritative sites. Use professional design language suited to the niche, ensure data accuracy and source credibility, and structure information to maximize shareability and embed potential.

## Output
Provide the infographic plan structured as:

### Introduction
- Hook statement that frames the topic's relevance
- Context for why this data matters now

### Key Statistics (Main Body)
- Organize {{key-statistics}} into 3-4 thematic sections
- For each section: headline, core data point, supporting context
- Specify visual treatment (chart type, icon suggestions, emphasis)

### Conclusion
- Takeaway or call-to-insight
- Suggested attribution/source line

### Design Specifications
- Recommended color palette aligned with {{industry-niche}} conventions
- Typography hierarchy
- Dimensions and format optimized for embedding (suggest aspect ratio, file type)
- Share metadata (suggested title tag, alt text)
```
