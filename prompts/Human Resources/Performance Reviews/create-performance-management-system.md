# Performance Management System Builder Prompt

## 簡介

The Performance Management System Builder Prompt is a free AI prompt that creates end-to-end performance management frameworks tailored to an organization's industry, size, culture, and maturity level. This performance management prompt for ChatGPT, Claude, and Gemini produces a structured system addressing the full employee lifecycle: objective-setting cadences aligned with company goals, performance tracking metrics and tools, employee development plans with skill gap analysis, multi-source evaluation criteria including 360-degree feedback, and rewards structures linking compensation to outcomes. You provide your organization profile, and the prompt delivers practical implementation strategies including manager training, pilot testing approaches, and communication plans. It identifies challenges specific to your context and offers actionable solutions for each component. Use this prompt when designing a new performance management system, overhauling an outdated process, or adapting frameworks to organizational change. HR leaders, people operations teams, and consultants rely on it to build systems that match their unique requirements rather than generic templates. ● Covers six integrated components from goal-setting through rewards and recognition programs ● Produces evaluation frameworks with rating scales, calibration processes, and self-assessment structures ● Includes development planning with career pathing, mentoring programs, and training needs assessment ● Delivers implementation plans with communication strategies, pilot testing, and risk mitigation ● Identifies organization-specific challenges and provides practical solutions for each system element ● Summarizes best practices, critical success factors, and key risks with mitigation strategies ## Prompt

```
## Role
You are an experienced HR consultant specializing in designing effective performance management systems.

## Task
Create a comprehensive performance management system tailored to the organization described below. Address the complete employee lifecycle from objective-setting through rewards, including practical implementation strategies.

## Context
Organization profile:
{{organization-profile}}

(Include industry, size, culture, current performance management maturity, and any specific challenges or constraints)

## Output
Deliver a structured performance management system covering:

### 1. Objective Setting
- Objective-setting process and cadence
- Alignment with company goals
- Objective types (individual, team, department)
- Timeframes and review frequency

### 2. Performance Tracking
- Key performance metrics
- Data collection methods
- Progress monitoring tools
- Feedback mechanisms
- Performance review meeting structure

### 3. Employee Development
- Training needs assessment approach
- Individual development plans
- Career path mapping
- Mentoring and coaching programs
- Skill gap analysis methodology

### 4. Performance Evaluation
- Evaluation criteria
- Rating scales and frameworks
- Self-evaluation process
- 360-degree feedback integration
- Calibration meetings

### 5. Rewards and Recognition
- Compensation linkage
- Bonus structure
- Non-monetary rewards
- Recognition programs
- Promotion criteria

### 6. Implementation Plan
- Communication strategy
- Training for managers and employees
- Pilot testing approach
- System refinement process
- Ongoing monitoring and improvement

For each component, identify potential challenges specific to this organization and provide actionable solutions.

Conclude with a summary of:
- Top 5 best practices for this system
- Critical success factors
- Key implementation risks and mitigation strategies

Format using clear headings, bullet points, and numbered lists for readability.
```
