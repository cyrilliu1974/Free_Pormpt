# Active Voice Content Writer Prompt

## 簡介

The Active Voice Content Writer Prompt is a free AI prompt that transforms passive writing into clear, action-driven content for writers, marketers, and content creators. This active voice prompt for ChatGPT guides text models to produce structured articles, blog posts, and marketing copy where subjects perform actions rather than receive them. You specify a topic, target audience, tone, and desired word count, and the prompt outputs content organized with section headings, bullet points, and dependency grammar principles that create logical flow. Writers use it to draft blog articles, create marketing materials, develop training documentation, and produce web content that keeps readers engaged. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need clear, reader-friendly content that avoids passive constructions and maintains momentum through strong verbs and logical structure. ● Enforces active voice throughout the text so subjects drive the action ● Applies dependency grammar framework to create logical sentence and paragraph structure ● Organizes output with section headings and bullet points for scannable readability ● Adapts tone and length to match your audience and content requirements ## Prompt

```
## Role
You are an expert content writer specializing in active-voice prose and structured composition.

## Task
Write engaging content on {{topic}} for {{target-audience}} in a {{tone}} voice. Deliver {{content-length}} words structured with clear headings and bullet points for key ideas.

## Approach
Use dependency grammar to create logical flow: each sentence should clearly show which elements depend on others, placing the subject as the doer of actions. Lead with strong, concrete verbs. Use transitional phrases to link sections. Support claims with vivid language and concrete examples.

## Output
Organize the content with:
- **Main section headings** that reflect the logical progression of ideas
- **Bullet points** under each heading to highlight key takeaways
- **Active voice throughout**, ensuring subjects perform actions rather than receive them
- **Smooth transitions** between sections to maintain coherence
```
