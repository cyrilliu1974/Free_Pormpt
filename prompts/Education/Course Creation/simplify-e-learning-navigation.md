# E-Learning Platform UX Redesign Prompt

## 簡介

The E-Learning Platform UX Redesign Prompt is a free AI prompt that creates structured navigation and user experience improvement plans for educational technology platforms. This e-learning platform UX redesign prompt for ChatGPT analyzes your current platform structure, identifies friction points in the student journey, and delivers prioritized recommendations across navigation architecture, course layout, interactive elements, and user guidance systems. You provide platform context and a target completion rate goal, and the prompt returns a detailed redesign plan with specific pain points, proposed solutions, and expected impact metrics ranked by implementation effort versus return. It works equally well on Claude, Gemini, and Grok for course designers, LMS administrators, and EdTech product teams tackling low engagement or high dropout rates. ● Analyzes navigation architecture and proposes simplified menu structures with clear information hierarchy ● Identifies course layout improvements that support progressive learning and reduce cognitive load ● Recommends interactive engagement features and onboarding systems that sustain student motivation ● Prioritizes every recommendation by implementation effort versus expected impact on completion rates ## Prompt

```
## Role
You are an expert UX designer specializing in educational platforms.

## Task
Streamline the navigation and user experience of an online learning platform to improve student engagement and course completion rates. Deliver a step-by-step redesign plan that addresses pain points and implements intuitive, user-centered solutions.

## Context
**Platform details:**
{{platform-context}}

**Target completion rate:**
{{completion-rate-goal}}

## Process
Analyze the current platform structure, identify friction points in the user journey, and propose solutions across these areas:

1. **Navigation architecture** – simplified menu structure with clear information hierarchy
2. **Course layout** – content organization that supports progressive learning
3. **Interactive elements** – engagement features that sustain motivation
4. **User guidance** – onboarding and in-context help systems

## Output
Deliver your recommendations as a numbered list with lettered sub-points (a, b, c) for detailed steps. For each recommendation, explain:

- The specific pain point addressed
- The proposed solution
- Expected impact on engagement or completion rates

Prioritize changes by implementation effort versus expected return.
```
