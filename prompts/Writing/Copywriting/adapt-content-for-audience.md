# Adapt Content for Target Audience Prompt

## 簡介

The Adapt Content for Target Audience Prompt is a free AI prompt that transforms existing material to match the needs, preferences, and comprehension level of any specified audience. This content adaptation prompt for ChatGPT uses dependency grammar principles to restructure sentences around core word relationships, ensuring clarity and coherence while adjusting vocabulary, tone, and complexity. Writers, marketers, educators, and corporate communicators use it to convert technical documentation into layman's terms, tailor marketing copy for different demographics, or rewrite training materials for varying skill levels. The prompt runs on ChatGPT, Claude, Gemini, and Grok, requiring three inputs: your original content, the target audience description, and any specific adaptation requirements such as reading level or format constraints. Reach for this prompt whenever you need to repurpose a single piece of content for multiple audience segments without losing the core message. ● Identifies core messages and applies dependency grammar to restructure sentences for maximum clarity ● Adjusts vocabulary, tone, and complexity to match the audience's comprehension level and interests ● Adds relevant examples, analogies, and explanations that resonate with the specific demographic ● Delivers structured output with clear section headings that maintain the original message's integrity ## Prompt

```
## Role
You are an expert content adaptor who rewrites material for specific audiences.

## Task
Transform the provided content to suit the target audience's needs, preferences, and comprehension level. Structure your rewrite using dependency grammar principles—building sentences around core relationships between words to maximize clarity and coherence.

## Context
**Original content:** {{original-content}}

**Target audience:** {{target-audience}}

**Adaptation requirements:** {{adaptation-requirements}}

## Process
1. Identify the core messages and structural elements in the original content
2. Apply dependency grammar to restructure sentences around key word relationships
3. Adjust vocabulary, tone, and complexity to match the audience
4. Add relevant examples, analogies, or explanations that resonate with this audience
5. Review for clarity and alignment with the intended purpose

## Output
Provide the adapted content in a structured format with clear section headings. Ensure the rewrite effectively communicates the original message while meeting the audience's specific requirements.
```
