# Course Learning Objectives Generator

## 簡介

The Course Learning Objectives Generator is a free AI prompt that creates clear, measurable learning objectives for educators and curriculum developers building any type of course. This learning objectives prompt for ChatGPT produces a hierarchical list of SMART objectives - Specific, Measurable, Achievable, Relevant, and Time-bound - that progress logically from foundational concepts to advanced mastery. It works by applying Bloom's Taxonomy to ensure varied cognitive levels, incorporating both lower-order skills (remembering, understanding) and higher-order skills (applying, analyzing, evaluating, creating). Each main objective is accompanied by related sub-objectives, balancing knowledge-based and skill-based outcomes. Educators use it when designing online courses, in-person training programs, hybrid learning experiences, or any curriculum that requires structured, coherent learning outcomes. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt whenever you need to translate course content into actionable learner expectations that align with your target audience's needs and your course's specific context. ● Structures objectives hierarchically with logical dependencies, moving from foundational knowledge to advanced application ● Incorporates Bloom's Taxonomy across all cognitive levels to ensure diverse intellectual challenge ● Balances declarative knowledge objectives with procedural skill-based objectives for comprehensive curriculum coverage ● Uses precise action verbs to describe observable, measurable learner behaviors and outcomes ## Prompt

```
## Role
You are an expert curriculum developer specializing in learning objective design.

## Task
Create clear, measurable learning objectives structured from foundational to advanced concepts. Ensure all objectives are SMART (Specific, Measurable, Achievable, Relevant, Time-bound) and incorporate varied cognitive levels from Bloom's Taxonomy—including both lower-order skills (remembering, understanding) and higher-order skills (applying, analyzing, evaluating, creating). Balance knowledge-based and skill-based objectives. Use precise action verbs that describe expected learner behaviors.

## Context
**Course:** {{course-name}}
**Target audience:** {{target-audience}}
**Course details:** {{course-details}}

Align all objectives with the course content and audience needs. Structure objectives hierarchically with logical progression and coherence.

## Output
Provide a numbered list where each main learning objective is followed by related sub-objectives in bullet points.
```
