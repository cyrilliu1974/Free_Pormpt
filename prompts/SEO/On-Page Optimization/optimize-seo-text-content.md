# SEO Content Rewriter and Keyword Optimizer

## 簡介

The SEO Content Rewriter and Keyword Optimizer is a free AI prompt that rewrites existing text to improve search engine visibility while preserving the original message and maintaining natural readability for human audiences. This SEO optimization prompt for ChatGPT guides the AI to strategically place your target keyword in titles, meta descriptions, subheadings, and body text at an optimal 1-2% density. It restructures content with proper heading hierarchy, suggests internal and external link opportunities, incorporates semantic variations to avoid keyword stuffing, and outputs a complete package including optimized title, meta description (155-160 characters), rewritten body text, and a call to action. The prompt runs on ChatGPT, Claude, Gemini, and Grok, making it versatile for teams using different text-generation models. This prompt is ideal for content marketers, SEO specialists, and website owners who need to refresh existing blog posts, landing pages, or articles to rank better without starting from scratch. ● Generates a complete SEO content package including optimized title, meta description, rewritten body, and call to action in one run ● Maintains 1-2% keyword density while using synonyms and related terms to avoid over-optimization penalties ● Identifies specific opportunities for internal links to related pages and external links to authoritative sources ● Preserves the original message and tone while improving structure, readability, and search engine signals ## Prompt

```
## Role
You are an SEO specialist optimizing content for search visibility.

## Task
Rewrite the provided text to be SEO-optimized for the target keyword while preserving the original message and maintaining natural readability.

## Context
Effective SEO optimization requires strategic keyword placement without sacrificing content quality. The keyword should appear in the title, at least one subheading, and throughout the body at a density of 1-2%. Use synonyms and related terms to avoid keyword stuffing. The content must remain engaging and informative for human readers while signaling relevance to search engines.

## Process
1. **Title optimization**: Craft a compelling title that naturally incorporates {{keyword}}
2. **Meta description**: Write a 155-160 character summary including {{keyword}} that entices clicks
3. **Subheading integration**: Include {{keyword}} in at least one subheading where it flows naturally
4. **Body placement**: Distribute {{keyword}} throughout the text at 1-2% density, maintaining natural flow
5. **Semantic enrichment**: Use synonyms and related phrases to support the primary keyword
6. **Link opportunities**: Identify places for internal links (to related site pages) and external links (to authoritative sources)
7. **Readability**: Break up dense paragraphs, use bullet points where helpful, maintain conversational tone
8. **Call to action**: End with a clear CTA that drives engagement

## Input
{{text-to-optimize}}

{{keyword}}

## Output
Provide:
- **Optimized Title**: [new title with keyword]
- **Meta Description**: [155-160 characters with keyword]
- **SEO-Optimized Body**: [rewritten text with natural keyword integration, improved structure, and internal/external link suggestions]
- **Call to Action**: [compelling CTA]

Ensure the content reads naturally, preserves the original meaning, and is optimized for both search engines and human readers.
```
