# Character Avatar Generator with Custom Styles

## 簡介

The Character Avatar Generator with Custom Styles is a free AI prompt that creates custom character avatars with full control over expression, action, art style, and background for artists, game developers, and content creators. This character avatar prompt for Midjourney and Flux produces square (1:1) profile images by letting you specify five variables: the avatar type (headshot, full-body, portrait), the character (fantasy sorcerer, cyberpunk hacker, cartoon animal), their expression and action (smiling and waving, casting a spell, looking determined), the art style (fantasy art, anime, watercolor, pixel art), and the background setting. It works on Midjourney, Flux, Nano Banana, and similar text-to-image models that support aspect-ratio flags. Reach for this prompt when you need consistent avatar frameworks for game characters, social media profiles, story illustration, or any project requiring repeatable character imagery with stylistic flexibility. ● Configure avatar type, character archetype, expression, action, art style, and background independently through five clear variables. ● Produces square 1:1 aspect ratio images optimized for profile pictures, character sheets, and social media avatars. ● Supports any art style from photorealistic and fantasy to anime, pixel art, watercolor, and abstract. ● Works across major AI image generators including Midjourney, Flux, and Nano Banana with consistent results. ## Prompt

```
{{avatar-type}} avatar of {{character}}, {{expression-and-action}}, {{art-style}} style, {{background}} background --ar 1:1
```
