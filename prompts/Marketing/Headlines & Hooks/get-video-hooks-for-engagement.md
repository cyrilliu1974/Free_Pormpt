# Video Hook Script Generator for Short-Form Content

## 簡介

The Video Hook Script Generator for Short-Form Content is a free AI prompt that builds structured hook script outlines designed to capture attention in the first 3 seconds and maximize viewer retention. This video hook prompt for ChatGPT helps creators develop scroll-stopping openings, sequence 3-5 key content beats, and recommend visual elements that amplify engagement. It runs on ChatGPT, Claude, Gemini, and Grok. You provide a video brief (topic, audience, length, call-to-action) and brand voice; the prompt returns a hook, key points, visual suggestions, and a catchy opening line under 10 words. Real use cases include TikTok scripts, Instagram Reels, YouTube Shorts, and product demos where the first three seconds determine watch-through rate. Reach for this prompt when you need a repeatable framework that aligns your hook with your core message and audience pain points, not generic template copy. ● Produces a 1-2 sentence hook that directly addresses audience curiosity or pain points. ● Sequences 3-5 key content beats optimized for watch-through and value delivery. ● Suggests motion, text overlays, transitions, and B-roll that stop the scroll. ● Outputs a sub-10-word verbal opening line engineered for immediate impact. ## Prompt

```
## Role
You are an expert video content creator specializing in short-form video scripts that maximize viewer retention and engagement.

## Task
Create a compelling hook script outline that captures attention within the first 3 seconds and drives viewers to watch the complete video.

## Context
**Video details:** {{video-brief}}
(Include: topic, target audience, desired length, and primary call-to-action)

**Brand voice:** {{brand-voice}}
(e.g., professional, playful, authoritative, conversational)

## Output
Deliver a structured script outline with these sections:

**Hook**
A 1-2 sentence attention-grabbing opening that directly addresses the audience's pain point or curiosity and aligns with the video's core message.

**Key Points (3-5)**
Bulleted list of the main content beats that build on the hook and deliver value, sequenced for maximum retention.

**Visuals**
Suggested visual elements, text overlays, transitions, or B-roll that amplify engagement (motion, color, contrast, dynamic cuts).

**Opening Line**
A single catchy verbal opening (under 10 words) designed to stop the scroll immediately.
```
