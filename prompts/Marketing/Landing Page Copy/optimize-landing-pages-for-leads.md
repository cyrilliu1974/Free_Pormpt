# Landing Page A/B Testing Optimization Prompt

## 簡介

The Landing Page A/B Testing Optimization Prompt is a free AI prompt that creates comprehensive conversion optimization strategies for digital marketers and growth professionals. This landing page optimization prompt for ChatGPT guides you through analyzing your current page, designing controlled experiments for high-impact elements like headlines and CTAs, calculating sample sizes, and interpreting test results with statistical rigor. It works on ChatGPT, Claude, Gemini, and Grok, delivering a structured report that covers everything from friction point identification to projected ROI calculations. Use it when you need to systematically improve conversion rates through evidence-based testing rather than guesswork. ● Produces a six-section optimization report including current page analysis, test design with control and variation specifications, and statistical validity frameworks ● Covers high-impact elements systematically: headlines, calls-to-action, form fields, value propositions, social proof placement, and visual hierarchy ● Includes implementation details like traffic allocation strategy, minimum sample size calculations, and 95% confidence thresholds ● Delivers prioritized recommendations with projected conversion lift and quick-win opportunities for immediate deployment ## Prompt

```
## Role
You are an expert digital marketing strategist specializing in landing page optimization and conversion rate improvement through A/B testing.

## Task
Conduct a complete A/B testing strategy and deliver a comprehensive optimization plan for a landing page. Analyze the current page, design test variations, outline implementation methodology, specify success metrics, and provide data-driven recommendations.

## Context
**Business and Audience:**
{{business-context}}
(Include: type of business, target audience, main product/service, unique selling proposition, and current conversion rate baseline)

**Testing Focus:**
Prioritize high-impact elements: headlines, calls-to-action, form fields, value propositions, social proof placement, and visual hierarchy.

## Output
Deliver a structured optimization report with the following sections:

### 1. Current Landing Page Analysis
- Key elements inventory (headline, hero section, CTAs, forms, trust signals)
- Conversion funnel assessment
- Identified friction points and optimization opportunities

### 2. A/B Test Design
For each test:
- **Element being tested** (e.g., headline, CTA button, form length)
- **Control version** (current state)
- **Variation(s)** (2-3 alternatives with rationale)
- **Hypothesis** (expected outcome and reasoning)
- **Success metrics** (primary: conversion rate; secondary: time on page, scroll depth, form starts)

### 3. Implementation Plan
- Recommended testing tools and setup requirements
- Traffic allocation strategy (typically 50/50 split)
- Minimum sample size and test duration calculations
- Statistical significance threshold (95% confidence level standard)

### 4. Data Collection Framework
- Key performance indicators to track
- Segmentation approach (device type, traffic source, new vs. returning)
- Quality assurance checklist

### 5. Analysis & Recommendations
- Winning variations and performance lift
- Statistical validity confirmation
- Prioritized implementation roadmap
- Projected conversion rate improvement
- Next iteration suggestions

### 6. Executive Summary
- Current state vs. optimized state comparison
- Expected ROI from implementing recommendations
- Quick-win opportunities for immediate deployment

Format all findings with clear headings, bullet points, and data tables where appropriate for maximum clarity and actionability.
```
