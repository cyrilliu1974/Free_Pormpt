# Getting Things Done (GTD) Implementation Plan Prompt

## 簡介

The Getting Things Done (GTD) Implementation Plan Prompt is a free AI prompt that creates personalized productivity systems based on David Allen's GTD methodology for individuals looking to organize any area of their life or work. This GTD prompt for ChatGPT walks you through building a complete five-phase system tailored to your specific context, tools, and challenges. It runs on ChatGPT, Claude, Gemini, and Grok, producing structured implementation plans that cover Capture (how to collect inputs), Clarify (processing criteria), Organize (category structures), Reflect (review schedules), and Engage (prioritization tactics). Whether you're managing a startup, organizing graduate school coursework, or streamlining household responsibilities, the prompt adapts GTD principles to your reality. Reach for this prompt when you need more than generic productivity advice - when you want a custom roadmap that accounts for your actual tools, time constraints, and workflow challenges. ● Structures output across all five GTD phases with clear dependency relationships between components ● Adapts recommendations based on your stated tools, time availability, and current productivity challenges ● Provides decision criteria for processing inputs and concrete examples for each phase ● Includes review cadences, prioritization approaches, and maintenance routines specific to your context ## Prompt

```
## Role
You are a productivity expert specializing in the Getting Things Done (GTD) methodology.

## Task
Create a comprehensive, actionable implementation plan that applies GTD principles to the user's specific context. Structure your explanation using clear dependency relationships: show how each GTD component builds on or supports the others.

## Context
{{context}}

Include:
- The specific area of life or work being organized
- Current productivity level and main challenges
- Available tools (apps, notebooks, systems)
- Realistic time commitment for setup and maintenance

## Output
Deliver your implementation plan as a structured bullet-point list organized by GTD phase:

- **Capture** – how and where to collect all inputs
- **Clarify** – decision criteria for processing items
- **Organize** – category structure and tool setup
- **Reflect** – review cadence and checklists
- **Engage** – prioritization approach and execution tactics

Use sub-bullets for detailed steps, examples, and context-specific adaptations. Ensure each phase clearly connects to the user's stated challenges and available resources.
```
