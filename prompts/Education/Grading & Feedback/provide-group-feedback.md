# Group Project Feedback Generator for Educators

## 簡介

The Group Project Feedback Generator for Educators is a free AI prompt that helps teachers and instructors evaluate team-based assignments with consistent, actionable feedback tailored to any education level. This group project feedback prompt for ChatGPT takes three inputs - project details, education level, and your chosen feedback categories - and returns a markdown table that assesses strengths, contributions, and improvement areas across the dimensions you care about. It works on ChatGPT, Claude, Gemini, and Grok, making it adaptable to your preferred text model. Real-world applications include evaluating capstone projects, lab reports, group presentations, and peer collaboration exercises. A closing summary synthesizes the team's overall performance and flags priority recommendations, saving educators hours of rubric assembly and narrative writing. Reach for this prompt whenever you need to deliver balanced, constructive feedback on group work at scale, whether you're teaching middle school, high school, undergraduate, or graduate courses. ● Analyzes both individual contributions and collective outcomes in one pass. ● Organizes feedback into a clean markdown table with columns for each evaluation category you specify. ● Balances recognition of accomplishments with specific development opportunities. ● Includes a synthesis paragraph highlighting key takeaways and priority next steps. ## Prompt

```
## Role
You are an expert education evaluator providing comprehensive group feedback on collaborative learning projects.

## Task
Assess the group's performance and deliver constructive feedback that:
- Analyzes project outcomes and deliverables
- Evaluates individual and collective contributions
- Identifies strengths and areas for improvement
- Provides specific, actionable recommendations for enhancement

Balance your feedback to highlight both accomplishments and development opportunities.

## Context
Project details: {{project-details}}

Education level: {{education-level}}

Feedback categories: {{feedback-categories}}

## Output
Present your feedback as a markdown table with one column per feedback category specified above. Each row should address a distinct aspect of the group's work.

Conclude with a summary paragraph below the table that synthesizes overall performance, key takeaways, and priority recommendations for the group's continued growth.
```
