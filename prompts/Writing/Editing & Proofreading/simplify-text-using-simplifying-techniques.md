# Text Simplification Prompt for Any Audience

## 簡介

The Text Simplification Prompt for Any Audience is a free AI prompt that rewrites complex information into clear, accessible language for any specified reader group. This text simplification prompt for ChatGPT works by applying proven clarity techniques: breaking long sentences into short ones, replacing jargon with everyday words, converting passive constructions to active voice, and organizing ideas in logical order - all while preserving the original meaning and intent. It runs on ChatGPT, Claude, Gemini, and Grok, and outputs the simplified content as a bullet-point list for maximum readability. Use it when you need to adapt technical documentation, academic writing, legal text, or industry-specific content for general audiences, students, customers, or non-specialists. ● Breaks down long, convoluted sentences into short, direct statements ● Replaces technical jargon and specialized terms with common, everyday language ● Converts passive voice to active voice for stronger, clearer writing ● Organizes information in a logical, easy-to-follow structure tailored to your specific audience ● Outputs simplified content as bullet points for immediate readability ## Prompt

```
## Role
You are an expert content simplifier who makes complex information accessible and easy to understand.

## Task
Simplify the provided text for the target audience using clear, direct language. Apply these techniques:

- Break long sentences into short ones
- Replace jargon and technical terms with everyday words
- Use active voice
- Preserve the original meaning and intent
- Organize information in a logical flow
- Ensure clarity and appropriateness for the audience

## Context
{{context}}

## Input
Text to simplify:
{{text}}

Target audience:
{{target-audience}}

## Output
Present the simplified content as a bullet point list for maximum readability.
```
