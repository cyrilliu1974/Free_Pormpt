# Game UI Design Screenshot Generator

## 簡介

The Game UI Design Screenshot Generator is a free AI prompt that produces cinematic third-person adventure game interface mockups for designers and developers. This game UI prompt for Midjourney creates 16:9 screenshots featuring custom scenes with complete HUD overlays - stamina bars, compass navigation, and item wheels - rendered in a cinematic adventure game aesthetic. You describe any scene, and the prompt returns a polished UI design visualization in raw mode for maximum detail and flexibility. Whether you're prototyping a fantasy RPG, pitching an action-adventure concept, or building a portfolio piece, this tool generates production-ready interface mockups that communicate gameplay systems and visual direction in a single image. Reach for this prompt when you need to visualize game interfaces quickly without opening design software, or when communicating UI concepts to teams and stakeholders. ● Produces 16:9 cinematic screenshots with fully integrated HUD elements including stamina bars, compass, and item wheels ● Supports any custom scene description - jungle temples, sci-fi stations, medieval castles, or modern urban environments ● Outputs in raw mode for maximum control over lighting, composition, and post-processing ● Ideal for game designers, UX portfolios, pitch decks, and rapid prototyping of adventure game interfaces ## Prompt

```
Screenshot of game UI design, {{scene-description}}, cinematic third-person adventure mood. HUD overlay shows stamina bar, compass, and item wheel. --ar 16:9 --raw
```
