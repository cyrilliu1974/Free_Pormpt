# Character Education Plan Builder for Homeschooling

## 簡介

The Character Education Plan Builder for Homeschooling is a free AI prompt that creates actionable virtue-based curricula for homeschooling families teaching ethics and character development. This character education prompt for ChatGPT builds a complete plan around four core virtues chosen to match your family's values and your children's age range. For each virtue, it generates a focused lesson, an age-appropriate moral dilemma for discussion, and a hands-on activity that makes the concept concrete. The prompt also recommends three feasible community service projects and outputs a progress-tracking table to help parents monitor growth over time. It runs on ChatGPT, Claude, and Gemini, turning a single family-context variable into a ready-to-use weekly or monthly curriculum. Homeschooling parents use it to move beyond abstract character talk and build daily routines that teach honesty, empathy, responsibility, and other virtues through real scenarios and meaningful action. This prompt is for homeschooling families who want a structured, values-aligned approach to character education without spending hours researching lesson ideas or designing discussion prompts from scratch. ● Selects four virtues aligned with your stated family values and generates a lesson, discussion scenario, and activity for each. ● Provides age-appropriate moral dilemmas that spark meaningful conversation without requiring separate research. ● Suggests three community service projects that homeschooling families can realistically complete together. ● Outputs a progress-tracking table so parents can document character growth and revisit concepts as children mature. ## Prompt

```
## Role
You are an experienced educator specializing in character development and ethics education for homeschooling families.

## Task
Design a comprehensive character education plan that integrates virtue-based lessons, moral dilemma discussions, and community service projects into daily homeschooling routines. Structure the plan to be immediately actionable and easy to follow.

## Context
**Family Profile:**
{{family-context}}
(Include: target age range, homeschooling approach, and core family values you want to emphasize)

**Focus:**
- Provide specific, actionable lessons and activities for each virtue
- Ensure discussions are thought-provoking and age-appropriate
- Make community service projects meaningful and feasible for homeschooling families
- Emphasize practical application over theory

## Output
Provide a structured plan with:

**Four Core Virtues** (choose virtues that align with the family's values)

For each virtue, include:
1. **Lesson:** Brief description of the core teaching
2. **Discussion:** A moral dilemma or thought-provoking scenario
3. **Activity:** Hands-on project or exercise

**Community Service Projects**

List 3 meaningful, feasible projects with brief descriptions

**Character Trait Development Table**

Create a table with these columns:
- Virtue
- Definition
- Lesson Summary
- Discussion Topic
- Activity
- Progress Tracking Method

Format each virtue section clearly with numbered items and use a markdown table for the tracking component.
```
