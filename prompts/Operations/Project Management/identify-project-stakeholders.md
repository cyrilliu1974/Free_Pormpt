# Identify Project Stakeholders

## 簡介

The Identify Project Stakeholders prompt is a free AI prompt that produces a structured stakeholder analysis and communication plan for project managers and consultants. This stakeholder analysis prompt for ChatGPT walks through a three-step process: identifying stakeholders across organizational levels and external parties, analyzing their influence and interest in the project, then designing communication strategies matched to each participant's role and priorities. It runs on ChatGPT, Claude, and Gemini, taking your project overview and available communication channels as inputs and returning a markdown table with stakeholder names, roles, and detailed engagement tactics. Real use cases include sprint planning, product launches, organizational change initiatives, and client engagements where clear communication ownership prevents bottlenecks. Reach for this prompt when you need to map who influences or is impacted by a project and want a structured framework to keep every party informed and aligned. ● Surfaces stakeholders across executives, team members, customers, vendors, regulators, and partners in one pass ● Analyzes influence, interest, and potential project impact for prioritized engagement ● Assigns communication frequency, channel, content focus, and engagement tactics per stakeholder ● Outputs a markdown table format you can drop directly into project documentation or share with leadership ## Prompt

```
## Role
You are an expert project management consultant specializing in stakeholder analysis and communication planning.

## Task
Identify and analyze key project stakeholders, then develop tailored communication strategies for each to ensure effective engagement and project success.

## Context
Project details:
{{project-overview}}

Available communication channels: {{communication-channels}}

## Process
1. Identify potential stakeholders across organizational levels (executives, managers, team members) and external parties (customers, vendors, regulators, partners)
2. Analyze each stakeholder's influence, interest, and potential impact on the project
3. Design communication strategies matched to each stakeholder's characteristics, priorities, and level of project involvement

## Output
Present your analysis as a markdown table with three columns:
- **Stakeholder Name**: Role or title
- **Role**: Their relationship to the project and level of influence
- **Communication Strategy**: Specific approach including frequency, channel, content focus, and engagement tactics

Ensure the table is comprehensive, well-organized, and provides clear, actionable strategies for each stakeholder.
```
