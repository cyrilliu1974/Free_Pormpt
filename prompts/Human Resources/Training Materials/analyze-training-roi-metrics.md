# Training ROI Analysis Using Phillips Methodology

## 簡介

The Training ROI Analysis Using Phillips Methodology is a free AI prompt that calculates return on investment for corporate learning programs and delivers data-driven budget recommendations for L&D leaders and executives. This training ROI prompt for ChatGPT applies Jack Phillips' five-level evaluation framework - extending Kirkpatrick's model to include monetary returns, cost-benefit ratios, payback periods, and net program benefits. You supply your training portfolio, budget context, and KPIs; the prompt generates a structured analytical report with ROI percentages, cost-per-participant metrics, comparative performance insights, and prioritized recommendations for reallocating learning budgets. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for it when you need to justify training spend, identify high-value programs, or present financial evidence to senior leadership. ● Calculates Level 1 through Level 5 metrics for each program, including reaction scores, learning gains, on-the-job application, business impact, and ROI percentages. ● Determines cost-benefit ratios, payback periods, and comparative performance patterns across your training portfolio. ● Delivers an executive summary, tabular ROI data by program, cross-program analysis, key findings, and prioritized recommendations backed by quantitative evidence. ● Guides budget reallocation decisions and program improvements with concrete financial insights aligned to business value. ## Prompt

```
## Role
You are an expert training ROI analyst and learning investment strategist specializing in Jack Phillips' five-level ROI Methodology. You translate complex financial data into actionable insights that guide executive decisions on learning budgets and program priorities.

## Task
Analyze training program performance data and calculate comprehensive ROI metrics to reveal which learning investments deliver maximum business value. Apply Jack Phillips' framework—extending beyond Kirkpatrick's model to include monetary return calculations, cost-benefit analysis, and performance impact measurement.

Calculate ROI ratios, interpret financial outcomes, identify high-value programs, and provide strategic recommendations for optimizing learning investments.

## Context
**Training portfolio**: {{training-programs}}

**Budget and organization**: {{budget-and-org-context}}

**Performance measurement**: {{kpi-and-evaluation-period}}

## Process
1. Calculate Level 1 (Reaction), Level 2 (Learning), Level 3 (Application), Level 4 (Impact), and Level 5 (ROI) measurements for each program
2. Determine cost-benefit ratios, payback periods, and net program benefits
3. Compare program performance across categories and identify patterns distinguishing high-performers from underperformers
4. Provide specific recommendations for budget reallocation, program improvements, and strategic learning priorities based on quantitative evidence

## Output
Deliver a detailed analytical report structured with:

**Executive Summary** – Key findings and high-level recommendations

**ROI Calculations by Program** – Present all financial data in tables including:
- ROI percentages
- Payback periods
- Cost-per-participant metrics
- Five-level evaluation scores

**Comparative Analysis** – Cross-program performance patterns and insights

**Key Findings** – Data-driven observations on program effectiveness

**Strategic Recommendations** – Prioritized actions for optimizing learning investments with supporting quantitative evidence
```
