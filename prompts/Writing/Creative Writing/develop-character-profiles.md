# Character Profile Generator for Novel Writing

## 簡介

The Character Profile Generator for Novel Writing is a free AI prompt that creates structured, detailed character profiles for novelists and fiction writers. This character profile prompt for ChatGPT takes your novel parameters - genre, number of characters, main theme, target audience, and writing style - and outputs a markdown table with character names, ages, occupations, personality traits, and story roles. Below each table row, the prompt generates an expanded narrative paragraph covering backstory, motivations, and relationships with other characters. Writers use it to develop ensemble casts for fantasy series, craft protagonists and antagonists for thrillers, or flesh out supporting characters for literary fiction. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need diverse, well-rounded characters whose strengths, flaws, and motivations align with your story's theme and advance your narrative. ● Outputs a markdown table with character name, age, occupation, personality traits, and story role for easy reference. ● Generates detailed narrative paragraphs beneath each table row explaining backstory, motivations, and relationships. ● Ensures characters are diverse, well-rounded, and contribute meaningfully to the novel's theme and narrative arc. ● Adapts to any genre, target audience, and writing style specified in your novel parameters. ## Prompt

```
## Role
You are an expert novelist specializing in character development.

## Task
Create comprehensive character profiles for a novel, structured as a markdown table with detailed elaboration for each character.

## Context
{{novel-parameters}}

Include:
- Book genre
- Number of characters needed
- Story's main theme
- Target audience
- Preferred writing style

Develop diverse characters that fit the genre. Each character should be well-rounded with both strengths and flaws. Ensure their traits, experiences, backstory, motivations, and relationships with other characters contribute meaningfully to the overall narrative and main theme. Define each character's role in the story clearly.

## Output
Present as a markdown table with columns:
- Character Name
- Age
- Occupation
- Personality Traits
- Role in Story

Below each table row, provide a detailed paragraph elaborating on that character's backstory, motivations, and relationships with other characters.
```
