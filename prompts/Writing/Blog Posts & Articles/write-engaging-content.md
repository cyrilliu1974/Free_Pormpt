# Audience-Tailored Content Writer Using Dependency Grammar

## 簡介

The Audience-Tailored Content Writer Using Dependency Grammar is a free AI prompt that generates structured, engaging content optimized for specific audiences and reading levels. This content writing prompt for ChatGPT works by analyzing your target audience's interests and comprehension level, then breaking complex topics into clear subtopics with logical dependencies between ideas. It applies dependency grammar principles to structure sentences that show explicit relationships between concepts, ensuring readers can follow your argument or narrative naturally. The prompt runs on ChatGPT, Claude, Gemini, and Grok to produce blog posts, articles, web copy, or any written content that requires clarity and reader engagement. It incorporates supporting examples, varied sentence structures, smooth transitions, and concludes with summaries that reinforce your core message. This prompt is for content marketers, bloggers, copywriters, and communications professionals who need to write material that connects with a defined audience while maintaining structural clarity and readability. ● Analyzes audience reading level and interests to tailor vocabulary, tone, and complexity ● Structures content using dependency grammar to show clear relationships between ideas and improve comprehension ● Incorporates varied sentence patterns, transitions, examples, and anecdotes for readability ● Outputs content with headings, subheadings, and paragraph formatting optimized for engagement ## Prompt

```
## Role
You are an expert content writer specializing in audience-tailored, structured writing.

## Task
Write engaging, well-structured content that uses dependency grammar principles to create clear logical flow between ideas. Analyze the audience's reading level and interests, break the topic into key points and subtopics, structure sentences to show clear relationships between concepts, and incorporate supporting examples, anecdotes, or data. Use varied sentence structures and smooth transitions throughout. Conclude with a strong summary that reinforces the main message and encourages further engagement.

## Context
**Audience & topic:** {{audience-and-topic}}

**Content scope:** {{content-length}} {{content-purpose}}

**Tone:** {{tone}}

## Output
Deliver the content with clear headings, subheadings, and paragraphs optimized for readability and engagement.
```
