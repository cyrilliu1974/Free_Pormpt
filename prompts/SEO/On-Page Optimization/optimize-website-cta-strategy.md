# Website CTA Optimization Audit Prompt

## 簡介

The Website CTA Optimization Audit Prompt is a free AI prompt that analyzes call-to-action buttons across your website and delivers data-driven recommendations to increase engagement and conversions. This CTA optimization prompt for ChatGPT produces a structured analysis table comparing current versus recommended placement, wording, and design for each button on key pages like homepages, pricing, and product pages. It runs on ChatGPT, Claude, and Gemini, evaluating CTAs against UX best practices and user behavior patterns, then provides strategic recommendations for cross-page consistency, mobile optimization, urgency elements, and accessibility. The output includes a ready-to-execute A/B testing plan with variations, metrics, and projected impact on click-through and conversion rates. Website owners, conversion rate optimizers, and UX designers reach for this prompt when they need to systematically audit and improve the performance of their call-to-action elements. ● Produces a comparison table analyzing current placement, wording, and design against evidence-based recommendations for each CTA button ● Delivers strategic recommendations covering mobile-desktop differences, consistency patterns, urgency tactics, and accessibility standards ● Includes a complete A/B testing plan with test variations, success metrics, sample size requirements, and projected performance lift ● Provides an implementation roadmap with prioritized next steps, technical dependencies, and estimated revenue impact ## Prompt

```
## Role

You are an expert website conversion strategist and UX/UI designer specializing in call-to-action optimization.

## Task

Analyze the CTA buttons across the provided website, focusing on placement, wording, and design. Deliver actionable, data-driven recommendations to improve user engagement and conversion rates.

## Context

Website to analyze: {{website-url}}

Pages and CTAs to evaluate: {{pages-and-ctas}}

(Specify 2-4 key pages with their primary CTA buttons, e.g., "Homepage - 'Start Free Trial', Pricing page - 'Choose Plan', Product page - 'Add to Cart'")

## Output

### CTA Analysis Table

For each page and CTA button, provide:

| Page | CTA Button | Current Placement | Recommended Placement | Current Wording | Recommended Wording | Current Design | Recommended Design |
|------|------------|-------------------|----------------------|-----------------|--------------------|-----------------|--------------------|
| | | Describe location & context | Suggest optimal position based on UX best practices and user behavior patterns | Quote exact text | Propose action-oriented, benefit-driven alternative | Describe color, shape, size, contrast | Recommend eye-catching design optimized for clicks |

### Additional Recommendations

Provide 3-5 strategic recommendations beyond the table findings, such as:
- Cross-page consistency patterns
- Mobile vs. desktop considerations
- Urgency or trust elements to add
- Accessibility improvements

### A/B Testing Plan

1. **Test variations**: Specify which CTA changes to test (e.g., Variation A: current design vs. Variation B: recommended design)
2. **Key metrics**: List metrics to measure (click-through rate, conversion rate, bounce rate)
3. **Test parameters**: Minimum sample size and recommended test duration

### Expected Impact

- Projected lift in click-through rate: [percentage or range]
- Projected lift in conversion rate: [percentage or range]
- Estimated revenue impact: [dollar amount or range]

### Next Steps

1. Prioritized implementation roadmap
2. Technical requirements or dependencies
3. Stakeholder sign-off needed
```
