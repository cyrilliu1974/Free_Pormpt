# Social Media Live Event Planner Prompt

## 簡介

The Social Media Live Event Planner Prompt is a free AI prompt that creates end-to-end live event strategies for businesses and marketers looking to drive real-time audience engagement on social platforms. This social media live event prompt for ChatGPT walks you through platform selection, optimal scheduling, topic development, promotional channels, engagement mechanics, and success metrics - organized as a dependency table that shows how each decision builds logically on the last. You provide your business offering, target audience, and event goals, and the prompt returns a markdown table mapping every element from pre-event promotion through post-event follow-up. It works on ChatGPT, Claude, Gemini, and Grok, tailoring recommendations to platform-specific features like live video, polls, and Q&A. Use this prompt when you need a cohesive, step-by-step roadmap for a webinar, product launch, AMA session, or any live social event where timing and platform choice matter. ● Recommends the best platform based on where your audience is most active and what features you need ● Identifies optimal scheduling windows to maximize live attendance and real-time interaction ● Develops compelling topics and engagement mechanics (polls, Q&A, challenges) that drive participation ● Structures every element with clear dependencies so you know the logical order of execution ## Prompt

```
## Role
You are an expert social media strategist specializing in live event planning and audience engagement.

## Task
Create a comprehensive live social media event plan that includes platform selection, event scheduling, topic development, and promotional strategy. Structure the plan so each element builds logically on previous decisions, ensuring a cohesive strategy from concept through execution.

## Context
**Business and offering:** {{business-and-offering}}

**Target audience:** {{target-audience}}

**Event goals:** {{event-goals}}

The plan should account for pre-event promotion, real-time engagement tactics, and post-event follow-up. Consider platform-specific features (live video, polls, Q&A, etc.) and tailor the approach to where the target audience is most active.

## Output
Deliver the plan as a markdown table with three columns:

| Event Element | Details | Dependencies |
|---------------|---------|-------------|

**Event Element:** Each component of the live event strategy (platform selection, scheduling, content themes, promotional channels, engagement mechanics, success metrics, etc.)

**Details:** Specific recommendations, tactics, and rationale for that element

**Dependencies:** Which previous elements this component relies on or builds upon

Ensure the Dependencies column clearly shows how each decision flows from earlier choices, creating a logical execution path.
```
