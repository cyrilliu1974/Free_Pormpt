# Breadcrumb Navigation SEO Audit and Guidelines

## 簡介

The Breadcrumb Navigation SEO Audit and Guidelines is a free AI prompt that analyzes your website's structure and produces a complete implementation plan for breadcrumb navigation optimized for both user experience and search engine visibility. This breadcrumb navigation prompt for ChatGPT examines your site's content hierarchy, evaluates existing navigation patterns, and delivers a structured report covering five tailored best practices, a four-level breadcrumb hierarchy recommendation, display and accessibility guidelines, ready-to-use JSON-LD schema markup, and measurable success metrics. It runs on ChatGPT, Claude, and Gemini, producing output grounded in your actual website URL rather than generic SEO advice. Technical SEO specialists use it to standardize internal linking structures, improve crawlability, and reduce bounce rates on deep content pages. Reach for this prompt when you need a site-specific breadcrumb strategy that balances user navigation with search engine requirements, especially for e-commerce platforms, documentation sites, or content hubs with three or more levels of hierarchy. ● Delivers a four-level breadcrumb hierarchy map tailored to your site's actual content structure and URL patterns. ● Generates complete JSON-LD schema markup code you can paste directly into your site's templates for rich snippet eligibility. ● Includes five visual display and responsive design guidelines that address mobile navigation, separator symbols, and ARIA accessibility labels. ● Specifies four SEO optimization opportunities, from internal link equity distribution to duplicate content mitigation through canonical signals. ## Prompt

```
## Role

You are an expert SEO strategist specializing in breadcrumb navigation optimization for user experience and search engine visibility.

## Task

Analyze the provided website and develop comprehensive, actionable guidelines for implementing effective breadcrumb navigation that improves site usability and SEO performance.

## Context

Website URL: {{website-url}}

Base your recommendations on the site's actual structure, content hierarchy, and target audience. Ensure all advice is specific to this website, not generic best practices.

## Output

Provide a structured analysis in the following format:

**Website Structure Analysis:**
- Main navigation overview

- Current breadcrumb implementation (if any)

**Breadcrumb Best Practices:**
1. Five specific best practices tailored to this website

**Recommended Breadcrumb Hierarchy:**
Present a clear 4-level hierarchy structure:
1. Level 1
   - Level 2
     - Level 3
       - Level 4

**Breadcrumb Display Guidelines:**
✓ Five display guidelines covering visual presentation, responsive behavior, and accessibility

**Breadcrumb Schema Markup:**
```
Provide a complete JSON-LD schema markup example appropriate for this site
```

**SEO Considerations:**
• Four specific SEO implications and optimization opportunities for breadcrumb implementation

**Measuring Success:**
1. Three concrete metrics with measurement methods to track breadcrumb navigation effectiveness
```
