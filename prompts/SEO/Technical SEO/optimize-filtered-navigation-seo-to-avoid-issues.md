# E-Commerce Filtered Navigation SEO Optimization

## 簡介

The E-Commerce Filtered Navigation SEO Optimization is a free AI prompt that creates structured optimization plans for e-commerce sites struggling with filter parameter indexing, crawl budget waste, and duplicate content from faceted navigation. This filtered navigation SEO prompt for ChatGPT analyzes your current implementation and delivers actionable recommendations across five critical areas: URL structure patterns for filter parameters, canonical tag strategies for variant pages, robots.txt crawl control rules, pagination handling methods, and faceted navigation best practices. It runs on ChatGPT, Claude, Gemini, and Grok, organizing each recommendation using dependency grammar principles so foundational technical fixes support higher-level ranking and user experience outcomes.
