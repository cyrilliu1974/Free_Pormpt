# Link Quality Audit Prompt for SEO Analysis

## 簡介

The Link Quality Audit Prompt for SEO Analysis is a free AI prompt that conducts systematic inbound link analysis for websites and delivers actionable recommendations to improve link profiles and keyword strategy. This link quality audit prompt for ChatGPT evaluates every inbound link using domain authority, page authority, niche relevance, and anchor text analysis. It categorizes each link as strong, moderate, or weak, examines how linking context supports target keywords, and identifies gaps in your link profile. The prompt runs on ChatGPT, Claude, and Gemini, producing a structured audit table, percentage breakdown of link quality tiers, keyword strategy analysis, and specific recommendations for strategic link acquisition. SEO consultants use it to audit client sites, content marketers apply it to assess campaign effectiveness, and digital agencies rely on it to guide link-building priorities. ● Categorizes every inbound link as strong, moderate, or weak using domain authority, page authority, and niche relevance metrics ● Maps anchor text and linking page content to target keywords, revealing how each link supports your keyword strategy ● Calculates percentage breakdown of link quality tiers to quantify overall profile health ● Identifies specific gaps in keyword coverage and opportunities for strategic link acquisition ## Prompt

```
## Role
You are an expert SEO consultant specializing in link analysis and keyword strategy.

## Task
Conduct a comprehensive link quality audit for the provided website and deliver actionable recommendations to improve its link profile and keyword strategy.

## Context
Analyze the website's inbound links using:
- Domain authority, page authority, and niche relevance
- Anchor text and linking page content to assess keyword strategy contribution
- Identification of strengths, weaknesses, gaps, and opportunities

Website: {{website-url}}

## Output

### Link Quality Audit Table
Present findings in this three-column format:

| Link URL | Quality (Strong/Moderate/Weak) | Keyword Relevance |
|----------|--------------------------------|-------------------|
| [URL]    | [Quality tier]                 | [Target keywords] |
| ...      | ...                            | ...               |

### Overall Link Quality Summary
Provide the percentage breakdown of strong, moderate, and weak links, highlighting the current state of the link profile.

### Keyword Strategy Analysis
Examine how inbound links support the website's keyword strategy. Identify:
- How anchor text and linking context align with target keywords
- Gaps in keyword coverage
- Opportunities for strategic link acquisition

### Recommendations
Deliver specific, actionable steps to:
- Improve link quality (address weak links, acquire high-authority links)
- Strengthen keyword targeting through strategic link building
- Fill identified gaps in the link profile
```
