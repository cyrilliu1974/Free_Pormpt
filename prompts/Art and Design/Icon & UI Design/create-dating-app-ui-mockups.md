# Dating App UI Mockup Generator

## 簡介

The Dating App UI Mockup Generator is a free AI prompt that creates modern, flat-design mobile dating app interfaces with customizable profile content and a warm gradient aesthetic. This dating app UI mockup prompt for Midjourney produces a centered mobile screen layout featuring a pink-to-purple gradient background, a hero profile card with large portrait placement, swipe left/right buttons at the bottom, and clean bold typography with a minimal top bar. Designers and product teams use it to visualize dating app concepts, pitch decks, or portfolio pieces without needing Figma prototypes. The prompt works on Midjourney, Flux, Nano Banana, and similar text-to-image models, delivering a 3:4 aspect ratio mockup ready for presentation or iteration. Reach for this prompt when you need a polished, modern dating app interface visual in seconds, whether for client proposals, A/B testing design directions, or app store preview concepts. ● Produces a centered mobile screen with warm pink and purple gradient background and flat design style. ● Includes swipe left/right buttons, minimal top bar icons, and bold typography for a playful, modern UX. ● Accepts a {{profile-content}} variable to customize the hero profile card with names, ages, bios, or photos. ● Outputs in 3:4 aspect ratio with raw style rendering for crisp, presentation-ready visuals. ## Prompt

```
Front view dating app UI mockup, flat design, centered mobile screen, warm pink and purple gradient background, {{profile-content}}, swipe left/right buttons at bottom, clean bold typography, minimal top bar with icons, modern and playful UX --ar 3:4 --style raw
```
