# E-Commerce Product Page SEO Checklist Generator

## 簡介

The E-Commerce Product Page SEO Checklist Generator is a free AI prompt that creates tailored, actionable SEO checklists for optimizing product pages across Amazon, eBay, Etsy, Shopify, WooCommerce, Magento, and custom platforms. This e-commerce SEO checklist prompt for ChatGPT, Claude, Gemini, and Grok produces two deliverables: a platform-specific optimization checklist organized by element (title tags, meta descriptions, images, schema markup, content, formatting) with validation steps, and a prioritized step-by-step workflow that ranks changes by impact and includes troubleshooting guidance. Each checklist adapts to the unique requirements of your platform while applying core SEO principles, helping you identify missing alt tags, poorly optimized titles, and other revenue-costing gaps. Reach for this prompt when you need to audit existing product pages, onboard new inventory, or train a team on platform-specific optimization standards. ● Adapts to platform-specific formatting rules and metadata requirements for Amazon, Shopify, WooCommerce, and other e-commerce systems. ● Prioritizes high-impact changes first, so you address title tag optimization, meta descriptions, and schema markup before lower-priority tweaks. ● Includes validation methods and troubleshooting guidance for common issues like missing structured data or keyword over-optimization. ● Provides both a checklist format for audits and a numbered workflow for systematic implementation. ## Prompt

```

Structure the checklist to prioritize high-impact changes first, include validation methods, and provide troubleshooting guidance for common issues.

Deliver:

1. **Platform-Specific Optimization Checklist** organized by element (title tags, meta descriptions, images, schema, content, formatting) with detailed sub-tasks and validation steps for each

Use clear section headings, bullet points for checklist items, and numbered steps for the workflow.
```
