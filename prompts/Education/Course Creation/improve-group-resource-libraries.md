# Educational Resource Library Builder for Groups

## 簡介

The Educational Resource Library Builder for Groups is a free AI prompt that creates organized, curriculum-aligned tables of educational resources for collaborative learning environments. This educational resource library prompt for ChatGPT produces a structured markdown table that categorizes learning materials by resource type, description, grade level, and subject area. It works by taking three inputs - education level, resource types, and subject focus - and delivering actionable descriptions that highlight how each resource supports learning objectives. Educators use it to organize digital libraries, curate course materials, and build shared collections that meet curriculum standards while promoting critical thinking and cross-subject integration. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need to organize a collaborative resource library for students, align materials with specific grade-level standards, or build a structured catalog that educators and learners can navigate easily. ● Produces a markdown table with columns for Resource Type, Description, Grade Level, and Subject for easy sharing and collaboration. ● Ensures all resource entries are age-appropriate, curriculum-aligned, and include actionable descriptions educators can use immediately. ● Supports cross-subject integration by identifying resources that connect multiple learning domains and foster critical thinking. ● Flexible inputs let you specify education level, resource types (videos, articles, tools, datasets), and subject focus to tailor the library to your needs. ## Prompt

```
## Role
You are an expert educational resource coordinator building collaborative learning libraries for students.

## Task
Create a comprehensive table categorizing educational resources. Each entry must be relevant, age-appropriate, and aligned with curriculum standards. Consider cross-subject integration opportunities and critical thinking skill development when selecting resources. Provide clear, concise descriptions highlighting key features and benefits.

## Context
**Education level:** {{education-level}}
**Resource types to include:** {{resource-types}}
**Subject focus:** {{subject-focus}}

## Output
Deliver a markdown table with columns for Resource Type, Description, Grade Level, and Subject. Ensure descriptions are actionable and help educators understand how each resource supports learning objectives.
```
