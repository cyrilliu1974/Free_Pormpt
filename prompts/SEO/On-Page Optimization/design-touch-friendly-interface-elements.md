# Mobile Touch-Friendly Interface Design Prompt

## 簡介

The Mobile Touch-Friendly Interface Design Prompt is a free AI prompt that creates detailed mobile optimization strategies for websites seeking better user experience and search visibility. This mobile interface design prompt for ChatGPT analyzes your website's current structure and delivers actionable recommendations across six key areas: touch-friendly navigation with thumb-zone positioning, content optimization for mobile screens, mobile SEO enhancements including structured data and AMP implementation, page load performance improvements, accessibility compliance, and testing strategies. It works on ChatGPT, Claude, Gemini, and Grok by taking your website name, target audience, products or services, competitors, and current mobile traffic percentage to produce a tailored strategy. Marketing teams use it to audit mobile sites before redesigns, UX designers rely on it to validate navigation patterns, and SEO specialists apply it to improve mobile search rankings. ● Designs navigation systems optimized for thumb-reachable zones and one-handed mobile use ● Identifies specific image compression and resource-loading techniques to reduce page load times ● Recommends mobile SEO implementations like structured data markup and Accelerated Mobile Pages ● Ensures mobile accessibility compliance for broader audience reach and legal standards ● Provides a testing and validation framework to measure the impact of design changes ## Prompt

```
## Role
You are an expert UX/UI designer and SEO specialist focused on mobile website optimization.

## Task
Design a comprehensive mobile interface strategy that enhances user experience and improves mobile SEO performance. Deliver touch-friendly interface elements, responsive design recommendations, and current mobile SEO techniques.

## Context
Website: {{website-name}}
Target audience: {{target-audience}}
Primary products/services: {{products-services}}
Main competitors: {{competitors}}
Current mobile traffic: {{mobile-traffic-percentage}}

Apply mobile usability best practices, responsive design principles, and current SEO trends. Balance aesthetic appeal with functional efficiency and search engine visibility.

## Approach
1. Analyze the current website structure and identify improvement opportunities
2. Design touch-friendly navigation with thumb-reachable zone considerations
3. Optimize page load times through efficient image and resource handling
4. Implement mobile SEO techniques including structured data and AMP where applicable
5. Create concise, SEO-optimized content
6. Ensure accessibility compliance for mobile users
7. Propose a validation and testing strategy

## Output
Structure your recommendations with clear headings for each main section:
- **Navigation Design**
- **Content Optimization**
- **SEO Enhancements**
- **Performance & Load Times**
- **Accessibility**
- **Testing & Validation**

Use bullet points for specific, actionable recommendations under each section.
```
