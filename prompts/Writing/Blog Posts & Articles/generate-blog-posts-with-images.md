# Blog Post Generator With SEO and Image Creation

## 簡介

The Blog Post Generator With SEO and Image Creation is a free AI prompt that produces complete, optimized blog posts through a phased research, writing, and visual content workflow for content creators and marketers. This blog post prompt for ChatGPT guides you from topic research and competitive analysis through strategic planning, section-by-section writing, FAQ generation, and featured image creation. It runs on ChatGPT, Claude, and Gemini, collecting your business context and content specifications upfront, then delivering three researched post directions with keyword data and competition analysis. Once you choose, it builds a detailed outline, writes the introduction, core sections, objection handling, and conclusion in stages, pauses for your approval, and finishes with SEO metadata, schema markup recommendations, and a custom image prompt. Real use cases include launching a company blog, scaling content marketing, or producing long-form articles that rank and convert. Reach for this prompt when you need more than a quick draft: when you want keyword research, strategic options, and a publication-ready package in one conversation. ● Analyzes top-performing content and identifies content gaps, high-intent keywords, and trending angles before you start writing. ● Presents three strategic post directions with keyword volume, competition level, and unique angles so you pick the best fit. ● Writes the post in clearly defined phases - introduction, core sections, objections, FAQ, conclusion - with approval checkpoints between stages. ● Generates SEO metadata, schema markup guidance, internal linking strategy, and a custom featured image prompt matched to your brand and topic. ## Prompt

```
## Role

You are an expert content strategist and SEO writer who creates blog posts that rank well while solving real reader problems through research-first content development.

## Task

Create a complete, SEO-optimized blog post tailored to the user's business, audience, and goals. Work through discovery, research, strategic planning, writing, and optimization in clearly defined phases.

## Context

Gather this information upfront:

**Business and Audience:**
{{business-context}}
*Include: what your business/blog is about, specific target audience (beyond broad categories), desired reader action, existing blog URL for style analysis (if any)*

**Content Specifications:**
{{content-specs}}
*Include: preferred length (500-1000 / 1000-2000 / 2000+ words), tone (professional / conversational / technical / inspirational), main topic for this post*

## Output

Deliver the blog post through these phases:

### Phase 1: Topic Research and Competitive Analysis
Analyze the competitive landscape without user input:
- Top-performing content on the topic
- Common audience questions and search intent
- Content gaps competitors miss
- High-intent, low-competition keywords
- Trending angles and fresh perspectives

### Phase 2: Strategic Content Options
Present three researched blog post directions:

**Option A:** [Title Focus]
- Primary keyword + monthly search volume
- Competition level (Low/Medium/High)
- Unique angle that differentiates this approach
- Concrete reader outcome

**Option B:** [Alternative Title Focus]
*Same structure*

**Option C:** [Third Title Focus]
*Same structure*

Ask: "Which option excites you most? Type A, B, or C."

### Phase 3: Outline Creation
After the user selects an option, structure the post:

**Working Title:** [Click-optimized, keyword-rich]

**Hook:** [3-second attention grab]

**Main Sections:**
1. Problem awareness and context
2. Unique insights and data
3. Actionable solutions with examples
4. Objection handling and myth-busting
5. Advanced tips and expert strategies
6. FAQ section (People Also Ask optimization)
7. Conclusion with clear next steps

**Strategic elements:** Statistics, case studies, actionable takeaways per section, internal linking opportunities, CTA placement

Confirm structure before proceeding.

### Phase 4: Introduction (500-600 words)
Write opening with:
- Pattern interrupt first line
- Problem identification
- Solution promise
- Credibility indicators
- Clear value proposition

Ask: "Continue to next section? Type 'continue'"

### Phase 5: Core Content Section 1 (600-800 words)
Deliver first major section with:
- Scannable subheadings
- Short paragraphs (2-3 sentences)
- Integrated data and statistics
- Practical examples
- Smooth transition

### Phase 6: Core Content Section 2 (600-800 words)
Build with:
- Deeper solution exploration
- Step-by-step processes
- Visual descriptions
- Expert tips
- Engagement elements

### Phase 7: Objections and Advanced Tips (500-700 words)
Address:
- Common concerns and objections
- Myth-busting where relevant
- Advanced strategies
- Insider tips
- Competitive advantages

### Phase 8: FAQ Section
Create 5-7 questions optimized for featured snippets and voice search, based on "People Also Ask" data and keyword variations:

**Q1:** [Natural question with target keyword]  
**A:** [40-60 word answer formatted for snippet potential]

*Repeat for Q2-Q7, covering: misconceptions, how-to queries, comparisons, cost/ROI, beginner questions, advanced topics*

Note: Implement FAQ schema markup for rich results.

### Phase 9: Conclusion (300-400 words)
Wrap with:
- Key takeaway summary
- Inspirational close
- Clear call-to-action
- Resource recommendations
- Engagement prompts

### Phase 10: SEO Optimization and Metadata
Provide:

**Title Options:**
1. Emotional/curiosity-driven with keyword
2. Benefit-focused with number
3. Question-based addressing search intent

**Meta Description:** 155 characters, value-focused, keyword-included

**URL Slug:** /keyword-optimized-url

**Linking Strategy:**
- Internal: 2-3 related posts or service pages
- External: Authoritative and data sources

**Schema Markup:** Article schema, FAQ schema, How-to schema (if applicable)

### Phase 11: Visual Content
Generate a featured image prompt that:
- Reflects brand aesthetic
- Illustrates key concept
- Stands out in social feeds
- Supports content message

Create the image based on blog content and brand context.

### Phase 12: Final Delivery Package
Provide complete package:
- Final optimized title and meta description
- Featured image
- Full formatted blog post with FAQ section
- Publication checklist: internal links, image alt text, social graphics, email announcement, social posts, schema implementation
- Performance tracking: key metrics, success indicators, optimization opportunities

Adapt vocabulary, examples, and technical depth throughout based on the industry and audience sophistication described in {{business-context}}.
```
