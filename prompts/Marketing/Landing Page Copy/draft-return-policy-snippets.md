# Return Policy Copy Generator for E-Commerce Sites

## 簡介

The Return Policy Copy Generator for E-Commerce Sites is a free AI prompt that transforms return policy parameters into three progressively condensed variations designed to reduce purchase anxiety and build customer confidence. This return policy prompt for ChatGPT, Claude, Gemini, and Grok takes your policy parameters (return window, conditions, product type, and brand tone) and produces six distinct versions: a detailed policy section, a mid-length reassurance blurb, and a short trust badge line, each with a standard informational format and a positively-framed alternative that emphasizes customer benefits. E-commerce managers use it to draft policy copy for product pages, checkout flows, and footer sections that align with their brand voice while addressing specific customer concerns like sizing, quality, or compatibility. Reach for this prompt when you need to rewrite legal return terms into language that encourages confident buying decisions rather than highlighting restrictions. ● Produces detailed policy sections, medium reassurance blurbs, and short trust signals in one pass. ● Delivers both standard informational versions and positively-framed alternatives that emphasize risk-free trials and satisfaction guarantees. ● Includes formatting suggestions (bullet points, bold text, visual hierarchy) to make each variation scannable. ● Accepts custom policy parameters including return windows, condition requirements, product categories, target concerns, and brand tone. ## Prompt

```
## Role

You are an expert e-commerce copywriter specializing in return policies that reduce purchase anxiety and increase conversion.

## Task

Create three progressively condensed return policy variations:
1. **Detailed Policy** – comprehensive terms
2. **Medium Reassurance Blurb** – mid-length confidence builder
3. **Short Trust Signal** – one-liner badge copy

For each variation, write both a standard informational version and a positively-framed alternative that emphasizes customer benefits over seller protections.

## Context

{{policy-parameters}}

Include return window (e.g., 30/60 days), return conditions (packaging, condition requirements), product type, target customer concerns (sizing, quality, compatibility), and brand tone (friendly/professional/luxury).

## Output

- Standard version
- Positively-framed version

Use bullet points, bold text, and visual hierarchy to make each version scannable and emphasize reassuring elements.
```
