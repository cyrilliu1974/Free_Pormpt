# Collaborative Learning Resource-Sharing Strategy Prompt

## 簡介

The Collaborative Learning Resource-Sharing Strategy Prompt is a free AI prompt that develops actionable plans to improve how students and faculty share educational resources within an institution. This collaborative learning prompt for ChatGPT guides the model through analyzing your current resource-sharing system, identifying gaps, and producing a markdown table with 5-8 strategic components. Each row pairs clear objectives with concrete action steps and measurable success metrics. The prompt works on ChatGPT, Claude, Gemini, and Grok, and you customize it by specifying your institution type and audience, describing your existing resource system, and listing available technology and budget. Use it to design rollout plans for shared digital libraries, establish peer tutoring resource hubs, integrate learning management platforms, or overhaul outdated file-sharing workflows. Educational strategists, instructional designers, academic administrators, and IT coordinators reach for this prompt when they need a repeatable framework to diagnose collaboration bottlenecks and propose technology-informed solutions. ● Analyzes the current resource-sharing landscape to surface improvement opportunities and collaboration gaps. ● Defines 5-8 objectives paired with actionable steps, technology integration guidance, and challenge-mitigation tactics. ● Outputs a three-column markdown table (Objectives, Action Steps, Success Metrics) that serves as an implementation roadmap. ● Includes feedback mechanisms and measurement criteria to enable continuous refinement of resource-sharing practices. ## Prompt

```
## Role
You are an expert educational strategist specializing in collaborative learning and resource-sharing systems.

## Task
Develop a comprehensive collaborative learning strategy that improves shared resources among students and faculty. The strategy should:

- Analyze the current resource-sharing landscape and identify improvement opportunities
- Define clear, achievable objectives that address collaboration gaps
- Outline actionable steps to implement each objective
- Establish measurable success metrics
- Integrate technology and digital platforms where appropriate
- Anticipate challenges and propose mitigation strategies
- Include feedback mechanisms for continuous improvement

## Context
**Institution & Audience:** {{institution-and-audience}}

**Current System:** {{current-resource-system}}

**Available Resources:** {{available-technology-and-budget}}

## Output
Present the strategy as a markdown table with three columns:

| Objectives | Action Steps | Success Metrics |
|------------|--------------|------------------|

Each row should represent one cohesive strategy component. Include 5-8 comprehensive strategies that cover analysis, implementation, technology integration, challenge mitigation, and feedback loops.
```
