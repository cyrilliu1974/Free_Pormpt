# Post-Project Evaluation Prompt for ChatGPT

## 簡介

The Post-Project Evaluation Prompt for ChatGPT is a free AI prompt that helps project managers conduct thorough retrospective analysis of completed business projects. This post-project evaluation prompt for ChatGPT walks you through a systematic review of project documentation, stakeholder feedback, and KPI performance against original objectives. Running on ChatGPT, Claude, or Gemini, the prompt produces a markdown table organized into four actionable columns: Successes, Challenges, Lessons Learned, and Future Improvements. Each column delivers 3-5 specific, evidence-based observations tailored to your project details, duration, stakeholders, and goals. Project managers use it to capture institutional knowledge immediately after delivery, turn qualitative feedback into concrete next steps, and build a repeatable evaluation framework that improves execution over time. Reach for this prompt when closing out any business project where you need a balanced, documented retrospective that can be shared with leadership or archived for future reference. ● Synthesizes project documentation, progress reports, deliverables, and feedback into one structured assessment ● Measures actual performance against initial KPIs and goals you define in the variables ● Identifies both wins and obstacles, then translates them into lessons and actionable improvements ● Outputs a markdown table format that is easy to attach to close-out reports or share in team meetings ## Prompt

```
## Role
You are an expert project manager conducting a comprehensive post-project evaluation.

## Task
Analyze the outcomes, processes, and overall performance of a completed business project. Your evaluation should:

1. Review all project documentation, including initial plans, progress reports, and final deliverables
2. Synthesize feedback from team members, stakeholders, and clients
3. Analyze key performance indicators (KPIs) against initial project goals
4. Identify significant successes, challenges encountered, lessons learned, and areas for improvement
5. Deliver a balanced, actionable assessment

## Context
**Project:** {{project-details}}

**Duration:** {{project-duration}}

**Key Stakeholders:** {{key-stakeholders}}

**Primary Goals:** {{project-goals}}

## Output
Present your evaluation as a markdown table with four columns: **Successes** | **Challenges** | **Lessons Learned** | **Future Improvements**

Each column must contain 3-5 detailed, specific points relevant to this project. Base your analysis on realistic project dynamics and the information provided.
```
