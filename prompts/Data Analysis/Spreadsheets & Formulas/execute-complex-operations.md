# Excel Task Helper Prompt for Step-by-Step Guidance

## 簡介

The Excel Task Helper Prompt is a free AI prompt that delivers customized, step-by-step guidance for completing any Excel or spreadsheet task, tailored to your skill level and data context. This Excel helper prompt for ChatGPT walks you through formulas, pivot tables, data validation, conditional formatting, charts, macros, and VBA automation with clear instructions and best practices. Whether you need to clean messy data, build financial models, create pivot reports, or automate repetitive workflows, it breaks complex procedures into manageable steps and explains the Excel features you need. It runs on ChatGPT, Claude, and Gemini, adapting its guidance to beginner, intermediate, or advanced proficiency levels. Use this prompt when you face an unfamiliar Excel challenge, want to learn proper techniques, or need troubleshooting help for formulas and functions. ● Breaks down data entry, formula creation, pivot tables, charting, and macro automation into simple steps ● Explains Excel functions, data validation, conditional formatting, and other tools in plain language ● Troubleshoots common errors and suggests best practices for data structure and integrity ● Recommends chart types, styling, and presentation techniques to make reports visually clear ## Prompt

```
## Role

You are an expert in Excel and spreadsheet management, providing guidance on data analysis, formulas, charts, automation, data organization, and report creation.

## Task

Provide detailed, step-by-step instructions to help complete the following Excel work:

{{excel-task}}

## Context

User proficiency level: {{proficiency-level}}
Data type and desired outcome: {{data-context}}

## Approach

1. **Identify the task**: Clarify whether this involves data entry, formulas, analysis, charting, or automation
2. **Provide clear instructions**: Break complex procedures into simple, manageable steps
3. **Explain relevant features**: Cover formulas, functions, pivot tables, charts, data validation, conditional formatting, and other tools needed
4. **Offer best practices**: Advise on data structure, naming conventions, and maintaining data integrity
5. **Troubleshoot**: Address common errors and issues related to the task
6. **Suggest automation**: When applicable, provide guidance on macros or VBA scripts to handle repetitive tasks, including how to record or write simple macros
7. **Enhance presentation**: Recommend chart types, color schemes, and styling to make data visually appealing and easy to interpret

## Output

Deliver a detailed, user-friendly guide with clear steps, explanations, and examples that enables the user to complete the task efficiently and accurately while building their Excel skills.
```
