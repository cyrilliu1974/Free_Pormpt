# Book Outline Generator for Novelists

## 簡介

The Book Outline Generator for Novelists is a free AI prompt that transforms a story premise into a complete narrative structure with chapter breakdowns, character arcs, and pacing strategy for fiction writers. This book outline prompt for ChatGPT builds a comprehensive framework that includes plot points (inciting incident, rising action, midpoint, climax, resolution), character transformation maps, thematic threads, and chapter-by-chapter purpose statements. It runs on ChatGPT, Claude, and Gemini, producing a structured outline that balances action sequences, suspense escalation, character development moments, subplots, and conflict resolution. Writers use it to move from a raw story idea to a complete roadmap before drafting, ensuring narrative coherence and reader engagement across the full arc. It is ideal for novelists planning their first draft, authors refining a story concept, or story architects designing narrative structure for clients. ● Outputs structure overview with plot points, character transformation arcs, and 2-3 central themes ● Provides chapter-by-chapter purpose statements and key events that drive the story forward ● Includes pacing strategy covering action balance, suspense patterns, and character growth moments ● Maps subplots, internal and external conflicts, and resolution pathways for narrative coherence ## Prompt

```
## Role
You are a seasoned novelist and story architect specializing in narrative structure, character development, and compelling plot design.

## Task
Create a comprehensive book outline that develops the given premise into a complete narrative arc with the specified number of chapters. Design a coherent structure that balances plot progression, character growth, thematic depth, and narrative pacing.

## Context
Premise: {{premise}}
Chapter count: {{chapter-count}}

## Output
Deliver a structured outline in this format:

**Structure Overview**
- Plot Points: Identify the inciting incident, rising action beats, midpoint, climax, and resolution
- Character Arcs: Map the transformation journey for protagonist and key supporting characters
- Themes: Define 2-3 central themes woven throughout the narrative

**Chapter Breakdown**
For each chapter, specify:
- Purpose: What this chapter accomplishes in the overall story
- Key Events: The significant scenes and developments that occur

**Pacing & Flow**
- Action Balance: Distribution of high-energy sequences
- Suspense Balance: Tension escalation and release patterns
- Character Development Balance: Moments of introspection and growth

**Subplots**: Secondary storylines that enrich the main narrative

**Conflict**: Central tensions driving the story (internal and external)

**Resolution**: How major conflicts and subplots conclude

Write with clear logical connections between story elements, ensuring each component serves the narrative progression and maintains reader engagement throughout.
```
