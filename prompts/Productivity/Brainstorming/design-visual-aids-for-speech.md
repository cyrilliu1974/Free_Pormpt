# Visual Aids Design Prompt for Speech Presentations

## 簡介

The Visual Aids Design Prompt for Speech Presentations is a free AI prompt that creates structured, presentation-ready visual aids for speakers, trainers, and presenters. This visual aids design prompt for ChatGPT analyzes speech content to identify key points that need visual support, then recommends specific formats - infographics, charts, diagrams, or images - matched to each message. It outputs design specifications including color palettes, typography choices, spacing guidelines, and placement instructions that align with the speech structure. The prompt delivers speaker notes, data visualizations for statistics, and cohesive visual narratives optimized for your presentation medium. Use it when preparing keynotes, training sessions, conference talks, or any speaking engagement where clear visuals will reinforce your message. It runs on ChatGPT, Claude, Gemini, and Grok. ● Analyzes speech content to pinpoint which ideas benefit most from visual representation ● Recommends specific visual formats - charts for data, diagrams for processes, infographics for comparisons - matched to each point ● Delivers color palette, typography, and layout specifications that maintain visual consistency across all slides or aids ● Provides placement guidance so each visual appears at the optimal moment in your speech flow ## Prompt

```
## Role
You are a visual communication specialist designing visual aids for speeches that maximize audience engagement and retention.

## Task
Create a complete set of visual aids tailored to the speech, including:

1. Analysis of content to identify key points requiring visual representation
2. Selection of appropriate visual formats (infographics, charts, images, diagrams) matched to each point
3. Design specifications that complement and reinforce the speaker's message
4. Visual consistency guidelines (color palette, typography, spacing)
5. Application of color theory and typography principles for readability and impact
6. Structured speaker notes or presentation outline using clear hierarchical relationships
7. A cohesive visual narrative that flows logically with speech structure
8. Optimization recommendations for the specified presentation medium
9. Data visualizations supporting key arguments or statistics
10. Clear annotations or captions for each visual element

## Context
{{speech-details}}

## Output
Structure your response with main headings for each visual aid, followed by:
- **Content**: What the visual displays
- **Purpose**: How it supports the speech
- **Design elements**: Colors, fonts, layout specifications, and formatting
- **Placement**: Where it appears in the speech flow
```
