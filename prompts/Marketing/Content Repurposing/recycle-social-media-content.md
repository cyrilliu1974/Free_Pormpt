# Social Media Content Repurposing Prompt

## 簡介

The Social Media Content Repurposing Prompt is a free AI prompt that converts existing written content into tailored, platform-specific social media posts for marketing teams, content creators, and social media managers. This content repurposing prompt for ChatGPT analyzes your original article, blog post, or written material and generates six adapted versions: a conversational Facebook post optimized for engagement, a visual-first Instagram caption with hashtags and emoji formatting, a Twitter thread broken into sub-280-character tweets, a professional LinkedIn narrative with industry insights, an SEO-optimized Pinterest pin description with image guidance, and a TikTok video script with hook-value-CTA structure. It works on ChatGPT, Claude, Gemini, and Grok by first extracting core messages from your source content, then rewriting each platform version according to format constraints, tone expectations, and audience behavior patterns unique to that channel. Use it when you have valuable long-form content but need to maintain an active presence across multiple social platforms without creating everything from scratch. ● Extracts and lists three key messages from your source content to ensure consistency across all platform adaptations. ● Generates format-compliant posts for Facebook, Instagram, Twitter, LinkedIn, Pinterest, and TikTok with platform-native features like hashtags, thread numbering, and character limits. ● Provides actionable creative direction for visual platforms, including Pinterest image overlay concepts and TikTok video treatment suggestions. ● Adapts tone and structure automatically - conversational for Facebook, professional for LinkedIn, script-style for TikTok - without manual rewriting. ## Prompt

```
## Role

You are a social media strategist and content repurposing expert specializing in adapting content for platform-specific engagement.

## Task

Transform the provided content into engaging, platform-specific social media posts for Facebook, Instagram, Twitter (as a thread), LinkedIn, Pinterest, and TikTok. Preserve the core message while adapting format, tone, and structure to each platform's best practices and audience expectations.

## Context

Original content to repurpose:
{{original-content}}

## Output

Provide your response in the following structure:

**Original Content:**
[Echo the original content]

**Key Messages:**
1. [Key message 1]
2. [Key message 2]
3. [Key message 3]

**Facebook Post:**
[Conversational post optimized for comments and shares, 1-3 paragraphs]

**Instagram Post:**
[Visual-first caption with line breaks, emojis, and 5-10 relevant hashtags]

**Twitter Thread:**
1. [Hook tweet, <280 characters]
2. [Supporting tweet, <280 characters]
3. [Supporting tweet, <280 characters]
4. [Closing tweet with CTA, <280 characters]

**LinkedIn Post:**
[Professional narrative with industry insights, 2-4 paragraphs, formatted for readability]

**Pinterest Pin:**
Description: [SEO-optimized pin description with keywords and CTA]
Image suggestion: [Description of vertical image (2:3 ratio) with text overlay concept]

**TikTok Video:**
Script: [Hook (0-3s), value delivery (15-45s), CTA]
Video concept: [Visual treatment, on-screen actions, and suggested audio style]
```
