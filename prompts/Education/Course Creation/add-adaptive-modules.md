# Adaptive Learning Module Builder for Online Courses

## 簡介

The Adaptive Learning Module Builder for Online Courses is a free AI prompt that creates fully structured, adaptive course modules for instructional designers, educators, and training professionals. This adaptive learning prompt for ChatGPT guides the AI to design a complete course module with diagnostic assessments, progressive content blocks, tiered question sets that adjust difficulty based on performance, and instant feedback mechanisms. It produces eight structured sections including module overviews, branching logic assessments, adaptive question sets organized by difficulty level, personalized feedback for every response, reinforcement activities targeting skill gaps, summative evaluations, and a curated resource repository. The prompt runs on ChatGPT, Claude, and Gemini, and is ideal for building online courses, employee training programs, certification modules, and educational content that responds to individual learner progress. Reach for this prompt when you need to create personalized learning experiences that meet learners where they are and guide them to mastery at their own pace. ● Generates diagnostic assessments with branching logic to identify learner skill levels at the start ● Creates tiered multiple-choice question sets that progressively adjust difficulty based on performance ● Produces specific, actionable feedback for every answer choice, including hints and supplementary resource links ● Designs reinforcement activities and practice exercises matched to demonstrated knowledge gaps ## Prompt

```
## Role
You are an expert instructional designer specializing in adaptive online learning.

## Task
Develop a comprehensive, interactive course module that adjusts to learner skill level and progress. Design a series of multiple-choice questions that:
- Gradually increase in difficulty based on performance
- Provide instant, actionable feedback after each response
- Offer supplementary explanations and resources when learners struggle
- Create pathways that adapt to individual mastery rates

## Context
**Topic:** {{topic}}

**Target audience:** {{target-audience}}

**Desired learning outcomes:** {{learning-outcomes}}

**Available resources:** {{available-resources}}

## Output
Deliver a structured, numbered learning module with clear section headings:

1. **Module Overview** – objectives, prerequisites, estimated completion time
2. **Diagnostic Assessment** – initial skill-level questions with branching logic
3. **Core Learning Path** – progressive content blocks with embedded assessments
4. **Adaptive Question Sets** – tiered multiple-choice questions (beginner/intermediate/advanced)
5. **Feedback Mechanisms** – specific responses for correct/incorrect answers, including hints and resource links
6. **Reinforcement Activities** – practice exercises matched to demonstrated skill gaps
7. **Summative Assessment** – final evaluation with mastery criteria
8. **Resource Repository** – organized list of supplementary materials by difficulty level
```
