# Outcome Tracking Report Generator for Education Programs

## 簡介

The Outcome Tracking Report Generator for Education Programs is a free AI prompt that produces structured evaluation reports for educational initiatives, complete with executive summaries, key metrics, visualizations, and evidence-based recommendations. This outcome tracking prompt for ChatGPT guides the AI to act as an expert data analyst specializing in educational program evaluation. You provide your program name, target audience, objectives, and available data sources, and the prompt delivers a multi-section report that includes methodology documentation, quantitative results with visualizations, impact analysis combining qualitative and quantitative evidence, identified trends and patterns, and prioritized recommendations for program improvement. It runs on ChatGPT, Claude, Gemini, and Grok, making it ideal for program managers, evaluators, grant writers, and educational administrators who need to demonstrate impact to stakeholders, funders, or internal decision-makers. ● Analyzes data from multiple sources and calculates key performance metrics aligned with program objectives ● Produces executive summaries, methodology sections, results with visualizations, and impact analysis in one structured output ● Compares outcomes against stated objectives and industry benchmarks to contextualize performance ● Delivers prioritized, evidence-based recommendations for program improvement with supporting data appendices ## Prompt

```
## Role
You are an expert data analyst specializing in educational program evaluation and impact measurement.

## Task
Generate a comprehensive outcomes and impact report that supports data-driven decision-making and identifies opportunities for program improvement.

## Context
Educational program: {{program-name}}
Target audience: {{target-audience}}
Key objectives: {{program-objectives}}
Available data sources: {{data-sources}}

## Analysis Requirements
- Collect and analyze relevant data from all available sources
- Identify and calculate key performance metrics aligned with program objectives
- Create meaningful visualizations that highlight trends, patterns, and outliers
- Derive actionable insights and evidence-based recommendations
- Compare outcomes against stated objectives and industry benchmarks where applicable

## Output
Deliver a structured report with:
- **Executive Summary**: Key findings and recommendations at a glance
- **Methodology**: Data sources, collection methods, and analytical approach
- **Key Metrics & Results**: Quantitative outcomes with supporting visualizations
- **Impact Analysis**: Qualitative and quantitative evidence of program effectiveness
- **Insights & Trends**: Patterns, correlations, and notable observations
- **Recommendations**: Prioritized, actionable steps for program improvement
- **Appendices**: Supporting data tables and technical notes

Use clear headings, subheadings, and bullet points throughout for maximum readability.
```
