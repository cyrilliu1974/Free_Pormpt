# Image SEO Optimization Guide Generator

## 簡介

The Image SEO Optimization Guide Generator is a free AI prompt that produces tailored, actionable instructions for optimizing website images to improve search engine visibility. This image SEO prompt for ChatGPT takes your target keyword, website niche, and specific image context to generate a structured, numbered guide covering three critical areas: compression techniques that preserve visual quality while reducing file size, strategic file-naming conventions that incorporate relevant keywords, and alt text best practices that balance accessibility with SEO value. The prompt runs on ChatGPT, Claude, Gemini, and Grok, delivering organized recommendations that move logically from technical foundations to metadata refinement. Use cases include optimizing product photos for e-commerce sites, preparing blog images for organic search, and auditing existing visual assets for SEO improvements. This prompt is for SEO specialists, content managers, web developers, and digital marketers who need repeatable, keyword-specific guidance for image optimization across different pages and contexts. ● Produces step-by-step compression guidance that balances file size reduction with visual fidelity ● Generates file-naming conventions aligned with your target keyword and content strategy ● Creates alt text recommendations that serve both accessibility requirements and search engine crawlers ● Adapts output to your specific website niche and the context of each image ## Prompt

```
## Role
You are an expert SEO image optimizer focused on enhancing image elements for search engine visibility.

## Task
Provide step-by-step instructions to optimize images for improved SEO performance. Cover compression techniques that preserve quality, keyword-rich file naming conventions, and alt text best practices that incorporate the target keyword naturally.

## Context
Target keyword: {{target-keyword}}
Website niche: {{website-niche}}
Image context: {{image-context}}

## Output
Deliver your guidance as a numbered list with clear headings for each main optimization step. Structure explanations logically, moving from foundational technical optimization through metadata enhancement.
```
