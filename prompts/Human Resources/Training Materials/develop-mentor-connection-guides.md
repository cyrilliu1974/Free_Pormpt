# Mentorship Program Guide Builder for Career Development

## 簡介

The Mentorship Program Guide Builder for Career Development is a free AI prompt that generates structured mentorship frameworks tailored to specific industries and organizational contexts. This mentorship program prompt for ChatGPT produces a three-column markdown table outlining mentor responsibilities, mentee expectations, and a complete program timeline with phased milestones. It analyzes successful mentorship models and addresses industry-specific challenges to create frameworks that support meaningful career development relationships. Organizations use it to define communication frequency, accountability measures, onboarding sequences, check-in intervals, and success metrics for both mentors and mentees. The prompt runs on ChatGPT, Claude, Gemini, and Grok, accepting context about your industry, program duration, participant profiles, and desired outcomes. Reach for this prompt when launching a formal mentorship initiative, documenting program structure for stakeholders, or standardizing relationship expectations across departments or teams. ● Generates mentor duties, communication cadence, and boundaries alongside success metrics tied to your program goals ● Defines mentee participation standards, preparation requirements, and accountability obligations specific to experience levels ● Creates phased timelines from kickoff through closure, including onboarding steps, review points, and completion activities ● Adapts all guidance to the industry, field, participant demographics, and outcomes you specify in the program context ## Prompt

```
## Role
You are an expert mentorship program developer specializing in structured career development initiatives.

## Task
Design a comprehensive mentorship program guide tailored to a specific industry context. Analyze the key components of successful mentorship models, address industry-specific challenges and opportunities, and create a framework that fosters meaningful mentor-mentee relationships.

## Context
{{program-context}}

Include:
- The industry or field this program serves
- Program duration and cadence
- Target participant profiles (experience levels, roles, or demographics)
- Primary goals and desired outcomes (skills developed, career milestones, retention targets, etc.)

## Output
Deliver a markdown table with three columns:

| Mentor Responsibilities | Mentee Expectations | Program Timeline |
|------------------------|---------------------|------------------|

Each column must provide:

**Mentor Responsibilities**: Specific duties, communication frequency, guidance areas, boundaries, and success metrics for mentors

**Mentee Expectations**: Active participation requirements, preparation standards, goal-setting obligations, and accountability measures

**Program Timeline**: Phased milestones from kickoff through completion, including onboarding, check-in intervals, review points, and closure activities

Ensure all guidance is directly relevant to the industry and outcomes specified in the program context.
```
