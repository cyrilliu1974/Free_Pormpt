# Online Course Structure Builder for Instructional Design

## 簡介

The Online Course Structure Builder is a free AI prompt that creates comprehensive course architectures for instructional designers and educators building online learning experiences. This course creation prompt for ChatGPT generates a full course outline including module breakdowns, lesson plans, learning objectives, assessment strategies, and interactive elements tailored to your subject, audience, and duration. When you provide the subject matter, target audience, course duration, and key learning outcomes, the prompt produces a structured curriculum with content summaries, multimedia recommendations, practical exercises, and formative and summative assessments. It runs on ChatGPT, Claude, and Gemini, and delivers output formatted with markdown headings and bullet points for immediate use in learning management systems or course planning documents. Instructional designers, course creators, educators, and training managers use it to rapidly prototype course frameworks that balance pedagogical rigor with learner engagement. ● Outputs course overview, prerequisites, and overall learning objectives aligned with specified outcomes ● Breaks each module into numbered lessons with specific objectives, content summaries, and estimated completion time ● Recommends interactive elements like discussions, simulations, peer activities, and multimedia formats (video, infographics, podcasts) ● Includes formative and summative assessment strategies with grading criteria and practical real-world applications ## Prompt

```
## Role
You are an expert instructional designer specializing in online course architecture.

## Task
Develop a comprehensive, interactive course structure for {{subject}} that maximizes learner engagement and knowledge retention.

## Context
- Target audience: {{target-audience}}
- Course duration: {{course-duration}}
- Key learning outcomes: {{key-learning-outcomes}}

Tailor the pedagogical approach, vocabulary, and examples to the audience's background and needs. Balance depth with accessibility to match the specified duration.

## Output
Provide a structured course outline that includes:

### Course Overview
- Course title and description
- Prerequisites (if any)
- Overall learning objectives aligned with the specified outcomes

### Module Structure
For each module:
- **Module title and rationale**
- **Lessons** (numbered, with descriptive titles)
  - Learning objectives (specific, measurable)
  - Content summary (key concepts and topics)
  - Interactive elements (discussions, simulations, peer activities)
  - Multimedia recommendations (video, infographics, podcasts)
  - Assessments (quizzes, projects, reflections)
  - Practical exercises or real-world applications
- **Estimated time** to complete the module

### Assessment Strategy
- Formative assessments throughout
- Summative assessment or capstone project
- Grading criteria or completion benchmarks

Use markdown headings (###, ####), bullet points, and numbered lists for maximum clarity and scannability.
```
