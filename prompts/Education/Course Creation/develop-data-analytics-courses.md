# Data Analytics Course Development Prompt

## 簡介

The Data Analytics Course Development Prompt is a free AI prompt that builds structured curriculum plans for instructors creating advanced data analytics certification programs. It produces a five-section course blueprint covering learning objectives, technology integration (SQL, Apache Spark, Power BI, AWS, Google Cloud, Azure), project-based assignments with multi-dimensional datasets, peer collaboration frameworks, and certification pathways aligned with career advancement. This data analytics course prompt for ChatGPT, Claude, and Gemini guides you through designing modules on predictive modeling, machine learning, A/B testing, time series analysis, customer segmentation, and financial forecasting, complete with capstone projects that solve real organizational challenges. Instructors building professional training programs, bootcamp coordinators adapting curricula to industry needs, and learning and development managers creating internal upskilling tracks will find this prompt saves weeks of curriculum design work. ● Structures course modules around advanced topics - predictive modeling, statistical hypothesis testing, data mining, experimentation design, and time series forecasting - with clear learning objectives for each. ● Maps professional-grade tools (SQL, Apache Spark, Power BI, cloud platforms) to specific use cases and curriculum integration points so learners gain hands-on experience. ● Defines project-based learning assignments using complex datasets, peer collaboration exercises, and industry mentor feedback sessions that prepare students for certification. ● Provides certification requirements, assessment rubrics, and career positioning strategies that connect course completion to professional advancement opportunities. ## Prompt

```
## Role
You are a seasoned data analytics instructor with extensive experience teaching advanced concepts and industry-specific applications.

## Task
Develop a comprehensive advanced certification course for data professionals seeking to enhance their skills in specialized industry applications. The course should prepare intermediate to advanced learners for professional certification and career advancement.

## Context
{{industry-and-learner-context}}

## Course Requirements
**Advanced Topics Coverage:**
- Predictive modeling and machine learning
- Statistical hypothesis testing
- Data mining techniques
- A/B testing and experimentation
- Time series analysis
- Customer segmentation
- Financial forecasting

**Tools and Technologies:**
- SQL and Apache Spark for data processing
- Power BI for visualization
- Cloud platforms (AWS, Google Cloud, Azure)

**Learning Approach:**
- Project-based learning using complex multi-dimensional datasets
- Peer collaboration exercises
- Industry mentor feedback sessions
- Capstone projects solving real organizational challenges

## Output
Provide a structured course development plan that includes:

1. **Course Structure** - Topics covered with specific learning objectives for each module
2. **Tools and Technologies** - How each tool will be integrated into the curriculum and which use cases it addresses
3. **Project-Based Learning** - Types of datasets, project formats, and how they map to real-world scenarios
4. **Collaboration and Feedback** - Mechanisms for peer interaction and mentor engagement throughout the course
5. **Certification Pathways** - Requirements for certification, assessment criteria, and how the course positions learners for career advancement

Format your plan using markdown headers, bullet points, and numbered lists for clarity.
```
