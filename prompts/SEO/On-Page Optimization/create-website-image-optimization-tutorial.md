# Website Image Optimization Tutorial Generator

## 簡介

The Website Image Optimization Tutorial Generator is a free AI prompt that creates structured, beginner-friendly tutorials teaching website owners how to reduce image file sizes, choose the right formats, implement responsive images, and write effective ALT text. This image optimization prompt for ChatGPT produces a six-section tutorial tailored to a specific website URL, walking through image selection, format choice (WebP, JPEG, PNG), compression techniques, responsive design methods, SEO-friendly ALT text practices, and testing workflows. It runs on ChatGPT, Claude, Gemini, and Grok, returning markdown-formatted instructions with numbered steps and sub-points. Web developers use it to document their optimization workflows, content creators use it to learn best practices without wading through technical jargon, and agencies use it to onboard clients on image performance. Reach for this prompt when you need a clear, actionable guide that balances image quality with page-load speed, written for audiences who may not have deep technical backgrounds. ● Covers six core areas: image selection, file format decisions, compression methods, responsive image techniques, ALT text best practices, and performance monitoring. ● Outputs markdown-formatted tutorials with numbered sections and sub-points for easy scanning and implementation. ● Explains concepts in plain language, making technical optimization accessible to content creators and small-business owners. ● Tailors recommendations to a specific website URL, ensuring relevance and immediate applicability. ## Prompt

```
## Role
You are an expert web developer specializing in image optimization, with deep knowledge of file formats, compression techniques, responsive design, and SEO best practices.

## Task
Create a comprehensive, step-by-step tutorial on optimizing images for {{website-url}}. The tutorial must cover:

1. Image Selection and Preparation
2. File Format Selection
3. Image Compression
4. Responsive Image Techniques
5. Effective ALT Text Usage
6. Testing and Monitoring

Each section should provide clear, actionable steps that website owners and content creators can follow immediately.

## Requirements
- Explain steps clearly for audiences with limited technical knowledge
- Focus on practical techniques that can be implemented quickly
- Use plain language; avoid unnecessary jargon
- Emphasize balancing image quality with file size for optimal performance
- Provide specific examples and recommendations where helpful

## Output
Format the tutorial as a numbered list for each main section, with sub-points for detailed explanations and examples. Use markdown formatting for readability.
```
