# Peer Review Session Agenda Builder

## 簡介

The Peer Review Session Agenda Builder is a free AI prompt that creates detailed, time-bound agendas for educational peer review sessions across any subject area. This peer review prompt for ChatGPT helps educators and facilitators design sessions with clearly defined time blocks, presenter guidelines, reviewer evaluation criteria, and facilitation notes that maintain momentum and respect. The prompt runs on ChatGPT, Claude, and Gemini, producing agendas that include introduction segments, individual presentation rounds with structured feedback, transitions, breaks for longer sessions, and time for synthesis or reflection. It specifies what presenters should prepare, how reviewers should evaluate work, and what materials participants need beforehand, ensuring every session component serves your learning objectives while accommodating all participants equally. ● Creates time-bound agendas with introduction, presentation rounds, feedback cycles, and conclusion segments tailored to your session parameters ● Provides explicit instructions for presenters on sharing work and for reviewers on evaluation criteria and constructive feedback techniques ● Includes facilitation notes and transition management to maintain a respectful, productive learning environment ● Specifies pre-session preparation and materials so participants arrive ready to contribute ## Prompt

```
## Role
You are an expert educational facilitator designing peer review sessions that balance participation, constructive feedback, and critical thinking.

## Task
Create a structured, time-bound agenda for a peer review session that ensures equal participation and a respectful learning environment.

## Context
**Subject:** {{subject}}
**Session parameters:** {{session-parameters}}
**Learning objectives:** {{learning-objectives}}

Design the session with well-paced time blocks that accommodate all participants. Include clear guidelines for both presenters (how to share work, what to prepare) and reviewers (how to give constructive feedback, what criteria to evaluate). Build in transitions, breaks if needed for longer sessions, and time for synthesis or reflection.

## Output
Deliver a detailed agenda with:
- Clearly defined time blocks for each segment (introduction, individual presentations with feedback rounds, conclusion)
- Specific instructions and expectations for presenters
- Specific instructions and evaluation criteria for reviewers
- Facilitation notes to maintain momentum and respect
- Any materials or preparation participants should complete beforehand
```
