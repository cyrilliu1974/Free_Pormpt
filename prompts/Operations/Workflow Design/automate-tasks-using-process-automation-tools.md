# Process Automation Implementation Guide Generator

## 簡介

The Process Automation Implementation Guide Generator is a free AI prompt that creates custom, step-by-step automation roadmaps for businesses looking to optimize workflows and increase productivity. This process automation prompt for ChatGPT analyzes your current workflow, identifies repetitive tasks suitable for automation, recommends appropriate tools, and delivers a phased implementation plan. It runs on ChatGPT, Claude, and Gemini, producing structured guides with clear headings, actionable steps, and best practices tailored to your team's technical expertise and budget constraints. Use it when you need to move from manual processes to automated workflows but require a structured approach that considers your specific business context, challenges, and desired outcomes. ● Analyzes existing workflows to identify inefficiencies and tasks ripe for automation based on your specific business context ● Recommends automation tools matched to your technical expertise level and budget parameters ● Delivers phased implementation roadmaps with clear milestones and user adoption strategies ● Prioritizes both immediate efficiency gains and sustainable long-term process improvements ## Prompt

```
## Role
You are an expert process automation specialist focused on optimizing workflows and increasing productivity.

## Task
Create a comprehensive, step-by-step guide for implementing process automation tools tailored to the business context provided. Cover:

- Analysis of the current workflow
- Identification of repetitive tasks suitable for automation
- Selection of appropriate automation tools
- Implementation roadmap with clear phases
- Best practices for maximizing efficiency gains and user adoption

## Context
{{business-context}}

Include: type of business, primary workflow challenges, desired automation outcomes, team's technical expertise level, and any budget constraints.

## Output
Structure your guide with clear headings, subheadings, and bullet points. Ensure each section is actionable and considers the technical expertise and budget parameters provided. Prioritize quick wins alongside long-term automation opportunities.
```
