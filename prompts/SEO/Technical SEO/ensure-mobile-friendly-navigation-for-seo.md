# Mobile Navigation SEO Optimization Prompt

## 簡介

The Mobile Navigation SEO Optimization Prompt is a free AI prompt that creates detailed mobile navigation strategies for web designers, developers, and SEO specialists working to improve mobile user experience and search rankings. This mobile navigation prompt for ChatGPT analyzes your website URL, target audience, current menu structure, main categories, and business type to deliver a seven-part optimization strategy. It runs on ChatGPT, Claude, Gemini, and Grok, producing actionable recommendations across responsive design requirements (breakpoints, touch targets, viewport settings), menu structure and information architecture, navigation pattern selection (hamburger, tab bar, priority+ models), labeling and microcopy guidelines, technical SEO implementation with semantic HTML and structured data, UX enhancements like search and breadcrumbs, and testing validation methods. Each section is tailored to your specific business context rather than generic advice. This prompt is for anyone redesigning a mobile site, auditing navigation performance, or addressing mobile usability issues flagged in search console reports. ● Provides responsive design specifications including breakpoint recommendations and touch-target sizing for accessibility ● Recommends navigation patterns (hamburger menu, tab bar, priority+) matched to your content volume and user behavior ● Delivers technical SEO implementation guidance covering semantic HTML5, crawlability considerations, and performance optimization ● Includes testing frameworks with usability methods, analytics tracking setup, and measurable success metrics ## Prompt

```
## Role
You are an expert web designer and SEO specialist focused on mobile navigation optimization.

## Task
Create a comprehensive plan to optimize the website's mobile navigation menu, improving user experience and SEO rankings through responsive design, user-friendly interface patterns, and technical SEO best practices.

## Context
Website URL: {{website-url}}
Target audience: {{target-audience}}
Current menu structure: {{current-menu-structure}}
Main categories: {{main-categories}}
Business type: {{business-type}}

## Output
Deliver your optimization strategy as a numbered list with clear subheadings covering:

1. **Responsive Design Requirements** – breakpoints, touch targets, viewport configuration
2. **Menu Structure & Information Architecture** – hierarchy, depth, grouping recommendations
3. **Navigation Patterns** – hamburger vs. tab bar vs. priority+ patterns, when to use each
4. **Labeling & Microcopy** – concise labels, icon usage, accessibility considerations
5. **Technical SEO Implementation** – semantic HTML, crawlability, structured data, performance
6. **User Experience Enhancements** – search functionality, breadcrumbs, quick actions
7. **Testing & Validation** – usability testing methods, analytics tracking, success metrics

For each section, provide specific, actionable recommendations tailored to the business context and audience provided.
```
