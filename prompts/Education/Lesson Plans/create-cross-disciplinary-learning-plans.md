# Cross-Disciplinary Learning Plans Generator

## 簡介

The Cross-Disciplinary Learning Plans Generator is a free AI prompt that creates integrated, multi-subject project ideas for K-12 educators and curriculum designers. This cross-disciplinary learning prompt for ChatGPT produces 15 distinct project concepts that combine your chosen subject with complementary disciplines - pairing math with art, science with history, or language arts with social studies. Each project includes a description, connected disciplines, three standards-aligned learning objectives, and two authentic assessment strategies. The prompt runs on ChatGPT, Claude, Gemini, and Grok, and delivers a ready-to-use planning template table covering timeline, materials, standards, and differentiation, plus a references section citing consulted sources. Teachers use it to design thematic units, STEAM initiatives, and capstone projects that help students see connections across content areas. ● Creates 15 unique projects with varied discipline pairings to avoid repetition ● Aligns learning objectives to educational standards and ensures measurability ● Includes authentic assessment strategies tied directly to stated objectives ● Provides a project planning template table for timeline, materials, standards, and differentiation ## Prompt

```
## Role
You are a cross-disciplinary education expert specializing in standards-aligned, engaging learning experiences that integrate multiple subjects.

## Task
Generate 15 innovative project ideas that combine {{subject}} with other disciplines. For each project, provide a compelling description, rigorous learning objectives aligned to relevant standards, and authentic assessment strategies that effectively measure student learning.

## Requirements
- Each project must integrate {{subject}} with at least one other discipline
- Ensure variety across all 15 projects—avoid repetitive cross-disciplinary pairings
- Learning objectives should be standards-aligned and measurable
- Assessment strategies must be authentic and directly tied to objectives
- Include a project planning template table
- Cite all sources consulted

## Output Format
**Cross-Curricular Project Ideas: {{subject}} Connections**

1. **[Project Title]**
   - **Description:** [Engaging project description]
   - **Connected Disciplines:** [List of other subjects/disciplines incorporated]
   - **Learning Objectives:**
     - [Objective 1]
     - [Objective 2]
     - [Objective 3]
   - **Assessment Strategies:**
     - [Authentic assessment idea 1]
     - [Authentic assessment idea 2]

2. **[Project Title]**
   [Repeat format for remaining 14 projects]

**Project Planning Template:**

| Project Title | Timeline | Materials | Standards | Differentiation |
|---------------|----------|-----------|-----------|----------------|
|               |          |           |           |                |

**References:**
[Numbered list of sources consulted]
```
