# Online Course Outline Builder for Solopreneurs

## 簡介

The Online Course Outline Builder for Solopreneurs is a free AI prompt that generates structured e-learning course outlines designed for passive income and scalability. This course creation prompt for ChatGPT takes your course context - target audience, topic, expertise level, duration, and income goals - and builds a complete outline with clear module progression, interactive elements like quizzes and case studies, practical exercises, and assessment points. It runs on ChatGPT, Claude, Gemini, and Grok, organizing content so learners systematically build knowledge while requiring minimal ongoing instructor involvement. Real use cases include solopreneurs launching their first digital product, coaches packaging expertise into self-paced programs, and subject-matter experts transitioning to online education. Reach for this prompt when you need to transform your knowledge into a monetizable course structure but lack instructional design experience. ● Builds logical content progression that systematically develops learner skills from foundational concepts to advanced application ● Embeds interactive elements - quizzes, case studies, practical exercises - at strategic points to reinforce retention and engagement ● Allocates time estimates per section and specifies deliverables so you can scope production effort accurately ● Designs for passive scalability by minimizing elements that require live instruction or ongoing manual grading ## Prompt

```
## Role
You are an expert online course creator specializing in designing e-learning programs that generate passive income for solopreneurs.

## Task
Create a comprehensive course outline that is engaging, informative, and structured for easy implementation. The outline must balance theoretical knowledge with hands-on application to maximize value for learners.

## Context
{{course-context}}

Include in your course context:
- Target audience (who they are, their skill level, pain points)
- Course topic and scope
- Your expertise level in the subject
- Desired course duration (hours, weeks, or modules)
- Primary income goal

## Requirements
- Organize content with clear logical progression that builds knowledge systematically
- Incorporate interactive elements: quizzes, case studies, and practical exercises that reinforce learning
- Balance theory with hands-on application throughout each module
- Design for passive income scalability (minimal ongoing instructor involvement)
- Include assessment points to track learner progress

## Output
Deliver a structured course outline using:
- Clear module/section headings
- Subheadings for lessons or units
- Bullet points detailing content, activities, and deliverables
- Estimated time allocation per section
- Specific interactive elements and exercises for each module
```
