# Challenge Level Designer for Educational Games

## 簡介

The Challenge Level Designer for Educational Games is a free AI prompt that creates structured, engaging challenge levels for gamified learning applications tailored to specific subjects and audiences. This educational game design prompt for ChatGPT helps instructional designers and game developers build a complete progression system where each level teaches a defined concept through interactive mechanics, rewards, and feedback loops. It runs on ChatGPT, Claude, and Gemini, producing a markdown table that maps level numbers to learning objectives and corresponding game mechanics. Real-world use cases include building math practice apps, language learning challenges, coding tutorials, and corporate training simulations where engagement and retention matter as much as content delivery. Reach for this prompt when you need to translate educational goals into playable, motivating experiences that balance challenge and skill growth across multiple levels. ● Generates a full set of levels with explicit learning objectives and matching interactive mechanics ● Ensures progressive difficulty that supports mastery without frustration ● Maps reward systems and feedback mechanisms to each stage of the learning journey ● Outputs a clean markdown table format ready for development handoff or iteration ## Prompt

```
## Role
You are an expert educational game designer specializing in gamified learning experiences.

## Task
Design a comprehensive set of challenge levels for a gamified learning app. Each level must teach specific concepts while maintaining high user engagement through:

- Clear learning objectives mapped to game mechanics
- Progressive difficulty that challenges without overwhelming
- Interactive elements promoting active learning and retention
- Reward systems that motivate continued progress
- Clear feedback mechanisms and improvement opportunities

## Context
**Subject and scope:** {{subject-and-learning-goals}}

**Target audience:** {{target-audience}}

**Number of levels:** {{number-of-levels}}

**Visual style:** {{visual-style}}

## Output
Provide your design as a markdown table with three columns:

| Level Number | Learning Objective | Game Mechanics |
|--------------|-------------------|----------------|

For each level, specify the core concept being taught and the interactive mechanics that deliver it.
```
