# Peer Feedback Template Generator

## 簡介

The Peer Feedback Template Generator is a free AI prompt that creates comprehensive peer evaluation frameworks designed to preserve relationships while delivering honest, actionable insights. This peer feedback template prompt for ChatGPT, Claude, Gemini, and Grok produces multiple template variations grounded in David Stone and Sheila Heen's Feedback Conversations Model. Each template incorporates three core feedback elements - appreciation, coaching, and evaluation - and structures them into distinct sections for strengths, improvement areas, and forward-looking suggestions. The prompt emphasizes separating person from performance, focusing feedback on specific behaviors rather than personality traits, and includes implementation guidance to help teams adopt the templates in psychologically safe conversations. Real use cases include quarterly peer reviews, 360-degree evaluations, project retrospectives, and ad-hoc performance discussions across diverse team dynamics and organizational cultures. Managers, HR professionals, team leads, and organizational development specialists use this prompt when building or refining feedback systems that balance candor with respect. ● Produces multiple template variations with clear headings, organized sections (appreciation, coaching, evaluation), and question frameworks that elicit concrete observations ● Separates person from performance by guiding feedback toward specific behaviors and outcomes rather than character judgments ● Balances honest assessment with relationship preservation through psychologically safe language and structured conversation flows ● Includes implementation guidance for adoption, ensuring teams can put templates into practice immediately ## Prompt

```
## Role
You are an organizational psychologist and feedback systems designer specializing in peer evaluation frameworks grounded in David Stone and Sheila Heen's Feedback Conversations Model.

## Task
Create comprehensive peer feedback templates that incorporate the three core elements of effective feedback conversations: appreciation, coaching, and evaluation. Design multiple template variations adaptable to different team dynamics and organizational cultures.

## Context
{{team-and-feedback-context}}

Each template must:
- Balance honest assessment with relationship preservation
- Separate person from performance, focusing on specific behaviors rather than personality traits
- Provide actionable insights through structured question frameworks
- Include distinct sections for strengths, improvement areas, and forward-looking suggestions
- Guide both feedback giver and receiver through psychologically safe, productive conversations
- Offer concrete, respectful suggestions that honor individual working styles

## Output
Provide multiple template variations, each structured with:
- Clear template heading and use case
- Organized sections (appreciation, coaching, evaluation)
- Specific question frameworks that elicit concrete observations
- Implementation guidance for adoption

Format each template for immediate usability with visual clarity and logical flow.
```
