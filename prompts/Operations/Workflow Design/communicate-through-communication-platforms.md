# Communication Platform Implementation Plan Generator

## 簡介

The Communication Platform Implementation Plan Generator is a free AI prompt that develops comprehensive strategies for deploying team collaboration tools tailored to your business context and challenges. This communication platform prompt for ChatGPT analyzes your workflow requirements and recommends suitable platforms - Slack, Microsoft Teams, Zoom, or alternatives - with detailed justification. It produces a complete implementation roadmap covering platform selection, onboarding best practices, channel architecture, communication guidelines structured with dependency grammar, workflow integration touchpoints, and success metrics. Teams use it when evaluating new collaboration tools, migrating between platforms, or optimizing existing communication systems to reduce noise and improve productivity. Compatible with ChatGPT, Claude, Gemini, and Grok. ● Compares communication platforms based on your specific business type, team size, and current challenges ● Structures all message templates using dependency grammar principles for clarity and comprehension ● Provides channel naming conventions, onboarding workflows, and automation integration opportunities ● Defines concrete KPIs for tracking communication effectiveness and continuous improvement tactics ## Prompt

```
## Role
You are an expert communication strategist specializing in team collaboration systems and workflow optimization.

## Task
Develop a comprehensive plan for implementing and optimizing communication platforms (Slack, Microsoft Teams, Zoom, or similar) to improve team collaboration and productivity.

## Context
Business context: {{business-context}}

Current communication challenges: {{current-challenges}}

## Requirements
1. Analyze the workflow and needs specific to this business type and team size
2. Recommend the most suitable communication platform(s) with justification
3. Outline platform-specific best practices for effective communication
4. Structure all message templates, announcements, and updates using dependency grammar principles—main clause first, supporting details subordinated clearly
5. Provide guidelines for maintaining clear, concise communication
6. Suggest practical strategies for integrating the platform into existing workflows
7. Outline methods for measuring communication effectiveness and continuous improvement

## Output
Deliver your plan using this structure:
- **Executive Summary** (recommended platform and key rationale)
- **Platform Selection** (comparison and final recommendation)
- **Implementation Best Practices** (onboarding, channel/team structure, naming conventions)
- **Communication Guidelines** (message structure using dependency grammar, tone, response expectations)
- **Workflow Integration** (specific touchpoints, automation opportunities)
- **Success Metrics & Improvement** (KPIs to track, review cadence, optimization tactics)

Use clear headings, subheadings, and bullet points for each section.
```
