# Website Error Page Optimization Prompt

## 簡介

The Website Error Page Optimization Prompt is a free AI prompt that creates comprehensive error page strategies for websites, turning broken links and server errors into engagement opportunities. This website error page optimization prompt for ChatGPT guides you through a seven-step implementation plan covering audit, design, messaging, navigation, interactivity, SEO configuration, and analytics tracking. You provide your website URL and site structure, and the prompt returns specific recommendations for 404, 500, and 503 error pages that maintain brand consistency, reduce visitor frustration, and retain traffic. It runs on ChatGPT, Claude, Gemini, and Grok, delivering actionable advice on user-friendly layouts, clear error explanations, strategic internal linking, search functionality, and correct HTTP status codes. Use it when redesigning error pages, improving UX metrics, or implementing retention strategies for technical issues. ● Audits existing error pages and identifies gaps in guidance, navigation, and branding ● Provides step-by-step design and messaging recommendations in plain language that reduces user frustration ● Includes strategic navigation elements, search bars, and interactive reporting buttons tailored to your site structure ● Delivers SEO optimization guidance with correct HTTP status codes, meta descriptions, and keyword integration ● Sets up analytics tracking frameworks to monitor error page performance and refine retention strategies over time ## Prompt

```
## Role
You are an expert website strategist specializing in error page optimization for user experience and visitor retention.

## Task
Create a comprehensive error page optimization strategy for the user's website. Provide a step-by-step implementation guide that transforms error pages (404, 500, etc.) into retention tools that maintain visitor engagement when they encounter broken links or server issues.

## Context
Website: {{website-url}}
Key navigation structure: {{site-structure}}

Include main categories, popular pages, and any unique site features that should be reflected in error page navigation.

## Output
Deliver a structured implementation guide covering:

### Step 1: Audit Current Error Pages
- Identify all existing error pages (404, 500, 503) and assess their design, messaging, and functionality
- Document gaps in user guidance, navigation options, and brand consistency

### Step 2: Design User-Friendly Error Pages
- Create a clean, visually appealing layout consistent with site branding
- Ensure mobile responsiveness and fast load times
- Maintain visual hierarchy that guides users toward solutions

### Step 3: Craft Clear Error Messages
- Explain errors in simple, non-technical language with a brief apology
- Provide actionable next steps tailored to the error type
- Use friendly tone that reduces user frustration

### Step 4: Add Strategic Navigation
- Link to homepage, main categories, and top-performing pages specific to this site
- Include a functional search bar
- Consider adding a condensed sitemap or popular content section

### Step 5: Implement Interactive Elements
- "Report a Problem" button to capture broken link data
- "Try Again" / "Refresh" option for server errors
- "Contact Support" link with context about the error

### Step 6: Optimize for Search Engines
- Configure correct HTTP status codes (404 for not found, 503 for server issues)
- Write custom page titles and meta descriptions for each error type
- Include relevant site keywords naturally in error page content

### Step 7: Monitor and Iterate
- Set up analytics tracking for error page visits, bounce rates, and navigation paths
- Review data monthly to identify recurring broken links and user behavior patterns
- Refine messaging and navigation based on performance data

For each step, provide specific implementation details, design recommendations, and examples of effective error page elements.
```
