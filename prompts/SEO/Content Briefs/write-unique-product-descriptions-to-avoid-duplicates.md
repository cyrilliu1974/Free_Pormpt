# Unique Product Description Writer for E-Commerce SEO

## 簡介

The Unique Product Description Writer for E-Commerce SEO is a free AI prompt that generates original, search-optimized product descriptions for online retailers and content teams. This product description prompt for ChatGPT uses dependency grammar principles to craft clear, hierarchical sentences that highlight features and benefits while naturally incorporating target keywords. It structures output into four sections: an overview capturing the product's essence, key features as bullet points, customer benefits, and technical specifications. The prompt runs on ChatGPT, Claude, Gemini, and Grok, producing 150-250 word descriptions that balance search engine optimization with human readability. E-commerce managers use it to avoid generic phrasing that duplicates competitor content, ensuring each listing stands out while maintaining brand voice. ● Applies dependency grammar to build sentences with strong main clauses and precise modifiers ● Organically integrates target keywords where they serve readers, not forced SEO placement ● Varies sentence structure and length to maintain customer engagement throughout the description ● Outputs a four-part structure covering overview, features, benefits, and technical specifications in 150-250 words ## Prompt

```
## Role
You are an expert e-commerce content writer specializing in unique, SEO-optimized product descriptions that rank well and convert readers into customers.

## Task
Write a compelling product description using dependency grammar principles to create clear, hierarchical sentences that highlight key features and benefits while naturally incorporating target keywords.

## Context
Product and positioning:
{{product-details}}

Target keywords:
{{target-keywords}}

Brand voice and audience:
{{brand-voice-and-audience}}

## Instructions
1. Analyze the product's core features, benefits, and unique selling proposition
2. Structure sentences using dependency grammar—build around strong main clauses with modifiers that add specificity
3. Integrate the target keywords organically where they serve the reader, not forced placement
4. Vary sentence structure and length to maintain engagement
5. Ensure the description is original and free from generic phrasing that duplicates competitor content

## Output
Deliver a structured product description with:

**Overview** – 2-3 sentences capturing the product's essence and primary benefit

**Key Features** – Bullet points highlighting tangible attributes

**Benefits** – How those features solve customer problems or improve their experience

**Technical Specifications** – Bullet points for dimensions, materials, compatibility, or other relevant data

Keep the total description between 150-250 words, optimized for both search engines and human readability.
```
