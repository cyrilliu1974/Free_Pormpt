# Email Automation Workflow Implementation Prompt

## 簡介

The Email Automation Workflow Implementation Prompt is a free AI prompt that designs end-to-end email automation systems based on subscriber behavior and customer journey stages for marketers and email strategists. This email automation prompt for ChatGPT walks through audience mapping, lead nurturing strategy, behavioral trigger setup, and A/B testing protocols tailored to your business context and email platform. It produces workflow diagrams, email template outlines structured with dependency grammar for maximum readability, trigger conditions with timing specifications, and a complete measurement framework with KPIs and optimization loops. Marketers use it to build welcome sequences, cart abandonment campaigns, re-engagement workflows, and multi-stage nurture tracks that align content with customer decision points. It runs on ChatGPT, Claude, Gemini, and Grok, adapting recommendations to platforms like Mailchimp, HubSpot, ActiveCampaign, or Klaviyo. Reach for this prompt when you need to move beyond one-off email blasts and implement systematic, behavior-responsive automation that guides subscribers through the customer journey with the right message at the right time. ● Maps customer journey stages and identifies behavioral triggers that should activate each automated email in the sequence ● Structures email content using dependency grammar principles to improve scanability, comprehension, and engagement rates ● Defines A/B testing protocols with sample size requirements, success criteria, and elements to test across subject lines, timing, and CTAs ● Establishes KPI dashboards, benchmarks, and monthly optimization loops to continuously refine workflow performance based on open rates, conversions, and revenue per email ## Prompt

```
## Role
You are an expert email marketing strategist specializing in automation workflows and behavior-driven campaigns.

## Task
Design a complete email automation workflow that triggers targeted messages based on subscriber behavior and preferences. Structure all email content using dependency grammar principles to maximize readability and engagement.

## Context
{{business-context}} describes the business type, target audience, primary marketing goals, and brand voice.

Current email marketing platform: {{email-platform}}

## Process
1. **Audience & Journey Mapping**: Analyze the target audience and map the customer journey stages relevant to this business. Identify key decision points and information needs at each stage.

2. **Lead Nurturing Strategy**: Develop a multi-touch nurturing sequence aligned with the customer journey. Define the objective and timing for each touchpoint.

3. **Email Series Design**: Create a series of email templates that reflect the brand voice and advance the marketing goals. Each template should have a clear purpose (welcome, education, conversion, retention, re-engagement).

4. **Behavioral Triggers**: Specify the subscriber actions or inactions that will trigger each automated email (e.g., sign-up, download, cart abandonment, engagement drop-off, purchase).

5. **Dependency Grammar Structure**: For each email, apply dependency grammar to organize sentences around core actions and benefits. Lead with the main clause, then add supporting details. This improves scanability and comprehension.

6. **A/B Testing Protocol**: Define which elements to test (subject lines, send times, content variations, CTAs). Establish sample size requirements and success criteria.

7. **KPIs & Measurement**: Set specific KPIs for the workflow (open rate, click-through rate, conversion rate, revenue per email, unsubscribe rate). Define benchmarks and reporting cadence.

8. **Optimization Loop**: Create a monthly review process to analyze performance data, gather qualitative feedback, and implement refinements to content, timing, and segmentation.

## Output
Provide a detailed, step-by-step implementation plan with specific recommendations for each stage. Include:
- Workflow diagram or sequence description
- Email template outlines with dependency grammar examples
- Trigger conditions and timing
- Testing and optimization roadmap
- Success metrics dashboard
```
