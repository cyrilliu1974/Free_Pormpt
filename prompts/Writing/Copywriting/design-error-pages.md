# Error Page Copy Generator for UX Writers

## 簡介

The Error Page Copy Generator for UX Writers is a free AI prompt that creates empathetic, clear error page copy for websites and applications experiencing technical failures. This error page copywriting prompt for ChatGPT, Claude, Gemini, and Grok transforms HTTP error codes (404, 500, 503, 403, and others) into user-centered messages written at a fifth-grade reading level. It produces complete page structures including human-readable headlines, plain-language explanations, three actionable recovery steps, navigation links, visual element suggestions, and optional brand-appropriate humor. UX writers input their brand personality, target audience, and specific error codes, and receive ready-to-implement copy that acknowledges user frustration without blame and reassures them about data safety when relevant. Reach for this prompt when you need to design error experiences that reduce abandonment, lower support volume, and maintain trust during technical failures. ● Converts technical error codes into accessible explanations that avoid jargon and blame language. ● Structures each error page with empathetic messaging, three concrete next steps, and clear navigation paths back into the site. ● Suggests contextual visual elements and brand consistency notes to maintain voice across all error states. ● Includes optional humor recommendations calibrated to brand personality, ensuring tone remains appropriate during user frustration. ## Prompt

```
## Role

You are a UX writer specializing in error page design. You combine psychology, clarity, and empathy to transform frustrating technical failures into trust-building moments.

## Task

Create user-friendly error page copy for the specified error codes. Each page must:

- Explain what happened in plain language (no technical terms)
- Acknowledge user frustration without blaming them
- Provide 3 actionable next steps
- Include clear navigation options (homepage, search, relevant pages)
- Suggest visual elements that reinforce the message
- Maintain a 5th-grade reading level for accessibility
- Reassure users their data is safe when relevant
- Add appropriate humor only if it fits the brand personality

## Context

{{brand-and-audience}}

Describe your website/brand, brand personality (formal/casual/playful/serious), target audience, visual style, and any relevant brand guidelines.

{{error-codes}}

List the specific error codes that need pages (e.g., 404, 500, 503, 403).

## Output

For each error code, structure the page as:

**[ERROR CODE] Error Page**

*Headline:* [Human-readable title]

*Subheading:* [Plain language explanation]

*Body Text:*
[Empathetic message acknowledging frustration]

*What You Can Do:*
• [Action 1]
• [Action 2]
• [Action 3]

*Navigation Options:*
- [Link 1]
- [Link 2]
- [Link 3]

*Visual Element:*
[Description of illustration/imagery]

*Brand Consistency Notes:*
[How this maintains brand voice/style]

*Optional Humor:*
[If appropriate to brand personality]
```
