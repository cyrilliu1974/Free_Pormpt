# Educational Ice-Breaker Activities Generator

## 簡介

The Educational Ice-Breaker Activities Generator is a free AI prompt that creates subject-specific ice-breaker activities for curriculum developers and educators. This ice-breaker activity prompt for ChatGPT produces 15 complete activities customized to any subject you specify, from mathematics to literature to science. Each activity includes a concise description, estimated time requirement, 2-3 learning objectives, and appears in both a numbered list and a comprehensive planning table that details required materials, preparation steps, and facilitation notes. The prompt works on ChatGPT, Claude, Gemini, and Grok, and automatically cites the sources used in generating the activities. Educators use it to design engaging class openers that encourage active learning, build classroom community, and introduce subject concepts in memorable ways. ● Delivers 15 distinct ice-breaker activities per subject with clear learning objectives aligned to educational goals ● Provides a structured planning table with materials lists, preparation workflows, and facilitator guidance for easy implementation ● Creates activities that promote active engagement and foster interactive learning environments from the first moments of class ● Includes source citations for all generated content, supporting evidence-based curriculum design ## Prompt

```
## Role
You are an expert curriculum designer specializing in engaging, educational activities for diverse subjects and age groups.

## Task
Generate 15 captivating ice-breaker activities tailored for {{subject}}. For each activity, provide:
- A concise description
- Estimated time required
- 2-3 intended learning objectives

Present the activities in a numbered list, followed by a comprehensive activity planning table detailing materials needed, preparation steps, and facilitation notes for each activity. Cite all sources used in your research.

## Requirements
- Activities must be engaging, educational, and appropriate for the subject
- Create a diverse range that promotes active learning and engagement
- Ensure all activities are practical and feasible to implement

## Output Format

**Ice-Breaker Activities for [Subject] Classes**

1. **[Activity Name]**
   - Description: [Brief description]
   - Time Required: [Estimated time]
   - Learning Objectives:
     - [Objective 1]
     - [Objective 2]
     - [Objective 3]

2. **[Activity Name]**
   - Description: [Brief description]
   - Time Required: [Estimated time]
   - Learning Objectives:
     - [Objective 1]
     - [Objective 2]

[Continue for all 15 activities]

**Activity Planning Table:**

| Activity Name | Materials Needed | Preparation Steps | Facilitation Notes |
|---------------|------------------|-------------------|--------------------|  
| [Activity 1]  | [Materials]      | [Steps]           | [Notes]            |
| [Activity 2]  | [Materials]      | [Steps]           | [Notes]            |
| ...           | ...              | ...               | ...                |

**References:**
1. [Citation]
2. [Citation]
3. [Citation]
[Continue for all sources]
```
