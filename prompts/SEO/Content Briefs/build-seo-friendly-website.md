# SEO Strategy Builder for Solopreneur Websites

## 簡介

The SEO Strategy Builder for Solopreneur Websites is a free AI prompt that creates a complete, prioritized search engine optimization roadmap for independent business owners and solo entrepreneurs. This SEO strategy prompt for ChatGPT walks through ten essential optimization areas - keyword research, on-page elements, content strategy, site structure, mobile responsiveness, performance optimization, backlink development, schema markup, local SEO, and analytics tracking - and returns specific, implementable recommendations for each. You provide your business and site context, and the prompt generates a structured plan that explains why each tactic matters, what steps to take, how to execute them, and which improvements deliver the highest ROI. It runs on ChatGPT, Claude, Gemini, and Grok, making it easy to adapt the strategy to different AI workflows. Use this prompt when you need a full-scope SEO audit and action plan without hiring an agency, or when you want to validate your current optimization priorities against best practices. ● Covers all core SEO disciplines - technical, on-page, off-page, content, and local - in a single structured output ● Explains the ranking impact and traffic benefit of each recommendation so you understand what to tackle first ● Provides concrete implementation steps, not vague advice, so you can hand tasks directly to a developer or execute them yourself ● Tags every recommendation with a High, Medium, or Low priority level based on expected return on investment ## Prompt

```
## Role
You are an expert SEO strategist and web developer specializing in solopreneur websites.

## Task
Create a comprehensive SEO strategy to boost online visibility, improve search engine rankings, and drive organic traffic.

## Context
Business and site details:
{{business-and-site-context}}

Develop actionable recommendations across these optimization areas:

1. **Keyword Research** – Identify high-value search terms, analyze competition, map keywords to content intent
2. **On-Page Elements** – Optimize title tags, meta descriptions, header hierarchy, URL structure, image alt text
3. **Content Strategy** – Create relevant, authoritative content that addresses user intent and incorporates target keywords naturally
4. **Site Structure** – Design intuitive navigation, internal linking, and information architecture
5. **Mobile Responsiveness** – Ensure seamless experience across devices with responsive design
6. **Performance Optimization** – Improve page load speed through compression, caching, CDN, and code optimization
7. **Backlink Strategy** – Build quality inbound links through outreach, content marketing, and digital PR
8. **Schema Markup** – Implement structured data for rich snippets (Organization, LocalBusiness, Product, FAQ, etc.)
9. **Local SEO** – Optimize Google Business Profile, local citations, NAP consistency, and location-based content
10. **Analytics & Tracking** – Set up Google Analytics, Search Console, conversion tracking, and KPI dashboards

## Output
For each optimization area above, provide:
- **Why it matters** – Impact on rankings and traffic
- **Specific recommendations** – Concrete actions tailored to the business context
- **Implementation steps** – How to execute each recommendation
- **Priority level** – High/Medium/Low based on expected ROI

Format your response with clear headings (##) for each of the 10 areas, followed by bulleted recommendations and implementation guidance.
```
