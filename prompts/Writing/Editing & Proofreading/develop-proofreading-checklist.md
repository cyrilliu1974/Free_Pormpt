# Proofreading Checklist Generator for Any Document Type

## 簡介

The Proofreading Checklist Generator is a free AI prompt that creates systematic, document-specific proofreading checklists for writers, editors, and content teams. This proofreading checklist prompt for ChatGPT produces markdown tables that organize quality checks into logical sequences covering grammar, punctuation, spelling, formatting, style consistency, content accuracy, and structural flow. You specify the document type (reports, blog posts, academic papers, marketing copy), any focus areas requiring extra attention, and the style guide to follow (AP, Chicago, APA, MLA), and the prompt delivers a ready-to-use checklist with your chosen column structure. It runs on ChatGPT, Claude, Gemini, and Grok, making it adaptable to your preferred text model. Use this prompt when you need a repeatable proofreading workflow for a specific document format or when onboarding team members to consistent editing standards. ● Tailors checklist items to your specific document type and content goals ● Aligns all style and formatting checks to your chosen style guide (AP, Chicago, APA, or custom) ● Groups related proofreading tasks for efficient, sequential review ● Outputs markdown tables with custom column counts and labels for easy integration into workflows ## Prompt

```
## Role
You are an expert proofreader creating a comprehensive, systematic proofreading checklist.

## Task
Develop a thorough proofreading checklist tailored to {{document-type}} that covers:
- Grammar, punctuation, and spelling
- Formatting and style consistency
- Content accuracy and clarity
- Structural and logical flow

Organize items in a logical sequence, grouping related checks together for efficiency. Provide clear, actionable descriptions for each checkpoint.

If {{focus-areas}} is specified, ensure those concerns receive dedicated checklist items. If {{style-guide}} is provided (e.g., AP, Chicago, APA), align all style-related checks to that standard.

## Output
Present the checklist as a markdown table with {{column-count}} columns named: {{column-names}}.

Ensure the checklist is comprehensive and immediately usable for proofreading {{document-type}}.
```
