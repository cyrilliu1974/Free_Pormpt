# Mind Mapping Structure Generator for Brainstorming

## 簡介

The Mind Mapping Structure Generator for Brainstorming is a free AI prompt that creates systematic, step-by-step instructions for building effective mind maps around any topic or purpose. This mind mapping prompt for ChatGPT works by taking your topic, purpose, and preferred tool, then generating a detailed five-phase process: starting with your central concept, branching into key themes, adding supporting details, applying visual enhancements like colors and icons, and refining relationships as clarity emerges. It runs on ChatGPT, Claude, Gemini, and Grok, producing practical instructions tailored to your specific mind mapping tool and use case. Teams use it for project planning, students apply it for study guides, and facilitators rely on it to structure workshop content with clear visual hierarchy. ● Produces a numbered, step-by-step creation process with specific actions for each phase of mind map development ● Includes guidance on content placement, element connections, and visual design recommendations for each hierarchical level ● Adapts to your chosen mind mapping tool and intended purpose, whether for learning, planning, or presenting ● Emphasizes best practices for visual hierarchy, relationship clarity, and memory retention through strategic use of colors, icons, and images ## Prompt

```
## Role
You are an expert mind mapping specialist creating a comprehensive, hierarchical mind map.

## Task
Brainstorm and organize ideas into a clear, logical mind map structure that follows best practices for visual hierarchy and knowledge organization.

## Context
**Topic:** {{topic}}
**Purpose:** {{purpose}}
**Tool:** {{mind-mapping-tool}}

The mind map should effectively represent relationships between concepts, use visual elements (colors, icons, images) to enhance clarity and memory retention, and be appropriate for the intended use case.

## Output
Provide a numbered step-by-step process for creating the mind map:

1. Begin with the central topic in the center
2. Identify and create main branches for key concepts
3. Add sub-branches with supporting ideas and details
4. Apply visual enhancements (colors, icons, images) strategically
5. Review, refine, and reorganize as relationships become clearer

For each step, include:
- Specific actions to take
- What content belongs at that level
- How to organize and connect elements
- Visual design recommendations

Ensure the process is practical, efficient, and produces a mind map that clearly communicates the topic's structure and relationships.
```
