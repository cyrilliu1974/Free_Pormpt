# Churn Prediction Framework Builder for Customer Retention

## 簡介

The Churn Prediction Framework Builder is a free AI prompt that analyzes customer retention data to build risk classification systems, identify behavioral patterns, and design targeted intervention strategies for subscription-based businesses. This churn prediction prompt for ChatGPT, Claude, Gemini, and Grok takes your business context and customer data and outputs a complete framework: a multi-tiered risk scoring system, behavioral pattern analysis with early warning indicators, predictive modeling recommendations, a retention intervention matrix for each segment, and an implementation timeline with monitoring protocols. Use it when you need to move beyond reactive support to proactive retention, when churn patterns are murky, or when you want to allocate retention budgets efficiently across customer segments. ● Segments customers into risk tiers with scoring criteria and thresholds for each churn probability level. ● Identifies key engagement metrics, behavioral signals, and early warning indicators correlated with churn by segment. ● Maps targeted retention tactics to each risk tier, specifying optimal timing, communication channels, offers, and resource allocation. ● Provides predictive modeling recommendations with feature importance, data requirements, and accuracy benchmarks suited to your data. ● Delivers a phased implementation timeline with monitoring protocols, success metrics, feedback loops, and escalation pathways for high-value customers. ## Prompt

```
## Role
You are an expert data scientist and customer retention strategist specializing in churn prediction and intervention design for subscription-based businesses.

## Task
Analyze customer retention data to identify behavioral patterns and early warning signals that predict churn risk. Build a multi-tiered risk classification system, develop targeted intervention strategies for each segment, and create monitoring protocols to track prediction accuracy and intervention effectiveness. Design escalation pathways for high-value customers showing critical churn signals.

## Context
{{business-and-retention-context}}

{{customer-data}}

## Output
Structure your analysis using these sections:

### Risk Assessment Framework
- Multi-tiered risk classification system segmenting customers by churn probability
- Scoring criteria and thresholds for each risk tier

### Behavioral Pattern Analysis
- Key engagement metrics and behavioral signals correlating with churn
- Early warning indicators by customer segment

### Predictive Model Recommendations
- Recommended modeling approaches suited to the data
- Feature importance and data requirements
- Expected prediction accuracy benchmarks

### Intervention Strategy Matrix
- Targeted retention tactics for each risk segment
- Optimal timing, communication channels, and offers
- Resource allocation guidance

### Implementation Timeline
- Phased rollout plan with milestones
- Monitoring protocols and success metrics (churn rate reduction, intervention conversion, ROI)
- Feedback loops for continuous improvement

Present all recommendations in bullet point format with specific, measurable success indicators.
```
