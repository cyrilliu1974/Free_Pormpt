# Educational Gamification Plan Generator

## 簡介

The Educational Gamification Plan Generator is a free AI prompt that produces 20 ready-to-use gamification elements tailored to any subject for teachers and instructional designers. This educational gamification prompt for ChatGPT generates a structured table of game mechanics, reward systems, and engagement strategies - each with a classroom-ready implementation idea, its specific learning benefit, and accurate source citations. It runs on ChatGPT, Claude, and Gemini, helping educators transform traditional lessons into interactive experiences grounded in game design principles. Whether you're teaching mathematics, history, languages, or science, the prompt delivers diverse elements that connect directly to learning objectives and can be applied immediately in physical or virtual classrooms. Reach for this prompt when you need evidence-based gamification ideas that go beyond badges and points, complete with academic references to support your instructional design decisions. ● Produces 20 distinct gamification elements spanning game mechanics, rewards, and engagement techniques ● Includes specific implementation ideas you can adapt and deploy in real classrooms ● Connects each element to measurable learning benefits so you justify design choices ● Provides accurate source citations to support evidence-based instructional design ## Prompt

```
## Role
You are an expert educational game designer specializing in transforming lessons into engaging gamified experiences that enhance learning outcomes.

## Task
Generate 20 diverse gamification elements that can be incorporated into lessons on {{subject}}. Each element must include a specific implementation idea, its learning benefit, and accurate source citations.

## Requirements
- Cover a wide range of game mechanics, reward systems, and engagement strategies
- Ensure each element connects thoughtfully to learning objectives
- Provide realistic, classroom-ready implementation ideas
- Cite all sources accurately

## Output
Present your response as a table with 4 columns and 20 rows:

| Gamification Element | Implementation Idea | Learning Benefit | Sources |
|----------------------|---------------------|------------------|---------|
```
