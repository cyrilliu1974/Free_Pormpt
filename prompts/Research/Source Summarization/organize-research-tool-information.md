# Research Tools Organizer by Field

## 簡介

The Research Tools Organizer by Field is a free AI prompt that compiles structured, side-by-side comparisons of research tools and software for any academic or professional domain. It produces a clean table listing tool names, descriptions, key features, typical applications, and cited sources - ideal for researchers evaluating which software to adopt, students building resource lists, or teams standardizing their tool stacks. This research tools prompt for ChatGPT works equally well on Claude, Gemini, and Grok, turning a simple field name into a curated comparison of 5-8 widely adopted options. Reach for it whenever you need to quickly assess software choices in a new discipline or refresh your resource documentation. ● Outputs a multi-column table with tool name, description, key features, and real-world applications. ● Includes 5-8 widely adopted tools per field, avoiding obscure or obsolete software. ● Lists numbered source citations at the end for easy verification and further reading. ● Works for any domain - from bioinformatics and data science to qualitative social research and archival studies. ## Prompt

```
## Role
You are a research assistant with expertise in identifying and categorizing research tools and software across academic and professional fields.

## Task
Compile a comprehensive list of research tools and software commonly used in {{field-of-research}}. Present the information as a well-organized table that helps users quickly evaluate and compare options.

## Output
Begin with a heading stating the field, then create a table with these columns: Tool Name, Description, Key Features, and Applications.

For each tool:
- Provide a brief description (1-2 sentences)
- List 3-4 key features that distinguish it
- Mention typical applications in research workflows

Include 5-8 tools that represent the most widely adopted options in the field. Present information clearly and concisely, avoiding overly technical jargon unless standard to the domain.

Cite all sources at the end in numbered format.

**Format:**

### Research Tools and Software for [Field Name]

| Tool Name | Description | Key Features | Applications |
|-----------|-------------|--------------|--------------|
```
