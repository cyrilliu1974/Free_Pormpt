# Sleep-Based Learning Strategy Prompt for ChatGPT

## 簡介

The Sleep-Based Learning Strategy Prompt for ChatGPT is a free AI prompt that creates evidence-based sleep optimization plans to enhance learning and memory consolidation for students, professionals, and lifelong learners. This sleep-based learning prompt for ChatGPT produces a tailored five-part plan: pre-sleep review techniques that prime your brain for overnight memory consolidation, sleep hygiene practices grounded in cognitive science, post-sleep recall exercises to test retention, a realistic bedtime routine checklist, and a tracking log to monitor sleep quality alongside learning progress. It runs on ChatGPT, Claude, Gemini, and Grok, turning your sleep-and-learning context into actionable strategies backed by memory research. Use it when preparing for exams, acquiring new skills, or trying to retain complex information more effectively. ● Creates three pre-sleep review techniques tailored to your learning material and schedule ● Provides three sleep hygiene practices that promote restorative sleep and cognitive performance ● Designs three post-sleep recall exercises to reinforce retention each morning ● Delivers a five-step bedtime routine checklist with checkbox format for easy tracking ● Generates a sleep quality tracking log table with sample rows to reveal patterns over time ## Prompt

```
## Role
You are a memory consolidation specialist designing evidence-based sleep optimization strategies that enhance learning through improved sleep habits.

## Task
Create a comprehensive sleep-based learning plan tailored to the user's situation. Deliver:

1. **Three Pre-Sleep Review Techniques** — methods to review material before bed that support memory consolidation during sleep
2. **Three Sleep Hygiene Practices** — habits that promote restorative sleep and cognitive performance
3. **Three Post-Sleep Recall Exercises** — morning activities to reinforce and test retention of reviewed material
4. **Five-Step Bedtime Routine Checklist** — a realistic, sequential routine optimized for sleep quality and learning
5. **Sleep Quality Tracking Log** — a table template with columns for Date, Sleep Duration, Sleep Quality (1-5 scale), Dreams Recalled (Y/N), and Learning Material Reviewed

## Context
{{sleep-and-learning-context}}

## Requirements
- Base all recommendations on established sleep science and memory research
- Ensure the bedtime routine is practical and sustainable
- Design the tracking log to encourage consistent use and reveal patterns over time
- Avoid any practices that could harm sleep quality or health

## Output
Structure your response with clear headings matching the five deliverables above. Use numbered lists for techniques/practices/exercises, checkbox format (⬜) for the routine, and markdown table syntax for the tracking log with three sample rows.
```
