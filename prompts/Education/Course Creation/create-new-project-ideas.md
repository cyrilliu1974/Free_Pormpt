# School Project Ideas Generator for Any Topic

## 簡介

The School Project Ideas Generator is a free AI prompt that creates diverse, feasible project ideas tailored to any educational topic, age group, available resources, and timeline. This project ideas prompt for ChatGPT produces 5-7 detailed project concepts, each with a clear title, description, learning outcomes, required materials, and presentation format. It works by analyzing your subject matter and constraints - age group, school resources, and project timeline - then generating creative ideas that balance inquiry-based learning with practical classroom feasibility. Teachers use it to plan science fairs, history presentations, art installations, and cross-curricular investigations that encourage research, problem-solving, and teamwork. The prompt runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need fresh, grade-appropriate project concepts that match your classroom resources and calendar, or when planning thematic units that require varied presentation formats to engage different learning styles. ● Tailors every project idea to your specified age group, available resources, and timeline ● Includes learning outcomes, required materials, and presentation formats for each concept ● Balances individual inquiry with collaborative work to build research and teamwork skills ● Varies formats across reports, models, presentations, and interactive activities to suit diverse learners ## Prompt

```
## Role
You are an experienced educator generating creative, feasible school project ideas.

## Task
Develop a diverse list of school project ideas based on {{topic}}. Each idea must be unique, educationally valuable, and practical within typical school constraints. Projects should engage students through inquiry, creativity, and collaboration while being appropriate for the specified age group.

## Context
- Age group: {{age-group}}
- Available resources: {{school-resources}}
- Timeline: {{project-timeline}}

## Guidelines
1. Brainstorm multiple angles within {{topic}} that spark curiosity and deep learning
2. Define clear objectives and expected outcomes for each project
3. Ensure feasibility using commonly available school materials and the given timeline
4. Balance individual work with teamwork to develop research, problem-solving, and collaboration skills
5. Vary presentation formats (reports, models, presentations, interactive activities) to suit different learning styles

## Output
For each project idea, provide:
- **Project title**
- **Brief description** (2-3 sentences explaining the core activity)
- **Learning outcomes** (key skills and knowledge students will gain)
- **Required materials** (list of supplies needed)
- **Presentation format** (how students will showcase their work)

Generate 5-7 distinct project ideas that are creative, aligned with {{topic}}, and adaptable to the specified age group and resources.
```
