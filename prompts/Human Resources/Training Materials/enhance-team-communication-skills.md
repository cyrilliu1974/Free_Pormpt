# Team Communication Skills Training Program Builder

## 簡介

The Team Communication Skills Training Program Builder is a free AI prompt that creates customized training outlines to strengthen workplace communication for teams across any industry. This communication training prompt for ChatGPT produces a complete program outline with sequenced modules that build on one another - active listening forms the foundation for conflict resolution, clear messaging enables collaborative problem-solving. Running on ChatGPT, Claude, Gemini, and Grok, it tailors the curriculum to your team size, industry context, specific communication challenges, and available training duration. Real teams use it to design onboarding workshops, quarterly skills refreshers, and leadership development tracks that address actual workplace friction points. Reach for this prompt when you need to design or refresh communication training that connects skill-building to measurable workplace outcomes, not generic soft-skills theory. ● Sequences modules to reflect skill dependencies, so foundational abilities support advanced techniques ● Includes learning objectives, detailed content descriptions, practical exercises, and assessment strategies for every module ● Adapts exercises to your team's specific industry context and communication goals ● Outputs a ready-to-deliver training outline with clear headings, organized for immediate implementation ## Prompt

```
## Role

You are an expert communication skills trainer designing a comprehensive training program.

## Task

Create a structured training program outline that enhances team communication skills. The program must cover active listening, clear messaging, conflict resolution, and collaborative problem-solving. Structure the modules to reflect the interdependencies between communication skills—for example, active listening as a foundation for conflict resolution, clear messaging as prerequisite for collaborative problem-solving.

## Context

{{team-and-industry-context}}

{{communication-challenges-and-goals}}

Training duration: {{training-duration}}

## Output

Provide a structured outline with:

- **Module titles and sequence** that reflect skill dependencies
- **Learning objectives** for each module (what participants will be able to do)
- **Detailed module descriptions** explaining content and approach
- **Practical exercises** for each module that apply to the team's industry context
- **Assessment or reinforcement strategies** to measure progress

Use headings, subheadings, and bullet points for maximum clarity and organization.
```
