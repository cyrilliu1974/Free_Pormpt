# Partnership Management System Template Creator

## 簡介

The Partnership Management System Template Creator is a free AI prompt that builds a comprehensive framework for tracking and optimizing business partnerships for companies managing strategic relationships. This partnership management prompt for ChatGPT generates a complete system with sections covering partnership overview, strategic objectives, performance metrics with status indicators, recent accomplishments, risk assessment, and prioritized action items. The template captures partner details, contact information, partnership tier, and strategic value proposition while providing structured tables for tracking metrics against targets, documenting wins, identifying challenges, and coordinating follow-up activities. Companies use it to standardize how they monitor vendor relationships, strategic alliances, channel partnerships, and co-marketing agreements across teams. The prompt runs on ChatGPT, Claude, Gemini, and Grok, producing scannable documents with clearly defined owners, due dates, and status tracking. Reach for this prompt when you need to establish a repeatable system for managing multiple partnerships, improve visibility into partner performance, or create alignment between partnership activities and business outcomes. ● Captures essential partnership details including contact information, partnership type, start date, and strategic value ● Defines 3-5 measurable objectives linked to business outcomes with performance tracking against target values ● Documents accomplishments, identifies current challenges and risks with severity assessment ● Creates action item lists with clear owners, due dates, priority levels, and status indicators ## Prompt

```
## Role
You are an expert in partnership management with deep knowledge of best practices for tracking and optimizing partnership performance.

## Task
Create a comprehensive partnership management template that enables systematic tracking of partner relationships, performance metrics, and strategic action items.

## Context
Company: {{company-name}}

The template will serve as a standardized framework for capturing critical partnership information, monitoring progress against objectives, and coordinating follow-up activities.

## Output
Structure the partnership management system with these sections:

**Partnership Overview**
- Partner name and primary contact
- Partnership type and start date
- Strategic value proposition
- Current partnership tier/level

**Key Partnership Objectives**
- List 3-5 primary objectives this partnership aims to achieve
- Connect each objective to business outcomes

**Partnership Performance Metrics**
For each key metric include:
- Metric name and definition
- Current performance value
- Target/goal value
- Status indicator (on track / at risk / off track)
- Measurement frequency

**Recent Accomplishments**
- Document 3-5 significant wins, milestones, or deliverables from the past quarter
- Include dates and business impact where relevant

**Challenges & Risks**
- Identify current obstacles affecting partnership performance
- Note potential risks on the horizon
- Assess severity and likelihood for each

**Action Items**
For each action item specify:
- Description of the action
- Owner (person responsible)
- Due date
- Status (not started / in progress / completed / blocked)
- Priority level

**Next Steps**
- Outline 3-5 concrete next steps to advance the partnership
- Include timeframes for upcoming meetings, reviews, or initiatives

Format as a clear, scannable document using tables or structured lists for metrics and action items.
```
