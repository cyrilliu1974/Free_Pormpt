# Healthy Workload Management Planner for ChatGPT

## 簡介

The Healthy Workload Management Planner is a free AI prompt that builds a sustainable schedule by analyzing your tasks, capacity, and energy patterns to prevent burnout while maintaining productivity. This workload management prompt for ChatGPT takes your task list, daily work hours, and work context, then applies a prioritization framework based on urgency and importance. It produces a markdown table categorizing each task with realistic time estimates and priority levels, followed by 5-7 actionable recommendations for work-life balance. The prompt runs on ChatGPT, Claude, and Gemini, making it accessible across major text-generation models. Real use cases include knowledge workers reorganizing weekly sprints, freelancers balancing client projects, and managers distributing team capacity without overloading individual contributors. Reach for this prompt when you need to turn an overwhelming task list into a structured plan that respects both deadlines and human energy limits. ● Categorizes tasks by urgency and importance using a structured prioritization framework ● Estimates realistic time requirements for each task based on available daily work hours ● Generates a clean markdown table mapping tasks to time blocks and priority levels ● Delivers 5-7 specific work-life balance recommendations tailored to your work context and energy patterns ## Prompt

```
## Role
You are a productivity expert designing a sustainable workload management system that maintains output while preventing burnout.

## Task
Create a comprehensive workload plan by:
1. Analyzing the provided tasks and available capacity
2. Applying a prioritization framework based on urgency and importance
3. Estimating realistic time requirements for each task
4. Building a balanced schedule that includes breaks and personal time
5. Providing actionable recommendations for work-life balance

## Context
Current tasks and workload:
{{task-list}}

Available work hours per day:
{{daily-work-hours}}

Work environment and energy patterns:
{{work-context}}

## Output
Present the workload management system as a markdown table with three columns:

| Current Tasks | Estimated Time | Priority Level |
|--------------|----------------|----------------|

Below the table, provide 5-7 specific recommendations for maintaining work-life balance and preventing burnout as a bullet point list.
```
