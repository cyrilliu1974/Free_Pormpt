# Blog Post SEO Checklist Generator

## 簡介

The Blog Post SEO Checklist Generator is a free AI prompt that creates actionable on-page optimization checklists for blog content creators and digital marketers. This blog post SEO prompt for ChatGPT produces a structured, ready-to-use checklist covering three critical elements: title optimization (character limits, keyword placement, click-worthiness), meta description writing (length, keyword inclusion, calls-to-action), and URL structure best practices (formatting, keyword use, special character handling). It runs on ChatGPT, Claude, Gemini, and Grok. Simply provide your blog post topic, and the prompt outputs a customized checklist you can follow before publishing. Use it when launching new blog content, auditing existing posts, or training editorial teams on SEO fundamentals. ● Covers all three foundational on-page elements: title tags, meta descriptions, and URL slugs ● Provides specific character limits and formatting rules based on current search engine requirements ● Outputs checkbox-format lists for immediate use during content publishing workflows ● Customizes recommendations to the specific blog post topic you provide ## Prompt

```
## Role
You are an SEO strategist specializing in on-page optimization for blog content.

## Task
Create a concise, actionable on-page SEO checklist for optimizing a blog post on {{blog-post-topic}}. Cover the three critical elements: title, meta description, and URL structure.

## Output
Format as a ready-to-use checklist:

**Blog Post Topic:** {{blog-post-topic}}

**Title Optimization Checklist:**
- [ ] Include primary keyword in title
- [ ] Keep title under 60 characters
- [ ] Make title compelling and click-worthy
- [ ] Place important keywords near beginning of title

**Meta Description Optimization Checklist:**
- [ ] Summarize key points of post in 1-2 sentences
- [ ] Include primary keyword
- [ ] Keep under 155 characters
- [ ] End with a call-to-action

**URL Structure Optimization Checklist:**
- [ ] Use short, descriptive URLs
- [ ] Include primary keyword in URL
- [ ] Use hyphens to separate words
- [ ] Avoid stop words like "and", "the", "a", "an"
- [ ] Use all lowercase letters
```
