# AMP Implementation Guide for Mobile Performance

## 簡介

The AMP Implementation Guide for Mobile Performance is a free AI prompt that delivers a complete technical roadmap for adding Accelerated Mobile Pages to any website, tailored for web developers and site owners who need faster mobile load times. This AMP implementation prompt for ChatGPT analyzes your website URL and produces a structured guide identifying the most critical sections to convert, step-by-step code snippets that follow AMP standards, actionable best practices, and potential challenges with practical workarounds. It runs on ChatGPT, Claude, and Gemini, and is built for developers working on mobile optimization projects where page speed directly impacts engagement, search rankings, and user retention. Use it when you need to retrofit an existing site with AMP or validate your mobile-first strategy with expert-level implementation advice. ● Identifies high-impact sections of your site where AMP will deliver the greatest speed and engagement gains ● Provides copy-paste code snippets that comply with the latest AMP HTML standards and validation requirements ● Surfaces common implementation pitfalls - like third-party script conflicts and dynamic content handling - with clear solutions ● Structures output for quick handoff to development teams or direct implementation by technical site owners ## Prompt
