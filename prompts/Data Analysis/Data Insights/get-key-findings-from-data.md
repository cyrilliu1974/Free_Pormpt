# Data Findings Summary Prompt for ChatGPT

## 簡介

The Data Findings Summary Prompt for ChatGPT is a free AI prompt that distills complex research and data analysis into prioritized, actionable bullet-point summaries for analysts, researchers, and decision-makers. This data insights prompt for ChatGPT takes raw research topics, data sources, and target audiences as input and produces a structured list of key findings. Each insight is presented in 1-2 sentences, includes relevant statistics where applicable, and explains why it matters. The prompt works on ChatGPT, Claude, and Gemini, organizing findings by importance or theme and highlighting trends, patterns, or unexpected results. Real-world use cases include summarizing customer research for stakeholders, distilling quarterly performance data for executive reports, and translating technical analyses into board-ready insights. Reach for this prompt when you need to transform sprawling datasets or lengthy research reports into focused, digestible summaries that drive decisions. ● Produces concise, single-insight findings with supporting statistics and clear explanations of significance. ● Organizes results by logical priority or theme, surfacing the most actionable insights first. ● Adapts language and technical depth to match your specified target audience. ● Formats output as markdown with bold and italic emphasis for readability and presentation. ## Prompt

```
## Role
You are an expert data analyst who distills complex information into clear, actionable insights.

## Task
Summarize the key findings from the provided research or data analysis into a prioritized list of concise bullet points. Each finding should:

- Highlight a single, distinct insight (1-2 sentences maximum)
- Include relevant statistics or quantitative data where applicable
- Explain the significance or implication clearly
- Use precise, jargon-free language accessible to the target audience
- Present factual information without speculation or personal opinion

Organize findings in logical order by importance or theme. Highlight trends, patterns, or unexpected results. Conclude with the most significant or actionable insight.

## Context
**Research topic:** {{research-topic}}

**Data sources:** {{data-sources}}

**Target audience:** {{target-audience}}

## Output
Deliver the summary as a markdown bullet list. Each bullet should state the finding clearly, then briefly explain why it matters. Use **bold** or *italic* formatting for emphasis where appropriate.
```
