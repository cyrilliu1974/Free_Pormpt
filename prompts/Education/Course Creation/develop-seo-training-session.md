# SEO Training Session for Web Developers

## 簡介

The SEO Training Session for Web Developers is a free AI prompt that creates a complete, customized training curriculum to teach development teams how to write search-engine-friendly code. The prompt generates a 100-minute workshop covering HTML structure, JavaScript SEO, technical optimization, and hands-on exercises specific to your team's technology stack and experience level. This SEO training prompt for ChatGPT adapts examples and technical depth based on whether your developers are junior, mid-level, or senior, and addresses the exact search visibility challenges your team faces. It runs on ChatGPT, Claude, Gemini, and Grok to produce a ready-to-deliver training session complete with learning objectives, timed modules, practical exercises, and implementation steps. Reach for this prompt when onboarding developers who need to understand how their code affects search rankings, when your team's sites suffer from indexing or crawlability issues, or when you need to align engineering practices with organic search goals. ● Generates a five-module training outline with timing, learning objectives, and specific topics like semantic HTML, JavaScript rendering, and structured data ● Includes hands-on exercises for HTML structure and JavaScript SEO that developers can complete during the session ● Produces tech-stack-specific examples and solutions that match your team's frameworks, libraries, and development environment ● Delivers curated resources and actionable next steps so developers can continue improving SEO practices after the training ## Prompt

```
## Role
You are an expert SEO trainer specializing in optimizing web development practices for search engines.

## Task
Develop a comprehensive training session that teaches web developers SEO-friendly coding practices. The session should be actionable, well-structured, and appropriate for {{team-experience-level}}.

## Context
The training is for a development team working primarily with {{tech-stack}}. Their biggest SEO challenges are: {{seo-challenges}}.

Tailor examples, technical depth, and exercises to their experience level and technology environment.

## Output
Deliver a complete training session using this structure:

**Training Session: SEO-Friendly Coding Practices for Web Developers**

**Objectives:**
- List 3 specific learning objectives

**Session Outline:**

**1. Introduction to SEO for Web Developers (10 mins)**
- Why SEO matters for developers
- How coding practices impact search rankings
- Common SEO pitfalls in web development

**2. SEO-Friendly HTML Structure (30 mins)**
- Semantic HTML tags and their SEO benefits (with examples)
- Optimizing headings, titles, and meta tags (with best practices)
- Structuring content for featured snippets (with techniques)
- Hands-on exercise

**3. JavaScript and SEO (30 mins)**
- How search engines process JavaScript
- Common JavaScript SEO issues and solutions
- SEO considerations for frameworks and libraries
- Implementing SEO-friendly infinite scroll (with techniques)
- Hands-on exercise

**4. Technical SEO Best Practices (20 mins)**
- Page speed optimization techniques
- Mobile-friendliness and responsive design (with best practices)
- Structured data and schema markup
- Sitemaps, robots.txt, and canonicalization (with tips)

**5. Q&A and Wrap-up (10 mins)**

**Resources:**
- Provide 5-7 authoritative resources for continued learning

**Next Steps:**
- List 3-5 actionable implementation steps the team can take immediately
```
