# User Journey Mapping Prompt for Digital Platforms

## 簡介

The User Journey Mapping Prompt for Digital Platforms is a free AI prompt that creates detailed user journey maps for UI/UX designers working on websites and mobile applications. This user journey mapping prompt for ChatGPT guides you through building an 8-stage map that covers initial engagement, onboarding, navigation, selection, barrier mitigation, action completion, and post-completion touchpoints. It produces actionable descriptions of UI elements, micro-interactions, and copy examples tailored to your specific user action and platform context. Designers use it to plan checkout flows, feature adoption paths, subscription funnels, or any sequence where understanding user motivations and removing friction directly impacts conversion and satisfaction. The prompt runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need to map out a complete user flow before wireframing, present journey documentation to stakeholders, or identify friction points in an existing experience. ● Maps eight distinct journey stages from first contact through post-completion engagement ● Identifies friction points and recommends design solutions to remove barriers ● Outputs specific UI elements, micro-interactions, and example copy for each stage ● Adapts to any user action and platform by accepting custom context and goals ## Prompt

```
## Role
You are a UI/UX designer experienced in user journey mapping for digital platforms.

## Task
Create a comprehensive user journey map that traces each step a user takes to complete a specific action on a website or app. The map should anticipate user needs, remove friction, and create an engaging experience from initial contact through post-completion.

## Context
{{user-action-and-platform}}

User goals, motivations, and context: {{user-context}}

## Output
Structure the journey map using these stages:

**1. Initial Engagement**
Describe the user's first interaction with the platform. What attracts them? How are they welcomed?

**2. Onboarding (if applicable)**
Outline any tutorial or introduction steps that orient the user to relevant features.

**3. User Goals & Motivations**
Clearly define what the user aims to achieve and why they're motivated to complete this action.

**4. Navigation to Action**
Detail the steps to reach the action, including search, filtering, browsing, or menu navigation.

**5. Selection & Customization**
Describe how the user chooses options, configures preferences, or customizes their selection.

**6. Addressing Barriers**
Identify potential friction points (confusion, hesitation, technical issues) and explain how the design mitigates them. Consider trust signals, help resources, and clarity of information.

**7. Completion of Action**
Explain final steps: review, confirmation, payment (if applicable), and success feedback.

**8. Post-Completion Engagement**
Detail follow-up touchpoints: confirmation communications, next steps, opportunities for continued engagement, feedback collection, or relationship building.

For each stage, provide specific, actionable descriptions rather than generic statements. Include UI elements, micro-interactions, and copy examples where they enhance clarity.
```
