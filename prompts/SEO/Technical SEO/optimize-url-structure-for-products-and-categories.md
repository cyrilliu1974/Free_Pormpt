# E-Commerce URL Structure Optimizer for SEO

## 簡介

The E-Commerce URL Structure Optimizer for SEO is a free AI prompt that evaluates existing URL patterns and generates a keyword-optimized, hierarchical URL architecture for e-commerce websites. This URL structure prompt for ChatGPT takes your website name, product categories, target keywords, and current URL setup, then applies dependency grammar principles to map parent-child relationships between pages. It delivers a complete analysis of current strengths and weaknesses, a proposed URL hierarchy, 3-5 category page examples, 3-5 product page examples, and implementation notes covering canonical tags, 301 redirects, and breadcrumb markup. The prompt runs on ChatGPT, Claude, Gemini, and Grok, making it flexible for any text-generation workflow. Use it when launching new product lines, restructuring an existing catalog, or preparing for a site migration that requires SEO-safe URL planning. ● Evaluates current URL weaknesses and identifies crawlability issues ● Maps category-to-product relationships in a clear hierarchical format ● Generates 6-10 concrete URL examples with hyphens and target keywords ● Includes technical notes on canonical tags, 301 redirects, and structured breadcrumbs ## Prompt

```
## Role
You are an SEO specialist optimizing URL structures for e-commerce websites.

## Task
Analyze the current URL structure and propose a new hierarchical URL architecture that improves search engine visibility and maintains user-friendly navigation. Use dependency grammar principles to reflect content relationships and incorporate relevant keywords.

## Context
Website: {{website-name}}
Product categories: {{product-categories}}
Target keywords: {{target-keywords}}
Current URL structure: {{current-url-structure}}

## Process
1. Evaluate the existing URL patterns and identify weaknesses
2. Map category relationships using hierarchical dependency
3. Integrate target keywords naturally into URL segments
4. Apply consistent formatting with hyphens as separators
5. Create examples for both category and product pages

## Output
Deliver your recommendations as a bullet point list that includes:
- Analysis of current structure strengths and weaknesses
- Proposed URL hierarchy showing parent-child relationships
- 3-5 optimized category page URL examples
- 3-5 optimized product page URL examples
- Implementation notes for technical SEO best practices (canonical tags, redirects, breadcrumbs)
```
