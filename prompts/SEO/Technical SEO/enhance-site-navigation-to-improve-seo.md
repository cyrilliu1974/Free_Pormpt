# Site Navigation Audit and Sitemap Optimization Prompt

## 簡介

The Site Navigation Audit and Sitemap Optimization Prompt is a free AI prompt that delivers a complete website structure overhaul for businesses and agencies seeking better SEO performance and user experience. This technical SEO prompt for ChatGPT takes your website URL, target audience, business goals, and current sitemap, then generates six structured deliverables: a current structure analysis, a proposed sitemap hierarchy with clear categories and subcategories, an internal linking strategy to strengthen site connectivity, navigation label recommendations optimized for both clarity and search value, a URL structure and redirect plan, and an implementation priority roadmap. It runs effectively on ChatGPT, Claude, Gemini, and Grok, producing actionable recommendations that balance user navigation ease with search engine crawling efficiency. Teams reach for this prompt when redesigning information architecture, launching site migrations, or fixing navigation issues that hurt conversion or indexing. ● Audits existing site structure to identify navigation gaps and content organization issues ● Builds a logical sitemap hierarchy with main categories, subcategories, and page relationships ● Maps internal linking opportunities to distribute page authority and improve crawl paths ● Evaluates and refines navigation labels for user clarity and keyword relevance ● Identifies URL structure improvements and generates redirect plans for migrations ● Prioritizes implementation steps so teams can sequence changes effectively ## Prompt

```
## Role

You are an expert website optimization specialist focused on navigation structure, user experience, and SEO performance.

## Task

Analyze the provided website information and create a comprehensive sitemap with a well-organized navigation hierarchy. Deliver actionable recommendations for internal linking, navigation labels, URL structure, and redirects to improve both user experience and search engine crawling efficiency.

## Context

**Website:** {{website-url}}

**Target audience:** {{target-audience}}

**Business objectives:** {{business-goals}}

**Current sitemap (if available):** {{current-sitemap}}

Work systematically through the optimization process:

1. Analyze the current website structure and identify key pages and content categories
2. Develop a logical hierarchy with clear main categories and subcategories
3. Map internal linking opportunities to strengthen site connectivity
4. Evaluate navigation labels for clarity and SEO value
5. Identify URL structure improvements and necessary redirects

## Output

Present your deliverables under the following headings, using bullet points for detailed actions and recommendations:

### Current Structure Analysis
### Proposed Sitemap Hierarchy
### Internal Linking Strategy
### Navigation Label Recommendations
### URL Structure & Redirect Plan
### Implementation Priority
```
