# Savings Goal Tracker Design Prompt for ChatGPT

## 簡介

The Savings Goal Tracker Design Prompt is a free AI prompt that creates personalized savings tracking systems with visual dashboards, milestone markers, and action plans for anyone working toward a financial target. This savings goal tracker prompt for ChatGPT takes your financial profile - including savings goal amount, timeframe, current savings, monthly income, and risk tolerance - and outputs a five-part tracking system: a visual dashboard with progress bars and completion projections, core features like automatic contribution tracking and adjustment tools, motivational elements such as milestone celebrations and success probability indicators, a recommended action plan with monthly savings targets and catch-up strategies, and a suite of alerts and reminders to keep you on schedule. It runs on ChatGPT, Claude, and Gemini, delivering structured output with clear headings and bullet points. Use it when you need to turn a savings aspiration into a trackable, actionable plan, whether you are saving for an emergency fund, a down payment, or any other financial milestone. ● Outputs a visual dashboard design with progress indicators, percentage complete, amount remaining, and projected completion dates ● Includes core tracking features like milestone celebration triggers, adjustment tools for changing circumstances, and progress history trends ● Provides a recommended action plan with suggested monthly savings amounts, catch-up strategies if behind schedule, and optimization opportunities based on conservative, moderate, or aggressive risk tolerance ● Generates personalized alerts and reminders for contributions, off-track warnings, milestone achievements, and periodic review prompts ## Prompt

```
## Role
You are an expert financial planner specializing in savings goal design and user motivation.

## Task
Design a comprehensive savings goal tracker with a user-friendly interface, key features, and motivational elements tailored to help the user reach their financial target.

## Context
**User's Financial Situation:**
{{financial-profile}}

Include: savings goal amount and purpose, timeframe, current savings, monthly income, and risk tolerance (conservative/moderate/aggressive).

## Output
Provide a structured savings tracker design with:

### 1. Dashboard Interface
- Visual progress indicators (progress bars, milestone markers)
- Key metrics display (percentage complete, amount remaining, projected completion date)
- At-a-glance summary

### 2. Core Features
- Automatic contribution tracking
- Milestone celebration triggers
- Adjustment tools for changing circumstances
- Progress history and trends

### 3. Motivational Elements
- Personalized encouragement messages
- Visual rewards for milestones
- Comparison to projected timeline
- Success probability indicators

### 4. Recommended Action Plan
- Suggested monthly savings amount
- Catch-up strategies if behind schedule
- Optimization opportunities based on risk tolerance
- Timeline adjustments if needed

### 5. Alerts & Reminders
- Contribution reminders
- Off-track warnings
- Milestone achievements
- Review prompts

Format with clear headings, subheadings, and bullet points for maximum readability.
```
