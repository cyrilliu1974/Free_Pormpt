# URL Structure Optimization for SEO

## 簡介

The URL Structure Optimization for SEO is a free AI prompt that audits existing URLs and delivers a complete framework of rules, examples, and priorities for search-friendly site architecture. This URL structure prompt for ChatGPT, Claude, and Gemini analyzes your current URLs against best practices for readability, keyword placement, hierarchy, and crawlability, then produces side-by-side comparison tables showing optimized versions for categories, products, and filter pages. It also ranks improvements by SEO impact and technical effort, so you tackle high-value changes first. E-commerce teams, technical SEO specialists, and content platform managers use it to clean up legacy URLs, standardize naming conventions, and plan redirect strategies that protect existing rankings while boosting discoverability. ● Produces maximum-length guidelines, keyword-positioning rules, character policies, and canonicalization standards tailored to your CMS and industry. ● Generates before-and-after comparison tables for representative page types so developers and stakeholders see exactly what will change. ● Prioritizes fixes by expected traffic lift and engineering effort, ensuring quick wins ship first. ● Includes redirect strategy and trailing-slash handling to preserve link equity during migration. ## Prompt

```
## Role
You are an expert SEO strategist and URL architecture specialist with deep experience optimizing e-commerce and content websites for search visibility, user trust, and conversion.

## Task
Analyze the provided website context and generate a comprehensive, actionable URL optimization framework. Deliver specific rules covering length limits, keyword placement, special character handling, and consistency standards. Provide before-and-after examples for categories, products, and filter pages, plus implementation priorities ranked by SEO impact and technical complexity.

## Context
{{website-context}}

Include:
- Website type and industry
- 3–5 current URL examples
- Main product or content categories
- Primary target keywords
- Any CMS or technical constraints

## Process
1. Assess the current URL structure against SEO best practices (readability, keyword density, hierarchy, crawlability).
2. Identify quick wins and longer-term improvements.
3. Develop optimization rules: maximum lengths, keyword positioning, permitted characters, hyphen vs. underscore policy, trailing-slash handling, canonicalization.
4. Create side-by-side comparison examples (current → optimized) for representative page types.
5. Prioritize changes by expected traffic impact and implementation effort.

## Output
Deliver your framework using:

**# URL Optimization Rules**
- Bullet list of concrete rules with rationale

**# Before & After Examples**
- Comparison table: Page Type | Current URL | Optimized URL | Reason

**# Implementation Roadmap**
- Phased rollout plan ordered by priority (high-impact/low-effort first)
- Notes on redirect strategy and canonicalization

Ensure every recommendation balances search-engine signals, human readability, and technical feasibility.
```
