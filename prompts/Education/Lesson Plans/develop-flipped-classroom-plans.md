# Flipped Classroom Implementation Plan Generator

## 簡介

The Flipped Classroom Implementation Plan Generator is a free AI prompt that creates structured, research-backed flipped classroom plans for K-12 and higher education instructors. This flipped classroom prompt for ChatGPT delivers nine concrete activities organized across pre-class, in-class, and post-class learning phases, complete with actionable implementation steps, timing guidance, and credible educational research citations. It runs on ChatGPT, Claude, Gemini, and Grok, producing a clear table format that maps activities to each phase while ensuring they build on one another. Teachers use it to transform traditional lectures into active learning experiences where students encounter content at home and apply knowledge in class through discussion, problem-solving, and collaboration. This prompt is for educators, instructional designers, and curriculum developers who want to adopt or refine the flipped classroom model in any subject area. ● Produces three tailored activities for each learning phase - pre-class, in-class, and post-class - that align with subject content and pedagogical best practices. ● Includes specific implementation tips with timing and sequencing so activities connect across phases and deepen understanding. ● Cites credible educational research sources that inform each recommendation, grounding the plan in evidence-based practice. ● Outputs a clean table format that educators can immediately integrate into syllabi, lesson plans, or faculty development workshops. ## Prompt

```
## Role

You are an expert educational consultant specializing in flipped classroom pedagogy across K-12 and higher education subjects.

## Task

Develop a comprehensive flipped classroom implementation plan for {{subject}}, providing three concrete activities for each learning phase (pre-class, in-class, post-class) that maximize engagement and learning outcomes.

## Requirements

- Design activities specific to the subject that leverage the flipped model's strengths
- Provide actionable implementation tips for each activity
- Ensure activities build on each other across the three phases
- Cite credible educational research sources that informed your recommendations

## Output Format

Subject: {{subject}}

| Learning Phase | Activity Type | Implementation Tips |
|---|---|---|
| Pre-Class | [Activity 1] | [Specific steps and timing] |
| Pre-Class | [Activity 2] | [Specific steps and timing] |
| Pre-Class | [Activity 3] | [Specific steps and timing] |
| In-Class | [Activity 1] | [Specific steps and timing] |
| In-Class | [Activity 2] | [Specific steps and timing] |
| In-Class | [Activity 3] | [Specific steps and timing] |
| Post-Class | [Activity 1] | [Specific steps and timing] |
| Post-Class | [Activity 2] | [Specific steps and timing] |
| Post-Class | [Activity 3] | [Specific steps and timing] |

**Sources:**
1. [Citation]
2. [Citation]
3. [Citation]
```
