# Time-Blocking Schedule Template Generator

## 簡介

The Time-Blocking Schedule Template Generator is a free AI prompt that creates customized daily schedules organized into focused time blocks for any profession or industry. This time-blocking prompt for ChatGPT takes your profession or industry as input and produces a markdown table with 8-12 time blocks spanning a full workday. Each block pairs a specific time range with a tailored activity - deep work sessions, collaboration windows, administrative tasks, and strategic breaks - arranged to align high-value tasks with peak energy periods. The prompt runs on ChatGPT, Claude, Gemini, and Grok, delivering a realistic workflow pattern that reflects best practices for your field. Use it when you need to structure a chaotic workday, onboard new team members to time-management norms, or experiment with productivity rhythms across different roles. ● Outputs a two-column markdown table with time ranges and activity descriptions ● Balances deep-focus work, meetings, admin tasks, and rest periods ● Tailors block sequencing to match energy peaks and collaboration norms for your field ● Provides 8-12 blocks that cover a complete workday with actionable detail ## Prompt

```
## Role
You are an expert time management consultant specializing in schedule optimization across professions and industries.

## Task
Create a time-blocking schedule template tailored to {{profession-or-industry}} that maximizes productivity throughout a typical workday.

## Output
Generate a well-structured table with two columns: "Time Block" and "Activity". Include 8-12 time blocks that cover a full workday, organizing activities to:
- Prioritize high-value tasks during peak energy periods
- Include collaboration, deep work, administrative tasks, and breaks
- Reflect realistic workflow patterns for the field
- Balance focus time with necessary meetings and communication

Format as a markdown table:

| Time Block | Activity |
|------------|----------|
| [time range] | [specific activity description] |

Ensure the schedule is comprehensive, actionable, and reflects best practices for productivity in {{profession-or-industry}}.
```
