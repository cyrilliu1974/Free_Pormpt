# UI Design Screenshot Generator for Apps

## 簡介

The UI Design Screenshot Generator for Apps is a free AI prompt that creates flat, minimalist interface mockups for any application type. This UI design prompt for Midjourney produces clean app screenshots with simple geometric shapes, rounded corners, minimal shadows, and white backgrounds in a 16:9 aspect ratio using raw style parameters. Whether you need mockups for a fitness tracker, e-commerce platform, productivity tool, or social app, the prompt generates polished interface designs that showcase specific subjects and icons you define. Designers, product managers, and developers reach for it when they need quick visual concepts, pitch deck materials, or portfolio pieces without opening Figma. ● Produces flat UI/UX screenshots with customizable app types and icon sets ● Outputs clean geometric layouts with rounded corners and minimal shadow effects ● Maintains consistent 16:9 aspect ratio and raw style for presentation-ready mockups ● Works with white backgrounds that keep focus on interface elements and design hierarchy ## Prompt

```
Screenshot of UI design for a {{app-type}} app, featuring {{subject-and-icons}}, flat UI/UX design, simple ui, clean geometric shapes, minimal shadows, rounded corners, white background --ar 16:9 --style raw
```
