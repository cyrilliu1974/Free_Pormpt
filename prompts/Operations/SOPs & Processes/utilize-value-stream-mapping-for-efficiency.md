# Value Stream Mapping Prompt for Process Improvement

## 簡介

The Value Stream Mapping Prompt for Process Improvement is a free AI prompt that builds a detailed Value Stream Map to optimize efficiency, productivity, and workflow for process improvement specialists and operations managers. This value stream mapping prompt for ChatGPT walks you through a four-phase methodology: documenting your current state with all process steps, cycle times, and material flows; identifying and categorizing seven types of waste (waiting, transportation, overprocessing, defects, inventory, motion, overproduction); designing a future state with quantified lead time reductions; and creating a sequenced implementation roadmap with resource assignments and timelines. It runs on ChatGPT, Claude, Gemini, and Grok, requiring only your process details as input. Use it when you need to analyze manufacturing workflows, service delivery processes, administrative procedures, or any business operation where you suspect hidden inefficiencies or want to systematically reduce lead times. ● Documents every process step with cycle times, lead times, waiting times, handoffs, and decision points in the current state ● Categorizes and quantifies waste across all seven Lean manufacturing types to prioritize improvement opportunities ● Designs a future state map with specific process changes, projected efficiency gains, and feasibility rankings ● Produces an implementation roadmap that sequences improvements logically, assigns owners, and sets realistic timelines ## Prompt

```
## Role

You are an expert process improvement specialist creating a Value Stream Map to optimize efficiency, productivity, and workflow.

## Task

Develop a comprehensive Value Stream Map for the specified business process. Work systematically through:

1. **Current State Analysis**
   - Identify all process steps (value-adding and non-value-adding activities)
   - Map information and material flows
   - Document cycle times, lead times, and waiting times between steps
   - Note handoffs, decision points, and dependencies

2. **Waste Identification**
   - Analyze the map to pinpoint bottlenecks and redundancies
   - Categorize waste types (waiting, transportation, overprocessing, defects, inventory, motion, overproduction)
   - Quantify impact of each waste source on overall performance

3. **Future State Design**
   - Propose specific improvements to streamline the process
   - Calculate projected lead time reductions and efficiency gains
   - Prioritize changes by impact and feasibility given available resources
   - Define metrics to track improvement success

4. **Implementation Roadmap**
   - Sequence improvements logically based on dependencies
   - Identify resource requirements and owners for each change
   - Set realistic timelines aligned with desired outcomes

## Context

{{process-details}}

## Output

Structure your Value Stream Map deliverable with clear headings for each major section (Current State Map, Analysis & Findings, Future State Map, Implementation Plan). Use bullet points for detailed steps, observations, and recommendations. Ensure each proposed improvement clearly links back to identified waste or constraints in the current state.
```
