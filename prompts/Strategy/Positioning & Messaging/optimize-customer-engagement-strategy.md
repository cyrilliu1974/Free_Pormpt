# Hooked Model Implementation Plan Generator

## 簡介

The Hooked Model Implementation Plan Generator is a free AI prompt that creates structured behavioral design strategies for businesses seeking to build habit-forming products using Nir Eyal's proven framework. This Hooked model prompt for ChatGPT analyzes your specific business context and audience to deliver a complete implementation plan across all four phases: Trigger (external and internal cues), Action (ease and motivation), Variable Reward (unpredictable gratification), and Investment (commitment mechanisms). It produces 5-8 concrete, context-specific steps rather than generic advice, along with ethical considerations for responsible habit design. The prompt works on ChatGPT, Claude, Gemini, and Grok, making it accessible across major text-generation platforms. Marketing teams use it to increase user retention, product managers apply it to feature roadmaps, and UX designers reference it when architecting engagement loops. This prompt is for anyone building digital products, content platforms, apps, or services where repeated user engagement drives business value. ● Delivers phase-by-phase breakdowns of Trigger, Action, Variable Reward, and Investment with business-specific applications ● Produces 5-8 executable steps customized to your audience and product category, not templated advice ● Includes ethical guardrails addressing transparency, user autonomy, and value creation in habit design ● Structures output with introduction, framework explanation, implementation plan, best practices, and summary for immediate team use ## Prompt

```
## Role

You are an expert in behavioral design and user engagement, specializing in Nir Eyal's "Hooked" framework for creating habit-forming products.

## Task

Analyze the business context provided and develop a comprehensive implementation plan that applies all four phases of the "Hooked" model—Trigger, Action, Variable Reward, and Investment—to increase user engagement and habit formation.

## Context

{{business-and-audience}}

## Output

Provide your response in the following structure:

### Introduction
Briefly explain the "Hooked" model and why it matters for creating habit-forming products.

### The Four Phases Explained
- **Trigger**: External and internal triggers that prompt user action
- **Action**: Designing for ease of use and psychological motivation
- **Variable Reward**: Creating craving through unpredictable rewards
- **Investment**: Increasing likelihood of future engagement through user commitment

### Implementation Plan
Deliver 5–8 concrete, actionable steps tailored to the specific business and audience provided. Each step should specify which phase(s) of the model it addresses and how to execute it in this context. Avoid generic advice.

### Best Practices & Ethical Considerations
Offer additional tips for sustaining engagement while addressing the ethical responsibility of designing habit-forming experiences. Emphasize transparency, user autonomy, and value creation.

### Conclusion
Summarize the key opportunities and next steps.
```
