# SERP Feature Analysis for Keyword Research

## 簡介

The SERP Feature Analysis for Keyword Research is a free AI prompt that examines the search landscape for your target keywords and maps specific optimization opportunities across featured snippets, People Also Ask boxes, local packs, knowledge panels, image carousels, and video results. This SERP feature analysis prompt for ChatGPT walks through each of your target keywords, identifies which SERP elements currently appear in the results, and delivers a prioritized table of concrete optimization tactics. Built for SEO professionals and content strategists, it runs on ChatGPT, Claude, Gemini, and Grok, requiring only your target keywords and competitive context to generate a markdown table pairing each keyword with its most promising SERP feature opportunities. Use it when planning content campaigns, auditing existing pages, or determining where to invest optimization effort for maximum visibility impact. ● Maps target keywords to the exact SERP features (featured snippets, PAA, local packs, video carousels) currently ranking or targetable ● Assesses difficulty and visibility impact for each keyword-feature pair based on competitive context ● Generates a three-column markdown table with keyword, SERP feature type, and concrete optimization strategy for each row ● Prioritizes opportunities by weighing visibility potential against competitive difficulty, so you focus effort where it counts ## Prompt

```
## Role
You are an expert SEO analyst specializing in SERP feature analysis and keyword optimization strategy.

## Task
Analyze the search engine results page (SERP) landscape for the provided keywords and identify specific optimization opportunities. Examine which SERP features appear for each keyword (featured snippets, People Also Ask, local packs, knowledge panels, image carousels, video results, etc.) and determine how to target them effectively.

## Context
{{target-keywords}}

{{competitive-context}}

## Analysis Requirements
- Identify which SERP features are currently appearing for each target keyword
- Assess the difficulty and opportunity of ranking for each feature type
- Consider the niche-specific patterns in how SERP features display
- Prioritize features based on visibility impact and competitive landscape
- Provide actionable optimization tactics specific to each keyword-feature combination

## Output
Present your analysis as a markdown table with three columns:

| KEYWORD | SERP FEATURE | OPTIMIZATION STRATEGY |
|---------|--------------|----------------------|

Each row must include:
- The specific target keyword analyzed
- The SERP feature present or targetable (featured snippet, PAA, local pack, etc.)
- A concrete, actionable strategy to optimize for that feature and improve organic visibility
```
