# Mobile Website Optimization Guide Generator

## 簡介

The Mobile Website Optimization Guide Generator is a free AI prompt that produces customized mobile optimization strategies for affiliate marketers and web developers looking to improve mobile user experience and conversion rates. This mobile optimization prompt for ChatGPT analyzes your current mobile metrics and generates a structured, nine-step implementation guide covering performance audits, responsive design techniques, media compression, navigation streamlining, touch interface adjustments, content restructuring, mobile-specific features, cross-device testing protocols, and continuous improvement frameworks. It runs on ChatGPT, Claude, and Gemini, accepting inputs for your website URL, target audience, affiliate niche, conversion goals, and current mobile performance data. Teams use it to audit existing sites, plan responsive redesigns, prioritize technical fixes, and create mobile-first strategies that align with specific business objectives. Reach for this prompt when you need a structured mobile optimization roadmap tailored to a particular website's context rather than generic best practices. ● Accepts current mobile metrics and conversion goals to generate audience-specific optimization strategies ● Produces nine-phase guides covering performance, responsive design, media optimization, navigation, touch interfaces, content structure, mobile features, testing, and analytics ● Structures recommendations with clear headings, bullet points, and prioritized action items ● Adapts guidance to affiliate marketing contexts, balancing user experience with conversion optimization ## Prompt

```
## Role
You are an expert web developer specializing in mobile optimization for affiliate marketing websites.

## Task
Create a comprehensive, step-by-step guide to optimize the website for mobile devices, improving user experience and increasing conversions.

## Context
**Website:** {{website-url}}
**Target audience:** {{target-audience}}
**Affiliate marketing niche:** {{niche}}
**Conversion goals:** {{conversion-goals}}
**Current mobile metrics:** {{mobile-metrics}}

## Optimization Framework

### 1. Performance Audit
Analyze the website's current mobile performance, identifying specific areas for improvement in speed, responsiveness, and usability based on the provided metrics.

### 2. Responsive Design Implementation
Ensure the website adapts seamlessly to various screen sizes and resolutions through responsive web design techniques.

### 3. Media Optimization
Optimize images and other media elements for faster mobile loading using compression techniques and appropriate file formats.

### 4. Navigation & Layout
Streamline navigation and layout to make information discovery intuitive and fast for mobile users.

### 5. Touch Interface Optimization
Ensure all interactive elements (buttons, forms, CTAs) are easily accessible and usable on touch screens.

### 6. Content Structure
Structure content for mobile readability using clear, concise language and logical information hierarchy that works on smaller screens.

### 7. Mobile-Specific Features
Implement features like click-to-call buttons and location-based services to enhance engagement and drive conversions.

### 8. Cross-Device Testing
Conduct thorough testing across multiple mobile devices and browsers to ensure consistent performance.

### 9. Continuous Improvement
Monitor mobile user behavior and feedback, using insights to refine the optimization strategy over time.

## Output
Provide a well-structured guide with clear headings, subheadings, bullet points, and actionable recommendations tailored to the specific audience, niche, and conversion goals.
```
