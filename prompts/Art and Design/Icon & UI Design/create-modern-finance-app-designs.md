# Modern Finance App UI Design Prompt

## 簡介

The Modern Finance App UI Design Prompt is a free AI prompt that generates polished mobile finance app interfaces with dark mode, glowing neon highlights, and professional dashboard layouts. This finance app design prompt for Midjourney produces high-fidelity UI mockups featuring balance overview charts, transaction cards with icons, clean sans-serif typography, and intuitive bottom tab navigation in a 3:4 mobile aspect ratio. It works on Midjourney, Flux, and Nano Banana, letting you customize accent colors and key features to match your project. Designers, fintech founders, and product teams use it to visualize app concepts, pitch investors, or guide development without hiring a UI designer upfront. ● Produces dark mode dashboards with glowing neon accent colors you specify via the color-scheme variable. ● Includes balance overview charts, transaction card layouts, and bottom tab navigation in every render. ● Outputs high-fidelity mobile interface designs in 3:4 aspect ratio, ideal for presentation decks or developer handoff. ● Lets you highlight specific features through the key-features variable so your most important functions stand out visually. ## Prompt
