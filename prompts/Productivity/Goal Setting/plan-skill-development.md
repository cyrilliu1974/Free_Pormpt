# Skill Development Plan Prompt for ChatGPT

## 簡介

The Skill Development Plan Prompt for ChatGPT is a free AI prompt that builds personalized learning roadmaps for anyone pursuing new skills or advancing existing ones. This skill development prompt for ChatGPT guides the AI to act as a learning and development specialist, producing a markdown table that organizes learning objectives, specific resources (books, courses, workshops, exercises), and realistic timelines based on your current proficiency, available study time, and preferred learning style. It works on ChatGPT, Claude, Gemini, and Grok, and is designed for lifelong learners, career changers, students, and professionals who want a clear, actionable plan rather than generic advice. The prompt accepts two variables: the skill you want to develop and a learner profile that includes your current level, weekly availability, learning preferences, and long-term goals. Reach for this prompt when you need a structured pathway from where you are now to mastery, with resources matched to how you learn best. ● Outputs a three-column markdown table mapping learning objectives, resources, and timelines in a single view. ● Ensures objectives build progressively from current proficiency to target mastery level. ● Recommends diverse, actionable resources - books, online courses, workshops, hands-on exercises - tailored to the learner's style and availability. ● Generates realistic timelines that respect weekly study capacity and avoid overly ambitious pacing. ## Prompt

```
## Role
You are an expert learning and development specialist creating structured skill development plans that support lifelong learning and personal growth.

## Task
Design a comprehensive skill development plan tailored to the learner's current proficiency and goals. The plan must include:

- Key learning objectives that chart a clear progression path from current to target proficiency
- Diverse, high-quality learning resources (books, online courses, workshops, hands-on exercises) matched to the learning style
- A realistic timeline for skill acquisition and mastery based on available study time

## Context
**Skill:** {{skill}}

**Learner Profile:** {{learner-profile}}
(Include: current proficiency level, available weekly learning time, preferred learning style, and long-term goal for this skill)

## Output
Provide the development plan as a markdown table with three columns:

| Learning Objectives | Resources | Timeline |
|---------------------|-----------|----------|

Ensure objectives build progressively, resources are specific and actionable, and timelines reflect realistic pacing given the learner's availability.
```
