# Voice Search Question Phrase SEO Content Builder

## 簡介

The Voice Search Question Phrase SEO Content Builder is a free AI prompt that creates highly searchable content optimized for voice search queries and natural language patterns. This voice search optimization prompt for ChatGPT, Claude, and Gemini transforms your topic, audience, and keywords into structured content that mirrors how people naturally speak and ask questions. It incorporates who/what/where/when/why/how question phrases throughout, uses dependency grammar principles for clarity, and targets featured snippet opportunities with conversational formatting. Content strategists use it to write blog posts, FAQ pages, and landing pages that rank for voice-activated searches on smart speakers, mobile assistants, and voice-enabled devices. Reach for this prompt when you need content that performs well in both traditional search and voice query results, especially for how-to topics, local services, and question-rich subject matter. ● Identifies common voice search queries specific to your topic and target audience ● Structures content with clear H2/H3 headings and question-based subheadings ● Delivers 500-800 word articles in scannable format with concise paragraphs and bullet points ● Optimizes for featured snippets and position-zero search results using dependency grammar ## Prompt

```
## Role
You are an expert content strategist specializing in voice search optimization.

## Task
Create highly searchable, readable content optimized for voice search queries with strong SEO performance.

## Context
Voice search uses natural language patterns and question-based queries. Structure content using dependency grammar principles to mirror how people naturally speak and ask questions. The content must serve both search engine algorithms and human readers.

## Approach
1. Identify common voice search queries for the topic and audience
2. Incorporate natural question phrases (who, what, where, when, why, how) throughout
3. Structure sentences using dependency grammar for clarity and flow
4. Optimize for featured snippet and position-zero opportunities
5. Use conversational tone that matches spoken language patterns

## Input
Topic: {{topic}}

Target audience: {{target-audience}}

Content type: {{content-type}}

Primary keywords: {{primary-keywords}}

## Output
Deliver structured content with:
- Clear hierarchical headings (H2, H3)
- Question-based subheadings where appropriate
- Concise paragraphs (2-3 sentences)
- Bullet points for scannable lists
- Natural conversational tone
- Strategic keyword placement
- 500-800 words unless specified otherwise
```
