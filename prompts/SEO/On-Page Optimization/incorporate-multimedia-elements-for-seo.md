# Multimedia SEO Integration Guide Generator

## 簡介

The Multimedia SEO Integration Guide Generator is a free AI prompt that creates comprehensive guides for bloggers who want to boost engagement and search visibility through strategic multimedia use and clearer content structure. This multimedia SEO prompt for ChatGPT produces a numbered guide covering selection criteria for images, videos, and infographics; creation and sourcing best practices; technical SEO optimization including file naming, alt text, and captions; CMS-specific integration strategies; and dependency grammar principles that improve both readability and search engine parsing. It runs on ChatGPT, Claude, and Gemini, tailoring output to your blog topic, target audience, and content management system. Use it when you need a complete roadmap for adding visual elements that serve both human readers and search algorithms. ● Provides criteria for selecting images, videos, and infographics aligned with target keywords and audience preferences ● Delivers CMS-specific placement and responsive design recommendations customized to your platform ● Explains how to optimize file names, alt text, and captions for accessibility and search visibility ● Applies dependency grammar principles to improve sentence structure, content hierarchy, and featured snippet optimization ## Prompt

```
## Role
You are an expert SEO content strategist specializing in multimedia integration and content structure optimization.

## Task
Create a comprehensive guide on incorporating multimedia elements (images, videos, infographics) into blog posts while applying dependency grammar principles to improve both search engine visibility and content readability.

## Context
Blog topic: {{blog-topic}}
Target audience: {{target-audience}}
Content management system: {{cms}}

The guide should address bloggers who want to boost engagement and SEO performance through strategic multimedia use and clearer sentence structure.

## Output
Deliver a numbered list with subsections using bullet points. Cover:

1. **Selecting Multimedia Elements**
   - Criteria for choosing images, videos, and infographics that align with topic and target keywords
   - How to match media type to content goals and audience preferences

2. **Creating and Sourcing Media**
   - Best practices for original creation vs. licensed content
   - Quality standards and format recommendations

3. **SEO Optimization for Multimedia**
   - Strategic file naming conventions using target keywords
   - Writing effective alt text that balances accessibility and SEO
   - Crafting captions that reinforce content themes
   - Technical considerations (file size, formats, lazy loading)

4. **Integration Within {{cms}}**
   - Placement strategies for maximum engagement
   - Responsive design considerations

5. **Applying Dependency Grammar Principles**
   - Structuring sentences with clear head-dependent relationships
   - Creating content hierarchy that search engines can parse effectively
   - Improving readability through grammatical coherence
   - How clearer sentence structure supports featured snippet optimization

Include specific examples and actionable steps throughout each section.
```
