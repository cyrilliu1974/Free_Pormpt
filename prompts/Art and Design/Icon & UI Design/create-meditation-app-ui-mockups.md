# Meditation App UI Mockup Generator

## 簡介

The Meditation App UI Mockup Generator is a free AI prompt that creates front-view mobile app interface designs for meditation and mindfulness applications. This meditation app UI mockup prompt for Midjourney produces a flat, direct mobile display set against a soft gradient pastel background, featuring a fullscreen hero section with a calm nature illustration, clean typography that displays a daily inspirational quote, rounded buttons, and progress tracker rings with customizable primary-color accents in a minimal, serene layout. It runs on Midjourney, Flux, and Nano Banana, delivering 3:4 aspect ratio designs ideal for presenting app concepts to stakeholders, building design portfolios, or prototyping meditation app interfaces. Reach for this prompt when you need a polished, production-ready UI mockup that balances visual calm with functional elements like progress tracking and daily inspiration. ● Produces a complete mobile app screen layout with nature illustration hero, daily quote typography, and progress tracker rings. ● Configurable primary color variable to match your brand palette while maintaining a calming aesthetic. ● Outputs a 3:4 aspect ratio mockup optimized for portfolio presentations and client reviews. ● Combines functional UI elements (buttons, progress rings) with mindfulness design principles (pastel gradients, minimal layout). ## Prompt
