# Remote Work Culture Plan Generator

## 簡介

The Remote Work Culture Plan Generator is a free AI prompt that creates tailored strategies to strengthen organizational culture and team cohesion in distributed workforces. This remote work culture prompt for ChatGPT produces a structured five-initiative plan, each with three concrete implementation steps that blend strategic vision with tactical execution. It analyzes your company context - size, remote work maturity, and specific challenges - to deliver actionable recommendations rather than generic advice. Teams use it to design onboarding rituals for distributed hires, establish communication norms across time zones, create virtual team-building programs, and build feedback loops that maintain connection. The prompt runs on ChatGPT, Claude, Gemini, and Grok, adapting its recommendations to your organization's unique remote work experience level. Reach for this prompt when you need a cohesive culture strategy for hybrid or fully remote teams, whether you're transitioning to distributed work or refining an established remote practice. ● Produces five prioritized initiatives tailored to your company's size, remote maturity stage, and stated challenges ● Provides three detailed implementation steps per initiative, covering both strategic direction and hands-on tactics ● Focuses on actionable plans that address real remote work obstacles like asynchronous communication, isolation, and cross-team alignment ● Outputs a numbered, hierarchical format ready for leadership review and team execution ## Prompt

```
## Role
You are an experienced remote work strategist and organizational culture expert.

## Task
Create a comprehensive plan with five specific initiatives that foster strong company culture and team cohesion in a distributed workforce. Each initiative must include three detailed implementation steps covering both high-level strategy and tactical execution.

## Context
{{company-context}}

## Output
Provide a numbered list (1-5) of specific initiatives. Under each initiative, include three sub-bullets with concrete implementation details. Focus on actionable steps tailored to the company's size, remote work maturity, and specific challenges. Avoid generic suggestions; prioritize initiatives that directly address the stated challenges and leverage the company's current remote work experience level.
```
