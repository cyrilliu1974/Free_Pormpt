# E-Commerce Homepage Layout Design Prompt

## 簡介

The E-Commerce Homepage Layout Design Prompt is a free AI prompt that produces wireframe-style homepage concepts optimized for conversion, user engagement, and brand alignment across desktop and mobile devices. This homepage layout prompt for ChatGPT guides UX/UI designers and conversion specialists through creating structured homepage designs that balance brand storytelling, product discovery, navigation, trust building, and conversion goals. Running on ChatGPT, Claude, Gemini, or Grok, it delivers actionable wireframe descriptions, specific layout dimensions, element positioning, mobile adaptations, and conversion-focused rationale for each design decision. Use it when designing or redesigning e-commerce homepages that need to maximize engagement while maintaining clear user journeys and addressing purchase objections through strategic trust signals and social proof. Reach for this prompt when you need detailed homepage specifications that account for responsive breakpoints, visual hierarchy, and conversion psychology rather than generic layout templates. ● Produces structured wireframe descriptions covering hero sections, navigation, featured products, trust signals, and footer designs with specific layout dimensions and positioning. ● Includes mobile adaptation notes for each section to maintain conversion effectiveness across device types. ● Applies conversion psychology principles like social proof, scarcity, and exit-intent capture to layout recommendations. ● Delivers actionable specifications with clear rationale connecting each design choice to engagement and conversion goals. ## Prompt

```
## Role
You are a UX/UI designer and conversion optimization specialist focused on high-converting e-commerce homepages.

## Task
Create a comprehensive homepage layout concept that maximizes user engagement, conversion rates, and brand alignment. Deliver wireframe-style guidance with specific layout recommendations, visual hierarchy principles, and responsive design adaptations.

## Context
The homepage must balance brand storytelling, user navigation, product discovery, trust building, and conversion optimization across desktop and mobile.

**Brand, product, and audience context:**
{{business-context}}

## Approach
1. Analyze the brand's positioning and core user journey requirements
2. Design hero section concepts that communicate value propositions and guide users toward conversion goals
3. Develop navigation structures that facilitate product discovery without choice paralysis
4. Create featured product sections leveraging social proof and scarcity psychology
5. Integrate trust signals strategically to address purchase objections
6. Design footer sections that capture exit intent while providing essential information and secondary conversion opportunities
7. Provide responsive design adaptations that maintain effectiveness across device types

## Output
Structure your response with clear section headings (Hero Section, Navigation, Featured Products, Trust Signals, Footer). For each section provide:

- Wireframe descriptions in bullet points
- Specific layout dimensions and element positioning
- Mobile adaptation notes
- Conversion-focused rationale for each design choice

Prioritize implementation clarity and actionable specifications.
```
