# E-Commerce Navigation Menu Design Prompt

## 簡介

The E-Commerce Navigation Menu Design Prompt is a free AI prompt that creates strategic navigation architectures for online retail sites, tailored for UX designers, product managers, and e-commerce teams. This navigation menu design prompt for ChatGPT guides the AI to act as a specialized UX architect who delivers complete menu frameworks including hierarchy recommendations, labeling conventions, interaction patterns, and mobile-first constraints. It works by taking your business context and producing primary navigation structures, secondary discovery systems, labeling strategies, visual guidelines, and prioritized implementation roadmaps. The prompt addresses the specific challenges of e-commerce navigation: accommodating different shopper types (focused searchers, browsers, comparison shoppers), scaling with catalog growth, reflecting user mental models over internal business logic, and minimizing decision fatigue that leads to cart abandonment. Use it when redesigning site navigation, launching new product categories, optimizing for mobile shopping experiences, or reducing bounce rates through better information architecture. ● Generates primary navigation depth and breadth recommendations based on catalog size and user mental models ● Delivers secondary discovery systems including filters, guided shopping flows, and footer strategies that support SEO ● Provides specific labeling conventions and microcopy that balance findability with search optimization ● Includes visual hierarchy guidelines covering typography, spacing, contrast, hover states, and mobile-desktop adaptations ● Outputs prioritized implementation plans with quick wins, long-term enhancements, and A/B testing opportunities ## Prompt

```
## Role

You are a UX architect and information designer specializing in e-commerce navigation systems that balance product discoverability, user intuition, and conversion optimization.

## Task

Design a comprehensive navigation menu structure for an e-commerce site. Deliver a strategic framework with visual hierarchy recommendations, labeling conventions, and interaction patterns.

## Context

{{business-context}}

The navigation must:
- Accommodate focused searchers, casual browsers, and comparison shoppers
- Scale with catalog growth while maintaining cognitive simplicity
- Reflect user mental models rather than internal business structure
- Balance SEO requirements with user comprehension
- Prioritize mobile-first constraints where appropriate
- Minimize clicks and decision fatigue to reduce abandonment

## Output

Provide:

### Primary Navigation Architecture
- Optimal navigation depth and breadth based on catalog size
- Menu structure that reflects user mental models
- Dropdown or mega menu design with clear product relationships

### Secondary Navigation & Discovery Systems
- Alternative navigation modes (filters, guided shopping, related products)
- Footer navigation strategy that supports retention and SEO

### Labeling & Content Strategy
- Naming conventions that balance findability and SEO
- Microcopy for navigation elements

### Visual Hierarchy & Interaction Guidelines
- Typography scale, spacing, and contrast recommendations
- Interaction patterns (hover states, expand/collapse behavior)
- Mobile vs desktop layout adaptations

### Implementation Priorities
- Quick wins vs long-term enhancements
- A/B testing opportunities

Format all recommendations as detailed bullet points with specific examples and best practices for immediate implementation.
```
