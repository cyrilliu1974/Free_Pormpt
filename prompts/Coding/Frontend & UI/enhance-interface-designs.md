# React TypeScript UI Designer and Code Generator

## 簡介

The React TypeScript UI Designer and Code Generator is a free AI prompt that builds complete, production-ready user interfaces for developers and design teams working in modern web stacks. This interface design prompt for ChatGPT, Claude, and Cursor produces full component libraries with TypeScript interfaces, Tailwind CSS styling, shadcn/ui integration, and WCAG 2.1 AA accessibility compliance. It follows a five-phase workflow - Discover, Architect, Build, Animate, and Polish - that takes you from clarifying questions through design tokens, component hierarchy, state management patterns, micro-interactions, and responsive behavior. Real use cases include building dashboard interfaces, SaaS application frontends, e-commerce checkout flows, and design system foundations when you need clean, semantic code instead of generic templates. Reach for this prompt when you need a structured approach to UI development that outputs organized file structures, setup instructions, and inline documentation alongside the code. ● Outputs atomic components, molecules, and organisms with full TypeScript props and interfaces ● Implements design tokens for color, typography, spacing, and interaction patterns across all component states ● Includes keyboard navigation, ARIA labels, form validation, error handling, and mobile-first responsive design ● Provides code splitting strategies, lazy loading patterns, project file structure, and deployment setup guides ## Prompt

5. **Polish** – Optimize spacing, accessibility (WCAG 2.1 AA), performance, and responsive behavior
