# Troubleshooting Guide Generator for Software & Systems

## 簡介

The Troubleshooting Guide Generator for Software & Systems is a free AI prompt that produces user-friendly technical documentation for diagnosing and resolving common problems in complex systems and applications. This troubleshooting guide prompt for ChatGPT helps technical writers and support teams create structured manuals that guide users through problem identification, diagnostic steps, and multiple resolution paths. It runs on ChatGPT, Claude, Gemini, and Grok, organizing output into sections covering introduction, step-by-step troubleshooting procedures, additional resources, and a summary. Each issue entry includes problem descriptions, recognizable symptoms, numbered diagnostic procedures, and bullet-pointed solutions that accommodate different scenarios. Real use cases include creating internal knowledge bases, customer-facing help documentation, and training materials for support staff working with software platforms, hardware systems, or enterprise applications. Reach for this prompt when you need to document common issues systematically or when building self-service support resources that reduce ticket volume and empower users to resolve problems independently. ● Produces markdown-formatted guides with clear problem descriptions, symptoms, diagnostic steps, and multiple solution options for each common issue ● Scales content accessibility by explaining technical terms and avoiding unnecessary jargon, making guides usable by novice and experienced users alike ● Includes sections for additional resources and support channels, connecting users to further help when self-service resolution is insufficient ● Generates consistent documentation structure that integrates easily into knowledge bases, help centers, and internal wikis ## Prompt

```
## Role
You are an expert technical writer who creates user-friendly troubleshooting guides for complex systems and applications.

## Task
Develop a comprehensive troubleshooting guide for {{system-or-application}} that enables users of varying technical skill levels to efficiently diagnose and resolve common problems on their own.

## Output
Structure the guide using markdown with these sections:

### 1. Introduction
- Brief overview of the system/application
- Purpose and scope of this troubleshooting guide

### 2. Troubleshooting Steps
For each common issue, provide:
- **Problem description** – what the issue is
- **Symptoms** – how users will recognize it
- **Diagnostic steps** – numbered procedures to identify the root cause
- **Solutions** – bullet-pointed resolution options (include multiple approaches where applicable)

### 3. Additional Resources
- Links to relevant documentation, forums, or support channels
- Contact information for further assistance

### 4. Conclusion
- Recap the guide's purpose
- Encourage users to refer to this guide when issues arise

## Guidelines
- Focus on common issues users are likely to encounter
- Write clear, concise problem descriptions and symptoms
- Provide step-by-step diagnostic procedures
- Make content accessible to users with varying technical expertise
- Explain any necessary technical terms; avoid jargon where possible
```
