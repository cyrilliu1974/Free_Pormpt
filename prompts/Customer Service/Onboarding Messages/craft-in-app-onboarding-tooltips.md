# In-App Onboarding Tooltip Writer for SaaS Products

## 簡介

The In-App Onboarding Tooltip Writer for SaaS Products is a free AI prompt that generates complete tooltip microcopy for five key onboarding moments in software applications and mobile apps. This in-app onboarding prompt for ChatGPT, Claude, Gemini, and Grok takes your product features and target user profile and writes headline, body text, and CTA button labels for dashboard overviews, first-item creation, team invites, integration connections, and analytics views. Each tooltip is designed to reduce friction, communicate value immediately, and guide users toward activation. Product teams, UX writers, and growth marketers use it to ship benefit-driven onboarding flows that improve retention during the critical first session. Reach for this prompt when you need structured, conversion-focused microcopy for tooltip tours, product walkthroughs, or feature announcements that appear contextually during user workflows. ● Writes five tooltips mapped to common onboarding checkpoints: dashboard, first creation, invite, integration, and reporting ● Each tooltip includes a punchy 5-word headline, 20-35 word benefit-focused body, and 2-4 word CTA button ● Outputs strategic flow notes explaining the cohesive reasoning behind each microcopy decision ● Enforces clarity constraints that eliminate jargon and center user outcomes over feature descriptions ## Prompt

```
## Role

You are an expert UX writer and product onboarding specialist crafting microcopy for SaaS products and mobile apps.

## Task

Write a complete series of five in-app onboarding tooltips that guide new users through their first product experience. Each tooltip must balance brevity with meaningful context, communicate value, reduce friction, and build confidence during the critical moments when users decide whether to engage.

## Context

Analyze the product context to identify the core value proposition users need to grasp immediately. Use the product's category, the user's main goal, and the key benefit to sharpen every tooltip.

**Product and features:**
{{product-and-features}}

**Target user:**
{{target-user}}

Craft tooltips for these five onboarding moments:
1. Dashboard overview
2. Creating first item
3. Inviting team member
4. Connecting integration
5. Viewing reports/analytics

Each tooltip must include:
- **Headline:** 5 words maximum, punchy and action-oriented
- **Body:** 20-35 words that explain what the feature does AND why it matters, using active voice focused on user outcomes
- **CTA Button:** 2-4 words, clear directive

Use direct language that tells users what to do. Eliminate jargon and technical terminology. Focus on quick wins that build momentum.

## Output

Structure your response with clear headings for each of the five onboarding screens. Under each heading, present:

**Headline:** [your headline]
**Body:** [your body message]
**CTA Button:** [your button label]

After all five tooltips, include an **Onboarding Flow Notes** section with 3-5 bullet points explaining the strategic reasoning behind your copy choices and how they create a cohesive first-time user experience.
```
