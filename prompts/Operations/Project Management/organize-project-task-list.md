# Project Task Breakdown and Prioritization Table

## 簡介

The Project Task Breakdown and Prioritization Table is a free AI prompt that transforms project descriptions into actionable, organized task lists with priorities, deadlines, and role assignments for project managers and team leaders. This project task breakdown prompt for ChatGPT analyzes your project description and outputs a clean table that breaks complex initiatives into granular tasks, assigns priority levels (High, Medium, Low), sets realistic deadlines, and specifies responsible parties. It runs on ChatGPT, Claude, Gemini, and Grok, delivering a structured format you can immediately share with your team or import into project management tools. Use it when launching a new initiative, planning a sprint, or reorganizing an existing workstream that needs clearer accountability and sequencing. ● Breaks down projects into granular, actionable tasks that cover all critical phases and deliverables ● Assigns priority labels based on urgency and importance to guide execution order ● Specifies realistic deadlines and responsible roles or individuals for accountability ● Outputs a table format that integrates easily into project tracking systems and team communications ## Prompt

```
## Role
You are a project manager creating a comprehensive, prioritized task breakdown.

## Task
Analyze the project description and generate a structured task list that:
- Breaks the project into granular, actionable tasks
- Prioritizes each task by urgency and importance
- Assigns realistic deadlines
- Specifies responsible parties
- Covers all critical aspects of the project

## Context
Project: {{project-description}}

## Output
Return only the completed table in this exact format:

**Project Name:** [derive from project description]

| Task | Priority | Deadline | Assigned To |
|------|----------|----------|-------------|
| [task 1] | [High/Medium/Low] | [date] | [role/person] |
| [task 2] | [High/Medium/Low] | [date] | [role/person] |
| [task 3] | [High/Medium/Low] | [date] | [role/person] |
| [task 4] | [High/Medium/Low] | [date] | [role/person] |
| [task 5] | [High/Medium/Low] | [date] | [role/person] |
| [task 6] | [High/Medium/Low] | [date] | [role/person] |
| [task 7] | [High/Medium/Low] | [date] | [role/person] |
| [task 8] | [High/Medium/Low] | [date] | [role/person] |
| [task 9] | [High/Medium/Low] | [date] | [role/person] |
| [task 10] | [High/Medium/Low] | [date] | [role/person] |

Include more rows if the project requires additional tasks. Provide no commentary outside the table.
```
