# Industry Event Presentation Planner for Solopreneurs

## 簡介

The Industry Event Presentation Planner for Solopreneurs is a free AI prompt that creates comprehensive, brand-focused presentation strategies for independent professionals speaking at conferences, summits, and industry gatherings. This industry event presentation prompt for ChatGPT guides solopreneurs through eight structured stages - from audience analysis and brand positioning to dependency-based content architecture and delivery tactics. It applies dependency grammar principles to ensure each idea logically builds on the previous one, creating coherent narratives rather than disconnected talking points. The prompt works on ChatGPT, Claude, and Gemini, producing actionable plans that include opening hooks, supporting evidence selection, visual design specifications, and concrete calls-to-action. Real use cases span tech founders presenting at startup showcases, consultants leading workshop sessions, and creators keynoting niche community events. This prompt is for solopreneurs who want to move beyond generic slide decks and craft talks that differentiate their personal brand, demonstrate expertise, and convert audience attention into business relationships. ● Analyzes target audience pain points and event format to tailor messaging and interaction design ● Structures content using dependency grammar so each concept reinforces the last, improving comprehension and recall ● Specifies opening hooks, supporting case studies, visual slide concepts, and rehearsal priorities for confident delivery ● Designs audience-specific calls-to-action that turn passive listeners into active connections or customers ## Prompt

```
## Role
You are an expert public speaker and personal branding strategist specializing in solopreneur positioning at industry events.

## Task
Create a comprehensive presentation plan that establishes a compelling personal brand. Organize the content using dependency grammar principles—structuring ideas so that each point builds logically on previous ones to maximize audience engagement and clarity.

## Context
{{solopreneur-profile}}

## Process
Develop the presentation through these stages:

1. **Audience & Event Analysis**: Assess who will attend, their pain points, expectations, and the event format.

2. **Brand Foundation**: Identify the core expertise, unique value proposition, and vision elements that distinguish this solopreneur from competitors.

3. **Dependency-Based Outline**: Structure main points so each concept depends on and reinforces the previous one, creating a logical narrative flow rather than isolated topics.

4. **Opening Hook**: Craft an introduction that immediately captures attention—use a provocative question, surprising statistic, or resonant story.

5. **Supporting Evidence**: For each main point, prepare concrete examples, case studies, or personal anecdotes that demonstrate expertise and build credibility.

6. **Visual Design**: Specify slide concepts, diagrams, or props that reinforce key messages without cluttering or distracting.

7. **Call-to-Action**: Design a clear, specific next step for the audience—whether connecting on a platform, visiting a resource, or adopting a framework.

8. **Delivery Notes**: Include timing, emphasis points, audience interaction moments, and rehearsal priorities.

## Output
Provide a detailed, step-by-step presentation plan with clear instructions for each stage. Format as numbered sections with actionable guidance the solopreneur can immediately implement.
```
