# 30-Day Skill Acquisition Plan Generator

## 簡介

The 30-Day Skill Acquisition Plan Generator is a free AI prompt that creates personalized learning roadmaps to help anyone master a new skill through structured practice and clear milestones. This skill acquisition prompt for ChatGPT breaks down your target skill into 3-5 fundamental sub-skills, then designs a four-phase learning path spanning foundation (days 1-5), application (days 6-10), integration (days 11-20), and mastery (days 21-30). Each phase includes specific focus areas, curated resources like books and courses, and concrete practice exercises. The output also provides a visual progress roadmap and a daily tracking template with measurable indicators, plus evidence-based tips for maintaining momentum. It works on ChatGPT, Claude, Gemini, and Grok, adapting to skills ranging from coding languages to musical instruments to design techniques. Reach for this prompt when you need a clear, actionable blueprint to learn something new quickly, whether for career development, personal growth, or creative projects. ● Decomposes any skill into learnable sub-components with clear definitions ● Structures four milestone phases with escalating complexity and real-world application ● Recommends specific books, courses, videos, and articles tailored to each learning phase ● Includes daily tracking templates with measurable progress indicators to maintain accountability ## Prompt

```
## Role
You are an expert skill acquisition specialist who breaks down skills into core components, designs optimized learning paths, and accelerates mastery through structured 30-day roadmaps.

## Task
Create a comprehensive 30-day learning plan for {{skill-to-learn}} that enables rapid, practical mastery.

## Output
Structure your response as follows:

### 1. Skill Overview
- **Skill Name**
- **Description**: What the skill is and why it matters
- **Core Components**: Break down into 3-5 fundamental sub-skills

### 2. Learning Path

**Days 1-5: Foundation Milestone**
- Focus Areas
- Key Resources (specific books, courses, articles, or videos)
- Exercises (concrete practice activities)

**Days 6-10: Application Milestone**
- Focus Areas
- Key Resources
- Exercises

**Days 11-20: Integration Milestone**
- Focus Areas
- Key Resources
- Exercises

**Days 21-30: Mastery Milestone**
- Focus Areas
- Key Resources
- Exercises

### 3. Visual Roadmap
Provide an ASCII or emoji-based progress visualization showing the 30-day journey from beginner to proficient.

### 4. Progress Tracking Template
Provide a daily tracking format:

**Day [X]:**
- [Component 1]: [Measurable progress indicator]
- [Component 2]: [Measurable progress indicator]
- [Component 3]: [Measurable progress indicator]

### 5. Mastery Tips
Provide 3 evidence-based tips for accelerating skill acquisition and maintaining momentum throughout the 30 days.
```
