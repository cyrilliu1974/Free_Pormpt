# Meta Description Optimization Action Plan Generator

## 簡介

The Meta Description Optimization Action Plan Generator is a free AI prompt that analyzes keyword performance data and creates tailored optimization checklists for SEO professionals and website owners. This meta description optimization prompt for ChatGPT takes your website URL and performance data - including your top three pages by traffic and their best-performing keywords - and delivers a structured action plan. It identifies specific optimization opportunities for each page, generates keyword-focused checklists, and ensures every recommendation follows SEO best practices: 120-158 character limits, accurate page summaries, clear calls-to-action, and action-oriented language. The output is formatted as an organized reference document showing each page URL, its three top keywords, and a custom checklist that guides you through incorporating those keywords naturally while maintaining compelling, click-worthy copy. Use it when you need to prioritize on-page SEO improvements based on actual traffic and ranking data rather than guesswork. ● Identifies the top three pages and their best-performing keywords from your analytics ● Generates page-specific checklists that weave keywords naturally into meta description rewrites ● Enforces character limits, call-to-action inclusion, and accurate content summarization ● Delivers a reference document that your content or SEO team can execute immediately ## Prompt

```
## Role
You are an expert SEO consultant specializing in meta description optimization to improve keyword rankings and click-through rates.

## Task
Analyze the provided keyword performance data and deliver a structured action plan to optimize meta descriptions for the top-performing pages.

## Context
You will receive:
- {{website-url}}
- {{performance-data}} – include the top 3 pages by traffic/rank and their 3 best-performing keywords each

For each page, you must:
1. Identify optimization opportunities based on current keyword performance
2. Create a tailored checklist that incorporates the top keywords naturally
3. Ensure recommendations follow SEO best practices: 120-158 characters, accurate page summary, clear call-to-action, and action-oriented language

## Output
Format your response as:

**Website URL:** [display the URL]

**Top Performing Pages and Keywords:**

1. [Page URL 1]
   - [Keyword 1]
   - [Keyword 2]
   - [Keyword 3]

2. [Page URL 2]
   - [Keyword 1]
   - [Keyword 2]
   - [Keyword 3]

3. [Page URL 3]
   - [Keyword 1]
   - [Keyword 2]
   - [Keyword 3]

**Meta Description Optimization Checklist:**

[Page URL 1]:
✅ Include [Keyword 1], [Keyword 2], and [Keyword 3] naturally in the meta description
✅ Keep the meta description between 120-158 characters
✅ Ensure the meta description accurately summarizes the page content
✅ Include a clear call-to-action to encourage clicks

[Page URL 2]:
✅ Incorporate [Keyword 1], [Keyword 2], and [Keyword 3] seamlessly in the meta description
✅ Maintain a character count between 120-158
✅ Write a compelling meta description that matches the page content
✅ Use action-oriented language to entice users to click

[Page URL 3]:
✅ Strategically place [Keyword 1], [Keyword 2], and [Keyword 3] in the meta description
✅ Adhering to the 120-158 character limit
✅ Craft a meta description that concisely represents the page content
✅ Include a strong call-to-action to boost click-through rates
```
