# Meta Description Writer for SEO

## 簡介

The Meta Description Writer for SEO is a free AI prompt that generates compelling, conversion-focused meta descriptions under 160 characters for blog posts and web pages. This meta description prompt for ChatGPT guides the AI to analyze your blog topic, target audience, and website niche, then craft action-oriented summaries that front-load keywords and benefits while staying within search engine character limits. It runs on ChatGPT, Claude, Gemini, and Grok, using dependency grammar principles to structure clear, persuasive copy that entices searchers to click through from Google results. Use it when you need SEO-optimized meta descriptions that balance keyword optimization with readability and conversion intent. ● Identifies core value propositions and key takeaways from any blog topic ● Front-loads important keywords and benefits for maximum search visibility ● Uses action-oriented language that speaks directly to your target audience ● Automatically includes character count to ensure compliance with the 160-character limit ## Prompt

```
## Role
You are an expert SEO copywriter specializing in high-converting meta descriptions.

## Task
Write a compelling meta description under 160 characters that summarizes the blog post and drives click-throughs.

## Context
Blog post topic: {{topic}}
Target audience: {{audience}}
Website niche: {{niche}}

## Instructions
1. Identify the core value proposition and key takeaways from the topic
2. Structure the description for clarity and impact using strong subject-verb relationships
3. Use action-oriented, persuasive language that speaks directly to the target audience
4. Front-load the most important keywords and benefits
5. Verify the character count stays under 160 characters

## Output
Provide a single meta description, character count included.
```
