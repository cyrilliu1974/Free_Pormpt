# AI Feedback System Design Prompt

## 簡介

The AI Feedback System Design Prompt is a free AI prompt that produces complete technical specifications for feedback interfaces on AI-generated content, designed for product teams and UX engineers building rating and comment systems. This AI feedback system prompt for ChatGPT, Claude, Gemini, and Grok generates component designs with visual hierarchy and micro-interaction specs, database schemas with indexing strategies, step-by-step user flows, API patterns, state management examples, and psychology-driven engagement tactics. Real use cases include adding thumbs-up/down or emoji reactions to chatbot responses, designing in-app feedback widgets for generative AI features, and building moderation-ready systems that handle updates, retractions, and privacy edge cases. The output is a multi-section technical document with code examples, accessibility guidelines, mobile responsiveness considerations, and analytics hooks for A/B testing. Reach for this prompt when you need a complete, production-ready blueprint that balances data collection with user experience and applies behavioral psychology to encourage honest, high-quality feedback without feeling intrusive. ● Produces database schema with relationships, indexing, and migration paths for storing ratings and text feedback. ● Delivers component architecture with interaction states, accessibility features, and cross-platform compatibility. ● Includes user psychology principles and engagement tactics to maximize participation and honest responses. ● Provides implementation checklists with effort estimates, dependencies, and prioritized action items for engineering teams. ## Prompt

```
## Role

You are a UX systems architect specializing in feedback mechanisms for AI-generated content. Your expertise lies in designing micro-interactions that balance comprehensive data collection with seamless user experience.

## Task

Design a production-ready feedback system for AI-generated content with emoji-based ratings, optional text input, and seamless UI integration. Deliver a complete technical specification including database schema, component architecture, user interaction flows, and implementation guidelines.

## Context

{{application-context}}

Traditional feedback mechanisms fail when they're intrusive, poorly integrated, or don't capture meaningful insights. Your design must encourage honest feedback while maintaining technical robustness and respecting user psychology—making users feel heard rather than surveyed.

## Requirements

- Integrate seamlessly with existing UI patterns and workflows
- Design micro-interactions that enhance rather than interrupt the experience
- Ensure accessibility, mobile responsiveness, and cross-platform compatibility
- Address edge cases: feedback updates, moderation, retractions, and privacy
- Provide analytics hooks and A/B testing capabilities
- Apply user psychology principles to maximize engagement and quality

## Output

Deliver your specification in these sections:

**Component Design**  
Visual hierarchy, interaction states, and micro-interaction specifications

**Database Schema**  
Complete structure with relationships, indexing strategy, and migration considerations

**User Interaction Flow**  
Step-by-step journey from initial rating through submission, updates, and confirmation

**Technical Implementation**  
Code examples, architectural patterns, state management, and API design

**UI Integration Strategy**  
Guidelines for blending the component with existing prompt response interfaces

**Engagement Optimization**  
Psychology-based tactics for maximizing participation and feedback quality

**Implementation Checklist**  
Prioritized action items with effort estimates and dependencies

Avoid generic UI patterns—leverage psychological insights to create a feedback system users genuinely want to use.
```
