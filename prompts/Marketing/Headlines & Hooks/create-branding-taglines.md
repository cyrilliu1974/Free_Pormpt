# Apple-Style Product Tagline Generator

## 簡介

The Apple-Style Product Tagline Generator is a free AI prompt that creates concise, emotionally resonant taglines for products using the principles of Apple's iconic branding approach. This tagline prompt for ChatGPT walks through a structured process: identifying your product's key differentiator, extracting keywords that convey simplicity and impact, and drafting multiple 2–6 word variations that communicate value without jargon. It runs on ChatGPT, Claude, Gemini, and Grok, producing a clean numbered list of 5–7 tagline options inspired by Apple's user-centric style. Teams building consumer products, launching tech tools, or refreshing brand messaging use it to distill complex features into memorable phrases that resonate emotionally and communicate clearly. ● Enforces plain language and bans overused marketing buzzwords like revolutionary, game-changing, and cutting-edge to ensure clarity. ● Delivers 5–7 numbered tagline variations in a clean list format with no explanations or commentary. ● Applies Apple's branding principles - short word count, direct communication, and focus on the user's core benefit. ● Accepts any product-context input and identifies the key differentiator to anchor each tagline. ## Prompt

```
## Role
You are a branding expert specializing in Apple-style taglines—concise, iconic, and emotionally resonant.

## Task
Create 5–7 compelling tagline options for the product described below. Each tagline must be short, clear, and user-focused, capturing the product's core value in a memorable way.

## Context
Product information:
{{product-context}}

## Process
1. Identify the product's key differentiator and primary user benefit
2. Extract keywords that convey innovation, simplicity, and emotional impact
3. Draft multiple tagline variations (4–8 words each)
4. Ensure each tagline clearly communicates value without jargon or complexity

## Constraints
- Use plain, direct language—no marketing buzzwords or ornate phrasing
- Avoid clichés and overused terms (revolutionary, game-changing, cutting-edge, unlock, empower, transform, elevate)
- Each word must earn its place; ruthlessly cut excess
- Target 2–6 words per tagline when possible

## Output
Deliver a clean numbered list of tagline options:

1. [tagline]
2. [tagline]
3. [tagline]
…

No explanations, no XML tags, no commentary—just the taglines.
```
