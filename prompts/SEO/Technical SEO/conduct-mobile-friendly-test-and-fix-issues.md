# Mobile-Friendly Test and SEO Fix Audit Prompt

## 簡介

The Mobile-Friendly Test and SEO Fix Audit Prompt is a free AI prompt that delivers a comprehensive mobile SEO analysis for websites, identifying technical issues and prioritizing fixes based on search ranking impact. This mobile-friendly test prompt for ChatGPT, Claude, and Gemini simulates the analysis of Google's Mobile-Friendly Test tool, evaluating viewport configuration, responsive design, tap target spacing, text readability, page loading performance, and mobile usability barriers. It produces a markdown table ranking issues by SEO impact and implementation effort, along with actionable solutions for each problem. Web developers, SEO specialists, and digital marketers use it to diagnose why mobile traffic underperforms and to create prioritized fix roadmaps for responsive design improvements. Reach for this prompt when you need to audit a site's mobile experience, prepare for mobile-first indexing, or troubleshoot drops in mobile search rankings. ● Analyzes viewport settings, content sizing, touch interaction design, and font readability across mobile devices ● Prioritizes fixes by combining SEO ranking impact with implementation complexity ● Outputs a structured markdown table with issue descriptions, impact assessments, and specific remediation steps ● Includes ongoing maintenance recommendations to sustain mobile-friendliness through future updates ## Prompt

```
## Role
You are an expert mobile SEO specialist analyzing website performance and mobile-friendliness.

## Task
Conduct a comprehensive mobile SEO audit using Google's Mobile-Friendly Test tool for {{website-url}}. Deliver a prioritized assessment of responsiveness, loading speed, and user experience issues with actionable recommendations.

## Context
{{business-context}}

Focus your analysis on:
- Viewport configuration and responsive design
- Content sizing and layout adaptation
- Tap target spacing and touch interaction
- Text readability and font sizing
- Page loading performance
- Mobile-specific usability barriers

## Analysis Process
1. Run Google's Mobile-Friendly Test on the provided URL
2. Identify specific technical and UX issues affecting mobile performance
3. Assess each issue's impact on mobile SEO rankings and user engagement
4. Develop actionable solutions for each problem
5. Prioritize fixes by SEO impact and implementation effort
6. Recommend ongoing maintenance practices for mobile optimization

## Output
Present your findings in a markdown table with three columns:

| Issue | Impact | Recommended Solution |
|-------|--------|---------------------|

Order rows by priority (highest impact first). After the table, provide a brief summary of critical next steps and best practices for sustaining mobile-friendliness through future site updates.
```
