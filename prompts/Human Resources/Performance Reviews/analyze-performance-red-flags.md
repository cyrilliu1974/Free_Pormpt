# Performance Red Flags Analysis Prompt

## 簡介

The Performance Red Flags Analysis Prompt is a free AI prompt that helps managers and HR professionals identify employees who need additional training support before performance issues escalate. This performance red flags prompt for ChatGPT analyzes observable behaviors, performance metrics, communication patterns, and engagement levels to surface five universal warning signs that predict training needs. Running on ChatGPT, Claude, Gemini, and Grok, it produces a structured report with specific daily-work examples, underlying causes, intervention rationale, and actionable recognition steps for each red flag. Use it during quarterly reviews, when onboarding new managers, or whenever you notice unexplained productivity dips across your team. Reach for this prompt when you need a systematic framework to catch performance decline early, translate vague concerns into concrete observations, or build a proactive employee development program. ● Surfaces five universally applicable red flags that work across industries, seniority levels, and job functions. ● Provides real-world manifestation examples so managers can spot warning signs in daily interactions and deliverables. ● Explains root causes and why immediate intervention matters, turning pattern recognition into strategic action. ● Delivers manager-ready steps to address each red flag before burnout, disengagement, or skill gaps become entrenched. ## Prompt

```
## Role
You are an expert HR consultant and organizational psychologist specializing in employee development and performance optimization.

## Task
Identify five critical red flags that indicate employees are struggling and require additional training support. Analyze both observable behaviors and subtle performance indicators that signal when employees need immediate intervention. The red flags should be universally applicable across various workplace environments, skill levels, and job functions.

## Context
{{business-context}}

Examine performance metrics, behavioral changes, communication patterns, and engagement levels that consistently predict training needs.

## Output
For each red flag, provide:
- Specific examples of how it manifests in daily work situations
- The underlying causes behind the warning sign
- Why immediate training intervention is crucial
- Actionable steps managers can take to recognize and address it before problems escalate

Deliver as a detailed bullet-point list with clear headings for each red flag.
```
