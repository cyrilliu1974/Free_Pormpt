# Task Prioritization Workshop Template Generator

## 簡介

The Task Prioritization Workshop Template Generator is a free AI prompt that builds ready-to-use templates for facilitating team prioritization sessions. This task prioritization prompt for ChatGPT produces a structured workshop framework organized into six sections: workshop overview with objectives and participant roles, pre-workshop preparation checklists, a detailed agenda with time allocations, descriptions of 3-4 prioritization techniques appropriate for your context, post-workshop action plans with accountability measures, and facilitation tips for managing participation and conflict. You provide your workshop context - team size, project type, duration, and specific challenges - and the prompt generates a complete template that first-time facilitators can follow. Teams use it to prepare for sprint planning sessions, product roadmap reviews, backlog grooming, and cross-functional prioritization meetings. It runs on ChatGPT, Claude, and Gemini. The template is designed for project managers, team leads, scrum masters, and anyone responsible for running prioritization workshops who need a proven structure rather than building one from scratch. ● Outputs a workshop overview section with measurable objectives, participant roles, and duration guidelines ● Provides pre-workshop preparation checklists covering materials, communication, and logistics ● Includes a detailed agenda with 5-7 time-boxed segments and transition guidance between sections ● Delivers descriptions of multiple prioritization techniques with decision criteria for when to apply each method ● Generates post-workshop documentation requirements, communication plans, and follow-up accountability measures ● Includes facilitation tips addressing time management, engagement, conflict resolution, and common pitfalls ## Prompt

```
## Task

Create a comprehensive template for running a task prioritization workshop that covers preparation, execution, and follow-through.

## Context

This workshop template will be used to facilitate team prioritization sessions. Adapt the structure to fit:

{{workshop-context}}

*Include team size, project type, typical workshop duration, and any specific prioritization challenges your team faces.*

## Output Structure

Deliver a ready-to-use workshop template organized into these sections:

**Workshop Overview**
- Purpose
- Key Objectives (3-5 measurable outcomes)
- Participants (roles and decision-making authority)
- Duration

**Pre-Workshop Preparation**
- Information gathering requirements
- Materials and tools to prepare
- Participant communication and pre-work
- Logistics and environment setup

**Workshop Agenda**
- Detailed timeline with 5-7 agenda items
- Time allocation for each segment
- Key activities and discussion points for each item
- Transition guidance between sections

**Prioritization Techniques**
- 3-4 specific techniques appropriate for the workshop context
- Clear description of each method
- Guidance on when to apply each technique
- Examples of output from each method

**Post-Workshop Actions**
- Documentation requirements
- Communication plan for decisions
- Implementation tracking approach
- Follow-up cadence and accountability measures

**Facilitation Tips**
- Time management strategies
- Participation and engagement techniques
- Conflict resolution approaches
- Common pitfalls and how to avoid them

## Requirements

- Make the template adaptable across different team sizes and project types
- Emphasize concrete actions in pre-workshop and post-workshop sections
- Include specific time estimates that can be scaled
- Provide decision criteria for selecting prioritization techniques
- Keep instructions clear enough for first-time facilitators
```
