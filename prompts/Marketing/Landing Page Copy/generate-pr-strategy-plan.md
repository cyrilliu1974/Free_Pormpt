# PR Strategy Plan Generator for Organizations

## 簡介

The PR Strategy Plan Generator is a free AI prompt that creates a structured public relations strategy for organizations seeking to build, strengthen, or protect their reputation with stakeholders and the public. This PR strategy prompt for ChatGPT guides the AI to develop a multi-faceted plan based on your organization context - including industry, products, value proposition, competitors, target markets, current versus desired reputation, budget, and internal resources. It produces a six-part strategic document with clearly defined goals, target audiences, core messages, tactical plans with budget estimates and KPIs, crisis management protocols with holding statements, and evaluation frameworks. Organizations use it to align internal teams, prepare for media outreach campaigns, anticipate reputation threats, and establish measurable milestones for their communications efforts. Reach for this prompt when you need a complete PR roadmap that connects messaging to metrics, whether you are launching a new initiative, managing a rebrand, or formalizing your communications function. ● Maps three core goals to specific target audiences and key messages for alignment across campaigns ● Designs tactical initiatives with concrete KPIs, budget estimates, and resource requirements ● Includes crisis preparedness with potential threat scenarios, holding statements, and step-by-step response protocols ● Defines evaluation metrics, monitoring tools, reporting cadence, and success benchmarks for accountability ## Prompt

```
## Role
You are an expert public relations strategist developing a comprehensive strategy to establish, strengthen, and protect an organization's reputation with key stakeholders and the general public.

## Task
Create a multi-faceted public relations strategy that covers messaging, tactics, crisis preparedness, and measurement. The strategy must be actionable, with specific KPIs and resource allocations.

## Context
{{organization-context}}

Include: organization name, industry, key products/services, unique value proposition, major competitors, target markets, current reputation vs. desired reputation, PR budget, and available internal PR resources.

## Output
Deliver the strategy in the following structure:

### 1. Goals
List 3 key goals the strategy aims to achieve.

### 2. Target Audiences
Identify 3 main target audiences for the PR efforts.

### 3. Key Messages
Develop 3 core messages to communicate to the target audiences.

### 4. Tactics
Outline 3 specific tactics to implement the strategy. For each tactic provide:
- Description
- KPIs to measure success
- Budget estimate

### 5. Crisis Management
- List 3 potential issues that could threaten the organization's reputation
- Provide 3 holding statements to use in response to crises
- Outline a step-by-step crisis response protocol

### 6. Evaluation and Measurement
- Define 3 KPIs to track overall success of the PR strategy
- Specify monitoring tools to be used and frequency of monitoring
- Determine the cadence for reporting on progress and results

Use clear headings and bullet points throughout.
```
