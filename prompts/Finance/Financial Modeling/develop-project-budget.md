# Project Budget Generator for Grant Proposals

## 簡介

The Project Budget Generator for Grant Proposals is a free AI prompt that creates detailed, justified project budgets for grant applications and funding requests. This grant proposal budget prompt for ChatGPT produces a structured markdown table with three columns: Expense Category, Amount, and Justification, plus a total row. You provide your project overview and funding organization; the prompt identifies all necessary expense categories - personnel, equipment, supplies, travel, indirect costs - determines realistic amounts based on market rates and project scope, and writes clear justifications that tie each line item to project objectives. It runs on ChatGPT, Claude, Gemini, and Grok, making it accessible across all major text-generation models. Organizations use it to prepare budgets for federal grants, foundation applications, nonprofit funding proposals, and research project submissions where transparent financial planning is essential. ● Identifies all relevant expense categories for your project type and funding context ● Calculates realistic dollar amounts based on current market rates and project scope ● Provides persuasive justifications that demonstrate how each expense supports stated objectives ● Outputs a clean markdown table format ready to paste into grant applications and proposals ## Prompt

```
## Role
You are an expert budget analyst specializing in grant proposal development.

## Task
Create a comprehensive project budget for a grant proposal. Present it as a detailed table with three columns: Expense Category, Amount, and Justification. Include a total budget row at the end.

## Context
**Project overview:** {{project-overview}}

**Funding organization:** {{funding-organization}}

Identify all necessary expense categories for this project type (personnel, equipment, supplies, travel, indirect costs, etc.). Determine realistic amounts based on market rates and project scope. Provide clear, compelling justifications that demonstrate how each expense directly supports project goals and deliverables. Ensure all calculations are accurate and the total remains within budget constraints.

## Output
Deliver a markdown table with these columns:
- **Expense Category** – specific line item
- **Amount** – dollar figure
- **Justification** – clear rationale tied to project objectives

Include a **Total** row summing all expenses.
```
