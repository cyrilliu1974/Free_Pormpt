# Site-Wide Meta Tag Optimization Prompt

## 簡介

The Site-Wide Meta Tag Optimization Prompt is a free AI prompt that creates unique meta titles and descriptions for entire websites, designed for SEO specialists and content teams managing multiple pages. This meta tag optimization prompt for ChatGPT analyzes your website context, target audience, and primary keywords to generate character-perfect meta titles (50-60 characters) and descriptions (150-160 characters) for different page types. It applies dependency grammar principles to structure compelling copy that balances keyword placement with natural language, ensuring each tag accurately represents page content while maximizing organic click-through rates. The output is a structured markdown table covering homepage, product pages, category pages, blog posts, and company pages, plus strategic notes on keyword placement and user intent. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when launching a new site, conducting an SEO audit, or scaling content without duplicating meta tags across hundreds of pages. ● Produces meta titles and descriptions that fit exact character limits (50-60 and 150-160) to avoid truncation in search results ● Ensures zero duplication across page types by tailoring messaging to specific content and user intent ● Applies dependency grammar to build phrases around strong head words for clearer, more compelling copy ● Includes strategic notes explaining keyword placement logic and how each tag addresses searcher needs ## Prompt

```
## Role
You are an SEO specialist optimizing meta tags to improve search visibility and drive organic traffic.

## Task
Create unique, compelling meta titles and descriptions for a website using dependency grammar principles. Analyze the site's content, keywords, and audience to craft tags that accurately represent each page while maximizing click-through rates from search results.

## Context
Website and business details:
{{website-and-business-context}}

Include: website URL, target audience characteristics, top 5 primary keywords, industry, and unique selling proposition.

## Requirements
- Each meta title: 50-60 characters, include primary keyword near the beginning
- Each meta description: 150-160 characters, incorporate secondary keywords naturally, include a clear value proposition or call-to-action
- Apply dependency grammar framework: structure phrases around head words with clear grammatical relationships
- Balance keyword optimization with natural, engaging language that appeals to human readers
- Ensure every meta tag is unique across pages—no duplication
- Tailor messaging to the target audience's search intent and pain points

## Output
Provide a markdown table with three columns: **Page Type/URL** | **Meta Title** | **Meta Description**

Include examples for at least five different page types:
- Homepage
- Product or service page
- Category or collection page
- Blog post or article
- About or company page

After the table, add brief notes explaining your keyword placement strategy and how each tag addresses user intent.
```
