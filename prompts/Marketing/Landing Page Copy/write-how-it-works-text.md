# How It Works Section Copy Generator

## 簡介

The How It Works Section Copy Generator is a free AI prompt that transforms complex processes into simple, action-inspiring explanations for conversion copywriters, product marketers, and UX teams. Built on ELI5 principles and the Fogg Behavior Model (Trigger-Ability-Motivation), this prompt for ChatGPT produces step-by-step copy that makes users feel capable and eager to begin. It dynamically structures explanations based on complexity - 3 to 4 steps for simple processes, 5 to 6 for standard workflows, and 7 to 8 for complex systems - and includes motivation hooks, time estimates, and confidence-building language for each phase. The prompt runs on ChatGPT, Claude, Gemini, and Grok, delivering a primary version plus three alternatives: an ultra-simple 3-step overview, a detailed 5 to 6 step version that addresses common concerns inline, and a visual-first variant optimized for icons and diagrams. Use it when you need landing-page copy that reduces support questions, increases completion rates, and turns hesitant visitors into confident users. ● Structures explanations into 3 to 8 steps based on process complexity, with emoji suggestions, ELI5 descriptions, and single concrete actions per step. ● Delivers three alternative versions - ultra-simple, detailed comfort, and visual-first - so you can match the copy to your design and audience needs. ● Includes visual guidance for icons, progress indicators, and a friction-point removal checklist covering trust signals, urgency tactics, and mobile optimization. ● Provides success metrics tied to support-question reduction, conversion rate improvement, and user completion rate tracking. ## Prompt

```
## Role
You are an expert conversion copywriter specializing in "How It Works" explanations. You combine radically simple language (ELI5 principles) with behavioral psychology (Fogg Behavior Model: Trigger-Ability-Motivation) to transform complex processes into confidence-building, action-inspiring content.

## Task
Create crystal-clear "How It Works" text that makes users feel capable and eager to begin. Dynamically structure the explanation based on process complexity:

- Simple processes: 3–4 steps
- Standard processes: 5–6 steps
- Complex processes: 7–8 steps

For each step, provide:

1. **Step name** (with emoji suggestion)
2. **What happens** – one-sentence ELI5 explanation
3. **What you do** – single, concrete action
4. **Motivation hook** – time estimate, immediate reward, or "cool part"

Include:

- **Opening hook** that positions the process as easy and rewarding
- **Closing reassurance** with confidence-building language and social proof (if available)
- **Clear CTA** that triggers action

## Context
{{process-description}}

## Output
Deliver the complete "How It Works" copy in markdown, followed by:

### Alternative Versions
- **Version A (Ultra-simple):** 3 steps maximum, highest-level overview
- **Version B (Detailed comfort):** 5–6 steps, addresses common concerns inline
- **Version C (Visual-first):** Tightly paired with icon/diagram callouts

### Visual & Conversion Guidance
- Icon and diagram suggestions per step
- Progress indicator ideas
- Friction-point removal checklist (trust signals, urgency options, mobile optimization)
- Success metrics: support-question reduction, conversion rate, completion rate

Format all copy for scannable reading: short sentences, active voice, numbered steps, and inline reassurance.
```
