# SEO Content Audit Prompt for Website Optimization

## 簡介

The SEO Content Audit Prompt for Website Optimization is a free AI prompt that systematically analyzes every page of a website and outputs a detailed audit table with prioritized SEO recommendations for content strategists and digital marketers. This content audit prompt for ChatGPT evaluates word count, keyword density, on-page elements, internal linking, and user intent alignment across your entire site. You supply your website URL, target audience, and primary keywords; the prompt then produces a markdown table showing each page's content type, metrics, and 3-5 actionable recommendations ranked by impact. It runs on ChatGPT, Claude, and Gemini, making it adaptable to your preferred text model. Teams use it to identify thin content, keyword cannibalization, missing meta descriptions, and internal linking gaps before major site refreshes or quarterly SEO reviews. Reach for this prompt when you need a repeatable, structured framework for auditing content at scale rather than manual spreadsheet workflows. ● Evaluates six core SEO dimensions per page: word count, keyword density, content quality, on-page elements, internal links, and user intent ● Outputs a sortable markdown table with dedicated columns for metrics and 3-5 ranked recommendations per URL ● Adapts to any industry by accepting custom target audience and primary keyword inputs ● Surfaces high-impact fixes first so teams can triage optimization work by expected ROI ## Prompt

```
## Role
You are an expert SEO content auditor conducting a comprehensive audit to identify optimization opportunities.

## Task
Analyze each page of the website systematically, evaluating content quality, structure, and SEO performance. Document findings and provide specific, actionable recommendations for improvement.

## Context
**Website:** {{website-url}}
**Target audience:** {{target-audience}}
**Primary keywords:** {{primary-keywords}}

## Assessment Criteria
For each page, evaluate:
- Word count and content depth
- Keyword density and placement
- Content relevance and quality
- On-page optimization elements (titles, headings, meta descriptions)
- Internal linking opportunities
- User intent alignment

## Output
Present your audit as a markdown table with these columns:

| Page URL | Content Type | Word Count | Keyword Density | Optimization Recommendations |
|----------|--------------|------------|-----------------|------------------------------|

For each page, provide 3-5 specific, prioritized recommendations that address the most impactful SEO improvements.
```
