# Brand Messaging Framework Generator for ChatGPT

## 簡介

The Brand Messaging Framework Generator is a free AI prompt that builds a cohesive brand messaging system for companies establishing or refining their market identity. This brand messaging framework prompt for ChatGPT analyzes your company's mission, values, and target market to produce three interconnected components: a defined brand voice that reflects your company's personality, 3-5 messaging pillars that communicate core value propositions, and detailed audience personas with demographic and psychographic profiles. The output is delivered as a structured markdown table that shows how voice, message, and audience align to create a unified brand presence. Runs on ChatGPT, Claude, and Gemini. This prompt is built for brand strategists, marketing directors, and founders who need to document a strategic foundation for all customer-facing communications. ● Analyzes mission statements, core values, and unique positioning to extract authentic brand voice characteristics ● Identifies 3-5 messaging pillars that translate company values into customer-facing value propositions ● Creates target audience personas that include motivations, pain points, and psychographic details ● Delivers all components in a three-column markdown table that reveals how brand elements interconnect and reinforce one another ## Prompt

```
## Role
You are an expert brand strategist developing a comprehensive Brand Messaging Framework.

## Task
Establish a consistent brand voice, key messaging pillars, and target audience personas that align with the company's values, mission, and unique positioning.

## Context
**Company:** {{company-name}}
**Industry:** {{industry}}
**Mission Statement:** {{mission-statement}}
**Core Values:** {{core-values}}
**Target Market:** {{target-market}}

## Process
1. Analyze the company's values, mission, and unique selling propositions
2. Define a brand voice that authentically reflects these foundational elements
3. Identify 3-5 key messaging pillars that support the brand's core message
4. Create detailed target audience personas incorporating demographic and psychographic characteristics
5. Ensure all framework elements are cohesive and mutually reinforcing

## Output
Present the Brand Messaging Framework as a markdown table with 3 columns:
- **Brand Voice**: Tone, personality traits, and communication style
- **Messaging Pillars**: Core themes and value propositions
- **Target Personas**: Detailed audience segments with motivations and pain points

Provide a brief explanation for each element in the respective cells, showing how they interconnect to create a powerful, unified brand identity.
```
