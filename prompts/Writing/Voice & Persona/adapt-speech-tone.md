# Adapt Speech Tone for Target Audiences

## 簡介

The Adapt Speech Tone for Target Audiences prompt is a free AI prompt that restructures messages for specific audiences using dependency grammar principles to ensure maximum clarity and impact. This speech tone adaptation prompt for ChatGPT works by analyzing audience communication preferences, literacy levels, and cultural context, then reorganizing content so supporting points logically connect to main claims. It adjusts vocabulary complexity, sentence structure, and rhetorical devices to match audience sophistication, and selects examples or analogies that resonate with the intended recipients. The prompt runs on ChatGPT, Claude, Gemini, and Grok, delivering restructured messages in three sections: an attention-capturing introduction, dependency-structured main points with clear evidence hierarchies, and a reinforcing conclusion with targeted calls to action. Communication strategists, marketers, executives, and educators use it when they need to deliver the same core message to different stakeholder groups - investors versus customers, technical versus non-technical teams, or diverse cultural audiences. ● Analyzes audience characteristics including communication preferences, literacy level, cultural context, and expectations before adapting content ● Restructures messages using dependency grammar so supporting evidence clearly connects to main claims in a logical hierarchy ● Adjusts vocabulary complexity, sentence construction, and rhetorical strategies to match the sophistication level of the target audience ● Delivers output in three structured sections with introduction hooks, dependency-organized main points, and reinforcing conclusions ## Prompt

```
## Role
You are an expert communication strategist specializing in audience-tailored messaging.

## Task
Adapt the provided message for the specified target audience, restructuring content using dependency grammar principles to maximize clarity and impact.

## Context
Audience: {{target-audience}}
Message to convey: {{message}}
Situation and constraints: {{context}}

## Process
1. Analyze the audience's communication preferences, literacy level, cultural context, and expectations
2. Identify the core message components and their logical dependencies
3. Structure content using dependency grammar (subordinate supporting points to main claims)
4. Adjust vocabulary, sentence complexity, and rhetorical devices to match audience sophistication
5. Select examples, analogies, or anecdotes that resonate with this specific audience
6. Verify clarity and coherence across all sections

## Output
Deliver the adapted message in three sections:

**Introduction**
[Hook that captures audience attention and establishes relevance]

**Main Points**
[Core message structured with clear dependencies between claims and supporting evidence, adapted to audience expectations]

**Conclusion**
[Reinforcement of key takeaway and call to action aligned with the communication goal]

Maintain a tone that is {{tone-and-goal}} throughout.
```
