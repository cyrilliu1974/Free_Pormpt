# Infographic Template Generator for Any Subject

## 簡介

The Infographic Template Generator for Any Subject is a free AI prompt that creates reusable, structured infographic templates tailored to any topic or industry. This infographic template prompt for ChatGPT walks you through creating 3–5 distinct templates, each optimized for a different communication goal: overviews, comparisons, processes, and data stories. For every template, the prompt outputs a clear purpose statement and a table of design elements - header zones, data-visualization placeholders, callout boxes, and image slots - that maximize clarity and visual impact. It also requires citations, ensuring every template is backed by credible sources. Content strategists use it to standardize visual storytelling frameworks; marketing teams use it to brief designers with structured layouts; educators use it to scaffold lesson infographics. The prompt runs on ChatGPT, Claude, and Gemini. Reach for this prompt when you need a repeatable infographic structure that adapts to multiple use cases within the same subject domain. ● Produces 3–5 templates per run, each suited to a distinct communication goal (overview, comparison, timeline, data narrative) ● Includes a table of design elements for every template, specifying purpose and placement of text, visuals, and data zones ● Requires source citations to maintain credibility and allow fact-checking ● Adapts to any subject by swapping the {{subject}} variable - finance, healthcare, education, SaaS features, research findings ## Prompt

```
## Role
You are an expert infographic designer specializing in visually compelling, information-dense templates.

## Task
Create a series of reusable infographic templates for {{subject}}. Each template should be tailored to a different communication goal (overview, comparison, process, data story, etc.) and include strategically positioned placeholders for text, images, and data visualizations that maximize clarity and impact.

## Output
For each template, provide:

**Infographic Template [N]: [Template Name]**  
Purpose: [Brief description of the template's main objective]

Table of Design Elements:

| Element | Purpose |
|---------|----------|
| [Element 1] | [Purpose of Element 1] |
| [Element 2] | [Purpose of Element 2] |
| [Element 3] | [Purpose of Element 3] |

Generate 3–5 distinct templates, each optimized for a different use case within the subject domain.

**Sources:**  
1. [Source 1]  
2. [Source 2]  
3. [Source 3]  

Cite all sources used in your research to maintain credibility.
```
