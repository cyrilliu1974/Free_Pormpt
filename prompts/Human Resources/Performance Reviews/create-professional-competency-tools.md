# Professional Competency Self-Assessment Tool Builder

## 簡介

The Professional Competency Self-Assessment Tool Builder is a free AI prompt that creates customized evaluation frameworks for individuals looking to identify skill gaps and plan targeted professional development. This professional competency prompt for ChatGPT produces a complete assessment tool with four sections: an introduction explaining the value of self-evaluation, detailed instructions for rating proficiency levels (1-5 scale), a structured table covering five competency areas with example action steps, and implementation guidance for converting insights into a 90-day development plan. It runs on ChatGPT, Claude, and Gemini, making it accessible across major text-generation models. Professionals use it to evaluate technical skills, leadership capabilities, communication competencies, or any domain-specific expertise, then translate findings into quarterly review cycles and measurable improvement milestones. This tool is ideal for HR professionals designing review processes, managers coaching team members, or individuals taking ownership of their career development. ● Produces a complete self-assessment tool with rating scales, competency areas, and example action steps tailored to the specified professional skill ● Includes clear instructions for setting target proficiency levels and identifying realistic improvement activities ● Provides implementation guidance for converting assessments into 90-day development plans with milestones and progress tracking ● Supports quarterly review cycles to measure growth and adjust development strategies over time ## Prompt

```
## Role
You are an assessment designer specializing in professional competency evaluation and development tools.

## Task
Create a comprehensive self-assessment tool for {{professional-competency}} that helps individuals identify skill gaps and plan targeted improvements.

## Output
Provide a structured self-assessment tool with four sections:

### Introduction
Explain the purpose of this self-assessment and its value for professional growth in {{professional-competency}}.

### Instructions
Describe how to:
- Rate current proficiency (1 = beginner, 5 = expert) for each competency area
- Set realistic target levels based on career goals
- Define specific, actionable steps to bridge the gap
- Review and update assessments quarterly

### Self-Assessment Table
Create a table with 5 competency areas relevant to {{professional-competency}}. For each area, provide example action steps that illustrate concrete improvement activities:

| Competency Area | Current Level (1-5) | Target Level (1-5) | Action Steps |
|-----------------|---------------------|--------------------|--------------|
| [Area 1] | | | [Example: "Complete X course, practice Y weekly"] |
| [Area 2] | | | [Example action] |
| [Area 3] | | | [Example action] |
| [Area 4] | | | [Example action] |
| [Area 5] | | | [Example action] |

### Next Steps
Provide guidance on:
- Converting action steps into a 90-day development plan
- Setting milestones and tracking progress
- Identifying resources (courses, mentors, practice opportunities)
- Scheduling regular self-assessment reviews to measure improvement
```
