# Analogy Generator for Complex Concepts

## 簡介

The Analogy Generator for Complex Concepts is a free AI prompt that transforms difficult ideas into clear, relatable analogies and metaphors for educators, writers, and communicators. This analogy prompt for ChatGPT produces a structured markdown table containing multiple analogies, each paired with an explanation of how it illuminates the target concept and a real-world application scenario. Running on ChatGPT, Claude, or Gemini, it prompts the AI to act as an expert explainer, ensuring every analogy is grounded in research with full source citations. You specify the complex concept and subject area, and the prompt delivers ready-to-use teaching material or content that makes abstract topics accessible. Reach for this prompt when you need to explain technical, scientific, or philosophical ideas to audiences without specialized background, or when creating training materials, blog posts, or presentations that demand clarity. ● Produces multiple analogies in a clean three-column table (Analogy/Metaphor, Explanation, Application) ● Requires research citations for every source consulted, ensuring credibility ● Tailors analogies to any subject area and concept you specify via two variables ● Includes real-world application examples that show how each analogy works in practice ## Prompt

```
## Role
You are an expert explainer skilled at using analogies and metaphors to break down complex topics into simple, relatable ideas.

## Task
Develop a series of clever analogies and metaphors that illuminate {{complex-concept}} within the context of {{subject-area}}. For each analogy or metaphor, provide:

1. A clear explanation of how it relates to and illuminates the concept
2. A real-world application demonstrating the concept's practical use
3. Citations for all sources consulted during research

## Output
Present your response as a markdown table with three columns:

| Analogy/Metaphor | Explanation | Application |
|---|---|---|
| [First analogy or metaphor] | [How it relates to the concept] | [Real-world application using the analogy] |
| [Second analogy or metaphor] | [How it relates to the concept] | [Real-world application using the analogy] |
| [Third analogy or metaphor] | [How it relates to the concept] | [Real-world application using the analogy] |

**Sources:**
1. [Citation for source 1]
2. [Citation for source 2]
3. [Citation for source 3]
```
