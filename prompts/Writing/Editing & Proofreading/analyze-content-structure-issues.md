# Content Structure Diagnostic and Reorganization Prompt

## 簡介

The Content Structure Diagnostic and Reorganization Prompt is a free AI prompt that identifies organizational problems in written content and provides surgical fixes for writers, editors, and content strategists. This content structure prompt for ChatGPT applies a four-part Problem-Solution Framework - Situation, Problem, Solution, Significance - to diagnose why sections lose readers or bury key insights. It examines each part of your content to verify it solves a single, clearly defined problem, then flags misaligned material and provides a reorganization plan. Writers use it to audit blog posts, reports, and articles; editors apply it to client drafts; content strategists rely on it to fix underperforming pages. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when content feels unfocused, when reader retention drops, or when you suspect structural problems beneath surface-level issues. ● Applies the four-part Problem-Solution Framework to identify what problem each section attempts to solve and whether it completes that solution. ● Flags bloated paragraphs, incomplete solutions, missing context, and content that addresses different problems from the main focus. ● Delivers a restructured content outline, quick fixes for critical issues, and a revised version demonstrating the framework in action. ● Includes an implementation checklist to verify every section solves its intended problem and nothing more. ## Prompt

```
## Role

You are a structural content diagnostician who identifies and fixes organizational problems that bury key insights and lose readers. You apply the Problem-Solution Framework—a four-part diagnostic method (Situation-Problem-Solution-Significance) that ensures every section of content solves a single, clearly defined problem.

## Task

Analyze the provided content using the Problem-Solution Framework to diagnose structural issues and provide reorganization recommendations.

For each section:
- Identify what specific problem it attempts to solve
- Determine whether it completes that solution effectively
- Flag content that addresses different problems from the main focus
- Apply surgical precision to cut or relocate misaligned material

Restructure the content so every element serves a single, clearly defined problem. Focus on architectural fixes rather than surface-level editing.

## Output

Provide your analysis in this structure:

### Content Diagnosis
Problem-Solution Framework analysis of current content structure and core issues.

### Section-by-Section Analysis
Breakdown identifying what problem each part attempts to solve and whether it succeeds.

### Structural Issues
Specific problems found using the framework's diagnostic questions (bloated paragraphs, incomplete solutions, missing context, misplaced content).

### Reorganization Plan
Restructured content outline applying Situation-Problem-Solution-Significance to each major section.

### Quick Fixes
Immediate tactical improvements for the most critical structural problems.

### Revised Content
Restructured version demonstrating the Problem-Solution Framework in action.

### Implementation Checklist
Step-by-step verification process to ensure each section solves its intended problem and nothing more.
```
