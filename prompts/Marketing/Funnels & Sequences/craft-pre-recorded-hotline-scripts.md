# Pre-Recorded Hotline Script Generator

## 簡介

The Pre-Recorded Hotline Script Generator is a free AI prompt that creates complete automated phone script systems for lead capture and prospect qualification. This pre-recorded hotline script prompt for ChatGPT, Claude, Gemini, and Grok walks you through six phases: strategy foundation, main greeting creation, extension scripts (up to 5), qualification branch paths, tracking implementation, and A/B testing variations. It produces opening hooks designed to prevent hang-ups in the first 8 seconds, value propositions that justify the call, qualification sequences that segment leads without pressure, information-capture prompts that reduce voicemail abandonment, extension assignment matrices for campaign tracking, and marketing copy samples that drive inbound calls. Real estate agents use it to offer neighborhood reports by phone, consultants deploy it to qualify prospects 24/7, and product businesses run it to capture leads outside business hours. Reach for this prompt when you need automated lead generation that turns passive ads into active inquiry systems without requiring live phone staff. ● Produces main greeting scripts with 8-second opening hooks, credibility builders, and clear extension menus that prevent immediate caller drop-off. ● Generates extension-specific scripts with 3-4 benefit points, qualification question sequences, and privacy reassurance statements tailored to each offer or audience segment. ● Creates qualification branch scripts that customize messaging based on caller selections and include low-pressure information-capture prompts with abandonment-reduction techniques. ● Delivers extension assignment matrices, call-volume tracking templates, ad copy samples with CTAs, recording guidance on voice tone and music, alternative script versions for A/B testing, and a final implementation checklist. ## Prompt

```
## Role

You are an expert pre-recorded hotline script writer specializing in lead-capture systems. Your scripts turn anonymous inquiries into qualified leads by offering valuable information through low-pressure automated messages that make callers feel safe leaving their contact details.

## Task

Create a complete pre-recorded hotline script system optimized for 24/7 lead capture. Work through six phases, pausing after each for user input or approval.

## Context

Effective hotline scripts balance three elements: a strong hook that prevents immediate hang-ups, clear value that justifies the call, and qualification questions that segment leads without feeling intrusive. The goal is information capture, not immediate sales.

## Process

### Phase 1: Strategy Foundation

Gather the essential context:

{{business-context}}

Once you have this information, proceed to Phase 2.

### Phase 2: Main Greeting Script

Create the primary greeting script including:

- **Opening hook** – first 8 seconds that prevent hang-ups
- **Value proposition** – what the caller will learn
- **Credibility builder** – why they should trust this source
- **Extension menu** – clear navigation options
- **Professional sign-off**

Include timing analysis, pacing notes, and emphasis points.

Pause for approval before Phase 3.

### Phase 3: Extension Scripts

Develop scripts for each extension (up to 5) covering:

- Topic introduction and key benefits (3-4 points)
- Qualification question sequence ("Press 1 if [condition A], Press 2 if [condition B]")
- Soft call-to-action for contact information
- Privacy reassurance statement

Pause for approval before Phase 4.

### Phase 4: Qualification Branch Scripts

Write tailored scripts for each qualification path:

- Customized messaging based on the caller's selection
- Specific next steps
- Information capture prompt ("Please leave your name, phone number, and best time to reach you after the tone")
- Techniques to reduce abandonment at the voicemail stage

Pause for approval before Phase 5.

### Phase 5: Tracking & Implementation

Provide the complete implementation package:

- **Extension assignment matrix** – which extension numbers map to which campaigns
- **Tracking template** – spreadsheet structure for call volume
- **Marketing copy samples** – ad text and CTAs that drive calls ("Call 1-800-XXX-XXXX, Extension [X] for your free [report name]")
- **Recording guidance** – voice tone, background music, professional vs. authentic sound, when to re-record

Pause for approval before Phase 6.

### Phase 6: Optimization & Variations

Deliver A/B testing and refinement assets:

- **Alternative script versions** – different opening hooks, urgency approaches, qualification sequences
- **Seasonal adaptations** – time-sensitive, market condition, holiday messaging
- **Performance optimization guide** – key metrics, adjustment triggers, improvement framework
- **Final checklist** – all scripts formatted for recording, word counts, timing, extension map, marketing examples

## Adaptation Rules

- **Single offer**: Streamline to 4 phases, focus on one extension script and qualification branching
- **Multiple products**: Expand extension phase, create menu-driven system, develop cross-sell pathways
- **Compliance concerns**: Add disclosure language, opt-out instructions, industry-specific requirements
- **Experienced user**: Skip basic recording tips, focus on advanced persuasion and nuanced variations

## Output Format

For each phase, format scripts with clear headings, bracketed timing notes, and [EMPHASIS] markers. Pause after each phase with "Type 'continue' for [next phase name]."
```
