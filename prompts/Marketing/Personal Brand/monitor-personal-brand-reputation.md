# Personal Brand Reputation Monitoring With Google Alerts

## 簡介

The Personal Brand Reputation Monitoring With Google Alerts is a free AI prompt that creates a comprehensive monitoring system for tracking your brand mentions and sentiment across digital platforms. This personal brand reputation monitoring prompt for ChatGPT builds a complete Google Alerts strategy table that includes exact match queries, keyword variations, common misspellings, and competitor contexts. It outputs a markdown table specifying alert queries with proper search operators, recommended frequency settings (as-it-happens, daily, or weekly), and source type selections. The prompt also delivers step-by-step setup instructions, management guidelines for organizing incoming alerts using filters and labels, and an action framework that explains how to interpret sentiment levels and respond to positive mentions, negative feedback, neutral coverage, and competitor references. It runs on ChatGPT, Claude, and Gemini, requiring only your brand details as input. This prompt is for entrepreneurs, consultants, thought leaders, and marketing professionals who need to monitor their personal brand reputation systematically without manual daily searches. ● Creates a detailed alert query table with exact search strings, frequency recommendations, and source selections ● Includes brand name variations, misspellings, industry keywords, and competitor comparison contexts ● Provides setup instructions, organization best practices using filters and labels, and review cadence guidance ● Delivers an action framework for interpreting sentiment and prioritizing responses to different mention types ## Prompt

```
## Role
You are a digital marketing strategist specializing in online reputation management and brand monitoring.

## Task
Create a comprehensive Google Alerts monitoring plan for tracking brand mentions and sentiment across online platforms. Deliver a structured system that enables efficient tracking, organization, and actionable insights.

## Context
Brand to monitor: {{brand-details}}

The monitoring plan should cover:
- Exact match and variation queries for the brand name
- Industry-specific keyword combinations
- Common misspellings and alternate formulations
- Competitor comparison contexts where relevant

## Output
Provide your monitoring plan as a markdown table with three columns:

| Alert Query | Frequency | Sources |
|-------------|-----------|----------|

For each alert query, specify:
- **Alert Query**: The exact search string to use in Google Alerts, with quotation marks and operators as needed
- **Frequency**: Recommended alert cadence (as-it-happens, daily, or weekly)
- **Sources**: Which source types to monitor (news, blogs, web, video, discussions, or combinations)

After the table, include:

**Setup Instructions**: Step-by-step process for creating these alerts in Google Alerts

**Management Guidelines**: Best practices for organizing incoming alerts (filters, labels, folders, review cadence)

**Action Framework**: How to interpret sentiment and priority, and what actions to take for different alert types (positive mentions, negative feedback, neutral coverage, competitor references)
```
