# Homeschool Essay Writing Curriculum Builder

## 簡介

The Homeschool Essay Writing Curriculum Builder is a free AI prompt that generates a complete, grade-specific essay writing program for homeschooling families and independent educators. This essay curriculum prompt for ChatGPT delivers four distinct writing prompts (narrative, persuasive, expository, and descriptive), three progressive skill-building exercises covering thesis development through revision, detailed grading rubrics matched to each essay type, and a structured table of essay templates showing introduction-body-conclusion frameworks. Parents teaching writing at home use it to create age-appropriate materials without needing a background in curriculum design. It runs on ChatGPT, Claude, and Gemini, adapting content complexity to match the developmental stage of any grade level you specify. Reach for this prompt when you need a cohesive writing program that covers multiple essay genres in one package, saving weeks of lesson planning. ● Generates four grade-appropriate essay prompts across narrative, persuasive, expository, and descriptive genres ● Includes three scaffolded exercises that build skills from thesis creation through editing and revision ● Provides detailed grading rubrics with criteria for content, organization, language, and mechanics tailored to the specified grade level ● Outputs a reference table mapping essay types to their structural components for quick student consultation ## Prompt

```
## Role
You are an expert writing coach specializing in homeschool essay curriculum development across all grade levels.

## Task
Create a complete essay writing curriculum package for {{grade-level}} that includes engaging prompts, skill-building exercises, assessment rubrics, and structural templates.

## Output
Deliver the curriculum in this format:

**Writing Prompts** (one for each essay type):
- **Narrative Essay**: Create a prompt that invites personal storytelling with clear beginning, middle, and end
- **Persuasive Essay**: Create a prompt requiring the student to take a position and support it with evidence
- **Expository Essay**: Create a prompt asking the student to explain or inform about a topic
- **Descriptive Essay**: Create a prompt encouraging rich sensory detail and vivid imagery

**Skill-Building Exercises** (3 progressive activities):
- Exercise focusing on thesis development and outlining
- Exercise practicing paragraph structure and transitions
- Exercise strengthening revision and editing skills

**Grading Rubrics** (for each essay type, include criteria for):
- Content and ideas
- Organization and structure
- Language and style
- Mechanics and conventions
- Grade-appropriate expectations

**Essay Structure Templates** (present as a table):

| Essay Type | Introduction | Body Paragraphs | Conclusion |
|------------|--------------|-----------------|------------|
| Narrative | Hook, setting, characters | Events in sequence, conflict/resolution | Reflection, lesson learned |
| Persuasive | Hook, clear thesis/position | Arguments with supporting evidence | Restate position, call to action |
| Expository | Hook, topic introduction | Facts, examples, explanations | Summary of key points |
| Descriptive | Hook, subject introduction | Sensory details, spatial organization | Final impression |

Ensure all prompts, exercises, and rubrics match the developmental stage and writing abilities typical of {{grade-level}}.
```
