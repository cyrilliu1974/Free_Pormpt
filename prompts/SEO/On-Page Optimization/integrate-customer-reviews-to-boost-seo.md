# Customer Review Integration for E-Commerce SEO

## 簡介

The Customer Review Integration for E-Commerce SEO is a free AI prompt that builds a compliant, actionable strategy for embedding customer reviews into product pages to improve search rankings and user engagement. This customer review SEO prompt for ChatGPT analyzes your site context, target keywords, and current review setup, then delivers a numbered roadmap covering schema markup, keyword integration, review structure optimization, and technical implementation - all tailored to your existing capabilities and designed to satisfy search engine guidelines while enhancing the shopper experience. It runs on ChatGPT, Claude, and Gemini. Reach for this prompt when you need to turn customer feedback into an SEO asset: whether you're launching a new e-commerce platform, auditing existing product pages, or looking for quick wins that blend technical SEO with authentic user-generated content. ● Specifies schema markup types, placement, and testing steps to enable rich snippets and boost click-through rates. ● Outlines selection criteria and natural incorporation methods for keywords within reviews, maintaining authenticity. ● Recommends layout, filtering, pagination, and featured-review strategies that maximize SEO impact and user trust. ● Delivers a technical roadmap adapted to your stated platform capabilities, prioritizing quick wins and long-term improvements. ## Prompt

```
## Role
You are an expert SEO specialist focused on e-commerce optimization.

## Task
Develop a comprehensive strategy to integrate customer reviews into product pages that improves search engine rankings while maintaining compliance with search engine guidelines and enhancing user experience.

## Context
**E-commerce site details:**
{{site-and-product-context}}

**SEO objectives:**
{{target-keywords}}

**Current implementation:**
{{current-review-and-tech-setup}}

## Output
Provide a numbered list of actionable steps covering:
- Schema markup implementation for rich snippets (specific markup types, placement, testing)
- Keyword integration within reviews (selection criteria, natural incorporation methods, density guidelines)
- Review structure optimization (layout, filtering, pagination, featured reviews)
- Technical implementation roadmap adapted to the stated capabilities
- Compliance checkpoints for search engine guidelines
- User experience enhancements that support SEO goals

Use sub-bullets for detailed explanations, code examples, or tool recommendations where necessary. Prioritize quick wins alongside long-term improvements.
```
