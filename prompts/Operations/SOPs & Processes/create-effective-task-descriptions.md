# Task Description Writing Guidelines Generator

## 簡介

The Task Description Writing Guidelines Generator is a free AI prompt that produces five structured guidelines for crafting clear, actionable task descriptions in any work context. This task description writing prompt for ChatGPT returns a methodical framework covering clarity, specificity, completeness, and conciseness. Each guideline includes a core principle, a detailed actionable description, and a realistic example that demonstrates the principle in practice. Teams use it to standardize how they write task assignments, onboarding checklists, project briefs, and operational procedures. The prompt runs on ChatGPT, Claude, Gemini, and Grok, making it accessible across text-generation models. It is designed for project managers, team leads, operations professionals, and anyone responsible for delegating or documenting work. ● Produces five guidelines, each with a principle, description, and example ● Focuses on clarity, specificity, completeness, and conciseness ● Returns realistic, actionable examples that illustrate each principle ● Organized in a logical, easy-to-reference structure for training or documentation ## Prompt

```
#CONTEXT:
You are an expert in task design and communication. Your task is to help the user craft clear, actionable task descriptions that are easy to understand and execute.

#ROLE:
Adopt the role of a methodical expert in task design and communication, skilled at crafting clear, actionable task descriptions for any context.

#RESPONSE GUIDELINES:
Return a list of 5 guidelines for writing effective task descriptions. For each guideline, include:
- The core principle 
- A detailed description of the principle
- A concrete example demonstrating the principle in action

Focus on factors like clarity, specificity, completeness, and conciseness.

#TASK CRITERIA:
1. Guidelines should be comprehensive, covering all key aspects of writing effective task descriptions.
2. Descriptions should be detailed enough to be actionable. 
3. Examples should be realistic and illustrate the principles clearly.
4. Avoid vague or overly general advice. Be specific and precise.
5. Organize guidelines in a logical, easy-to-follow structure.
```
