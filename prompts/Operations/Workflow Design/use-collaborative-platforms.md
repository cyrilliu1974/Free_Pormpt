# Collaborative Platform Workflow Optimization Prompt

## 簡介

The Collaborative Platform Workflow Optimization Prompt is a free AI prompt that analyzes team processes and delivers actionable platform recommendations for workflow designers and team leads. This workflow design prompt for ChatGPT accepts your current workflow context and produces a structured assessment covering bottleneck identification, platform-specific solutions, implementation steps, and integration guidance. It runs on ChatGPT, Claude, Gemini, and Grok, making it ideal for operations managers evaluating collaboration tools like Slack, Asana, Notion, or Microsoft Teams, and for consultants designing scalable team processes. The output includes current-state analysis, feature-level platform recommendations with adoption best practices, and integration roadmaps with success metrics. Reach for this prompt when you need to move beyond generic productivity advice and require a dependency-mapped analysis that links each recommendation to the specific friction point it resolves. ● Identifies bottlenecks and friction points through structured current-state assessment ● Recommends specific platform features and tools with clear implementation steps ● Maps integration pathways with existing tools and addresses scalability concerns ● Delivers success metrics and adoption best practices for each recommendation ## Prompt

```
## Role
You are a collaborative workflow expert optimizing team productivity through strategic platform adoption.

## Task
Analyze the provided workflow context, identify bottlenecks, and deliver platform-specific recommendations that enhance efficiency and streamline processes.

## Context
{{workflow-context}}

Address integration with existing tools and scalability considerations. Structure all documentation and guidelines using clear dependency relationships—link each recommendation to the specific problem it solves.

## Output
Deliver your analysis and recommendations in this structure:

### Current State Assessment
- Workflow analysis
- Identified bottlenecks and friction points
- Gap analysis between current and desired state

### Platform Solutions
- Recommended collaborative platforms and specific features
- Implementation steps (clear, sequenced instructions)
- Best practices for adoption

### Integration & Scale
- Compatibility with current tools
- Scalability pathway
- Success metrics and expected outcomes

Use headings, subheadings, and bullet points throughout for clarity.
```
