# Collaborative Feedback Cycle Design for Education

## 簡介

The Collaborative Feedback Cycle Design for Education is a free AI prompt that creates hierarchical peer learning systems tailored to specific subjects, settings, audiences, and learning objectives. This collaborative feedback prompt for ChatGPT analyzes your learning goals, then builds a multi-stage framework showing how primary activities, peer review protocols, reflection prompts, and feedback loops connect and depend on one another. It delivers sequenced implementation guidelines - timing, grouping strategies, facilitation techniques - and defines qualitative and quantitative effectiveness measures tied directly to your stated objectives. The prompt runs on ChatGPT, Claude, Gemini, and Grok, producing hierarchical frameworks that use dependency grammar to show which components are foundational and which are derivative. Educators use it to design peer assessment cycles for K-12 classrooms, university seminars, professional training programs, and online courses where structured peer interaction accelerates skill development. ● Analyzes learning objectives to identify which knowledge and skills benefit from peer interaction ● Generates multi-stage feedback cycles with clear dependencies between activities, protocols, and reflection prompts ● Provides sequenced implementation steps covering timing, group formation, and educator facilitation techniques ● Defines effectiveness measures - both qualitative indicators and quantitative metrics - matched to your stated goals ## Prompt

```
## Role
You are an expert educational consultant specializing in collaborative learning design.

## Task
Design a structured peer feedback and knowledge-sharing system tailored to the provided educational context. Present your recommendations as a hierarchical framework that shows dependencies and relationships between components.

## Context
- Subject: {{subject}}
- Educational setting: {{educational-setting}}
- Target audience: {{target-audience}}
- Learning objectives: {{learning-objectives}}

## Output
Provide:

1. **Learning Objective Analysis**: Identify the core knowledge and skills students must develop, and how peer interaction supports each objective.

2. **Feedback Cycle Framework**: Design a multi-stage collaborative process showing:
   - Primary activities (dependent on learning objectives)
   - Supporting mechanisms (peer review protocols, reflection prompts)
   - Feedback loops connecting stages

3. **Implementation Guidelines**: Clear, sequenced steps for educators to launch and sustain the cycles, including timing, grouping strategies, and facilitation techniques.

4. **Effectiveness Measures**: Specific qualitative and quantitative indicators tied to the stated learning objectives, with suggested assessment methods.

Structure your entire response hierarchically, using indentation and connectors ("depends on," "enables," "informs") to illustrate how each element relates to and builds upon others. Show which components are foundational and which are derivative.
```
