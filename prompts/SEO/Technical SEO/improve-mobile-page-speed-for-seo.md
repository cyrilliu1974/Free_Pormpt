# Mobile Page Speed Optimization Prompt for SEO

## 簡介

The Mobile Page Speed Optimization Prompt for SEO is a free AI prompt that analyzes mobile websites and creates actionable speed, content, and search ranking improvement plans for web developers and SEO professionals. This mobile page speed prompt for ChatGPT takes your website URL, target audience, current load time, and SEO keywords, then delivers a structured optimization strategy covering technical fixes, content restructuring using dependency grammar principles, and mobile-first indexing recommendations. It runs on ChatGPT, Claude, Gemini, and Grok, identifying performance bottlenecks while balancing technical improvements with content quality and search engine visibility. Use it when you need to diagnose slow mobile load times, improve Core Web Vitals scores, or prepare a site audit that connects page speed to organic search performance. ● Identifies specific technical bottlenecks slowing mobile page load times and provides code-level fixes with expected performance gains. ● Restructures content using dependency grammar to improve clarity, user experience, and search engine comprehension. ● Delivers prioritized recommendations organized by technical optimizations, content architecture, and mobile-first SEO enhancements. ● Includes clear implementation steps, rationale, and impact assessments for page speed, rankings, and user experience for each suggestion. ## Prompt

```
## Role
You are an expert web developer and SEO specialist optimizing mobile websites for performance, search rankings, and user experience.

## Task
Analyze the provided mobile website and create a comprehensive optimization plan that balances technical improvements with content refinement. Use dependency grammar principles to restructure content for clarity and search engine understanding.

## Context
Website URL: {{website-url}}
Target audience and industry: {{audience-and-industry}}
Current mobile page load time: {{current-load-time}}
Primary SEO keywords: {{seo-keywords}}

## Analysis Requirements
- Identify performance bottlenecks affecting mobile load speed
- Assess current content structure and SEO implementation
- Evaluate user experience friction points
- Apply dependency grammar framework to content analysis

## Output
Provide a detailed optimization strategy organized under these headings:

**Technical Optimizations**
- Specific speed improvement techniques with expected impact
- Infrastructure and code-level recommendations

**Content Restructuring**
- Dependency grammar-based content improvements
- Information architecture refinements

**SEO Enhancements**
- Keyword integration strategies
- Mobile-first indexing optimizations

For each recommendation, include:
- Clear implementation steps
- Rationale explaining why it matters
- Potential impact on page speed, user experience, and search rankings
- Priority level (high/medium/low)

Format all sections as bullet point lists for easy implementation.
```
