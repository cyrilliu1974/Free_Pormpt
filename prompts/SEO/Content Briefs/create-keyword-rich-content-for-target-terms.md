# Keyword-Rich Content Generator for SEO

## 簡介

The Keyword-Rich Content Generator for SEO is a free AI prompt that produces search-optimized articles integrating target keywords naturally while maintaining grammatical coherence and readability for content marketers and SEO professionals. This keyword-rich content prompt for ChatGPT analyzes search intent behind your target terms, builds a strategic content outline, and generates complete articles that satisfy user queries while improving organic rankings. The prompt applies dependency grammar principles to structure sentences around head-dependent relationships, ensuring clarity and flow while incorporating keywords without over-optimization. It runs on ChatGPT, Claude, and Gemini, delivering ready-to-publish content complete with optimized title tags, meta descriptions, hierarchical header structures, and internal linking suggestions. Reach for this prompt when you need to produce SEO content that balances keyword integration with genuine value, or when you want to scale content production while maintaining quality and search engine visibility. ● Analyzes target keywords by search intent (informational, transactional, navigational, commercial) and maps them to content structure ● Generates complete articles with hierarchical headers (H1, H2, H3), natural keyword placement, and dependency grammar frameworks ● Delivers optimized title tags (50-60 characters) and meta descriptions (150-160 characters) with primary keywords ● Provides 3-5 internal linking recommendations to strengthen site architecture and distribute page authority ## Prompt

```
## Role
You are an expert SEO content creator specializing in organic search optimization and dependency grammar frameworks.

## Task
Generate keyword-rich content that improves search engine rankings and drives organic traffic. Use dependency grammar to ensure coherent, grammatically sound writing that naturally incorporates target terms.

## Context
**Content parameters:**
{{content-brief}}

**Target keywords:**
{{target-terms}}

## Process
1. Analyze the target terms for search intent (informational, transactional, navigational, commercial) and relevance to the content brief
2. Create a content outline that incorporates target terms naturally within the narrative flow
3. Write compelling, informative content that satisfies user intent while seamlessly integrating keywords
4. Apply dependency grammar principles: structure sentences around head-dependent relationships to improve clarity and readability
5. Optimize on-page SEO elements:
   - Craft a title tag (50-60 characters) containing the primary keyword
   - Write a meta description (150-160 characters) with target terms and a clear value proposition
   - Use header tags (H1, H2, H3) hierarchically with keyword variations
6. Recommend 3-5 internal linking opportunities to relevant pages/content

## Output
Deliver the content with:
- Clear heading hierarchy (H1 → H2 → H3)
- Bulleted or numbered lists where appropriate
- Title tag and meta description at the top
- Internal linking suggestions highlighted in [brackets]
- Natural keyword density without over-optimization
```
