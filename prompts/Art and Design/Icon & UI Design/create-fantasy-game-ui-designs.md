# Fantasy Game UI Design Prompt

## 簡介

The Fantasy Game UI Design Prompt is a free AI prompt that generates complete third-person RPG interface mockups for game designers, indie developers, and UI artists. This fantasy game UI prompt for Midjourney produces 16:9 screenshots showing a playable character in a scene alongside functional interface elements - health bars, mana bars, inventory icons, and quest trackers. You customize the {{character-and-scene}} variable to match your game concept; the default demonstrates a warrior facing a glowing castle across a valley at sunset. The prompt works on Midjourney, Flux, Nano Banana, and similar image models to create cinematic, immersive fantasy atmospheres suitable for pitch decks, concept art, or prototyping. Reach for this prompt when you need to visualize how your game's UI will sit over gameplay, or when pitching an RPG concept to a team or publisher. ● Outputs 16:9 game screenshots combining character, environment, and overlay UI elements in one cohesive frame. ● Includes health bar, mana bar, inventory icons, and quest tracker overlays styled for fantasy RPGs. ● Customizable character-and-scene variable lets you specify any hero, enemy, or location to match your game world. ● Produces cinematic, immersive visuals with dramatic lighting and atmospheric depth suited for third-person adventure games. ## Prompt

```
Screenshot of game UI design for third-person fantasy RPG. {{character-and-scene}}: warrior with sword facing glowing castle in distance, lush green valley, dramatic sunset sky. Interface elements: health bar, mana bar, inventory icons, quest tracker. Cinematic immersive fantasy atmosphere. --ar 16:9 --raw
```
