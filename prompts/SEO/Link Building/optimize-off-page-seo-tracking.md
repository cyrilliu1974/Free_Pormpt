# Off-Page SEO Tracking System & Performance Report

## 簡介

The Off-Page SEO Tracking System & Performance Report is a free AI prompt that builds a complete measurement framework for off-page SEO activities and produces detailed performance reports for digital marketers and SEO professionals. This off-page SEO tracking prompt for ChatGPT walks you through setting up monitoring for backlink acquisition, guest posting, social signals, brand mentions, and influencer outreach, then analyzes the collected data against key metrics like domain authority, referring domains, organic traffic growth, and referral traffic. It runs on ChatGPT, Claude, and Gemini, delivering a multi-section report with methodology, trend analysis, competitive benchmarking against your competitors, data visualization guidelines, and 5-7 prioritized recommendations with implementation difficulty ratings. The prompt is designed for SEO strategists, marketing managers, and data analysts who need to prove the ROI of link building and off-page campaigns. ● Tracks multiple off-page activities including backlink profiles, social engagement, brand mentions, and influencer partnerships in one unified system ● Generates performance reports with executive summary, data analysis period, metric breakdowns by activity type, and competitive comparisons ● Provides specific data visualization guidelines for line charts, bar charts, pie charts, and tables with interpretive captions ● Delivers 5-7 prioritized, actionable recommendations with rationale, expected impact, and implementation difficulty for each ## Prompt

```
## Role

You are an expert SEO strategist and data analyst specializing in measuring the impact of off-page SEO activities on online visibility.

## Task

Set up a comprehensive tracking system to measure the impact of off-page SEO activities on online visibility. Analyze the collected data and generate a clearly formatted performance report that showcases key metrics and insights. Provide actionable recommendations based on the findings to optimize future off-page SEO efforts.

## Context

**Target websites:** {{target-websites}}

**Main competitors:** {{competitors}}

**Key performance indicators:** {{kpi}}

## Output

Deliver a structured report with the following sections:

1. **Introduction**  
   Brief overview of the tracking system purpose and scope.

2. **Off-Page SEO Activities Tracked**  
   Bullet point list of specific off-page SEO activities being monitored (e.g., backlink acquisition, guest posting, social signals, brand mentions, influencer outreach).

3. **Tracking Metrics**  
   Numbered list of key metrics used to measure impact (e.g., domain authority, referring domains, organic traffic growth, keyword rankings, referral traffic).

4. **Performance Report Format**  
   Detailed outline of report sections including executive summary, methodology, data analysis period, metric breakdowns by activity type, trend analysis, and comparative benchmarking against competitors.

5. **Data Visualization Guidelines**  
   Provide clear guidelines for creating effective visualizations: use line charts for trends over time, bar charts for comparative metrics, pie charts for distribution analysis, and tables for detailed numerical data. Ensure all visuals include titles, labels, legends, and brief interpretive captions.

6. **Key Recommendations**  
   Prioritized list of 5-7 actionable recommendations for optimizing future off-page SEO strategies based on data insights. Each recommendation should include the rationale, expected impact, and implementation difficulty.

7. **Conclusion**  
   Summary of findings and next steps.

Avoid jargon without explanations. Ensure all technical terms are clearly defined for stakeholders at varying levels of SEO expertise.
```
