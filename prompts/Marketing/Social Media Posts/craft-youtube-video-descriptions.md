# YouTube Video Description Generator for Campaigns

## 簡介

The YouTube Video Description Generator for Campaigns is a free AI prompt that creates structured, discovery-optimized video descriptions for content creators and influencers running branded campaigns. This YouTube video description prompt for ChatGPT, Claude, Gemini, and Grok produces complete descriptions formatted in seven sections: a hook optimized for the first 125 characters, a value proposition with natural keyword integration, timestamp breakdowns for key moments, brand partner disclosures when applicable, formatted link sections, engagement prompts to drive comments, and trend-aligned hashtags. Content creators use it to write descriptions that serve YouTube's algorithm while maintaining authentic viewer connection, particularly for influencer partnerships that require transparent brand integration without appearing overly promotional. Reach for this prompt when you need to craft video descriptions for sponsored content, product reviews, brand collaborations, or any YouTube upload where discovery, watch time, and partnership compliance all matter. ● Outputs a keyword-optimized hook in the critical first 125 characters that mirrors the video opening ● Structures timestamps, links, and hashtags in consistent, scannable formats that improve watch time signals ● Integrates brand partnerships and required disclosures naturally without disrupting readability ● Includes engagement prompts designed to increase comment activity and viewer interaction ## Prompt

```
## Role
YouTube content strategist specializing in influencer campaign descriptions that balance algorithm performance, viewer engagement, and brand partnership requirements.

## Task
Write a YouTube video description optimized for discovery and watch time. Structure it to serve both the algorithm and human readers without appearing overly promotional.

## Context
{{campaign-details}}

Include: video topic, target audience, brand partner (if any), primary keyword, video length, key timestamps with moments, and desired call-to-action.

## Output
Deliver the description in this structure:

**Hook (first 125 characters)**
Open with the primary keyword and a curiosity gap that mirrors the video's opening.

**Value Proposition**
Expand on what viewers will gain. Use conversational language, active voice, and simple words. Naturally incorporate 2-3 secondary keywords. Break into short paragraphs for readability.

**Timestamps**
Format as:
0:00 - Introduction
X:XX - [Key moment 1]
X:XX - [Key moment 2]

**Brand Integration**
If a partner is involved, integrate naturally with required disclosures clearly stated but not disruptive.

**Links**
Format as:
► [Link 1 description]
► [Link 2 description]

**Engagement Prompt**
End with a question or request that encourages comments.

**Hashtags**
3-5 relevant hashtags aligned with current trends: #hashtag1 #hashtag2 #hashtag3

**Guidelines:**
- Never use all caps except for acronyms
- Avoid keyword stuffing (3-5 strategic placements maximum)
- Use line breaks to create visual hierarchy
- Include social proof (statistics, testimonials) when applicable
- Keep call-to-action clear and mutually beneficial
```
