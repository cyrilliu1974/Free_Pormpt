# Contact Form Design Prompt for UX and Conversion

## 簡介

The Contact Form Design Prompt for UX and Conversion is a free AI prompt that produces comprehensive contact form implementation guides for businesses and designers seeking higher completion rates. This contact form design prompt for ChatGPT, Claude, Gemini, and Grok analyzes your business context and generates field selection strategy, validation rules with constructive error messages, mobile-first optimization guidelines, and success flow handling. It applies UX research principles like progressive disclosure and visual hierarchy to reduce form friction while collecting the data you need. Teams use it to redesign underperforming contact forms, launch new lead-capture pages, or audit existing forms against conversion best practices. Reach for this prompt when you need to balance user experience with lead generation goals, or when current contact forms show high abandonment rates. ● Analyzes essential versus optional fields to minimize friction while capturing necessary lead data ● Provides inline validation rules with non-judgmental error messages that guide users to successful submission ● Delivers mobile-first specifications including touch targets, appropriate input types, and spacing guidelines ● Includes code examples and technical implementation steps for developers at any skill level ## Prompt

```
## Role
You are an expert UX/UI designer and web form specialist with deep experience in high-conversion contact forms.

## Task
Create a comprehensive contact form design and implementation guide. Cover field selection strategy, validation patterns, error messaging, mobile optimization, and success flow handling.

## Context
{{business-context}}

Include: website/business type, primary goals for the contact form, target audience profile, technical skill level (beginner/intermediate/advanced), and any current form completion challenges.

## Process
1. Analyze essential versus nice-to-have data collection
2. Structure the form using clear visual hierarchy with labels positioned above fields
3. Implement logical field grouping and progressive disclosure where appropriate
4. Define inline validation rules with helpful, constructive error messages
5. Design mobile-first with adequate touch targets, spacing, and appropriate input types
6. Include clear required field indicators and immediate submission feedback

## Output
Structure your response with these sections:

**Form Strategy** – Essential fields vs. optional, friction analysis

**Field Selection** – Specific fields to include with justification

**Technical Implementation** – Code examples and integration steps

**Validation Rules** – Field-by-field validation with error message examples

**Mobile Optimization** – Touch targets, input types, spacing guidelines

**Success Messaging** – Confirmation flow and next-step communication

Provide actionable implementation steps in bullet format with specific code snippets where applicable.
```
