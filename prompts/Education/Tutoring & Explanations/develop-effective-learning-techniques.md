# Elaborative Rehearsal Learning Program Builder

## 簡介

The Elaborative Rehearsal Learning Program Builder is a free AI prompt that creates complete learning programs using evidence-based elaborative rehearsal techniques for educators, trainers, and self-directed learners. This elaborative rehearsal prompt for ChatGPT delivers a comprehensive learning program that includes prior knowledge activation questions, five progressive elaborative rehearsal steps with examples and practice exercises, self-reflection prompts, and spaced retrieval practice questions. The program systematically guides learners from surface-level encoding to deep, meaningful knowledge integration. It works on ChatGPT, Claude, and Gemini to produce structured learning experiences that promote genuine understanding rather than rote memorization. Reach for this prompt when you need to design learning experiences that help students connect new concepts to what they already know, whether you're teaching academic subjects, professional skills, or technical knowledge. ● Activates prior knowledge with targeted questions that surface existing mental models and experiences ● Delivers five progressive elaborative rehearsal steps that move from surface processing to deep integration, each with concrete examples and practice exercises ● Includes metacognitive self-reflection prompts that help learners assess comprehension and identify knowledge gaps ● Provides spaced retrieval practice questions designed to strengthen memory consolidation and test genuine understanding ## Prompt

```
## Role
You are a learning scientist specializing in elaborative rehearsal techniques that promote deep processing, knowledge integration, and long-term retention.

## Task
Design a comprehensive elaborative rehearsal program for {{subject}} that connects new information to existing knowledge through structured practice and reflection.

## Output
Deliver a complete learning program structured as follows:

**Subject:** {{subject}}

**Learning Objectives:**
List 3 specific, measurable objectives the learner will achieve.

**Prior Knowledge Activation:**
Provide 3 questions that help the learner surface relevant existing knowledge and experience related to {{subject}}.

**Elaborative Rehearsal Technique:**
Design 5 progressive steps, each containing:
- Step description explaining the cognitive technique
- Concrete example demonstrating the technique applied to {{subject}}
- Targeted practice exercise for the learner to complete

Each step should build on the previous one, moving from surface encoding to deep, meaningful integration.

**Self-Reflection Prompts:**
Include 3 metacognitive questions that help learners assess their understanding, identify connections, and recognize gaps.

**Retrieval Practice:**
Provide 3 spaced retrieval questions designed to strengthen memory consolidation and test genuine comprehension rather than recognition.
```
