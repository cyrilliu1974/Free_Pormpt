# Conversion Rate Optimization Strategy Builder

## 簡介

The Conversion Rate Optimization Strategy Builder is a free AI prompt that creates detailed, actionable CRO plans to help businesses systematically increase online sales through data-driven website improvements. This conversion rate optimization prompt for ChatGPT works by analyzing your current metrics, target goals, and audience to produce a structured optimization roadmap. It examines user behavior patterns, identifies conversion bottlenecks across your sales funnel, and proposes specific solutions for homepage design, product pages, checkout flows, and other critical touchpoints. The prompt runs on ChatGPT, Claude, Gemini, and Grok, delivering a comprehensive plan with expected impact estimates for each recommendation. Use it when you need to close the gap between current and target conversion rates with a prioritized, evidence-based improvement strategy. ● Analyzes current conversion rate, target goals, and audience characteristics to surface high-impact opportunities ● Identifies friction points at each stage of the conversion funnel, from landing pages through checkout ● Delivers prioritized recommendations with implementation steps and expected conversion lift estimates ● Structures output into analysis, recommendations, and implementation sections for immediate team execution ## Prompt

```
## Role
You are a conversion rate optimization (CRO) specialist developing a comprehensive strategy to boost online sales through data-driven techniques.

## Task
Create a detailed CRO optimization plan that analyzes current performance, identifies improvement opportunities, and provides actionable implementation steps. Focus on user experience, persuasive design, and conversion funnel optimization.

## Context
**Business overview:** {{business-and-product}}

**Current conversion rate:** {{current-conversion-rate}}

**Target conversion rate:** {{target-conversion-rate}}

**Target audience:** {{target-audience}}

## Approach
Work systematically through:
1. Analysis of current website metrics and user behavior
2. Identification of key friction points and opportunities
3. Data-driven solution proposals with rationale
4. Prioritized implementation roadmap with expected impact

## Output
Provide a structured optimization plan using:
- **Main headings** for each major focus area (Analysis, Recommendations, Implementation)
- **Subheadings** for specific categories (Homepage, Product Pages, Checkout, etc.)
- **Bullet points** for concrete strategies, tactics, and next steps
- Expected impact estimates where applicable
```
