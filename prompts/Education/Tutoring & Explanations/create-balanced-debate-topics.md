# Balanced Debate Topics Generator With Arguments

## 簡介

The Balanced Debate Topics Generator With Arguments is a free AI prompt that creates structured debate frameworks with equal pro and con arguments for educators, trainers, and discussion leaders. This debate topics prompt for ChatGPT produces five debate topics tailored to any subject or theme you specify, each accompanied by three substantive arguments supporting the position and three arguments opposing it. The output is delivered as a clean markdown table that presents both sides with equal rigor, making it ideal for classroom debates, team training exercises, student assignments, and facilitated discussions. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need to quickly design debate activities that encourage critical thinking, when preparing discussion materials that model intellectual fairness, or when you want participants to see multiple perspectives on complex topics. ● Creates five distinct debate topics relevant to your chosen subject or theme ● Provides three substantive pro arguments and three substantive con arguments for each topic ● Maintains neutrality and balance so both sides receive equal treatment ● Outputs a markdown table format that is easy to share, print, or adapt for any audience ## Prompt

```
## Role
You are a discussion facilitator who generates balanced debate topics and argumentation frameworks.

## Task
Create 5 debate topics related to {{subject-or-theme}}. For each topic, provide 3 arguments supporting the position and 3 arguments opposing it.

## Requirements
- Topics must be relevant to the subject and encourage critical thinking
- Arguments should be balanced, substantive, and free of bias
- Present both sides with equal rigor

## Output
Format as a markdown table:

| Topic | Pro Arguments | Con Arguments |
|-------|---------------|---------------|
| Topic 1 | - Argument 1<br>- Argument 2<br>- Argument 3 | - Argument 1<br>- Argument 2<br>- Argument 3 |
| Topic 2 | - Argument 1<br>- Argument 2<br>- Argument 3 | - Argument 1<br>- Argument 2<br>- Argument 3 |
| Topic 3 | - Argument 1<br>- Argument 2<br>- Argument 3 | - Argument 1<br>- Argument 2<br>- Argument 3 |
| Topic 4 | - Argument 1<br>- Argument 2<br>- Argument 3 | - Argument 1<br>- Argument 2<br>- Argument 3 |
| Topic 5 | - Argument 1<br>- Argument 2<br>- Argument 3 | - Argument 1<br>- Argument 2<br>- Argument 3 |
```
