# Website SEO Keyword Density Analysis Prompt

## 簡介

The Website SEO Keyword Density Analysis Prompt is a free AI prompt that audits your site's top pages and reveals exactly where keywords appear, how often, and what to adjust for better rankings. This SEO keyword analysis prompt for ChatGPT walks through your highest-traffic pages, calculates keyword density, maps distribution across titles, headers, body text, and meta tags, then builds comparison tables and word cloud visualizations. It flags over-optimization risks, identifies content gaps, and delivers 3-5 prioritized recommendations backed by the data it extracts. The prompt runs on ChatGPT, Claude, Gemini, and Grok, making it flexible for any workflow that requires fast, repeatable on-page analysis. Use it when you need a snapshot of keyword performance across multiple pages, want to spot semantic opportunities, or need to justify content changes with density metrics and visual proof. ● Analyzes top 3-5 pages by traffic and calculates keyword density relative to total word count. ● Maps keyword placement across title tags, H1-H6 headers, body copy, and meta descriptions. ● Generates side-by-side comparison tables showing density, distribution, and suggested adjustments for each term. ● Produces word cloud visualizations that highlight keyword prominence and reveal semantic clusters. ● Flags over-optimization risks, content gaps, and opportunities for related-term expansion. ## Prompt

```
## Role
You are an SEO specialist and data analyst conducting keyword optimization analysis.

## Task
Analyze the top-performing pages of {{website-url}} to identify keyword density and distribution patterns. Generate word cloud visualizations and provide actionable SEO recommendations.

## Analysis Requirements
1. Identify the top 3-5 performing pages by traffic or engagement
2. For each page, analyze:
   - Keyword density (frequency relative to total word count)
   - Keyword distribution (placement in titles, headers, body, meta)
   - Semantic keyword clusters and related terms
3. Create a comparison table with columns: Keyword | Density | Distribution | Suggested Adjustments
4. Generate word cloud visualizations for each analyzed page showing keyword prominence
5. Provide 3-5 overall recommendations prioritized by impact
6. Note any content gaps, over-optimization risks, or opportunities for semantic expansion

## Output Format
**Website Analyzed:** [URL]

**Top-Performing Pages:**
1. [Page URL] - [Primary focus keyword]
2. [Page URL] - [Primary focus keyword]
3. [Page URL] - [Primary focus keyword]

**Keyword Analysis Table:**
[Table with Keyword | Density | Distribution | Suggested Adjustments]

**Word Cloud Visualizations:**
[Word cloud for each page highlighting frequency and placement patterns]

**Overall Recommendations:**
- [Prioritized recommendation with expected impact]
- [Prioritized recommendation with expected impact]
- [Prioritized recommendation with expected impact]

**Additional Insights:**
[Strategic observations on content opportunities, competitive positioning, or technical SEO factors]
```
