# User Persona Document Generator for UI/UX Design

## 簡介

The User Persona Document Generator for UI/UX Design is a free AI prompt that creates comprehensive, research-based user personas for designers building websites and mobile applications. This user persona prompt for ChatGPT helps UI/UX designers synthesize user research data into actionable persona documents that include demographic profiles, behavioral traits, motivations, pain points, and realistic usage scenarios. It works on ChatGPT, Claude, and Gemini by guiding the model through a structured process: analyzing quantitative and qualitative research, identifying user goals and barriers, documenting interaction patterns, and delivering a formatted persona with profile headers, representative quotes, and design implications. Teams use it when starting design projects, validating feature priorities, or aligning stakeholders around user-centered decisions. ● Synthesizes survey data, interviews, analytics, and reports into coherent user profiles ● Generates 2-3 realistic usage scenarios showing how the persona interacts with your product ● Outputs actionable design implications for feature prioritization and navigation decisions ● Formats personas for easy reference during design sprints and stakeholder presentations ## Prompt

```
## Role
You are a UI/UX designer creating a data-backed user persona for a website or app design project.

## Task
Develop a comprehensive user persona that represents the primary user base. The persona will guide design decisions by capturing demographics, behaviors, needs, motivations, and pain points in an accessible, actionable format.

## Context
{{product-details}}

Include in your product details: the type of website/app, its key features, the target user's primary goals, known pain points, and any available data sources for user research (surveys, interviews, analytics, reports).

## Process
1. **Research Foundation**: Synthesize quantitative and qualitative data from the sources provided to understand user demographics, preferences, and technological proficiency
2. **Goals and Pain Points**: Identify what motivates users and what barriers they face when trying to accomplish their objectives
3. **Demographic Profile**: Define age range, location, education, occupation, and other relevant characteristics based on data
4. **Behavioral Traits**: Document browsing habits, preferred devices, valued features, and interaction patterns
5. **Needs and Motivations**: Articulate what users hope to achieve and how the product serves their objectives
6. **User Scenarios**: Create 2-3 realistic scenarios showing how the persona would interact with the product to complete common tasks
7. **Narrative**: Bring the persona to life with a fictional name, representative details, and a relatable story that makes the user real to the design team

## Output
Deliver a structured user persona document containing:

- **Profile Header**: Name, age, location, occupation, education
- **Quote**: A statement capturing their core attitude or need
- **Goals**: 3-5 primary objectives related to using the product
- **Pain Points**: 3-5 frustrations or barriers they currently experience
- **Behavioral Traits**: Device preferences, usage patterns, feature priorities
- **User Scenarios**: 2-3 concrete examples of tasks they need to accomplish
- **Design Implications**: Brief guidance on how this persona should inform feature prioritization, navigation design, and overall user experience decisions

Format the persona for easy reference during design sprints and stakeholder discussions.
```
