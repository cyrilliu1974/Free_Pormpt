# Column Series Builder for Multi-Part Content

## 簡介

The Column Series Builder for Multi-Part Content is a free AI prompt that creates structured three-part column series with original insights and clear, grammatically precise writing for journalists, bloggers, and content creators. This column series prompt for ChatGPT helps you develop a full series outline, complete with a unifying title, individual column titles, key talking points, and 150–200 word sample excerpts for each installment. It structures sentences using dependency grammar - a linguistic framework that organizes clauses around strong predicates with subordinate elements - to ensure clarity and readability. Writers planning thought leadership pieces, magazine columns, or blog series use it to map out multi-part narratives that build on one another while each standing alone. The prompt runs on ChatGPT, Claude, Gemini, and Grok, producing text output that includes a series description, three column outlines, and excerpts that demonstrate compelling, original perspectives. ● Produces a three-column series outline with titles, key points, and sample excerpts for each installment ● Applies dependency grammar principles to ensure sentences are clear, hierarchical, and impactful ● Builds narrative continuity across columns while keeping each piece self-contained ● Encourages original insights and avoids generic commentary, suitable for thought leadership and expert analysis ## Prompt

```
## Role
You are an expert writer with deep domain knowledge, creating a three-part column series that provides original insights and analysis. Structure your writing using dependency grammar principles—building sentences around core predicates with clear hierarchical relationships between clauses—to maximize clarity and impact.

## Task
Develop a complete series outline and sample excerpts for {{topic}}.

## Output
Provide the following structure:

**Series Title:** [Catchy, engaging title]

**Series Description:** [2-3 sentences highlighting the unique value proposition and what readers will gain]

**Column 1 Title:** [Thought-provoking title]

Key Points:
- [Point 1]
- [Point 2]
- [Point 3]

Excerpt: [150-200 word sample demonstrating dependency grammar—clear main clauses with subordinate elements that reveal relationships between ideas]

**Column 2 Title:** [Thought-provoking title]

Key Points:
- [Point 1]
- [Point 2]
- [Point 3]

Excerpt: [150-200 word sample demonstrating dependency grammar]

**Column 3 Title:** [Thought-provoking title]

Key Points:
- [Point 1]
- [Point 2]
- [Point 3]

Excerpt: [150-200 word sample demonstrating dependency grammar]

**Series Conclusion:** [2-3 sentences tying together the through-line and reinforcing the series' unique insights]

## Requirements
- Offer compelling, original perspectives; avoid generic commentary
- Each column should build on previous installments while standing alone
- Excerpts must showcase dependency grammar: sentences structured around strong predicates with clearly subordinated modifying elements
```
