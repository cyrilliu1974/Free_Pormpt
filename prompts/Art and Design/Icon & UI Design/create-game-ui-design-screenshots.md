# Game UI Design Screenshot Generator

## 簡介

The Game UI Design Screenshot Generator is a free AI prompt that creates clean, minimalist game interface mockups for designers and developers. This game UI design prompt for Midjourney produces 16:9 screenshots showcasing modular grid layouts, modern visual effects, and specified UI elements for any game genre - from RPGs and puzzle games to FPS titles and mobile apps. It runs on Midjourney, Flux, Nano Banana, and similar text-to-image models, letting you visualize health bars, inventory screens, skill trees, menus, HUDs, and other interface components in a consistent, professional style. Designers use it to prototype concepts quickly, present ideas to stakeholders, or build reference libraries without opening design software. Reach for this prompt when you need polished UI mockups for pitch decks, portfolio pieces, or rapid iteration on interface ideas. ● Produces 16:9 game interface screenshots with modular grid layouts and minimalist styling ● Supports any game type - RPG, strategy, shooter, mobile, VR - and any UI element combination ● Generates consistent, modern visual effects and clean typography across mockups ● Works across Midjourney, Flux, and other image generation platforms with minimal adjustments ## Prompt

```
Screenshot of game UI design for {{game-type}}, featuring {{ui-elements}}, simple minimalist interface, clean modern effects, modular grid layout --ar 16:9
```
