# Interactive Webinar Series Planner for Education

## 簡介

The Interactive Webinar Series Planner for Education is a free AI prompt that generates complete webinar series outlines with session-by-session interactive elements, multimedia components, and formative assessments for educators and instructional designers. This interactive webinar prompt for ChatGPT structures each session with logically sequenced topics and subtopics, interactive activities like polls and breakout discussions, multimedia elements tailored to different learning styles, and assessment methods that check comprehension. It works on ChatGPT, Claude, Gemini, and Grok by taking three variables - education level, subject, and series scope - and producing a detailed outline where each webinar builds on the previous session's knowledge. Real use cases include designing professional development series, creating university course supplements, developing corporate training programs, and planning certification prep workshops. Reach for this prompt when you need to design a coherent learning journey that balances live synchronous activities with asynchronous review options and incorporates collaboration strategies like peer review and group challenges. ● Outputs session-by-session outlines with topics, subtopics, and logical dependencies clearly mapped ● Specifies interactive elements with timing and type (polls, Q&A, hands-on activities, breakout rooms) ● Includes multimedia recommendations (video, slides, demos, visualizations) matched to learning objectives ● Embeds formative assessments and participation strategies for both live and asynchronous learners ## Prompt

```
## Role
You are an expert educational content developer specializing in interactive webinar design.

## Task
Create a complete webinar series outline that delivers engaging, effective learning experiences. Structure the content logically so each session builds on prior knowledge, incorporating interactive elements, multimedia, and assessments throughout.

## Context
**Target audience:** {{education-level}}
**Subject:** {{subject}}
**Series scope:** {{series-scope}}

Each webinar should include:
- Core topics and subtopics arranged in logical progression
- Interactive elements (polls, breakout discussions, Q&A, hands-on activities) to maintain engagement
- Multimedia components (video, slides, demos, visualizations) suited to different learning styles
- Formative assessments (quizzes, reflections, practice problems) to check understanding
- Synchronous activities for live sessions and asynchronous options for flexible review
- Collaboration and participation strategies (peer review, group challenges, discussion prompts)

## Output
Provide a detailed outline with this structure for each webinar:

**Webinar [N]: [Title]**
- Main topics
  - Subtopic with key concepts
  - Subtopic with key concepts
- Interactive elements (specify type and timing)
- Multimedia components
- Assessment method
- Participation strategy

Ensure each session connects to the overall learning objectives and creates a coherent learning journey across the full series.
```
