# Business Process Automation Plan Generator

## 簡介

The Business Process Automation Plan Generator is a free AI prompt that creates detailed automation strategies for specific business workflows, complete with efficiency projections and cost impact analysis. This business process automation prompt for ChatGPT analyzes existing workflows, identifies bottlenecks, proposes concrete automation technologies, and delivers a structured implementation roadmap with quantified ROI. It runs on ChatGPT, Claude, Gemini, and Grok, producing a four-part plan that covers current process analysis, recommended automation solutions with efficiency and cost-saving estimates, a phased rollout timeline, and financial projections including payback period and three-year return. Use it when you need to justify automation investments, prioritize which processes to automate first, or build a board-ready business case for digital transformation. ● Performs structured workflow analysis rating automation potential for each process ● Recommends specific automation tools and technologies with realistic efficiency benchmarks ● Builds a three-phase implementation roadmap with durations, milestones, and deliverables ● Quantifies total implementation cost, annual savings, payback period, and multi-year ROI ## Prompt

```
## Role

You are a business process automation consultant specializing in workflow optimization, system integration, and operational cost reduction.

## Task

Develop a comprehensive automation plan for the client's business processes. Analyze current workflows, propose concrete automation solutions with efficiency and cost impact, create a phased implementation roadmap, and quantify ROI.

## Context

Key business processes to automate:
{{processes-to-automate}}

## Output

Structure your response in four sections:

**1. Current Process Analysis**

For each process, document:
- Process name
- Current steps
- Pain points and bottlenecks
- Automation potential rating (low/medium/high)

**2. Proposed Automation Solutions**

For each solution, specify:
- Target process name
- Automation technologies and tools recommended
- Which steps will be automated and how
- Expected efficiency improvement (percentage)
- Estimated annual cost savings (dollar amount)

**3. Implementation Roadmap**

Break implementation into 3 phases, each detailing:
- Phase name and strategic focus
- Duration (weeks or months)
- Key activities and milestones
- Concrete deliverables

**4. ROI Analysis**

Provide:
- Total implementation cost estimate
- Total annual cost savings estimate
- Payback period (months)
- 3-year ROI (percentage)

Base all recommendations on proven automation technologies and realistic efficiency benchmarks for similar business contexts.
```
