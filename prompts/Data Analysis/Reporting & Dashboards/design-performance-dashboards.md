# Performance Dashboard Design Prompt for CIPD Framework

## 簡介

The Performance Dashboard Design Prompt for CIPD Framework is a free AI prompt that transforms raw performance data into multi-layered dashboard specifications for HR and business leaders. This performance dashboard prompt for ChatGPT, Claude, Gemini, and Grok applies the CIPD HR Metrics and Analytics Framework to convert organizational performance data into structured dashboard designs. It follows the 3-second rule - ensuring critical insights are immediately visible - and generates eight distinct layers: executive summary dashboards, departmental performance views, trend analysis visualizations, comparative performance matrices, action trigger alerts, interactive navigation guides, mobile optimization notes, and implementation roadmaps. Real use cases include HR teams designing people analytics dashboards, operations managers building performance monitoring systems, and executives creating strategic decision-support tools. Reach for this prompt when you need to move beyond raw metrics and create visualization specifications that guide users from high-level KPIs to granular detail while maintaining cognitive clarity. ● Structures dashboards around 5-7 key metrics per view to prevent cognitive overload and ensure decision-makers focus on what matters. ● Specifies chart types, color coding (red/amber/green), contextual benchmarks, and data relationships for each visualization layer. ● Defines action trigger thresholds that link specific metric values to recommended business actions, turning dashboards into decision-support tools. ● Includes interactive drill-down paths, mobile optimization guidance, and accessibility compliance notes for real-world deployment. ## Prompt

```
## Role
You are a data visualization architect specializing in the CIPD HR Metrics and Analytics Framework. You design dashboards that follow the 3-second rule: critical insights must be immediately apparent without interpretation effort.

## Task
Transform the provided performance data into a multi-layered dashboard system that reveals hidden patterns, triggers immediate action, and guides decision-makers from executive summary to granular detail. Every metric must link directly to a business decision.

## Context
{{organizational-context}}

{{performance-data}}

## Dashboard Design Principles
- Limit each view to 5-7 key metrics to prevent cognitive overload
- Use color strategically: red (critical issues), amber (warnings), green (targets met)
- Focus on leading indicators that predict future performance, not just lagging measures
- Include contextual benchmarks: internal historical and external industry standards
- Eliminate vanity metrics that impress but drive no action
- Ensure accessibility compliance for users with visual impairments
- Display data freshness indicators so users know how current the information is

## Output
Deliver a comprehensive dashboard specification structured as:

### 1. Executive Summary Dashboard
High-level view with critical KPIs aligned to CIPD decision-making principles. Describe specific chart types, data relationships, and the insight each visualization communicates in 3 seconds.

### 2. Departmental Performance Views
Breakdown by team/department showing comparative performance and trends. Specify how users navigate between views.

### 3. Trend Analysis Visualizations
Historical patterns and forward projections that reveal performance trajectory.

### 4. Comparative Performance Matrices
Internal benchmarks across teams/periods and external industry standards for context.

### 5. Action Trigger Alerts
Specific thresholds linked to recommended actions. Define what happens when metrics cross critical boundaries.

### 6. Interactive Elements Guide
Drill-down paths, filtering options, and navigation patterns that let leaders explore areas of concern.

### 7. Mobile Optimization Notes
Key adaptations for real-time mobile decision-making.

### 8. Implementation Roadmap
Step-by-step guide to build, test, and deploy the dashboard system.

For each visualization, specify: chart type, data fields, interaction model, and the decision it enables. Include narrative summaries alongside visualizations to provide context.
```
