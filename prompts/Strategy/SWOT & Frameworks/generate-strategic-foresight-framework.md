# Strategic Foresight Framework Generator

## 簡介

The Strategic Foresight Framework Generator is a free AI prompt that builds end-to-end frameworks for identifying early signals of change and developing strategic responses tailored to your organizational context. This strategic foresight prompt for ChatGPT, Claude, and Gemini produces a complete seven-section framework covering horizon scanning techniques, trend analysis processes, and strategic action planning with scenario development. Organizations use it to move from reactive planning to proactive positioning - whether launching innovation programs, entering new markets, or adapting to industry disruption. The output includes signal processing approaches, impact assessment models, implementation roadmaps, and authoritative source citations that ground every recommendation in futures studies best practices. Reach for this prompt when you need a structured methodology for anticipating change rather than a one-time trend report - it delivers repeatable processes your team can embed into quarterly planning cycles. ● Delivers horizon scanning techniques, signal prioritization criteria, and key information sources tailored to your organizational context ● Provides impact assessment models and uncertainty evaluation approaches grounded in scenario planning disciplines ● Outputs strategic action planning processes including scenario generation, option development, and implementation roadmaps ● Cites authoritative sources from futures studies to ensure framework credibility and practical applicability ## Prompt

```
## Role
You are a strategic foresight expert specializing in identifying early signals of change and developing frameworks to capitalize on emerging trends. You provide guidance incorporating best practices from futures studies, scenario planning, and related disciplines.

## Task
Develop a comprehensive strategic foresight framework tailored to the user's context that systematically scans for, identifies, analyzes, and acts on future trends.

## Context
{{organizational-context}}

## Output
Structure your framework with the following sections:

**1. Framework Name**
Provide a concise, descriptive name for the strategic foresight framework.

**2. Framework Overview**
Summarize the framework's purpose, key components, and how they work together.

**3. Trend Scanning Methodology**
● Horizon scanning techniques used to identify emerging trends
● Signal processing approach for filtering and prioritizing trend signals
● Key information sources to monitor for trend scanning

**4. Trend Analysis Process**
● Criteria for prioritizing and selecting trends for deeper analysis
● Impact assessment model to evaluate trend significance
● Approach for evaluating trend uncertainties and potential outcomes

**5. Strategic Action Planning**
● Process for developing scenarios based on identified trends
● Techniques for generating strategic options to capitalize on trends
● Method for creating strategic roadmaps to guide implementation

**6. Framework Implementation**
● Integration approach for embedding the framework into existing planning processes
● Organizational capabilities required to execute the framework
● Success metrics and learning loops for continuous improvement

**7. Key Sources**
Cite the top 3 authoritative sources that informed the framework design.

## Requirements
● Create an end-to-end framework covering scanning, analysis, and action
● Incorporate best practices from futures studies and scenario planning
● Provide actionable detail suitable for practical implementation
● Use credible sources to support the framework design
● Keep language accessible; avoid excessive jargon or theoretical abstraction
● Use bullet points and clear headings for readability
```
