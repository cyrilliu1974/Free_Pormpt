# Social Media Profile Optimization Checklist Generator

## 簡介

The Social Media Profile Optimization Checklist Generator is a free AI prompt that creates platform-specific optimization checklists to improve discoverability and search engine visibility for businesses and creators. This social media optimization prompt for ChatGPT produces a comprehensive, actionable checklist organized by category: description optimization with character limits and keyword placement, web link verification, keyword research guidance with hashtag recommendations, visual element specifications, and ongoing maintenance tasks. It tailors advice to the specific platforms you specify - whether Instagram, LinkedIn, Twitter, Facebook, TikTok, or others - ensuring recommendations match each platform's features and audience expectations. Real use cases include launching a new brand presence, auditing existing profiles for SEO improvements, onboarding team members to social media standards, and ensuring consistency across multiple platform accounts. The prompt runs on ChatGPT, Claude, Gemini, and Grok. This checklist generator is ideal for marketing teams, small business owners, personal brands, and agencies managing multiple client profiles who need a systematic approach to profile optimization without guessing at best practices. ● Creates category-organized checklists covering bio writing, keyword placement, link verification, visual standards, and maintenance schedules ● Adapts recommendations to match the features and character limits of specified platforms ● Provides concrete action items with checkboxes, emoji usage tips, and character count reminders ● Includes ongoing best practices for content frequency, engagement, and performance tracking ## Prompt

```
## Role
You are an SEO expert specializing in social media profile optimization for discoverability and search engine visibility.

## Task
Generate a comprehensive optimization checklist for the user's social media profiles. Cover profile descriptions, web links, keyword strategy, visual elements, and ongoing best practices.

## Context
The user wants to improve their social media presence across {{platforms}} to increase discoverability, rank better in search results, and attract their target audience. The checklist should provide actionable, platform-appropriate guidance they can implement immediately.

## Output
Deliver a structured checklist organized by optimization category. For each item, provide specific, actionable advice. Format as follows:

**Optimization Checklist for {{platforms}}**

### Description Optimization
✅ Write a concise, engaging bio that highlights your unique value proposition  
✅ Naturally incorporate relevant keywords for your niche or industry  
✅ Stay within the platform's character limit (typically 150-160 for most platforms)  
✅ Use emoji strategically to add visual appeal and break up text 😊  

### Web Links
✅ Include a link to your main website or primary landing page  
✅ Verify the link is clickable and directs to the correct URL  
✅ Consider adding links to other key social profiles or featured content  

### Keyword Strategy
✅ Research 5-10 high-impact keywords specific to your niche  
✅ Place primary keywords in profile name, bio, and regular post captions  
✅ Avoid keyword stuffing—prioritize natural language and readability  
✅ Use 3-5 relevant hashtags per post to boost discoverability with your target audience  

### Visual Optimization
✅ Upload a high-quality, recognizable profile picture (logo or professional headshot)  
✅ Select a cover photo that aligns with your brand identity and message  
✅ Ensure all images meet platform-specific size requirements  

### Ongoing Best Practices
✅ Maintain consistent brand voice and visual aesthetic across all profiles  
✅ Post fresh, engaging content regularly (minimum weekly)  
✅ Respond promptly to comments and direct messages  
✅ Review analytics monthly to track performance and refine your strategy  

Tailor all recommendations to the specific features and audience expectations of {{platforms}}.
```
