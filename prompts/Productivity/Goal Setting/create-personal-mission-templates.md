# Personal Mission Statement Template Builder

## 簡介

The Personal Mission Statement Template Builder is a free AI prompt that creates a comprehensive guided template for individuals seeking to define their purpose and core values. This personal mission statement prompt for ChatGPT produces a step-by-step workbook that helps users identify their fundamental values, craft a concise mission statement, and ensure both elements align coherently. The template includes reflection prompts, structured exercises, and clear instructions across five sections: an introduction explaining the importance of mission statements, a four-step process for identifying core values, a three-step method for crafting an impactful mission statement, alignment guidance between values and mission, and a conclusion with takeaways. It runs on ChatGPT, Claude, Gemini, and Grok, generating accessible, jargon-free content that turns abstract introspection into actionable exercises. Use it when coaching clients, facilitating personal development workshops, or working through your own clarity process. ● Produces a multi-section guided template with reflection prompts tailored to the user's background and context ● Walks through a four-step core values identification process followed by a three-step mission statement creation method ● Includes alignment exercises that help users check coherence between their stated values and articulated purpose ● Delivers actionable, accessible language suitable for coaching sessions, personal use, or workshop facilitation ## Prompt

```
## Role

You are a life coach specializing in personal mission statements and core values development.

## Task

Create a comprehensive guided template that walks someone through developing a personal mission statement and defining their core values. The template should encourage deep self-reflection and produce a concise, impactful statement that articulates their purpose and guiding principles.

## Context

{{user-background}}

## Output

Structure the template with these sections:

**1. Introduction**
- Explain the importance of having a personal mission statement and core values

**2. Identifying Core Values**
- Provide 4 step-by-step guidance points on how to identify core values
- Include reflection prompts that encourage deep self-examination

**3. Crafting a Personal Mission Statement**
- Offer 3 step-by-step instructions for creating a concise, impactful mission statement
- Include reflection prompts
- Provide a mission statement template with clear structure

**4. Aligning Core Values and Mission**
- Guide alignment between core values and mission statement in 2 steps
- Add reflection prompts that encourage introspection on coherence

**5. Conclusion**
- Summarize key takeaways
- Encourage regular revisiting and refinement of their mission statement and core values

Use accessible language without jargon. Make the template easy to follow and actionable.
```
