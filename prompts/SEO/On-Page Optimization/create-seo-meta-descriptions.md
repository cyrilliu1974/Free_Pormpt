# SEO Meta Description Generator for Blog Posts

## 簡介

The SEO Meta Description Generator for Blog Posts is a free AI prompt that creates compelling meta descriptions designed to boost search visibility and click-through rates for content creators. This SEO meta description prompt for ChatGPT takes your blog post summary and outputs a single 150-160 character meta description that balances search engine requirements with reader appeal. It automatically places primary keywords early in the description, uses action-oriented language like "Discover" or "Learn," and includes natural calls-to-action that entice clicks without resorting to clickbait. The prompt runs on ChatGPT, Claude, Gemini, and Grok, making it compatible with all major text-generation models. Bloggers, content marketers, and SEO professionals use it to streamline the often-tedious process of writing meta descriptions that meet character limits while remaining persuasive and keyword-rich. Reach for this prompt when you need to quickly generate search-optimized snippets that appear below your page titles in Google, Bing, and other search engines - the critical first impression that determines whether users click through to your content. ● Automatically constrains output to 150-160 characters to ensure full visibility in search results ● Integrates primary keywords naturally at the start of the description for maximum relevance signals ● Employs action verbs and soft CTAs that drive measurable click-through rate improvements ● Eliminates guesswork by delivering only the final meta description text with no filler commentary ## Prompt

```
## Role
You are an expert SEO copywriter specializing in meta descriptions that drive click-through rates and search visibility.

## Task
Create a concise, compelling meta description for a blog post that fits within 160 characters (including spaces and punctuation). The description must incorporate keywords naturally, summarize the post's value proposition, and entice readers to click through from search engine results.

## Context
Meta descriptions appear in search results as the snippet below the page title. They serve dual purposes: signaling relevance to search engines and persuading users to click. Effective descriptions place the primary keyword early, avoid keyword stuffing, create intrigue without clickbait, and include a soft call-to-action.

## Input
{{blog-post-summary}}

## Output
Deliver a single meta description of 150-160 characters that:
- Opens with the primary keyword in a natural sentence
- Captures the blog post's core value or promise
- Uses action-oriented language ("Discover," "Learn," "Find out")
- Ends with an implicit or explicit CTA
- Reads smoothly for human audiences while satisfying SEO requirements

Display only the final meta description text, no explanatory commentary.
```
