# AMP Implementation Guide for Mobile SEO

## 簡介

The AMP Implementation Guide for Mobile SEO is a free AI prompt that creates detailed technical roadmaps for deploying Accelerated Mobile Pages and optimizing mobile content structure for SEO specialists and web developers. This AMP implementation prompt for ChatGPT walks you through six critical phases: auditing current mobile SEO performance with Core Web Vitals analysis, identifying which pages benefit most from AMP conversion based on traffic and conversion data, implementing proper AMP HTML markup and components, structuring content using dependency grammar principles for maximum mobile readability, testing AMP pages across real devices and validators, and monitoring the SEO impact through Search Console and analytics. It runs on ChatGPT, Claude, Gemini, and Grok, and tailors recommendations to your specific website URL, target content types, existing mobile SEO challenges, and industry context. This prompt is for mobile SEO specialists, technical SEO consultants, and web developers who need a systematic framework for AMP adoption that balances page speed improvements with content quality and ongoing maintenance requirements. ● Produces numbered action steps covering assessment, page selection, AMP markup implementation, dependency grammar content structuring, testing protocols, and impact measurement ● Addresses technical challenges, validation requirements, and long-term maintenance strategies specific to your website and industry ● Includes tool recommendations, Core Web Vitals benchmarking, and Search Console tracking setup for ROI assessment ● Structures guidance around real conversion goals, traffic patterns, and mobile usability constraints ## Prompt

```
## Role
You are an expert mobile SEO specialist focused on implementing AMP (Accelerated Mobile Pages) and optimizing content structure for mobile performance.

## Task
Create a comprehensive, step-by-step guide for implementing AMP and structuring content using dependency grammar framework to enhance mobile readability and SEO performance.

## Context
Website: {{website-url}}
Target pages/content types for AMP: {{amp-targets}}
Current mobile SEO challenges: {{mobile-seo-issues}}
Target audience & industry: {{audience-and-industry}}

## Output
Provide a numbered list with clear, actionable steps covering:

1. **Assessing current mobile SEO performance** — audit tools, Core Web Vitals, mobile usability issues, baseline metrics

2. **Identifying suitable pages or content types for AMP implementation** — content type analysis, traffic patterns, conversion goals, technical feasibility

3. **Implementing AMP for the selected pages or content types** — AMP HTML markup, component selection, validation, deployment strategy

4. **Structuring content using dependency grammar framework** — hierarchical content relationships, core-dependent sentence structures, mobile readability optimization

5. **Testing and optimizing AMP pages for maximum performance** — AMP validator, real-device testing, performance benchmarking, iterative improvements

6. **Monitoring and analyzing the impact of AMP implementation on mobile SEO** — Search Console tracking, analytics setup, KPI measurement, ROI assessment

For each section, address:
- Potential challenges and solutions
- Best practices specific to the industry and audience
- Long-term maintenance strategies
- Tools and resources needed
```
