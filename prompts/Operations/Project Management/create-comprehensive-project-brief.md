# Project Brief Generator for UI/UX Designers

## 簡介

The Project Brief Generator for UI/UX Designers is a free AI prompt that produces detailed project briefs covering all essential elements needed for successful UI/UX project execution and team alignment. This project brief prompt for ChatGPT walks through ten structured sections - from project overview and target audience analysis to design principles, team roles, and success metrics - turning your project description, design principles, and success criteria into a professional document that serves as the foundation for collaboration. It runs on ChatGPT, Claude, and Gemini, helping designers translate strategic intent into actionable guidance for developers, stakeholders, and cross-functional teams. Real use cases include onboarding new team members mid-project, securing stakeholder buy-in, and documenting scope to prevent feature creep. Reach for this prompt when you need to establish shared understanding at the start of a design initiative or when restructuring an existing project that lacks clear documentation. ● Covers ten essential sections including project overview, target audience, problems and solutions, scope, deliverables, timeline, team roles, design approach, iteration process, and success metrics. ● Applies your stated design principles to the project context and references past work to illustrate methodology. ● Defines clear boundaries by specifying what is in scope and what is excluded, reducing misalignment and scope drift. ● Structures feedback loops and iteration cycles so stakeholders understand how input will shape the design. ## Prompt

```
## Role

You are an experienced UI/UX designer creating a comprehensive project brief that will serve as the foundation for successful project execution and team alignment.

## Task

Write a detailed project brief that provides a clear, actionable guide for the entire project team. The brief must ensure shared understanding of objectives, scope, deliverables, and design approach.

## Context

{{project-description}}

{{design-principles}}

## Output

Structure the project brief with these sections:

**1. Project Overview**
Summarize the project and its primary objectives. Explain how it aligns with broader organizational goals and its strategic significance.

**2. Target Audience**
Define demographics, behaviors, needs, and how the project benefits them. Ground the description in research and data.

**3. Problems & Solutions**
List the main challenges the project addresses. For each, outline the proposed solution and how your design approach resolves user pain points.

**4. Project Scope**
Clearly state what is included and what is excluded to set appropriate boundaries and expectations.

**5. Key Deliverables**
Specify all products, services, or documents to be provided, with detailed descriptions and acceptance criteria.

**6. Timeline**
Provide milestones, deadlines, dependencies, and any critical paths that could impact the schedule.

**7. Team Roles and Responsibilities**
Outline the project team composition, each member's role and responsibilities, and how design leadership will guide the project.

**8. Design Approach and Principles**
Explain how your design principles apply to meet project objectives. Reference relevant past work to illustrate methodology and effectiveness.

**9. Feedback and Iteration Process**
Describe how stakeholder and user feedback will be collected, reviewed, and incorporated into iterative design cycles.

**10. Success Metrics**
Define measurable outcomes and KPIs that will evaluate project impact: {{success-metrics}}

Format the brief as a professional document with clear headings, concise language, and actionable information.
```
