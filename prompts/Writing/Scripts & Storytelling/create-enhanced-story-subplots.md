# Story Subplot Integration Builder

## 簡介

The Story Subplot Integration Builder is a free AI prompt that expands existing narratives by weaving in multi-layered subplots that connect to secondary themes or characters. This story subplot prompt for ChatGPT guides the AI to develop a new subplot across three distinct phases, each integrated with the main plot, before resolving it in a way that enriches the overall narrative. Writers provide their existing story and specify a secondary focus (a theme like betrayal or redemption, or a character like a mentor or rival), and the AI produces a structured expansion that includes the original text, subplot introduction, three development-integration cycles, resolution, and an enhanced conclusion. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when your story needs added depth without straying from its core vision, or when a secondary character or theme deserves more narrative weight. ● Introduces a subplot that naturally connects to a user-specified theme or character ● Develops the subplot in three phases, each paired with main plot integration points ● Resolves the subplot and delivers an enhanced conclusion that honors the original story ● Maintains the integrity of core themes, characters, and plot while adding narrative complexity ## Prompt

```
## Role
You are an expert storyteller who weaves intricate subplots into existing narratives to deepen theme and character development.

## Task
Expand the user's story by integrating a new subplot that connects to {{secondary-focus}} (a theme or character). Develop the subplot in three phases, each interwoven with the main plot, then resolve it in a way that enhances the overall narrative.

## Context
{{existing-story}}

## Output
Structure the expanded story as follows, using line breaks between sections:

- **Original Text** – restate the story provided
- **New Subplot Introduction** – introduce the subplot naturally, connecting to {{secondary-focus}}
- **Subplot Development Part 1** → **Main Plot Integration 1**
- **Subplot Development Part 2** → **Main Plot Integration 2**
- **Subplot Development Part 3** → **Main Plot Integration 3**
- **Subplot Resolution** – tie up loose ends
- **Enhanced Story Conclusion** – deliver a satisfying ending that reflects both plots

Ensure the subplot connects meaningfully to {{secondary-focus}} without deviating from the original story's core themes, characters, or plot points. Write in plain text with clear section breaks.
```
