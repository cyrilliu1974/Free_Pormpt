# Mobile Navigation Enhancement Prompt for SEO and UX

## 簡介

The Mobile Navigation Enhancement Prompt for SEO and UX is a free AI prompt that creates structured improvement plans for mobile website navigation tailored to your target audience and traffic patterns. This mobile navigation prompt for ChatGPT analyzes your current site structure, audience needs, and SEO keywords to deliver a prioritized action plan covering architecture improvements, touch-friendly interface design, load time optimization, and mobile-first indexing compatibility. It applies dependency grammar principles to ensure logical navigation hierarchy and flow. The prompt runs on ChatGPT, Claude, Gemini, and Grok, and is built for UX designers, SEO specialists, and web developers who need to optimize mobile experiences with consideration for crawlability, accessibility standards, and conversion paths. Input your website URL, current navigation structure, target audience, primary keywords, and mobile traffic percentage to receive specific recommendations with implementation priorities and success metrics. ● Delivers navigation architecture improvements based on user intent and keyword targeting hierarchy ● Specifies technical requirements including 44×44px minimum tap targets and finger-friendly spacing ● Provides mobile SEO optimizations for crawlability and mobile-first indexing compatibility ● Includes implementation priorities, quick wins, and measurable success metrics to track post-launch ## Prompt

```
## Role
You are an expert mobile UX designer and SEO specialist focused on optimizing mobile navigation for websites.

## Task
Create a structured, actionable plan to enhance user experience and improve mobile SEO for the specified website. Analyze and restructure navigation elements using dependency grammar principles to ensure logical flow and hierarchy.

## Context
**Website:** {{website-url}}
**Target audience:** {{target-audience}}
**Current navigation structure:** {{current-navigation}}
**Primary SEO keywords:** {{seo-keywords}}
**Mobile traffic percentage:** {{mobile-traffic-percentage}}

## Requirements
Your plan must address:
- User-friendly design principles for mobile contexts
- SEO best practices specific to mobile indexing
- Mobile-specific considerations: load time optimization, touch-friendly interface sizing (minimum 44×44px tap targets), finger-friendly spacing
- Search engine crawlability and mobile-first indexing compatibility
- Navigation hierarchy that reflects both user intent and keyword targeting
- Accessibility standards for mobile devices

## Output
Deliver your plan as a numbered list with main points and nested sub-points. Each recommendation should be specific, actionable, and prioritized by impact. Include:
1. Navigation architecture improvements
2. UX enhancements for mobile interaction
3. Technical SEO optimizations
4. Implementation priorities and quick wins
5. Success metrics to track post-implementation
```
