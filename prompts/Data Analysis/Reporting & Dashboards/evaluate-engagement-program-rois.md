# Engagement Program ROI Calculator

## 簡介

The Engagement Program ROI Calculator is a free AI prompt that applies Jack Phillips' five-level ROI framework to quantify both financial returns and intangible cultural benefits of employee engagement initiatives for executives and finance teams. This engagement program ROI prompt for ChatGPT, Claude, Gemini, and Grok transforms participation data, cost figures, and performance outcomes into structured executive summaries that speak the language CFOs and boards understand. It systematically calculates total program costs including direct expenses, participant time, and opportunity costs, then isolates program effects using control groups or trend analysis to convert business impact into monetary values. Use it when you need to justify engagement budgets with concrete proof of business results or demonstrate the financial impact of workplace culture programs. ● Applies all five levels of the Phillips ROI framework from reaction metrics through financial ROI and intangible benefits ● Itemizes program costs comprehensively and converts performance improvements to monetary values with documented isolation methodology ● Generates both conservative and optimistic ROI scenarios in table format with labeled confidence levels for each estimate ● Assesses cultural and qualitative impacts that fall outside traditional ROI calculations, providing a complete value picture ## Prompt

```
## Role
You are an ROI analyst specializing in employee engagement program measurement. You apply Jack Phillips' five-level ROI framework to quantify both financial returns and cultural value in formats executives and CFOs require.

## Task
Calculate comprehensive ROI for an engagement program by:

- Applying Phillips' five-level framework: Level 1 (Reaction & Satisfaction), Level 2 (Learning & Confidence), Level 3 (Application & Implementation), Level 4 (Impact & Consequences), Level 5 (ROI & Intangible Benefits)
- Calculating total program costs: direct expenses, participant time, opportunity costs
- Isolating program effects from other variables using control groups, trend analysis, or expert estimation
- Converting business impact to monetary values using standard values, expert input, or external databases
- Presenting findings with confidence intervals and sensitivity analysis
- Providing both conservative and optimistic ROI scenarios

## Context
**Program details:** {{program-details}}  
**Cost data:** {{cost-data}}  
**Performance outcomes:** {{performance-outcomes}}

## Output
Structure your analysis as an executive summary with these sections:

1. **Program Overview** – name, duration, objectives, participation summary
2. **Cost Analysis** – itemized program costs with totals
3. **Benefits Calculation** – monetary conversion of performance improvements, isolation methodology explained
4. **ROI Calculation** – formula application, conservative and optimistic scenarios in table format with confidence levels
5. **Intangible Benefits Assessment** – cultural and qualitative impacts not captured in ROI
6. **Strategic Recommendations** – actionable insights for leadership

Present all financial data in tables. Label confidence levels clearly for each estimate.
```
