# Image Alt Text Optimizer for SEO and Accessibility

## 簡介

The Image Alt Text Optimizer for SEO and Accessibility is a free AI prompt that audits and improves image alt attributes across websites for better search performance and user experience. This image alt text prompt for ChatGPT analyzes every image on a target website, evaluates existing alt attributes, and delivers specific rewrite recommendations that balance SEO keyword relevance with accessibility standards. It works by reviewing image file names, assessing current alt text quality, and providing improved versions alongside optimization notes that explain the reasoning. The prompt runs on ChatGPT, Claude, and Gemini, making it practical for webmasters conducting technical SEO audits, accessibility compliance reviews, or content optimization projects. It distinguishes between decorative and functional images, avoids generic descriptions, and ensures alt text serves both search crawlers and screen reader users. Reach for this prompt when you need to scale accessibility improvements across a site, prepare for WCAG compliance audits, or recover from manual SEO penalties related to thin or missing image metadata. ● Produces a line-by-line inventory of every image with current and recommended alt attributes, plus optimization reasoning for each change ● Balances keyword integration for SEO with descriptive clarity for assistive technologies like screen readers ● Identifies priority images in navigation, product catalogs, and key content areas that have the highest impact on rankings and usability ● Includes broader recommendations on file naming conventions, image compression, lazy loading strategies, and structured data markup ## Prompt

```
## Role
You are an SEO and web accessibility expert analyzing image alt attributes to improve search rankings and user experience.

## Task
Review all images on the provided website, assess their current alt attributes, and provide actionable recommendations for optimization.

## Context
Website URL: {{website-url}}

Focus on:
- Clear, descriptive alt text that accurately represents each image's content and purpose
- Relevant keywords for SEO without keyword stuffing
- Concise, understandable language for all users, including those using assistive technologies
- Priority images: navigation, products, key content
- Avoiding generic descriptions like "image" or "picture"

## Output
Provide your analysis in the following structure:

**Website URL:** [restate the URL]

**Image Inventory:**
For each image:
- Image file name: [filename]
- Current alt text: [existing text or "none"]
- Recommended alt text: [improved version]
- Optimization notes: [specific reasoning]

**SEO Considerations:**
List 3-5 key SEO principles applied in your recommendations (keyword relevance, search intent alignment, context matching, etc.)

**Accessibility Considerations:**
List 3-5 accessibility principles applied (screen reader compatibility, descriptive clarity, functional vs. decorative distinction, etc.)

**Additional Recommendations:**
Provide 2-4 broader suggestions for image optimization (file naming, image compression, lazy loading, structured data, etc.)
```
