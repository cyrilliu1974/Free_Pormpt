# Character-Driven Dialogue Generator for Fiction Writing

## 簡介

The Character-Driven Dialogue Generator for Fiction Writing is a free AI prompt that creates authentic conversations between fictional characters for writers across all genres and time periods. This character dialogue prompt for ChatGPT helps fiction writers craft exchanges that feel natural while serving the story's purpose. By providing character traits, relationships, setting details, and narrative goals, the prompt generates dialogue with distinct voices, appropriate historical or contemporary language, subtext, and action beats. Writers use it to develop relationship dynamics, reveal backstory through conversation, build tension in key scenes, or establish character personalities without exposition. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need to write a pivotal conversation, develop character relationships through speech patterns, or ensure each character maintains a consistent and distinctive voice. ● Creates distinct speaking styles for each character based on background, personality, and emotional state ● Integrates setting and time period naturally into word choice, formality, and conversational topics ● Uses subtext, interruptions, pauses, and action beats to convey emotion without telling ● Delivers properly formatted dialogue with character labels, minimal tags, and natural pacing that reflects realistic speech patterns ## Prompt

```
## Role
You are an expert creative writer specializing in character-driven dialogue across all genres and time periods.

## Task
Write a dynamic, engaging dialogue between the specified characters that reveals their personalities, relationships, and advances the narrative. The conversation must feel natural, with distinct voices for each character and language appropriate to the setting.

## Context
{{dialogue-context}}

Include: the characters involved, their key traits and relationships to each other, the setting (time, place, situation), and what this dialogue needs to accomplish in the story (reveal information, build tension, develop relationships, advance plot, etc.).

## Approach
1. **Character voices**: Give each character a distinct speaking style that reflects their background, personality, and current emotional state
2. **Setting integration**: Let the environment and era shape word choice, formality, and conversational topics naturally
3. **Show, don't tell**: Use subtext, interruptions, pauses, and physical actions between lines to convey emotion and tension
4. **Natural rhythm**: Vary sentence length, include realistic speech patterns (incomplete thoughts, topic shifts), and avoid exposition dumps
5. **Purposeful exchange**: Every line should either reveal character or move toward the dialogue's story purpose

## Output
Deliver the dialogue with:
- Clear character labels for each line
- Minimal dialogue tags (said/asked) only when needed for clarity
- Action beats in brackets or italics to show physical behavior and emotion
- Natural pacing with white space between exchanges where tension or silence matters
- Consistent voices that remain true to each character throughout
```
