# Continuous Onboarding Feedback Loop System Designer

## 簡介

The Continuous Onboarding Feedback Loop System Designer is a free AI prompt that builds structured feedback systems for HR teams and organizational development professionals refining their employee onboarding programs. This onboarding feedback prompt for ChatGPT, Claude, Gemini, and Grok applies Deming's PDCA (Plan-Do-Check-Act) Cycle to create repeatable, data-driven improvement processes. It identifies feedback collection methods, defines success metrics, establishes analysis procedures, and assigns specific timelines and ownership for each phase. Teams use it to address stagnation caused by sporadic surveys, disconnected improvement efforts, or feedback that never translates into change. Reach for this prompt when your onboarding program collects feedback inconsistently, struggles to turn data into action, or lacks accountability for follow-through. ● Plan Phase outputs include feedback collection methods, success KPIs, improvement hypotheses, and assigned owners with timelines. ● Do Phase specifies implementation steps for gathering feedback, data collection processes, and initial analysis approaches. ● Check Phase defines pattern identification methods, impact measurement criteria, and gap analysis procedures with designated reviewers. ● Act Phase delivers change implementation steps, communication plans, and documentation templates for the next improvement cycle. ## Prompt

```
## Role
You are an organizational development consultant specializing in continuous improvement methodologies, with deep expertise in applying Deming's PDCA (Plan-Do-Check-Act) Cycle to onboarding programs.

## Task
Design a comprehensive, repeatable feedback loop system that transforms fragmented onboarding feedback into actionable intelligence. The system must be scalable, data-driven, and create sustainable improvement processes.

## Context
**Onboarding Program:**
{{onboarding-context}}

**Current Challenges:**
{{pain-points}}

Many onboarding programs stagnate due to lack of systematic feedback collection, analysis paralysis, and disconnected improvement efforts. Your system must capture employee experiences at critical touchpoints, establish clear metrics, and generate actionable recommendations with specific timelines and ownership.

## Output
Structure your feedback loop system using the four PDCA phases as primary headings:

### Plan Phase
- Feedback collection methods (surveys, interviews, observation points)
- Success metrics and KPIs
- Improvement hypotheses to test
- Timeline and responsible parties

### Do Phase
- Feedback gathering implementation steps
- Data collection processes
- Initial analysis approach
- Timeline and responsible parties

### Check Phase
- Pattern and trend identification methods
- Impact measurement criteria
- Gap analysis procedures
- Timeline and responsible parties

### Act Phase
- Change implementation steps
- Communication plan for updates
- Documentation for next cycle
- Timeline and responsible parties

Provide actionable bullet points with specific timelines (e.g., "Week 1-2:", "Monthly:") and clearly designated responsible parties (e.g., "HR Lead", "Hiring Managers", "New Hire Cohort") for maximum implementation clarity.
```
