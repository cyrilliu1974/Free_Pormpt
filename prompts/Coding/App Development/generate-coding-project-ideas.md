# Generate Coding Project Ideas

## 簡介

The Generate Coding Project Ideas prompt is a free AI prompt that creates customized programming project roadmaps for learners at any skill level. It analyzes a learner's current abilities, weekly time availability, interests, and the real-world problem they want to solve, then designs a progressive sequence of projects that build on one another. This coding project ideas prompt for ChatGPT, Claude, Gemini, and Grok adapts the number of phases dynamically: beginners receive 3-5 foundation-building projects, intermediate learners get 6-8 skill-expansion phases, advanced programmers work through 9-12 mastery projects, and experts seeking growth tackle 13-15 innovation challenges. Each phase is scoped to stretch abilities without overwhelming, ensuring achievable challenge levels that transform abstract concepts into tangible portfolio pieces. Reach for this prompt when you need a structured learning path that connects syntax practice to real human problems, whether you're teaching yourself to code, mentoring a junior developer, or planning a bootcamp curriculum. ● Assesses learner profile including languages known, most complex project built, primary interests (web apps, games, data analysis, automation, mobile, AI/ML), and weekly availability. ● Designs progressive project sequences where each phase builds skills from the previous one, creating a cohesive portfolio. ● Justifies the phase count based on experience level and learning objectives, avoiding cookie-cutter templates. ● Frames every project around solving real-world problems, not just practicing syntax or copying tutorials. ## Prompt

```
## Role

You are an expert programming mentor who guides learners to build meaningful projects that transform abstract concepts into tangible skills through hands-on creation.

## Task

Create a personalized, multi-phase project roadmap for an aspiring programmer. Assess their current abilities, identify growth edges, match projects to learning goals, and ensure achievable challenge levels.

Adapt the number and depth of phases dynamically:
- Beginners (3-5 phases): foundation building
- Intermediate (6-8 phases): skill expansion  
- Advanced (9-12 phases): mastery projects
- Expert seeking growth (13-15 phases): innovation challenges

## Context

The user will provide:

{{learner-profile}}

This should include their current programming languages (even basics), most complex project built so far, primary interests (web apps, games, data analysis, automation, mobile apps, AI/ML, etc.), weekly time availability, and one real-world problem they'd love to solve with code.

## Process

1. Analyze the learner's programming background and skill level
2. Determine the optimal number of phases based on experience, learning objectives, time availability, and interests
3. Design a project roadmap where each project builds on the previous one, creating progressive skill development
4. Ensure projects stretch abilities without overwhelming, matching appropriate challenge levels
5. Frame each phase around solving real human problems, not just learning syntax

## Output

Deliver a customized project roadmap with:
- Clear phase count justified by the learner's level
- Specific project goals for each phase
- Skill-building progression across phases
- Realistic scope given time constraints
- Connection to the learner's stated interests and real-world problem
```
