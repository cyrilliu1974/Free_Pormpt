# Social Media Comment Automation Prompt for ChatGPT

## 簡介

The Social Media Comment Automation Prompt for ChatGPT is a free AI prompt that builds a complete engagement system for social media managers who need to respond consistently and strategically across platforms. This social media comment automation prompt for ChatGPT analyzes incoming comments by sentiment and urgency, generates response templates that match your brand voice, and establishes a metrics-tracking framework to measure engagement performance. It runs on ChatGPT, Claude, and Gemini, taking your business context, brand voice, and target audience as inputs to produce a three-part system: a comment analysis protocol with sentiment classification and priority scoring, a response framework with brand-aligned templates for different comment types, and an engagement tracking system that identifies which metrics matter and when to adjust your strategy. Social media managers use it to handle high comment volumes on Instagram, TikTok, LinkedIn, or Facebook while maintaining authentic, value-adding interactions. ● Sentiment classification and urgency scoring to prioritize which comments need immediate attention ● Response templates organized by comment type that align with your specific brand voice and values ● Engagement metrics framework that tracks performance and identifies when strategy adjustments are needed ● Works across platforms including Instagram, TikTok, LinkedIn, Facebook, and X with customizable brand voice guidelines ## Prompt

```
## Role
You are an expert social media manager building an automated engagement system.

## Task
Create personalized, brand-aligned responses to social media comments that strengthen customer relationships. Analyze comment sentiment and content, prioritize by urgency and brand impact, and develop a tracking system for engagement metrics.

## Context
**Platform & Business:**
{{business-context}}
(Include: social media platform, type of business, key product/service)

**Brand Voice:**
{{brand-voice}}
(Describe tone, style, values, and any language guidelines)

**Target Audience:**
{{target-audience}}
(Demographics, interests, communication preferences)

## Output
Provide a numbered list with detailed sub-points for each step:

1. Comment analysis protocol
   - Sentiment classification criteria
   - Content categorization system
   - Urgency and priority scoring

2. Response framework
   - Brand voice alignment checklist
   - Response templates by comment type
   - Value-add guidelines per interaction

3. Engagement tracking system
   - Key metrics to monitor
   - Response performance indicators
   - Strategy adjustment triggers
```
