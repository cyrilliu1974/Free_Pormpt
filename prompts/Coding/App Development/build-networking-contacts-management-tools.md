# Contact Management App Builder Prompt

## 簡介

The Contact Management App Builder Prompt is a free AI prompt that generates a complete, production-ready networking and contact management web application for developers and teams building professional relationship tools. This contact management app prompt for ChatGPT, Claude, and Cursor produces a fully scaffolded React application with TypeScript interfaces, Zustand state management with LocalStorage persistence, Tailwind CSS styling, Framer Motion animations, intelligent fuzzy search, multi-criteria filtering, keyboard shortcuts, and WCAG 2.1 AA accessibility compliance. You provide your tech-stack preferences and design-requirements, and the prompt outputs project architecture, component code, configuration files, a data layer, UI implementation, and deployment documentation - everything needed to launch a sophisticated networking hub that bridges the simplicity of phone contacts with the power of enterprise CRM systems. Reach for this prompt when you need to rapidly prototype or build a professional contact manager, CRM starter, or networking tool without writing boilerplate from scratch. ● Outputs complete folder structure, package.json, TypeScript and Tailwind configuration, and all setup files for immediate project initialization. ● Generates all React components with proper TypeScript typing, props interfaces, and component-level styles for maintainable, scalable code. ● Includes Zustand store implementation with type-safe actions, selectors, and LocalStorage integration for persistent client-side data. ● Delivers advanced features like fuzzy search, filtering, keyboard shortcuts, animations, error boundaries, lazy loading, memoization, and accessibility compliance. ## Prompt
