# AI Productivity Tools Research Organizer

## 簡介

The AI Productivity Tools Research Organizer is a free AI prompt that compiles evidence-based overviews of AI productivity software for professionals evaluating tools to improve work efficiency. This AI productivity tools research prompt for ChatGPT structures your findings into a comparative table covering 8-12 tools across categories like writing assistants, coding helpers, project management platforms, automation software, and data analysis tools. It produces an introduction to the current landscape, a detailed comparison table with pricing, features, integrations, and user reviews, plus tailored recommendations based on your specific domain, budget constraints, and technical familiarity. The prompt runs on ChatGPT, Claude, Gemini, and Grok, and automatically includes properly cited sources with working URLs for every tool mentioned. Reach for this prompt when you need to systematically evaluate AI productivity options rather than sifting through scattered vendor marketing and review sites. ● Organizes findings into scannable tables with consistent categories: tool name, features, pricing, integrations, user reviews, and sources ● Adapts recommendations to your specific context - domain focus, budget range, and technical expertise level ● Requires citation of all claims with working URLs to ensure verifiable, current information ● Produces balanced analysis covering 8-12 diverse tools across writing, coding, automation, communication, and research categories ## Prompt

```
## Role
You are an AI productivity researcher and technical writer compiling an evidence-based overview of AI-powered productivity tools.

## Task
Research and document AI productivity tools in a structured table format, then provide analysis and recommendations.

## Context
The user is exploring AI tools to improve work efficiency and effectiveness. Their familiarity level, focus domain, and budget constraints are: {{user-context}}

## Output
Deliver your findings in this structure:

**Introduction**: Brief overview of the current AI productivity tools landscape (2-3 paragraphs).

**Research Table**:

| AI Tool Name | Category | Key Features | Pricing | Integrations | User Reviews | Source |
|--------------|----------|--------------|---------|--------------|--------------|--------|
| [Tool 1]     | [Cat. 1] | [Features 1] | [Price 1]| [Int. 1]     | [Reviews 1]  | [URL 1]|
| [Tool 2]     | [Cat. 2] | [Features 2] | [Price 2]| [Int. 2]     | [Reviews 2]  | [URL 2]|

Include 8-12 tools covering diverse categories (writing, coding, project management, communication, automation, research, design, data analysis).

**Conclusion**: Synthesize findings with specific recommendations based on the user's context. Address:
- Best tools for their domain and budget
- Strengths and limitations of top options
- Implementation considerations

**Quality Standards**:
- Cite all sources with working URLs
- Use current pricing and feature information
- Present objective assessments without vendor bias
- Include real user review summaries from multiple platforms
- Write for clarity and scannability
```
