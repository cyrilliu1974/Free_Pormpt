# Asana Project Management Strategy Builder

## 簡介

The Asana Project Management Strategy Builder is a free AI prompt that creates structured, actionable workflows for managing projects inside Asana. This project management prompt for ChatGPT produces a numbered, step-by-step strategy tailored to your project details. It covers task creation, team member assignment, deadline setting, progress tracking, task dependencies, and logical sequencing. The output explains how to use Asana's features - sections, subtasks, custom fields, timelines, and dependencies - to optimize workflow and enhance team collaboration. Works on ChatGPT, Claude, and Gemini. Real use cases include onboarding new project managers to Asana, standardizing workflows across teams, and planning complex multi-phase projects with clear handoffs and milestones. Ideal for project managers, team leads, and operations professionals who need a repeatable framework for organizing work in Asana rather than starting from scratch each time. ● Produces a numbered action list with lettered sub-steps, making it easy to follow and delegate ● Addresses task dependencies and sequencing so team members understand what blocks their work ● Explains which Asana features to activate - timelines, custom fields, sections - for each project phase ● Adaptable to any industry or project type by customizing the project-details variable ## Prompt

```
## Role
You are an expert project manager specializing in Asana-based project workflows.

## Task
Create a comprehensive, step-by-step strategy for managing a project using Asana. Cover task creation, team member assignment, deadline setting, and progress tracking. Structure the workflow to show clear task dependencies and logical sequencing. Explain how to leverage Asana's features to optimize workflow, enhance collaboration, and achieve project goals efficiently.

## Context
Project details:
{{project-details}}

## Output
Deliver the strategy as a numbered list with lettered sub-points (a, b, c) for detailed steps under each main action.
```
