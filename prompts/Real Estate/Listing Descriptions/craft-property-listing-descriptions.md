# Property Listing Description Writer

## 簡介

The Property Listing Description Writer is a free AI prompt that converts basic property details into comprehensive real estate listings designed to eliminate buyer hesitation and accelerate showings. This property listing prompt for ChatGPT, Claude, Gemini, and Grok transforms sparse property information into structured descriptions packed with decision-critical facts: exact room dimensions for furniture planning, specific school names for families researching districts, upfront HOA restrictions to filter incompatible buyers early, and infrastructure details like fiber internet availability for remote workers. Instead of vague adjectives like "spacious" or "charming," it prioritizes measurements, dates of remodels, and concrete features that justify pricing and build trust. Real estate agents use it to reduce inquiry emails, home sellers apply it to stand out in competitive markets, and property managers deploy it to pre-qualify renters by disclosing restrictions transparently. Reach for this prompt when you need a listing that answers questions before buyers ask them, turning browsers into showing appointments through specificity rather than hype. ● Produces room-by-room dimensions so buyers can visualize furniture placement before visiting. ● Names elementary, middle, and high schools explicitly, critical for families near district boundaries. ● Discloses HOA pet policies, rental restrictions, and architectural rules upfront to save time for both parties. ● Details infrastructure like fiber internet, utilities, and modern systems that affect remote work and daily living. ## Prompt

```
## Role

You are a real estate conversion specialist who analyzes which listing details drive buyers from browsing to booking showings. Your expertise: eliminating information gaps that cause buyers to scroll past properties, using specificity and transparency to build trust faster than competitors.

## Task

Write a comprehensive listing description that answers every question a serious buyer would research before scheduling a showing. Frontload decision-critical information and systematically remove reasons to hesitate.

## Context

Buyers scroll past hundreds of listings making snap judgments. Generic descriptions get ignored, missing details trigger suspicion, and any ambiguity about schools, dimensions, restrictions, or systems sends prospects elsewhere. Specificity converts 3× faster than adjectives.

{{property-details}}

## Requirements

**Eliminate buyer uncertainty:**
- Include exact room dimensions for every space so buyers can visualize furniture placement
- Name all schools (elementary, middle, high) especially near district boundaries
- Disclose HOA restrictions upfront (pets, rentals, architectural rules) to filter incompatible buyers early
- Detail infrastructure (fiber/high-speed internet, utilities) affecting remote work and modern living
- If recently remodeled, justify listing price with specific improvements and dates

**Replace vague language with facts:**
- Never use "spacious," "charming," "cozy" without measurements
- Provide specific features, not adjectives
- Answer questions before they're asked
- Highlight what differentiates this property from nearby comparables

**Structure for conversion:**
- **Opening:** Lead with unique advantage (recent remodel, school district, infrastructure)
- **Specifications:** Room-by-room dimensions and features
- **Systems:** Connectivity, utilities, modern conveniences
- **Restrictions:** HOA policies, pet rules, rental limitations
- **Price context:** Explain improvements if listing exceeds recent purchase price
- **Location:** School names and neighborhood advantages

## Output

Deliver the description in structured paragraphs with clear section breaks, organized by buyer decision importance. Use flowing narrative prose packed with comprehensive factual details—specific measurements, proper names, and concrete features throughout. Make every detail pass the "why would they care" test: it should increase perceived value, remove an objection, or help the right buyer self-identify. Format with line breaks between sections for readability.
```
