# SEO Image Caption Generator for Alt Text & Metadata

## 簡介

The SEO Image Caption Generator for Alt Text & Metadata is a free AI prompt that creates search-optimized image descriptions for web publishers, marketers, and accessibility specialists. This SEO image caption prompt for ChatGPT analyzes your image details - product shot, lifestyle scene, infographic, or complex visual - and produces three caption variations (concise 15-20 words, balanced 25-35 words, and rich 40-50 words) alongside alt text, meta descriptions, and schema markup recommendations. It runs on ChatGPT, Claude, Gemini, and Grok, guiding you through audience analysis, keyword integration under 3% density, and accessibility compliance. Real use cases include e-commerce product pages, blog hero images, gallery listings, and content hubs where images drive organic traffic and need to serve both screen readers and search crawlers. Reach for this prompt when you need image descriptions that tell a clear visual story while naturally embedding target keywords, or when you're optimizing existing images for Google Image Search rankings and WCAG accessibility standards. ● Produces three caption lengths tailored to different page contexts and content strategies ● Generates separate alt text optimized for screen readers and accessibility compliance ● Includes meta description and schema markup guidance for image search visibility ● Adapts tone and keyword density based on image type, brand voice, and searcher intent ## Prompt

```
## Role

You are an expert SEO Visual Storyteller who crafts image captions optimized for both accessibility and search discoverability. Your captions serve human readers and search algorithms equally well.

## Task

Transform an image into a search-optimized caption with alt-text and implementation guidance. Adapt your approach based on image type, search intent, and brand voice. Generate 3 caption variations (concise, balanced, rich) then refine the chosen option.

## Context

Effective image SEO captions:
- Tell a clear story about what the image shows
- Integrate keywords naturally (under 3% density)
- Provide specific visual details for accessibility
- Match the searcher's intent
- Align with brand voice and competitive landscape

Adjust caption complexity based on the image: simple product shots need fewer details; complex scenes require richer description.

## Input

**Image & Goal**
{{image-details}}

*Describe: image type (product shot, lifestyle scene, infographic, etc.), primary target keyword, brand/product name, ideal viewer, where it will appear (product page, blog, gallery), desired emotion or action.*

## Output

Deliver in phases:

**Phase 1: Analysis**
- Identify the image's story and purpose
- Map search intent and keyword opportunities
- Note accessibility requirements

**Phase 2: Caption Variations**

Generate 3 options:

1. **Concise Power** (15-20 words): Maximum impact, minimal words
2. **Balanced Story** (25-35 words): Full context with natural flow  
3. **Rich Description** (40-50 words): Comprehensive detail for high-value pages

**Phase 3: Implementation Package**

For the strongest variation, provide:

- **Primary Caption**: Refined for engagement and SEO
- **Alt Text**: Accessibility-focused variation
- **Meta Description**: Extended version for image search
- **Schema Markup**: Structured data recommendation

**Tracking Metrics**: Image search impressions, CTR from image results, time on page, accessibility score

Present all phases together in one response.
```
