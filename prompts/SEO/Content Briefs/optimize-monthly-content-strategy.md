# Monthly Content Refresh Plan for SEO Performance

## 簡介

The Monthly Content Refresh Plan for SEO Performance is a free AI prompt that helps SEO strategists and content marketers build systematic plans to audit, prioritize, and update website content for better search rankings and user engagement. This content strategy prompt for ChatGPT analyzes your website overview, conducts a content audit examining outdated information, broken links, keyword relevance, readability, and multimedia gaps, then produces a prioritized list of 5 pages ranked by traffic potential and SEO performance. For each page, it specifies exactly what information to refresh, which internal and external links to add, how to optimize keywords naturally, structural improvements for readability, and multimedia enhancements. The prompt runs on ChatGPT, Claude, Gemini, and Grok, delivering a complete 4-week implementation timeline with success metrics including organic traffic growth, keyword ranking changes, bounce rate reduction, and time-on-page improvements. Marketing teams use it to maintain content freshness without guesswork, agencies apply it for client audits, and in-house SEO professionals rely on it to systematically prevent content decay. ● Conducts five-point content audits covering outdated facts, broken links, keyword density, readability structure, and multimedia gaps ● Ranks pages by importance and traffic potential, eliminating guesswork about which content to update first ● Provides page-specific action items - exact information to refresh, link suggestions with anchor text, keyword placement, readability fixes, and multimedia recommendations ● Includes week-by-week implementation schedules and five trackable success metrics for measuring post-update performance ## Prompt

```
## Role
You are an expert SEO strategist and content marketer developing a comprehensive monthly content refresh plan to maintain relevance and boost search rankings.

## Task
Analyze the provided website, audit existing content for freshness and SEO performance, then create a detailed 4-week action plan that prioritizes 5 pages for updates including new information, optimized keywords, improved links, better readability, and enhanced multimedia.

## Context
Website details:
{{website-overview}}

Provide the website URL, brief description of existing content, target audience demographics and interests, and main keywords you're targeting.

## Output
Deliver a structured plan in the following format:

**Website Overview:**
- Website URL: [from input]
- Current content overview: [summary]
- Target audience: [demographics and interests]
- Main keywords: [list]

**Content Audit Findings:**
1. Outdated information identified
2. Broken links detected
3. Keyword relevance and density analysis
4. Content structure and readability assessment
5. Multimedia element evaluation

**Priority Pages (5 pages ranked by importance, traffic potential, and current SEO performance):**
1. [Page URL] - [Reason for prioritization]
2. [Page URL] - [Reason for prioritization]
3. [Page URL] - [Reason for prioritization]
4. [Page URL] - [Reason for prioritization]
5. [Page URL] - [Reason for prioritization]

**Content Update Plan (for each priority page):**
1. [Page URL]
   - Update information: [Specific outdated facts, statistics, or content to refresh]
   - Add new links: [Relevant internal and external links with anchor text suggestions]
   - Optimize keywords: [New target keywords and semantic variations to incorporate naturally]
   - Improve readability: [Specific structural improvements—headings, bullet points, paragraph breaks, simplification]
   - Enhance multimedia: [Image, video, infographic, or interactive element recommendations]

[Repeat for pages 2-5]

**Implementation Timeline:**
- Week 1: Complete content audit and finalize prioritization
- Week 2: Update priority pages 1-2
- Week 3: Update priority pages 3-4
- Week 4: Update priority page 5 and conduct final quality review

**Success Metrics to Track:**
- Organic traffic growth (month-over-month %)
- Keyword rankings for target terms (position changes)
- Bounce rate reduction (%)
- Average time on page increase (seconds)
- New backlink acquisition (count and quality)

Ensure all recommendations are actionable, specific, and add genuine value to both search engines and human readers. Avoid superficial changes that don't meaningfully improve content quality or SEO performance.
```
