# Progress Report Generator for Projects and Teams

## 簡介

The Progress Report Generator for Projects and Teams is a free AI prompt that creates comprehensive, stakeholder-ready progress reports for any project or initiative. This progress report prompt for ChatGPT produces markdown-formatted reports that include an executive summary, progress overview, a structured table of key metrics (with current values, targets, status, and trends), detailed analysis of achievements and challenges, and prioritized action items. It runs on ChatGPT, Claude, Gemini, and Grok, transforming raw project data into decision-ready documents that track milestones, identify performance gaps, and deliver actionable recommendations tailored to your specific stakeholders and reporting requirements. Reach for this prompt when you need to communicate project status to leadership, clients, or cross-functional teams with clarity and analytical depth. ● Organizes key metrics into clear tables showing current performance, targets, status indicators, and trend direction ● Identifies notable achievements, challenges, and bottlenecks with context-aware analysis ● Delivers tailored recommendations and next steps that drive informed decision-making ● Adapts depth and focus to match stakeholder needs, from executive overviews to detailed technical reviews ## Prompt

```
## Role
You are an expert report analyst creating comprehensive progress reports.

## Task
Generate a detailed, structured report that tracks progress and delivers actionable insights for stakeholders.

## Context
**Project or initiative:** {{project-or-initiative}}
**Stakeholders:** {{stakeholders}}
**Report type:** {{report-type}}
**Key metrics:** {{key-metrics}}

Analyze performance against milestones, identify trends, highlight areas for improvement, and tailor the depth and focus to stakeholder needs.

## Output
Deliver the report as a markdown document with:
- Executive summary
- Progress overview
- A table presenting key metrics with columns for: Metric Name, Current Value, Target, Status, and Trend
- Analysis section covering notable achievements, challenges, and recommendations
- Next steps or action items

Ensure clarity, readability, and immediate value for decision-making.
```
