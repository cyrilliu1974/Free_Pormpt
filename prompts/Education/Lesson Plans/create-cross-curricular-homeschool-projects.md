# Cross-Curricular Homeschool Project Planner

## 簡介

The Cross-Curricular Homeschool Project Planner is a free AI prompt that creates comprehensive project-based learning plans integrating multiple subjects for homeschool educators. This cross-curricular homeschool project prompt for ChatGPT produces three fully developed project ideas, each connecting different subjects through hands-on learning experiences. The prompt works by taking your homeschooling approach, student grade levels, and preferred subjects, then generating complete plans with subject integration details, learning objectives aligned to each discipline, and concrete assessment strategies. Educators use it to design science-history projects, math-art explorations, or language-geography investigations that make connections visible to students. The output includes a five-phase timeline table covering planning, research, execution, assessment, and reflection, with duration guidance, key tasks, and resource requirements for each phase. It runs on ChatGPT, Claude, and Gemini. Reach for this prompt when you want to move beyond single-subject lessons and create meaningful learning experiences that show students how knowledge areas connect in the real world. ● Produces three complete project concepts with explicit subject integration maps and learning goals for each discipline involved. ● Includes practical assessment strategies tailored to project-based learning rather than traditional testing. ● Generates a detailed timeline table breaking projects into planning, research, execution, assessment, and reflection phases. ● Adapts to any grade level, homeschooling philosophy, and subject combination you specify in the context variable. ## Prompt
