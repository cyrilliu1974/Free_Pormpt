# Concept Map Development Guide Generator

## 簡介

The Concept Map Development Guide Generator is a free AI prompt that creates detailed, actionable guides for building concept maps across any subject domain. This concept map prompt for ChatGPT, Claude, and Gemini produces a five-section framework covering key concept identification techniques, relationship types (hierarchical, causal, associative, sequential), knowledge expansion strategies, a complete step-by-step mapping process, and concrete examples tailored to your chosen subject. Instead of generic advice, you receive 5-7 specific techniques for extracting core concepts, 4-6 relationship frameworks with usage guidelines, and 6-8 detailed process steps complete with execution tips. Educators designing curriculum materials, students organizing complex coursework, instructional designers building training programs, and researchers structuring knowledge domains will find this prompt produces immediately usable concept mapping guides. ● Produces 5-7 actionable techniques for identifying core concepts within any subject area ● Defines 4-6 relationship types with clear descriptions and usage scenarios ● Delivers 6-8 detailed process steps with execution tips and rationale ● Includes three illustrative examples showing text-based map structures with hierarchies and connections ## Prompt

```
## Role
You are an expert concept mapping strategist who creates comprehensive concept maps across any subject domain.

## Task
Develop a detailed step-by-step guide for creating concept maps for {{subject}}. Include practical techniques for identifying key concepts, establishing relationships between them, and expanding knowledge systematically.

## Output
Structure your guide using these five sections:

### 🔍 Key Concept Identification Techniques
Provide 5-7 numbered techniques for extracting core concepts from {{subject}}. Each technique should be actionable and briefly described (1-2 sentences).

### 🔗 Establishing Relationships Between Concepts
Outline 4-6 relationship types relevant to {{subject}} (hierarchical, causal, associative, sequential, etc.). For each type, provide a clear description and indicate when to use it.

### 📈 Knowledge Expansion Strategies
List 5-7 strategies for deepening and broadening the concept map. Present each as a bullet point with concrete actions the user can take.

### 📋 Step-by-Step Concept Mapping Process
Provide a detailed 6-8 step process for building the concept map from start to finish. Each step should include what to do, why it matters, and any tips for execution.

### 🧩 Concept Mapping Examples
Create three illustrative examples that demonstrate different applications or complexity levels within {{subject}}. For each example, provide either a text-based map structure (using indentation and connecting words) or a detailed description that clearly shows the central concept, branches, and key relationships.

Use clear, accessible language throughout. Focus on practical application rather than theory.
```
