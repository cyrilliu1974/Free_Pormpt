# Website Headline Generator for SEO and Engagement

## 簡介

The Website Headline Generator for SEO and Engagement is a free AI prompt that produces five distinct, keyword-rich headlines optimized for search visibility and user engagement. This website headline prompt for ChatGPT guides the AI to act as an expert copywriter, creating headlines in five proven formats: direct value propositions with clear calls to action, problem-focused questions that address audience pain points, unique differentiators that highlight your competitive edge, how-to formats that position your page as an essential resource, and social proof testimonials that build trust. Each headline stays under 70 characters for scannability, incorporates SEO keywords naturally, and aligns with your site's branding. It runs on ChatGPT, Claude, Gemini, and Grok, requiring only your page type and business context as inputs. ● Produces five headlines in different strategic formats to test which resonates best with your audience ● Naturally weaves SEO keywords into each headline to improve search engine discoverability ● Keeps headlines concise and scannable, optimized for both desktop and mobile displays ● Adapts tone and messaging to match your business context and target audience behavior ## Prompt

```
## Role

You are an expert copywriter specializing in SEO-optimized web headlines.

## Task

Generate 5 engaging, attention-grabbing headlines for {{page-type}} that incorporate strategic SEO keywords, align with the site's branding, and encourage visitors to explore further.

## Context

{{business-context}}

## Approach

1. **Direct Value Proposition**: Lead with the primary benefit and a clear call to action, incorporating the main SEO keyword naturally.

2. **Problem-Focused Question**: Frame a question that addresses a key pain point or need of the target audience, weaving in an SEO keyword to spark curiosity.

3. **Unique Differentiator**: Highlight a distinctive feature, benefit, or offer using compelling adjectives and an SEO keyword to create urgency and excitement.

4. **How-To Format**: Position the page as an essential resource by offering actionable solutions or valuable insights related to the page topic.

5. **Social Proof**: Use a testimonial or success story format that includes an SEO keyword to build trust and credibility.

## Output

Deliver 5 distinct headlines, each on its own numbered line:

1. [Direct value proposition with primary SEO keyword]
2. [Question format addressing audience pain point with SEO keyword]
3. [Unique feature/benefit with powerful descriptors and SEO keyword]
4. [How-to format offering solution with SEO keyword]
5. [Testimonial/success story format with SEO keyword]

Each headline should be concise (under 70 characters when possible), scannable, and tailored to the target audience's interests and search behavior.
```
