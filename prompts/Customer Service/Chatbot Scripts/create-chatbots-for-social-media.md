# Social Media Chatbot Blueprint Generator

## 簡介

The Social Media Chatbot Blueprint Generator is a free AI prompt that produces structured automated marketing chatbot designs for businesses deploying conversational agents on social media platforms. This social media chatbot prompt for ChatGPT, Claude, and Gemini analyzes platform-specific technical capabilities, maps user journey triggers and conversation branches, designs conversational flows using dependency grammar principles, and integrates lead capture tactics, CTAs, and nurture sequences. Real applications include e-commerce businesses building Facebook Messenger bots for product recommendations, service providers creating Instagram chatbots for appointment booking, and B2B companies deploying LinkedIn chat agents for lead qualification. The prompt outputs a six-section blueprint covering platform analysis, user journey mapping, conversational flow architecture, marketing funnel integration, brand voice guidelines, and success metrics with actionable implementation steps. Marketing teams, chatbot developers, and social media managers reach for this prompt when planning automated conversational experiences that must balance engagement, conversion goals, and platform policy compliance. ● Analyzes platform APIs, interaction types, and integration constraints specific to the chosen social network ● Maps complete user journeys with entry points, intent-based branching, and fallback handling ● Designs question sequences using dependency grammar so each user response shapes the next prompt intelligently ● Integrates lead qualification criteria, conversion funnel stages, and data collection points aligned with marketing objectives ● Provides brand voice guidelines with example responses, tone patterns, and messaging guardrails ● Defines trackable KPIs and A/B testing recommendations for continuous optimization ## Prompt

```
## Role
You are an expert chatbot developer and social media marketer specializing in automated marketing solutions.

## Task
Design a comprehensive chatbot blueprint for {{platform}} that achieves {{marketing-goal}} while maximizing engagement and conversions.

## Context
Business: {{business-context}}

Analyze the platform's features and API limitations, map key user interactions and triggers, develop a conversational flow using dependency grammar principles, integrate proven marketing tactics (lead capture, nurture sequences, CTAs), and ensure compliance with platform policies and data protection standards.

## Output
Provide a structured chatbot blueprint with the following sections:

**1. Platform Analysis**
- Technical capabilities and constraints
- Supported interaction types (buttons, quick replies, carousels, etc.)
- Integration requirements

**2. User Journey Map**
- Entry points and triggers
- Conversation branches based on user intent
- Fallback and error handling

**3. Conversational Flow**
- Opening message and value proposition
- Question sequences using dependency grammar (each response informs the next prompt)
- Transition logic between conversation states

**4. Marketing Integration**
- Lead qualification criteria
- CTA placement and timing
- Conversion funnel stages
- Data collection points

**5. Brand Voice Guidelines**
- Tone and language patterns
- Example responses demonstrating brand personality
- Do's and don'ts for bot messaging

**6. Success Metrics**
- KPIs to track (engagement rate, completion rate, conversion rate)
- A/B testing recommendations

Format all steps as bullet points with actionable sub-items.
```
