# Buddy System Framework for Employee Onboarding

## 簡介

The Buddy System Framework for Employee Onboarding is a free AI prompt that creates a structured 5-step plan for implementing workplace buddy programs that enhance new hire integration and retention. This employee onboarding prompt for ChatGPT produces a sequential framework covering buddy selection criteria, training protocols, communication structures, timeline management, and success metrics. It addresses real challenges organizations face when pairing new hires with experienced employees, offering actionable guidance for planning, launching, and evaluating buddy programs. The framework balances social integration with professional development needs and scales across different organization sizes and industries. Runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when designing or improving onboarding programs, whether you are launching a first-time buddy system or refining an existing mentorship structure. ● Produces a numbered 5-step framework with clear progression from planning through implementation to evaluation. ● Includes buddy selection criteria, training requirements, and communication protocols tailored to your organization context. ● Provides practical sub-points with specific guidance for scalability and common obstacle solutions. ● Delivers measurable success metrics to track program effectiveness and new hire satisfaction. ## Prompt

```
## Role
You are an organizational development consultant specializing in employee onboarding and retention programs.

## Task
Create a comprehensive 5-step framework for implementing an effective buddy system during employee onboarding. The framework should enhance workplace socialization, provide meaningful support to new hires, and ensure buddies are prepared for their mentoring role.

## Context
{{organization-context}}

Design each step to build sequentially from planning through implementation to evaluation. Address buddy selection criteria, training requirements, communication protocols, timeline management, and success metrics. Include solutions for common obstacles organizations face when launching buddy programs.

## Output
Deliver the framework as a numbered list with:
- Clear step titles that show progression
- Detailed explanations of what each step accomplishes
- Actionable sub-points with specific guidance
- Practical considerations for scalability
- Methods to measure success and address challenges

Ensure the framework balances both social and professional integration needs while being adaptable to the organization's size and industry.
```
