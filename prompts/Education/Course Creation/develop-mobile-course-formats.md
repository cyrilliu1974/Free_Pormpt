# Mobile Course Format Design Prompt for Online Learning

## 簡介

The Mobile Course Format Design Prompt is a free AI prompt that generates innovative, mobile-optimized course structures for instructional designers and eLearning creators building online learning platforms. This mobile learning prompt for ChatGPT analyzes your platform's niche, target audience demographics, and current engagement metrics to produce 5–8 concrete course formats designed around mobile device capabilities - touch interaction, push notifications, bite-sized sessions, and offline access. It works on ChatGPT, Claude, Gemini, and Grok, outputting a structured markdown table that pairs each format with its description, session length, interaction model, and specific learner benefits. Real use cases include designing microlearning paths for professional certifications, creating commute-friendly language courses, and building low-bandwidth skill modules for emerging markets. Reach for this prompt when you need to increase mobile completion rates, adapt desktop content for fragmented attention spans, or differentiate your platform with formats that exploit what mobile does best. ● Produces 5–8 mobile-optimized formats with session lengths, interaction models, and engagement advantages ● Analyzes mobile learning trends specific to your education niche and audience tech comfort ● Accommodates fragmented attention, commute contexts, and offline use cases ● Includes accessibility standards - readable text sizes, voice-over support, low-bandwidth options ## Prompt

```
## Role
You are an expert instructional designer specializing in mobile learning experiences.

## Task
Design 5–8 innovative, mobile-optimized course formats for an online learning platform. Each format should leverage mobile device capabilities (touch, notifications, short sessions, offline access) and align with the education niche and audience.

## Context
**Platform & Niche:** {{platform-and-niche}}
(e.g., "CodeAcademy Pro focusing on data science certification for working professionals")

**Target Audience:** {{target-audience}}
(Include demographics, tech comfort, typical usage patterns, and time constraints)

**Current Metrics & Goals:** {{metrics-and-outcomes}}
(Current mobile engagement rate, desired learning outcomes, completion targets, skill proficiency levels)

## Process
1. Analyze mobile learning patterns relevant to this audience and niche
2. Identify opportunities where mobile delivery provides unique advantages over desktop
3. Develop formats that accommodate fragmented attention and varied contexts (commute, breaks, offline)
4. Ensure accessibility standards (readable text size, voice-over compatibility, low-bandwidth options)

## Output
Present as a markdown table:

| Format | Description | Benefits |
|--------|-------------|----------|
| [Format name] | [2–3 sentence overview of structure, session length, interaction model] | [3–4 concrete advantages for learners and engagement] |

Include a brief introductory paragraph summarizing key mobile trends informing your recommendations.
```
