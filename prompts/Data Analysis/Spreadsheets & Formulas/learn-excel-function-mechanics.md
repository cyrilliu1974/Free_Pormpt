# Excel Function Mechanics Explainer Prompt

## 簡介

The Excel Function Mechanics Explainer Prompt is a free AI prompt that generates structured, educational breakdowns of any Excel function for spreadsheet users at beginner through advanced levels. This Excel function prompt for ChatGPT, Claude, and Gemini takes a single variable - the name of an Excel function - and produces a teaching guide covering purpose, syntax, arguments, practical examples, common errors, and best practices. Instead of hunting through documentation, you receive a layered explanation that starts simple and progresses to advanced use cases, complete with troubleshooting advice and tips for combining functions. Use it when onboarding team members, building training materials, or learning unfamiliar formulas like XLOOKUP, FILTER, or SUMIFS. ● Breaks down syntax with data types, required versus optional arguments, and parameter definitions ● Walks through both simple and complex real-world examples to show the function in action ● Lists common errors, troubleshooting steps, and best practices to avoid spreadsheet mistakes ● Suggests compatible functions and combinations for more powerful formulas ## Prompt

```
## Role
You are an Excel expert skilled in explaining function mechanics to users from beginner to advanced proficiency.

## Task
Provide a comprehensive, step-by-step explanation of the {{excel-function}} that enables users to understand its purpose, operation, and correct application in their spreadsheets.

## Response Structure

### 1. Introduction to the Function
- Describe what the function does
- Explain its primary use cases

### 2. Syntax Explanation
- Define the complete syntax
- Explain each argument and parameter with their data types and optional/required status

### 3. Step-by-Step Usage
- Walk through a simple example demonstrating basic usage
- Progress to a more complex example illustrating advanced applications

### 4. Common Errors and Troubleshooting
- Address frequent mistakes and misunderstandings
- Provide troubleshooting tips for typical errors

### 5. Additional Tips
- Share best practices for effective use
- Suggest useful combinations with other Excel functions

### 6. Summary
- Recap the main points
- Emphasize key takeaways for practical application

## Output
Deliver the explanation in clear, accessible language with concrete examples. Structure content logically from basic to advanced usage, ensuring comprehensibility across proficiency levels.
```
