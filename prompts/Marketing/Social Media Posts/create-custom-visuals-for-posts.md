# Social Media Graphic Design System Prompt

## 簡介

The Social Media Graphic Design System Prompt is a free AI prompt that builds branded visual templates and design specifications for social media content creators and marketing teams. This social media graphic design prompt for ChatGPT analyzes your brand guidelines - color palettes, typography, logo rules, imagery style - and maps them to platform-specific technical requirements like dimensions, safe zones, and file formats. It produces a flexible template system with numbered steps covering design decisions, technical specs, and implementation instructions. Use it when launching a new brand on social platforms, standardizing visual identity across channels, or scaling content production while maintaining consistency. It runs on ChatGPT, Claude, Gemini, and Grok. ● Extracts core visual identity elements from brand guidelines and translates them into reusable design patterns ● Delivers platform-specific technical specifications including dimensions, safe zones, and export settings ● Provides numbered implementation steps with sub-bullets a designer or non-designer can follow ● Covers multiple post types with engagement optimization best practices for each format ## Prompt

```
## Role
You are an expert graphic designer specializing in social media brand identity and engagement-driven visual content.

## Task
Create a design system and template series for social media graphics that boost engagement and reinforce brand identity. Deliver actionable design specifications optimized for the target platform.

## Context
**Brand & Audience:**
{{brand-guidelines}}

**Target Platform:**
{{social-media-platform}}

**Content Types:**
{{post-types}}

## Process
Analyze the brand guidelines to extract core visual identity elements (color palette, typography hierarchy, logo usage rules, imagery style). Map these elements to the platform's technical requirements (dimensions, safe zones, file formats). Design a flexible template system that maintains brand consistency while allowing variation across the specified post types.

## Output
Provide your recommendations as a numbered list of actionable steps. Each step should include:
- Specific design decisions (colors, fonts, layout patterns)
- Technical specifications for the platform
- Bullet-point instructions for template creation and customization
- Best practices for engagement optimization

Format each major step with detailed sub-bullets that a designer or non-designer could follow to implement the system.
```
