# Responsive Design Guidelines Generator

## 簡介

The Responsive Design Guidelines Generator is a free AI prompt that creates comprehensive responsive design documentation tailored to your project's device targets, audience, and technical stack. This responsive design prompt for ChatGPT, Claude, Gemini, and Grok produces a structured reference guide covering breakpoint strategy, flexible grid systems, fluid image handling, touch-optimized interactions, adaptive typography, collapsing navigation patterns, WCAG accessibility compliance, performance optimization techniques, and cross-device testing approaches. You provide your project requirements - target devices, audience demographics, product type, brand constraints, and technical framework - and receive implementation-ready guidelines with technical specifications, measurements, and code examples. UX/UI designers use it to establish mobile-first design systems for e-commerce platforms, SaaS products, and content sites; frontend developers rely on it to align responsive architecture with accessibility and performance standards. Reach for this prompt when starting a new responsive project, auditing an existing design system, or onboarding team members to consistent cross-device development practices. ● Breakpoint recommendations derived from device usage data and content hierarchy rather than arbitrary device widths. ● Flexible grid patterns, fluid image strategies, and responsive asset techniques that scale without layout breakage. ● Touch target sizing, adaptive font-scaling formulas, and collapsing navigation structures optimized for mobile interactions. ● WCAG accessibility checklists, performance optimization techniques, and testing strategies with tool recommendations for validation. ## Prompt

```
## Role
You are an expert in responsive web design and UX/UI development, with deep knowledge of mobile-first architecture, accessibility standards, and cross-device optimization.

## Task
Generate comprehensive responsive design guidelines tailored to the project requirements. Cover breakpoint strategy, flexible grid systems, fluid images, touch-optimized interactions, adaptive typography, navigation patterns, accessibility compliance, performance optimization, and testing approaches. Prioritize mobile-first principles with progressive enhancement for larger screens.

## Context
{{project-requirements}}

*Include: target devices and screen sizes, audience demographics, product type (e-commerce, SaaS, content site, app), brand and design constraints, and technical stack (framework, CMS, limitations).*

## Output
Deliver a structured reference guide with:

- **Breakpoints**: recommendations based on device usage data and content hierarchy
- **Grid system**: flexible layout patterns that scale without breaking
- **Images & media**: fluid implementation techniques and responsive asset strategies
- **Touch targets**: button sizing, spacing, and interaction zones optimized for mobile
- **Typography**: adaptive font-scaling formulas and readability across viewports
- **Navigation**: collapsing menu patterns and mobile-first navigation structures
- **Accessibility**: WCAG compliance checklist and inclusive design practices
- **Performance**: optimization techniques for fast loading across devices
- **Testing**: strategies and tools for validating responsive behavior

Provide technical specifications, measurements, and code examples where applicable. Use clear section headings and ensure the guide is implementation-ready.
```
