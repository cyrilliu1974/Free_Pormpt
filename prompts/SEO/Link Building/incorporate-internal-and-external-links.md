# Internal and External Link Strategy Builder

## 簡介

The Internal and External Link Strategy Builder is a free AI prompt that creates comprehensive linking strategies for content creators, SEO specialists, and digital marketers who need to balance search optimization with reader experience. This internal and external linking prompt for ChatGPT analyzes your content type, maps topic hierarchies, and produces a complete link architecture plan that includes internal page connections, authoritative external sources, optimized anchor text, and sentence restructuring using dependency grammar - a linguistic framework that keeps prose tight and scannable. You define your target audience, main website topics, and focus keyword; the prompt returns topic maps, internal link placements with rationale, external source validation, sample rewritten paragraphs, and an SEO summary covering keyword integration and link density. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need to retrofit existing content with strategic links, plan link architecture for new articles, or train a team on dependency grammar for clearer writing that search engines parse efficiently. ● Maps topic hierarchies and dependencies so you understand content relationships before placing links ● Recommends a balanced internal-to-external link ratio (2:1 or 3:1) and enforces link density limits to avoid over-optimization ● Applies dependency grammar to restructure sentences, ensuring each link sits within clear, logical prose that readers and crawlers can follow ● Outputs sample rewritten paragraphs, anchor text suggestions, and an SEO summary including readability scores ## Prompt

```
## Role
You are an expert content strategist specializing in SEO optimization and reader engagement through strategic linking and coherent information architecture.

## Task
Create a comprehensive internal and external linking strategy for {{content-type}}, structured using dependency grammar principles to ensure logical flow and readability.

## Context
**Target audience:** {{target-audience}}
**Website main topics:** {{main-topics}}
**Focus keyword:** {{focus-keyword}}

Dependency grammar ensures each sentence element relates clearly to its head, creating tight, scannable prose that both search engines and readers can parse efficiently.

## Process
1. **Topic mapping** – Identify the main topics and subtopics within the content; map their hierarchical relationships
2. **Internal link research** – Find relevant pages on the website that provide deeper context or related information
3. **External source validation** – Locate authoritative external sources (academic papers, industry leaders, official statistics) that support claims
4. **Sentence structure** – Apply dependency grammar to ensure each sentence has a clear head and logical modifiers; avoid nested complexity
5. **Link placement** – Position internal links where they extend the reader's journey; place external links where they add credibility
6. **Anchor text optimization** – Use natural, keyword-relevant anchor text that describes the destination accurately
7. **Link balance** – Maintain a 2:1 or 3:1 internal-to-external link ratio; avoid over-linking (max one link per 100–150 words)
8. **Flow review** – Read through to ensure links enhance rather than interrupt the narrative
9. **Coherence check** – Verify that all links remain relevant to the content's core purpose and audience needs

## Output
Deliver your strategy in a structured format:
- **Topic Architecture** (main topics, subtopics, dependencies)
- **Internal Linking Plan** (pages, anchor text, placement rationale)
- **External Linking Plan** (sources, anchor text, relevance)
- **Sample Restructured Paragraphs** (showing dependency grammar application)
- **SEO Summary** (keyword integration, link density, readability score)

Use headings, subheadings, bullet points, and numbered lists for clarity.
```
