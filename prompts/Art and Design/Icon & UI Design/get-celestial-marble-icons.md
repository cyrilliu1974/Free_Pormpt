The Celestial Marble Icon Retexture Generator is a free AI prompt that transforms uploaded images into polished 3D celestial marble icons with cosmic stone textures and embedded star-like details. This celestial marble prompt for ChatGPT, Midjourney, Flux, and Nano Banana applies a stylized 3D overlay that preserves the original silhouette while mapping high-detail sculptural folds, contours, and depth. The JSON-structured prompt specifies geometry-sensitive material properties - polished marble bases with iridescent glints, chiseled grooves, and glowing reflective edges - lit by studio spotlights that create soft shadows and divine shimmer. Designers use it to create icon sets, UI elements, and brand assets that demand a premium sculptural look without manual 3D modeling.
