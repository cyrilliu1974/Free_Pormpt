# Level Progression System for Educational Games

## 簡介

The Level Progression System for Educational Games is a free AI prompt that creates structured learning paths for gamified educational platforms used by instructional designers and educational game developers. This level progression prompt for ChatGPT guides the model to generate a complete table mapping 5-8 learning levels, each with aligned objectives, activities, and reward systems that apply scaffolding principles and spaced repetition. The prompt runs on ChatGPT, Claude, and Gemini, and produces a markdown table showing how learners move from foundational concepts to advanced skills. Use cases include designing mobile learning apps, corporate training platforms, K-12 educational games, and skill-building courses where motivation and retention matter as much as content delivery. Reach for this prompt when you need to translate a subject and desired learning outcomes into a coherent progression system that balances challenge, engagement, and pedagogical best practices. ● Generates a multi-level table mapping learning objectives, diverse activities, and meaningful rewards that reinforce intrinsic motivation ● Applies scaffolding and spaced repetition to ensure each level builds logically on prior knowledge and reinforces retention ● Accepts custom inputs for subject, target audience, learning outcomes, and platform features to tailor the system to your course or game ● Produces 5-8 progression levels that demonstrate a complete learning arc from beginner to advanced mastery ## Prompt

```
## Role
You are an expert educational game designer specializing in learning progression systems and gamification mechanics.

## Task
Design a structured level progression system for a gamified educational platform. Create a table that maps out a complete learning path, balancing objectives, activities, and rewards to drive engagement and skill mastery. Apply scaffolding principles, spaced repetition, and intrinsic motivation throughout.

## Context
**Subject:** {{subject}}
**Target audience:** {{target-audience}}
**Desired learning outcomes:** {{learning-outcomes}}
**Available platform features:** {{platform-features}}

Ensure activities are diverse, appropriately challenging, and directly aligned with learning objectives. Design rewards that are meaningful and reinforce the learning process rather than distract from it.

## Output
Deliver your progression system as a markdown table with these columns: Level, Learning Objectives, Activities, and Rewards. Each row should represent one coherent progression step that builds logically on previous levels. Include at least 5-8 levels to demonstrate a complete learning arc from foundational to advanced skills.
```
