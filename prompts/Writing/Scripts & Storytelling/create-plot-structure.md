# Plot Structure Generator for Novelists

## 簡介

The Plot Structure Generator for Novelists is a free AI prompt that builds comprehensive, act-based story outlines for fiction writers working in any genre. This plot structure prompt for ChatGPT takes your genre, chosen act structure (three-act, four-act, Save the Cat, Hero's Journey, etc.), and story foundation, then produces a markdown table mapping key plot points, character development moments, and thematic beats across every act. It identifies genre conventions, distributes dramatic tension and pacing across the narrative, and ensures each act serves a clear structural purpose. Writers use it to outline novels, screenplays, and serialized fiction before drafting, ensuring coherent progression from inciting incident through climax and resolution. The prompt runs on ChatGPT, Claude, Gemini, and Grok. Reach for this tool when you need a bird's-eye view of your story architecture or want to test whether your premise can sustain a full narrative arc. ● Adapts to any act structure - three-act, five-act, Save the Cat beat sheet, or custom frameworks - so you control the scaffolding. ● Outputs a markdown table with acts as columns and story elements (plot points, character growth, theme) as rows, making it easy to see gaps or imbalances. ● Applies genre-specific conventions (mystery reveals, romance emotional beats, thriller twists) to ensure your outline aligns with reader expectations. ● Maintains narrative momentum by distributing tension, pacing, and dramatic peaks across the entire structure. ## Prompt

```
## Role
You are an expert novelist and plot structure specialist creating comprehensive story outlines.

## Task
Develop a detailed plot structure for a novel, organized as a markdown table with acts as columns and story elements as rows.

## Context
Genre: {{genre}}
Act structure: {{act-structure}}
Story foundation: {{story-foundation}}

Begin by identifying the genre's conventions and typical story arcs. Break the plot into the specified acts, ensuring each has clear purpose and progression. Distribute key plot points, character development moments, and thematic elements across acts to maintain tension, pacing, and narrative coherence throughout.

## Output
Deliver a markdown table with:
- **Column headers**: act names from the specified structure
- **Rows**: key plot points, character developments, and thematic elements
- Each cell should contain specific story beats appropriate to that act and element type
- The progression should follow genre conventions while building dramatic momentum
```
