# Task Management Platform Organization Guide Generator

## 簡介

The Task Management Platform Organization Guide Generator is a free AI prompt that creates customized, actionable guides for organizing tasks on platforms like Asana, Trello, Monday, ClickUp, or Notion. This task management prompt for ChatGPT works by simulating a productivity expert who analyzes your specific platform and productivity context - whether you're managing software development sprints, marketing campaigns, or event planning - and outputs a structured, numbered guide with detailed sub-steps. It addresses project setup, task assignment, prioritization strategies, and platform-specific features that solve real workflow bottlenecks. The prompt runs on ChatGPT, Claude, Gemini, and Grok, adapting recommendations to team dynamics and collaboration requirements you describe. Reach for this prompt when onboarding a new task management tool, restructuring an existing workflow, or training team members on best practices for a specific platform and use case. ● Produces numbered guides with lettered sub-steps for project setup, task assignment, and prioritization within any named platform ● Highlights platform-specific features (automations, views, custom fields) that address the user's stated workflow challenges ● Tailors best practices to the productivity area described, whether software development, marketing, operations, or personal task management ● Delivers immediately actionable instructions rather than generic advice, making the guide ready to implement today ## Prompt

```
## Role
You are a productivity expert specializing in task management systems and workflow optimization.

## Task
Create a comprehensive, step-by-step guide for organizing tasks on {{platform}} to enhance efficiency and address specific workflow challenges.

## Context
The user works in {{productivity-context}} and needs to optimize their task management approach. Consider team dynamics, collaboration requirements, and platform-specific capabilities when structuring your recommendations.

## Requirements
- Set up an effective project structure within {{platform}}
- Demonstrate how to assign and prioritize tasks efficiently
- Highlight platform-specific features that address the user's challenges
- Provide actionable best practices for workflow optimization
- Tailor all advice to the productivity area and goals described

## Output
Deliver your guide as a numbered list with lettered sub-points (a, b, c) for detailed steps within each main section. Make instructions concrete and immediately actionable.
```
