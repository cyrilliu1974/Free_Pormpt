# User Manual Template for Software and Products

## 簡介

The User Manual Template for Software and Products is a free AI prompt that creates comprehensive documentation for any product or software aimed at audiences with varying technical expertise. This user manual prompt for ChatGPT walks through seven core sections: Introduction, Getting Started, Basic Operations, Advanced Features, Troubleshooting, FAQ, and Conclusion. It runs on ChatGPT, Claude, Gemini, and Grok, producing step-by-step instructions, visual interface overviews, and common-issue resolutions formatted for easy navigation. Technical writers use it to standardize documentation for SaaS platforms, hardware devices, and enterprise tools without starting from scratch each time. Reach for this prompt when you need consistent, audience-appropriate manuals that cover installation through advanced workflows in a single pass. ● Outputs seven organized sections from product overview to support contacts, ensuring nothing critical is omitted. ● Includes subsection prompts for 3–5 basic tasks, 2–4 advanced features, and 3–5 troubleshooting scenarios with clear issue-solution pairs. ● Adapts tone and detail depth to match your target audience, whether novice end-users or technical administrators. ● Generates FAQ and additional-resources sections to reduce repetitive support queries. ## Prompt

```
## Role
You are a technical writer creating a comprehensive user manual. Write for users with varying technical knowledge levels, providing clear instructions, troubleshooting guidance, and explanations that make the product accessible to all.

## Task
Create a complete user manual for {{product-or-software}} structured in seven sections: Introduction, Getting Started, Basic Operations, Advanced Features, Troubleshooting, FAQ, and Conclusion. Each section should be clearly organized with appropriate subsections.

## Context
Target audience: {{target-audience}}
Company: {{company-name}}

The manual should be easy to navigate and focus on the most important aspects without overwhelming users with unnecessary detail. Include step-by-step instructions where appropriate.

## Output
Format the manual using this structure:

### Introduction
- Product Overview
- Intended Audience
- Prerequisites

### Getting Started
- Installation Instructions
- Initial Setup
- User Interface Overview

### Basic Operations
Provide step-by-step instructions for 3-5 key tasks, each as a separate subsection.

### Advanced Features
Explain 2-4 advanced features, each as a separate subsection with clear descriptions.

### Troubleshooting
List 3-5 common issues with their solutions in this format:
- Issue: [description]
- Solution: [step-by-step resolution]

### FAQ
Provide 3-5 frequently asked questions with concise answers.

### Conclusion
- Summary of key points
- Additional Resources (documentation, tutorials, community forums)
- Contact Information (support channels)
```
