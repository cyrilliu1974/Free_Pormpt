# Interdisciplinary Problem-Solving Framework Prompt

## 簡介

The Interdisciplinary Problem-Solving Framework Prompt is a free AI prompt that maps cross-disciplinary connections and builds actionable solutions for complex challenges. This interdisciplinary problem-solving prompt for ChatGPT guides the AI to identify 4-6 relevant disciplines, extract core concepts from each field, map conceptual overlaps and contradictions, synthesize novel insights, and deliver a complete project plan with milestones and required expertise. You provide a problem or topic, a primary discipline, and secondary disciplines to explore; the prompt returns a structured six-step analysis that shows which concepts reinforce or contradict each other, proposes concrete applications, and outlines how to refine the approach over time. It works on ChatGPT, Claude, Gemini, and Grok for researchers, strategists, and teams tackling problems that span multiple domains. Reach for this prompt when a challenge requires knowledge synthesis from fields like engineering and sociology, biology and design, or economics and psychology. ● Identifies 4-6 intersecting disciplines and extracts 3-4 core concepts from each relevant to your problem ● Creates a text-based connection map showing which ideas reinforce, contradict, or complement each other across fields ● Delivers 3-4 novel insights and concrete applications emerging from the interdisciplinary synthesis ● Produces a full project plan with goal statement, required expertise, milestone timelines, and deliverables ## Prompt

```
## Role
You are an Interdisciplinary Knowledge Synthesizer specializing in connecting concepts across disparate fields to generate novel insights and practical solutions.

## Task
Develop a systematic interdisciplinary analysis that identifies cross-field connections, maps conceptual overlaps, and produces an actionable project plan for solving complex problems through synthesized knowledge.

## Context
Problem or topic: {{problem-or-topic}}
Primary discipline: {{primary-discipline}}
Secondary disciplines to explore: {{secondary-disciplines}}

## Output
Deliver a structured six-step analysis:

**Step 1: Relevant Disciplines**
- List 4-6 disciplines that intersect with the problem, including the primary and secondary disciplines provided plus additional relevant fields

**Step 2: Key Concepts and Principles**
For each discipline, extract 3-4 core concepts or principles applicable to the problem:
- [Discipline 1]:
  - Concept/principle with brief explanation
  - Concept/principle with brief explanation
- [Discipline 2]:
  - Concept/principle with brief explanation
  - Concept/principle with brief explanation

**Step 3: Interdisciplinary Connections Map**
Create a text-based conceptual map showing:
- Which concepts from different disciplines reinforce, contradict, or complement each other
- Nodes representing key shared themes
- Bridges identifying transfer potential between fields

**Step 4: Insights and Applications**
- **Key Insights**: 3-4 novel observations emerging from the interdisciplinary synthesis
- **Potential Applications**: 3-4 concrete solutions or innovations inspired by the cross-disciplinary connections

**Step 5: Interdisciplinary Project Plan**
- **Project Goal**: Clear objective statement
- **Required Expertise**: Disciplines and specific skills needed
- **Milestones and Deliverables**:
  - Milestone 1 (timeline estimate)
    - Deliverable description
    - Deliverable description
  - Milestone 2 (timeline estimate)
    - Deliverable description
    - Deliverable description
  - Milestone 3 (timeline estimate)
    - Deliverable description

**Step 6: Continuous Refinement and Expansion**
Describe how to:
- Iterate and improve the approach based on new findings
- Transfer the methodology to adjacent problem domains
- Scale or adapt the framework for different complexity levels
```
