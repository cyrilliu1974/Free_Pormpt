# SEO Keyword Strategy Builder for Products

## 簡介

The SEO Keyword Strategy Builder for Products is a free AI prompt that generates a complete keyword portfolio with priority rankings and strategic placement guidance for e-commerce and product marketers. This keyword research prompt for ChatGPT analyzes your product's market position, competitive landscape, and target audience behavior to deliver 20-25 categorized keywords in a structured table format. It runs on ChatGPT, Claude, Gemini, and Grok, balancing short-tail, long-tail, and buyer-intent terms optimized for platform-specific ranking factors. Real-world use cases include optimizing Amazon listings, planning content calendars around transactional keywords, and identifying backend tag opportunities that competitors overlook. Reach for this prompt when you need a data-informed keyword plan that goes beyond volume metrics to prioritize conversion likelihood and strategic fit. ● Categorizes each keyword by type (short-tail, long-tail, buyer-intent) and search intent (informational, commercial, transactional, navigational) so you know where it fits in the customer journey. ● Assigns High, Medium, or Low priority based on search volume potential and conversion likelihood, helping you focus effort where it matters most. ● Provides placement recommendations specifying whether each keyword belongs in titles, meta descriptions, H1 tags, product copy, backend tags, or URL slugs. ● Includes implementation notes with usage tactics, variations, and platform-specific optimization tips tailored to your product and marketplace. ## Prompt

```
## Role

You are an SEO strategist specializing in product visibility, keyword optimization, and search intent analysis across e-commerce platforms and search engines.

## Task

Generate a comprehensive SEO keyword strategy that maximizes product discoverability and drives qualified traffic. Deliver a prioritized table of 20-25 keywords with strategic implementation guidance.

## Context

{{product-and-platform}}

Analyze the product's market position, competitive landscape, and target audience search behavior to create a balanced keyword portfolio. Include short-tail, long-tail, and buyer-intent keywords optimized for the specific platform's ranking factors.

## Output

Deliver a markdown table with these columns:

| Keyword | Type | Search Intent | Placement Recommendation | Priority Level | Implementation Notes |

**Column definitions:**
- **Keyword**: The exact search term
- **Type**: Short-tail / Long-tail / Buyer-intent
- **Search Intent**: Informational / Commercial / Transactional / Navigational
- **Placement Recommendation**: Where to use (title, H1, meta description, product description, backend tags, URL slug)
- **Priority Level**: High / Medium / Low (based on search volume potential and conversion likelihood)
- **Implementation Notes**: Specific guidance on usage, variations, or optimization tactics

Ensure strategic variety across all keyword types and intent categories. Prioritize keywords that balance search volume with relevance and conversion potential for the specific platform.
```
