# SEO-Optimized Webinar Planner for Any Industry

## 簡介

The SEO-Optimized Webinar Planner for Any Industry is a free AI prompt that creates beginner-friendly, keyword-rich webinar outlines structured for search visibility and audience engagement. This webinar planning prompt for ChatGPT produces a full outline including an SEO-optimized title, a keyword-rich description, a three-topic curriculum table with subtopics and key points, two potential guest speakers per topic, duration and format recommendations, and three promotion tactics. It runs on ChatGPT, Claude, Gemini, and Grok, guiding you through every planning element from content structure to marketing strategy. Use it when you need to design educational webinars that rank well in search, appeal to beginners in any field, and organize ideas into a presentation-ready format. ● Produces a structured table organizing three main topics, nine subtopics, key teaching points, and guest speaker recommendations ● Generates SEO-optimized titles and descriptions that incorporate relevant search keywords for better discoverability ● Includes webinar duration, format elements, and three actionable promotion tactics to maximize attendance ● Keeps content beginner-accessible and jargon-free, making complex subjects approachable for new learners ## Prompt

```
## Role
You are an SEO webinar planning expert specializing in beginner-friendly, search-optimized content across industries.

## Task
Create a comprehensive SEO-focused webinar outline tailored to {{industry}}. The outline should be beginner-accessible, keyword-rich, and actionable.

## Requirements
- Craft a catchy, SEO-optimized webinar title
- Write a brief, keyword-rich webinar description
- Organize content in a table with columns: Topic | Subtopics | Key Points | Potential Guest Speakers
- Include 3 main topics, each with 3 subtopics, key points, and 2 suggested guest speakers
- Specify webinar duration and format (3 format elements)
- Provide 3 webinar promotion tactics
- Use relevant keywords throughout to improve search visibility
- Avoid technical jargon; focus on practical, implementable insights
- Ensure content is well-organized, informative, and engaging for beginners

## Output
Deliver the outline in this structure:

**Industry:** {{industry}}

**Webinar Title:** [your SEO-optimized title]

**Webinar Description:** [keyword-rich description, 2-3 sentences]

**Webinar Outline:**

| Topic | Subtopics | Key Points | Potential Guest Speakers |
|-------|-----------|------------|-------------------------|
| [Topic 1] | - [Subtopic 1A]<br>- [Subtopic 1B]<br>- [Subtopic 1C] | - [Key Point 1A]<br>- [Key Point 1B]<br>- [Key Point 1C] | - [Speaker 1A]<br>- [Speaker 1B] |
| [Topic 2] | - [Subtopic 2A]<br>- [Subtopic 2B]<br>- [Subtopic 2C] | - [Key Point 2A]<br>- [Key Point 2B]<br>- [Key Point 2C] | - [Speaker 2A]<br>- [Speaker 2B] |
| [Topic 3] | - [Subtopic 3A]<br>- [Subtopic 3B]<br>- [Subtopic 3C] | - [Key Point 3A]<br>- [Key Point 3B]<br>- [Key Point 3C] | - [Speaker 3A]<br>- [Speaker 3B] |

**Webinar Duration:** [specify length]

**Webinar Format:**
- [Format element 1]
- [Format element 2]
- [Format element 3]

**Webinar Promotion:**
- [Promotion tactic 1]
- [Promotion tactic 2]
- [Promotion tactic 3]
```
