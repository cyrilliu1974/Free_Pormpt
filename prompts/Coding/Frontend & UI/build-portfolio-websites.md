# React Portfolio Website Builder

## 簡介

The React Portfolio Website Builder is a free AI prompt that generates complete, production-ready portfolio applications for developers and designers who need professional, animated web presences. This portfolio website prompt for ChatGPT walks through every layer of a modern React application: foundation setup with Tailwind configuration and theming, glassmorphism navigation with scroll effects, animated hero sections with parallax backgrounds, interactive project galleries with hover animations and filtering, case-study layouts with lightbox galleries, skills sections with animated tags, contact forms with real-time validation, and mobile optimization. It runs on ChatGPT, Claude, and Cursor, delivering TypeScript-typed components, Framer Motion animations, and production-grade code you can deploy immediately. Use it when you need a visually striking portfolio that showcases projects through interactive storytelling while maintaining accessibility and performance standards. ● Scaffolds complete project structure with Tailwind CSS configuration, theme system, and React component architecture ● Builds interactive UI elements including glassmorphism navigation, parallax hero sections, filterable project cards, and lightbox galleries ● Implements Framer Motion animations for hover effects, scroll interactions, page transitions, and success states ● Delivers accessibility-compliant, mobile-optimized code with real-time form validation and production-grade performance ## Prompt

```
## Role

You are an expert full-stack developer and web designer specializing in production-ready portfolio sites that combine modern frontend engineering with visual storytelling.

## Task

Create a complete, production-ready React portfolio application using TypeScript, Tailwind CSS, and Framer Motion. Build a professional digital experience that balances bold design with flawless functionality.

## Context

{{portfolio-content}}

Include: personal brand/headline, 3-5 featured projects with descriptions, technical skills and expertise areas, professional background/story, and contact information with social links.

## Output

Deliver complete, functional components structured across these sections:

### Foundation Setup
Project structure, Tailwind configuration, and theme system

### Core Layout and Navigation
Glassmorphism navigation with scroll effects

### Hero Section
Animated gradient backgrounds with parallax effects

### Interactive Projects Gallery
Hover animations and filterable project cards

### Case Study Pages
Rich content layouts with lightbox galleries

### About and Skills Section
Animated skill tags and professional storytelling

### Contact Form
Real-time validation with success animations

### Performance and Accessibility
Mobile optimization and production-grade code quality

Provide deployment-ready code with proper TypeScript typing, Framer Motion animations, and modern React patterns. Ensure all components are accessible, performant, and ready for immediate use.
```
