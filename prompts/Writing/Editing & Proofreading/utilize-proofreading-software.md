# Grammar and Punctuation Proofreading Prompt

## 簡介

The Grammar and Punctuation Proofreading Prompt is a free AI prompt that systematically reviews written content for errors and produces detailed correction lists with explanations for writers, editors, and content teams. This proofreading prompt for ChatGPT works by analyzing your document for subject-verb agreement issues, tense consistency problems, spelling mistakes, punctuation errors, and flow concerns. Running on ChatGPT, Claude, or Gemini, it outputs a structured table listing each error found, the corrected version, and a clear rationale for the change - making it easy to understand and apply fixes. Writers use it to polish blog posts, students rely on it for academic papers, and professionals apply it to business communications before publication. Reach for this prompt when you need a methodical, line-by-line review that not only corrects mistakes but teaches you why each change matters, turning proofreading into a learning opportunity. ● Catches grammatical issues including subject-verb agreement, tense consistency, incorrect articles, and misused prepositions ● Detects spelling mistakes, commonly confused words, and proper noun errors ● Evaluates punctuation placement and usage across commas, semicolons, periods, and other marks ● Assesses document coherence and logical flow, suggesting structural improvements where text is unclear or disconnected ● Outputs corrections in a three-column format - error quoted, correction provided, and explanation given - so you understand every change ## Prompt

```
## Role
You are an expert proofreader correcting written content for grammatical, spelling, and punctuation errors while ensuring clarity and coherence.

## Task
Review the provided document and:

1. Identify and correct grammatical errors (subject-verb agreement, tense consistency, articles, prepositions)
2. Fix spelling mistakes, including commonly confused words and proper nouns
3. Evaluate punctuation usage (commas, semicolons, etc.)
4. Assess overall coherence and flow, suggesting improvements where necessary
5. Provide clear explanations for each correction

## Context
{{document-context}}

## Output
Provide a detailed, numbered list with three columns for each issue:
- **Error found**: Quote the problematic text
- **Correction**: The fixed version
- **Explanation**: Brief rationale for the change
```
