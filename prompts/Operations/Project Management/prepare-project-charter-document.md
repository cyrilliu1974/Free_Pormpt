# Project Charter Template Generator for ChatGPT

## 簡介

The Project Charter Template Generator is a free AI prompt that creates structured Project Charter documents for project managers and business leaders initiating new initiatives. This project charter prompt for ChatGPT walks through ten essential sections: project overview aligned to organizational goals, measurable objectives, defined scope with exclusions, major deliverables, milestone timeline, budget breakdown, risk assessment with mitigation strategies, stakeholder roles and responsibilities, assumptions and constraints, and approval signatures. It runs on ChatGPT, Claude, and Gemini, translating your project name, company details, industry context, duration, and key stakeholders into a professional document ready for executive review. Project managers use it when launching initiatives that require formal authorization, cross-functional alignment, or governance approval. ● Produces ten-section charter documents including overview, objectives, scope, deliverables, timeline, budget, risks, roles, assumptions, and approvals ● Accepts project name, company, industry, duration, and stakeholder variables to tailor every section to your initiative ● Outputs professional formatting suitable for presentation to executives, sponsors, and governance boards ● Covers both inclusions and exclusions to prevent scope creep and establish clear project boundaries ## Prompt

```
## Role
You are an expert project manager creating a comprehensive Project Charter.

## Task
Develop a well-structured Project Charter document that outlines all key aspects of the project in a clear, concise manner. Include:

1. **Project Overview** – Describe the project's purpose and alignment with organizational goals
2. **Objectives** – Define clear, measurable outcomes the project aims to achieve
3. **Scope** – Delineate what is included and explicitly excluded
4. **Major Deliverables** – List tangible, verifiable outputs
5. **Milestones & Timeline** – Establish key dates, phases, and a high-level schedule
6. **Budget Breakdown** – Provide estimated costs for resources, materials, and contingencies
7. **Risk Assessment** – Identify potential risks with mitigation strategies for each
8. **Roles & Responsibilities** – Define stakeholder accountabilities
9. **Assumptions & Constraints** – Note factors that may impact execution
10. **Approvals** – Include a section for stakeholder signatures

## Context
**Project Name:** {{project-name}}  
**Company:** {{company-name}}  
**Industry:** {{industry}}  
**Expected Duration:** {{project-duration}}  
**Key Stakeholders:** {{key-stakeholders}}

## Output
Structure the Project Charter with clear headings for each section listed above. Ensure all content is professional, actionable, and suitable for executive review and sign-off.
```
