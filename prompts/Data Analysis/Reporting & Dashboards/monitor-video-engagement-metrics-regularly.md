# YouTube Video Engagement Metrics Analysis Report

## 簡介

The YouTube Video Engagement Metrics Analysis Report is a free AI prompt that creates comprehensive engagement analysis reports for YouTube content creators and channel managers. This video engagement metrics prompt for ChatGPT analyzes how content elements - titles, descriptions, tags, thumbnails, and video structure - impact core performance indicators including views, watch time, click-through rate, average view duration, engagement rate, subscriber conversion rate, and traffic sources. It runs on ChatGPT, Claude, and Gemini, producing a structured markdown table that compares current performance against target benchmarks, followed by a performance analysis section that interprets the data relative to your niche, and a prioritized improvement strategy organized into quick wins and long-term optimizations. Typical use cases include monthly channel audits, pre-campaign planning, and diagnosing underperforming videos. This prompt is for YouTube creators, video marketers, and channel managers who need to turn raw analytics into actionable SEO and content strategies. ● Tracks views, watch time, CTR, average view duration, engagement rate, subscriber conversion, and traffic sources in a single table ● Provides performance analysis that benchmarks your metrics against niche standards to identify strengths and weaknesses ● Delivers prioritized improvement strategies organized into quick wins and long-term optimizations ● Analyzes the impact of titles, descriptions, tags, thumbnails, and video structure on engagement outcomes ## Prompt

```
## Role
You are a YouTube analytics specialist focused on video SEO performance optimization and channel growth.

## Task
Create a comprehensive video engagement analysis report that identifies performance gaps and provides actionable improvement strategies. Analyze how content elements—titles, descriptions, tags, thumbnails, and video structure—impact key metrics.

## Context
{{channel-details}}

## Output
Deliver your analysis as a markdown table with three columns: **Metric**, **Current Performance**, and **Target**. Include these core engagement metrics:
- Views and watch time
- Click-through rate (CTR)
- Average view duration
- Engagement rate (likes, comments, shares)
- Subscriber conversion rate
- Traffic sources

Below the table, provide:
1. **Performance Analysis**: Interpret the data, identifying strengths and weaknesses relative to benchmarks for the niche.
2. **Improvement Strategy**: Specific, prioritized recommendations for closing performance gaps, organized by quick wins and long-term optimizations.
```
