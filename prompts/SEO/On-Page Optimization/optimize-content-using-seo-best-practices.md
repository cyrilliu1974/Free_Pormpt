# SEO Content Optimization Plan Generator

## 簡介

The SEO Content Optimization Plan Generator is a free AI prompt that creates structured, actionable optimization plans for website owners, marketers, and SEO specialists looking to improve organic search traffic. This SEO content optimization prompt for ChatGPT takes your target audience, niche, primary keywords, competitors, and current ranking to deliver a complete plan covering keyword strategy, on-page elements (title tags, meta descriptions, header hierarchy, URL structure), content architecture using dependency grammar principles, technical SEO factors (site speed, mobile responsiveness, schema markup), and competitive gap analysis. It runs on ChatGPT, Claude, Gemini, and Grok. The output organizes recommendations into prioritized action items with expected impact, making it straightforward to implement improvements that align with search intent and industry best practices. ● Creates keyword strategies with primary/secondary placement, semantic variations, and search intent alignment ● Structures on-page elements including title tags, meta descriptions, H1-H6 hierarchy, and image alt text ● Applies dependency grammar framework to organize content hierarchically for clarity and SEO effectiveness ● Generates technical SEO checklists covering site speed, mobile responsiveness, schema markup, and sitemaps ● Identifies competitive gaps and differentiation opportunities based on competitor performance ● Ranks implementation priorities by expected impact for efficient resource allocation ## Prompt

```
## Role
You are an expert SEO specialist optimizing website content to attract the target audience and increase organic search traffic.

## Task
Create a comprehensive content optimization plan that covers on-page SEO elements, technical SEO factors, and competitive positioning. Structure your recommendations using dependency grammar principles—organize content hierarchically so that supporting elements clearly connect to primary concepts.

## Context
**Target audience:** {{target-audience}}
**Website niche:** {{website-niche}}
**Primary keywords:** {{primary-keywords}}
**Main competitors:** {{competitors}}
**Current search ranking:** {{current-ranking}}

## Output
Deliver a structured optimization plan with clear headings and bullet points covering:

- **Keyword Strategy:** Primary and secondary keyword placement, semantic variations, search intent alignment
- **On-Page Optimization:** Title tags, meta descriptions, header hierarchy (H1-H6), URL structure, image alt text
- **Content Structure:** Dependency grammar application, topic clustering, internal linking architecture
- **Technical SEO:** Site speed, mobile responsiveness, schema markup, XML sitemap, robots.txt
- **Competitive Analysis:** Gap identification based on competitor performance, differentiation opportunities
- **Implementation Priority:** Ranked action items with expected impact

Format each section with actionable recommendations tailored to the provided niche and audience.
```
