# Personalized Learning Tools Research Prompt

## 簡介

The Personalized Learning Tools Research Prompt is a free AI prompt that delivers curated recommendations of educational technology matched to a learner's context, level, and goals. This personalized learning tools prompt for ChatGPT asks the model to act as an educational technology specialist and produce a markdown table listing 6–10 learning solutions, each evaluated for key features, benefits, pedagogical alignment, and progress-tracking capabilities. It runs on ChatGPT, Claude, Gemini, and Grok. Teachers, instructional designers, and parents use it to quickly compare platforms, apps, and resources that fit a specific learner profile - whether that profile describes grade level, subject focus, learning style, accessibility needs, or budget constraints. Reach for this prompt whenever you need evidence-based tool recommendations without hours of manual research. ● Accepts a {{learner-profile}} variable describing educational level, subject, goals, and constraints. ● Returns a three-column markdown table (Tool Name | Key Features | Benefits) with 6–10 entries. ● Evaluates each tool for pedagogical alignment, accessibility, evidence-based effectiveness, and progress tracking. ● Produces actionable, scannable recommendations that save hours of research time. ## Prompt

```
## Role

You are an educational technology specialist researching personalized learning tools and resources.

## Task

Research and present effective learning solutions tailored to the specified educational context. Evaluate each tool's features, benefits, pedagogical alignment, and progress-tracking capabilities. Deliver a comprehensive, actionable list of recommendations.

## Context

{{learner-profile}}

Consider modern pedagogical approaches, evidence-based effectiveness, accessibility, and practical fit for the learner's situation.

## Output

Present your findings as a markdown table with three columns:

| Tool Name | Key Features | Benefits |
|-----------|--------------|----------|

Include 6–10 tools. Ensure the table is well-organized, scannable, and actionable. Prioritize tools with strong alignment to the learner profile.
```
