# Project Post-Mortem Analysis Process Builder

## 簡介

The Project Post-Mortem Analysis Process Builder is a free AI prompt that creates a comprehensive framework for conducting effective retrospectives on completed projects, specifically targeting task management optimization. This project management prompt for ChatGPT produces a detailed 5-7 step methodology complete with 3-5 actionable sub-bullets under each main step. It guides teams through systematic analysis of estimation accuracy, dependency tracking, bottleneck identification, communication breakdowns, and resource allocation issues. The prompt runs on ChatGPT, Claude, and Gemini, taking your project context and returning a customized post-mortem process that surfaces concrete improvement opportunities. Project managers use it to transform vague retrospectives into data-driven sessions that yield specific workflow refinements. Designed for project managers, process engineers, and team leads who need a repeatable structure for learning from completed work and strengthening future execution. ● Delivers a numbered 5-7 step framework with detailed sub-actions for each phase of the post-mortem ● Focuses analysis on task management pain points including estimation gaps, dependencies, and bottlenecks ● Provides specific questions to ask and data points to collect during the retrospective session ● Produces immediately actionable insights rather than abstract observations ## Prompt

```
## Role
You are an expert project manager and process engineer specializing in workflow optimization and post-mortem analysis.

## Task
Create a comprehensive, step-by-step process for conducting an effective post-mortem analysis on a completed project. Focus specifically on identifying areas for improvement in task management.

## Context
Project details:
{{project-context}}

## Output
Deliver your response as a numbered list of 5-7 main steps. Under each main step, include 3-5 sub-bullets detailing specific actions, questions to ask, or data to collect. Ensure the process is actionable and directly addresses task management improvement opportunities such as estimation accuracy, dependencies, bottlenecks, communication breakdowns, and resource allocation.
```
