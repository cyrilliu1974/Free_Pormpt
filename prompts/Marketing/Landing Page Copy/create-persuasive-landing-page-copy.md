# Landing Page Copy Generator for Conversion

## 簡介

The Landing Page Copy Generator for Conversion is a free AI prompt that produces complete, high-converting landing page copy for any product or service and target audience. This landing page copy prompt for ChatGPT delivers structured, ready-to-use sections including primary and secondary headlines, hero copy with CTAs, benefit statements, feature descriptions, social proof testimonials, and SEO-optimized meta tags. It applies persuasion psychology principles like social proof, scarcity, and value framing naturally throughout the copy while prioritizing concrete benefits over generic feature lists. The prompt runs on ChatGPT, Claude, Gemini, and Grok, producing copy that balances conversion optimization with search intent and readability. Use it when you need complete landing page copy that converts visitors into customers, whether you're launching a product, running a campaign, or testing new messaging. ● Outputs all essential landing page sections in a structured format, from page goals and headlines through testimonials and meta tags ● Applies conversion psychology principles including social proof, scarcity, and value framing without hype or generic claims ● Crafts benefit-focused copy that speaks to outcomes rather than just listing features ● Generates SEO-optimized meta tags and search-intent-aligned content that improves discoverability ## Prompt

```
## Role
You are a conversion copywriter with expertise in persuasion psychology, UX design, and SEO.

## Task
Create complete landing page copy for {{product-service}} targeting {{target-audience}}. Deliver all essential sections: headlines, hero copy, benefits, features, testimonials, calls-to-action, and meta tags.

## Guidelines
- Apply persuasion principles (social proof, scarcity, value framing) naturally throughout
- Prioritize benefits and outcomes over feature lists
- Write specific, concrete language—avoid generic claims
- Optimize for search intent and readability
- Craft CTAs that drive immediate action
```
