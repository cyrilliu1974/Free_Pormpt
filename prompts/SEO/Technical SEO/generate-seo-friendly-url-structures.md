# SEO-Friendly URL Structure Generator

## 簡介

The SEO-Friendly URL Structure Generator is a free AI prompt that creates scalable, search-optimized URL architectures for websites and e-commerce platforms. This technical SEO prompt for ChatGPT takes your business context and outputs a complete framework with consistent naming conventions, hierarchical category structures, URL mapping templates for content migration, and implementation guidelines that preserve link equity while improving crawlability. It runs on ChatGPT, Claude, Gemini, and Grok, delivering structured documentation that covers products, categories, filters, pagination, and internationalization patterns. The prompt is built for SEO specialists, web developers, and business owners redesigning site architecture or migrating platforms who need to maintain search visibility while improving user navigation. ● Outputs consistent naming conventions that incorporate target keywords naturally while maintaining readability and user intent alignment. ● Designs hierarchical category taxonomies that map content types to URL paths, improving both crawlability for search engines and navigation for users. ● Provides before-and-after URL mapping templates with redirect strategies to prevent duplicate content and preserve link equity during platform migrations. ● Includes implementation checklists covering special characters, parameters, filters, pagination, seasonal collections, and internationalization requirements. ## Prompt

```
## Role

You are an expert SEO strategist and URL architecture specialist. You optimize site structures for crawlability, user experience, and keyword relevance signals.

## Task

Create a comprehensive SEO-friendly URL structure and mapping framework tailored to the business context provided. Develop consistent naming conventions, hierarchical structures, and scalable URL patterns that accommodate future growth. Include rules for different content types (product pages, category pages, filters, special collections), prevention of duplicate content, link equity preservation during migrations, and clear breadcrumb navigation paths.

## Context

{{business-context}}

The URL structure must reflect both user intent and search behavior, incorporate target keywords naturally while remaining readable, and account for any platform or technical constraints.

## Output

Deliver your framework under these headings:

**URL Structure Framework**  
Overarching principles and hierarchy rules for the site.

**Category Hierarchy**  
Logical taxonomy that maps main categories, subcategories, and content types to URL paths.

**Naming Conventions**  
Consistent rules for slugs, keyword placement, special characters, parameters, filters, pagination, and internationalization.

**URL Mapping Template**  
Before → After examples for products, categories, filters, seasonal collections, promotional pages, and user-generated content. Include redirect strategies to preserve SEO equity.

**Implementation Guidelines**  
Actionable steps, technical best practices, and quality-control checklist for deployment.

Provide specific examples and rules in bullet-point format for maximum clarity.
```
