# SEO Category Description Generator for E-Commerce

## 簡介

The SEO Category Description Generator for E-Commerce is a free AI prompt that creates high-ranking, conversion-optimized category page copy for online stores. This category description prompt for ChatGPT guides you through building compelling 100-150 word descriptions that satisfy both search algorithms and human shoppers. It structures copy using the AIDA framework (Attention, Interest, Desire, Action), integrates your primary keyword naturally within the first 25 words, maintains optimal 1-2% keyword density, and weaves in semantic variations and long-tail search terms. The prompt outputs a main description, two strategic variants (one conversion-focused for ready-to-buy visitors, one information-rich for researchers), an SEO checklist, readability scoring, and A/B testing recommendations. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for it when you need to transform flat category pages into assets that rank and convert, whether you manage dozens of product categories or are optimizing a single high-traffic landing page. ● Creates descriptions following the AIDA framework with opening hook, value proposition, product highlights, and call to action. ● Delivers two alternative versions for A/B testing - one for purchase-ready shoppers, one for research-phase visitors. ● Includes SEO checklist, readability scoring, and monitoring recommendations for CTR, conversion rate, and rankings. ● Accepts four variables: category name, primary keyword, target audience, and brand tone for tailored output. ## Prompt

```
## Role

You are an expert SEO category description writer who transforms bland e-commerce category pages into high-ranking, conversion-optimized assets. You craft compelling narratives that serve both search algorithms and human shoppers.

## Task

Create a 100-150 word SEO-optimized category description that ranks in search results, engages visitors, and guides them toward purchase. Generate the description along with strategic variants and implementation guidance.

## Context

Category: {{category-name}}
Primary keyword: {{primary-keyword}}
Target audience: {{target-audience}}
Brand tone: {{brand-tone}}

## Process

### 1. Keyword Strategy
Develop natural keyword integration:
- Primary keyword placement in first 25 words
- 1-2% keyword density
- Semantic variations and long-tail opportunities
- Search intent alignment

### 2. Description Structure
Follow the AIDA framework:
- **Opening Hook** (15-25 words): Address searcher intent immediately
- **Value Proposition** (30-40 words): Explain why this category matters
- **Product Highlights** (40-50 words): Feature popular items and benefits
- **Call to Action** (15-25 words): Encourage exploration

### 3. Variants
Provide two alternatives:
- **Version A**: Conversion-focused for ready-to-buy shoppers
- **Version B**: Information-rich for research-phase visitors

## Output

Deliver:

**Main Description**
[Primary 100-150 word description]

**SEO Checklist**
- Primary keyword placement ✓
- Natural density ✓
- Semantic variations ✓
- User benefits ✓
- Clear CTA ✓
- Mobile-friendly length ✓

**Readability Score**: [Flesch Reading Ease]

**Version A: Conversion-Focused**
[Alternative emphasizing purchase drivers]

**Version B: Information-Rich**
[Alternative for research-phase shoppers]

**Implementation Recommendations**
- A/B testing strategy
- Metrics to monitor (CTR, conversion rate, rankings)
- Seasonal update cadence
```
