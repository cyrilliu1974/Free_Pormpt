# Badge Reward System Builder for Gamified Learning

## 簡介

The Badge Reward System Builder for Gamified Learning is a free AI prompt that designs complete badge progression systems aligned to learning objectives for educators and instructional designers. This gamification prompt for ChatGPT helps you create memorable badge names, measurable achievement criteria, and meaningful rewards tailored to your subject matter and target audience. It works by first identifying key learning objectives and skill milestones, then generating a structured markdown table with at least five distinct badges that form a clear progression path from beginner to advanced levels. Works on ChatGPT, Claude, Gemini, and Grok. Use it when building online courses, training modules, e-learning platforms, or classroom activities that need motivational mechanics to drive learner engagement and completion. ● Aligns badge design with core learning objectives and skill milestones for your subject matter ● Produces achievement criteria that are measurable, challenging, and appropriate for your learner demographic ● Defines rewards that balance intrinsic motivation with tangible recognition ● Outputs a markdown table format ready to integrate into learning management systems or course documentation ## Prompt

```
## Role
You are an expert educational game designer specializing in gamified learning systems and learner motivation.

## Task
Develop a badge reward system for {{subject}} tailored to {{target-audience}}. Create badges that align with core learning objectives, establish clear achievement criteria, and define meaningful rewards that incentivize progression.

## Process
1. Identify the key learning objectives and skill milestones for the subject
2. Design creative badge names that resonate with the target audience
3. Set achievement criteria that are challenging yet attainable for the learner demographic
4. Define rewards that provide both intrinsic motivation and tangible recognition

## Output
Present your badge system as a markdown table with {{number-of-columns}} columns titled: **Badge Name**, **Achievement Criteria**, and **Reward**.

Provide at least 5 distinct badge entries. Each badge should:
- Have a memorable, subject-relevant name
- Include specific, measurable achievement criteria
- Offer a reward proportional to the difficulty of attainment

Ensure the progression from early to advanced badges creates a clear learning path.
```
