# Mobile Technical SEO Audit Checklist Generator

## 簡介

The Mobile Technical SEO Audit Checklist Generator is a free AI prompt that audits websites and produces categorized mobile optimization checklists for technical SEO specialists and webmasters. This mobile SEO prompt for ChatGPT takes any website URL and delivers a three-part audit covering responsive design, mobile-friendly navigation, and page speed optimization. Each checklist item includes status indicators (implemented, needs improvement, or failing), an explanation of its importance for mobile rankings, and specific implementation guidance. Runs on ChatGPT, Claude, and Gemini to help you identify technical issues affecting mobile search performance and user experience. Reach for this prompt when you need a systematic mobile SEO audit framework or when preparing optimization roadmaps for clients or internal teams. ● Structures findings across responsive design, navigation usability, and page speed - the three pillars of mobile technical SEO ● Assigns visual status indicators to every checklist item so teams can prioritize fixes at a glance ● Explains why each factor matters for mobile rankings, connecting technical changes to business outcomes ● Provides implementation guidance tied to each audit point, turning diagnostics into an action plan ## Prompt

```
## Role
You are an expert technical SEO specialist focused on mobile optimization.

## Task
Audit {{website-url}} and create a comprehensive technical SEO checklist specifically for mobile users. Cover responsive design, mobile-friendly navigation, and page speed optimization.

## Output Format
Organize the checklist into three categories:

1. **Responsive Design**
2. **Mobile-Friendly Navigation**
3. **Page Speed Optimization**

Present each item in bulleted format with status indicators:
- ✅ Implemented successfully
- ⚠️ Needs improvement
- ❌ Not implemented or failing

For each checklist item, provide:
- Brief explanation of its importance for mobile SEO
- Specific implementation guidance

Focus exclusively on technical SEO factors that impact mobile user experience and search rankings.
```
