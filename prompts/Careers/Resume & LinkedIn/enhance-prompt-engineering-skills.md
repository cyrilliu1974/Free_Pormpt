# Resume & Cover Letter Tailoring Guide Generator

## 簡介

The Resume & Cover Letter Tailoring Guide Generator is a free AI prompt that produces industry-specific application optimization resources for job seekers and career coaches. This resume and cover letter customization prompt for ChatGPT, Claude, and Gemini researches hiring practices in your target industry and delivers a structured guide that includes best practices with real-world examples, ready-to-use templates for different role levels, a comparison table showing generic versus tailored application elements, and properly cited references. Career counselors use it to build client-specific toolkits, while job seekers run it to understand what hiring managers in fields like tech, healthcare, or finance actually want to see in application materials. Reach for this prompt when you need to move beyond generic resume advice and create documentation that addresses ATS requirements and industry-specific expectations. ● Creates multiple template variations suited to different seniority levels and specializations within an industry ● Produces side-by-side comparison tables that show exactly how to transform generic statements into compelling, industry-relevant content ● Identifies key best practices with concrete examples that demonstrate effective implementation ● Includes properly formatted citations in your preferred style to support recommendations with credible sources ## Prompt

```
## Role
You are a career development expert specializing in job application optimization, with deep knowledge of industry-specific hiring practices and ATS (Applicant Tracking System) requirements.

## Task
Research and compile a comprehensive guide for tailoring resumes and cover letters to {{industry}} positions. Create actionable resources that demonstrate the difference between generic and customized application materials.

## Output
Deliver the following components:

### 1. Best Practices Analysis
Identify {{number-of-practices}} key best practices for customizing application materials in {{industry}}. For each practice:
- Provide a concise explanation of why it matters
- Include {{examples-per-practice}} real-world examples showing effective implementation

### 2. Templates
Create resume and cover letter templates that embody these best practices, with {{template-variations}} variations tailored to different role levels or specializations within {{industry}}.

### 3. Comparison Table
Develop a side-by-side comparison with three columns:
- Generic application element
- Industry-tailored version
- Explanation of the transformation and its impact on hiring outcomes

Include enough rows to cover the most critical application components.

### 4. References
Cite all sources in {{citation-style}} format.

## Format
Use clear markdown structure with headings, bullet points, and tables. Present all content directly without meta-commentary.
```
