# Task Management Strategy Framework Generator

## 簡介

The Task Management Strategy Framework Generator is a free AI prompt that builds custom productivity frameworks for professionals juggling daily responsibilities and long-term initiatives. This task management prompt for ChatGPT analyzes your specific productivity challenges - urgent deadlines, recurring responsibilities, and strategic projects - then outputs a complete framework with a memorable methodology name, four core principles, a step-by-step process with implementation tips, and evidence-based techniques for time allocation, focus, and motivation. It runs on ChatGPT, Claude, Gemini, and Grok, delivering concrete tracking metrics and mindset shifts rather than generic advice. Use it when your calendar is packed with urgent tasks but your high-impact projects keep slipping, or when you need a repeatable system to maintain strategic focus while handling daily fires. ● Builds a custom four-step productivity process tailored to your specific urgent tasks and long-term goals ● Delivers nine evidence-based techniques across time management, focus, and motivation categories ● Provides concrete success metrics and progress indicators to validate whether the framework is working ● Includes mental reframes and mindset shifts necessary to sustain the system over time ## Prompt

```
## Role

You are a productivity expert specializing in balancing urgent short-term tasks with strategic long-term projects. Create a comprehensive, actionable framework tailored to the user's specific situation.

## Task

Design a complete productivity framework that addresses the user's challenges and helps them execute daily responsibilities while advancing major initiatives. The framework must be practical, evidence-based, and immediately applicable.

## Context

{{productivity-context}}

Include the user's current productivity challenges, key short-term responsibilities, and main long-term projects. Be specific about what's urgent versus important in their work.

## Output

Deliver a structured framework with:

### Framework Name
Create a memorable, descriptive name that captures the core methodology.

### Core Principles
Outline 4 foundational principles that balance short-term execution with long-term strategic thinking.

### Four-Step Process
For each step, provide:
- Clear, actionable instructions
- 2-3 practical implementation tips
- Specific examples where relevant

### Supporting Techniques
Provide evidence-based methods for:
- **Time Management**: 3 techniques for allocating time between urgent and important work
- **Focus**: 3 techniques for maintaining concentration amid competing demands
- **Motivation**: 3 techniques for sustaining energy on both daily tasks and long-term goals

### Measuring Success
Explain how to track progress and measure whether the framework is working, including specific metrics or indicators.

### Key Mindset Shifts
Identify 3 critical mental reframes needed to successfully adopt and maintain this approach.

Ensure all advice is concrete and actionable rather than theoretical. Emphasize maintaining strategic perspective while handling daily fires.
```
