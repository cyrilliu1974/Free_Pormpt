# Canonical Tag Implementation Plan for E-Commerce SEO

## 簡介

The Canonical Tag Implementation Plan for E-Commerce SEO is a free AI prompt that builds a comprehensive strategy to eliminate duplicate content issues and optimize search engine crawling for online stores. This canonical tag implementation prompt for ChatGPT guides you through identifying duplicate content patterns across product variations, category pages, filters, and pagination, then structures a prioritized plan for placing canonical tags correctly throughout your e-commerce site. It runs on ChatGPT, Claude, Gemini, and Grok, delivering a hierarchical implementation roadmap that shows which steps depend on others using dependency grammar principles. Use it when launching a new store, migrating platforms, experiencing indexing problems, or auditing existing canonical tag configurations that may be causing SEO penalties. ● Audits and identifies duplicate content patterns across product pages, category views, pagination, sorting parameters, and session URLs ● Maps canonical tag placement strategy for each page type with clear dependency relationships between implementation phases ● Provides platform-appropriate technical implementation guidance with validation procedures and testing methods ● Includes monitoring framework to measure crawl budget optimization, indexing improvements, and search visibility impact ## Prompt

```
## Role

You are an expert SEO specialist designing a canonical tag implementation strategy for e-commerce websites.

## Task

Create a comprehensive, step-by-step plan to implement canonical tags that prevents duplicate content issues and improves search engine crawling and indexing. Structure your response using dependency grammar principles to show how each implementation step builds on or depends on others.

## Context

Website and platform context:
{{website-and-platform}}

Key details:
{{seo-context}}

Consider:
- Page hierarchy and URL structure patterns common to e-commerce sites
- Product variation relationships (size, color, pagination, sorting, filters)
- Crawl budget optimization and indexing priorities
- Testing and validation methods
- Performance measurement and impact tracking

## Output

Deliver your implementation plan as a hierarchical bullet point list where:
- Top-level bullets represent major implementation phases
- Nested sub-bullets show dependent steps or related considerations
- The dependency relationships make clear which steps must precede others and why

Include:
1. Duplicate content audit and identification methods
2. Canonical tag placement strategy for product pages, category pages, pagination, filters, and session parameters
3. Technical implementation approach appropriate for the platform
4. Quality assurance and validation procedures
5. Monitoring and measurement framework to track SEO impact
```
