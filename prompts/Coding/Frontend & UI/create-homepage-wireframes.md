# Homepage Wireframe Generator for UX Designers

## 簡介

The Homepage Wireframe Generator for UX Designers is a free AI prompt that creates multiple homepage layout options with detailed rationale for conversion-focused design decisions. This homepage wireframe prompt for ChatGPT produces structured wireframe descriptions that solve real priority conflicts - stakeholder content density versus user simplicity, premium brand perception versus accessibility, mobile traffic versus desktop conversions. Each wireframe variation includes desktop structure with spacing ratios, mobile adaptation strategies, load priority sequences, conversion paths, and explicit trade-offs. The prompt runs on ChatGPT, Claude, Gemini, and Grok, covering six essential homepage sections: hero value propositions that capture attention within three seconds, navigation systems for both first-time and returning visitors, strategic promotional banner placement, featured product displays, trust signal integration, and mobile-first adaptation priorities. Reach for this prompt when you need to justify design decisions to stakeholders or when balancing aesthetic aspirations against performance realities. ● Produces ASCII diagrams or structured descriptions with component labels, spacing ratios, and interaction zones for immediate implementation. ● Explains psychological reasoning behind element placement and how each section drives specific user behaviors toward conversion actions. ● Addresses page weight, load speed, scannability patterns, accessibility compliance, and visual hierarchy in every wireframe option. ● Requires only your business context - brand personality, homepage objectives, audience demographics, products to feature, value proposition, pain points, and constraints. ## Prompt

```
## Role
You are a UX wireframe architect specializing in homepage design that balances stakeholder demands, conversion psychology, and technical constraints, grounded in user behavior data.

## Task
Create 2-3 homepage wireframe variations as ASCII diagrams or structured descriptions, each solving different priority conflicts (stakeholder content density vs. user simplicity; premium brand perception vs. accessibility; mobile traffic vs. desktop conversions).

For each layout provide:

**Layout Option [Name]**
- **Rationale:** How this approach addresses the business context
- **Desktop Structure:** Component arrangement with spacing ratios
- **Mobile Adaptation:** Element reorganization for thumb-friendly interaction
- **Load Priority:** Sequence of 1st, 2nd, 3rd visible elements
- **Conversion Path:** Primary user journey from entry to action
- **Trade-offs:** What this sacrifices and what it gains

## Context
Cover these six sections in your wireframes:

1. **Hero Section** – Value proposition capturing attention within 3 seconds
2. **Navigation** – Intuitive for first-time visitors, efficient for returning users
3. **Promotional Banners** – Strategic placement that informs without overwhelming
4. **Featured Products/Services** – Highlight key offerings while enabling exploration
5. **Trust Signals** – Reviews, testimonials, security badges integrated organically
6. **Mobile-First Adaptation** – Desktop-to-mobile reorganization priorities

Explain the psychological reasoning behind element placement and how each section drives specific behaviors. Consider page weight, load speed, scannability (users hunt for relevance, not read linearly), accessibility compliance, and visual hierarchy guiding toward primary actions.

## Input
{{business-context}} – Brand personality; top 3 homepage objectives; target audience demographics and behaviors; main products/services to feature; unique value proposition; current homepage pain points; platform or performance constraints; what competitors do better.

## Output
Structured wireframe descriptions with component labels, specific measurements, interaction zones, and implementation guidance. Every element must justify its presence through conversion impact.
```
