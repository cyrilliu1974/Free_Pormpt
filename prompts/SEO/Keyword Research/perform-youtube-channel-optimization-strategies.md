# YouTube Channel SEO Optimization Strategy Prompt

## 簡介

The YouTube Channel SEO Optimization Strategy Prompt is a free AI prompt that creates detailed, actionable SEO implementation plans for YouTube content creators and digital marketers. This YouTube SEO prompt for ChatGPT produces a structured guide covering six core areas: keyword research with search volume analysis, video title optimization using dependency grammar principles, description formatting with strategic keyword placement, tag hierarchy and selection, algorithm signals like watch time and engagement, and performance testing recommendations. The prompt applies dependency grammar framework to organize metadata - treating primary keywords as root elements and supporting terms as modifiers - ensuring clarity and search efficiency. It runs reliably on ChatGPT, Claude, Gemini, and Grok, adapting to your specific video topic, target audience, and existing channel context. Reach for this prompt when you need to improve video discoverability, plan metadata for new uploads, or audit an existing channel's SEO structure. ● Identifies primary and secondary keywords with competition and search volume analysis tailored to your video topic ● Structures video titles, descriptions, and tags using dependency grammar to clarify hierarchical keyword relationships ● Provides actionable recommendations for thumbnail alignment, engagement metrics, and watch-time optimization ● Includes A/B testing strategies and analytics monitoring priorities for iterative performance improvement ## Prompt

```
## Role
You are an expert YouTube SEO specialist optimizing channels for visibility and engagement.

## Task
Create a comprehensive, step-by-step guide to implement SEO best practices for the specified video topic. Use dependency grammar principles to structure all recommendations—prioritize main keywords as root elements with supporting terms as modifiers, ensuring clear hierarchical relationships in titles, descriptions, and tags.

## Context
Video topic: {{video-topic}}
Target audience: {{target-audience}}
Channel details: {{channel-context}}

## Output
Provide a numbered list with clear subheadings covering:

1. **Keyword Research**
   - Primary and secondary keyword identification
   - Search volume vs. competition analysis
   - Dependency grammar application (core terms → modifiers)

2. **Video Title Optimization**
   - Optimal length (50-60 characters)
   - Keyword placement using dependency hierarchy
   - Click-through rate optimization techniques

3. **Description Formatting**
   - First 150 characters strategy
   - Keyword density and natural placement
   - Timestamp, link, and CTA positioning

4. **Tag Selection Strategy**
   - Tag hierarchy (broad → specific)
   - Quantity and relevance balance
   - Competitor tag analysis

5. **Algorithm Leveraging**
   - Watch time and retention signals
   - Engagement metrics optimization
   - Thumbnail and metadata alignment

6. **Performance Enhancement**
   - A/B testing recommendations
   - Analytics monitoring priorities
   - Iterative optimization based on channel metrics

For each section, provide actionable instructions tailored to the video topic and audience.
```
