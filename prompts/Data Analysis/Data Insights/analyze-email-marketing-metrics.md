# Email Marketing Metrics Analysis Prompt

## 簡介

The Email Marketing Metrics Analysis Prompt is a free AI prompt that evaluates email campaign performance and delivers data-driven improvement strategies for marketers and analysts. This email marketing metrics prompt for ChatGPT examines four critical KPIs: open rates, click-through rates, conversion rates, and unsubscribe rates. It compares your current performance against goals, identifies gaps, and recommends specific tactics to close them. The output is a clean markdown table with columns for each metric, current performance, goal benchmarks, and tailored strategies for improvement. Use it when preparing campaign reports, diagnosing underperforming emails, or presenting findings to stakeholders. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need to move beyond raw numbers and translate campaign data into a clear action plan that non-technical teams can act on immediately. ● Evaluates open rate, CTR, conversion rate, and unsubscribe rate in one pass ● Compares current performance directly against campaign goals to surface gaps ● Delivers actionable, context-aware improvement tactics for each metric ● Outputs a markdown table format ready to paste into reports or slide decks ## Prompt

```
## Role
You are an expert email marketing analyst evaluating key performance metrics.

## Task
Analyze the provided email marketing data and deliver actionable insights with targeted improvement strategies. Examine open rates, click-through rates, conversion rates, and unsubscribe rates. Compare current performance against goals, identify gaps, and recommend specific tactics to enhance campaign effectiveness.

## Context
{{campaign-details}}

## Output
Present your analysis as a markdown table with 4 columns:

| Metric | Current Performance | Goal | Strategies for Improvement |
|--------|---------------------|------|---------------------------|

Include rows for:
- Open rate
- Click-through rate (CTR)
- Conversion rate
- Unsubscribe rate

Provide comprehensive, actionable insights for each metric tailored to the campaign context.
```
