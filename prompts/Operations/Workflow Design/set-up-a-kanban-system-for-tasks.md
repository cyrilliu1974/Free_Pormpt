# Kanban Board Setup Guide for Task Management

## 簡介

The Kanban Board Setup Guide for Task Management is a free AI prompt that creates a customized, step-by-step Kanban implementation plan for teams and solo practitioners looking to streamline their workflow. This Kanban system prompt for ChatGPT produces an eight-part implementation guide covering board structure, column usage, work-in-progress limits, task movement rules, prioritization methods, review schedules, bottleneck identification, and efficiency metrics. You supply your project context - team size, complexity, tools in use - and the prompt adapts every instruction accordingly. It runs on ChatGPT, Claude, Gemini, and Grok. Real use cases include software development teams adopting agile workflows, marketing departments coordinating campaign launches, and operations managers tracking cross-functional initiatives. Reach for this prompt when you need more than a generic Kanban tutorial: you want actionable guidance that fits your team's dynamics and existing tooling. ● Defines a four-column board structure with clear purpose statements for Backlog, To Do, In Progress, and Done. ● Establishes team-appropriate work-in-progress limits to prevent overload and maintain flow. ● Provides task movement rules, prioritization frameworks, and review cadences tailored to your project context. ● Includes techniques for spotting bottlenecks and tracking efficiency metrics over time. ## Prompt

```
## Role
You are an expert project manager specializing in Kanban systems for task management.

## Task
Create a structured, step-by-step guide to implement a Kanban board that optimizes productivity and workflow. Cover setup, usage, and continuous improvement.

## Context
{{project-context}}

Adapt your guidance to this environment, considering team dynamics, project complexity, and existing tool capabilities.

## Output
Deliver your implementation guide as a numbered list with clear headings for each major step:

1. **Board Structure Setup** - Define the four core columns (Backlog, To Do, In Progress, Done) and their purpose
2. **Column Usage Guidelines** - Detailed instructions for effectively using each column
3. **Work-in-Progress (WIP) Limits** - How to establish and enforce WIP limits appropriate to the team
4. **Task Movement System** - Rules and triggers for moving tasks between columns
5. **Prioritization Framework** - Methods for ranking and selecting tasks
6. **Review Cadence** - Schedule and structure for regular board reviews
7. **Bottleneck Identification** - Techniques to spot and resolve workflow constraints
8. **Efficiency Metrics** - Key indicators to track and improve over time

Ensure each step includes actionable instructions tailored to the specified context.
```
