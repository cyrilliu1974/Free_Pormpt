# Lead Capture Form Blueprint Builder

## 簡介

The Lead Capture Form Blueprint Builder is a free AI prompt that designs high-converting lead capture forms for businesses seeking to maximize conversion rates while minimizing user friction. This lead capture form prompt for ChatGPT creates detailed form blueprints that specify field types, logical sequencing, call-to-action copy, and mobile-first design guidelines. It applies progressive disclosure principles - revealing fields in dependency order to reduce cognitive load - and incorporates psychological triggers like reciprocity and social proof. The prompt runs on ChatGPT, Claude, Gemini, and Grok, delivering structured recommendations organized by form sections, CTA strategy, and A/B testing priorities. Use it when launching new products, building landing pages, or redesigning lead generation flows to balance information capture with user experience. ● Sequences form fields using progressive disclosure to guide users naturally from one input to the next ● Provides rationale for each field's inclusion, format, and placement tied to conversion psychology ● Generates primary and secondary CTA copy with wording explanations aligned to your business context ● Delivers mobile-first design specifications, visual hierarchy guidelines, and prioritized A/B testing recommendations ## Prompt

```
## Role
You are an expert lead generation strategist specializing in conversion-optimized form design.

## Task
Create a comprehensive lead capture form blueprint that maximizes conversion rates. Design the form structure, field sequence, and calls-to-action using progressive disclosure principles that reduce cognitive load and guide users naturally from one field to the next.

## Context
Business context: {{business-context}}

Apply established UX principles:
- Progressive disclosure: reveal fields in logical dependency order
- Psychological triggers: reciprocity, social proof, urgency where appropriate
- Friction reduction: minimize required fields, use smart defaults, provide clear value exchange
- Mobile-first design considerations

## Output
Provide your lead capture form blueprint as a bullet-point list organized by:

**Form Sections & Elements**
- Field type, label, and placement
- Rationale for inclusion and ordering (explain how each field builds on or depends on previous context)
- Input format specifications (dropdown, text, checkbox, etc.)

**Call-to-Action Strategy**
- Primary CTA copy and placement
- Secondary CTAs if applicable
- Wording rationale tied to the conversion goal

**Design & Optimization Recommendations**
- Visual hierarchy and spacing guidelines
- Mobile responsiveness requirements
- A/B testing priorities (which elements to test first and why)
- Performance benchmarks to track

Balance information capture with user experience—request only what's essential for the stated conversion goal, and explain the value users receive in exchange for their information.
```
