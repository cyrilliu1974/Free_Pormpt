# Document Management System Design Prompt

## 簡介

The Document Management System Design Prompt is a free AI prompt that creates comprehensive DMS implementation plans for organizations seeking to streamline document workflows and collaboration. This document management system prompt for ChatGPT walks through system architecture, end-to-end document handling workflows, security and access controls, collaboration features with version control, search and retrieval mechanisms, and standard operating procedures for daily use. It runs on ChatGPT, Claude, Gemini, and Grok, taking three variables - your organization context, current challenges, and required features - and producing structured documentation with clear headings, actionable procedures, and technical specifications. Teams use it to design custom DMS solutions that address specific pain points like slow retrieval, poor version control, or inadequate security. Reach for this prompt when you need to architect a document management system from the ground up or redesign an existing setup that no longer meets your team's needs. ● Produces system architecture blueprints with key components, integrations, and technical specifications ● Maps end-to-end workflows from document creation and approval through archival and disposal ● Details security measures including role-based access controls, encryption, and audit logging ● Defines collaboration features such as real-time editing, version control, and review workflows ● Specifies search and retrieval mechanisms with metadata tagging, full-text indexing, and filter options ● Delivers standard operating procedures written in clear, actionable language for team adoption ## Prompt

```
## Role
You are an expert document management system (DMS) architect designing a comprehensive solution tailored to the user's organization.

## Task
Create a complete DMS implementation plan that streamlines document organization, enhances collaboration, and enables efficient retrieval. Cover:

- System architecture and key components
- End-to-end document handling workflows
- Security measures and access controls
- Collaboration features and version control
- Search and retrieval mechanisms
- Standard operating procedures for daily use

## Context
Organization context: {{organization-context}}

Current challenges: {{current-challenges}}

Required features: {{required-features}}

## Output
Deliver the implementation plan as structured documentation with:

- Clear main headings for each system area
- Subheadings that break down components and processes
- Bullet points for specifications, steps, and requirements
- Actionable procedures written with clear subject-verb-object structure
- Technical diagrams or flowchart descriptions where helpful

Organize content logically from system overview through implementation details to operational procedures.
```
