# Ghostwriting Rate Negotiation Framework Generator

## 簡介

The Ghostwriting Rate Negotiation Framework Generator is a free AI prompt that creates structured compensation proposals for writing projects by analyzing scope, writer credentials, and budget constraints. This ghostwriting rate negotiation prompt for ChatGPT takes your project details - including deliverables, complexity, writer experience, and timeline - and produces a three-column markdown table mapping project requirements to writer qualifications and corresponding rate tiers. Each proposed rate includes payment structure recommendations (per-word, per-hour, or flat fee) alongside 2-3 sentence justifications that explain how the compensation reflects both project demands and the writer's expertise level. Freelance writers, content agencies, and clients hiring ghostwriters use it to establish transparent, defensible pricing before entering negotiations. Reach for this prompt when you need to formalize rate discussions for articles, books, whitepapers, or any ghostwriting engagement where fair compensation must align with quality expectations and experience. ● Outputs a structured markdown table with project details, writer qualifications, and tiered rate proposals ● Includes payment structure guidance (per-word, per-hour, flat-fee) matched to project type ● Provides written justifications for each rate tier that reference both complexity and experience ● Supports transparent negotiation by linking compensation directly to deliverables and credentials ## Prompt

```
## Role
You are an expert negotiator specializing in writing project rate discussions.

## Task
Create a structured negotiation framework that balances project requirements with writer expertise. Analyze the project scope and writer qualifications, then develop a comprehensive rate proposal table that ensures fair compensation while maintaining quality standards.

## Context
**Project & Writer Details:**
{{project-details}}

Include: type of writing project, scope (word count, deliverables, complexity), writer's experience level and relevant credentials, available budget range (if any), and timeline/deadlines.

## Output
Present your analysis as a markdown table with three columns:

| Project Details | Writer's Experience | Proposed Rates |
|-----------------|--------------------|-----------------|

For each rate tier or milestone:
- **Project Details column:** Specify the deliverable, complexity, or phase
- **Writer's Experience column:** Note the relevant qualifications that justify the rate
- **Proposed Rates column:** State the recommended compensation with payment structure (per word/hour/project)

After the table, provide a 2-3 sentence justification for each proposed rate tier, explaining how it reflects both the project requirements and the writer's expertise level.
```
