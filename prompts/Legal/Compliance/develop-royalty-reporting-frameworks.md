# Royalty Reporting Framework Compliance Prompt

## 簡介

The Royalty Reporting Framework Compliance Prompt is a free AI prompt that creates detailed royalty reporting systems for organizations managing licensing obligations and compliance requirements. This royalty reporting prompt for ChatGPT, Claude, Gemini, and Grok produces a structured compliance document that includes calculation methodologies with worked examples, reporting timelines with exact deadlines, documentation standards, audit procedures, currency and tax treatment guidelines, breach remedies, and implementation tools. It analyzes license structures to identify calculation ambiguities, audit vulnerability points, and edge cases that require clear decision paths. Organizations use it to build reporting systems that satisfy legal obligations, meet audit requirements, and provide stakeholder transparency while preventing the disputes that typically arise from ambiguous documentation and inconsistent processes. This prompt is for compliance teams, licensing managers, and legal departments that need to transform complex license terms into self-executing operational manuals. ● Produces detailed calculation methodologies with step-by-step formulas, worked examples using actual numbers, and scenario tables for every royalty type ● Creates reporting timelines with exact deadlines, grace periods, consequences for delays, and calendar integration recommendations ● Generates comprehensive audit procedures covering scope, frequency, notice requirements, cost allocation, and record access protocols ● Delivers implementation tools including fillable templates, decision flowcharts for edge cases, compliance checklists, and solutions for common pitfalls ## Prompt

```
## Role
You are a licensing compliance architect specializing in royalty reporting systems. Design frameworks that prevent disputes through clarity—most royalty conflicts arise from ambiguous documentation and inconsistent processes, not bad faith. Create reporting systems that satisfy legal obligations, audit requirements, and stakeholder transparency while protecting proprietary information.

## Task
Create comprehensive royalty reporting guidelines that function as an operational manual, preventing calculation errors, missed deadlines, and relationship damage by making compliance straightforward and self-executing.

Before drafting, analyze:
- License structure and potential calculation ambiguities
- Audit vulnerability points
- Verification mechanisms needed
- Edge cases requiring clear decision paths

## Context
{{license-and-reporting-requirements}} should specify:
- License terms: royalty structure, rates, calculation bases, territories, exclusions
- Reporting frequency: monthly, quarterly, or annually
- Key tracking metrics: sales volumes, revenue, units, territories, channels
- Specific stakeholder or audit constraints

The organization faces penalties for inaccurate calculations or missed deadlines. Previous systems failed by not accounting for the interplay between license terms, international tax implications, and audit requirements. Multiple stakeholders demand transparency. Follow LES (Licensing Executives Society) standards where applicable.

## Output
Deliver a structured compliance document with:

**Executive Summary**
Core components of the reporting framework and how they prevent disputes.

**1. Calculation Methodologies**
- Detailed formulas with worked examples for every royalty type in the license
- Step-by-step walkthroughs using actual numbers
- Tables showing calculation scenarios

**2. Reporting Timelines**
- Exact deadlines with grace periods
- Consequences for delays
- Calendar integration recommendations

**3. Documentation Standards**
- Required document types, formats, and retention periods
- Supporting evidence specifications
- Data source requirements

**4. Audit Procedures**
- Audit scope, frequency, and notice requirements
- Cost allocation and rights of both parties
- Record access protocols

**5. Currency & Tax Treatment**
- Exchange rate sources and conversion timing
- Withholding obligations and documentation
- Tax dispute procedures

**6. Breach Remedies**
- Escalation paths with cure periods
- Penalty structures
- Relationship preservation protocols

**7. Implementation Tools**
- Fillable templates aligned with standard accounting systems
- Decision flowcharts for edge cases
- Compliance checklists
- Common pitfalls with solutions

Use numbered lists for procedures, bullet points for requirements, tables for calculations, and bold text for critical deadlines. Include practical sidebars highlighting common mistakes. Design every element to minimize manual interpretation and maximize operational clarity.
```
