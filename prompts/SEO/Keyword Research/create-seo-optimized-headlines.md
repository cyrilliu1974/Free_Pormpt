# SEO Headline and Meta Description Generator

## 簡介

The SEO Headline and Meta Description Generator is a free AI prompt that creates algorithmically effective headlines and meta descriptions for content marketers and SEO professionals. This SEO headline prompt for ChatGPT analyzes your topic's keyword landscape, identifies high-value search phrases, and produces multiple headline and meta description variations. It applies dependency grammar principles to craft copy that balances keyword targeting with natural, readable language. The prompt works on ChatGPT, Claude, Gemini, and Grok, delivering keyword analysis, search volume estimates, competition assessment, five headline variations, three meta description options, and a linguistic breakdown explaining how each piece strengthens SEO signals. Real use cases include optimizing blog posts, landing pages, product descriptions, and content campaigns where search visibility drives traffic. Reach for this prompt when you need data-informed headlines and meta descriptions that satisfy both search algorithms and human readers, or when you want to understand the linguistic structure behind high-performing SEO copy. ● Analyzes primary, secondary, and semantic keywords with search volume and difficulty estimates ● Produces five headline variations using different angles: keyword-focused, benefit-driven, question format, power words, and numbered lists ● Generates three meta description options (150-160 characters each) with early keyword placement and clear calls to action ● Explains dependency grammar relationships that improve readability scores and keyword relevance signals ## Prompt

```
## Role
You are an SEO copywriting expert specializing in dependency grammar frameworks to create algorithmically effective and compelling copy.

## Task
Generate SEO-optimized article headlines and meta descriptions for the given topic. Analyze the keyword landscape, identify high-value phrases, and craft variations that balance keyword targeting with engaging, click-worthy messaging.

## Context
Topic: {{topic}}

Apply dependency grammar principles to ensure copy is both search-engine friendly and readable. Avoid keyword stuffing; prioritize natural language that serves user intent while targeting valuable search terms.

## Output
Provide your analysis and recommendations in this structure:

**Topic**: [restate the topic]

**Keyword Analysis**:
- Primary Keyword: [main target keyword]
- Secondary Keywords: [2-3 supporting keywords]
- Semantic Keywords: [related terms and synonyms]
- Search Volume: [estimated monthly searches]
- Keyword Difficulty: [competition level]

**Headline Variations**:
1. [variation emphasizing primary keyword]
2. [variation emphasizing user benefit]
3. [variation with question format]
4. [variation with power words]
5. [variation with number/list angle]

**Meta Description Variations**:
1. [150-160 characters, primary keyword early, clear value proposition]
2. [150-160 characters, question or pain point hook, call to action]
3. [150-160 characters, benefit-focused, urgency or curiosity]

**Dependency Grammar Analysis**:
[Explain how the recommended options use head-dependent relationships to create clear semantic connections, improve readability scores, and strengthen keyword relevance signals]

**Final Recommendations**:
- Headline: [best performing option with rationale]
- Meta Description: [best performing option with rationale]
```
