# Virtual Community Event Planner Prompt

## 簡介

The Virtual Community Event Planner Prompt is a free AI prompt that creates structured plans for virtual meetups and workshops designed to build and strengthen online communities. This community event planning prompt for ChatGPT takes your target audience, event goals, and community details and produces a nine-section plan covering event overview, audience analysis, format recommendations (platform choice, session structure, interactive elements), content topics, speaker profiles, promotion strategy, and success metrics. It runs on ChatGPT, Claude, Gemini, and Grok, delivering actionable plans for virtual events that foster genuine engagement. Community managers use it to design workshops, panels, and meetups that address audience pain points while maximizing interaction through polls, breakout rooms, and Q&A sessions. Reach for this prompt when you need to transform event ideas into execution-ready plans that balance structure with community-building elements. ● Delivers audience analysis with demographics, interests, and pain points to inform every planning decision ● Recommends platform choices, session structures, and interactive elements (polls, breakouts, Q&A) suited to your event type ● Provides pre-event, during-event, and post-event promotion and engagement tactics to maximize participation ● Includes measurable success metrics aligned with your community-building goals ## Prompt

```
## Role
You are an expert community manager and event planner specializing in virtual events that foster engagement and strengthen online communities.

## Task
Create a comprehensive plan for a virtual meetup or workshop that builds and strengthens an online community.

## Context
Use the following information to tailor the plan:

**Target Audience:** {{target-audience}}

**Event Goals:** {{event-goals}}

**Event & Community Details:** {{event-details}}

## Output
Deliver a structured event plan with these sections:

### 1. Event Overview
- Event Name
- Event Type (workshop, meetup, panel, etc.)
- Duration
- Proposed Date and Time

### 2. Target Audience Analysis
- Demographics
- Interests
- Pain Points

### 3. Event Goals
- Primary Goal
- Secondary Goal
- Tertiary Goal

### 4. Event Format
- Recommended Platform (Zoom, Discord, etc.)
- Session Structure
- Interactive Elements (polls, breakouts, Q&A, etc.)

### 5. Content Plan
- Topic 1 with brief description
- Topic 2 with brief description
- Topic 3 with brief description

### 6. Speakers and Moderators
- Suggested Speaker 1 profile
- Suggested Speaker 2 profile
- Moderator profile

### 7. Promotion Strategy
- Pre-event Promotion tactics
- During-event Engagement tactics
- Post-event Follow-up tactics

### 8. Success Metrics
- Measurable Metric 1
- Measurable Metric 2
- Measurable Metric 3

### 9. Key Takeaways
Summarize the most important elements that will drive community engagement and growth.

Tailor all recommendations to the specific audience demographics, interests, and pain points. Ensure the format maximizes interaction and the content delivers genuine value.
```
