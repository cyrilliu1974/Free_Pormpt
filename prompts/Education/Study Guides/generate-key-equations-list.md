# Key Equations Reference Table Generator

## 簡介

The Key Equations Reference Table Generator is a free AI prompt that creates comprehensive equation reference tables for any mathematical or scientific subject. This key equations prompt for ChatGPT produces a three-column markdown table listing 5-8 critical formulas, each with its purpose and a concrete example showing when and how to apply it in practice. The prompt works across ChatGPT, Claude, Gemini, and Grok, ensuring proper LaTeX or plain notation formatting, accessible explanations for learners, and logical organization by topic area or complexity. Students use it to build study guides for exams, educators create handouts for courses, and professionals compile quick-reference sheets for disciplines ranging from physics and chemistry to engineering and finance. Reach for this prompt when you need a curated, well-explained collection of the most important formulas in a domain, rather than an overwhelming list without context. ● Produces accurate, properly formatted equations in LaTeX or plain notation with quality control built into the instructions ● Pairs every formula with both a concise purpose statement and a specific real-world application scenario ● Organizes equations logically by topic area, complexity level, or practical workflow to support learning progression ● Includes contextual introduction and summary sections that explain why these formulas matter and encourage hands-on practice ## Prompt

```
## Role
You are an expert in mathematical and scientific equations across disciplines, able to identify the most important formulas for any subject and explain their purpose and application clearly.

## Task
Generate a comprehensive reference table of key equations and formulas for {{subject-or-topic}}. For each equation, provide its purpose and a concrete example of when and how to use it in practice.

## Context
Begin with a brief introduction explaining why equations and formulas are fundamental to understanding {{subject-or-topic}}. Focus on the most widely used and important formulas that practitioners and students need to know.

## Output
Present the information as a markdown table with three columns:

| Equation/Formula | Purpose | Example Application |
|------------------|---------|---------------------|
| [formula in LaTeX or plain notation] | [concise explanation of what it calculates or represents] | [specific real-world scenario showing how to apply it] |

**Requirements:**
- Ensure all equations are accurate and properly formatted
- Write explanations that are accessible to learners with basic background knowledge
- Choose examples that demonstrate practical, real-world applications
- Organize formulas logically (by topic area, complexity, or workflow)
- Include at least 5-8 key equations, more if the subject warrants

Conclude with a brief summary of the most critical takeaways and encourage hands-on practice with these formulas to build fluency.
```
