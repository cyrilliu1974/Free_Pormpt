# Goal Tracking App Builder Prompt for React and TypeScript

## 簡介

The Goal Tracking App Builder Prompt for React and TypeScript is a free AI prompt that generates complete, production-ready goal tracking web applications with gamification psychology and habit-forming design for developers and product teams. This goal tracking app prompt for ChatGPT, Claude, and Cursor produces full-stack React code organized into seven functional modules: conversational onboarding wizards, animated dashboards, streak and achievement systems, mood-aware check-ins, visual growth metaphors (gardens, cities, or constellations), and performance-optimized UI with Tailwind CSS and Framer Motion. The output includes TypeScript type definitions, state management, routing, accessibility features, and mobile-responsive layouts. Use it when you need to build consumer applications that users open daily by choice, not obligation, or when transforming traditional productivity tools into emotionally engaging experiences. ● Outputs conversational goal-creation flows with personality-driven copy and micro-interactions that feel human ● Includes celebration engines with streak tracking, badge unlocks, confetti animations, and contextual encouragement messages ● Generates visual growth metaphors that evolve as users progress, creating emotional attachment and long-term retention ● Provides accessibility-compliant code with ARIA labels, keyboard navigation, smooth animations, and mobile-first responsive design ## Prompt

```
## Role

You are an expert product designer and full-stack developer specializing in high-retention consumer applications that combine gamification psychology, behavioral design, and technical excellence.

## Task

Build a complete goal tracking web application that transforms progress monitoring into an engaging, joyful experience. The app must retain users through strategic gamification, personality-driven interactions, conversational flows, animated feedback, and visual growth metaphors that make users want to return daily.

## Context

{{technical-stack}} specifies your frameworks, libraries, styling approach, and tooling constraints.

{{design-direction}} covers visual style, color schemes, UI patterns, and aesthetic preferences.

{{user-profile}} describes target demographics (age, lifestyle, tech comfort) and preferred motivational mechanics (reward types, achievement systems, engagement hooks).

## Output

Provide production-ready React code with TypeScript, organized into these sections:

**Foundation & Technical Architecture**  
Project setup, folder structure, core data models, state management, and routing.

**Conversational Goal Creation**  
Multi-step wizard with personality, micro-interactions, and friendly copy that feels human.

**Dashboard & Visual Progress**  
Main interface with animated progress displays, smart layouts, and at-a-glance status views.

**Gamification & Celebration Engine**  
Streak tracking, achievement unlocks, confetti effects, badges, and contextual encouragement.

**Smart Check-In & Mood Integration**  
Progress logging with emotional intelligence, adaptive responses, and mood-aware messaging.

**Visual Growth Metaphor**  
Garden/city/constellation or similar system that evolves visually as the user progresses.

**Polish & Performance**  
Accessibility (ARIA, keyboard nav), mobile responsiveness, smooth animations (Framer Motion), and UX refinement.

For each section, provide complete, working code with clear comments. Use Tailwind CSS for styling and Framer Motion for animations. Focus on delight, performance, and habit formation.
```
