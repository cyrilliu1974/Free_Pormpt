# Schema.org Structured Data Implementation Guide

## 簡介

The Schema.org Structured Data Implementation Guide is a free AI prompt that creates complete, step-by-step plans for adding structured data markup to websites for any product or service. This structured data prompt for ChatGPT walks you through identifying the right Schema.org types (Product, Service, Organization, LocalBusiness, etc.), defining essential properties, and generating ready-to-use JSON-LD code blocks tailored to your offering. It runs on ChatGPT, Claude, Gemini, and Grok, producing a five-part guide covering type selection, property mapping, example markup, implementation instructions, and ongoing monitoring using Google Search Console and validation tools. SEO specialists and web developers use it to improve search visibility, enable rich snippets, and help search engines parse page content accurately. Reach for this prompt when you need to implement or audit structured data but want expert guidance on which Schema.org vocabulary matters most for your industry and how to avoid common markup errors. org Structured Data Implementation Guide: it is a tested, ready-to-run technical SEO prompt for ChatGPT, Claude, Gemini, and Grok that produces actionable markup plans with realistic JSON-LD examples and validation workflows. ● Identifies the most relevant Schema.org types and properties for your specific product or service context ● Generates complete JSON-LD code blocks with realistic example values you can adapt and deploy immediately ● Includes placement instructions, validation tool recommendations, and troubleshooting tips for common errors ● Provides a monitoring and maintenance schedule so your structured data stays current with Schema.org updates ## Prompt

```
## Role
You are a structured data implementation expert with comprehensive knowledge of Schema.org vocabulary across industries and use cases.

## Task
Create a step-by-step implementation guide for adding Schema.org structured data to the user's offering.

## Context
Structured data helps search engines understand content and can enhance search result appearance through rich snippets. The guide should focus on the most impactful Schema.org types and properties for {{product-or-service}}, with concrete examples and maintenance advice.

## Output
Deliver a five-step implementation guide:

**Step 1: Identify the primary Schema.org type(s)**
- List the most relevant Schema.org types for {{product-or-service}}
- Explain why each type fits

**Step 2: Define essential properties for each type**
- For each identified type, list the required and recommended properties
- Note which properties have the greatest impact on search visibility

**Step 3: Provide example markup**
- For each type, provide complete JSON-LD markup tailored to {{product-or-service}}
- Use realistic example values that match the offering's context
- Format as code blocks

**Step 4: Implement on the website**
- Explain where to place the JSON-LD markup in the HTML
- Recommend validation tools (Google Rich Results Test, Schema.org validator)
- Provide troubleshooting tips for common implementation errors

**Step 5: Monitor and maintain**
- Describe how to monitor for markup errors using Google Search Console
- Recommend a schedule for reviewing and updating structured data
- Note when to check for new Schema.org vocabulary updates

Ensure all markup is accurate, complete, and follows current Schema.org best practices.
```
