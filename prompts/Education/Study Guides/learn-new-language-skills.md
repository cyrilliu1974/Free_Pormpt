# Language Learning Study Plan Prompt for ChatGPT

## 簡介

The Language Learning Study Plan Prompt for ChatGPT is a free AI prompt that creates personalized, comprehensive study roadmaps for learners working to master any target language. This language learning prompt for ChatGPT analyzes the learner's current skill level, preferred learning style, specific goals, and available study time to generate a structured plan organized into daily, weekly, and monthly phases. It outputs a detailed markdown table that balances all core skill areas - speaking, listening, reading, writing, grammar, and vocabulary - while recommending specific activities and resources such as textbooks, online courses, apps, immersion techniques, and practice exercises. Ideal use cases include self-learners building a roadmap for Spanish or Mandarin fluency, language tutors designing custom curricula for students, and educators preparing structured study guides for classroom or remote instruction. The prompt runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need a complete, phase-based learning plan that adapts to individual learner profiles and time constraints, ensuring balanced skill development and measurable progress milestones. ● Outputs a detailed markdown table with timeframes, objectives, activities, resources, and time allocations ● Balances speaking, listening, reading, writing, grammar, and vocabulary development based on learner goals ● Aligns all recommendations with the learner's current skill level and preferred learning style ● Incorporates diverse resource types - textbooks, apps, online courses, immersion methods, and practice activities - for comprehensive skill building ## Prompt

```
## Role
You are an expert language learning strategist who designs personalized, comprehensive study plans.

## Task
Create a detailed learning roadmap that helps the learner master their target language through structured daily, weekly, and monthly objectives. Analyze the learner's profile and design an optimal plan that incorporates diverse resources—textbooks, online courses, apps, immersion techniques, and practice activities—to maximize progress and retention.

## Context
**Target language:** {{target-language}}

**Learner profile:** {{learner-profile}}
(Include: current skill level, preferred learning style, specific goals, and available study time per week)

## Output
Deliver the study plan as a markdown table with these columns:

| Timeframe | Learning Objectives | Recommended Activities | Resources | Time Allocation |

Cover daily, weekly, and monthly phases. Ensure activities align with the learner's skill level, style preferences, and time constraints. Balance skill areas (speaking, listening, reading, writing, grammar, vocabulary) appropriately for their goals.
```
