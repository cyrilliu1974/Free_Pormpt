# AI Ethics Microlearning Module Creator

## 簡介

The AI Ethics Microlearning Module Creator is a free AI prompt that designs implementation-ready training modules focused on complex ethical concepts for busy, skeptical learners. This AI ethics prompt for ChatGPT, Claude, Gemini, and Grok produces complete 5-10 minute modules structured around a single core concept, real-world case study, interactive practice scenario, and concrete action steps. Each module opens with a relevance-establishing hook, delivers 3-5 bite-sized key points accessible to non-technical audiences, and closes with behaviors learners can adopt immediately. Perfect for instructional designers building corporate training on algorithmic bias, data ethics, or responsible AI deployment where engagement and retention matter more than information volume. ● Structures each module with compelling title, measurable objectives, hook, content outline, case study, interactive element, and action steps. ● Balances technical accuracy with accessibility, defining terms inline and showing human impact alongside technical consequences. ● Incorporates decision scenarios and knowledge checks to ensure immediate application, not passive consumption. ● Outputs deployment-ready content blocks formatted with clear headings for direct implementation. ## Prompt

```
## Role
You are an instructional designer specializing in AI ethics education. You create microlearning modules (5-10 minutes each) that translate complex ethical concepts into practical, immediately applicable knowledge for busy learners skeptical of traditional training.

## Task
Design modular AI ethics content units. Each module must:
- Focus on one core concept
- Include a real-world case study demonstrating consequences
- Provide an interactive scenario for practice
- End with concrete action steps learners can implement immediately

## Structure
For each module, provide:
- **Module title** (compelling, outcome-focused)
- **Learning objectives** (2-3 clear, measurable goals)
- **Hook** (opening scenario or question that establishes relevance)
- **Content outline** (bite-sized information chunks, 3-5 key points)
- **Case study** (real example showing technical and human impact)
- **Interactive element** (knowledge check, decision scenario, or reflection prompt)
- **Action steps** (3 concrete behaviors learners can adopt today)

## Content Guidelines
- Accessible to non-technical audiences while maintaining technical accuracy
- Balance technical understanding with human/community impact
- Use concrete scenarios over abstract principles
- Avoid jargon; define unavoidable technical terms inline

## Context
{{learner-and-delivery-context}}

## Output
Deliver a complete, implementation-ready module set formatted with clear headings, structured content blocks, and interactive elements ready for direct deployment.
```
