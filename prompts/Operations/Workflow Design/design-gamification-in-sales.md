# Sales Gamification Framework Designer

## 簡介

The Sales Gamification Framework Designer is a free AI prompt that creates customized gamification systems to optimize sales team performance and engagement. This sales gamification prompt for ChatGPT takes your sales context - team size, industry, key metrics like revenue targets and conversion rates, and current challenges - and produces a detailed implementation table. Each row maps a specific game element (badges, leaderboards, progression systems) to where it fits in your sales process, what triggers rewards, and scores both expected impact and implementation difficulty. The framework also defines concrete thresholds and milestones, such as quota-based badge tiers and performance benchmarks for bonuses and recognition. It runs on ChatGPT, Claude, and Gemini, helping sales leaders turn abstract gamification concepts into actionable plans. Reach for this prompt when you need to boost sales motivation, address activity or conversion challenges, or create transparent performance incentives that align team behavior with business goals. ● Maps game elements to specific points in the sales cycle with concrete reward triggers ● Scores each gamification component for both expected performance impact and ease of rollout ● Defines progression thresholds, badge milestones, and advancement criteria tailored to your metrics ● Addresses distinct challenges like pipeline velocity, activity levels, and conversion rates through targeted game mechanics ## Prompt

```
## Role
You are a gamification expert specializing in sales optimization and performance metrics.

## Task
Design a comprehensive gamification framework tailored to the provided sales environment. Deliver a structured table that maps game elements to implementation points, reward mechanisms, and projected impact.

## Context
{{sales-context}}

Include: team size, industry, primary performance metrics (revenue targets, conversion rates, pipeline velocity, activity levels, etc.), and any current challenges or goals.

## Output
Provide your framework as a table with these columns:

| Gamification Element | Description | Implementation Point | Reward Mechanism | Impact Score (1-10) | Ease of Implementation (1-10) |
|---|---|---|---|---|---|
| [Element name] | [What it does and why] | [Where in sales process] | [Specific reward trigger] | [Expected impact] | [Implementation difficulty] |

After the table, list **Thresholds and Metrics** that define progression and reward unlocking:
- Specific milestones (e.g., "Bronze badge at 80% quota, Silver at 100%, Gold at 120%")
- Performance thresholds for bonuses, prizes, and recognition
- Advancement criteria through the gamification system

Ensure each element addresses a distinct aspect of the sales process with clear, actionable implementation details.
```
