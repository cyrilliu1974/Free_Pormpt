# Value Proposition Testing Framework Generator

## 簡介

The Value Proposition Testing Framework Generator is a free AI prompt that builds stage-gated testing methodologies for startups and product teams validating core messaging through experiments and audience data. This value proposition testing prompt for ChatGPT, Claude, Gemini, and Grok produces a complete framework including quantitative survey templates, qualitative interview guides, A/B test structures, and segmentation analysis tools. It progresses from concept validation through message refinement to competitive differentiation measurement, defining sample sizes, statistical significance thresholds, and decision criteria for advancing between phases. Startups use it to move beyond polite feedback and uncover authentic market response - measuring differentiation strength, purchase intent, and message memorability across audience segments. Reach for this prompt when you need structured experimentation that reveals which value proposition elements actually drive purchasing decisions, not just generic approval. ● Survey instruments capturing both rational and emotional triggers across audience segments ● A/B test structures with control groups, sample size requirements, and statistical significance criteria ● Analysis frameworks identifying resonance patterns and prioritization matrices for message refinement ● Step-by-step execution guidance with timeline milestones and channel-specific adaptations ## Prompt

```
## Role
You are a value proposition strategist specializing in message testing frameworks that validate and refine core positioning through experimentation and data analysis.

## Task
Design a comprehensive, multi-phase testing methodology to systematically validate value propositions, progressing from concept validation through message refinement to competitive differentiation measurement.

## Context
{{business-context}}

The framework must reveal authentic market response—not polite feedback—by capturing both rational and emotional triggers that drive purchasing decisions. Testing should identify which value proposition elements resonate most strongly across different audience segments and measure differentiation strength, purchase intent, and message memorability.

## Output
Deliver a structured testing methodology that includes:

### Phase Structure
- Stage-gated progression from initial validation to competitive positioning
- Decision criteria for advancing between phases
- Resource allocation across phases

### Survey Instruments
- Quantitative survey templates capturing rational and emotional responses
- Qualitative interview guides uncovering deeper motivations
- Questions designed for different audience segments
- Rating scales for differentiation, intent, and recall

### Experiment Design
- A/B test structures for message variations across touchpoints
- Sample size and statistical significance requirements
- Control and treatment group specifications

### Analysis Framework
- Segmentation approach for identifying resonance patterns
- KPI definitions and measurement criteria
- Template for synthesizing quantitative and qualitative findings
- Prioritization matrix for message refinement decisions

### Implementation Guidance
- Specific step-by-step execution instructions
- Timeline milestones aligned with {{budget-timeline}}
- Channel-specific adaptation for {{testing-channels}}

Format all frameworks, questions, and templates as organized bullet points with clear headings for immediate usability.
```
