# User Onboarding Guide Generator for New Customers

## 簡介

The User Onboarding Guide Generator for New Customers is a free AI prompt that produces complete onboarding documentation for any product or service. This user onboarding guide prompt for ChatGPT builds structured manuals that walk new customers through their first experience with clear action steps, expected outcomes, and troubleshooting advice. It uses dependency grammar principles to ensure instructions show how each action connects to prerequisites and results, making complex processes easy to follow. The prompt runs on ChatGPT, Claude, Gemini, and Grok, organizing content into prerequisites, step-by-step actions with tips and outcomes, common problem resolution, and support resources. Teams use it to standardize onboarding documentation for software, physical products, subscription services, or multi-step workflows where first-time user success matters. ● Structures guides with prerequisites, multi-step instructions, troubleshooting sections, and resource lists ● Uses dependency grammar to clarify how each step connects to prior actions and expected results ● Includes best-practice tips and prevention advice alongside every major action ● Adapts to any product or service by requiring only a single variable input ## Prompt

```
## Role
You are an expert technical writer specializing in user-friendly onboarding guides. Write using dependency grammar principles to enhance clarity: structure sentences so relationships between instructions, outcomes, and context are immediately clear.

## Task
Create a comprehensive step-by-step onboarding guide for new customers of {{product-or-service}}. Provide clear instructions, actionable tips, and troubleshooting advice to ensure a smooth first experience.

## Output Structure

### Introduction
- Brief overview of the product or service
- Purpose of this onboarding guide
- Key benefits for new customers

### Prerequisites
- Requirements before starting
- Necessary resources or materials
- Estimated time for completion

### Step-by-Step Guide
For each step, provide:
- **Action**: Start with a clear action verb and specific instruction
- **Tip**: Include a helpful best practice
- **Outcome**: State the expected result

Structure at least 3-5 steps covering the essential onboarding journey.

### Troubleshooting
Address 2-3 common issues:
- **Problem**: Describe what users typically encounter
- **Solution**: Provide step-by-step resolution
- **Prevention**: Offer a tip to avoid the issue

### Conclusion
- Recap the key steps
- Encourage successful onboarding
- List additional resources or support channels

## Guidelines
- Write clear, concise, and actionable instructions
- Explain any necessary technical terms in plain language
- Use dependency grammar to show how each action relates to its prerequisites and outcomes
- Ensure comprehensive coverage of the complete onboarding process
```
