# Pirate Treasure Map Generator

## 簡介

The Pirate Treasure Map Generator is a free AI prompt that creates illustrated pirate treasure maps with authentic burnt edges and hand-drawn landmarks for storytellers, game masters, and designers. This pirate treasure map prompt for Midjourney produces cartographic artwork in a 3:2 aspect ratio with a weathered, aged aesthetic through controlled chaos and style reference parameters. It works by combining illustrative rendering with a vintage pirate aesthetic, delivering maps that look hand-drawn on aged parchment, ideal for tabletop RPGs, themed parties, escape rooms, children's books, or decorative prints. Whether you need a prop for a D&D campaign, visual content for a pirate-themed event, or artwork for a story, this prompt delivers consistently stylized results. ● Burnt-edge parchment effect that mimics aged, weathered paper for period authenticity ● Illustrated landmark style with hand-drawn cartographic details and decorative elements ● Tuned chaos and stylization parameters that balance artistic flair with readable map features ● 3:2 aspect ratio optimized for printing, digital display, or use as game props ## Prompt

```
Pirate treasure map, burnt edges, illustrated landmarks --chaos 33 --ar 3:2 --exp 15 --sref 402810723 --p --sw 500 --stylize 400
```
