# Keyword Integration & On-Page SEO Content Optimizer

## 簡介

The Keyword Integration & On-Page SEO Content Optimizer is a free AI prompt that creates strategic content plans for SEO specialists and web marketers looking to improve search visibility through natural keyword placement. This keyword integration prompt for ChatGPT analyzes your target keywords, webpage elements (titles, headings, meta descriptions, body copy), and business context to produce optimized text that serves both search engines and human readers. It runs on ChatGPT, Claude, and Gemini, delivering a markdown table that pairs each keyword with its ideal webpage element and shows exactly how to integrate it naturally. Real-world use cases include optimizing product pages, refreshing blog post metadata, improving landing page headlines, and aligning existing content with new keyword targets without sacrificing tone or user experience. Reach for this prompt when you need to transform keyword lists into actionable, placement-specific content rather than generic optimization advice. ● Produces a strategic optimization plan with keyword, element, and optimized content in one scannable table ● Maintains natural readability and brand voice while meeting search engine criteria ● Maps each target keyword to its most effective webpage element for maximum ranking impact ● Saves hours of manual copywriting by generating placement-specific optimized text in one pass ## Prompt

```
## Role
You are an expert SEO specialist optimizing website content for search engine ranking.

## Task
Analyze the target keywords and webpage elements provided, then create optimized content that naturally incorporates keywords while maintaining readability and user experience. Deliver a strategic optimization plan that improves search visibility.

## Context
**Target keywords:** {{target-keywords}}

**Webpage elements to optimize:** {{webpage-elements}}

**Business context:** {{business-context}}

For each keyword-element pairing:
- Identify the most effective placement strategy
- Write optimized content that integrates keywords naturally
- Ensure the content serves both search engines and human readers
- Maintain the voice and tone appropriate for the audience

## Output
Deliver your optimization strategy as a markdown table with exactly 3 columns:

| Target Keywords | Webpage Elements | Optimized Content |
|----------------|------------------|-------------------|
| [keyword] | [element] | [your optimized text] |

Include one row for each keyword-element combination, showing how to integrate the keyword into that specific webpage element.
```
