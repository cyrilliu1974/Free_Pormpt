# Practice Test Generator for Exams and Subjects

## 簡介

The Practice Test Generator for Exams and Subjects is a free AI prompt that creates comprehensive practice tests with detailed answer keys for educators and students preparing for academic assessments. This practice test generator prompt for ChatGPT produces a full set of exam questions across multiple formats - multiple-choice with four plausible answer options, short answer, and essay questions - designed to test understanding from basic recall to higher-order analysis. It runs on ChatGPT, Claude, Gemini, and Grok, generating original questions tailored to any exam type and subject area, from standardized tests to classroom assessments. Each question comes with a detailed explanation highlighting correct reasoning, common misconceptions, and step-by-step solutions that reinforce key concepts. This prompt is ideal for teachers building study materials, tutors preparing students for upcoming exams, or learners creating self-assessment tools to gauge their readiness. ● Generates multiple question types in a single test: multiple-choice, short answer, and essay formats to assess diverse cognitive skills ● Creates plausible distractors for multiple-choice questions that surface common student misconceptions and errors ● Delivers detailed answer explanations with step-by-step reasoning, key concept references, and guidance on what constitutes a strong response ● Outputs questions and answers in an organized table format that separates question type, content, options, correct answers, and explanations for easy reference ## Prompt

```
## Role
You are an expert exam question creator, adept at generating comprehensive practice tests across various subjects and difficulty levels.

## Task
Create a set of practice questions for {{exam-or-test}} in {{subject-area}}. Include an assortment of question types:
- Multiple-choice (with four plausible answer options)
- Short answer
- Essay questions

Develop a complete answer key providing detailed explanations for each question.

## Requirements
- Test various levels of understanding, from basic recall to application and analysis
- For multiple-choice questions, create plausible distractors that help identify common misconceptions
- In answer explanations, provide step-by-step reasoning and refer to key concepts or formulas as necessary
- Ensure questions are original and not directly copied from existing resources

## Output
Present the questions and answers in this table format:

**Practice Questions for [Exam/Test Name] in [Subject]**

| Question Type | Question | Answer Options (if applicable) | Correct Answer | Explanation |
|---|---|---|---|---|
| Multiple-choice | [Question text] | A. [Option 1]<br>B. [Option 2]<br>C. [Option 3]<br>D. [Option 4] | [Letter of correct option] | [Detailed explanation of why this answer is correct and the others are incorrect] |
| Short Answer | [Question text] | N/A | [Correct answer] | [Detailed explanation of the key points that should be included in a correct answer] |
| Essay | [Question text] | N/A | [Key points to include in answer] | [Detailed explanation of important concepts, examples, and reasoning that should be incorporated into a strong essay response] |
```
