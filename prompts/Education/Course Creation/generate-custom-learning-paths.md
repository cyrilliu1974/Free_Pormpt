# Custom Learning Path Generator for Any Topic

## 簡介

The Custom Learning Path Generator for Any Topic is a free AI prompt that builds personalized, step-by-step learning roadmaps aligned to individual goals, skill levels, and learning styles. This learning path prompt for ChatGPT takes any topic and a learner profile, then produces a markdown table mapping out modules, measurable learning objectives, and high-quality resources (courses, books, tutorials, exercises) in a logical progression from foundational to advanced concepts. It balances theory with hands-on practice, incorporates assessment checkpoints, and respects time commitments. The prompt runs on ChatGPT, Claude, Gemini, and Grok, making it ideal for educators, coaches, self-learners, and training teams who need to design curriculum quickly without starting from scratch. Reach for this prompt when you need to onboard a new hire, plan self-study for skill development, or design a course outline for a client with specific constraints. ● Breaks any topic into logical modules that follow a natural difficulty curve. ● Defines measurable learning objectives so progress is trackable and clear. ● Recommends specific, high-quality resources matched to each objective and learner style. ● Outputs a clean markdown table ready to share, print, or embed in a learning management system. ## Prompt

```
## Role
You are an expert educational consultant specializing in personalized curriculum design.

## Task
Create a comprehensive learning path for {{topic}} tailored to the learner's profile. Deliver it as a structured roadmap that progresses logically from foundational to advanced concepts.

## Context
Learner profile:
{{learner-profile}}

The learning path should:
- Break the topic into logical modules or units
- Define clear, measurable learning objectives for each module
- Identify high-quality resources (courses, books, tutorials, practice exercises) for each objective
- Follow a progressive difficulty curve
- Balance theory with hands-on practice
- Include suggested checkpoints or assessments to measure progress
- Align with the learner's goals, current skill level, preferred learning style, and available time commitment

## Output
Provide your response as a markdown table with three columns:

| Module | Learning Objectives | Resources |
|--------|---------------------|-----------|
```
