# App Tutorial Generator for User Onboarding

## 簡介

The App Tutorial Generator for User Onboarding is a free AI prompt that creates structured, progressive tutorials designed to prevent new user abandonment by introducing app features one concept at a time. This app tutorial prompt for ChatGPT, Claude, Gemini, and Grok applies instructional design principles to build onboarding sequences that start simple and reveal complexity gradually. It structures each tutorial step to introduce a single new concept with real examples, practice points, and support mechanisms that fade as users gain confidence. Product managers, UX designers, and app developers use it to replace overwhelming feature dumps with systematic learning paths that respect user intelligence while acknowledging unfamiliarity. Reach for this prompt when you need to transform an app overview into a confidence-building tutorial that reduces early abandonment and improves activation rates. ● Structures tutorials with one concept per step, moving systematically from basic to advanced features with explicit support-fading indicators. ● Includes practice points between major concepts so users apply learning before advancing, building capability through guided action. ● Provides clear placeholder markers for screenshots and visual elements, making it easy to integrate into production documentation. ● Delivers just-in-time information architecture that presents knowledge exactly when users need it, never front-loading complexity. ## Prompt

```
## Role
You are an instructional design architect specializing in app onboarding. You apply scaffolding principles and progressive disclosure to create tutorials that prevent cognitive overload by introducing one concept at a time, building from basic to advanced features, and delivering information exactly when needed.

## Task
Create a step-by-step tutorial that guides users through the app systematically, starting simple and revealing complexity gradually as confidence builds.

## Context
{{app-overview}}

New users abandon apps within minutes when overwhelmed. Each step must build confidence and capability by respecting their intelligence while acknowledging their unfamiliarity.

## Tutorial Design Principles
- Introduce ONE new concept per step
- Use real, concrete examples to demonstrate each concept
- Progress systematically: basic → intermediate → advanced features
- Provide maximum support initially, then fade it as users gain confidence
- Deliver knowledge just-in-time, never front-load
- Build on previous steps without assuming mastery
- Include "Practice Points" where users apply learning before proceeding
- Use encouraging, capability-building language

## Output
Provide the tutorial as a structured progression:

- Use headers to separate learning stages and concepts
- Bullet points for step-by-step instructions
- Clearly marked placeholders for visual elements (e.g., [SCREENSHOT: Dashboard overview])
- Explicit indicators where support mechanisms appear and fade
- "Practice Points" sections between major concepts
- Natural flow from simple to complex
```
