# Academic Complexity Adjuster for Course Content

## 簡介

The Academic Complexity Adjuster for Course Content is a free AI prompt that adapts educational materials to match specific academic levels while maintaining subject-matter accuracy for educators and instructional designers. This academic complexity prompt for ChatGPT, Claude, Gemini, and Grok analyzes existing course content, identifies core concepts and terminology, then systematically adjusts vocabulary, sentence structure, explanation depth, and examples to suit the cognitive abilities and background knowledge of your target audience. Whether you need to simplify graduate-level research for undergraduates, elevate high-school material for advanced placement courses, or adapt technical content for elementary learners, the prompt delivers restructured content organized under a clear level heading plus a "Key Adjustments" summary that documents every vocabulary change, conceptual modification, and structural improvement made. Use it when developing differentiated instruction materials, creating tiered assignments, or repurposing content across multiple course levels. ● Assesses original content complexity and identifies terminology requiring simplification or elaboration ● Adjusts vocabulary, sentence structure, and explanation depth to match target cognitive abilities ● Selects and modifies examples appropriate for the specified academic level ● Provides a detailed "Key Adjustments" section documenting vocabulary changes, conceptual modifications, example updates, and structural improvements ## Prompt

```
## Role
You are an academic content specialist who adapts educational materials to different complexity levels while preserving subject-matter accuracy.

## Task
Adjust the provided academic content to match the target difficulty level. Analyze the current complexity, identify core concepts and terminology, then modify language, examples, and explanations to suit the intended audience's background knowledge and cognitive abilities.

## Context
**Content:** {{current-content}}

**Target academic level:** {{target-level}}

**Subject area:** {{subject-area}}

## Process
1. Assess the original content's complexity and key concepts
2. Identify terminology that needs simplification or elaboration
3. Adjust vocabulary, sentence structure, and explanation depth
4. Select or modify examples appropriate for the target level
5. Verify alignment with educational standards and learning objectives

## Output
Provide the adapted content under a clear heading that reflects the target level (e.g., "Elementary Level Version," "Undergraduate Version," "Graduate Level Version").

Then include a "Key Adjustments" section with bullet points summarizing:
- Vocabulary changes made
- Conceptual simplifications or elaborations
- Example modifications
- Structural changes to improve accessibility
```
