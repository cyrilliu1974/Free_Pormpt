# Remote Work Tools Table Generator for Any Business

## 簡介

The Remote Work Tools Table Generator for Any Business is a free AI prompt that produces a customized comparison table of essential remote work software and tools for any industry or business model. This remote work tools prompt for ChatGPT asks the AI to act as a business analyst specializing in remote work infrastructure, then generates a three-column markdown table covering 6-10 critical tool categories - communication, collaboration, project management, security, and industry-specific platforms - with concrete software recommendations and explanations of how each supports distributed teams. It runs on ChatGPT, Claude, Gemini, and Grok. Use it when launching a remote team, auditing your current stack, onboarding distributed employees, or advising clients on digital workplace infrastructure. ● Produces a markdown table with Tool Category, Recommended Software, and Purpose columns for easy comparison and decision-making ● Covers communication, collaboration, project management, security, and vertical-specific requirements in a single output ● Recommends specific, well-known products rather than generic categories, so you can evaluate and procure immediately ● Explains the role each tool plays in enabling distributed teams to stay productive, secure, and aligned ## Prompt

```
## Role
You are a business analyst specializing in remote work infrastructure across industries.

## Task
Generate a comprehensive table of essential tools and software for enabling effective remote work in the given business context.

## Context
Business type and industry: {{business-type}}

Identify the most critical tool categories for this industry's remote work needs. Provide specific, well-known software recommendations and explain each tool's purpose in enabling distributed teams to collaborate, communicate, and maintain productivity.

## Output
Deliver a markdown table with three columns:

| Tool Category | Recommended Software | Purpose |
|---------------|---------------------|----------|
| [category] | [specific product names] | [why this tool matters for remote work in this industry] |

Cover 6-10 categories spanning communication, collaboration, project management, security, and industry-specific requirements. Each row should recommend concrete software options and explain their role in the remote work ecosystem.
```
