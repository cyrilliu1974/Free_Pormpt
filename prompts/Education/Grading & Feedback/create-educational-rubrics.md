# Educational Rubric Generator for Any Assignment

## 簡介

The Educational Rubric Generator for Any Assignment is a free AI prompt that creates comprehensive assessment rubrics with clearly defined criteria and performance levels for educators. This educational rubric prompt for ChatGPT produces a complete grading matrix with 4-6 evaluation criteria tailored to your specific assignment type and subject area, four distinct performance levels, and 3-5 cited reputable sources. The output organizes everything into a clean table format where each criterion describes what Exemplary, Proficient, Developing, and Novice performance looks like. Teachers use it to build rubrics for essays, lab reports, presentations, projects, and any other assignment across mathematics, science, English, history, and all subject areas. It runs on ChatGPT, Claude, and Gemini. Reach for this prompt when you need a consistent, standards-aligned assessment tool that saves hours of rubric design time and ensures students understand exactly how their work will be evaluated. ● Produces 4-6 assignment-specific criteria that cover all essential aspects of student work ● Defines four performance levels with concise, distinguishable descriptions at each tier ● Includes 3-5 source citations grounded in educational assessment best practices ● Outputs a formatted table ready to share with students or include in assignment instructions ## Prompt

```
## Role
You are an expert rubric creator, skilled at designing clear and effective assessment tools for educational assignments.

## Task
Create a comprehensive rubric for evaluating {{assignment-type}} in {{subject-area}}. Develop well-defined criteria and performance levels that accurately measure student achievement.

## Requirements
- Include 4-6 evaluation criteria specific to the assignment type and subject area
- Define four performance levels: Exemplary (4), Proficient (3), Developing (2), and Novice (1)
- Write concise descriptions for each performance level that are clearly distinguishable from one another
- Ensure criteria cover all essential aspects of the assignment
- Cite 3-5 reputable sources relevant to the assignment type and subject area

## Output Format
**Assignment type:** {{assignment-type}}

**Subject area:** {{subject-area}}

**Rubric:**

| Criteria | Exemplary (4) | Proficient (3) | Developing (2) | Novice (1) |
|----------|---------------|----------------|----------------|------------|
| [First criterion] | [Description] | [Description] | [Description] | [Description] |
| [Second criterion] | [Description] | [Description] | [Description] | [Description] |
| [Continue for all criteria] | [Description] | [Description] | [Description] | [Description] |

**Sources:**
1. [Source citation]
2. [Source citation]
3. [Source citation]
```
