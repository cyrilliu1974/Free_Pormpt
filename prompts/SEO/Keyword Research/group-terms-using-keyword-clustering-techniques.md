# Keyword Clustering for SEO Content Strategy

## 簡介

The Keyword Clustering for SEO Content Strategy is a free AI prompt that organizes keywords into actionable clusters for SEO professionals and content strategists. This keyword clustering prompt for ChatGPT analyzes semantic relationships and user intent patterns across your target keywords, then delivers both a structured markdown table and strategic recommendations for content development. It runs on ChatGPT, Claude, Gemini, and Grok, accepting your keyword list with search volumes, industry context, competitor information, and SEO goals. The prompt applies clustering logic to group keywords by theme and intent type - informational, transactional, or navigational - while identifying content gaps and competitive opportunities within each cluster. Use this prompt when planning content calendars, auditing existing keyword coverage, or mapping keyword strategy to user journeys across your site. ● Produces a three-column table organizing keywords by search volume and thematic cluster ● Identifies high-priority clusters for immediate content development and long-term targets ● Recommends content formats tailored to each cluster's dominant search intent ● Reveals internal linking opportunities between related keyword groups and competitive content gaps ## Prompt

```
## Role
You are an expert SEO strategist specializing in keyword clustering and semantic analysis.

## Task
Group the provided keywords using clustering techniques based on semantic relationships and search intent. Deliver a structured analysis that informs content strategy and improves search engine rankings.

## Context
{{keywords-and-context}}

Include:
- List of target keywords with search volumes (if available)
- Industry and target audience
- Primary competitors
- Current SEO goals and objectives

## Process
1. Analyze the keywords for semantic relationships and user intent patterns
2. Apply clustering logic to group keywords into thematic clusters
3. Identify cluster characteristics (informational, transactional, navigational intent)
4. Assess competitive landscape and content gap opportunities within each cluster

## Output
Deliver your analysis in two parts:

**Part 1: Keyword Clustering Table**
Present a markdown table with three columns:
- Keyword
- Search Volume
- Keyword Cluster

**Part 2: Strategic Recommendations**
Provide 5-7 actionable bullet points covering:
- High-priority clusters for content development
- Content format recommendations per cluster
- Internal linking opportunities between clusters
- Quick-win keywords vs. long-term targets
- Gaps in current coverage relative to competitors
```
