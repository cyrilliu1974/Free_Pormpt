# Online Learning Resource Curator for Any Subject

## 簡介

The Online Learning Resource Curator for Any Subject is a free AI prompt that compiles organized lists of vetted online learning materials tailored to specific subjects, skill levels, and learning constraints for students, educators, and self-learners. This learning resource prompt for ChatGPT evaluates platforms and materials for credibility, relevance, and pedagogical quality, then structures them into an easy-to-follow list organized by resource type or learning progression. Each entry includes the title, platform, a brief description, time commitment estimate, and recommendation rationale. The prompt accommodates diverse formats - courses, tutorials, articles, videos, and interactive platforms - so learners can choose materials that match their preferred learning style. It runs on ChatGPT, Claude, Gemini, and Grok, making it accessible across text-based AI models. Reach for this prompt when you need to quickly assemble a curated reading or study list for a new topic, guide a student through structured self-study, or map out a learning path that respects time and goal constraints. ● Evaluates online platforms and content for credibility, currency, and pedagogical quality before inclusion. ● Organizes resources by type or learning sequence with clear headings, bullet points, and time estimates for easy navigation. ● Accommodates multiple learning formats - video courses, interactive tutorials, written guides, and articles - to suit different learner preferences. ● Includes a usage guide introduction that explains how to work through the list effectively based on goals and constraints. ## Prompt

```
## Role
You are an expert educational content curator specializing in identifying and organizing high-quality online learning resources.

## Task
Compile a comprehensive, well-organized list of online learning materials tailored to the specified subject and skill level. Evaluate resources for credibility, relevance, and pedagogical quality. Include diverse formats (courses, tutorials, articles, videos, interactive platforms) to accommodate different learning approaches.

## Context
**Subject and level:** {{subject-and-skill-level}}
**Learning context:** {{learning-goals-and-constraints}}

Consider the learner's goals, available time commitment, and preferred learning styles when selecting and organizing resources. Prioritize materials that are accessible, current, and from reputable platforms or educators.

## Output
Structure your resource list with:
- Clear headings organized by resource type or learning progression
- For each resource: title, platform/source, brief description (1-2 sentences), estimated time commitment, and why it's recommended
- Subheadings to group related materials
- Bullet points for easy scanning
- A brief introduction explaining how to use the list effectively
```
