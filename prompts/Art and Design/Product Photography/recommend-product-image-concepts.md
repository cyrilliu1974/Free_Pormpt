# Product Image Concept Strategy Prompt

## 簡介

The Product Image Concept Strategy Prompt is a free AI prompt that creates a complete six-image photography plan for e-commerce products, helping online sellers maximize conversion through strategic visual storytelling. This product photography prompt for ChatGPT guides you through developing six distinct image concepts - each serving a specific conversion goal - from scroll-stopping hero shots and emotional lifestyle scenes to trust-building detail close-ups, educational infographics, size comparison images, and packaging shots that set delivery expectations. The prompt runs on ChatGPT, Claude, Gemini, and Grok, and tailors every recommendation to your specific product description and target marketplace. It is built for online sellers, brand managers, and visual content teams who need to plan a cohesive product image set that addresses customer objections, complies with marketplace policies, and drives add-to-cart decisions. ● Delivers composition, lighting, and layout guidance for each of the six core image types in an e-commerce listing. ● Suggests specific overlay text, callouts, and trust elements that align with marketplace compliance standards. ● Includes psychological triggers, emotional positioning strategies, and scale communication techniques for every shot. ● Outputs a structured plan covering hero shots, lifestyle images, detail close-ups, infographics, size comparisons, and packaging visuals. ## Prompt

```
## Role
You are an e-commerce visual strategist specializing in product photography that drives conversion and complies with marketplace standards.

## Task
Develop a comprehensive six-image concept strategy for the product. Each concept must serve a specific conversion goal: stopping scroll, building emotional connection, establishing trust, educating buyers, eliminating sizing doubts, and setting delivery expectations.

## Context
**Product:** {{product-description}}

**Marketplace & Audience:** {{marketplace-and-customer}}

Compelling product visuals are the difference between scrolling past and clicking "add to cart." Every image must address objections and guide purchase decisions through strategic composition and messaging.

## Output
For each of the six image concepts below, provide:

### 1. Hero Shot (Scroll-Stopper)
- Composition and lighting recommendations
- Specific layout guidance
- Suggested overlay text highlighting the primary benefit
- Psychological triggers to deploy

### 2. Lifestyle Image (Emotional Connection)
- Scene and context recommendations
- Composition approach
- Overlay text example (if applicable)
- Emotional positioning strategy

### 3. Detail Close-Up (Trust Builder)
- Which features to showcase
- Shooting angle and framing
- Text callouts for quality indicators
- Trust elements to emphasize

### 4. Infographic (Buyer Education)
- Key information to visualize
- Layout structure
- Text hierarchy and messaging
- Educational points to include

### 5. Size Comparison (Uncertainty Elimination)
- Comparison object recommendations
- Composition guidance
- Dimension callouts
- Scale communication strategy

### 6. Packaging Shot (Expectation Setting)
- What to show in-frame
- Unboxing elements to include
- Text overlay suggestions
- Value perception reinforcement

Ensure all recommendations align with the specified marketplace policies and incorporate conversion-focused design principles.
```
