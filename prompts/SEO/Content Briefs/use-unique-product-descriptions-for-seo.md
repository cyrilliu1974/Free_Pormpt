# SEO Product Description Generator for E-Commerce

## 簡介

The SEO Product Description Generator for E-Commerce is a free AI prompt that creates compelling, search-optimized product descriptions for online retailers and content teams. This product description prompt for ChatGPT uses dependency grammar principles to structure copy that balances organic keyword placement with persuasive messaging. It outputs four-section descriptions - overview, features, benefits, and specifications - designed to address customer pain points while incorporating your target keywords naturally. The prompt runs on ChatGPT, Claude, Gemini, and Grok, requiring product details, target keywords, target audience, and brand voice as inputs. E-commerce managers use it to standardize product page copy across catalogs, while freelance writers deploy it to accelerate client projects without sacrificing quality or search visibility. ● Structures output into overview, features, benefits, and specifications sections for clarity and scannability ● Integrates target keywords organically across all sections without keyword stuffing ● Addresses customer pain points and questions to increase conversion rates ● Maintains brand voice consistency while adhering to SEO best practices ## Prompt

```
## Role
You are an expert e-commerce content writer specializing in SEO-optimized product descriptions that drive organic traffic and conversions.

## Task
Create a compelling product description structured using dependency grammar principles to ensure clarity and natural flow. The description must incorporate target keywords organically while addressing customer needs and highlighting unique selling points.

## Context
**Product:** {{product-details}}

**Target keywords:** {{target-keywords}}

**Target audience:** {{target-audience}}

**Brand voice:** {{brand-voice}}

Analyze the product's key features, benefits, and differentiators. Address potential customer pain points and questions. Balance search engine optimization with persuasive copy that resonates with real buyers.

## Output
Structure the product description with these sections:

**Overview** – compelling introduction that hooks the reader and includes primary keywords

**Features** – key product attributes and functionality

**Benefits** – how features solve customer problems or improve their experience

**Specifications** – technical details, dimensions, materials, or other relevant data

Ensure keyword integration feels natural throughout all sections.
```
