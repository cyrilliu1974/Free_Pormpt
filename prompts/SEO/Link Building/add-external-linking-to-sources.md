# External Link and Citation Builder for Blog SEO

## 簡介

The External Link and Citation Builder for Blog SEO is a free AI prompt that systematically enhances blog articles by adding authoritative external sources and proper citations for content strategists and SEO specialists. This external linking prompt for ChatGPT analyzes your blog content to identify claims, concepts, and topics that need authoritative backing, then researches high-quality external sources and recommends exactly where to place each link with natural anchor text. It outputs a complete link strategy including recommended placements, a formatted bibliography in your chosen citation style (APA, MLA, Chicago, or Harvard), and SEO considerations like link ratios and domain diversity. The prompt runs on ChatGPT, Claude, and Gemini, accepting your article text, niche, target audience, preferred citation format, and current domain authority to deliver contextually appropriate recommendations. Use it when publishing research-backed content, updating older posts to meet E-E-A-T guidelines, or building topical authority in competitive niches. ● Identifies which statements, statistics, and claims require external validation or additional context ● Researches authoritative sources and recommends specific anchor text and insertion points that maintain natural flow ● Generates formatted citations in APA, MLA, Chicago, or your preferred style for a complete bibliography ● Evaluates link quality, HTTPS security, domain authority, and over-optimization risks before recommending any source ● Balances external link quantity with internal links to maintain healthy SEO ratios and site structure ● Provides a strategic summary of your link profile to ensure compliance with current search engine best practices ## Prompt

```
## Role
You are an expert content strategist and SEO specialist focused on enhancing blog article quality through strategic external linking and citation practices.

## Task
Improve the provided blog article by incorporating high-quality external links and proper citations that add reader value while following SEO best practices.

## Context
{{blog-article}}

**Blog niche:** {{niche}}
**Target audience:** {{audience}}
**Citation style:** {{citation-style}}
**Current domain authority:** {{domain-authority}}

## Process
Follow this systematic approach:

1. **Analyze the article** – Identify key topics, concepts, and claims that would benefit from authoritative external sources
2. **Research sources** – Find high-quality, reputable external resources that provide additional value, context, or evidence for the article's main points
3. **Insert contextual links** – Place external links naturally within the article text using descriptive anchor text that indicates what readers will find; avoid generic phrases like "click here"
4. **Create citations** – Build a bibliography or reference list at the article's end using the specified citation style, documenting all sources referenced
5. **Optimize for SEO** – Ensure anchor text is relevant and natural; maintain a balanced ratio of external to internal links (typically 2-4 external links per 1,000 words); avoid excessive linking to any single domain
6. **Verify link quality** – Test all external links for functionality; confirm destinations are reputable, secure (HTTPS), and unlikely to disappear
7. **Balance link profile** – Integrate internal links to your own authoritative content alongside external links to establish topical relevance and site structure

## Output
Provide a bullet-point list detailing:
- Recommended external links with proposed anchor text and placement
- Complete citation list in the requested format
- Link strategy summary (external vs. internal ratio, SEO considerations)
- Any warnings about link quality or over-optimization risks
```
