# Grant Proposal Writer for Non-Profit Funding

## 簡介

The Grant Proposal Writer for Non-Profit Funding is a free AI prompt that creates persuasive, well-structured grant proposals for non-profit organizations seeking funding. This grant proposal prompt for ChatGPT guides you through writing all five essential sections that review committees expect: an executive summary, evidence-based statement of need, detailed project description with timeline and methodology, itemized budget with justifications, and a measurable evaluation plan. It works on ChatGPT, Claude, Gemini, and Grok by accepting your organization mission, project details, target audience, and requested grant amount, then building a cohesive funding case that connects each section logically. Non-profits use it to apply for foundation grants, government funding, and corporate sponsorships where a formal written proposal is required. ● Produces all five core sections required by most grantors: executive summary, statement of need, project description, budget breakdown, and evaluation plan ● Aligns project goals with organizational mission and demonstrates impact on the specified target audience ● Provides itemized budget justifications and measurable outcomes that strengthen credibility with review committees ● Maintains professional tone and logical flow appropriate for foundation program officers and grant reviewers ## Prompt

```
## Role
You are an expert grant writer specializing in non-profit funding proposals.

## Task
Create a persuasive, well-structured grant proposal that effectively communicates project goals, impact, and financial needs. The proposal must include five core sections: Executive Summary, Statement of Need, Project Description, Budget, and Evaluation Plan.

## Context
Organization mission: {{organization-mission}}

Project details: {{project-description}}

Target audience: {{target-audience}}

Grant amount requested: {{grant-amount}}

Analyze how the project aligns with the organization's mission and serves the target audience. Ensure logical flow and clear connections between sections, with each part building a cohesive case for funding.

## Output
Structure the proposal with these sections, using clear headings:

**Executive Summary** – Concise overview of the organization, project, funding request, and expected impact (typically 1 paragraph)

**Statement of Need** – Evidence-based explanation of the problem being addressed, supported by data and relevance to the target audience

**Project Description** – Detailed explanation of activities, timeline, methodology, and how the project addresses the stated need

**Budget** – Itemized breakdown of how the grant funds will be allocated, with justification for major expense categories

**Evaluation Plan** – Measurable outcomes, assessment methods, and timeline for demonstrating project success and impact

Write concisely while emphasizing significance and outcomes. Maintain professional tone appropriate for grant review committees.
```
