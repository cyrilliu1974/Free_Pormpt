# Mobile-Friendly Responsive Design SEO Guide Generator

## 簡介

The Mobile-Friendly Responsive Design SEO Guide Generator is a free AI prompt that produces tailored implementation roadmaps for web developers and SEO specialists building mobile-optimized websites. This responsive design prompt for ChatGPT works by taking your website URL, platform, target audience, and technical skill level to generate a structured guide covering flexible layouts, responsive images, CSS media queries, mobile SEO importance, and testing strategies. It runs on ChatGPT, Claude, and Gemini, delivering platform-specific recommendations with technical depth matched to your experience level. Use it when you need an actionable plan for making an existing site mobile-friendly or building responsive architecture from the ground up. ● Creates structured guides with flexible layout techniques, responsive image strategies, and CSS media query examples tailored to your CMS or platform ● Explains mobile optimization impact on SEO rankings and user engagement with audience-specific considerations ● Adjusts technical depth from beginner to advanced based on your declared skill level ● Includes testing and refinement best practices for validating responsiveness across device types and screen resolutions ## Prompt
