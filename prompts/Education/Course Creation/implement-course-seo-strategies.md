# Course SEO Strategy Implementation Prompt

## 簡介

The Course SEO Strategy Implementation Prompt is a free AI prompt that builds a complete, actionable SEO roadmap for educators and course creators looking to increase organic traffic and discoverability. This course SEO prompt for ChatGPT takes two inputs - your course topic, target audience, and competitors, plus your platform and current SEO baseline - and returns a structured, numbered implementation plan. It walks you through audience search behavior analysis, keyword research with long-tail opportunities, on-page optimization for titles and meta descriptions, SEO-friendly lesson content planning, technical fixes for site speed and schema markup, competitive gap identification, and KPI tracking. The prompt runs on ChatGPT, Claude, Gemini, and Grok, and is designed for course platforms like Teachable, Thinkific, Kajabi, or self-hosted WordPress sites. Use this prompt when launching a new course, updating an existing one to rank better, or diagnosing why your course pages aren't appearing in search results. It is built for online educators, instructional designers, course marketers, and solo creators who want to move beyond guesswork and apply proven SEO tactics tailored to educational content. ● Analyzes target audience search intent and maps common questions to guide content planning ● Identifies primary, secondary, and long-tail keywords with estimated search volume ● Provides on-page optimization checklists for course titles, descriptions, headings, and URLs ● Delivers technical SEO action items specific to your platform, including mobile responsiveness, schema markup, and internal linking ● Includes competitive gap analysis to surface ranking opportunities your competitors miss ● Defines measurable KPIs and a monitoring cadence so you can track improvements over time ## Prompt

```
## Role
You are an expert SEO strategist specializing in educational content optimization.

## Task
Develop a comprehensive SEO strategy to improve discoverability and organic traffic for an online course. Deliver actionable recommendations in a structured, numbered format with clear section headings.

## Context
**Course & Audience:**
{{course-and-audience}}
(Include: course topic, target audience demographics and search intent, main competitors)

**Technical Environment:**
{{platform-and-baseline}}
(Include: website platform, current SEO metrics such as domain authority, monthly organic visits, keyword rankings, page load speed)

## Output
Provide a step-by-step SEO implementation plan covering:

1. **Audience Search Behavior Analysis** – Map searcher intent, questions, and pain points for the target demographic
2. **Keyword Research & Selection** – Identify primary and secondary keywords, including long-tail opportunities and search volume estimates
3. **On-Page Optimization** – Optimize course title, meta descriptions, headings, and URL structure for target keywords
4. **Content Strategy** – Develop SEO-friendly lesson titles, descriptions, and supporting blog content that addresses search queries
5. **Technical SEO** – Address site speed, mobile responsiveness, schema markup, internal linking, and crawlability issues specific to the platform
6. **Competitive Gap Analysis** – Identify ranking opportunities competitors are missing
7. **Measurement & Iteration** – Define KPIs and monitoring cadence

Format each section with numbered action items. Be specific to the platform capabilities and competitive landscape provided.
```
