# Course Outline Template Generator for Educators

## 簡介

The Course Outline Template Generator for Educators is a free AI prompt that produces comprehensive, standards-aligned course architectures for teachers and instructional designers. This course outline prompt for ChatGPT uses backward design principles to build complete curriculum frameworks. You input your subject, grade level, duration, and any required standards, and it returns a hierarchical outline with main sections, topics, subtopics, measurable learning objectives written with action verbs, varied assessment strategies (formative, summative, and authentic), instructional method suggestions, pacing recommendations, and resource ideas. Teachers use it to map semester plans, workshop facilitators use it to design multi-week training modules, and homeschool parents use it to structure year-long curricula that meet state requirements. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need to transform a subject and set of standards into a ready-to-implement course structure with logical topic sequencing and clear learning outcomes. ● Produces hierarchical outlines with sections, topics, and subtopics logically sequenced for student mastery ● Writes measurable learning objectives using action verbs aligned to Bloom's taxonomy ● Integrates multiple assessment types throughout the course timeline ● Suggests instructional methods, activities, and resource recommendations for each section ● Includes pacing guidance to fit your specified course duration and standards ## Prompt

```
## Role
You are an expert curriculum designer specializing in evidence-based course architecture and backward design principles.

## Task
Create a comprehensive course outline template with clear learning objectives, topics, subtopics, and assessment strategies. Structure the curriculum to optimize pacing, sequencing, and student mastery.

## Context
**Subject:** {{subject}}
**Grade level:** {{grade-level}}
**Duration:** {{duration}}
**Curriculum standards and special requirements:** {{standards-and-requirements}}

## Process
1. Outline the main course sections aligned to the curriculum standards
2. Break each section into specific topics and subtopics with logical progression
3. Define measurable learning objectives for each section using action verbs (analyze, evaluate, create, etc.)
4. Integrate varied assessment strategies (formative, summative, authentic) throughout
5. Suggest appropriate instructional methods, resources, and activities for each section
6. Indicate recommended pacing to ensure adequate coverage within the timeframe

## Output
Deliver a structured course outline using:
- **Headings** for main sections
- **Subheadings** for topics
- **Bullet points** for subtopics, learning objectives, assessments, and instructional suggestions

Ensure the outline is clear, organized, and ready for implementation.
```
