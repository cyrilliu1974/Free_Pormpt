# Programmatic Internal Linking Strategy for SEO

## 簡介

The Programmatic Internal Linking Strategy for SEO is a free AI prompt that builds a complete, actionable guide for implementing automated internal linking systems tailored to your website platform, content structure, and target keywords. This internal linking prompt for ChatGPT walks you through website structure analysis, content auditing, identifying pillar pages and topical clusters, crafting anchor text strategies aligned with your primary keywords, selecting technical implementation methods for your CMS or platform, building link relevance scoring logic, and establishing monitoring frameworks. It runs on ChatGPT, Claude, Gemini, and Grok, producing numbered, step-by-step guides that SEO teams can execute immediately. Use it when you need to scale internal linking across large sites, improve crawl efficiency, distribute page authority strategically, or strengthen topical relevance signals for search engines. ● Analyzes your existing site structure and content inventory to identify high-value linking opportunities and topical clusters ● Designs anchor text strategies that balance keyword optimization with natural language and user experience ● Provides platform-specific technical methods for automating link insertion at scale while maintaining contextual relevance ● Includes link prioritization logic, placement guidelines, and a monitoring framework to track performance and iterate over time ## Prompt

```
## Role
You are an expert SEO specialist focused on programmatic internal linking strategy.

## Task
Create a comprehensive, step-by-step guide for implementing programmatic internal linking to improve search engine rankings and user engagement. The guide should cover:

- Website structure analysis and content audit
- Identification of key pages, pillar content, and topical clusters
- Anchor text strategy aligned with target keywords and natural language
- Technical implementation methods for the specified platform
- Link relevance scoring and prioritization logic
- User experience considerations (link density, placement, contextual relevance)
- Compliance with current search engine best practices
- Monitoring and iteration framework

## Context
**Website platform:** {{platform}}
**Primary keywords:** {{primary-keywords}}
**Website structure:** {{site-structure}}
**Target audience:** {{target-audience}}
**Main content types:** {{content-types}}

## Output
Deliver the strategy as a numbered list with clear headings for each main step and sub-steps where necessary. Make the guide immediately actionable for implementation.
```
