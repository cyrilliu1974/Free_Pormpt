# Team Productivity Trends Analysis Report Prompt

## 簡介

The Team Productivity Trends Analysis Report Prompt is a free AI prompt that produces structured productivity reports with actionable recommendations for managers, analysts, and team leads. This team productivity trends prompt for ChatGPT guides the AI to act as a productivity analyst, examining quantitative metrics like task completion rates and time-to-completion alongside qualitative data from performance reviews. It generates a full report structure including executive summary, methodology, data analysis with visualizations, insights on productivity drivers and bottlenecks, SMART-formatted recommendations, and an implementation plan with success metrics. The prompt runs on ChatGPT, Claude, and Gemini, requiring only your team context as input. Use it when you need to present productivity findings to leadership, identify performance gaps against benchmarks, or build data-backed improvement strategies. ● Structures analysis around both quantitative metrics and qualitative team feedback for balanced insights ● Requires SMART criteria for all recommendations to ensure actionable, measurable outcomes ● Includes data visualization guidance and trend pattern identification over time ● Delivers implementation plans with rollout timelines and success tracking mechanisms ## Prompt

```
## Role
You are a productivity analyst with expertise in team performance measurement, data-driven insights, and operational optimization.

## Task
Analyze team productivity trends and deliver a comprehensive report with actionable recommendations to improve efficiency and output.

## Context
Team: {{team-context}}

Focus on quantitative metrics (task completion rates, time-to-completion, output quality) and qualitative data (team feedback, performance reviews). Analyze trends over time, comparing performance against industry benchmarks and organizational goals. Consider external factors affecting productivity (tool changes, process shifts, workload variations). Ensure all recommendations follow SMART criteria (specific, measurable, achievable, relevant, time-bound). Avoid assumptions without data-backed evidence.

## Output
Deliver your analysis in this structure:

**Executive Summary**

**Introduction**
- Importance of productivity trend analysis for this team

**Methodology**
- Framework for comprehensive productivity analysis
- Data collection approach

**Data Analysis**
- Key metrics and data points examined
- Data visualizations representing productivity trends
- Identified patterns (short-term fluctuations and long-term trends)

**Insights and Findings**
- Core productivity drivers and bottlenecks
- Performance gaps relative to benchmarks and goals

**Actionable Recommendations**
- Prioritized, SMART-formatted recommendations with expected impact

**Implementation Plan**
- Rollout steps and timeline
- Success metrics and tracking mechanisms

**Conclusion**
- Summary and next steps
```
