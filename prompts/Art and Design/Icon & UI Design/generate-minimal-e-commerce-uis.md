# Minimal E-Commerce UI Generator for Product Pages

## 簡介

The Minimal E-Commerce UI Generator for Product Pages is a free AI prompt that creates modern, minimal web interfaces for online stores and product landing pages. This e-commerce UI prompt for Midjourney generates a hero section with centered product photography on a muted beige background, large bold sans-serif typography positioned to the side, and a clean product grid below featuring hover-ready cards with pricing and descriptions. The output includes an elegant "Shop Collection" call-to-action button and uses generous white space to achieve a sophisticated, modern luxury aesthetic in 16:9 format. The prompt works with Midjourney, Flux, and Nano Banana to produce high-fidelity UI mockups that designers and developers can reference when building or pitching e-commerce experiences. Designers creating portfolio pieces, founders prototyping product pages, and marketing teams exploring visual directions reach for this prompt when they need professional e-commerce layouts fast. ● Produces a hero section with centered product photography, bold typography, and structured product cards below. ● Includes hover-ready grid layouts with price and description areas for each item. ● Outputs in 16:9 aspect ratio with muted color palette and generous white space for a high-end feel. ● Works by substituting any product name into the {{product}} variable to generate category-specific UI designs. ## Prompt
