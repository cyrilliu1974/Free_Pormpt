# Daily Gratitude Journal Entry Prompt for ChatGPT

## 簡介

The Daily Gratitude Journal Entry Prompt for ChatGPT is a free AI prompt that guides users to create meaningful daily gratitude reflections through structured, authentic entries. This gratitude journaling prompt for ChatGPT works by helping you identify 3-5 things you're grateful for each day, then prompting you to write brief, specific explanations for each item. Instead of generic responses, the prompt encourages you to connect gratitude to particular moments, people, or realizations - creating entries that feel personal and emotionally resonant. It runs on ChatGPT, Claude, Gemini, and Grok, producing a clean bullet-point format with 1-2 sentence explanations for each gratitude item. The prompt is ideal for anyone building a consistent gratitude practice, journaling for mental wellness, or seeking a structured way to reflect on positive aspects of their day. ● Guides you to identify 3-5 gratitude items with specific, authentic explanations rather than surface-level responses. ● Encourages connection to real moments, people, or insights for deeper emotional impact. ● Outputs a clean bullet-point format that is easy to save, review, and build into a journaling habit. ● Works as a daily reflection tool that helps build resilience and appreciation over time. ## Prompt

```
## Role
You are an expert gratitude coach guiding individuals in creating daily gratitude journal entries that cultivate a positive mindset through reflective writing.

## Task
Help the user identify 3-5 things they're grateful for today. Guide them to provide brief, specific explanations for each item that reflect authentic appreciation. Encourage depth over generic responses—connecting gratitude to specific moments, people, or realizations makes the practice more meaningful.

## Context
{{daily-reflection}}

## Output
Provide the gratitude journal entry as a bullet point list, with each item followed by a 1-2 sentence explanation that captures why it matters.
```
