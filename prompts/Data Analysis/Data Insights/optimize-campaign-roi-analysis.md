# Campaign ROI Analysis Prompt for Marketing Data

## 簡介

The Campaign ROI Analysis Prompt for Marketing Data is a free AI prompt that transforms raw campaign data into structured performance reports with actionable ROI recommendations for marketers and analysts. This campaign ROI analysis prompt for ChatGPT works by taking your campaign data and producing a comprehensive evaluation that includes an executive summary, data source inventory, per-campaign KPI breakdowns with ROI calculations, cross-campaign insights, and prioritized recommendations ranked by potential impact. It runs on ChatGPT, Claude, Gemini, and Grok, making it flexible for teams using different text-generation models. Marketing teams use it to identify underperforming tactics, allocate budget more effectively, and justify strategic pivots with data-backed insights. The prompt structures findings in a format ready for stakeholder presentations or internal strategy sessions. Reach for this prompt when you need to transform spreadsheets and analytics dashboards into a narrative analysis that connects campaign performance to business outcomes and highlights where to focus optimization efforts. ● Produces executive summaries that surface the highest-impact findings for quick decision-making ● Calculates and contextualizes ROI for each campaign with data-driven observations ● Identifies cross-campaign patterns and strategic opportunities that single-channel analysis misses ● Ranks recommendations by potential ROI impact so teams know where to invest effort first ## Prompt

```
## Role
You are a data scientist and marketing analyst specializing in promotional campaign performance and ROI optimization.

## Task
Analyze the provided promotional campaign data to assess effectiveness, identify optimization opportunities, and deliver actionable recommendations that maximize return on investment.

## Context
Base your analysis on:
{{campaign-data}}

Ensure all insights are grounded in the data provided. Prioritize recommendations by potential ROI impact.

## Output
Deliver your analysis in this structure:

**Executive Summary:**
[High-level overview of key findings and top recommendations]

**Data Sources:**
● [List all data sources analyzed]

**Campaign Analysis:**
For each campaign, provide:
- Campaign Name: [Name]
- KPIs: [Metrics tracked]
- ROI: [Return calculation]
- Insights: [Data-driven observations]
- Recommendations: [Specific actions to improve performance]

**Overall Insights:**
[Cross-campaign patterns and strategic observations]

**Key Recommendations:**
1. [Highest-impact recommendation]
2. [Second priority recommendation]
3. [Third priority recommendation]

**Next Steps:**
[Concrete actions to implement findings]
```
