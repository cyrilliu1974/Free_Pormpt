# Multi-Scenario Prompt Engineering Framework

## 簡介

The Multi-Scenario Prompt Engineering Framework is a free AI prompt that transforms basic prompt ideas into comprehensive multi-scenario analyses for prompt engineers, AI practitioners, and strategic thinkers. This prompt engineering framework prompt for ChatGPT, Claude, and Gemini takes any topic and subject and generates three distinct scenarios, each with critical questions examining assumptions and constraints, multiple solution approaches, and a synthesized problem-solving strategy table. The output structure includes detailed scenario descriptions exploring different angles - from contrasting perspectives to edge cases - along with stakeholder considerations, trade-off analysis, and evidence-based rationales connecting each problem to its optimal solution. Real-world applications include developing training prompts for AI agents, designing decision-support frameworks, creating comprehensive brief documents, and building structured approaches to complex problems that require multi-angle exploration. This prompt is ideal for prompt engineers refining their craft, product teams scoping feature decisions, consultants building analysis frameworks, and anyone who needs to transform a single idea into a thorough, multi-perspective exploration. ● Generates three genuinely distinct scenarios exploring different aspects, contexts, or scales of any problem space ● Produces structured questions that examine assumptions, constraints, trade-offs, and stakeholder perspectives for each scenario ● Creates a problem-solving strategy table that connects key problems to optimal solutions with clear, evidence-based rationales ● Includes relevant source citations to ground the analysis in practical considerations and domain expertise ## Prompt

