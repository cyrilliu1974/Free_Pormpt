# Predictive Modeling Curriculum Designer for Analytics

## 簡介

The Predictive Modeling Curriculum Designer for Analytics is a free AI prompt that builds structured, progressive predictive modeling course sessions for data analytics educators and instructional designers. This predictive modeling curriculum prompt for ChatGPT takes your course parameters - student education level, the analytics tool being taught, industry focus, course duration, and prior knowledge - and produces a markdown table mapping session topics, measurable learning objectives, and hands-on exercises. It calibrates content complexity to match learners, structures sessions from foundational to advanced concepts, and ensures each exercise ties directly to session goals. Use it for university courses, corporate training programs, bootcamps, or online analytics education. It works on ChatGPT, Claude, and Gemini. Reach for this prompt when you need to design or redesign a predictive modeling track that balances theory with practical application and builds logically over time. ● Tailors session complexity and prerequisites to match your students' education level and prior analytics knowledge. ● Structures topics in logical progression so each session builds on the last, avoiding knowledge gaps. ● Defines measurable learning objectives and ties hands-on exercises directly to session concepts. ● Outputs a clean markdown table format ready for syllabus documents, LMS uploads, or planning spreadsheets. ## Prompt

```
## Role

You are an expert curriculum designer specializing in data analytics education, focused on predictive modeling pedagogy.

## Task

Create a comprehensive predictive modeling curriculum broken into progressive sessions. Each session must include a topic, clear learning objectives, and hands-on exercises that balance theory with practical application.

## Context

{{course-parameters}}

Include: education level of students, data analytics tool being taught, specific industry focus (if any), total course duration, and students' prior knowledge level.

## Requirements

- Analyze the education level to calibrate content complexity
- Structure sessions in logical progression from foundational to advanced
- Define measurable learning objectives for each session
- Design exercises that reinforce concepts and provide real-world practice
- Ensure each session builds on prior knowledge

## Output

Deliver as a markdown table with three columns:

| Session Topic | Learning Objectives | Hands-on Exercises |
|---------------|---------------------|--------------------|

Ensure logical progression from basic to advanced concepts, with exercises directly tied to each session's topic and objectives.
```
