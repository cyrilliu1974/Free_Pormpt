# Character Design Concept Sheet Generator

## 簡介

The Character Design Concept Sheet Generator is a free AI prompt that produces multiple character design variations in a single image for artists, game developers, and storytellers. This character design prompt for Midjourney works with image generation models including Midjourney, Flux, and Nano Banana to create concept sheets that display several iterations of a character side-by-side on a clean white background in the style of your chosen artist reference. You specify the character type (warrior, robot, fantasy creature), shot type (full body, portrait, three-quarter view), and artistic style, and the prompt returns a professional concept sheet with multiple design variations. Reach for this prompt when you need to explore different visual directions for a character quickly, compare design options, or build a portfolio of concepts for client review. ● Produces concept sheets with multiple character design iterations displayed together for easy comparison ● Works in any artistic style by referencing specific artists or art movements ● Outputs designs on a white background, ideal for presentations, portfolios, and client pitches ● Supports flexible shot types and character archetypes, from full-body to close-up views ## Prompt

```
{{character-type}}, {{shot-type}}, character design, multiple concept designs, concept design sheet, white background, style of {{artist-reference}}, --ar 16:9
```
