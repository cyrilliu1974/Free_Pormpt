# Role-Based Training Framework Builder

## 簡介

The Role-Based Training Framework Builder is a free AI prompt that creates structured employee development programs using the ADDIE instructional design model for corporate training teams and L&D professionals. This role-based training framework prompt for ChatGPT, Claude, Gemini, and Grok walks you through five phases: analyzing skill gaps and role requirements, designing learning objectives and curriculum architecture, developing training modules with clear outcomes and assessments, planning implementation logistics and timelines, and establishing evaluation methods using Kirkpatrick's four levels. It transforms abstract job requirements into actionable training programs with specific deliverables, resource allocations, and performance indicators at every stage. Reach for this prompt when you need to build a competency-based training program from scratch, document learning pathways for a new role, or redesign existing employee development initiatives with measurable outcomes. ● Breaks down role requirements and identifies skill gaps with learner profile assessments and success criteria. ● Designs measurable learning objectives, curriculum architecture, and instructional strategies aligned to performance standards. ● Develops training modules, content formats, practice scenarios, and assessment instruments with clear learning outcomes. ● Plans implementation timelines, resource allocation, logistics, and support structures for program rollout. ● Establishes evaluation frameworks using Kirkpatrick levels 1-4, performance indicators, and continuous improvement processes. ## Prompt

```
## Role

You are an instructional design architect specializing in evidence-based corporate training programs that deliver measurable competency improvements.

## Task

Create a comprehensive, implementation-ready training framework using the ADDIE model (Analysis, Design, Development, Implementation, Evaluation) for the specified role. The framework must translate job requirements into concrete learning pathways that bridge current performance and role expectations.

## Context

**Role & Requirements:**
{{role-and-requirements}}

**Performance Standards:**
{{performance-standards}}

**Training Constraints:**
{{training-constraints}}

## Output

Structure your framework using the five ADDIE phases as primary headings, with detailed subsections in bullet-point format:

### Analysis
- Role requirements breakdown
- Skill gap identification
- Learner profile assessment
- Success criteria definition

### Design
- Learning objectives (specific, measurable)
- Curriculum architecture
- Instructional strategies
- Assessment approach

### Development
- Training modules with clear learning outcomes
- Content formats and materials
- Practice activities and scenarios
- Assessment instruments

### Implementation
- Delivery timeline with milestones
- Resource allocation (budget, personnel, tools)
- Logistics and scheduling
- Support structures

### Evaluation
- Performance indicators (quantitative and qualitative)
- Assessment methods (Kirkpatrick levels 1-4)
- Data collection plan
- Continuous improvement process

Include specific timelines, resource requirements, and measurable outcomes throughout.
```
