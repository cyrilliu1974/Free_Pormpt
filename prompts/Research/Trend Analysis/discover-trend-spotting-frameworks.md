# Trend Spotting Framework Comparison Generator

## 簡介

The Trend Spotting Framework Comparison Generator is a free AI prompt that researches and compares industry-specific trend analysis frameworks for strategists, analysts, and business leaders. This trend spotting prompt for ChatGPT produces a comprehensive markdown table comparing 5-7 frameworks, evaluating each one's key components, data analytics integration, real-world applications, and practical effectiveness. You specify your industry and the data analytics methods you want emphasized - time-series analysis, sentiment tracking, predictive modeling, or any other approach - and the prompt systematically identifies the most relevant frameworks, analyzes how each incorporates your chosen methods, and documents proven use cases. It runs on ChatGPT, Claude, Gemini, and Grok, delivering a side-by-side comparison that saves hours of manual research. Reach for this prompt when you need to evaluate which trend spotting methodology fits your domain, compare competing frameworks on objective criteria, or build a business case for adopting a data-driven trend analysis approach. ● Compares 5-7 state-of-the-art frameworks relevant to your specified industry. ● Documents how each framework integrates your chosen data analytics methods. ● Includes real-world application examples and effectiveness assessments for every entry. ● Outputs a clean markdown table with five columns: Framework Name, Key Components, Data Analytics Integration, Real-World Examples, and Effectiveness Assessment. ## Prompt

```
## Role
You are an expert trend analyst specialized in data-driven insights and framework evaluation.

## Task
Uncover and analyze trend spotting frameworks for the specified industry. Research applicable frameworks, analyze how they incorporate data analytics methods to identify emerging trends, and compile findings into a comprehensive comparison table.

## Context
Industry: {{industry}}
Data analytics methods to emphasize: {{data-analytics-methods}}

## Process
1. Identify the most relevant trend spotting frameworks for the industry
2. Analyze how each framework integrates the specified data analytics methods
3. Evaluate their practical effectiveness with documented real-world applications
4. Organize findings in a structured comparison format

## Output
Present your analysis as a markdown table with these columns:
- Framework Name
- Key Components
- Data Analytics Integration
- Real-World Examples
- Effectiveness Assessment

Include 5-7 frameworks that represent the current state of the art in the industry.
```
