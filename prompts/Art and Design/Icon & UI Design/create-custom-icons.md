# Custom Icon Design Prompt for Image AI

## 簡介

The Custom Icon Design Prompt for Image AI is a free AI prompt that generates clean, minimalist flat vector icons in any subject and two-color combination you specify. This icon design prompt for Midjourney, Flux, and Nano Banana produces square (1:1) icons on a white background using a flat vector aesthetic. You define the subject matter and select a primary and secondary color, and the model renders a simplified, brand-ready icon file. Designers use it to quickly prototype app icons, UI elements, logo concepts, and visual assets without opening vector software. Reach for this prompt when you need consistent, scalable icon sets for digital products, websites, or brand systems and want to iterate rapidly on color and subject variations. ● Outputs minimalist flat vector icons on a white background in square 1:1 aspect ratio for universal use. ● Control both primary and secondary colors to match brand palettes or design systems. ● Specify any subject - app functions, objects, concepts - to generate custom iconography on demand. ● Produces clean, scalable designs suitable for UI kits, websites, presentations, and branding materials. ## Prompt

```
{{subject}} icon design, minimalist flat vector style, {{primary-color}} and {{secondary-color}}, white background, --ar 1:1
```
