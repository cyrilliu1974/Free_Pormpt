# Keyword Research Prompt for SEO Content Planning

## 簡介

The Keyword Research Prompt for SEO Content Planning is a free AI prompt that identifies high-value keywords, analyzes search intent, and recommends content formats for SEO strategists and content creators. This keyword research prompt for ChatGPT walks you through a structured discovery process: brainstorm relevant keywords for any topic, evaluate each for search volume and competition, prioritize terms with strong traffic potential and manageable competition, and select long-tail keywords that capture specific user needs. It concludes with 2-3 content-type recommendations - such as comprehensive guides, comparisons, or tutorials - matched to the keyword set and search intent. The output is a prioritized keyword list with data annotations and a content plan ready to inform your editorial calendar. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need to build an SEO content strategy around a new topic, refresh an existing pillar page, or identify gaps in your keyword coverage. ● Delivers 10-15 primary keywords annotated with search volume and competition metrics ● Identifies 3-5 long-tail keyword variations for targeted, lower-competition opportunities ● Recommends 2-3 content formats aligned with user search intent and keyword themes ● Provides a structured evaluation process covering main themes, subtopics, and common user questions ## Prompt

```
## Role
You are an SEO and content optimization expert conducting keyword research to help optimize web content.

## Task
Identify 10-15 high-value keywords for the given topic, plus 3-5 long-tail variations. Then recommend 2-3 content formats that align with user search intent.

## Process
1. Brainstorm relevant keywords covering main themes, subtopics, and common user questions for {{topic}}
2. Evaluate each keyword for search volume, competition level, and search intent
3. Prioritize keywords with high search volume and low-to-medium competition
4. Select long-tail keywords that attract targeted traffic and cover specific user needs
5. Recommend content types (e.g., comprehensive guide, comparison, tutorial) that match the keyword set and search intent

## Output Format
**Primary Keywords:**
● [Keyword] (Search Volume: [number], Competition: [Low/Medium/High])
● [Keyword] (Search Volume: [number], Competition: [Low/Medium/High])
[Continue for 10-15 keywords]

**Long-tail Keywords:**
● [Long-tail keyword phrase]
● [Long-tail keyword phrase]
[Continue for 3-5 phrases]

**Content Recommendations:**
1. [Content type and rationale based on keyword analysis]
2. [Content type and rationale based on keyword analysis]
3. [Content type and rationale based on keyword analysis]
```
