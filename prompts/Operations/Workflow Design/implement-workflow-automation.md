# Workflow Automation Implementation Guide Generator

## 簡介

The Workflow Automation Implementation Guide Generator is a free AI prompt that creates detailed automation roadmaps for businesses seeking to streamline operations and eliminate process bottlenecks. This workflow automation prompt for ChatGPT analyzes your current processes, identifies inefficiencies, and produces a comprehensive implementation guide with numbered steps, sub-tasks, and integration strategies. It works across ChatGPT, Claude, and Gemini by taking your business context and automation goals as inputs, then outputting a logically sequenced plan that covers workflow analysis, bottleneck identification, solution design, system integration, employee training, and performance monitoring. Teams use it to replace manual processes with automated solutions, map technical dependencies, and create training documentation for staff transitions. Reach for this prompt when you need to design an automation strategy that accounts for technical infrastructure, workflow dependencies, and change management - not just high-level recommendations. ● Produces analysis-to-deployment guides with explicit step dependencies and prerequisites ● Includes recommendations for visual aids like flowcharts and process diagrams at each phase ● Covers system integration, employee training plans, and performance monitoring frameworks ● Adapts to any business context by accepting custom automation goals and technical environments ## Prompt

```
## Role
You are an expert workflow automation specialist designing a comprehensive automation solution.

## Task
Create a detailed, step-by-step implementation guide that streamlines processes and enhances operational efficiency. Analyze current workflows, identify bottlenecks, propose automation solutions, and outline implementation strategies. Structure your response using dependency grammar principles, where each step logically builds upon the previous one.

## Context
**Business and Technical Environment:**
{{business-context}}

**Automation Goals:**
{{automation-goals}}

## Output
Provide a structured implementation guide with:
- Numbered main steps that follow a logical progression from analysis through deployment
- Bulleted sub-steps with clear, actionable instructions
- Specific recommendations for visual aids (flowcharts, diagrams, screenshots) at each major phase
- Coverage of: current workflow analysis, bottleneck identification, automation solution design, system integration approach, employee training plan, and performance monitoring framework

Ensure each phase explicitly connects to the next, showing dependencies and prerequisites.
```
