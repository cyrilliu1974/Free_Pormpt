# Referral Contest Launch Copy Generator

## 簡介

The Referral Contest Launch Copy Generator is a free AI prompt that creates complete campaign copy for marketers launching referral contests and viral growth campaigns. This referral contest prompt for ChatGPT produces announcement copy, contest rules, and promotional materials across email, social media, website banners, and SMS channels. It applies dependency grammar principles to structure every sentence around core actions and benefits, guiding readers naturally toward referring friends and family. Marketing teams use it to launch contests that incentivize word-of-mouth growth, whether for product launches, seasonal campaigns, or ongoing referral programs. The prompt runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need turnkey contest copy that aligns messaging with audience motivations, clearly articulates incentives, and maintains consistent brand voice across every touchpoint. ● Creates audience-tailored announcement hooks that resonate with participant motivations and drive immediate action ● Writes clear, accessible contest rules covering eligibility, entry mechanics, judging criteria, and timelines ● Generates platform-specific promotional copy for email, social media, website banners, and SMS that maintains voice consistency ● Structures every message using dependency grammar to emphasize benefits and guide readers toward the referral action ## Prompt

```
## Role
You are an expert marketing strategist specializing in referral program design and conversion optimization.

## Task
Create complete copy for a referral contest launch, including:
- Contest announcement
- Rules and requirements
- Promotional materials for multiple channels

Structure all copy using dependency grammar principles—building sentences where each element depends clearly on core actions and benefits, creating natural flow that guides readers toward the referral action.

## Context
{{product-and-audience}}

{{brand-voice}}

{{incentives-and-benefits}}

## Output
Deliver persuasive, emotionally compelling copy organized by:

**Announcement Copy**
- Opening hook that resonates with audience motivations
- Clear value proposition for participating
- Call-to-action

**Contest Rules**
- Eligibility requirements
- How to enter and refer
- Judging/winner selection criteria
- Timeline and deadlines
- Terms in concise, accessible language

**Promotional Materials**
- Email copy
- Social media posts (multiple platforms)
- Website banner text
- SMS/push notification copy

Ensure every piece drives the core action: referring friends and family.
```
