# Visual Identity Style Guide Generator for Solopreneurs

## 簡介

The Visual Identity Style Guide Generator for Solopreneurs is a free AI prompt that creates complete brand style guides for independent business owners and solo entrepreneurs. This visual identity prompt for ChatGPT analyzes your solopreneur profile and produces a structured style guide covering four core areas: logo design concepts with usage rules (minimum sizes, clear space, color variations, prohibited uses), a color palette with hex codes and accessibility notes, typography systems specifying font families and size scales, and imagery guidelines defining photography style and visual treatments. The prompt runs on ChatGPT, Claude, Gemini, and Grok, delivering outputs tailored to your brand personality, target audience expectations, and industry context. Use it when launching a new solopreneur brand, refreshing an existing identity, or preparing brand assets for designers and marketing teams. ● Produces logo usage guidelines including size minimums, spacing rules, and common misuse examples ● Specifies primary and secondary color palettes with hex codes and hierarchical usage instructions ● Defines typography systems with font pairings, weight assignments, and size scales for headings and body text ● Establishes imagery direction covering composition, subject matter, mood, filters, and elements to avoid ## Prompt

```
## Role
You are an expert brand strategist developing a comprehensive visual identity style guide for a solopreneur.

## Task
Create a complete style guide that ensures cohesive branding across all platforms and marketing materials. Include:

- **Logo**: Design concept that embodies the brand personality, with usage guidelines (minimum size, clear space, color variations, what not to do)
- **Color Palette**: Primary and secondary colors with hex codes, usage hierarchy, and accessibility considerations
- **Typography**: Font families for headings and body text, size scales, weight usage, and pairing rules
- **Imagery**: Style guidelines for photography and graphics (composition, subject matter, filters/treatments, mood, what to avoid)

## Context
Analyze the solopreneur's brand foundation before developing visual elements:
- Brand essence and personality traits
- Target audience preferences and expectations
- Industry norms and opportunities for differentiation
- Business goals and how visual identity supports them

Ensure all elements work harmoniously together and are practical for implementation across digital and print applications.

## Input
{{solopreneur-profile}}

## Output
Deliver a structured style guide with clear headings for each element (Logo, Color Palette, Typography, Imagery). Use bullet points for specific, actionable guidelines under each section. Include rationale connecting visual choices back to brand strategy.
```
