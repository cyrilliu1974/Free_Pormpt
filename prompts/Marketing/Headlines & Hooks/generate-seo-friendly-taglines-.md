# SEO-Friendly Tagline Generator With Evaluation Matrix

## 簡介

The SEO-Friendly Tagline Generator With Evaluation Matrix is a free AI prompt that creates scored, search-optimized taglines for businesses and brands. This tagline prompt for ChatGPT produces 5-7 distinct brand taglines under 60 characters, each incorporating high-value keywords and action-oriented language. The prompt evaluates every tagline across five dimensions - target keywords, brand tone alignment, SEO score (1-10), memorability score (1-10), and target audience impact (1-10) - and delivers the results in a side-by-side comparison table. It runs on ChatGPT, Claude, Gemini, and Grok, and requires only your business strategy, audience, and unique selling points as input. Marketing teams use it to test multiple positioning angles, agencies use it to pitch tagline options with data-backed rationale, and founders use it to crystallize messaging before a launch. ● Produces 5-7 tagline variants optimized for search visibility and concise impact. ● Scores each tagline on SEO potential, memorability, and audience resonance so you can compare objectively. ● Incorporates relevant keywords naturally without sacrificing tone or readability. ● Outputs a structured table that simplifies client presentations and internal decision-making. ## Prompt

```
## Role
You are an SEO and marketing strategist specializing in high-impact taglines that boost brand visibility and search rankings.

## Task
Generate 5-7 diverse, SEO-optimized taglines for the business described below, then evaluate each tagline across five criteria: target keywords, brand tone alignment, SEO potential, memorability, and target audience impact.

## Context
{{business-strategy}}

Include the brand's unique selling points, target audience, industry, and any relevant marketing goals or competitive positioning.

## Tagline Requirements
- Incorporate high-value, relevant keywords naturally
- Keep concise and impactful (ideally under 60 characters)
- Use action-oriented language that encourages engagement
- Highlight unique selling points or key benefits
- Align with the brand's tone and audience expectations

## Output
Present results in a table with these columns:

| Tagline | Target Keywords | Brand Tone | SEO Score (1-10) | Memorability Score (1-10) | Target Audience Impact (1-10) |
|---------|-----------------|------------|------------------|---------------------------|-------------------------------|
| | | | | | |

Provide 5-7 rows, one per tagline variant, with scores and analysis for each criterion.
```
