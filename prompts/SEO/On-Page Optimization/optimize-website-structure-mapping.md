# Website Structure Mapping for SEO Optimization

## 簡介

The Website Structure Mapping for SEO Optimization is a free AI prompt that analyzes any website URL and produces a comprehensive multi-level hierarchy showing optimal site architecture for user experience and search engine performance. This website structure prompt for ChatGPT takes a URL as input and returns a detailed mind map with main categories, subcategories, and key pages organized into a logical, intuitive flow that keeps content within 3-4 clicks of the homepage, supports topical clustering for SEO, and identifies opportunities for navigation improvements. It works across ChatGPT, Claude, Gemini, and Grok to deliver actionable site architecture recommendations alongside the visual hierarchy. Use it when redesigning a site, auditing information architecture, planning content migrations, or building SEO-friendly navigation that balances discoverability with crawl efficiency. ● Analyzes existing websites or plans greenfield architecture with clear parent-child page relationships ● Identifies orphaned pages, excessive depth, and consolidation opportunities that hurt crawlability ● Groups related content into thematic clusters that strengthen topical authority and internal link equity ● Delivers 3-5 specific recommendations for navigation improvements and SEO enhancements ## Prompt

```
## Role
You are an experienced website architect specializing in logical, intuitive site structures optimized for user experience and search engine navigation.

## Task
Analyze the provided website and develop a comprehensive mind map showcasing an optimal site structure. Create a detailed, multi-level hierarchy that demonstrates:

- Main categories, subcategories, and key pages
- Clear hierarchical relationships
- User-friendly navigation flow
- SEO best practices (logical URL paths, proper depth, topical clustering)

## Context
Website to analyze: {{website-url}}

## Constraints
- Prioritize clarity over complexity—avoid structures that confuse users or create orphaned pages
- Keep site depth reasonable (typically 3-4 clicks from homepage to any page)
- Ensure each category serves the website's purpose and target audience
- Group related content to support topical authority and internal linking

## Output
Deliver your analysis in this format:

**Website:** [URL]

**Mind Map: Optimized Site Structure**

- Main Category 1
  - Subcategory 1.1
    - Page 1.1.1
    - Page 1.1.2
  - Subcategory 1.2
    - Page 1.2.1
    - Page 1.2.2
- Main Category 2
  - Subcategory 2.1
    - Page 2.1.1
    - Page 2.1.2
  - Subcategory 2.2
    - Page 2.2.1
    - Page 2.2.2
- Main Category 3
  - [continue pattern]

**Recommendations:**
[Provide 3-5 specific insights about navigation improvements, missing pages, consolidation opportunities, or SEO enhancements]
```
