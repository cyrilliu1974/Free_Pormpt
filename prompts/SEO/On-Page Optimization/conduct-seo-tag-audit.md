# SEO Heading Tag Audit Prompt for ChatGPT

## 簡介

The SEO Heading Tag Audit Prompt is a free AI prompt that conducts a comprehensive on-page SEO analysis of H1 and H2 tags across any website URL, delivering actionable optimization recommendations for search visibility. This heading tag audit prompt for ChatGPT systematically examines every H1 and H2 element on a specified site, evaluating how effectively each incorporates primary keywords and aligns with SEO best practices. It runs on ChatGPT, Claude, and Gemini, producing a structured report that marks well-optimized tags with ✅ and problematic ones with ❌, complete with specific suggestions for each heading. SEO professionals use it to identify quick wins in on-page optimization, content teams rely on it to audit landing pages before launch, and agencies deploy it for client site audits that pinpoint exactly where keyword strategy falls short. Reach for this prompt when you need a systematic review of heading structure rather than manual page-by-page inspection, or when preparing a data-backed optimization roadmap for stakeholders. ● Evaluates every H1 and H2 tag on a website URL for keyword relevance and SEO impact ● Provides clear pass/fail markers and tailored suggestions for each heading element ● Generates 3-5 concrete, site-specific recommendations based on audit findings ● Outputs a structured report format that non-technical stakeholders can act on immediately ## Prompt

```
## Role
You are an expert SEO strategist specializing in on-page optimization.

## Task
Conduct a comprehensive audit of the H1 and H2 tags across the provided website, analyzing their effectiveness in incorporating primary keywords for SEO.

## Context
Website URL: {{website-url}}

## Output
Provide your analysis in the following structure:

**Website URL:** [Display the URL]

**H1 Tag Analysis:**
For each H1 tag found:
- Use ✅ for well-optimized tags and ❌ for poorly optimized tags
- H1 Tag: [exact text]
  - Analysis: [brief evaluation of keyword usage, relevance, and optimization]
  - Suggestion: [specific, actionable improvement recommendation]

**H2 Tag Analysis:**
For each H2 tag found:
- Use ✅ for well-optimized tags and ❌ for poorly optimized tags
- H2 Tag: [exact text]
  - Analysis: [brief evaluation of keyword usage, relevance, and optimization]
  - Suggestion: [specific, actionable improvement recommendation]

**Overall Recommendations:**
Provide 3-5 specific, actionable recommendations for improving the site's heading tag strategy and keyword implementation. Avoid generic advice; focus on concrete next steps tailored to the findings.
```
