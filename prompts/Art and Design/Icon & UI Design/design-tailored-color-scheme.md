# Color Scheme Generator for UI/UX Design

## 簡介

The Color Scheme Generator for UI/UX Design is a free AI prompt that creates accessible, brand-aligned color palettes for digital products tailored to specific audiences. This UI color scheme prompt for ChatGPT walks you through brand identity translation, audience psychology mapping, accessibility validation against WCAG standards, and practical application across UI components. It produces complete primary and secondary palettes with hex codes, psychological rationale for each color choice, contrast compliance confirmation for users with color vision deficiencies, and detailed guidance on applying colors to buttons, navigation, backgrounds, and interactive elements. Designers use it when starting a new interface project, rebranding an existing product, or ensuring their color choices meet accessibility requirements while resonating emotionally with their target users. It runs on ChatGPT, Claude, Gemini, and Grok. ● Translates brand values into color language grounded in color psychology principles ● Validates all combinations against WCAG contrast requirements and color blindness considerations ● Maps audience demographics and psychographics to color preferences and emotional responses ● Provides hex codes, rationale, and concrete application examples for every UI element ## Prompt

```
## Role

You are an expert UI/UX designer specializing in color theory, color psychology, accessibility standards, and current design trends for digital products.

## Task

Create a comprehensive color scheme proposal for {{website-or-app-type}} that resonates with {{target-audience}} while reflecting the brand's core identity and values.

## Context

The color scheme must balance brand expression, audience appeal, accessibility compliance (including color blindness and visual impairments), and contemporary design trends. Base all recommendations on color psychology principles, WCAG accessibility guidelines, and industry best practices.

## Process

1. **Brand translation**: Analyze how the brand's identity and values translate into color language (e.g., sustainability → earth tones, innovation → cool futuristic hues).

2. **Audience psychology**: Map the target audience's demographic and psychographic characteristics to color preferences and emotional responses.

3. **Trend assessment**: Identify prevailing design trends in the relevant industry (minimalist palettes, bold vibrant colors, pastels, etc.).

4. **Accessibility validation**: Ensure all color combinations meet WCAG contrast requirements and remain distinguishable for users with color vision deficiencies.

5. **Primary palette**: Define 2-3 main brand colors with rationale explaining each choice and its psychological impact on the target audience.

6. **Secondary accents**: Select complementary colors for highlights, calls-to-action, and emphasis elements that enhance but don't overpower the primary palette.

7. **Application examples**: Demonstrate the color scheme in context—show how it applies to buttons, navigation, backgrounds, and other UI components through descriptions or mockup concepts.

## Output

Deliver a detailed color scheme proposal that includes:

- Complete primary and secondary color palettes with hex codes
- Psychological and strategic rationale for each color choice
- Accessibility compliance confirmation
- Practical application guidance for key UI elements
- Visual descriptions or mood board concepts showing the scheme in use
```
