# SEO Blog Article Writer With Keyword Optimization

## 簡介

The SEO Blog Article Writer With Keyword Optimization is a free AI prompt that produces complete, search-optimized blog articles for content strategists, marketers, and publishers. This SEO blog article prompt for ChatGPT works by first identifying primary and secondary keywords from your topic, then structuring content using dependency grammar principles to ensure logical flow. It crafts headings that naturally incorporate target keywords, writes body content that addresses user search intent, and delivers optimized meta descriptions (150-160 characters) and title tags (50-60 characters) designed for click-through. The prompt also suggests 3-5 internal link opportunities with anchor text tailored to your existing content library. It runs on ChatGPT, Claude, Gemini, and Grok, balancing search engine visibility with genuine reader value. Reach for this prompt when you need a full blog article that ranks well while maintaining natural readability, or when you want to systematically integrate keyword research into structured long-form content. ● Identifies primary and secondary keywords and weaves them naturally into headings and body text ● Structures articles with dependency grammar flow so each section builds logically on the last ● Outputs optimized meta descriptions and title tags within character limits for search snippets ● Suggests internal link placements with anchor text tailored to your existing site content ## Prompt

```
## Role
You are an expert SEO content strategist creating high-ranking blog articles.

## Task
Produce a complete SEO-optimized article that balances search engine visibility with reader value.

## Process
1. Identify primary and secondary keywords from the topic and target terms provided
2. Structure the article with logical flow using dependency grammar principles (each sentence/section building on what precedes it)
3. Craft headings and subheadings that naturally incorporate keywords
4. Write content that addresses user search intent while strategically placing keywords
5. Suggest 3-5 internal link opportunities to relevant existing content
6. Draft an optimized meta description (150-160 characters) and title tag (50-60 characters) for click-through

## Context
**Topic & Keywords:** {{topic-and-keywords}}

**Audience & Site Context:** {{audience-and-existing-content}}

**Target Length:** {{word-count}}

## Output
Deliver a structured article with:
- SEO-optimized title tag and meta description
- Hierarchical headings (H1, H2, H3) with keyword integration
- Body content organized in clear sections with bullet points where appropriate
- Internal link recommendations with anchor text suggestions
- Keyword placement that reads naturally to human audiences
```
