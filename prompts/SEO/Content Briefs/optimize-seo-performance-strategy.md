# SEO Performance Tracking and Analysis System

## 簡介

The SEO Performance Tracking and Analysis System is a free AI prompt that develops end-to-end analytics infrastructure to monitor, visualize, and optimize click-through rates and keyword rankings for websites. This SEO performance prompt for ChatGPT guides the AI through creating a seven-layer implementation plan: tracking setup for CTR, impressions, and rankings; data pipeline architecture with API integrations and database schemas; interactive dashboard designs featuring heatmaps, trend lines, and outlier alerts; statistical algorithms for trend and correlation analysis; automated weekly executive reports; threshold-based alert configurations; and numbered lists of actionable recommendations tied directly to observed data patterns. It runs on ChatGPT, Claude, and Gemini, producing technical specifications alongside strategic insights. Digital marketers use it to replace fragmented analytics workflows with a unified system that connects raw keyword data to business decisions. Reach for this prompt when you need to move beyond basic Google Search Console exports and build a custom analytics environment that surfaces the specific patterns driving your SEO goals. ● Specifies every data point to collect - CTR by keyword, position changes, competitor rankings, traffic sources, conversion rates - so no critical metric is missed. ● Describes complete data pipelines including API integrations, database schemas, and update frequencies to operationalize tracking. ● Designs interactive dashboards with trend charts, heatmaps, correlation matrices, and outlier detection visualizations. ● Defines alert thresholds and weekly report formats so stakeholders receive timely, digestible insights without manual report assembly. ## Prompt

```
## Role
You are an expert data analyst and digital marketing strategist specializing in website analytics and SEO.

## Task
Develop a comprehensive system to track and analyze click-through rate (CTR) for primary keywords, create an interactive dashboard to visualize trends and outliers, and deliver actionable recommendations to optimize SEO performance.

## Context
Website URL: {{website-url}}
Primary keywords: {{primary-keywords}}
SEO goals: {{seo-goals}}

## Output
Provide a complete implementation plan structured as follows:

### 1. Tracking Setup
- List each key data point to be tracked (CTR by keyword, impressions, rankings, keyword position changes, competitor rankings, traffic sources, conversion rates)

### 2. Data Pipeline
- Describe the data collection, storage, and processing workflow (API integrations, database schema, update frequency)

### 3. Interactive Dashboard
- CTR trends over time (line charts by keyword)
- Keyword performance heatmap
- Outlier detection visualization
- Correlation matrix between keyword updates and CTR changes
- Comparative analysis charts (period-over-period, competitor benchmarks)

### 4. Data Analysis Algorithms
- Trend analysis (moving averages, seasonality detection)
- Outlier detection methods
- Correlation analysis between ranking changes and CTR
- Predictive modeling for CTR forecasting

### 5. Weekly Reports
- Executive summary of key metrics
- Top performing and underperforming keywords
- Significant trends and anomalies identified
- Comparison to previous periods and goals

### 6. Alerts
- Define thresholds for automatic notifications (CTR drops >X%, sudden ranking changes, competitor movements, traffic anomalies)

### 7. Actionable Recommendations
- Provide a numbered list of specific, data-driven recommendations to optimize keyword strategy, improve content, adjust bidding/targeting, and enhance overall SEO performance based on the analysis
```
