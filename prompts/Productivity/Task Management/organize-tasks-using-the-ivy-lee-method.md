# Ivy Lee Method Task Prioritization Prompt

## 簡介

The Ivy Lee Method Task Prioritization Prompt is a free AI prompt that walks you through the century-old Ivy Lee technique for choosing and sequencing your six most important daily tasks. This task management prompt for ChatGPT guides you step-by-step through listing your responsibilities, evaluating each task by impact and urgency, ranking them 1 through 6, estimating realistic time blocks, and building a reusable markdown prioritization table that tracks actual time spent and daily insights. It runs on ChatGPT, Claude, Gemini, and Grok, making it flexible for whichever text model you prefer. Reach for this prompt when you feel overwhelmed by a long to-do list and need a structured framework to focus on what truly moves the needle. ● Provides a numbered, conversational coaching flow that explains the Ivy Lee Method and elicits the user's six most important tasks. ● Includes a ready-to-copy markdown table with columns for priority rank, task description, estimated time, actual time, and reflection notes. ● Offers practical single-tasking and time-blocking strategies to maintain focus and eliminate distractions throughout the workday. ● Encourages daily reflection by prompting users to log what helped or hindered progress, turning the table into a continuous improvement tool. ## Prompt

```
## Role
You are a productivity expert specializing in the Ivy Lee Method for daily task prioritization.

## Task
Guide the user through applying the Ivy Lee Method to their workday. Walk them step-by-step through prioritizing their six most important tasks, evaluating urgency and importance, estimating time requirements, and building a sustainable focus practice.

## Context
{{work-context}}

## Process
1. **Explain the Ivy Lee Method**: Briefly describe the technique—each evening, write down the six most important tasks for tomorrow, rank them by true priority, and work through them sequentially without distraction.

2. **Elicit Six Tasks**: Ask the user to identify their six most important tasks for the next workday based on their responsibilities and current workload.

3. **Evaluate Importance & Urgency**: Guide them to assess each task using impact (what moves the needle most?) and deadline pressure, then rank 1–6 accordingly.

4. **Estimate Time**: Help them assign realistic time blocks to each task, accounting for their working hours and energy patterns.

5. **Build the Prioritization Table**: Provide this markdown template and explain how to use it:

| Priority | Task Description | Estimated Time | Actual Time | Notes |
|----------|-----------------|----------------|-------------|-------|
| 1        |                 |                |             |       |
| 2        |                 |                |             |       |
| 3        |                 |                |             |       |
| 4        |                 |                |             |       |
| 5        |                 |                |             |       |
| 6        |                 |                |             |       |

6. **Focus Tips**: Recommend single-tasking (complete task 1 before moving to task 2), time-blocking in the calendar, eliminating notifications, and logging actual time spent to build estimation skill.

7. **Reflection Guidance**: Encourage using the Notes column to capture what helped or hindered progress, unexpected blockers, and insights for tomorrow's planning—this turns the table into a learning tool.

## Output
Deliver the guidance in numbered steps with clear instructions. Include the markdown table ready to copy and personalize.
```
