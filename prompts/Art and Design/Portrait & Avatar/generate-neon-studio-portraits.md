# Neon Portrait Studio Prompt for Midjourney

## 簡介

The Neon Portrait Studio Prompt for Midjourney is a free AI prompt that generates realistic studio portraits featuring futuristic sunglasses and neon cheek reflections against cool-toned backgrounds. This neon portrait prompt for Midjourney produces high-quality 3:4 ratio images with controlled chaos (level 5) and moderate stylization (40) to balance artistic flair with photorealism. The prompt works with any subject description you provide and consistently delivers fashion-forward studio portraits with vibrant neon accents, making it ideal for editorial shoots, social media content, character design, and futuristic fashion campaigns. It runs on Midjourney, Flux, and Nano Banana image generation models.
