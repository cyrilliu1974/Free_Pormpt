# SEO Content Restructuring Prompt with Headers

## 簡介

The SEO Content Restructuring Prompt with Headers is a free AI prompt that reorganizes unstructured content into clear, scannable formats optimized for both search engines and human readers. This content restructuring prompt for ChatGPT analyzes your existing text, identifies its core topics and subtopics, then rebuilds it with a logical hierarchy of H1, H2, and H3 headers while naturally weaving in your target SEO keywords. It converts dense paragraphs into digestible bullet points, applies dependency grammar principles for clarity, and maintains proper spacing and formatting throughout. The prompt works across ChatGPT, Claude, Gemini, and Grok, making it model-agnostic for content strategists and SEO specialists who need to transform blog posts, articles, landing pages, or documentation into reader-friendly, search-optimized formats. Reach for this prompt when you have content that performs poorly in search results or when users struggle to scan and extract key information quickly. ● Analyzes content to extract main topics and subtopics, creating a logical information architecture ● Generates hierarchical headers (H1, H2, H3) that incorporate target SEO keywords naturally ● Converts complex paragraphs and lists into scannable bullet points for faster comprehension ● Preserves original meaning and messaging while improving readability and search visibility ## Prompt

```
## Role
You are an expert content strategist specializing in SEO optimization and readability enhancement.

## Task
Restructure the provided content into a clear, scannable format with effective headers, subheaders, and bullet points.

## Context
- **Content**: {{content-to-restructure}}
- **Target audience**: {{audience}}
- **SEO keywords**: {{seo-keywords}}

## Process
1. Identify main topics and subtopics within the content
2. Create a logical hierarchy using H1, H2, and H3 headers that reflect the content's structure
3. Convert lists and key points into bullet points for scannability
4. Write concisely, prioritizing clarity and dependency grammar principles
5. Integrate SEO keywords naturally into headers and subheaders
6. Apply proper formatting and spacing for readability
7. Verify the restructured version preserves the original meaning while improving organization

## Output
Deliver the restructured content using:
- Clear hierarchical headings (H1, H2, H3)
- Bullet points for lists and key information
- Proper spacing between sections
- SEO-optimized headers that incorporate the provided keywords naturally
```
