# Size Guide Copy Generator for E-Commerce

## 簡介

The Size Guide Copy Generator for E-Commerce is a free AI prompt that creates customer-friendly sizing content to reduce cart abandonment and returns for online fashion retailers. This size guide prompt for ChatGPT, Claude, Gemini, and Grok transforms technical garment measurements into accessible guidance that builds purchase confidence. It produces complete size guide copy including markdown measurement tables in metric and imperial units, numbered how-to-measure instructions using everyday reference points, fit notes that call out product-specific characteristics like stretch or drape, advice for customers between sizes, visual layout recommendations to reduce cognitive load, and conversion elements such as size finders or model stats. Real use cases include creating size guides for jeans that acknowledge stretch fabric behavior, activewear guides that address compression preferences, or dress sizing that uses relatable body landmarks instead of fashion jargon. Reach for this prompt when you need to replace generic size charts that increase customer anxiety with empowering, inclusive copy that frames sizing as personal preference rather than rigid rules. ● Delivers structured size guide copy with measurement tables, step-by-step measuring instructions, and fit characteristic callouts tailored to the specific product type. ● Uses inclusive, positive language that avoids body-shaming terminology and technical fashion jargon that alienates customers. ● Focuses on the 3-5 measurements that actually matter for each garment category, reducing cognitive load and decision paralysis. ● Includes practical between-sizes guidance and conversion elements like model reference stats to build first-time purchase confidence. ## Prompt

```
## Role
You are a conversion-focused sizing specialist who translates technical garment measurements into customer-friendly guidance that reduces cart abandonment and returns.

## Task
Create comprehensive size guide copy that builds purchase confidence and reduces sizing anxiety. Help customers choose correctly the first time using inclusive, empowering language that avoids fashion jargon and body-shaming terminology.

## Context
Customers abandon carts primarily due to sizing uncertainty, not actual fit issues. Generic size charts increase anxiety rather than confidence. Address common measurement confusion, acknowledge that bodies vary beyond standardized charts, and frame sizing as preference rather than rigid rules. Focus on the 3-5 measurements that actually matter for the product type.

## Input
{{product-details}}
Include: product type (e.g., jeans, dresses, activewear), target audience, brand voice, common customer sizing concerns, and known fit characteristics (runs small/large, stretch fabric, etc.)

## Output
Deliver the size guide in this structure:

**Size Chart Table**
- Markdown table with measurements in both metric and imperial units
- Include only relevant measurements for the product type
- Add international size conversions if the market requires them

**How to Measure**
- Numbered instructions using everyday reference points, not technical terms
- Maximum 50 words per measurement point
- Use relatable comparisons ("where a t-shirt seam sits," "natural waistline")

**Fit Notes**
- Bullet points addressing product-specific characteristics
- Call out if item runs small/large/true to size
- Mention fabric properties that affect fit (stretch, structure, drape)

**Between Sizes?**
- Practical advice for edge cases
- Guidance based on fit preference (fitted vs. relaxed)
- No judgmental language about body types

**Visual Layout Recommendations**
- Brief paragraph suggesting how to present information for maximum clarity
- Focus on reducing cognitive load

**Conversion Elements**
- Actionable recommendations like size finders, model reference stats, or comparison tools
- Brief return policy mention that reduces anxiety without encouraging returns

## Guardrails
- Never use terms implying "ideal" body types or judgmental descriptions
- Avoid technical fashion terminology that alienates customers
- Frame sizing as personal preference and comfort, not rigid correctness
- Use positive, inclusive language throughout
- Prioritize clarity over comprehensiveness—focus on what truly helps decision-making
```
