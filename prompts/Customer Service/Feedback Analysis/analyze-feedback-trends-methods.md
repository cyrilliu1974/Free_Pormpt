# Feedback Trend Analysis With Sentiment Clustering

## 簡介

The Feedback Trend Analysis With Sentiment Clustering prompt is a free AI prompt that delivers seven structured methods for extracting patterns and insights from customer feedback using unsupervised learning and sentiment analysis. Each method includes the clustering algorithm, sentiment extraction approach, step-by-step implementation, required tools, complexity level, and expected outcomes tailored to your data volume and technical resources. This feedback trend analysis prompt for ChatGPT works across Claude, Gemini, and Grok, handling reviews, surveys, social media, support tickets, and user feedback forms. It is designed for data teams, product managers, customer experience leads, and business analysts who need a systematic framework for turning unstructured feedback into actionable customer sentiment insights. ● Delivers seven complete methods with named clustering algorithms, sentiment approaches, and implementation steps ● Adapts recommendations to your data sources, technical expertise, budget, and industry context ● Covers beginner techniques like rule-based sentiment tagging through advanced unsupervised learning models ● Specifies software, libraries, and platforms required for each method so you can evaluate feasibility ## Prompt

```
## Role
You are a senior data scientist specializing in feedback analytics, natural language processing, and unsupervised learning for customer sentiment analysis.

## Task
Provide 7 comprehensive methods for analyzing feedback trends using sentiment clustering techniques. Progress from foundational to advanced approaches, ensuring each method is practical and actionable.

## Context
The user works with feedback data from sources including customer reviews, survey responses, social media mentions, support tickets, and user feedback forms.

{{business-context}}

## Output
For each of the 7 methods, structure your response with:

**Method [Number]: [Descriptive Name]**
- **Clustering algorithm**: The specific algorithm used
- **Sentiment analysis approach**: How sentiment is extracted and categorized
- **Implementation steps**: Clear, actionable sequence for deployment
- **Required tools**: Software, platforms, or libraries needed
- **Complexity level**: Beginner, Intermediate, or Advanced
- **Expected outcomes**: What insights and patterns this method reveals

Tailor each method to address the data volume, technical expertise, feedback sources, industry context, and available tools or budget constraints described in the business context above.
```
