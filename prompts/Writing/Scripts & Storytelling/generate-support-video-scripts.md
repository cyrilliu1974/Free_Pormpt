# Video Tutorial Script Generator for Products

## 簡介

The Video Tutorial Script Generator for Products is a free AI prompt that produces complete, camera-ready instructional video scripts for any product or service. This video tutorial script prompt for ChatGPT creates three distinct tutorials targeting beginner, intermediate, and advanced skill levels. Each script includes a descriptive title, estimated duration, three measurable learning objectives, and a timestamped breakdown pairing narration with specific visual cues in the format "00:00 – [Action] | Visual: [on-screen element]." The prompt closes each set with three supplementary resources such as documentation links, practice exercises, or community forums. It runs on ChatGPT, Claude, Gemini, and Grok, producing structured text output that content teams, customer success managers, and instructional designers can hand directly to video editors or voice-over artists. Reach for this prompt when you need production-ready tutorial scripts that eliminate guesswork and maintain clarity across different audience levels. ● Produces three tutorials per run, each tailored to a specific skill level or product aspect ● Includes timestamped script segments paired with visual cues for editors and producers ● Outputs three measurable learning objectives per tutorial to align with instructional design standards ● Appends three supplementary resources viewers can explore after watching ## Prompt

```
## Role

You write video tutorial scripts for instructional use.

## Task

Produce three video tutorial scripts for {{product-or-service}}. Each tutorial should target a different skill level (beginner, intermediate, advanced) or cover a distinct aspect of the product.

For each tutorial, provide:

- **Title**
- **Description** (one to two sentences on what the video covers)
- **Estimated duration**
- **Target audience** (skill level: beginner / intermediate / advanced)
- **Learning objectives** (exactly three, written as measurable outcomes)
- **Script** with timestamps and visual cues in the format:
  - `00:00 – [Action/narration] | Visual: [what appears on screen]`

After the three tutorials, list three supplementary resources viewers can use to go deeper (documentation links, related tools, practice exercises, or community forums).

## Guidelines

- Write for the stated skill level. Do not assume prior knowledge beyond what that level implies.
- Use plain language. Cut jargon unless the audience level requires it.
- Keep scripts step-by-step and specific. Vague directions are not useful on camera.
- Chunk information, reinforce key steps, and signal transitions clearly.
- Each script should feel ready to shoot, not a template.

## Output Format

**Tutorial 1:**

Title: [Clear, descriptive title]

Description: [One to two sentences]

Duration: [e.g., 3–4 minutes]

Target Audience: [Beginner / Intermediate / Advanced]

Learning Objectives:
- [Objective 1]
- [Objective 2]
- [Objective 3]

Script:
00:00 – Introduction and overview | Visual: Product interface, key feature highlighted
00:30 – Step 1: [Action] | Visual: [Screen or demo view]
01:15 – Step 2: [Action] | Visual: [Screen or demo view]
...

---

**Tutorial 2:**

[Same structure]

---

**Tutorial 3:**

[Same structure]

---

**Additional Resources:**
- [Resource 1: type and brief description]
- [Resource 2: type and brief description]
- [Resource 3: type and brief description]
```
