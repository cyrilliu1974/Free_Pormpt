# CRM Dashboard Framework Design Prompt

## 簡介

The CRM Dashboard Framework Design Prompt is a free AI prompt that builds structured analytics dashboards for customer relationship management, focusing on lifetime value, churn prediction, purchase behavior, and conversion funnel performance. This CRM dashboard prompt for ChatGPT, Claude, Gemini, and Grok walks you through strategic discovery, tiered KPI architecture (executive, operational, tactical), and visualization strategy with specific chart types for trend analysis, cohort comparisons, and predictive indicators. It outputs a complete framework including KPI definitions, calculation methods, dashboard layout priorities, refresh frequencies, and alert thresholds tailored to your business context. Marketing ops teams, revenue leaders, and CRM managers use it to move beyond vanity metrics and design dashboards that surface early warning signals and growth levers. ● Produces a tiered dashboard architecture with primary KPIs for executives, secondary metrics for managers, and drill-down views for tactical teams. ● Covers customer lifetime value optimization, churn prediction and prevention, purchase behavior patterns, and conversion funnel performance with specific calculation formulas. ● Maps visualization types to each metric category - trend lines, cohort tables, predictive gauges - so insights are immediately interpretable. ● Delivers an implementation roadmap with layout priorities, data refresh schedules, and alert thresholds for proactive management. ## Prompt

```
## Role

You are a CRM analytics consultant specializing in dashboard design that transforms customer data into revenue-driving insights.

## Task

Design a comprehensive CRM dashboard framework with strategic KPI selection and visualization recommendations. Address:

- **Tiered architecture**: primary KPIs for executive overview, secondary metrics for operational management, and drill-down capabilities for tactical analysis
- **Four core pillars**: customer lifetime value optimization, churn prediction and prevention, purchase behavior patterns, and conversion funnel performance
- **Visualization strategy**: specific chart types (trend analysis, cohort comparisons, predictive indicators) that make complex data immediately interpretable
- **Implementation guidance**: dashboard layout, refresh frequencies, and alert thresholds that enable proactive management

## Context

{{business-context}}

Provide specific KPI definitions, calculation methods, recommended visualization types, and implementation priorities tailored to this environment.

## Output

Structure your response with these sections:

1. **Strategic Discovery Summary** - key insights from the business context
2. **Dashboard Architecture** - tiered structure with specific KPIs for each level
3. **Core Pillar Metrics** - detailed KPIs for each of the four pillars with calculation formulas
4. **Visualization Recommendations** - chart types mapped to each metric category
5. **Implementation Roadmap** - layout priorities, refresh schedules, and alert configurations
```
