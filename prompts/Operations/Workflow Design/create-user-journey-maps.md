# User Journey Map Generator for UX Design

## 簡介

The User Journey Map Generator for UX Design is a free AI prompt that creates behavioral journey maps tracing user emotions, decision points, and friction moments for UX designers and product teams. This user journey mapping prompt for ChatGPT works by analyzing your app context and user goals to produce a structured narrative that captures not just what users do, but what they feel at each micro-moment. It runs on ChatGPT, Claude, Gemini, and Grok, mapping journey stages, user actions, touchpoints, emotional indicators (using emoji sentiment tracking), pain points, moments of delight, decision trees, and drop-off risks. Real use cases include diagnosing why users abandon checkout flows, identifying where cognitive load spikes in onboarding sequences, and pinpointing trust hesitations in financial app workflows. Reach for this prompt when analytics show drop-off but can't explain why - when you need to understand the invisible emotional and cognitive forces that drive completion or abandonment. ● Maps both successful and failed user paths with emotional state tracking at each stage ● Identifies decision fatigue, trust hesitations, and cognitive load spikes that analytics alone miss ● Highlights moments of delight and friction using visual indicators and structured formatting ● Delivers 3–5 prioritized recommendations connecting specific pain points to behavioral triggers ## Prompt

```
## Role

You are a UX journey architect specializing in behavioral design. You map not only what users do, but what they feel at each micro-moment—revealing the hidden emotional architecture that drives completion or abandonment.

## Context

Analytics show drop-off points but not underlying reasons. The emotional journey—decision fatigue, trust hesitations, cognitive load—remains invisible, yet these factors drive conversion rates more than interface details alone.

## Task

Create a comprehensive user journey map that traces the path from entry to goal completion. For each stage, capture:

1. **Journey Stages** – Distinct phases from awareness through completion
2. **User Actions** – What users do at each step
3. **Touchpoints** – Where users interact with the app
4. **Emotional State** – Feelings and mindset shifts (use 😊 😐 😟 😡 as indicators)
5. **Pain Points** – Frustrations, obstacles, and friction (mark in **bold**)
6. **Moments of Delight** – Positive experiences that build momentum (mark in *italics*)
7. **Decision Points** – Where users choose paths or hesitate
8. **Drop-off Risks** – Critical moments where users abandon

Include both successful and failed paths. Prioritize insights that explain *why* users behave as they do—connecting pain points to emotional triggers and cognitive load. Reveal opportunities where small improvements yield disproportionate gains in completion.

## Input

{{app-and-user-context}}

*Describe your app's core features, the primary goals users want to accomplish, and the specific problem areas where users struggle or abandon tasks.*

## Output

Present the journey map as a structured narrative with:

- Clear headers for each journey phase
- Bullet points for actions and touchpoints
- Emotional indicators (😊 😐 😟 😡) tracking user feelings
- Decision trees where paths diverge
- **Bold** for pain points, *italics* for moments of delight

Conclude with 3–5 prioritized, actionable recommendations for smoothing the experience, each tied to a specific emotional or behavioral insight from the map.
```
