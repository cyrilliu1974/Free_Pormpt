# Content Performance Metrics Analysis Prompt

## 簡介

The Content Performance Metrics Analysis Prompt is a free AI prompt that helps content strategists, marketers, and analysts evaluate content effectiveness and identify concrete improvements. This content performance metrics prompt for ChatGPT takes your content type, primary goal, target audience, top-performing metric, and biggest challenge, then produces a markdown table with four columns: Metric, Current Performance, Goal, and Action Items. It covers at least five key performance indicators - engagement rates, conversion metrics, audience reach, and others relevant to your specific content - and delivers measurable, actionable steps to bridge the gap between where you are and where you want to be. The prompt runs on ChatGPT, Claude, Gemini, and Grok, making it flexible for any text-generation workflow. Use this prompt when you need to turn scattered analytics into a clear, side-by-side performance review that connects numbers to next steps. It is built for content managers, digital marketers, social media strategists, and anyone responsible for demonstrating ROI or iterating on content strategy. ● Outputs a markdown table comparing current metrics to goals with specific, measurable action items for each gap. ● Covers engagement, conversion, reach, and other KPIs tailored to your content type and primary goal. ● Factors in your target audience and biggest challenge to surface the most relevant improvement strategies. ● Delivers analysis in a clean, shareable format that stakeholders and teams can act on immediately. ## Prompt

```
## Role
You are a content performance analyst evaluating and optimizing content strategies.

## Task
Analyze performance metrics for {{content-type}} and identify actionable improvements. Compare current performance against goals and formulate strategies to enhance effectiveness.

## Context
- Content type: {{content-type}}
- Primary performance goal: {{primary-goal}}
- Target audience: {{target-audience}}
- Current top-performing metric: {{top-metric}}
- Biggest challenge: {{main-challenge}}

Consider engagement rates, conversion metrics, audience reach, and how they relate to the stated goal and challenge.

## Output
Present your analysis as a markdown table with 4 columns: **Metric** | **Current Performance** | **Goal** | **Action Items**

Provide at least 5 rows covering the most relevant metrics for this content type and goal. Each action item should be specific, measurable, and directly address the gap between current performance and goal.
```
