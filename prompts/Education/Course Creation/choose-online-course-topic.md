# Online Course Outline Builder for Solopreneurs

## 簡介

The Online Course Outline Builder for Solopreneurs is a free AI prompt that creates structured course outlines with modules, lessons, and key learning points for educators targeting solopreneur audiences. This course creation prompt for ChatGPT takes your course context - topic, learning goals, target audience background, and desired scope - and produces a complete markdown table organizing your content into coherent learning units. It runs on ChatGPT, Claude, Gemini, and Grok, ensuring logical progression from foundational to advanced concepts while emphasizing actionable takeaways, time efficiency, and direct business application that solopreneurs need. Course creators, subject-matter experts, and educators use it to transform expertise into well-structured online courses that support progressive skill building. Reach for this prompt when you need to organize course material into a clear teaching sequence or want to ensure your modules and lessons flow logically for adult learners balancing business demands. ● Produces a three-column markdown table (Module, Lesson, Key Points) for immediate use in course platforms ● Groups related concepts into coherent modules with lessons that follow natural learning progression ● Identifies core concepts, skills, and actions for each lesson to guide content development ● Tailors structure to solopreneur learning preferences: practical application, efficiency, and business relevance ## Prompt

```
## Role
You are an expert course architect specializing in online education for solopreneurs.

## Task
Create a comprehensive course outline structured into modules and lessons with defined key points for each. Ensure logical progression of concepts and skills that align with the learning objectives and practical application needs of the target audience.

## Context
{{course-context}}

Include:
- The course topic and primary learning goal
- Target audience (background, skill level, pain points)
- Your expertise level in the subject
- Desired course duration or scope

Consider how solopreneurs learn best: actionable takeaways, time efficiency, and direct business application.

## Output
Present the course outline as a markdown table with three columns:

| Module | Lesson | Key Points |
|--------|--------|------------|

Ensure:
- Modules group related concepts into coherent learning units
- Lessons within each module follow a logical sequence
- Key Points identify the core concepts, skills, or actions covered in each lesson
- The complete structure supports progressive skill building from foundational to advanced topics
```
