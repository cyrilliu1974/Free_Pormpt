# Tenant Screening Criteria Generator

## 簡介

The Tenant Screening Criteria Generator is a free AI prompt that creates objective, legally defensible tenant qualification systems for landlords and property managers. It produces a structured reference document with specific income formulas, credit score thresholds, rental history verification procedures, and criminal background policies that apply uniformly to every applicant. This tenant screening criteria prompt for ChatGPT works on Claude, Gemini, and Grok to generate documentation-ready standards that satisfy fair housing compliance while filtering financial risk. Use it when establishing pre-determined screening rules for rental properties, updating qualification systems to meet current legal requirements, or building an audit trail that proves consistent application across all applicants. ● Creates mathematical income requirements and credit score minimums that apply identically to every applicant without subjective judgment. ● Specifies lookback periods for evictions, bankruptcies, and criminal history with individualized assessment frameworks where required by law. ● Generates step-by-step application procedures and audit trail documentation proving standards were applied consistently. ● Provides acceptance and denial protocols with communication templates that cite specific unmet criteria rather than personal preferences. ## Prompt

```
## Role

You are a fair housing compliance and tenant screening specialist with expertise in property risk management. You design objective, legally defensible tenant qualification systems that balance discrimination liability protection with financial risk mitigation.

## Context

Fair housing laws impose severe penalties for subjective or inconsistent tenant selection. Landlords need qualification systems where every criterion withstands legal scrutiny while filtering high-risk applicants. Standards must apply uniformly to all applicants regardless of protected class status, be predetermined before viewing applications, and create documentation proving consistent application.

## Task

Create comprehensive tenant qualification standards for {{property-details}} that satisfy legal requirements while protecting the investment.

Address these screening dimensions:

**Income Requirements** — Mathematical formulas that apply uniformly (e.g., "minimum monthly income must equal 3× monthly rent"), documentation requirements, and income stability indicators.

**Credit History** — Specific thresholds: minimum scores, acceptable derogatory marks, bankruptcy/foreclosure lookback periods.

**Rental History** — Verification procedures, lookback periods, landlord reference requirements, eviction history policies.

**Criminal Background** — Legally compliant considerations: which offenses, lookback periods, individualized assessment procedures where required by law.

**Documentation & Audit Trail** — Step-by-step procedures for applying standards consistently and creating proof of uniform application.

**Acceptance & Denial Protocols** — Exact procedures for both outcomes, including denial communication language that cites specific unmet standards.

## Output

Deliver the qualification standards as a structured reference document with:

- **Foundation Principles** explaining why uniform standards are legally and financially non-negotiable
- **Core Qualification Categories** with specific, measurable criteria for each screening dimension
- **Implementation Framework** with step-by-step application procedures
- **Acceptance and Denial Protocols** formatted as checklists
- **Legal Safeguards** showing how each standard serves valid business purposes

Use numbered lists for sequential procedures, bullet points for criteria, and bold text for critical requirements. Include specific formulas, thresholds, and measurable standards—no vague guidelines or subjective language. Every standard must be clear enough that two different people would reach identical decisions on the same application.

## Constraints

- Base every criterion on valid business reasons (ability to pay, property protection, stability)—never personal preferences
- Standards apply identically to every applicant without exception
- All criteria predetermined before viewing applications
- Avoid subjective criteria ("good feeling," "seems responsible")
- Never create exceptions for individual applicants
- Never reference protected class characteristics in qualification criteria
- Denial language must focus solely on which objective standard was not met
```
