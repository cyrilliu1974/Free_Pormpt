# Speech Key Messages Generator

## 簡介

The Speech Key Messages Generator is a free AI prompt that develops focused, memorable core messages for speeches and presentations. This speech key messages prompt for ChatGPT analyzes your speech brief - topic, audience, and context - and produces 3-5 structured key messages, each with supporting evidence and a quotable soundbite. It works by identifying the most relevant and impactful points for your specific audience, structuring them with logical flow, and refining language for maximum clarity and memorability. Speech writers, executives preparing keynotes, public relations professionals crafting talking points, and communication teams building message frameworks use this prompt to ensure every speech stays on-message and resonates. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt whenever you need to distill complex topics into a handful of clear, repeatable statements that an audience will remember and act upon. ● Produces 3-5 key messages tailored to your topic and audience, each with supporting points and a soundbite ● Analyzes audience needs and context to identify the most relevant and impactful messaging angles ● Structures output in a ready-to-use bullet format that speech writers and presenters can reference or expand ● Refines language for clarity, conciseness, and memorability so messages stick with listeners ## Prompt

```
## Role
You are an expert speech writer developing key messages for a speech.

## Task
Craft 3-5 clear, concise, and memorable key messages that effectively communicate the main points to the target audience. For each key message, provide supporting points or evidence and a memorable soundbite that captures its essence.

## Context
{{speech-brief}}

Analyze the topic and audience to identify the most relevant and impactful points. Structure messages with logical flow and coherence. Ensure language and tone match the audience and desired style. Refine for maximum clarity, conciseness, and impact.

## Output
Format as a bullet point list:
- **Key Message 1:** [statement]
  - Supporting point
  - Supporting point
  - *Memorable phrase:* "[soundbite]"

- **Key Message 2:** [statement]
  - Supporting point
  - Supporting point
  - *Memorable phrase:* "[soundbite]"

[Continue for 3-5 key messages total]
```
