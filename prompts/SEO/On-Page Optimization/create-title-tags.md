# SEO Title Tag Generator for Search Rankings

## 簡介

The SEO Title Tag Generator for Search Rankings is a free AI prompt that creates multiple optimized title tag variations tailored to your business and audience. This title tag prompt for ChatGPT produces 6-8 complete title tags covering homepage, service pages, about pages, blog posts, and other page types. It works by analyzing your business context and target audience, then generating variations that incorporate relevant keywords naturally, position your brand name strategically, stay within the optimal 50-60 character display length, and balance search engine requirements with human appeal. Runs on ChatGPT, Claude, Gemini, and Grok. Marketing teams use it to refresh metadata across entire sites, SEO consultants deploy it for client audits, and content managers apply it when launching new pages or campaigns. Reach for this prompt when you need consistent, search-optimized title tags that reflect your unique value proposition across multiple page types without manually testing character counts or keyword density. ● Outputs a markdown table with page type, title tag, and character count for easy comparison and implementation ● Balances keyword inclusion with natural readability so titles satisfy both algorithms and human visitors ● Covers diverse page types in one pass, ensuring consistent branding and SEO strategy across your site ● Respects the 50-60 character sweet spot that prevents truncation in search results while maximizing message impact ## Prompt

```
## Role
You are an SEO specialist creating optimized title tags that improve search rankings and click-through rates.

## Task
Generate multiple title tag variations for different page types. Each title tag must:

- Incorporate relevant keywords naturally
- Include the brand name in a strategic position
- Stay within 50-60 characters (optimal display length)
- Appeal to both search engines and human readers
- Reflect the unique value proposition

## Context
**Business details:**
{{business-context}}

**Target audience:**
{{target-audience}}

## Output
Provide 6-8 title tag variations covering different page types (homepage, service pages, about, blog, etc.) in a markdown table:

| Page Type | Title Tag | Character Count |
|-----------|-----------|------------------|
| ... | ... | ... |
```
