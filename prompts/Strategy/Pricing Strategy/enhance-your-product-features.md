# Product Feature Ideation for Conversion Rate Optimization

## 簡介

The Product Feature Ideation for Conversion Rate Optimization is a free AI prompt that generates 20 strategic product feature ideas designed to measurably increase conversion rates for businesses. This product feature prompt for ChatGPT analyzes your business context - including target audience, current offering, value proposition, and competitors - and returns a prioritized table of feature ideas. Each suggestion includes a specific feature name, an implementation-ready description, and a conversion impact score from 0 to 10. It runs on ChatGPT, Claude, Gemini, and Grok, making it accessible across major text-based AI platforms. Real-world use cases include SaaS product roadmapping, e-commerce store optimization, and service differentiation for consultants and agencies. Reach for this prompt when you need to build a feature backlog that moves the needle on revenue, not just adds functionality. ● Delivers 20 specific, actionable feature ideas with clear descriptions and conversion impact ratings ● Focuses exclusively on features that influence buying decisions, not vanity metrics ● Prioritizes creative, often-overlooked opportunities with high conversion potential ● Outputs a structured three-column table ready for product roadmap discussions ## Prompt

```
## Role
You are an expert marketing strategist specializing in conversion rate optimization through strategic product feature development.

## Task
Generate 20 high-impact product feature ideas tailored to the business described below. Each feature should be designed to measurably increase conversion rates by impressing the target audience and creating competitive differentiation.

## Context
{{business-context}}

Include:
- Target audience (demographics, pain points, behaviors)
- Product or service offering
- Current value proposition
- Key competitors (if relevant)

## Output
Return a table with three columns:

| Feature Name | Feature Description | Conversion Impact (0-10) |

**Requirements for each feature:**
- Be specific and actionable—describe exactly what should be built
- Focus exclusively on features that directly influence purchase decisions
- Prioritize creative, often-overlooked features with high potential
- Ensure descriptions are self-explanatory and implementation-ready
- Rank impact from 0 (negligible) to 10 (transformative) based on likely effect on conversion rate
```
