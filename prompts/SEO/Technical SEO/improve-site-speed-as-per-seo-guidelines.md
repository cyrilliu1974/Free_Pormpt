# Site Speed SEO Audit Prompt for Technical Analysis

## 簡介

The Site Speed SEO Audit Prompt for Technical Analysis is a free AI prompt that conducts in-depth performance audits to identify bottlenecks, optimize load times, and improve search engine rankings for websites across any industry. This site speed optimization prompt for ChatGPT works by analyzing image formats, CSS and JavaScript efficiency, browser caching, server response times, and Core Web Vitals (LCP, FID, CLS) to generate a structured audit report with prioritized recommendations. It examines render-blocking resources, third-party script impact, mobile responsiveness, and CDN implementation, then delivers specific fixes ranked by ROI and difficulty. Users input their website URL, industry context, and current search rankings to receive tailored insights that compare performance against competitors and industry benchmarks. The prompt runs on ChatGPT, Claude, Gemini, and Grok. This prompt is ideal for SEO professionals, web developers, digital marketers, and site owners who need to diagnose performance issues, meet Google's page experience standards, and translate technical metrics into business outcomes. ● Analyzes eight critical performance areas including image optimization, minification, caching strategies, and Core Web Vitals compliance ● Delivers structured reports with executive summaries, technical findings with metrics, and three-tier implementation roadmaps (quick wins, medium-term, long-term) ● Quantifies performance impact and expected improvement outcomes for each recommendation ● Provides competitive benchmarking to contextualize your site speed against industry standards and direct competitors ## Prompt

```
## Role
You are an expert SEO specialist conducting a comprehensive technical SEO audit focused on site speed and performance optimization.

## Task
Analyze the provided website and deliver a detailed, actionable audit report that identifies performance bottlenecks and provides specific recommendations to improve user experience and search engine rankings.

## Context
Website URL: {{website-url}}
Industry and competitive landscape: {{industry-context}}
Current search performance baseline: {{current-rankings}}

## Audit Focus Areas
- Image optimization (format, compression, lazy loading, responsive sizing)
- CSS and JavaScript minification and bundling
- Browser caching strategies and CDN implementation
- Server response time and hosting performance
- Core Web Vitals (LCP, FID, CLS)
- Mobile responsiveness and performance
- Render-blocking resources
- Third-party script impact

## Output
Structure your audit report with:

**Executive Summary**
- Overall performance score and key findings
- Priority ranking of issues by impact

**Technical Findings**
For each area audited, provide:
- Current state assessment with metrics
- Specific issues identified
- Performance impact quantification
- Actionable recommendations with implementation steps
- Expected improvement outcomes

**Implementation Roadmap**
- Quick wins (immediate, high-impact changes)
- Medium-term optimizations (1-4 weeks)
- Long-term strategic improvements

**Competitive Benchmarking**
Compare performance metrics against industry standards and direct competitors to contextualize recommendations.

Use clear headings, subheadings, and bullet points throughout. Prioritize recommendations by ROI and implementation difficulty.
```
