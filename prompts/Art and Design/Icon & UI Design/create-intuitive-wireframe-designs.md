# Wireframe Design Plan Generator for User Flows

## 簡介

The Wireframe Design Plan Generator for User Flows is a free AI prompt that creates comprehensive wireframe documentation for websites and apps, mapping complete user journeys with detailed layout specifications and interaction patterns. This wireframe design prompt for ChatGPT guides you through building structured wireframe plans that include user flow diagrams, annotated layouts for each key page, component placement specifications, and responsive behavior notes. It works by taking your project details and brand guidelines, then producing a complete design plan covering homepage structure, product pages, checkout flows, user account areas, and navigation patterns. UI/UX designers use it to document navigation hierarchies, interaction states, form validation logic, and accessibility considerations before moving to high-fidelity mockups. The prompt runs on ChatGPT, Claude, and Gemini. Reach for this prompt when you need to translate project requirements and brand standards into actionable wireframe documentation that developers and stakeholders can review and approve. ● Maps complete user journeys from entry point to conversion with decision points and interaction states ● Specifies layout and component placement for homepage, product pages, checkout flows, and user account areas ● Documents responsive behavior, navigation consistency, and brand alignment across all screens ● Includes design rationale, visual hierarchy notes, and recommendations for user testing cycles ## Prompt

```
## Role
You are an experienced UI/UX designer creating wireframe documentation for a website or app user flow.

## Task
Generate a comprehensive wireframe design plan that maps the complete user journey and specifies layout, component placement, and interaction patterns for each page in the flow. The design must prioritize intuitive navigation, user-friendliness, and brand alignment.

## Context
**Project Details:**
{{project-details}}

**Brand Guidelines:**
{{brand-guidelines}}

## Process

**1. User Flow Mapping**
Map the complete journey from entry point to end action, documenting each step, decision point, and interaction.

**2. Page Inventory**
Identify all required pages and components based on the flow (homepage, product/service pages, checkout, user account area, etc.).

**3. Layout Specifications per Page**
- **Homepage**: Navigation menu, hero section, CTA placement, promotional areas
- **Product/Service Pages**: Image galleries, descriptions, pricing, CTAs, reviews, related items
- **Checkout Flow**: Cart summary, information forms, payment selection, confirmation
- **User Account**: Profile, order history, settings, preferences

**4. Design Standards**
- Maintain consistent navigation and interaction patterns throughout
- Ensure responsive behavior across devices and screen sizes
- Apply brand colors, typography, and imagery consistently
- Use clear labels, intuitive icons, and accessible form design
- Incorporate current UI patterns that enhance usability

**5. Iteration Notes**
Include recommendations for user testing and stakeholder feedback cycles before finalization.

## Output
Deliver a structured wireframe plan with:
- Complete user flow diagram
- Annotated layout for each key page showing component placement
- Interaction specifications (hover states, transitions, form validation)
- Responsive behavior notes
- Design rationale for strategic choices
- Visual hierarchy and accessibility considerations
```
