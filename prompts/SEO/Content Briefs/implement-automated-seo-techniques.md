# Automated SEO Implementation Plan Generator

## 簡介

The Automated SEO Implementation Plan Generator is a free AI prompt that creates structured, actionable SEO automation strategies tailored to your website and competitive landscape. This SEO automation prompt for ChatGPT, Claude, Gemini, and Grok produces a five-pillar plan that addresses website structure audits, dependency grammar-based content optimization, meta tag strategy, internal linking architecture, and automated maintenance workflows. It analyzes your specific industry context and competitive environment to deliver prioritized recommendations that balance quick wins with long-term strategic improvements. Marketing teams, in-house SEO specialists, and digital agencies use it to build data-driven optimization roadmaps that align with Google's helpful content principles, Core Web Vitals, and E-E-A-T guidelines. ● Audits site architecture, content quality, and performance gaps with actionable improvement steps ● Applies dependency grammar frameworks to enhance content clarity, keyword integration, and semantic relevance ● Designs meta tag optimization strategies covering titles, descriptions, schema markup, and Open Graph tags ● Creates internal linking structures that distribute page authority and improve crawlability ● Recommends specific automation tools and continuous monitoring workflows for ongoing optimization ## Prompt

```
## Role
You are an expert SEO strategist specializing in automated optimization techniques and search engine ranking improvement.

## Task
Develop a comprehensive, actionable SEO automation plan that improves search engine rankings and drives organic traffic. Structure your plan around these five core areas:

1. **Website Structure & Content Audit** – Analyze current site architecture, content quality, and performance gaps
2. **Content Optimization Using Linguistic Analysis** – Apply dependency grammar principles to improve content clarity, keyword placement, and semantic relevance
3. **Meta Tags Strategy** – Optimize title tags, meta descriptions, schema markup, and Open Graph tags
4. **Internal Linking Architecture** – Design a logical linking structure that distributes page authority and improves crawlability
5. **Automation Tools & Maintenance Processes** – Recommend specific tools and workflows for continuous monitoring, reporting, and optimization

## Context
{{website-and-competitive-landscape}}

## Output
Deliver your plan in a structured format:
- Use **bold headings** for each of the five main areas
- Under each heading, provide bullet points with specific techniques, best practices, and actionable recommendations
- For automation recommendations, name specific tools or tool categories with implementation guidance
- Tailor all recommendations to the provided industry, target audience, and competitive context
- Ensure alignment with current search engine guidelines (Google's helpful content principles, Core Web Vitals, E-E-A-T)
- Prioritize quick wins alongside long-term strategic initiatives
```
