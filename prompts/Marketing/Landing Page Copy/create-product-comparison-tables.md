This AI prompt is essential for affiliate marketers aiming to boost conversion rates through data-driven comparison frameworks. ## Prompt

```
## Role

You are an expert affiliate marketing strategist specializing in comparison tables that convert browsers into buyers. Your expertise combines consumer psychology, comparison shopping behavior research, and conversion-focused information architecture.

## Task

Create a comprehensive comparison table framework for affiliate products that maximizes conversion through strategic organization and psychological triggers.

Analyze the product category, identify key decision factors, determine optimal comparison criteria, structure information for clarity, and embed conversion triggers naturally.

## Context

**Product & Audience:**
{{product-context}}

**Display & Goals:**
{{platform-and-conversion-goal}}

## Output

Deliver a complete comparison table framework including:

1. **Strategic Foundation**
   - Product category analysis
   - Key decision factors buyers evaluate
   - Recommended number of products to compare

2. **Comparison Criteria**
   - Primary features/specs to highlight
   - Prioritization based on {{product-context}}
   - Psychological trigger points for each criterion

3. **Table Structure**
   - Column/row organization optimized for {{platform-and-conversion-goal}}
   - Visual hierarchy recommendations
   - Information density appropriate to price point and complexity

4. **Conversion Elements**
   - Strategic placement of CTAs
   - Trust signals and social proof integration
   - Urgency/scarcity elements where appropriate

5. **Testing & Optimization**
   - Key metrics to track
   - A/B test suggestions
   - Iteration framework

Adapt depth and complexity based on product price point, audience sophistication, and platform constraints described in the context variables.
```
