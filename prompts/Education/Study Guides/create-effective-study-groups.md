# Study Group Framework Generator for Any Subject

## 簡介

The Study Group Framework Generator is a free AI prompt that creates structured peer learning frameworks tailored to any academic subject. This study group prompt for ChatGPT produces a complete organizational system including four distinct participant roles with clear responsibilities, three discussion formats that encourage active engagement, evidence-based collaborative problem-solving techniques, a session planner template with time-blocked agendas, and a five-question post-session evaluation form. It runs on ChatGPT, Claude, Gemini, and Grok, adapting the framework to your subject's learning objectives while remaining flexible for different group sizes and skill levels. Students organizing review sessions, educators facilitating collaborative learning, and study coordinators can use this prompt to build accountability structures and maximize knowledge sharing. ● Assigns four participant roles that distribute responsibility and keep every member actively contributing ● Provides multiple discussion formats tailored to different learning styles and subject matter complexity ● Includes collaborative problem-solving techniques grounded in educational research ● Delivers a practical session planner with time blocks, agenda items, and materials checklists for immediate use ● Generates a post-session evaluation form that captures feedback on effectiveness and surfaces improvement opportunities ## Prompt

```
## Role
You are an expert peer learning facilitator who designs effective study group frameworks across disciplines.

## Task
Create a comprehensive study group framework for {{subject}} that includes participant roles, discussion formats, collaborative problem-solving techniques, a session planner template, and a post-session evaluation form.

## Context
The framework should be tailored to the subject's learning objectives while remaining adaptable to different group sizes and skill levels. Focus on evidence-based techniques that encourage active participation, critical thinking, and knowledge sharing. The framework's effectiveness depends on participant commitment, so design for flexibility and engagement.

## Output
Deliver the framework in the following structure:

**Study Group Framework for {{subject}}**

**Participant Roles:**
1. Role name and responsibilities
2. Role name and responsibilities
3. Role name and responsibilities
4. Role name and responsibilities

**Discussion Formats:**
- Format name and description
- Format name and description
- Format name and description

**Collaborative Problem-Solving Techniques:**
1. Technique name and explanation
2. Technique name and explanation
3. Technique name and explanation

**Study Group Session Planner:**
- Date, time, and location fields
- Agenda with 4 time-blocked activities
- Materials needed list

**Post-Session Evaluation Form:**
1. Session effectiveness rating (1-5 scale)
2. What worked well? (open response)
3. What could be improved? (open response)
4. Were collaborative techniques helpful? Yes/No with explanation
5. Additional comments

Ensure all roles clearly contribute to group effectiveness, formats promote deep understanding, and the planner is user-friendly for efficient session structuring.
```
