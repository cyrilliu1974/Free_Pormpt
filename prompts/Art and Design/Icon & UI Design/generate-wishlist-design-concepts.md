# E-Commerce Wishlist UI Design Prompt

## 簡介

The E-Commerce Wishlist UI Design Prompt is a free AI prompt that generates detailed interface layouts, interaction patterns, and feature recommendations for online retail wishlist systems. It produces strategic discovery analysis, multiple design concepts covering visual iconography and layout structures, advanced feature specifications including price monitoring and social sharing, and responsive implementation guidelines optimized for both desktop and mobile experiences. This wishlist design prompt for ChatGPT runs on ChatGPT, Claude, Gemini, and Grok, helping product teams translate project context into actionable UI/UX specifications that balance user engagement, conversion goals, and technical constraints. Reach for it when you need to build a new wishlist feature from scratch or optimize an existing one with proven interaction patterns and accessibility standards. ● Conducts strategic discovery to identify audience behavior patterns, platform constraints, and conversion objectives based on your project context. ● Generates multiple design concepts with specific visual iconography options (heart icons, star ratings, bookmark styles), layout structures (list, grid, hybrid), and interactive element recommendations. ● Recommends advanced features like social sharing, automated price-drop alerts, inventory notifications, and cross-device synchronization with implementation guidance. ● Provides responsive specifications including touch target sizing (minimum 44×44px for mobile), hover states for desktop, WCAG 2.1 AA accessibility compliance, and performance optimization techniques like lazy loading. ## Prompt

```
## Role
You are an expert UX/UI designer and product strategist specializing in e-commerce wishlist optimization.

## Task
Create comprehensive wishlist UI layout recommendations that maximize user engagement and conversion rates.

## Context
The user is building or optimizing an e-commerce wishlist feature for their platform. They need actionable design guidance covering visual elements, layout structures, advanced features, and responsive implementation.

{{project-context}}

## Approach
Begin with strategic discovery based on the provided context, then deliver:

**Discovery & Strategy**
- Analyze audience engagement objectives and current user behavior patterns
- Identify platform constraints and opportunities

**Design Concepts**
- Visual iconography (heart icons, star ratings, bookmark styles)
- Layout structures (list view, grid layouts, hybrid approaches)
- Interactive elements optimized for user flow

**Advanced Features**
- Social sharing capabilities
- Price monitoring and price-drop alerts
- Inventory notifications
- Cross-device synchronization

**Responsive Specifications**
- Desktop: hover states, screen real estate optimization
- Mobile: touch target sizing (minimum 44×44px), gesture interactions
- Performance: lazy loading, optimistic updates
- Accessibility: WCAG 2.1 AA compliance, keyboard navigation, screen reader labels

## Output
Structure your response with clear section headings. Present all recommendations in detailed bullet points with specific implementation guidance.
```
