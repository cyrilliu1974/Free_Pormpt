# Employee Engagement Program Builder

## 簡介

The Employee Engagement Program Builder is a free AI prompt that creates structured, research-backed employee engagement programs for HR leaders and organizational psychologists. This employee engagement program prompt for ChatGPT guides you through building a complete initiative tailored to your organization's context, incorporating proven strategies from organizational psychology that address motivation, communication, recognition, and work-life balance. It produces a named program with 3-5 measurable objectives, detailed core components with implementation steps, evaluation metrics, a phased timeline, and budget allocation - all grounded in evidence rather than trends. Runs on ChatGPT, Claude, Gemini, and Grok. Ideal for HR professionals launching engagement initiatives, organizational development consultants designing retention strategies, or leadership teams seeking to improve job satisfaction and productivity through structured programs. ● Outputs 3-5 core program components with specific implementation steps and expected outcomes ● Defines quantifiable metrics (engagement scores, turnover rate, productivity indicators) and evaluation methods ● Creates a phased timeline with milestones and resource allocation across program areas ● Ensures all recommendations are evidence-based and adaptable to your organization's unique challenges ## Prompt

```
## Role
You are an organizational psychologist and human resources expert designing an evidence-based employee engagement program that boosts job satisfaction, productivity, and retention.

## Task
Create a comprehensive employee engagement program tailored to the organization's context. Incorporate proven strategies from organizational psychology addressing motivation, communication, recognition, and work-life balance. The program must be actionable, measurable, and adaptable.

## Context
{{organization-context}}

## Output
Deliver a structured program plan:

### Program Name
Provide a clear, memorable name

### Program Objectives
List 3-5 specific, measurable objectives aligned with the organization's challenges

### Key Components
Describe 3-5 core program elements, each including:
- **Description**: What the component is and why it matters
- **Implementation**: Concrete steps to launch and sustain it
- **Expected Outcomes**: Specific improvements anticipated

### Measurement and Evaluation
- **Metrics**: 3-5 quantifiable indicators (e.g., engagement scores, turnover rate, productivity metrics)
- **Evaluation Methods**: How data will be collected and analyzed (surveys, focus groups, performance data)
- **Reporting Frequency**: How often progress will be reviewed

### Program Timeline
Outline 3-4 implementation phases with:
- Duration of each phase
- Key milestones

### Budget and Resources
- Total budget estimate
- Resource allocation across major program areas

Ensure all recommendations are research-backed and avoid unproven or ineffective strategies.
```
