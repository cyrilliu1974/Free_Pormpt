# Remote Work Security Plan Prompt for ChatGPT

## 簡介

The Remote Work Security Plan Prompt is a free AI prompt that creates a customized, step-by-step cybersecurity framework for organizations managing distributed teams. This remote work security prompt for ChatGPT, Claude, Gemini, and Grok produces a structured plan with 5–7 prioritized security measures, each broken down into concrete implementation steps. You provide your organization context - team size, tools in use, existing security posture, compliance requirements - and the prompt acts as an expert cybersecurity consultant, delivering guidance written for both technical administrators and everyday remote workers. Real-world use cases include onboarding secure remote workflows, auditing current practices after a security incident, preparing for compliance reviews, and training distributed teams on data protection. Reach for this prompt when you need a tailored security roadmap that reflects your actual infrastructure and risk profile, not generic checklists. ● Produces a numbered plan with 5–7 key security measures ranked by criticality for your context ● Breaks each measure into specific, actionable implementation steps that non-technical users can follow ● Adapts recommendations based on your organization's size, tools, technical maturity, and compliance needs ● Balances IT-level controls with accessible practices every remote employee can adopt ## Prompt

```
## Role
You are an expert cybersecurity consultant specializing in secure remote work environments.

## Task
Develop a comprehensive, actionable plan for ensuring data security and privacy in a remote work setting. Present the plan as a numbered list of key security measures, with sub-bullets detailing specific implementation steps for each measure.

## Context
Organization context: {{organization-context}}

Tailor guidance for both IT professionals and non-technical remote workers. Prioritize the most critical aspects of remote work security based on the organization's current setup, technical maturity, and specific challenges described above.

## Output
Structure your response as:

**Introduction**
Brief paragraph emphasizing the importance of data security and privacy in this remote work setting.

**Security Plan**
1. Security Measure 1
   - Implementation Step 1
   - Implementation Step 2
   - Implementation Step 3

2. Security Measure 2
   - Implementation Step 1
   - Implementation Step 2
   - Implementation Step 3

[Continue with 5–7 prioritized measures]

Use clear, accessible language that avoids unnecessary jargon. Ensure each implementation step is concrete and actionable.
```
