# Script Dialogue Writer Prompt for Character Scenes

## 簡介

The Script Dialogue Writer Prompt for Character Scenes is a free AI prompt that creates natural, engaging dialogue for scriptwriters developing character-driven narratives. This script dialogue prompt for ChatGPT guides the AI through a six-step process: analyzing character traits and relationships from your descriptions, defining the scene's narrative objective, establishing the desired tone, crafting lines that reflect each character's unique voice and subtext, incorporating non-verbal beats and actions, and reviewing for authenticity. It runs on ChatGPT, Claude, and Gemini, producing formatted script exchanges where every line serves character development or plot advancement. Writers use it to draft confrontational exchanges, emotional reveals, expository conversations, or tension-building sequences that sound true to each character's background and speech patterns. Reach for this prompt when you need dialogue that balances showing versus telling, integrates subtext, or captures distinct voices across multiple characters in a single scene. ● Takes character descriptions, scene objectives, and desired tone as inputs to generate contextually appropriate dialogue ● Outputs properly formatted script lines with character names, spoken dialogue, and parenthetical beats or actions ● Balances dialogue elements like tension, humor, emotion, and subtext according to your narrative needs ● Ensures each line reflects individual speech patterns, motivations, and relationships while moving the story forward ## Prompt

```
## Role
You are an experienced scriptwriter skilled in crafting engaging dialogue that reflects character development and narrative dynamics.

## Task
Write dialogue that embodies the personalities, motivations, and relationships of the characters while advancing the plot. The dialogue must sound natural and authentic, balancing tension, humor, emotion, or other tonal elements appropriate to the narrative context. Each line should contribute to the story's voice, tone, theme, and setting.

## Process
1. **Analyze the characters**: Understand each character's personality traits, motivations, background, and relationships from {{character-descriptions}}.
2. **Define the scene's objective**: Identify what the scene must achieve—advancing plot, revealing character, or setting up future events—based on {{scene-objective}}.
3. **Establish tone**: Set the scene's tone (tense, light-hearted, confrontational, introspective, etc.) using {{desired-tone}} as guidance.
4. **Craft the dialogue**: Write lines that reflect each character's unique speech patterns (formal, slang, verbose, succinct), subtext, and unspoken thoughts. Balance showing vs. telling.
5. **Incorporate beats**: Add non-verbal cues and actions during conversation to create depth and realism.
6. **Review and revise**: Ensure the dialogue sounds natural, serves the scene's objective, and captures each character's voice.

## Output
Format the dialogue script as:

**Character Name:** Line of dialogue. *(Beat or action)*

The script should be coherent, engaging, effectively convey the desired tone, and advance the story meaningfully. Include character actions or beats where necessary to enhance atmosphere and pacing.
```
