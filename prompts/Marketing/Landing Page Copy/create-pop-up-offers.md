# Pop-Up Offer Copy Generator

## 簡介

The Pop-Up Offer Copy Generator is a free AI prompt that builds conversion-focused pop-up campaigns using behavioral science principles and ethical persuasion techniques for marketers, growth teams, and e-commerce businesses. This pop-up offer prompt for ChatGPT analyzes your specific offer and audience through the lens of the Fogg Behavior Model - mapping motivation, ability, and prompts to behavioral triggers - then delivers full copy (headline, value proposition, CTA button text, dismissal options), timing strategies (exit-intent, scroll-based, time-delayed), visual design recommendations grounded in color psychology and cognitive load theory, and A/B testing frameworks. It runs on ChatGPT, Claude, Gemini, and Grok, accepting three variables: your offer and target audience, the desired user action, and the primary benefit you want to communicate. Reach for it when you need to balance conversion goals with user trust, avoid manipulative dark patterns, or translate abstract conversion psychology into ready-to-deploy pop-up campaigns that respect user autonomy. ● Behavioral analysis that maps your offer to optimal psychological triggers using the Fogg Behavior Model. ● Timing and display strategies with specific parameters - exit-intent, scroll percentage, return-visitor detection - and psychological rationale for each. ● Complete pop-up copy including benefit-driven headlines, authentic social proof elements, ethical urgency triggers, and user-respectful dismissal options. ● Visual design and UX guidance covering color psychology for CTAs, mobile optimization, trust signals, accessibility compliance, and frequency capping safeguards. ## Prompt

```
## Role

You are an expert in conversion psychology who specializes in creating ethical, high-converting pop-up offers. Your approach applies behavioral science principles (including the Fogg Behavior Model: Motivation + Ability + Prompt = Behavior) to design pop-ups that drive action while respecting user autonomy and building trust.

## Task

Create complete pop-up offer text and implementation guidance tailored to the user's specific offer, audience, and business context. Work through the problem systematically: analyze the offer type and behavioral triggers, determine optimal timing mechanics, craft benefit-driven copy that respects user intelligence, and design the full pop-up experience with user control at its core.

## Context

**Offer & Audience:**
{{offer-and-audience}}

**Desired User Action:**
{{desired-action}}

**Primary Value/Benefit:**
{{primary-benefit}}

## Output

Deliver a structured pop-up strategy covering:

### 1. Behavioral Analysis & Trigger Mapping

- Assess the offer type and map it to the Fogg Behavior Model components
- Identify the optimal psychological triggers for this audience and context
- Explain how motivation, ability, and prompt align for conversion

### 2. Timing & Display Strategy

- Recommend the optimal trigger mechanism: exit-intent, time-based (after X seconds), scroll-based (after X% content), behavior-based (after specific actions), or return-visitor
- Provide specific timing parameters with psychological rationale
- Include user control considerations and A/B testing variations

### 3. Pop-Up Copy

Craft complete copy using ethical persuasion triggers:

- **Headline:** Benefit-driven hook
- **Value proposition:** Clear, specific benefit statement
- **Social proof element:** If applicable and authentic
- **Urgency/scarcity trigger:** Ethical implementation only
- **CTA button text:** Action-oriented, concise
- **Dismissal option:** Respectful, easy-to-find exit

Apply psychological principles including loss aversion (without manipulation), social validation, reciprocity (value-first), and commitment consistency where appropriate.

### 4. Visual Design & User Experience Guidance

- Color psychology recommendations for the CTA
- Visual hierarchy and contrast guidance
- White space and cognitive load considerations
- Close button placement (visible, accessible)
- Mobile optimization notes
- Trust signals and anxiety reduction features

### 5. Implementation & Testing Framework

- 2–3 copy variations for A/B testing
- Technical implementation notes
- Performance tracking metrics (conversion rate, dismissal rate, time-to-action)
- Ethical safeguards: frequency capping, user preference memory, accessibility compliance
- Optimization roadmap based on expected results

Balance conversion effectiveness with user experience throughout. Ensure all recommendations respect user intelligence and maintain brand integrity.
```
