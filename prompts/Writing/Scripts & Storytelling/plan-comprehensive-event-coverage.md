# Event Coverage Planning Prompt for Journalists

## 簡介

The Event Coverage Planning Prompt for Journalists is a free AI prompt that helps journalists and editors structure comprehensive event coverage with multiple reporting angles and source lists. This event coverage prompt for ChatGPT guides you through building a dependency-grammar-based editorial plan: one primary coverage focus, three distinct reporting angles (each with newsworthy details and key contacts), and three contextual modifiers. It works on ChatGPT, Claude, Gemini, and Grok to turn a single event name into a structured assignment framework that identifies what makes each angle newsworthy and which sources can provide insight or access. Use it when planning field assignments, pre-event briefings, or newsroom coordination for conferences, launches, protests, or recurring beats. ● Outputs one main editorial focus plus three distinct reporting perspectives, each with key details and contact recommendations ● Structured using dependency grammar principles to clarify hierarchy and logical flow between angles ● Identifies what makes each angle newsworthy and which sources can provide authoritative insight or access ● Includes three modifying phrases for background context, helping reporters understand the broader story landscape ## Prompt

```
## Role
You are an experienced journalist planning comprehensive coverage for an event, exploring multiple storylines and identifying crucial sources.

## Task
Develop a detailed coverage plan for {{event-name}} structured using dependency grammar principles: one main coverage focus, three distinct reporting angles (each with key details and contacts), and three modifying phrases that add context.

## Output
Format your plan as:

**{{event-name}}**

**Main clause:**  
Coverage focus: [state the primary editorial focus]

**Subordinate clause 1:**  
Angle: [first distinct perspective]  
Key details: [what makes this angle newsworthy]  
Key contacts: [sources who can provide insight or access]

**Subordinate clause 2:**  
Angle: [second distinct perspective]  
Key details: [what makes this angle newsworthy]  
Key contacts: [sources who can provide insight or access]

**Subordinate clause 3:**  
Angle: [third distinct perspective]  
Key details: [what makes this angle newsworthy]  
Key contacts: [sources who can provide insight or access]

**Modifying phrases:**  
1. [additional context or background]  
2. [additional context or background]  
3. [additional context or background]

Ensure each angle provides unique value and contacts are relevant to their respective angles.
```
