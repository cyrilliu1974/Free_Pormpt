# Content Repurposing Strategist Prompt

## 簡介

The Content Repurposing Strategist Prompt is a free AI prompt that transforms a single piece of content into a multi-platform distribution strategy for marketers, content teams, and social media managers. This content repurposing prompt for ChatGPT analyzes your source material, extracts core messages, and generates a structured markdown table mapping 5-8 platforms with tailored adaptations for each channel. It accounts for platform-specific constraints (character limits, video lengths, image ratios), audience behaviors, and format requirements while preserving brand voice consistency. You input a description of your existing content, target audience goals, and brand voice, and the prompt outputs a table with four columns: Platform, Content Type, Key Adaptations, and Engagement Tactics. It runs on ChatGPT, Claude, Gemini, and Grok, making it compatible with the most widely used text-generation models. Use it when you need to extend the reach of blog posts, webinars, whitepapers, or campaigns without starting from scratch on every channel. ● Produces a markdown table covering 5-8 distribution channels with format, messaging, and engagement strategies for each ● Extracts and preserves your core messages while adapting tone, length, visuals, and calls-to-action to fit platform norms ● Maintains brand voice consistency across all recommended adaptations ● Identifies platform-native engagement tactics like hashtags, Stories features, threading, and video specs to maximize performance ## Prompt

```
## Role
You are a content repurposing strategist who maximizes reach and engagement across platforms.

## Task
Create a comprehensive repurposing plan that transforms existing content for multiple distribution channels. Analyze the source material to extract key messages, then adapt them for each platform while maintaining brand consistency. Account for platform-specific constraints, audience behaviors, and format requirements.

## Context
**Original content:** {{existing-content-description}}

**Target audience and goals:** {{audience-and-goals}}

**Brand voice:** {{brand-voice}}

## Output
Deliver your strategy as a markdown table with these columns:
- **Platform** – the distribution channel
- **Content Type** – the format/medium for that platform
- **Key Adaptations** – specific changes to messaging, length, tone, visuals, or calls-to-action
- **Engagement Tactics** – platform-native features or techniques to boost performance

Include 5–8 platforms that align with the audience and goals. Ensure each adaptation preserves core messages while leveraging the strengths of its medium.
```
