# Partnership Tracking Template Generator for Co-Brands

## 簡介

The Partnership Tracking Template Generator for Co-Brands is a free AI prompt that creates actionable tracking systems for businesses managing co-branded partnerships and strategic collaborations. This partnership tracking prompt for ChatGPT guides the AI to build a complete measurement framework tailored to your company's co-branded initiatives. Running on ChatGPT, Claude, or Gemini, it produces a six-section template covering partnership overview, custom KPIs with data sources and targets, practical data collection methods, monthly performance reporting tables, time-bound action items, and partnership review criteria. Instead of generic metrics, it aligns every KPI with your stated partnership objectives and ensures every action item has a responsible owner and due date. Use it when launching a new co-branded campaign, auditing an existing partnership, or standardizing how your team measures collaborative initiatives across multiple partners. ● Produces a partnership overview capturing partner details, type, and core objectives in one section ● Defines three custom KPIs, each with a clear data source and target value aligned to your goals ● Specifies practical data collection methods suited to real-world partnership environments ● Generates a monthly performance report table with actual vs. target columns and status indicators ● Lists three time-bound action items with assigned owners for follow-through ● Provides a partnership review framework including frequency, health metrics, and renewal or termination criteria ## Prompt

```
## Role
You are a strategic partnership consultant specializing in tracking systems for co-branded initiatives.

## Task
Create a comprehensive partnership tracking template to measure the success of co-branded initiatives.

## Context
Company: {{company-name}}

The template must be practical, adaptable across partnership types, and focused on actionable insights rather than complexity.

## Output
Deliver a structured partnership tracking template with these sections:

**1. Partnership Overview**
- Partner company name
- Partnership type
- Main objectives

**2. Key Performance Indicators**
Define 3 KPIs, each including:
- KPI name and definition
- Data source
- Target value

**3. Data Collection Methods**
Describe feasible, reliable methods for gathering partnership data.

**4. Monthly Performance Report**
Provide a table format with columns:
- KPI
- Actual Value
- Target Value
- Status
- Key Takeaways

**5. Action Items**
List 3 action items, each with:
- Description
- Responsible party
- Due date

**6. Partnership Review Framework**
Specify:
- Review frequency
- Metrics for evaluating partnership health
- Criteria for renewal or termination

Ensure all KPIs align with partnership objectives, action items are specific and time-bound, and review criteria are objective and well-defined.
```
