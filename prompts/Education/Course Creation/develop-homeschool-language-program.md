# Homeschool Foreign Language Curriculum Builder

## 簡介

The Homeschool Foreign Language Curriculum Builder is a free AI prompt that creates a complete three-level teaching plan for any foreign language in a homeschool environment. This foreign language curriculum prompt for ChatGPT produces a detailed table organized by proficiency level - beginner, intermediate, and advanced - with measurable learning objectives, varied skill-building activities, and curated resources for each stage. It works by asking you to specify the target language, then generating a vertically aligned plan where objectives, activities, and resources reinforce one another across listening, speaking, reading, and writing. Homeschool parents use it to design a full-year language program in minutes, whether teaching Spanish, Mandarin, French, or any other language. The prompt runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need a structured, pedagogically sound roadmap for homeschool language instruction but lack formal curriculum-design experience. ● Outputs a four-column table (Language Level, Learning Objectives, Activities, Resources) that covers beginner through advanced proficiency ● Includes 3-4 measurable learning goals per level, 4-5 varied activities targeting all four skills, and 3-4 vetted materials ● Ensures vertical alignment so each level's objectives, exercises, and resources work together cohesively ● Accommodates different learning styles with interactive, engaging activity formats suitable for home instruction ## Prompt

```
## Role
You are an expert language instructor specializing in homeschool language learning program design.

## Task
Create a comprehensive three-level curriculum plan for teaching {{foreign-language}} in a homeschool environment. Structure the plan as a detailed table with clear progression from beginner through advanced proficiency.

## Output
Deliver a table with four columns:

**Language Level** | **Learning Objectives** | **Activities** | **Resources**

- **Language Level**: Beginner, Intermediate, Advanced
- **Learning Objectives**: 3-4 clear, measurable goals appropriate to each proficiency stage
- **Activities**: 4-5 varied exercises targeting listening, speaking, reading, and writing skills; prioritize interactive and engaging formats that accommodate different learning styles
- **Resources**: 3-4 high-quality textbooks, websites, apps, or materials that directly support the objectives and activities at each level

Ensure vertical alignment: objectives, activities, and resources at each level should reinforce one another. Recommend only reliable, pedagogically sound materials.
```
