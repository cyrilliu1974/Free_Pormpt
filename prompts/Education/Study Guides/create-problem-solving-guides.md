# Problem-Solving Guide Creator for Any Subject

## 簡介

The Problem-Solving Guide Creator for Any Subject is a free AI prompt that generates detailed, step-by-step instructional guides tailored to specific problem types and subject areas. This problem-solving guide prompt for ChatGPT produces organized, numbered sequences where each step includes a clear actionable description, sub-bullets with additional context or examples, and warnings about common mistakes to avoid. It works by accepting two variables - problem type and subject area - then structuring expert-level guidance that covers all essential aspects of solving that particular challenge. Educators use it to build teaching materials, professionals apply it to document troubleshooting workflows, and students rely on it to break down complex academic problems into manageable steps. The prompt runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt whenever you need to document a repeatable solution process, create training materials, or help others navigate unfamiliar problem domains systematically. ● Produces numbered step sequences with actionable descriptions, supporting examples, and pitfall warnings in every step. ● Accepts any problem type and subject area, from technical troubleshooting to academic topics to creative workflows. ● Structures output with consistent formatting - main steps, illustrative sub-bullets, and common-mistake alerts - for easy scanning and implementation. ● Ensures comprehensive coverage by prompting the model to address all essential aspects of the problem domain. ## Prompt

```
## Role
You are an expert problem-solving guide creator with deep knowledge across diverse subjects.

## Task
Create a comprehensive step-by-step guide for solving {{problem-type}} in {{subject-area}}.

## Output Structure
Organize the guide as a numbered list where each step includes:

- A clear, concise, actionable description
- Sub-bullets with additional details or illustrative examples
- Common pitfalls and mistakes to avoid

Format:

**Guide for Solving {{problem-type}} in {{subject-area}}**

1. Step 1: [brief description]
   - [sub-bullet with additional details or example]
   - [sub-bullet highlighting a common pitfall]

2. Step 2: [brief description]
   - [sub-bullet with additional details or example]
   - [sub-bullet highlighting a common pitfall]

3. Step 3: [brief description]
   - [sub-bullet with additional details or example]
   - [sub-bullet highlighting a common pitfall]

[Continue with additional steps as needed]

Ensure the guide covers all essential aspects of solving this problem type, with examples that clarify key points and help users navigate successfully.
```
