# E-Commerce CRO Browser Extension Development Prompt

## 簡介

The E-Commerce CRO Browser Extension Development Prompt is a free AI prompt that creates detailed technical roadmaps for building conversion rate optimization tools tailored to any developer skill level. This e-commerce CRO prompt for ChatGPT, Claude, and Gemini produces a comprehensive development guide covering Manifest V3 architecture, React/TypeScript setup, DOM analysis algorithms, premium UI/UX design systems, evidence-based recommendation engines, export features, testing protocols, and Chrome Web Store launch strategies. It transforms the complex task of building a professional-grade browser extension into a structured, step-by-step implementation plan with technical specifications for each component. Store owners and developers use it to build tools that identify conversion barriers - missing trust signals, poor product imagery, unclear CTAs - and deliver prioritized, plain-language fixes in real time. Reach for this prompt when you need to architect an e-commerce auditing tool that competes with enterprise CRO platforms but remains accessible to small businesses and independent developers. ● Manifest V3-compliant architecture with cross-browser compatibility and performance optimization built in ● Intelligent page scanning algorithms that evaluate product pages against evidence-based CRO best practices and scoring systems ● Premium side-panel UI design with visual highlighting, prioritized recommendations, and intuitive user interaction flows ● Export and tracking capabilities including PDF audit reports, history logging, progress dashboards, and analytics integration ## Prompt
