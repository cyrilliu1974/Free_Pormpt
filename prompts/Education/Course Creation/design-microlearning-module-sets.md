# Microlearning Module Set Design Prompt

## 簡介

The Microlearning Module Set Design Prompt is a free AI prompt that generates complete microlearning curricula with 5-10 bite-sized modules, each optimized for retention through spaced repetition and active learning elements. This microlearning prompt for ChatGPT, Claude, and Gemini takes your learning project details - topic, audience, outcomes, and constraints - and produces a fully structured module set where each lesson fits into 3-7 minutes. The prompt specifies learning objectives, recommends formats (video, infographic, interactive scenario, or quiz), identifies 2-4 key teaching points per module, and embeds active learning activities like reflection prompts and micro-exercises. It sequences modules to scaffold knowledge progressively and maps spaced repetition touchpoints so learners revisit earlier concepts at optimal intervals. Assessment checkpoints every 2-3 modules ensure comprehension before advancing. Instructional designers, L&D professionals, and educators reach for this prompt when they need to transform dense subject matter into engaging, retention-focused learning experiences that respect adult learners' time constraints. It is ideal for corporate training, professional development programs, and any scenario where lifelong learners need to master complex topics without cognitive overload. ● Generates 5-10 focused modules with specific durations, formats, and teaching points tailored to your audience and outcomes ● Embeds spaced repetition by identifying which prior concepts to revisit in later lessons for stronger retention ● Includes active learning elements - practice questions, reflection prompts, micro-exercises - in every module to drive engagement ● Provides assessment checkpoints every 2-3 modules so you can verify understanding before learners progress ## Prompt

```
## Role
You are an instructional designer specializing in microlearning for lifelong learners.

## Task
Design a comprehensive microlearning module set that breaks complex topics into engaging, bite-sized content. Structure the learning path to promote retention through spaced repetition and active recall.

## Context
**Learning project:** {{learning-project}}
(Include: topic, target audience, desired learning outcomes, time constraints per module, and available production resources)

## Process
1. Define 3-5 specific, measurable learning objectives aligned to the outcomes
2. Chunk the topic into 5-10 focused modules, each completable in 3-7 minutes
3. For each module, specify:
   - Core concept or skill
   - Recommended format (video, infographic, interactive scenario, or mini-quiz)
   - Key teaching points (2-4 maximum)
   - One active learning element (practice question, reflection prompt, or micro-exercise)
4. Sequence modules to scaffold knowledge progressively
5. Embed spaced repetition by noting which earlier concepts to revisit in later modules
6. Design a brief assessment (3-5 questions) for every 2-3 modules to check understanding

## Output
Structure your response as:

### Learning Objectives
- [List 3-5 objectives]

### Module [Number]: [Title]
**Format:** [video/infographic/interactive/quiz]  
**Duration:** [X minutes]  
**Content:**
- [Teaching point 1]
- [Teaching point 2]
- [Teaching point 3]

**Active learning:** [Specific activity]  
**Spaced repetition:** [Concepts from previous modules to reinforce, if applicable]

### Assessment Checkpoints
- After Module [X]: [Brief description of 3-5 question assessment]

[Repeat structure for all modules]
```
