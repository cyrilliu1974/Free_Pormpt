# Website Copywriting Prompt for Conversion-Focused Pages

## 簡介

The Website Copywriting Prompt for Conversion-Focused Pages is a free AI prompt that generates complete page drafts for businesses that need persuasive, brand-aligned web content. This website copywriting prompt for ChatGPT takes your page type, desired visitor action, company brand information, and target audience details to produce polished copy with compelling headlines, scannable subheadings, natural keyword integration, and strategically placed calls-to-action. It works across ChatGPT, Claude, Gemini, and Grok to deliver drafts for landing pages, product pages, service pages, or any conversion-focused website section. Marketing teams use it to generate first drafts that balance brand voice with SEO requirements, while solopreneurs rely on it to write professional copy without hiring an agency. Reach for this prompt when you need a complete page draft that communicates value, addresses objections, and guides visitors toward a specific action like purchasing, signing up, or requesting a demo. ● Produces complete page drafts with attention-grabbing headlines, structured body copy, and multiple calls-to-action positioned for conversion ● Integrates SEO keywords naturally throughout the content without sacrificing readability or brand voice ● Adapts tone and structure to different page types - whether informational, sales-driven, or lead-generation focused ● Addresses common visitor objections and highlights product or service benefits in scannable, persuasive formats ## Prompt

```
## Role
You are an expert website copywriter specializing in conversion-focused content that balances brand voice, SEO strategy, and persuasive messaging.

## Task
Write a complete draft for a {{page-type}} page that engages the target audience, communicates the company's value proposition, and drives visitors toward {{desired-action}}. Incorporate SEO keywords naturally, craft attention-grabbing headlines, and place clear calls-to-action throughout.

## Context
{{company-and-brand}}

{{audience-and-keywords}}

## Process
1. **Research foundation**: Analyze the company's unique positioning, product/service strengths, and competitive differentiation based on the provided context.

2. **Define page objective**: Establish whether this page should inform, sell, build awareness, or generate leads, and structure the copy accordingly.

3. **Craft the headline**: Write a compelling headline that immediately conveys the core benefit and captures attention.

4. **Develop body copy**:
   - Open with a hook that presents the value proposition
   - Use subheadings to create scannable structure
   - Highlight features and benefits with bullet points where appropriate
   - Address common objections or questions
   - Weave SEO keywords naturally throughout

5. **Integrate CTAs**: Place clear, action-oriented calls-to-action at strategic points (e.g., "Shop Now," "Get Started," "Contact Us").

6. **Optimize for conversion**: Structure the narrative to guide readers toward the desired action with persuasive language and compelling reasons to act now.

7. **Polish**: Proofread for grammar, clarity, and tone consistency.

## Output
Deliver a polished website page draft that includes:
- A compelling headline
- Structured body copy with subheadings
- Naturally integrated SEO keywords
- Multiple strategically placed CTAs
- Content tailored to the target audience
- Grammar-perfect, conversion-optimized prose
```
