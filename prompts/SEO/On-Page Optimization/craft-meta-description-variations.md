# Meta Description Variations Generator

## 簡介

The Meta Description Variations Generator is a free AI prompt that creates multiple tested meta description options for products, each emphasizing a different conversion angle to maximize click-through rates from search results. This meta description prompt for ChatGPT produces 5-7 unique variations per product, each staying within Google's 150-160 character display limit and built around a distinct psychological strategy: emotional benefits, practical advantages, urgency, social proof, or problem-solving. You provide your product details, and the prompt analyzes the core benefits and audience motivations before crafting variations optimized for A/B testing. Each output includes the meta description text with character count, the psychological strategy employed, and the audience segment it will resonate with most. The prompt runs on ChatGPT, Claude, Gemini, and Grok, making it ideal for SEO professionals, e-commerce managers, and digital marketers who need multiple meta description options quickly. ● Produces 5-7 unique meta descriptions per product, each using different power words and psychological triggers to avoid redundant phrasing. ● Enforces Google's 150-160 character limit automatically, ensuring every variation displays correctly in search results without truncation. ● Labels each variation with its strategy (urgency, social proof, benefit-focused) and ideal audience context for informed A/B testing decisions. ● Analyzes product details to extract the strongest unique selling propositions and audience pain points before writing. ## Prompt

```
## Role
You are an SEO copywriter specializing in meta descriptions that drive above-average click-through rates.

## Task
Create 5-7 distinct meta description variations for a product, each emphasizing a different angle: emotional benefits, practical advantages, urgency, social proof, or problem-solving. Each variation must stay within 150-160 characters to fit Google's display limits.

## Context
Meta descriptions function as the digital storefront—they determine whether users click through from search results. Effective descriptions combine power words, action-oriented language, and clear value propositions. Each variation should use unique phrasing to enable A/B testing.

Analyze the product details below to identify the strongest benefits, unique selling propositions, and audience motivations before writing.

{{product-details}}

## Output
For each variation, provide:
- **Variation [N]:** The meta description text (character count in parentheses)
- **Strategy:** The psychological approach used (e.g., urgency, social proof, benefit-focused)
- **Best for:** The audience segment or context where this variation will perform strongest

Avoid duplicate phrasing across variations. Use concrete, specific language over generic claims.
```
