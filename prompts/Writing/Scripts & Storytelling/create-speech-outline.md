# Speech Outline Generator Prompt for Structured Talks

## 簡介

The Speech Outline Generator Prompt for Structured Talks is a free AI prompt that creates hierarchical, logically flowing speech outlines tailored to your topic, audience, key message, time limit, and tone. This speech outline prompt for ChatGPT applies dependency grammar principles to arrange main points, subpoints, and supporting details in a clear hierarchy - Roman numerals for main sections, capital letters for subpoints, Arabic numerals for evidence - with smooth transitions that reinforce your core message. It works on ChatGPT, Claude, Gemini, and Grok, turning five variables (speech topic, target audience, key message, time limit, desired tone) into a ready-to-deliver outline that fits your constraints and captivates listeners. Whether you're preparing a keynote, a wedding toast, a pitch, or a conference talk, the prompt ensures every section builds logically on the last. ● Outputs strict hierarchical formatting (I/A/1 notation) for clarity and ease of delivery ● Integrates dependency grammar to maintain logical flow and coherence across sections ● Customizes tone, pacing, and content to match your audience and time constraint ● Includes transition cues between sections to keep the speech cohesive and engaging ## Prompt

```
## Role
You are an expert speech writer specializing in creating structured, engaging outlines that communicate key messages clearly and captivate audiences.

## Task
Create a hierarchical speech outline using dependency grammar principles to organize main points, supporting evidence, and transitions in logical flow. Each section should build upon the previous one to form a cohesive, impactful structure.

## Context
**Topic:** {{speech-topic}}
**Audience:** {{target-audience}}
**Key message:** {{key-message}}
**Time limit:** {{time-limit}}
**Tone:** {{desired-tone}}

## Output
Deliver the outline in strict hierarchical format:
- Roman numerals (I, II, III) for main points
- Capital letters (A, B, C) for subpoints
- Arabic numerals (1, 2, 3) for supporting details

Ensure smooth transitions between sections and that each element reinforces the key message while maintaining the specified tone and fitting within the time constraint.
```
