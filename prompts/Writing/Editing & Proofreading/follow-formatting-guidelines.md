# Document Formatting Guidelines Generator

## 簡介

The Document Formatting Guidelines Generator is a free AI prompt that creates detailed formatting and style standards for any document type tailored to specific audiences and industries. This document formatting prompt for ChatGPT uses dependency grammar principles to build structured guidelines that cover heading hierarchy, paragraph formatting, visual elements, language conventions, and accessibility standards. It analyzes your document type - whether technical reports, marketing materials, legal documents, or academic papers - and produces a numbered guide with subsections for structure, typography, language, visual elements, and readability. Works across ChatGPT, Claude, and Gemini to deliver formatting rules that ensure clarity, consistency, and professionalism in every document your team produces. Ideal for content teams, technical writers, documentation specialists, and anyone responsible for establishing or maintaining organizational style standards across multiple document types. ● Analyzes structural requirements specific to your document type and industry context ● Establishes clear heading hierarchies, paragraph standards, and spacing rules using dependency grammar ● Defines language conventions including tone, terminology, and sentence length appropriate for your target audience ● Includes accessibility and readability standards for font choices, contrast, white space, and plain language ● Delivers guidelines as an organized numbered list with subsections for easy implementation and team adoption ## Prompt

```
## Role
You are an expert document formatter specializing in creating comprehensive formatting and style guidelines.

## Task
Create detailed formatting guidelines for {{document-type}} that ensure clarity, consistency, and professionalism. Structure your recommendations using dependency grammar principles to establish clear hierarchical relationships between document elements.

## Context
**Document specifications:**
- Document type: {{document-type}}
- Target audience: {{target-audience}}
- Industry context: {{industry-context}}

## Process
1. Analyze the structural requirements specific to this document type
2. Identify key elements (sections, headings, data presentation) and their hierarchical dependencies
3. Map the logical flow of information from opening to conclusion
4. Define formatting standards for:
   - Heading hierarchy (H1, H2, H3)
   - Paragraph structure and spacing
   - Lists, tables, and visual elements
   - Citations and references (if applicable)
5. Establish language conventions:
   - Appropriate tone and voice for the audience
   - Terminology standards
   - Sentence and paragraph length guidelines
6. Include accessibility and readability best practices (contrast, font choices, white space, plain language)

## Output
Deliver the guidelines as a numbered list with clear subsections for each major formatting aspect (structure, typography, language, visual elements, accessibility).
```
