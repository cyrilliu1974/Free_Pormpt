# Guest Post Outline Generator for Link Building

## 簡介

The Guest Post Outline Generator for Link Building is a free AI prompt that creates research-backed guest post outlines designed to earn backlinks and establish authority in your niche. This guest post prompt for ChatGPT helps content strategists and SEO professionals build structured article frameworks that match a target blog's editorial style and audience expectations. It applies dependency grammar principles to ensure logical flow, identifies reader pain points, and maps out where to place credibility elements like statistics, case studies, and expert quotes. The prompt runs on ChatGPT, Claude, Gemini, and Grok, producing markdown-formatted outlines with introduction hooks, 3-5 main sections, and conclusions that naturally incorporate your desired backlink as a resource rather than a sales pitch. Use this prompt when pitching guest posts to authority sites in your industry, when you need to align content with a publication's voice, or when building a link-building campaign that prioritizes editorial value over promotional copy. ● Researches target blog style and audience before generating the outline structure ● Maps logical section flow using dependency grammar so each point builds on prior context ● Identifies strategic placement for data, quotes, and case studies to boost credibility ● Incorporates backlinks naturally as resources rather than promotional insertions ## Prompt

```
## Role
You are an expert content strategist specializing in guest posts that build authority and earn backlinks.

## Task
Create a structured outline for a guest post targeting {{target-blog}}. The post must align with the blog's audience and editorial style while establishing thought leadership in {{niche}}.

## Context
Your unique value: {{usp}}

The outline should use dependency grammar principles—each sentence and section building logically on what precedes it. Research the target blog's recent content, audience pain points, and trending topics in the niche before outlining.

## Output
Deliver a complete outline with:

**Introduction**
- Hook that addresses a pressing reader problem or curiosity gap
- Brief context establishing relevance
- Clear thesis previewing the unique angle

**Main Body (3-5 sections)**
For each section:
- Descriptive subheading
- 2-4 key points with placeholders for supporting evidence (statistics, case studies, expert quotes, or original research)
- Logical flow showing how each section depends on and builds from the previous

**Conclusion**
- Synthesis of main insights
- Actionable takeaway for readers
- Subtle authority signal (one natural reference to {{desired-backlink}} as a resource, not a pitch)

Format the outline using markdown headings (###) and bullet points. Indicate where credibility elements (data, quotes, examples) should be inserted.
```
