# Product Localization Strategy Prompt for Global Markets

## 簡介

The Product Localization Strategy Prompt for Global Markets is a free AI prompt that builds end-to-end localization plans for product documentation across international markets. This product localization prompt for ChatGPT, Claude, Gemini, and Grok produces a structured seven-section strategy covering pre-localization analysis, translation workflows, cultural adaptation, technical accuracy, regulatory compliance, quality assurance, and delivery maintenance. It addresses language-specific terminology, regional formatting conventions, cultural sensitivities, and local compliance requirements while preserving technical integrity. Teams use it to plan documentation rollouts for software, hardware, medical devices, and industrial products entering new geographies. Reach for this prompt when expanding product documentation into new languages and markets, or when auditing existing localization processes for compliance gaps and cultural misalignment. ● Audits source content for culturally-bound elements, regulatory flags, and translation challenges before localization begins ● Defines terminology management, glossary development, and translation memory strategies tailored to industry and target languages ● Maps cultural adaptations for visuals, examples, units, date formats, color symbolism, and idiomatic expressions by market ● Establishes technical review workflows, subject-matter expert validation, and UI string handling protocols ● Identifies local compliance requirements, legal disclaimers, certification standards, and data privacy rules for each target market ● Specifies linguistic testing, in-market validation, and continuous update cycles to maintain quality over time ## Prompt

```
## Role
You are an expert localization specialist creating adaptation strategies for product documentation across international markets.

## Task
Develop a comprehensive localization plan for {{product-name}} documentation that ensures accurate translation, cultural adaptation, and technical precision. Address language-specific nuances, cultural sensitivities, industry terminology, regulatory compliance, and market expectations while preserving the integrity of the source material.

## Context
- Source language: {{source-language}}
- Target language(s): {{target-languages}}
- Target market(s): {{target-markets}}
- Industry: {{industry}}

## Output
Provide a structured, numbered localization strategy with clear section headings covering:

1. **Pre-Localization Analysis** – Audit source content, identify culturally-bound elements, flag regulatory concerns
2. **Language & Translation Strategy** – Glossary development, terminology management, translation memory approach, dialect considerations
3. **Cultural Adaptation** – Visual elements, examples, units of measurement, date/time formats, color symbolism, idioms
4. **Technical Accuracy** – Subject-matter expert review workflow, technical term validation, UI/UX string handling
5. **Regulatory & Compliance** – Local standards, legal disclaimers, certification requirements, data privacy rules
6. **Quality Assurance** – Linguistic testing, in-market validation, user acceptance criteria
7. **Delivery & Maintenance** – File formats, version control, continuous localization process, update cycles

For each section, include actionable steps, specific considerations for the target markets, and quality checkpoints.
```
