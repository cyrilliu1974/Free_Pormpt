# eCommerce SEO Platform Comparison Prompt

## 簡介

The eCommerce SEO Platform Comparison Prompt is a free AI prompt that produces a systematic evaluation of no-code website builders based on their search infrastructure, technical SEO foundation, and real-world performance for online stores. This eCommerce SEO platform comparison prompt for ChatGPT, Claude, Gemini, and Grok analyzes product page optimization, URL control, schema markup, Core Web Vitals, scalability thresholds at 100, 1,000, and 10,000+ products, and hidden costs buried in pricing tiers. It delivers a comparison matrix, platform deep-dives with actual performance data, scenario-based recommendations for startups through enterprise, and migration considerations. Store owners planning to launch or switch platforms use it to match technical SEO requirements with business scale and avoid costly lock-in. This prompt is built for eCommerce founders, growth marketers, and SEO consultants evaluating Shopify, BigCommerce, Wix, Squarespace, Webflow, and similar builders before committing. ● Compares product page SEO workflows, canonical tag control, sitemap generation, and robots.txt access across major no-code platforms. ● Identifies scalability breaking points and Core Web Vitals performance at different catalog sizes with transparent cost breakdowns. ● Maps integration ecosystems, API flexibility, international SEO capabilities, and migration difficulty for each builder. ● Delivers scenario-based recommendations aligned to startup, growing, and enterprise store profiles with implementation roadmaps. ## Prompt

```
## Role
You are an eCommerce SEO platform analyst with deep technical expertise in search infrastructure and hands-on experience building profitable online stores. You understand both the technical requirements for ranking and the business implications of platform choices at different scales.

## Task
Create a comprehensive, evidence-based comparison of no-code eCommerce website builders, focusing exclusively on their SEO capabilities and limitations. Evaluate platforms across critical dimensions that directly impact organic search performance and revenue.

Analyze each platform systematically:

1. **Product Page SEO**: How effectively does each platform handle product optimization, schema markup, and bulk editing workflows?

2. **Technical SEO Foundation**: Assess URL structure control, canonical tags, sitemap generation, robots.txt access, and Core Web Vitals performance. Distinguish between real control and surface-level features.

3. **Scalability & Performance**: Identify breaking points at 100, 1,000, and 10,000+ products. Include actual load times, mobile optimization, and CDN capabilities.

4. **Integration & Flexibility**: Map meaningful SEO tool integrations, API capabilities, data portability, and migration paths.

5. **True Cost of Ownership**: Expose transaction fees, bandwidth limits, required add-ons, and restrictions buried in fine print.

6. **International SEO**: Evaluate multi-language, multi-currency, and geo-targeting capabilities for businesses planning global expansion.

## Context
{{business-context}}

*Include in your business context: business model (B2C/B2B/DTC), product catalog size, target markets (local/national/international), current monthly traffic, SEO experience level (beginner/intermediate/advanced), monthly platform budget, and 12-month growth projections.*

## Output
Deliver your analysis in this structure:

### Executive Summary
Top 3 platform recommendations for the user's specific situation with one-sentence justifications.

### Comparison Matrix
| Platform | Product SEO | URL Control | Schema Support | Performance Score | Scalability Limit | True Monthly Cost | Best For |
|----------|------------|-------------|----------------|-------------------|-------------------|-------------------|----------|

### Platform Deep-Dives
For each major platform:

**[Platform Name]**
- **Core Strengths**: 3-4 key SEO advantages with specific examples
- **Critical Limitations**: Deal-breaker constraints and hidden friction points
- **Performance Data**: Actual Core Web Vitals scores from live stores
- **Pricing Reality**: Transparent cost breakdown including fees at scale
- **Ideal Customer Profile**: Business size, growth stage, and technical capability match

### Scenario-Based Recommendations
- **Startup Store (<100 products)**: Platform + justification
- **Growing Business (100-1,000 products)**: Platform + justification  
- **Established/Enterprise (1,000+ products)**: Platform + justification

### Migration Considerations
Data export capabilities, SEO impact during transition, and switching difficulty for each platform.

### Final Recommendation
One clear platform choice for the user's business context with implementation roadmap.

---

**Quality Standards**:
- Base recommendations on real-world performance data, not marketing claims
- Flag platforms with proprietary lock-in or poor data portability
- Prioritize features that directly impact organic traffic and conversion
- Include documented SEO success stories where available
- Address customer support quality for technical SEO issues
```
