# Correct Formatting Errors Prompt for ChatGPT

## 簡介

The Correct Formatting Errors Prompt for ChatGPT is a free AI prompt that reviews copy for formatting mistakes, layout inconsistencies, and presentation problems without changing your message. This formatting review prompt for ChatGPT works by analyzing your text structure, spacing, headings, bullets, and visual hierarchy, then returning a categorized list of errors with specific fixes and severity ratings (1-5 scale). Writers, editors, marketers, and content teams use it to catch spacing mistakes, inconsistent headings, broken bullet lists, and other layout flaws that hurt readability before publishing. It runs on ChatGPT, Claude, and Gemini to deliver a markdown-formatted review complete with corrected examples, best-practice guidelines, an overall presentation score, and prioritized action steps. Reach for this prompt when you need a formatting audit separate from content edits - ideal for final layout checks, brand-standard enforcement, or teaching teams proper document structure. ● Identifies specific formatting errors - headings, spacing, bullets, emphasis - and explains why each one disrupts clarity ● Rates every issue by severity (1-5) so you know which problems to fix first ● Provides correct usage examples and best-practice tips for every formatting element found in your copy ● Delivers an overall presentation score and a ranked list of the top three actions to improve layout quality ## Prompt

```
## Role
You are an expert copywriting reviewer specializing in formatting, structure, and presentation. You ensure professionalism and clarity through detailed analysis of layout and consistency.

## Task
Thoroughly review the provided copy for formatting errors and inconsistencies. Focus exclusively on presentation—not content or messaging. Identify each issue, explain the problem, recommend fixes, and rate severity.

## Copy to Review
{{copy}}

## Output
Return your review using this structure:

### Formatting Review Results 📝

**Current Issues Found**
- List each error type
- Explain the issue in detail
- Recommend a specific fix
- Rate severity (1-5, where 5 is critical)

**Proper Formatting Guidelines**
- Provide correct usage examples for key elements found in the copy
- Include best practice tips for each formatting element

**Overall Presentation Score**
- Rate the overall presentation (1-5 scale)

**Final Recommendations**
- List the top 3 actions to improve formatting and presentation

Use markdown formatting (headings, bullets, emphasis). Do not use XML tags.
```
