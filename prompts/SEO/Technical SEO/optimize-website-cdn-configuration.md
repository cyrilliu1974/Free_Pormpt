# CDN Configuration Guide for Website Speed Optimization

## 簡介

The CDN Configuration Guide for Website Speed Optimization is a free AI prompt that produces structured, actionable instructions for configuring a Content Delivery Network to accelerate website performance across diverse geographic regions. This CDN configuration prompt for ChatGPT walks you through the essential setup process in 5-7 clearly formatted steps, each breaking down the specific action required, implementation details, and the expected performance outcome. After analyzing your website URL, it covers initial CDN assessment, provider selection, DNS configuration, cache rule setup, and deployment verification, then adds 3-5 targeted optimization tips to maximize delivery speed. It runs on ChatGPT, Claude, Gemini, and Grok, making it accessible for any technical SEO workflow. Typical use cases include migrating static assets to edge servers, reducing latency for international users, and diagnosing slow load times caused by distant origin servers. Reach for this prompt when you need a repeatable, site-specific CDN implementation roadmap that accounts for geographical distribution and avoids generic advice. ● Provides 5-7 structured steps, each with action, details, and expected outcome for easy execution. ● Tailored to a specific website URL input, ensuring relevant configuration advice. ● Includes a dedicated section of 3-5 additional optimization tips beyond basic setup. ● Covers the full CDN workflow from initial assessment through deployment and verification. ## Prompt

```
## Role
You are an expert website performance engineer specialized in Content Delivery Network (CDN) configuration for optimal site speed across diverse geographical locations.

## Task
Provide a clear, step-by-step guide for configuring a CDN to improve site speed for users in various geographical locations.

## Context
Website URL: {{website-url}}

## Output
Present each step in this format:

**Step [number]:**
- **Action:** The specific action to be taken
- **Details:** Additional information or explanation about the action
- **Expected Outcome:** The anticipated result of completing the action

Provide 5-7 steps covering the essential CDN configuration process, from initial assessment through deployment and verification.

After the numbered steps, include a section titled **Additional Tips** with 3-5 optimization recommendations to enhance CDN effectiveness.

Keep explanations clear and actionable, avoiding unnecessary jargon.
```
