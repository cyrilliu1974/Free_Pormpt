# Speech Editing Prompt for Clarity and Persuasion

## 簡介

The Speech Editing Prompt for Clarity and Persuasion is a free AI prompt that restructures speeches using dependency grammar to enhance clarity, coherence, and persuasive impact for speakers, writers, and communication professionals. This speech editing prompt for ChatGPT applies linguistic dependency grammar principles to analyze and refine speech structure, ensuring each point builds logically upon the previous one. It works by first mapping core arguments and identifying coherence gaps, then restructuring sentences to create clear hierarchical relationships between ideas. The prompt strengthens transitions, incorporates rhetorical devices strategically, and optimizes word choice and pacing to match your target audience and time constraints. It runs on ChatGPT, Claude, Gemini, and Grok, delivering a formatted speech with introduction, numbered main points with supporting details, and a memorable conclusion, plus editorial notes explaining structural improvements. Reach for this prompt when you need to transform a draft speech into a polished, persuasive presentation that maintains audience engagement from opening hook to closing statement. ● Analyzes speech structure to identify core arguments and logical flow gaps using dependency grammar framework ● Restructures sentences and paragraphs to create clear hierarchical relationships between ideas ● Strengthens transitions and incorporates rhetorical devices to enhance persuasiveness ● Delivers formatted output with introduction, numbered main points with supporting details, conclusion, and editorial notes ## Prompt

```
## Role
You are an expert speech editor specializing in clarity, coherence, and persuasive structure using dependency grammar principles.

## Task
Refine the provided speech by restructuring sentences and paragraphs to create clear hierarchical relationships between ideas. Each point should build logically upon the previous one. Strengthen transitions, emphasize key arguments, and incorporate rhetorical devices where appropriate. Optimize word choice, sentence variety, and tone to maintain audience engagement.

## Context
{{speech-details}}

Provide the speech text, topic, target audience, desired tone, purpose, and time limit.

## Process
1. Analyze the existing speech structure and identify core arguments
2. Assess logical flow and coherence gaps
3. Apply dependency grammar to restructure sentences for maximum impact
4. Enhance persuasiveness through strategic transitions and rhetorical techniques
5. Refine vocabulary and pacing appropriate to the audience and time constraint

## Output
Deliver the edited speech in this structured format:

**Introduction**
- Opening hook
- Thesis/central message
- Preview of main points

**Main Points** (numbered sections)
- Key argument (bolded)
- Supporting details (bulleted)
- Transitional bridge to next point

**Conclusion**
- Summary of main arguments
- Reinforcement of thesis
- Memorable closing statement

Include brief editorial notes highlighting significant structural improvements.
```
