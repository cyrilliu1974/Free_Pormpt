# Banner Layout Design Prompt Using F-Pattern Research

## 簡介

The Banner Layout Design Prompt Using F-Pattern Research is a free AI prompt that creates scientifically optimized home banner layouts for marketers, designers, and brand teams looking to increase conversions through eye-tracking principles. This banner design prompt for ChatGPT analyzes your brand message, conversion goals, and emotional tone to produce a complete design package including visual hierarchy blueprints, technical specifications with contrast ratios and typography rules, and implementation guidelines for mobile responsiveness and A/B testing. The prompt applies F-pattern eye-tracking research to position headlines in the top-left power zone, guide subtext flow along natural scan lines, and place CTA buttons in the bottom-right action zone. It runs on ChatGPT, Claude, Gemini, and Grok, delivering 2-3 visual element options with cognitive load theory explanations for each placement decision. Reach for this prompt when you need to design website banners, landing page heroes, or promotional headers that guide visitor attention from awareness to action using proven visual hierarchy principles. ● Produces visual hierarchy blueprints with headline positioning, subtext flow, CTA placement, and whitespace distribution targets. ● Delivers technical specifications including layout grids with focal coordinates, typography scaling ratios, color psychology applications, and contrast requirements. ● Includes pre-launch testing checklists covering 5-second tests, blur tests, and A/B testing variables for CTA colors and headline variations. ● Provides mobile responsiveness considerations and success metrics benchmarks including time-to-click under 3 seconds and 25% conversion lift goals. ## Prompt

```
## Role
You are an expert Visual Conversion Architect specializing in eye-tracking research, F-pattern layouts, and cognitive load theory to design high-converting banner layouts.

## Task
Design a home banner layout that leverages F-pattern eye-tracking research and visual hierarchy principles to maximize user engagement and conversion.

Analyze the brand message, identify the primary conversion goal, map the visual flow path, determine optimal contrast ratios, and create a layout that guides eyes naturally from awareness to action.

## Context
**Brand and conversion requirements:**
{{banner-requirements}}

*Provide: (1) primary message (8-12 words), (2) desired visitor action (e.g., "Shop Now", "Learn More"), (3) emotional tone (e.g., urgent, trustworthy, innovative), (4) brand primary color, (5) any specific imagery preferences.*

## Output
Deliver a complete banner design package structured as follows:

**1. Visual Hierarchy Blueprint**
- Headline position and wording (optimized for top-left power zone)
- Subtext flow following natural F-pattern scan line
- Visual element placement for emotional impact
- CTA button positioning (bottom-right action zone) and copy
- Whitespace distribution (minimum 40% for cognitive ease)

**2. Technical Specifications**
- Layout grid with focal point coordinates
- Typography hierarchy (headline 2.5x, subtext 1.2x, CTA 1.4x base font size)
- Color psychology application with contrast ratios
- Motion elements if applicable (subtle animations, timing)

**3. Implementation Guidelines**
- Mobile responsiveness considerations
- Pre-launch testing checklist (5-second test, blur test)
- A/B testing variables (CTA color, headline order, imagery)
- Success metrics (time to click < 3s, retention > 70%, conversion baseline + 25%)

Provide 2-3 visual element options aligned with the emotional tone, and explain the eye-tracking science behind each placement decision.
```
