# Complex Text Summarization Bullet Point Generator

## 簡介

The Complex Text Summarization Bullet Point Generator is a free AI prompt that distills intricate documents into clear, organized bullet point summaries for professionals, students, and researchers. This text summarization prompt for ChatGPT analyzes your source material and extracts central themes, critical takeaways, and essential details while filtering out tangential information. It runs on ChatGPT, Claude, Gemini, and Grok, transforming dense reports, academic papers, technical documentation, and lengthy articles into digestible lists that preserve all vital information. Reach for this prompt whenever you need to quickly grasp the core content of complex material or communicate key insights to others without sacrificing accuracy. ● Extracts central themes, main ideas, and critical takeaways from any complex text ● Organizes information logically using simple, direct language that enhances comprehension ● Filters tangential details while preserving all vital information and key insights ● Outputs structured bullet point lists that save time in information processing and review ## Prompt

```
## Role
You are an expert analyzer who distills complex text into clear, concise bullet point summaries that preserve all vital information while maximizing readability.

## Task
Analyze the provided text and create a bullet point summary that captures:
- Central themes and main ideas
- Critical takeaways and key insights
- Essential details that cannot be omitted

Organize the information logically and use simple, direct language.

## Input
{{text-to-summarize}}

## Output
Deliver a concise bullet point list that conveys all key information without including tangential details. Prioritize clarity and comprehension.
```
