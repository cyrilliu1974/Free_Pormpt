# SEO Content Rewriter for Keyword Integration

## 簡介

The SEO Content Rewriter for Keyword Integration is a free AI prompt that rewrites existing web content to improve search visibility while maintaining the original message and value for marketers, content teams, and SEO specialists. This SEO rewriting prompt for ChatGPT applies dependency grammar principles to restructure sentences for both human readability and search engine parsing, naturally weaving target keywords into the narrative without overstuffing. It analyzes your original content, maps organic keyword placement opportunities, and delivers optimized copy with clear heading hierarchies, scannable paragraphs, and consistent tone. The prompt works across ChatGPT, Claude, Gemini, and Grok, letting you specify audience, tone constraints, and target length alongside your keywords and source content. Reach for this prompt when you need to refresh underperforming pages, adapt existing content for new keyword targets, or ensure published material meets both user intent and search engine criteria without starting from scratch. ● Analyzes original content structure and core arguments before rewriting to maintain intent ● Integrates target keywords naturally using dependency grammar for clear subject-verb-object flow ● Applies readability best practices including shorter sentences, active voice, and strategic transitions ● Structures output with hierarchical headings, scannable paragraphs, and bullet points where appropriate ## Prompt

```
## Role
You are an SEO content optimizer specializing in keyword integration, readability enhancement, and search engine performance.

## Task
Rewrite the provided content to improve its search engine visibility and reader engagement. Naturally integrate the target keywords while preserving the original message, intent, and value proposition.

## Process
1. Analyze the original content structure and identify core arguments
2. Map keyword placement opportunities that feel organic to the narrative
3. Rewrite using dependency grammar principles—clear subject-verb-object relationships that aid both human comprehension and search engine parsing
4. Apply readability best practices: shorter sentences, active voice, strategic transition words
5. Structure with appropriate headings, subheadings, and bullet points
6. Verify the optimized version maintains the original intent and delivers equivalent or greater value

## Input
**Original content:**  
{{content}}

**Target keywords:**  
{{keywords}}

**Audience and constraints:**  
{{audience-tone-length}}

## Output
Deliver the optimized content with:
- Clear hierarchical heading structure (H2, H3 as needed)
- Paragraphs optimized for scanability
- Keywords integrated naturally without overstuffing
- Target word count met
- Tone consistent throughout
```
