# Mobile Usability Audit Prompt for Technical SEO

## 簡介

The Mobile Usability Audit Prompt for Technical SEO is a free AI prompt that conducts thorough mobile usability audits to identify critical issues affecting user experience and search engine rankings. This mobile usability audit prompt for ChatGPT analyzes your website's mobile performance across nine key areas: Core Web Vitals (LCP, FID, CLS), responsive design, touch element sizing, font readability, interstitials, navigation structure, image optimization, structured data, and mobile crawlability. It produces a prioritized markdown table with three columns (Issue, Impact, Solution) containing 8-12 findings ranked by severity, making it ideal for SEO analysts, webmasters, and digital marketers working with ChatGPT, Claude, Gemini, or Grok. Reach for this prompt when you need to diagnose why mobile traffic underperforms, prepare technical SEO audits for clients, or benchmark your site against competitors. ● Surfaces page speed bottlenecks, viewport misconfigurations, and Core Web Vitals failures that harm rankings ● Identifies touch-target problems, pop-up interference, and navigation issues that increase bounce rates ● Evaluates image optimization, lazy loading, and structured data gaps affecting mobile indexing ● Delivers actionable solutions prioritized by severity so you fix high-impact problems first ## Prompt

```
## Role
You are an expert SEO analyst specializing in mobile usability audits.

## Task
Conduct a comprehensive mobile usability audit for {{website-url}}. Identify critical mobile SEO issues that affect user experience and search engine rankings, then provide actionable solutions.

## Context
Target audience: {{target-audience}}
Primary competitors: {{competitors}}
Current mobile traffic: {{mobile-traffic-percentage}}

Focus your analysis on:
- Page load speed and Core Web Vitals (LCP, FID, CLS)
- Mobile-responsive design and viewport configuration
- Touch element sizing and spacing
- Font readability and text scaling
- Interstitial and pop-up interference
- Mobile-friendly navigation and menu structure
- Image optimization and lazy loading
- Structured data implementation
- Mobile crawlability and indexing issues

## Output
Present your findings as a markdown table with three columns:

| Issue | Impact | Solution |
|-------|--------|----------|

Each row must contain:
- **Issue**: Specific mobile usability problem identified
- **Impact**: How it affects user experience, conversions, and search rankings
- **Solution**: Clear, actionable steps to resolve the issue

Prioritize issues by severity (critical, high, medium, low) and include 8-12 of the most impactful findings.
```
