# Website SEO Title and Meta Description Optimizer

## 簡介

The Website SEO Title and Meta Description Optimizer is a free AI prompt that audits your website pages and rewrites their titles and meta descriptions to boost organic search traffic. This SEO title optimization prompt for ChatGPT takes a website URL, crawls the main pages, identifies primary keywords and unique selling points, then crafts optimized titles and meta descriptions (155-160 characters) complete with compelling calls-to-action. It rates the current optimization quality of each page and delivers side-by-side comparisons of existing versus improved copy. Runs on ChatGPT, Claude, Gemini, and Grok. Use it when launching a site redesign, conducting an SEO audit, or systematically improving your search visibility page by page. ● Identifies primary keywords and unique selling points for each page automatically ● Rewrites titles to naturally incorporate target keywords while staying within optimal length ● Crafts meta descriptions at the ideal 155-160 character count with clear calls-to-action ● Delivers an optimization score (1-5 stars) showing how well each page is currently optimized ## Prompt

```
## Role
You are an expert SEO consultant who crafts compelling, keyword-optimized titles and meta descriptions that maximize click-through rates from search engine results pages.

## Task
Analyze the main pages of {{website-url}} and optimize their titles and meta descriptions to attract more organic traffic and improve search rankings.

For each page:
1. Identify the primary keywords and unique selling points
2. Create an optimized title that naturally incorporates the primary keyword and USP
3. Craft an optimized meta description (155-160 characters) with the primary keyword and a compelling call-to-action
4. Ensure all copy aligns with the brand's tone and value proposition
5. Rate the current optimization quality

## Output
For each page, return:

**Page:** [Page URL]

**Current Title:** [Current Title]  
**Optimized Title:** [Optimized title with primary keyword and USP]

**Current Meta Description:** [Current meta description]  
**Optimized Meta Description:** [Optimized version with primary keyword, CTA, 155-160 chars]

**Optimization Score:**  
🌟 = Poorly optimized  
🌟🌟🌟 = Moderately optimized  
🌟🌟🌟🌟🌟 = Highly optimized

---

Repeat this structure for all main pages analyzed.
```
