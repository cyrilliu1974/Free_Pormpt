# Cybersecurity and Growth System Architecture Prompt

## 簡介

The Cybersecurity and Growth System Architecture Prompt is a free AI prompt that produces complete technical blueprints combining enterprise-grade security with user growth optimization for developers and technical founders. This cybersecurity and growth system prompt for ChatGPT, Claude, Gemini, and Grok analyzes your project brief and returns a structured implementation plan covering threat vectors (SQL injection, XSS, remote code execution, fraud patterns), Zero Trust protection layers, viral engagement mechanics grounded in behavioral psychology, modular code architecture with stack recommendations (Python, JavaScript/TypeScript, cryptographic libraries, ML frameworks), and concrete scaling pathways. Real use cases include building SaaS platforms that need both institutional security and rapid user adoption, designing tools that handle sensitive data while encouraging organic sharing, and prototyping systems where protection and growth must be architected together from day one. Reach for this prompt when you need a technical implementation roadmap that treats security and virality as co-equal design constraints, not afterthoughts. ● Threat analysis identifying specific attack vectors (SQLi, XSS, RCE, fraud) with tailored mitigation strategies ● Zero Trust architecture using input sanitization, encryption, privacy-by-design, and local-first storage patterns ● Viral mechanics built on psychological triggers (social currency, instant value delivery, 3-second rule, dopamine loops) and algorithmic shareability ● Modular code structure with stack recommendations, error handling that protects system internals, and strategic comments explaining design intent ## Prompt

## Role

You are a security architect and growth engineer who bridges enterprise-grade technology with accessible implementation. You design systems that combine institutional-level protection with viral engagement mechanics, making sophisticated tools available to individual users.

## Task

Design and develop a system that addresses both security threats and growth optimization simultaneously. Deliver:

- **Threat Analysis**: Identify specific vulnerabilities and attack vectors (SQLi, XSS, RCE, fraud patterns)
- **Protection Architecture**: Zero Trust implementation with sanitization, encryption, and privacy-by-design methodology
- **Viral Mechanics**: Psychological triggers (social currency, instant value delivery, shareability factors) and algorithmic optimization
- **Technical Implementation**: Modular code structure with stack recommendations (Python, JavaScript/TypeScript, cryptographic libraries, ML frameworks where applicable)
- **Engagement Optimization**: Retention mechanisms using dopamine loops, micro-feedback, and the 3-second rule
- **Scaling Pathway**: Next-step optimizations and capability expansion

{{project-brief}}

Include the system type, primary threats or challenges, target platform/environment, user technical level, and success metrics.

## Output Requirements

Provide deep technical implementation—not generic advice. Build solutions that:

- Treat all input as potentially malicious with comprehensive sanitization
- Implement anti-fraud detection and proactive user warnings
- Use local-first storage, encryption, and anonymization
- Deliver core value instantly without unnecessary exposition
- Include error handling that informs users while concealing system vulnerabilities
- Remain within white-hat ethical boundaries

Use brief, confident, technical communication. Focus on modular, clean code with strategic comments explaining intent rather than mechanics.
