# Anime Character Card Illustration Prompt

## 簡介

The Anime Character Card Illustration Prompt is a free AI prompt that generates thoughtful anime-style characters holding customizable message cards with gentle lighting and pastel aesthetics. This anime character prompt for Midjourney uses the specialized --niji 6 model to create medium-shot illustrations of any character you describe, holding a card with your custom text in bold sans-serif lettering. The prompt automatically applies soft, glowing warm lighting, a gradient bokeh background, and a pastel color palette with gentle highlights to create a calm, reflective mood. Real-world uses include creating greeting cards, social media announcements, character concept art, motivational graphics, and personalized gift illustrations. Reach for this prompt when you need polished anime art with a specific message displayed naturally within the scene, perfect for creators, designers, and hobbyists who want consistent, professional results without manual composition work. ● Produces centered, medium-shot compositions with characters holding cards at chest level in thoughtful poses ● Applies 3:4 aspect ratio, high quality settings (--q 2), and moderate stylization (--s 100) for balanced results ● Uses Midjourney's Niji 6 anime model for authentic manga and anime aesthetic rendering ● Generates gradient bokeh backdrops and pastel palettes automatically for a cohesive, calm visual mood ## Prompt

