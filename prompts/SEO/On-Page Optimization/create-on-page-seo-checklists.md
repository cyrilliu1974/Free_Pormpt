# On-Page SEO Checklist Generator

## 簡介

The On-Page SEO Checklist Generator is a free AI prompt that creates customized, actionable on-page optimization checklists for website owners, marketers, and SEO professionals. The prompt produces structured checklists covering content metadata (title tags, meta descriptions, header hierarchy), technical implementation (Core Web Vitals, schema markup, canonical tags), and image optimization, complete with character limits, common pitfalls, and verification tools. This on-page SEO prompt for ChatGPT, Claude, Gemini, and Grok adapts to your website context and SEO experience level, delivering priority-ranked steps that balance technical precision with user-focused strategy. Reach for this prompt when you need a systematic audit framework, when onboarding clients or team members to SEO standards, or when preparing a site migration or content refresh that requires comprehensive optimization coverage. ● Produces organized checklists spanning content metadata (title tags with 50-60 character limits, meta descriptions at 150-160 characters, header tag hierarchy), image optimization (alt text, file naming, compression), and internal linking strategy. ● Includes technical implementation steps for mobile responsiveness, Core Web Vitals optimization, JSON-LD schema markup, robots meta tags, and canonical tag configuration. ● Specifies verification tools for each element (Google Search Console, PageSpeed Insights, schema validators) and flags common mistakes to avoid. ● Tailors priority indicators (critical, recommended, advanced) to your declared SEO experience level, ensuring beginners focus on high-impact fundamentals while advanced users see nuanced technical opportunities. ## Prompt

```
## Role
You are an expert SEO strategist specializing in on-page optimization, technical implementation, and user experience.

## Task
Create a comprehensive, immediately actionable on-page SEO optimization checklist covering all critical elements for improving search rankings and user engagement. Include specific character limits, best practices, common pitfalls to avoid, and verification methods.

## Context
{{website-context}}

Successful on-page optimization balances technical precision with user-focused content strategy, ensuring every element serves both search engines and human visitors.

## Checklist Structure
Organize the checklist logically from foundational content elements to advanced technical implementation:

**Content & Metadata**
- Title tag optimization: primary keyword integration, readability guidelines, character limits (50-60 chars)
- Meta descriptions: compelling copy that drives click-through rates (150-160 chars)
- Header tag hierarchy (H1-H6): proper semantic structure
- Image optimization: descriptive alt text, file naming, compression
- Internal linking: strategic anchor text and authority distribution
- URL structure: SEO-friendly construction (short, descriptive, keyword-rich)

**Technical Implementation**
- Mobile responsiveness validation
- Page speed optimization techniques (Core Web Vitals)
- Schema markup implementation (JSON-LD preferred)
- Indexation controls: robots meta tags, noindex/nofollow directives
- Canonical tags: duplicate content prevention

## Output Format
Deliver as a comprehensive bullet-point checklist with:
- Clear category headers
- Specific, actionable steps for each optimization element
- Character limits and technical specifications where applicable
- Common mistakes to avoid for each item
- Tools or methods for verification (e.g., Google Search Console, PageSpeed Insights, schema validators)
- Priority indicators tailored to {{seo-experience-level}} (critical/recommended/advanced)
```
