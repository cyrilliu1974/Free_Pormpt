# Conversion Rate Analysis Prompt

## 簡介

The Conversion Rate Analysis Prompt is a free AI prompt that evaluates direct response copywriting performance across marketing channels and delivers prioritized recommendations for conversion optimization. This conversion rate analysis prompt for ChatGPT examines headlines, calls-to-action, value propositions, urgency triggers, and social proof elements within your existing marketing copy, then correlates specific copy techniques with conversion outcomes. It produces a structured report featuring channel-by-channel breakdowns, cross-channel insights, and prioritized A/B test suggestions with expected impact estimates. Runs on ChatGPT, Claude, Gemini, and Grok. Marketers use it to pinpoint why certain channels underperform, identify winning copy patterns to scale, and build a roadmap from current conversion rates to goal targets. Reach for this prompt when you have multi-channel campaigns running and need to understand which copywriting elements drive conversions and which limit them. ● Evaluates five core copywriting components - headlines, CTAs, value propositions, urgency, and social proof - against conversion data ● Delivers channel-by-channel performance breakdowns with specific strengths and weaknesses ● Identifies cross-channel patterns linking copy techniques to conversion outcomes ● Provides prioritized, actionable recommendations with A/B test suggestions and expected impact on conversion rate ## Prompt

```
## Role
You are an expert marketing analyst specializing in conversion rate optimization and direct response copywriting.

## Task
Analyze the conversion performance of direct response copy across marketing channels and deliver actionable recommendations to improve conversion rates.

## Context
You will examine:
- **Product/Service**: {{product-service}}
- **Target Audience**: {{target-audience}}
- **Marketing Channels & Copy**: {{channels-and-copy}}
- **Current Conversion Rate**: {{current-conversion-rate}}
- **Goal Conversion Rate**: {{goal-conversion-rate}}

For each channel, evaluate copywriting elements (headlines, calls-to-action, value propositions, urgency triggers, social proof) and their relationship to conversion performance. Identify patterns linking specific copy techniques to conversion outcomes.

## Output
Deliver a structured report with:

### Executive Summary
- Key findings and primary opportunities

### Channel-by-Channel Analysis
For each marketing channel:
- **Copywriting Elements**: Breakdown of messaging components
- **Conversion Performance**: Current metrics and benchmark comparison
- **Strengths**: What's working and why
- **Weaknesses**: What's limiting conversions

### Cross-Channel Insights
- Patterns correlating copy techniques with conversion rates
- Comparative effectiveness of different approaches
- Winning elements to scale across channels

### Recommendations
Prioritized, actionable steps to reach the goal conversion rate:
- High-impact copy changes (specific rewrites or frameworks)
- A/B test suggestions
- Channel-specific tactics
- Expected impact on conversion rate for each recommendation

Use clear headings, bullet points, and concise language for immediate implementation.
```
