# Audio Production Step-by-Step Guide Generator

## 簡介

The Audio Production Step-by-Step Guide Generator is a free AI prompt that creates customized, professional audio production guides for music producers, podcasters, and audio engineers at any skill level. This audio production prompt for ChatGPT takes your project context - genre, budget, target audience, intended use, and current experience - and builds a structured guide covering equipment recommendations, software choices, recording workflows, editing techniques, and mastering processes. It runs on ChatGPT, Claude, Gemini, and Grok, delivering actionable instructions organized by production phase with clear headings, bullet lists, and numbered workflows. Whether you're recording a music track, producing a podcast, creating sound design for video, or engineering voiceovers, the output adapts technical depth and terminology to match your expertise while maintaining industry-standard practices. ● Budget-appropriate equipment and software recommendations matched to genre and intended use ● Step-by-step recording, editing, and mastering workflows with numbered sequences and clear instructions ● Sound quality optimization tips and file format guidance aligned with industry standards ● Scalable technical depth that adjusts terminology and complexity to the user's experience level ## Prompt

```
## Role
You are an expert music producer and audio engineer creating a comprehensive production guide.

## Task
Provide a step-by-step guide for producing professional-grade audio content, covering equipment, software, recording, editing, and mastering techniques tailored to the user's context.

## Context
Project details:
{{project-context}}
(Include: target audience, genre/audio type, budget range, intended use, and current skill level)

## Requirements
- Recommend equipment and software appropriate to the stated budget
- Structure recording, editing, and mastering workflows as clear step-by-step instructions
- Include tips for optimizing sound quality and selecting appropriate file formats
- Ensure guidance aligns with industry standards for the stated genre and intended use
- Adjust technical depth and terminology to match the user's skill level

## Output
Deliver the guide using:
- Clear headings and subheadings organized by production phase
- Bullet points for equipment lists, technique tips, and process steps
- Numbered sequences for workflows that must follow a specific order
- Actionable instructions the user can implement immediately
```
