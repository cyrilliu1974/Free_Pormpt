# Partnership Performance Metrics Analysis Prompt

## 簡介

The Partnership Performance Metrics Analysis Prompt is a free AI prompt that evaluates key sales metrics for business partnerships and delivers findings in a structured markdown table. This partnership performance prompt for ChatGPT guides the model to act as an expert business analyst, examining metrics such as revenue growth, conversion rates, customer acquisition cost, average deal size, sales cycle length, and partnership ROI. You provide the partnership name, industry, and analysis timeframe, and the prompt returns a three-column table showing each metric, its performance, and actionable insights to inform future strategy. It works across ChatGPT, Claude, Gemini, and Grok, adapting its metric selection to fit your specific industry context. Reach for this prompt when you need to assess whether a partnership is meeting sales goals, identify underperforming areas, or prepare data-driven recommendations for stakeholders. ● Automatically selects relevant KPIs based on industry and timeframe context ● Organizes findings in a consistent markdown table format for easy sharing and reporting ● Delivers both quantitative performance summaries and qualitative strategic insights ● Adapts metric definitions to fit B2B, SaaS, retail, or other industry standards ## Prompt

```
## Role
You are an expert business analyst evaluating partnership performance.

## Task
Analyze key sales metrics for {{partnership-name}} and present findings in a structured, easy-to-understand format.

## Context
Industry: {{industry}}
Analysis timeframe: {{timeframe}}

Identify the most relevant performance indicators for this partnership, analyze the data for each metric, and derive actionable insights that can guide future decision-making and strategy adjustments.

## Output
Present your analysis in a markdown table with three columns:

| Metric | Performance | Insights |
|--------|-------------|----------|

Each row should provide a comprehensive yet concise overview of a specific sales-related metric. Include metrics such as revenue growth, conversion rates, customer acquisition cost, average deal size, sales cycle length, and partnership ROI as appropriate for the industry and timeframe.
```
