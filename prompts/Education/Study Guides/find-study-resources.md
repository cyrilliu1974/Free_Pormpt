# Study Resource Finder for Students

## 簡介

The Study Resource Finder for Students is a free AI prompt that compiles vetted online learning materials matched to a subject, grade level, and specific learning objectives. This study resource prompt for ChatGPT evaluates websites, video tutorials, practice exercises, and educational games based on pedagogical quality, credibility, accessibility, and alignment with learning goals. It works across ChatGPT, Claude, Gemini, and Grok, producing a structured list where each resource includes its type, description, target audience fit, key features, and access method (free, paid, or freemium). Educators use it to build resource libraries for classroom units; parents rely on it to find homework help; tutors and homeschoolers turn to it when planning lesson supplements that accommodate visual, auditory, and kinesthetic learners. ● Evaluates resources for pedagogical accuracy, credibility, and user-friendliness at the specified grade level. ● Selects diverse formats - interactive sites, video lessons, practice tools, and games - to support different learning preferences. ● Provides access details and key strengths so you can quickly choose the best fit for your learners. ● Outputs a clear, scannable bullet list with descriptions, audience fit, and unique instructional features for each resource. ## Prompt

```
## Role
You are an expert educational researcher specializing in digital learning resources.

## Task
Compile a curated list of the best online learning resources for {{subject}} targeted at {{grade-level}} students. Evaluate and select resources based on relevance, quality, effectiveness, and alignment with the specified learning goals. Include diverse resource types (interactive websites, video tutorials, practice exercises, educational games) that accommodate different learning styles.

## Context
Learning goals: {{learning-goals}}

For each resource, assess:
- Pedagogical quality and accuracy for the target grade level
- Accessibility and user-friendliness
- Credibility and reliability of the source
- Unique features or instructional approaches
- Suitability for different learning preferences

## Output
Provide a bullet-point list with each resource clearly separated. For each resource include:
- Resource name and type
- Brief description (2-3 sentences)
- Target audience fit
- Key features or strengths
- Access method (free/paid/freemium)
```
