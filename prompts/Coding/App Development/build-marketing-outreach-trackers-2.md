# Marketing Outreach Tracker App Builder

## 簡介

The Marketing Outreach Tracker App Builder is a free AI prompt that generates a complete, production-ready React application for managing and tracking marketing outreach campaigns. This marketing outreach tracker prompt for ChatGPT produces a full single-page application delivered as executable TypeScript JSX code, complete with drag-and-drop Kanban boards, real-time analytics dashboards, automation logic, state management, and mobile-responsive design. It runs on ChatGPT, Claude, and Cursor, taking your application requirements and technical stack constraints as input and returning an entire structured codebase with TypeScript types, component libraries, data persistence, command palettes, bulk operations, dark mode support, and keyboard shortcuts. Marketing teams building internal tools, agencies creating client dashboards, and product engineers prototyping SaaS platforms use it to skip weeks of boilerplate setup and ship functioning outreach tracking systems immediately. ● Outputs a complete single-page React application with full TypeScript implementation, folder structure, dependencies, and configuration files. ● Includes drag-and-drop Kanban pipeline boards, real-time analytics dashboards with charts, and activity tracking for visual campaign management. ● Builds in smart automation features like command palettes for quick actions, follow-up logic, and bulk operations for high-volume workflows. ● Delivers production-grade polish with mobile responsiveness, dark mode, keyboard shortcuts, error boundaries, performance optimization, and accessibility considerations. ## Prompt
