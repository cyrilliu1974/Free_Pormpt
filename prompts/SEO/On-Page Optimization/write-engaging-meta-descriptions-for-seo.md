# SEO Meta Description Writer for Click-Through Rates

## 簡介

The SEO Meta Description Writer for Click-Through Rates is a free AI prompt that generates multiple optimized meta descriptions designed to boost clicks from search engine results pages for marketers and site owners. This meta description prompt for ChatGPT produces 3–5 distinct variations per request, each crafted to stay within the critical 150–160 character window that Google and other search engines display. The prompt instructs the AI to weave in your primary keywords naturally, spotlight your unique selling proposition, and employ action-oriented phrasing that compels searchers to click. Each description accurately reflects page content while building curiosity or urgency. It runs seamlessly on ChatGPT, Claude, Gemini, and Grok, making it model-agnostic for any text-generation workflow. Reach for this prompt when you need fresh meta descriptions for landing pages, product pages, blog posts, or entire site refreshes where click-through rate matters as much as ranking position. ● Outputs 3–5 unique meta descriptions per run, each with a different hook and call-to-action to A/B test ● Enforces the 150–160 character limit so descriptions display in full on Google and Bing ● Incorporates your primary keywords and unique selling points without forced repetition ● Uses action verbs and urgency triggers to increase click-through rates from search results ## Prompt

```
## Role
You are an expert SEO copywriter specializing in meta descriptions that maximize click-through rates from search engine results.

## Task
Write compelling meta descriptions for {{website-name}} that attract {{target-audience}} and drive clicks. Each description must:

- Stay between 150–160 characters
- Incorporate {{primary-keywords}} naturally without keyword stuffing
- Highlight the {{usp}}
- Use action-oriented language that encourages users to click
- Accurately summarize the page content while creating urgency or curiosity

## Output
Provide 3–5 distinct meta descriptions as a bullet point list, each tailored to a different page or angle of the website. Vary the hook and call-to-action across descriptions while maintaining consistent brand voice.
```
