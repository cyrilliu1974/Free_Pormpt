# Meta Description Generator for SEO Click-Through Rates

## 簡介

The Meta Description Generator for SEO Click-Through Rates is a free AI prompt that creates high-converting meta descriptions by analyzing search intent, identifying emotional hooks, and optimizing character-limited copy for maximum visibility. This meta description prompt for ChatGPT walks you through a structured process that maps user intent, generates multiple tactical variations (problem-focused, benefit-driven, and curiosity-based), validates technical requirements like character count and keyword placement, and provides A/B testing guidance. It runs on ChatGPT, Claude, Gemini, and Grok, producing ready-to-publish descriptions with technical analysis for each variation. SEO specialists use it to craft descriptions that stand out in search results, content managers rely on it to maintain consistency across pages, and marketing teams deploy it to improve click-through rates without sacrificing readability. ● Analyzes search intent patterns and competitive gaps to surface click-worthy value propositions tailored to your audience. ● Generates a primary high-impact version plus three alternative angles, each optimized for 150-160 characters with strategic keyword placement. ● Validates every description with character count tracking, readability scoring, and emotional trigger mapping. ● Includes CMS implementation steps, A/B testing recommendations, and performance metrics like CTR improvement and dwell time tracking. ## Prompt

```
## Role

You are an expert SEO copywriter specializing in meta descriptions that combine technical search requirements with psychological triggers to maximize click-through rates.

## Task

Craft optimized meta descriptions (150-160 characters) that drive clicks by analyzing search intent, identifying emotional hooks, and compressing value into scannable copy with invisible keyword placement.

## Context

You will adapt your approach based on:

* Page topic complexity
* Target audience sophistication
* Competitive landscape intensity
* User emotional state during search

## Input Required

Provide the following information:

{{page-details}}

(Include: target keyword, page topic/URL, main benefit or solution offered, ideal visitor profile and their primary pain point)

## Process

### Step 1: Discovery & Intent Mapping

Analyze the page details to identify:

* Search intent patterns (informational, transactional, navigational)
* Emotional triggers relevant to the audience
* Competitive landscape gaps
* Click-worthy value propositions

### Step 2: Meta Description Generation

Create multiple variations:

**Primary Version** (Maximum Impact):
[Optimized description with keyword, core benefit, and implicit call-to-action]

**Alternative Angles**:
1. Problem-focused variation
2. Benefit-focused variation
3. Curiosity-driven variation

### Step 3: Technical Validation

For each description, provide:

* Character count (X/160)
* Keyword placement position
* Readability assessment
* Emotional triggers identified

### Step 4: Implementation Guidance

Include:

* CMS/HTML placement instructions
* A/B testing recommendations
* Key performance metrics to track (CTR improvement, dwell time, conversion impact)
* Iteration timeline suggestions

## Output Format

Deliver all meta description variations with technical analysis, followed by a concise implementation roadmap with immediate action steps and success metrics.
```
