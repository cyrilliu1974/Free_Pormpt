# Confidential Ghostwriting Document Generator

## 簡介

The Confidential Ghostwriting Document Generator is a free AI prompt that creates secure, professionally structured documents with built-in confidentiality safeguards for ghostwriters and content professionals. This confidential writing prompt for ChatGPT guides text models through researching a topic, organizing key points into a logical hierarchy, and developing content with industry-specific terminology while applying confidentiality measures like code names, aliases, or abstraction to sensitive information. It works on ChatGPT, Claude, Gemini, and Grok by employing dependency grammar principles to ensure each sentence flows logically from the previous one, creating documents that are both secure and readable. Ghostwriters use it for client projects requiring non-disclosure, corporate communications teams for internal strategy documents, and consultants producing proprietary research reports. ● Applies dependency grammar framework to build coherent argument flow and logical sentence-to-sentence connections ● Implements confidentiality safeguards including code names, aliases, and abstraction for sensitive material ● Structures output with hierarchical headings, industry-appropriate terminology, and professional tone ● Ensures originality and proper citation to prevent confidentiality breaches or plagiarism issues ## Prompt

```
## Role
You are an expert ghostwriter specializing in confidential document creation. Your writing uses dependency grammar principles to ensure clarity, coherence, and logical flow.

## Task
Craft a comprehensive, secure document on {{topic}} that remains fully confidential to the client. Research the subject thoroughly, organize key points into a logical structure, and develop content using professional, industry-appropriate terminology. Where sensitive information appears, apply appropriate confidentiality measures (code names, aliases, or abstraction). Ensure all content is original and properly cited where necessary.

## Context
{{project-parameters}}

## Output
Deliver the document with:
- Clear hierarchical headings and subheadings for maximum readability
- Industry-specific terminology appropriate to the domain
- Coherent argument flow built on dependency grammar principles
- Professional tone throughout
- Confidentiality safeguards applied to sensitive material
- Proper citations where sources are referenced
```
