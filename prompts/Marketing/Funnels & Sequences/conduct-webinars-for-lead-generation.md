# Webinar Outline Generator for Lead Generation

## 簡介

The Webinar Outline Generator for Lead Generation is a free AI prompt that creates complete webinar structures for businesses seeking to convert attendees into qualified leads. This webinar outline prompt for ChatGPT builds a presentation framework that connects audience pain points to actionable solutions, incorporates your unique value proposition, and strategically positions calls-to-action throughout the flow. It runs on ChatGPT, Claude, Gemini, and Grok, applying dependency grammar principles so each section builds logically on the previous one. You input your business context, target audience pain points, unique value proposition, and desired call-to-action; the prompt returns a complete webinar structure from hook to close, including an introduction that establishes credibility, main content sections that address each pain point with supporting evidence, anticipated Q&A responses, and a conclusion with clear next steps. Marketing teams, sales professionals, and course creators use it to design lead-generation webinars that maintain engagement and drive conversions. ● Builds a logical content flow using dependency grammar so concepts build on one another naturally ● Creates hooks, credibility statements, and outcome previews tailored to your specific audience pain points ● Generates prepared answers for 3-5 anticipated questions to handle Q&A confidently ● Incorporates urgency elements and clear next-step instructions to convert attendees into leads ## Prompt

```
## Role
You are an expert webinar host and content strategist.

## Task
Create a structured webinar outline that generates qualified leads by addressing audience pain points and delivering actionable solutions. Organize the content using dependency grammar principles to ensure each section builds logically on the previous one.

## Context
**Business context:** {{business-and-audience}}

**Pain points to address:** {{pain-points}}

**Unique value proposition:** {{usp}}

**Call-to-action:** {{cta}}

## Output
Deliver a complete webinar structure with these sections:

### Introduction
- Hook that connects to the primary pain point
- Credibility establishment
- Preview of what attendees will learn
- Expected outcomes

### Main Content
- For each pain point: the underlying problem, why it matters, and one actionable solution
- Supporting evidence or case examples
- How your unique value proposition addresses these challenges
- Dependency flow: ensure each point builds on previous concepts

### Q&A
- 3-5 anticipated questions with prepared answers
- Transition strategy to the close

### Conclusion
- Key takeaways summary (3-4 bullets)
- Reinforcement of unique value proposition
- Clear call-to-action with next steps
- Urgency or incentive element

Format each section with clear headings and bullet points for all key talking points.
```
