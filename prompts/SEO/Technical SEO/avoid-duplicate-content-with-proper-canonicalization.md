# Canonicalization Strategy for Duplicate Content SEO

## 簡介

The Canonicalization Strategy for Duplicate Content SEO is a free AI prompt that builds a tailored technical SEO plan to prevent and resolve duplicate content issues across your website. This canonicalization prompt for ChatGPT analyzes your site structure, CMS platform, and current duplicate content challenges to deliver a seven-part implementation guide covering canonical tags, 301 redirects, internal linking optimization, robots.txt configuration, XML sitemaps, content consolidation, and URL parameter handling. It runs on ChatGPT, Claude, and Gemini, adapting technical depth to match your expertise level. Real-world use cases include fixing HTTP/HTTPS splits, managing product variant duplicates, resolving pagination issues, and consolidating ranking signals across www and non-www versions. Reach for this prompt when you need actionable canonicalization guidance customized to your specific CMS, technical constraints, and duplicate content patterns rather than generic SEO advice. ● Identifies high-priority duplicate content risks including pagination, URL parameters, product variants, and protocol inconsistencies ● Provides exact canonical tag syntax and placement instructions formatted for your CMS platform ● Delivers redirect rules and robots.txt directives ready to implement in your server environment ● Includes Search Console configuration steps and ongoing monitoring tasks to validate canonicalization effectiveness ## Prompt

```
## Role

You are an expert SEO specialist focused on technical optimization and duplicate content mitigation.

## Task

Develop a comprehensive canonicalization strategy tailored to the website and situation described below. Deliver step-by-step implementation guidance that matches the user's technical expertise level.

## Context

**Website and technical details:**
{{website-and-technical-context}}
(Include: website URL, CMS platform, technical skill level)

**Content and SEO situation:**
{{content-and-seo-challenges}}
(Include: primary content type, current duplicate content issues, ranking challenges)

## Analysis and Strategy

Analyze the website structure and identify:
- Areas where duplicate content is most likely (e.g., pagination, product variants, HTTP/HTTPS splits, www/non-www versions, URL parameters)
- High-priority pages that require canonical protection
- Technical constraints imposed by the CMS

## Output

Provide a structured canonicalization implementation plan organized into these sections:

### 1. Canonical Tag Implementation
- Specific pages/page types requiring canonical tags
- Exact tag syntax and placement instructions for the CMS
- Self-referencing canonical guidance for key pages

### 2. 301 Redirect Strategy
- URL patterns to redirect (duplicates, old URLs, parameter variations)
- Redirect rules formatted for the server/CMS environment
- Testing checklist

### 3. Internal Linking Optimization
- Link audit priorities
- Standardized URL format to use site-wide
- Navigation and footer link updates

### 4. Robots.txt and XML Sitemap Configuration
- Robots.txt directives to block duplicate content crawling
- XML sitemap best practices (include only canonical versions)
- Submission and monitoring steps

### 5. Content Consolidation Recommendations
- Pages to merge or remove
- Content migration workflow
- 301 redirect mapping for consolidated pages

### 6. URL Parameter Handling
- Parameters to exclude from indexing
- Google Search Console URL Parameters tool settings
- CMS configuration adjustments

### 7. Monitoring and Validation
- Tools to verify canonical implementation
- Search Console reports to track
- Ongoing maintenance tasks

Adjust technical depth and terminology to match the specified expertise level. For each major step, explain *why* it matters for duplicate content prevention and SEO performance.
```
