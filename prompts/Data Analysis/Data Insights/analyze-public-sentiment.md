# Public Sentiment Analysis Report Generator

## 簡介

The Public Sentiment Analysis Report Generator is a free AI prompt that transforms raw opinion data into structured reports with actionable insights for data analysts, researchers, and decision-makers. This sentiment analysis prompt for ChatGPT guides the model through collecting data from your specified sources - social media, surveys, news articles, or custom feeds - then applies sentiment categorization (positive, negative, neutral) to surface trends, demographic patterns, and temporal shifts. The prompt structures output into five sections: an executive summary with key takeaways, a methodology breakdown (sample size, time range, classification approach), bulleted findings highlighting sentiment shifts and audience patterns, descriptions of data visualizations (pie charts, trend graphs, word clouds), and 3–5 prioritized recommendations tied directly to your analysis objectives. It runs on ChatGPT, Claude, Gemini, and Grok. Reach for this prompt when you need to turn scattered opinion data into a board-ready report, whether tracking brand perception, policy reactions, product launch reception, or competitive positioning. ● Categorizes sentiment across positive, negative, and neutral dimensions with pattern detection ● Structures output into executive summary, methodology, findings, visualization descriptions, and recommendations ● Adapts to any data source - social platforms, survey results, news feeds, or custom datasets ● Delivers 3–5 prioritized, data-backed actions aligned with your specific analysis objectives ## Prompt

```
## Role
You are an expert data analyst specializing in public sentiment analysis.

## Task
Analyze public sentiment on {{topic}} and deliver a comprehensive report with actionable insights. Use advanced sentiment analysis techniques to categorize opinions, identify trends and patterns, and provide data-driven recommendations.

## Context
**Data sources**: {{data-sources}}
**Target audience for the report**: {{audience}}
**Analysis objectives**: {{analysis-goals}}

Collect data from the specified sources (social media, surveys, news articles, or others listed). Apply sentiment categorization (positive, negative, neutral) and surface meaningful patterns that address the stated objectives.

## Output
Structure the report with:
- **Executive Summary**: high-level sentiment overview and key takeaways
- **Methodology**: data sources used, sample size, time range, sentiment classification approach
- **Findings**: bullet points for major trends, notable sentiment shifts, demographic or temporal patterns
- **Data Visualizations**: describe charts or graphs that would illustrate sentiment distribution, trend lines, and comparative breakdowns
- **Recommendations**: 3–5 prioritized, data-backed actions aligned with the analysis objectives

Use clear headings, concise bullet points, and specify where visualizations (sentiment distribution pie charts, time-series trend graphs, word clouds) should appear.
```
