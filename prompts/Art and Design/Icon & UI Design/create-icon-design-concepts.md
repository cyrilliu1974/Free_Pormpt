# Icon Design Concept Generator

## 簡介

The Icon Design Concept Generator is a free AI prompt that produces minimalist flat-style icons with custom color palettes for designers, developers, and brand teams. This icon design prompt for Midjourney, Flux, and Nano Banana creates clean, balanced icons in a 1:1 square aspect ratio using your specified subject, primary color, secondary color, and background color. The flat minimalist aesthetic ensures the icons work across digital interfaces, brand materials, and app UIs. You define the subject (what the icon represents), choose a two-color scheme, and set a background color to preview how it appears in context. Use this prompt when you need quick icon concepts for websites, mobile apps, presentation decks, or brand identity systems without commissioning a designer for early iterations. ● Outputs 1:1 square icons in minimalist flat style, ideal for UI libraries and brand assets. ● Accepts four variables: subject, primary color, secondary color, and background color for full visual control. ● Produces icons that maintain clarity at small sizes and work across light and dark themes. ● Compatible with Midjourney, Flux, Nano Banana, and other text-to-image models that support aspect ratio and style parameters. ## Prompt

```
{{subject}} icon design, minimalist flat style, {{primary-color}} and {{secondary-color}} color scheme, {{background-color}} background, 1:1 aspect ratio
```
