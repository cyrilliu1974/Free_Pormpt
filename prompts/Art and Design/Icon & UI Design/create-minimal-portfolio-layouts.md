# Minimal Portfolio Layout Generator

## 簡介

The Minimal Portfolio Layout Generator is a free AI prompt that produces modern web UI designs for creative portfolios with cinematic, fullscreen layouts. This minimal portfolio prompt for Midjourney creates asymmetrical split sections featuring high-resolution editorial portraits, bold white sans-serif typography, and interactive scroll transitions with a clean navigation bar. It runs on Midjourney, Flux, and Nano Banana, letting you customize the layout style and color accent through two variables. Designers, developers, and creatives building portfolio sites or mockups can use this to visualize modern interface concepts quickly. ● Produces fullscreen web UI designs with asymmetrical split sections that balance large editorial portraits and bold typography. ● Includes interactive scroll transition concepts and clean navigation elements suited for modern portfolio sites. ● Supports custom layout styles and color accents via prompt variables for brand-aligned mockups. ● Outputs in 16:9 aspect ratio with raw mode for maximum creative control over the composition. ## Prompt

```
Minimal creative portfolio web UI, fullscreen layout, high-resolution editorial portraits, asymmetrical split sections, bold white sans-serif typography, interactive scroll transitions, clean navigation bar, immersive cinematic interface, {{layout-style}}, {{color-accent}}, --ar 16:9 --raw
```
